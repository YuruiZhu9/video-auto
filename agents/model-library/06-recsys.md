## 📌 推荐系统算法学习路径（转行必备）

```
推荐算法知识体系
├── 经典推荐
│   ├── 协同过滤（User-CF / Item-CF）
│   ├── 矩阵分解（FM / SVD++）
│   └── 深度协同过滤（NCF / DCN）
│
├── LLM4Rec（当前前沿）
│   ├── ID vs Semantic ID（语义鸿沟问题）
│   ├── 生成式推荐（BGE → COLD → SEAL）
│   ├── 多模态推荐（LMMRec / VLM2Rec）
│   └── 推荐Agent（Self-Evolving / GRACE）
│
├── 序列建模
│   ├── DIN / DIEN / DSIN（注意力机制）
│   ├── BST / TRAM（Transformer序列）
│   └── 生成式序列（GR2 / TS-Rec）
│
├── 工业级架构
│   ├── 召回 → 粗排 → 精排 → 重排
│   ├── 多目标优化（MMoE / PLE）
│   └── 生成式架构（COBRA+GRAB）
│
└── 评估指标
    ├── 离线：Recall@K / NDCG@K / MRR
    └── 在线：AUC / CTR / CVR / 用户时长
```

# 🏗️ video-auto 架构设计

> video-auto: 从主题+音频到完整配音视频的全自动流水线

---

## 一、系统定位

**一句话：** 输入主题+原始音频，输出带克隆配音的 PPT 网页视频。

**适用场景：**
- 知识博主：图文内容快速视频化
- 企业内训：PPT + 解说词一键生成视频
- 个人 IP：用自己声音做系列内容

---

## 二、技术架构

```
┌─────────────────────────────────────────────────────────┐
│                    用户输入层                            │
│   原始音频(.mp3/.wav) + 文本资料(.md/.txt) + 主题(topic)  │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────┐
│  Step1: 声音克隆                                         │
│  模型: Fish Audio / CosyVoice 3.0（开源免费）             │
│  输入: 原始音频(5-30秒)                                   │
│  输出: 克隆声音模型 / TTS API                              │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────┐
│  Step2: 内容加工扩展                                      │
│  模型: GLM-4-Flash（免费，智谱AI）                        │
│  模型: Qwen3.5-4B（硅基流动，免费）                       │
│  输入: 原始文本 + 主题                                      │
│  输出: 扩展后完整解说词（分段，带时间戳）                    │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────┐
│  Step3: 场景智能分段 🎬 新增（scene_detector.py）           │
│  视觉轨道: FFmpeg场景检测，阈值0.3~0.7可调                  │
│  音频轨道: 静音停顿边界辅助校正                              │
│  智能合并: 最小5s，最大60s，自动避免碎片化                  │
│  输出: [{start, end, duration, index}, ...] + SRT时间戳    │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────┐
│  Step4: HTML Slide 生成 ← ppt-html-generator Skill        │
│  输入: 主题 + 扩展内容                                     │
│  输出: 完整网页版 Slide（单HTML文件，可浏览器预览）           │
│  特性: 渐入动画 / 进度条 / 响应式 / 深色主题                │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────┐
│  Step5: 视频合成                                          │
│  方式A: 截图序列 → batch_image_to_video → 片段            │
│  方式B: Kling 2.0 API（Hypereal免费积分）                 │
│  过渡效果: 统一使用 naming_utils.py 命名                   │
│  输出: slide_*.mp4 片段序列                                │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────┐
│  Step6: 统一文件命名 📋 新增（naming_utils.py）            │
│  格式: {prefix}_{topic_slug}_{date}_{seq:02d}.{ext}       │
│  示例: slide_ai_tuijian_20260406_01.mp4                  │
│        transition_ai_01_to_02_xfade_20260406.mp4        │
│        tts_ai_tuijian_20260406_03.mp3                     │
│  中文主题 → 拼音slug（自动清理特殊字符）                    │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────┐
│  Step7: GitHub 上传                                       │
│  仓库: github.com/YuruiZhu9/video-auto                   │
│  内容: index.html(Slide) + 视频 + README.md 更新           │
└─────────────────────────────────────────────────────────┘
```

## 三、技术选型（免费优先）

| 环节 | 方案 | 费用 | 说明 |
|------|------|------|------|
| 声音克隆 | Fish Audio / CosyVoice 3.0 | 免费开源 | 5秒音频即可克隆，支持中文 |
| 内容生成 | 智谱GLM-4-Flash | 免费 | 200K上下文，永久免费 |
| 内容生成备选 | 硅基流动Qwen3.5-4B | 免费 | 12个模型可选 |
| Slide生成 | ppt-html-generator（自建Skill）| - | HTML + CSS + JS |
| 视频合成 | 截图+ffmpeg+克隆TTS | 免费 | 本地执行 |
| 视频合成备选 | Hypereal AI Kling | 免费积分 | 35积分≈数百秒视频 |
| GitHub | GitHub API + Token | 免费 | ghp_xxx |

## 四、文件结构

```
video-auto/
├── index.html              ← 主Slide（用户访问入口）
├── audio/                  ← 克隆声音样本
│   └── clone_sample.wav
├── content/                ← 内容文件
│   └── script.md
├── video/                  ← 生成的视频
│   └── output.mp4
├── assets/                 ← 静态资源
└── README.md
```

## 五、触发方式

1. **主动触发**：用户向 Agent 发送任务指令
2. **定时触发**：每天 4 次心跳（见下方）
   - 🕐 06:00 — 早间内容预备
   - 🕛 12:00 — 午间发布
   - 🕕 18:00 — 傍晚发布
   - 🕛 00:00 — 夜间存档

心跳独立于其他 Agent 任务，使用 `sessionTarget: isolated`，不与其他任务冲突。

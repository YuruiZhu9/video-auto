# 04 - 代码实现

> 高效编码的核心：明确需求 + 清晰上下文 + 及时验证

## 编码前准备

### 1. 打开CLAUDE.md
确保AI知道项目的：
- 技术栈和版本
- 代码风格约定
- 常用命令
- 目录结构

### 2. 设置上下文
> "这个任务的技术栈是：React 18 + TypeScript + Tailwind"

## 编码最佳实践

### 单任务原则
❌ "帮我同时实现登录和注册"
✅ 一次只实现一个功能，完成后再做下一个

### 增量提交
每完成一个小功能：
1. 运行测试
2. git commit
3. 确保功能可用

### 及时验证
> "这段代码写完后，运行一下看看有没有报错"

## Prompt模板

### 实现新功能
```
实现[功能名称]：
- 位置：[文件路径]
- 依赖：[前置条件]
- 要求：[具体实现要求]
- 验收标准：[怎么算完成]
```

### 修改现有代码
```
修改[文件/模块]：
- 改动点：[具体要改什么]
- 原因：[为什么改]
- 预期结果：[改完后的行为]
```

### 代码审查
```
请审查[文件]：
- 检查点：[安全性/性能/可读性/规范]
- 关注：[特定问题]
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| AI写错了 | 明确指出错误，给出参考实现 |
| 不知道对不对 | 让AI运行代码并解释结果 |
| 上下文太长 | 用/compact压缩上下文 |

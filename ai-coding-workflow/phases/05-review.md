# 05 - 代码审查

> 代码审查是提升质量的关键环节

## AI辅助审查要点

### 安全性检查
- [ ] 敏感信息是否硬编码？
- [ ] SQL注入风险？
- [ ] XSS跨站脚本？
- [ ] 权限校验是否完整？

### 性能检查
- [ ] 数据库查询是否有效索引？
- [ ] 是否有N+1查询问题？
- [ ] 大数据量是否有分页？
- [ ] 是否有不必要的重复计算？

### 可维护性
- [ ] 命名是否清晰？
- [ ] 函数是否过长？（建议<50行）
- [ ] 是否有重复代码？
- [ ] 注释是否充分？

### 规范一致性
- [ ] 是否遵循项目代码风格？
- [ ] 错误处理是否统一？
- [ ] 日志记录是否适当？

## 审查Prompt模板

审查刚写的[文件名]代码：
1. 安全性是否有问题？
2. 性能有哪些可以优化的地方？
3. 代码可读性如何？
4. 还有哪些改进建议？

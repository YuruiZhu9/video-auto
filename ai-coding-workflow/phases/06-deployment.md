# 06 - 部署交付

> 确保代码可运行、可部署

## 交付检查清单

### 功能验证
- [ ] 所有功能测试通过？
- [ ] 手动测试关键流程？
- [ ] 边界情况已处理？

### 代码质量
- [ ] 无lint错误？
- [ ] 单元测试覆盖率>80%？
- [ ] E2E测试通过？

### 部署准备
- [ ] 环境变量配置文档？
- [ ] 数据库迁移脚本？
- [ ] 回滚方案准备？

## 常用部署命令

```bash
# 构建
npm run build

# 测试
npm run test

# lint
npm run lint

# 部署(示例)
npm run deploy
```

## 部署后验证

1. 健康检查：/health 端点
2. 功能测试：核心流程走通
3. 日志检查：无ERROR级别日志

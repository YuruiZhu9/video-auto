# Title:Self-EvolveRec: Self-Evolving Recommender Systems with LLM-based Directional Feedback
Authors: [Sein Kim](https://arxiv.org/search/cs?searchtype=author&query=Kim,+S), [Sangwu Park](https://arxiv.org/search/cs?searchtype=author&query=Park,+S), [Hongseok Kang](https://arxiv.org/search/cs?searchtype=author&query=Kang,+H), [Wonjoong Kim](https://arxiv.org/search/cs?searchtype=author&query=Kim,+W), [Jimin Seo](https://arxiv.org/search/cs?searchtype=author&query=Seo,+J), [Yeonjun In](https://arxiv.org/search/cs?searchtype=author&query=In,+Y), [Kanghoon Yoon](https://arxiv.org/search/cs?searchtype=author&query=Yoon,+K), [Chanyoung Park](https://arxiv.org/search/cs?searchtype=author&query=Park,+C)
View a PDF of the paper titled Self-EvolveRec: Self-Evolving Recommender Systems with LLM-based Directional Feedback, by Sein Kim and 7 other authors
[View PDF](https://arxiv.org/pdf/2602.12612) [HTML (experimental)](https://arxiv.org/html/2602.12612v1)
> Abstract:Traditional methods for automating recommender system design, such as Neural Architecture Search (NAS), are often constrained by a fixed search space defined by human priors, limiting innovation to pre-defined operators. While recent LLM-driven code evolution frameworks shift fixed search space target to open-ended program spaces, they primarily rely on scalar metrics (e.g., NDCG, Hit Ratio) that fail to provide qualitative insights into model failures or directional guidance for improvement. To address this, we propose Self-EvolveRec, a novel framework that establishes a directional feedback loop by integrating a User Simulator for qualitative critiques and a Model Diagnosis Tool for quantitative internal verification. Furthermore, we introduce a Diagnosis Tool - Model Co-Evolution strategy to ensure that evaluation criteria dynamically adapt as the recommendation architecture evolves. Extensive experiments demonstrate that Self-EvolveRec significantly outperforms state-of-the-art NAS and LLM-driven code evolution baselines in both recommendation performance and user satisfaction. Our code is available at [this https URL](https://github.com/Sein-Kim/self\_evolverec).

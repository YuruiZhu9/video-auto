**二、多智能体架构搭建**

**2. 定义Agent职责与权限**

为不同Agent分配差异化权限和职责，确保安全与高效：

主Agent配置（全权限）

openclaw config set skills.permission-manager.agents.media-manager.permissions '["file:read", "file:write", "api:call", "monitor(view"]'

微信公众号Agent配置（内容生成+API调用）

openclaw config set skills.permission-manager.agents.media-wechat.permissions '["file:read", "api:call:bailian"]'

小红书Agent配置（内容生成+API调用）

openclaw config set skills.permission-manager.agents媒体-xhs.permissions '["file:read", "api:call:bailian"]'

重启网关

openclaw gateway restart

**3. 常见问题排查**

部署过程中可能遇到的问题及解决方案：

1. 端口被占用

- 解决方案：执行lsof -i:18789（macOS/Linux）或netstat -ano | findstr "18789"（Windows），终止占用进程后重启服务

2. API调用失败

- 检查日志：tail -n 100 /root/.openclaw/logs/openclaw.log

- 常见错误：API密钥错误、IP未在白名单、模型调用额度耗尽

- 解决方案：核对API密钥、更新IP白名单、检查模型调用额度

3. 内容生成质量不佳

- 检查提示词：确保提示词清晰明确，包含足够细节

- 调整模型参数：修改config.yaml中的temperature（0.2-0.8）和maxTokens（500-2000）

- 尝试不同模型：OpenClaw支持多种大模型，可切换为智谱AI、MiniMax等

4. 草稿箱同步失败

- 检查API凭证：确保微信公众号和小红书的API凭证有效

- 验证网络连接：执行ping api.weixin.qq.com和ping api.xiaohongshu.com

- 更新Skill：执行openclaw skills update wechat-property和openclaw skills update xiaohongshu-publisher

一、先搞懂：Skill 是什么？怎么装？（小白必看）
--------------------------

### 1. 什么是 Skills？

* **Skill = 插件/功能包**，让 OpenClaw 拥有真实执行能力
* **Tool = 器官**（能不能做）；**Skill = 教程**（怎么做）
* 安装一行命令，不用写代码，不用懂原理

### 2. 4条万能命令（记住就够）

```
# 1. 安装技能管理器（必装）
npm i -g clawhub
# 2. 安装技能
clawhub install 技能名
# 3. 搜索技能
clawhub search 关键词
# 4. 更新所有技能
clawhub update --all

```
### 3. 黄金安装顺序（避免踩坑）

1. 先装**安全审查**技能
2. 再装**基础能力**（搜索、浏览器、记忆）
3. 最后装**场景技能**（办公、开发、自媒体）
4. 不用的技能及时关闭，避免卡顿与风险

二、必装底座技能（所有用户第一步）
-----------------

这8个是**地基**，不装其他技能都白搭！

### 1. skill-vetter（安全审查官）

* 作用：装任何技能前先扫描，防病毒、防偷数据
* 命令：`clawhub install skill-vetter`
* 必装理由：ClawHub曾查出341个恶意技能，这个是保命盾

### 2. clawhub（技能商店）

* 作用：搜索、安装、管理所有技能
* 命令：`npm i -g clawhub`
* 地位：OpenClaw的应用商店，没有它无法扩展

### 3. tavily-search（AI专属联网搜索）

* 作用：AI专用精准搜索，无广告、直接给结果
* 命令：`clawhub install tavily-search`
* 亮点：比百度/谷歌更适合AI读取，做总结、调研神器

### 4. agent-browser（浏览器自动化）

* 作用：AI自己操控浏览器，点按钮、填表单、截网页、下文件
* 命令：`clawhub install agent-browser`
* 神技：自动抢票、监控价格、采集数据

### 5. self-improving-agent（自我进化）

* 作用：AI越用越聪明，记住错误、优化流程、不重复踩坑
* 命令：`clawhub install self-improving-agent`
* 亮点：本地运行，不泄露隐私

### 6. agent-memory（永久记忆）

* 作用：记住你的习惯、工作流、常用信息
* 命令：`clawhub install agent-memory`
* 效果：不用每次重复说明需求，AI秒懂你

### 7. summarize（万能总结）

* 作用：PDF、网页、视频、长文一键提炼要点
* 命令：`clawhub install summarize`
* 效率：100页报告30秒读完

### 8. cron（定时任务）

* 作用：每天/每周自动执行任务（早报、监控、发消息）
* 命令：`clawhub install cron`
* 场景：自动发日报、定时查资讯、监控网站

十、超重要避坑指南（重点！）
--------------

1. **先装安全技能**，再装其他技能
2. **不装来源不明**、低星、无更新的技能
3. 高权限技能（shell、agent-browser）**必须开确认**
4. 不用的技能及时关闭，避免卡顿与泄露
5. 定期执行：`clawhub update --all` 保持最新

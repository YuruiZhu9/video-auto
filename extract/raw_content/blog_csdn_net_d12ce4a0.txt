### 二、阿里魔搭社区（ModelScope）：2000 次/天的稳定之选

#### 2.1 平台背景与免费政策

[魔搭社区（ModelScope）](https://modelscope.cn) 是阿里云推出的**模型开放平台**，集成了通义千问（Qwen）系列、语音、视觉等数千个开源与闭源模型。自 2025 年起，平台为所有实名用户开放**每日 2000 次免费 API 调用额度**，成为开发者首选。

##### ✅ 免费额度细则：

* **总量**：2000 次/天（UTC+8 00:00 重置）
* **单模型上限**：500 次/天（防止单点滥用）
* **支持模型**：`qwen-max`、`qwen-plus`、`qwen-turbo`、`qwen-vl`（多模态）等
* **有效期**：长期有效，无试用期限制

> 📌 **注意**：需在模型详情页确认“**支持免费调用**”标签，部分新模型可能暂未纳入。

#### 2.2 获取 API Key 步骤

1. 访问 <https://modelscope.cn>，登录阿里云账号；
2. 点击右上角头像 → **「个人中心」**；
3. 左侧菜单选择 **「访问令牌」** → **「创建令牌」**；
4. 输入名称（如 `dev-free-api`），勾选 **「大模型推理」** 权限；
5. 复制生成的 **Token**（即 API Key），妥善保存。

> 🔒 **安全提示**：该 Token 具有全局权限，请勿泄露或提交至公共代码库。

#### 2.3 API 调用实战（Python）

魔搭 API 基于 DashScope，接口设计接近 OpenAI，但需注意字段差异。

##### 安装依赖

```
pip install requests python-dotenv

```
##### 完整调用脚本（含错误处理）

```
# qwen_api_demo.py
import os
import requests
from dotenv import load_dotenv

load_dotenv()  # 从 .env 文件加载 API_KEY

API_KEY = os.getenv("MODELSCOPE_API_KEY")
BASE_URL = "https://dashscope.aliyuncs.com/api/v1/services/aigc/text-generation/generation"

def call_qwen(model: str, prompt: str, max_tokens: int = 512) -> str:
    """
    调用 Qwen 系列模型
    
    Args:
        model: 模型名称，如 "qwen-max"
        prompt: 用户输入
        max_tokens: 最大生成长度
    
    Returns:
        模型回复文本
    """
    headers = {
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json"
    }
    
    payload = {
        "model": model,
        "input": {
            "messages": [{"role": "user", "content": prompt}]
        },
        "parameters": {
            "max_tokens": max_tokens,
            "temperature": 0.7,
            "top_p": 0.9
        }
    }
    
    try:
        response = requests.post(BASE_URL, headers=headers, json=payload, timeout=30)
        response.raise_for_status()
        data = response.json()
        
        if "output" in data and "choices" in data["output"]:
            return data["output"]["choices"][0]["message"]["content"]
        else:
            raise ValueError(f"Unexpected response format: {data}")
            
    except requests.exceptions.RequestException as e:
        print(f"网络请求失败: {e}")
        return None
    except Exception as e:
        print(f"解析响应失败: {e}")
        return None

# 使用示例
if __name__ == "__main__":
    result = call_qwen("qwen-max", "用 Python 实现快速排序，并解释时间复杂度。")
    if result:
        print("模型回复：\n", result)
    else:
        print("调用失败，请检查 API Key 或网络。")

```
##### `.env` 文件示例

```
MODELSCOPE_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

```
> ⚠️ **调试技巧**：
> 
> * 若返回 `403 Forbidden`，检查 Token 是否过期或权限不足；
> * 若返回 `400 Bad Request`，确认 `model` 名称是否正确（区分大小写）；
> * 使用 `curl` 快速测试：

### 三、百度千帆（QianFan）：中文任务专家，500 次/天

#### 3.1 平台特色与免费策略

[百度千帆大模型平台](https://cloud.baidu.com/product/qianfan) 是文心大模型的官方 API 入口。其**每日 500 次免费调用额度**虽低于阿里，但在**中文语义理解、搜索增强、插件调用**方面表现卓越。

##### ✅ 免费额度说明：

* **调用次数**：500 次/天（00:00 重置）
* **Token 折算**：约 1.6 万 Tokens/天（按平均 32 tokens/次估算）
* **支持模型**：`ERNIE-Bot-4.5`（旗舰）、`ERNIE-Bot-turbo`（高速）、`ERNIE-Character`（角色扮演）

> 📌 **优势**：集成百度搜索，可实时获取最新信息（需开启 `disable_search: false`）。

#### 3.2 获取 API Key（AK/SK）

百度采用 **Access Key (AK) + Secret Key (SK)** 的签名认证机制：

1. 登录 [百度智能云控制台](https://console.bce.baidu.com/)
2. 进入 **「千帆大模型」** → **「API 密钥管理」**
3. 点击 **「创建密钥」**，记录 `Access Key ID` 和 `Secret Access Key`
4. 在环境变量中配置：
   ```
   QIANFAN_ACCESS_KEY=your_ak
   QIANFAN_SECRET_KEY=your_sk
   
   ```

#### 3.3 官方 SDK 调用示例

百度提供 `qianfan` Python SDK，简化签名流程。

##### 安装 SDK

```
pip install qianfan

```
##### 调用代码

```
from qianfan import ChatCompletion
import os

# 环境变量自动读取 AK/SK
os.environ["QIANFAN_ACCESS_KEY"] = "your_ak"
os.environ["QIANFAN_SECRET_KEY"] = "your_sk"

def call_ernie(prompt: str, model: str = "ERNIE-Bot-4.5") -> str:
    """调用文心大模型"""
    try:
        resp = ChatCompletion().do(
            model=model,
            messages=[{"role": "user", "content": prompt}],
            temperature=0.7,
            top_p=0.9,
            disable_search=False  # 启用联网搜索
        )
        return resp["result"]
    except Exception as e:
        print(f"调用失败: {e}")
        return None

# 测试
print(call_ernie("2026 年春节是几月几日？"))

```
> 💡 **小贴士**：
> 
> * `disable_search=False` 可让模型联网查询最新信息；
> * 使用 `system` 角色可设定 AI 人设，如 `"你是一位资深 Python 工程师"`。

### 四、蚂蚁 Ling Studio：50 万 Tokens/天，OpenAI 兼容最佳

#### 4.1 为什么 Ling Studio 是“隐藏王者”？

[Ling Studio](https://ling-studio.antgroup.com) 是蚂蚁集团于 2025 年底推出的**大模型开放平台**，主打 **高性能、高并发、高兼容性**。其**每日 50 万 Tokens 免费额度**为国内最高，且 API 设计**高度兼容 OpenAI**，迁移成本极低。

##### ✅ 核心优势：

* **50 万 Tokens/天**（约 37.5 万中文字符）
* **OpenAI 格式 90% 兼容**（仅需替换 base\_url 和 api\_key）
* **首 Token 延迟 < 800ms**
* 支持 **文件上传、函数调用、自定义角色**

#### 4.2 注册与 API Key 获取

1. 访问 <https://ling-studio.antgroup.com>
2. 使用支付宝扫码登录（需完成实名）
3. 进入 **「API 管理」** → **「创建 Key」**
4. 复制 `API Key`，格式为 `lsk_xxxxxx`

> 📌 **注意**：目前仅对中国大陆用户开放，需绑定大陆手机号。

#### 4.3 OpenAI 兼容调用（零代码修改）

假设你已有 OpenAI 调用代码，只需两处修改：

##### 原 OpenAI 代码

```
from openai import OpenAI
client = OpenAI(api_key="sk-...")

```
##### 修改为 Ling Studio

```
from openai import OpenAI
client = OpenAI(
    api_key="lsk_xxxxxx",  # 替换为 Ling Key
    base_url="https://ling-studio.antgroup.com/v1"  # 替换 endpoint
)

```
##### 完整示例

```
from openai import OpenAI

client = OpenAI(
    api_key=os.getenv("LING_API_KEY"),
    base_url="https://ling-studio.antgroup.com/v1"
)

response = client.chat.completions.create(
    model="Ling-1T",
    messages=[{"role": "user", "content": "解释 Transformer 架构"}],
    max_tokens=512
)
print(response.choices[0].message.content)

```
> ✅ **优势**：
> 
> * 无需学习新接口；
> * 可直接用于现有 LangChain、LlamaIndex 项目；
> * 支持 `stream=True` 流式输出。

### 六、避坑指南：常见问题与解决方案

#### ❓ Q1：调用返回 “403 Forbidden” 怎么办？

* **原因**：API Key 无效、未实名、或 IP 被风控。
* **解决**：
  1. 检查 Key 是否复制完整；
  2. 确认账号已完成实名认证；
  3. 更换网络环境（避免代理或数据中心 IP）。

#### ❓ Q2：免费额度用完后会收费吗？

* **不会自动扣费**！所有平台均需**手动开通按量付费**才会产生费用。免费额度用尽后，API 将返回 `429 Too Many Requests`。

#### ❓ Q3：能否多个账号叠加使用？

* **可以**，但需注意：
  + 百度/腾讯限制同一身份证注册多个账号；
  + 阿里/蚂蚁允许，但建议合理使用，避免触发反爬。

#### ❓ Q4：如何监控当日剩余额度？

* **阿里魔搭**：控制台 → 「用量统计」
* **百度千帆**：「配额管理」页面
* **Ling Studio**：API 返回头包含 `X-RateLimit-Remaining`

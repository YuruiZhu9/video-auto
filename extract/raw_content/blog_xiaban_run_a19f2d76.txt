安装[#](#安装)
----------

首先需要确保已经安装了 [python](https://www.python.org/downloads/) **3.11 版本**, 如果本地的 `python` 版本不在 `3.8 ~ 3.11` 范围内, 可以使用 `pyenv` 来安装 `python`, 详见 [pyenv](#pyenv) 章节

Terminal window

```
1pip install -U openai-whisper
```
### pyenv[#](#pyenv)

> TIP
> 
> 对于安装 `openai-whisper` 来说, `pyenv` 是可选的, **只有在本地 `python` 版本不是 `3.8 ~ 3.11` 才需要安装**

1. `whisper` 需要的 `python` 版本是 `3.8 ~ 3.11`, 所以需要安装 `pyenv` 来 **管理和切换 `python` 版本**, 以 `MacOS` 环境为例, 我们可以直接使用 `brew` 安装

Terminal window

```
1brew update2brew install pyenv
```

1. 配置环境变量, 这里我是用的是 `fish shell`:

Terminal window

```
1set -Ux PYENV_ROOT $HOME/.pyenv2test -d $PYENV_ROOT/bin; and fish_add_path $PYENV_ROOT/bin3
4pyenv init - fish | source
```

1. 切换 `python` 版本, 这里我选择的是 `3.11.x`

Terminal window

```
1# 1. 首先查看 3.11.x 的所有版本(可选)2pyenv install -l | grep 3.113
4  3.11.05  3.11-dev6  3.11.17  3.11.28  3.11.39  3.11.410  3.11.511  3.11.612  3.11.713  3.11.814  3.11.915  3.11.1016  3.11.1117  3.11.1218  3.11.1319  3.11.1420  ...
```

Terminal window

```
1# 2. 设置下载镜像(可选, 这是 fish shell 的设置命令, 其他 shell 请自行修改)2set -Ux PYTHON_BUILD_MIRROR_URL https://mirrors.tuna.tsinghua.edu.cn/python3
4# 3. 安装 3.11.145pyenv install 3.11.146
7# 4. 切换到 3.11.14, 这里我们选择只在当前 shell 中切换8pyenv shell 3.11.14 # ✅ 只在当前 shell 生效, 不会影响全局的 python 环境9# pyenv local 3.11.14 # 位于当前目录下时自动选择此版本10# pyenv global 3.11.14 # 全局切换版本
```
> NOTE
> 
> 如果切换时提示 `pyenv: shell integration not enabled. Run 'pyenv init' for instructions.`, 则需要 执行 `pyenv init` 命令, 并且按照输出的提示进行操作, 例如在 `fish shell` 下是需要执行 `pyenv init - fish | source`

Terminal window

```
1# 5. 查看 python 版本2python --version
```
> TIP
> 
> 其他系统的安装方式参考 [pyenv - Installation](https://github.com/pyenv/pyenv?tab=readme-ov-file#installation), `pyenv` 并不支持 `windows`, 可使用 [pyenv-win](https://github.com/pyenv-win/pyenv-win?tab=readme-ov-file#quick-start)


ffmpeg[#](#ffmpeg)
------------------

whisper 需要 `ffmpeg` 来处理音频文件, 所以需要安装 `ffmpeg`

你可以直接下载: [ffmpeg - Download](https://ffmpeg.org/download.html)

或者通过命令行工具安装:

Terminal window

```
1# on Ubuntu or Debian2sudo apt update && sudo apt install ffmpeg3
4# on Arch Linux5sudo pacman -S ffmpeg6
7# on MacOS using Homebrew (https://brew.sh/)8brew install ffmpeg9
10# on Windows using Chocolatey (https://chocolatey.org/)11choco install ffmpeg12
13# on Windows using Scoop (https://scoop.sh/)14scoop install ffmpeg
```

选择模型和语言[#](#选择模型和语言)
--------------------

有 [以下模型](https://github.com/openai/whisper?tab=readme-ov-file#available-models-and-languages) 可选择:

| Size | Parameters | English-only model | Multilingual model | Required VRAM | Relative speed |
| --- | --- | --- | --- | --- | --- |
| tiny | 39 M | `tiny.en` | `tiny` | ~1 GB | ~10x |
| base | 74 M | `base.en` | `base` | ~1 GB | ~7x |
| small | 244 M | `small.en` | `small` | ~2 GB | ~4x |
| medium | 769 M | `medium.en` | `medium` | ~5 GB | ~2x |
| large | 1550 M | `N/A` | `large` | ~10 GB | 1x |
| turbo | 809 M | `N/A` | `turbo` | ~6 GB | ~8x |

由于我们需要识别的是中文普通话, 所以只能选择 `Multilingual model`, 然后我们安装本地的内存大小选择适合的模型, 这里我选择 `large`


使用[#](#使用)
----------

接下来我们尝试使用 [yd-dlp](https://github.com/yt-dlp/yt-dlp) 从 `bilibili` 获取视频, 然后使用 `ffmpeg` 提取其中的音频, 再交给 `whisper` 进行语音识别, 最终提取视频中的语音文本:

### yt-dlp[#](#yt-dlp)

> TIP
> 
> 💡 实际上可以直接使用 `yt-dlp` 提取音频, **这里为了演示增加了 `ffmpeg` 提取的操作, 详见 [直接下载音频](#%E7%9B%B4%E6%8E%A5%E4%B8%8B%E8%BD%BD%E9%9F%B3%E9%A2%91) 章节**

我们随便找一个自己喜欢的视频, 这里为了直观的感受语音识别的准确率, 我们找一个翻唱视频:

#### 下载视频[#](#下载视频)

由于 B 站是视频和音频分离的, 所以我们可以直接下载音频文件

Terminal window

```
1# 查看可以下载的视频资源格式2yt-dlp "https://www.bilibili.com/video/BV1bJ41137yp" -F
```

![]()

然后我们按照 id 来下载视频和音频文件, 最终下载的是 `.mp4` 格式的音频文件:

Terminal window

```
1yt-dlp "https://www.bilibili.com/video/BV1bJ41137yp" -f 30280+100026 -o "说好不哭.mp4"
```

![]()

#### 提取音频[#](#提取音频)

我们使用 `ffmpeg` 提取音频文件:

Terminal window

```
1ffmpeg -i 说好不哭.mp4 -vn -c:a copy 说好不哭-audio.m4a
```
#### 直接下载音频[#](#直接下载音频)

或者我们选择 `audio only` 中质量最高的音频文件进行下载

Terminal window

```
1yt-dlp "https://www.bilibili.com/video/BV1bJ41137yp" -f 30280 -o "说好不哭.m4a"
```

![]()

### 使用 whisper 识别语音[#](#使用-whisper-识别语音)

最终, 我们得到了此视频的音频文件 `说好不哭.m4a`, 我们使用 `whisper` 识别:

Terminal window

```
1whisper 说好不哭.m4a --model large --language Chinese
```

![]()

> TIP
> 
> 首次执行需要下载对应的模型

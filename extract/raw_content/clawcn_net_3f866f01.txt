# ClawHub [​](https://clawcn.net/tools/clawhub\#clawhub)
ClawHub 是 \*\*OpenClaw 的公共技能注册表\*\*。它是一项免费服务：所有技能都是公开、开放的，对所有人可见，可供分享和重用。技能只是一个包含 `SKILL.md` 文件（加上支持的文本文件）的文件夹。您可以在 Web 应用中浏览技能，或使用 CLI 搜索、安装、更新和发布技能。
站点： [clawhub.ai](https://clawhub.ai/)
## ClawHub 是什么 [​](https://clawcn.net/tools/clawhub\#clawhub-%E6%98%AF%E4%BB%80%E4%B9%88)
- OpenClaw 技能的公共注册表。
- 技能包和元数据的版本化存储。
- 用于搜索、标签和使用信号的发现界面。
## 工作原理 [​](https://clawcn.net/tools/clawhub\#%E5%B7%A5%E4%BD%9C%E5%8E%9F%E7%90%86)
1. 用户发布技能包（文件 \+ 元数据）。
2. ClawHub 存储该包，解析元数据并分配版本。
3. 注册表为搜索和发现建立技能索引。
4. 用户在 OpenClaw 中浏览、下载和安装技能。
## 您可以做什么 [​](https://clawcn.net/tools/clawhub\#%E6%82%A8%E5%8F%AF%E4%BB%A5%E5%81%9A%E4%BB%80%E4%B9%88)
- 发布新技能和现有技能的新版本。
- 通过名称、标签或搜索发现技能。
- 下载技能包并检查其文件。
- 举报滥用或不安全的技能。
- 如果您是管理员，可以隐藏、取消隐藏、删除或封禁。
## 适用对象（新手友好） [​](https://clawcn.net/tools/clawhub\#%E9%80%82%E7%94%A8%E5%AF%B9%E8%B1%A1-%E6%96%B0%E6%89%8B%E5%8F%8B%E5%A5%BD)
如果您想为 OpenClaw 智能体添加新功能，ClawHub 是查找和安装技能的最简单方式。您不需要了解后端的工作原理。您可以：
- 使用自然语言搜索技能。
- 将技能安装到您的工作区。
- 稍后使用一条命令更新技能。
- 通过发布来备份您自己的技能。
## 快速开始（非技术性） [​](https://clawcn.net/tools/clawhub\#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B-%E9%9D%9E%E6%8A%80%E6%9C%AF%E6%80%A7)
1. 安装 CLI（参见下一节）。
2. 搜索您需要的内容：
- `clawhub search "calendar"`
3. 安装技能：
- `clawhub install `
4. 启动新的 OpenClaw 会话，以便它获取新技能。

## 如何融入 OpenClaw [​](https://clawcn.net/tools/clawhub\#%E5%A6%82%E4%BD%95%E8%9E%8D%E5%85%A5-openclaw)
默认情况下，CLI 将技能安装到当前工作目录下的 `./skills`。如果配置了 OpenClaw 工作区，`clawhub` 会回退到该工作区，除非您覆盖 `--workdir`（或 `CLAWHUB\_WORKDIR`）。OpenClaw 从 `/skills` 加载工作区技能，并在 \*\*下一个\*\* 会话中获取它们。如果您已经使用 `~/.openclaw/skills` 或捆绑技能，工作区技能优先。
有关如何加载、共享和控制技能的更多详细信息，请参阅 [Skills](https://clawcn.net/tools/skills.html)。
## 技能系统概述 [​](https://clawcn.net/tools/clawhub\#%E6%8A%80%E8%83%BD%E7%B3%BB%E7%BB%9F%E6%A6%82%E8%BF%B0)
技能是版本化的文件包，教 OpenClaw 如何执行特定任务。每次发布都会创建一个新版本，注册表保留版本历史记录，以便用户审计更改。
典型技能包括：
- 包含主要描述和用法的 `SKILL.md` 文件。
- 技能使用的可选配置、脚本或支持文件。
- 元数据，如标签、摘要和安装要求。
ClawHub 使用元数据来支持发现并安全地公开技能功能。注册表还跟踪使用信号（如星标和下载量）以改进排名和可见性。
## 服务提供的功能 [​](https://clawcn.net/tools/clawhub\#%E6%9C%8D%E5%8A%A1%E6%8F%90%E4%BE%9B%E7%9A%84%E5%8A%9F%E8%83%BD)
- 技能及其 `SKILL.md` 内容的 \*\*公开浏览\*\*。
- 由嵌入（向量搜索）支持的 \*\*搜索\*\*，不仅仅是关键词。
- 使用 semver、变更日志和标签（包括 `latest`）的 \*\*版本控制\*\*。
- 每个版本的 zip \*\*下载\*\*。
- 用于社区反馈的 \*\*星标和评论\*\*。
- 用于审批和审计的 \*\*审核\*\* 钩子。
- 用于自动化和脚本的 \*\*CLI 友好 API\*\*。
## 安全和审核 [​](https://clawcn.net/tools/clawhub\#%E5%AE%89%E5%85%A8%E5%92%8C%E5%AE%A1%E6%A0%B8)
ClawHub 默认开放。任何人都可以上传技能，但 GitHub 账户必须至少有一周的历史才能发布。这有助于减缓滥用，而不会阻止合法贡献者。
举报和审核：
- 任何已登录用户都可以举报技能。
- 需要提供并记录举报原因。
- 每个用户最多可以同时有 20 个活跃举报。
- 超过 3 个不同举报的技能默认自动隐藏。
- 管理员可以查看隐藏的技能，取消隐藏、删除或封禁用户。
- 滥用举报功能可能导致账户封禁。
有兴趣成为管理员？请在 OpenClaw Discord 中询问并联系管理员或维护者。
## CLI 命令和参数 [​](https://clawcn.net/tools/clawhub\#cli-%E5%91%BD%E4%BB%A4%E5%92%8C%E5%8F%82%E6%95%B0)
全局选项（适用于所有命令）：
- `--workdir `：工作目录（默认：当前目录；回退到 OpenClaw 工作区）。
- `--dir `：技能目录，相对于工作目录（默认：`skills`）。
- `--site `：站点基础 URL（浏览器登录）。
- `--registry `：注册表 API 基础 URL。
- `--no-input`：禁用提示（非交互式）。
- `-V, --cli-version`：打印 CLI 版本。
认证：
- `clawhub login`（浏览器流程）或 `clawhub login --token `
- `clawhub logout`
- `clawhub whoami`
选项：
- `--token `：粘贴 API 令牌。
- `--label `：为浏览器登录令牌存储的标签（默认：`CLI token`）。
- `--no-browser`：不打开浏览器（需要 `--token`）。
搜索：
- `clawhub search "query"`
- `--limit `：最大结果数。
安装：
- `clawhub install `
- `--version `：安装特定版本。
- `--force`：如果文件夹已存在则覆盖。
更新：
- `clawhub update `
- `clawhub update --all`
- `--version `：更新到特定版本（仅单个 slug）。
- `--force`：当本地文件与任何已发布版本不匹配时覆盖。
列表：
- `clawhub list`（读取 `.clawhub/lock.json`）
发布：
- `clawhub publish `
- `--slug `：技能 slug。
- `--name `：显示名称。
- `--version `：Semver 版本。
- `--changelog `：变更日志文本（可以为空）。
- `--tags `：逗号分隔的标签（默认：`latest`）。
删除/取消删除（仅所有者/管理员）：
- `clawhub delete  --yes`
- `clawhub undelete  --yes`
同步（扫描本地技能 \+ 发布新的/更新的）：
- `clawhub sync`
- `--root `：额外扫描根目录。
- `--all`：无提示上传所有内容。
- `--dry-run`：显示将要上传的内容。
- `--bump `：更新的 `patch|minor|major`（默认：`patch`）。
- `--changelog `：非交互式更新的变更日志。
- `--tags `：逗号分隔的标签（默认：`latest`）。
- `--concurrency `：注册表检查（默认：4）。

## 高级详细信息（技术性） [​](https://clawcn.net/tools/clawhub\#%E9%AB%98%E7%BA%A7%E8%AF%A6%E7%BB%86%E4%BF%A1%E6%81%AF-%E6%8A%80%E6%9C%AF%E6%80%A7)
### 版本控制和标签 [​](https://clawcn.net/tools/clawhub\#%E7%89%88%E6%9C%AC%E6%8E%A7%E5%88%B6%E5%92%8C%E6%A0%87%E7%AD%BE)
- 每次发布都会创建一个新的 \*\*semver\*\*`SkillVersion`。
- 标签（如 `latest`）指向一个版本；移动标签可以回滚。
- 每个版本都附加变更日志，在同步或发布更新时可以为空。
### 本地更改与注册表版本 [​](https://clawcn.net/tools/clawhub\#%E6%9C%AC%E5%9C%B0%E6%9B%B4%E6%94%B9%E4%B8%8E%E6%B3%A8%E5%86%8C%E8%A1%A8%E7%89%88%E6%9C%AC)
更新通过内容哈希将本地技能内容与注册表版本进行比较。如果本地文件与任何已发布版本不匹配，CLI 会在覆盖前询问（或在非交互式运行中需要 `--force`）。
### 同步扫描和回退根目录 [​](https://clawcn.net/tools/clawhub\#%E5%90%8C%E6%AD%A5%E6%89%AB%E6%8F%8F%E5%92%8C%E5%9B%9E%E9%80%80%E6%A0%B9%E7%9B%AE%E5%BD%95)
`clawhub sync` 首先扫描您当前的工作目录。如果未找到技能，它会回退到已知的旧位置（例如 `~/openclaw/skills` 和 `~/.openclaw/skills`）。这是为了在不需要额外标志的情况下找到旧的技能安装。
### 存储和锁文件 [​](https://clawcn.net/tools/clawhub\#%E5%AD%98%E5%82%A8%E5%92%8C%E9%94%81%E6%96%87%E4%BB%B6)
- 已安装的技能记录在工作目录下的 `.clawhub/lock.json` 中。
- 认证令牌存储在 ClawHub CLI 配置文件中（通过 `CLAWHUB\_CONFIG\_PATH` 覆盖）。
### 遥测（安装计数） [​](https://clawcn.net/tools/clawhub\#%E9%81%A5%E6%B5%8B-%E5%AE%89%E8%A3%85%E8%AE%A1%E6%95%B0)
当您在登录状态下运行 `clawhub sync` 时，CLI 会发送最小快照以计算安装次数。您可以完全禁用它：
bash
```
export CLAWHUB\_DISABLE\_TELEMETRY=1
```
1
## 环境变量 [​](https://clawcn.net/tools/clawhub\#%E7%8E%AF%E5%A2%83%E5%8F%98%E9%87%8F)
- `CLAWHUB\_SITE`：覆盖站点 URL。
- `CLAWHUB\_REGISTRY`：覆盖注册表 API URL。
- `CLAWHUB\_CONFIG\_PATH`：覆盖 CLI 存储令牌/配置的位置。
- `CLAWHUB\_WORKDIR`：覆盖默认工作目录。
- `CLAWHUB\_DISABLE\_TELEMETRY=1`：在 `sync` 上禁用遥测。

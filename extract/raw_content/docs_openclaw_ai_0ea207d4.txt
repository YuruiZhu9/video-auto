# [​](https://docs.openclaw.ai/zh-CN/install\#%E5%AE%89%E8%A3%85) 安装
除非有特殊原因，否则请使用安装器。它会设置 CLI 并运行新手引导。
## [​](https://docs.openclaw.ai/zh-CN/install\#%E5%BF%AB%E9%80%9F%E5%AE%89%E8%A3%85%EF%BC%88%E6%8E%A8%E8%8D%90%EF%BC%89) 快速安装（推荐）
复制
```
curl -fsSL https://openclaw.ai/install.sh | bash
```
Windows（PowerShell）：
复制
```
iwr -useb https://openclaw.ai/install.ps1 | iex
```
下一步（如果你跳过了新手引导）：
复制
```
openclaw onboard --install-daemon
```
## [​](https://docs.openclaw.ai/zh-CN/install\#%E7%B3%BB%E7%BB%9F%E8%A6%81%E6%B1%82) 系统要求
- \*\*Node >=22\*\*
- macOS、Linux 或通过 WSL2 的 Windows
- `pnpm` 仅在从源代码构建时需要
## [​](https://docs.openclaw.ai/zh-CN/install\#%E9%80%89%E6%8B%A9%E5%AE%89%E8%A3%85%E8%B7%AF%E5%BE%84) 选择安装路径
### [​](https://docs.openclaw.ai/zh-CN/install\#1%EF%BC%89%E5%AE%89%E8%A3%85%E5%99%A8%E8%84%9A%E6%9C%AC%EF%BC%88%E6%8E%A8%E8%8D%90%EF%BC%89) 1）安装器脚本（推荐）
通过 npm 全局安装 `openclaw` 并运行新手引导。
复制
```
curl -fsSL https://openclaw.ai/install.sh | bash
```
安装器标志：
复制
```
curl -fsSL https://openclaw.ai/install.sh | bash -s -- --help
```
详情： [安装器内部原理](https://docs.openclaw.ai/install/installer)。非交互式（跳过新手引导）：
复制
```
curl -fsSL https://openclaw.ai/install.sh | bash -s -- --no-onboard
```
### [​](https://docs.openclaw.ai/zh-CN/install\#2%EF%BC%89%E5%85%A8%E5%B1%80%E5%AE%89%E8%A3%85%EF%BC%88%E6%89%8B%E5%8A%A8%EF%BC%89) 2）全局安装（手动）
如果你已经有 Node：
复制
```
npm install -g openclaw@latest
```
如果你全局安装了 libvips（macOS 上通过 Homebrew 安装很常见）且 `sharp` 安装失败，请强制使用预构建二进制文件：
复制
```
SHARP\_IGNORE\_GLOBAL\_LIBVIPS=1 npm install -g openclaw@latest
```
如果你看到 `sharp: Please add node-gyp to your dependencies`，要么安装构建工具（macOS：Xcode CLT + `npm install -g node-gyp`），要么使用上面的 `SHARP\_IGNORE\_GLOBAL\_LIBVIPS=1` 变通方法来跳过原生构建。或使用 pnpm：
复制
```
pnpm add -g openclaw@latest
pnpm approve-builds -g # 批准 openclaw、node-llama-cpp、sharp 等
pnpm add -g openclaw@latest # 重新运行以执行 postinstall 脚本
```
pnpm 需要显式批准带有构建脚本的包。在首次安装显示”Ignored build scripts”警告后，运行 `pnpm approve-builds -g` 并选择列出的包，然后重新运行安装以执行 postinstall 脚本。然后：
复制
```
openclaw onboard --install-daemon
```
### [​](https://docs.openclaw.ai/zh-CN/install\#3%EF%BC%89%E4%BB%8E%E6%BA%90%E4%BB%A3%E7%A0%81%EF%BC%88%E8%B4%A1%E7%8C%AE%E8%80%85/%E5%BC%80%E5%8F%91%EF%BC%89) 3）从源代码（贡献者/开发）
复制
```
git clone https://github.com/openclaw/openclaw.git
cd openclaw
pnpm install
pnpm ui:build # 首次运行时自动安装 UI 依赖
pnpm build
openclaw onboard --install-daemon
```
提示：如果你还没有全局安装，请通过 `pnpm openclaw ...` 运行仓库命令。

## [​](https://docs.openclaw.ai/zh-CN/install\#%E5%AE%89%E8%A3%85%E5%90%8E) 安装后
- 运行新手引导：`openclaw onboard --install-daemon`
- 快速检查：`openclaw doctor`
- 检查 Gateway 网关健康状态：`openclaw status` \+ `openclaw health`

## [​](https://docs.openclaw.ai/zh-CN/install\#%E5%AE%89%E8%A3%85%E6%96%B9%E5%BC%8F%EF%BC%9Anpm-vs-git%EF%BC%88%E5%AE%89%E8%A3%85%E5%99%A8%EF%BC%89) 安装方式：npm vs git（安装器）
安装器支持两种方式：
- `npm`（默认）：`npm install -g openclaw@latest`
- `git`：从 GitHub 克隆/构建并从源代码 checkout 运行
### [​](https://docs.openclaw.ai/zh-CN/install\#cli-%E6%A0%87%E5%BF%97) CLI 标志
复制
```
# 显式 npm
curl -fsSL https://openclaw.ai/install.sh | bash -s -- --install-method npm
# 从 GitHub 安装（源代码 checkout）
curl -fsSL https://openclaw.ai/install.sh | bash -s -- --install-method git
```
常用标志：
- `--install-method npm|git`
- `--git-dir `（默认：`~/openclaw`）
- `--no-git-update`（使用现有 checkout 时跳过 `git pull`）
- `--no-prompt`（禁用提示；CI/自动化中必需）
- `--dry-run`（打印将要执行的操作；不做任何更改）
- `--no-onboard`（跳过新手引导）
### [​](https://docs.openclaw.ai/zh-CN/install\#%E7%8E%AF%E5%A2%83%E5%8F%98%E9%87%8F) 环境变量
等效的环境变量（对自动化有用）：
- `OPENCLAW\_INSTALL\_METHOD=git|npm`
- `OPENCLAW\_GIT\_DIR=...`
- `OPENCLAW\_GIT\_UPDATE=0|1`
- `OPENCLAW\_NO\_PROMPT=1`
- `OPENCLAW\_DRY\_RUN=1`
- `OPENCLAW\_NO\_ONBOARD=1`
- `SHARP\_IGNORE\_GLOBAL\_LIBVIPS=0|1`（默认：`1`；避免 `sharp` 针对系统 libvips 构建）
## [​](https://docs.openclaw.ai/zh-CN/install\#%E6%95%85%E9%9A%9C%E6%8E%92%E9%99%A4%EF%BC%9A%E6%89%BE%E4%B8%8D%E5%88%B0-openclaw%EF%BC%88path%EF%BC%89) 故障排除：找不到 `openclaw`（PATH）
快速诊断：
复制
```
node -v
npm -v
npm prefix -g
echo "$PATH"
```
如果 `$(npm prefix -g)/bin`（macOS/Linux）或 `$(npm prefix -g)`（Windows） \*\*不\*\* 在 `echo "$PATH"` 的输出中，你的 shell 无法找到全局 npm 二进制文件（包括 `openclaw`）。修复：将其添加到你的 shell 启动文件（zsh：`~/.zshrc`，bash：`~/.bashrc`）：
复制
```
# macOS / Linux
export PATH="$(npm prefix -g)/bin:$PATH"
```
在 Windows 上，将 `npm prefix -g` 的输出添加到你的 PATH。然后打开新终端（或在 zsh 中执行 `rehash` / 在 bash 中执行 `hash -r`）。

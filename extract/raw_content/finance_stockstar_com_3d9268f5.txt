# MiniMax 发布 M2.7 大模型 国泰海通梳理AI全产业链投资标的
来源：[格隆汇](https://www.gelonghui.com/news/5195891)
![](//i.ssimg.cn/images/public/news/jt.png)[格隆汇 更多文章 >>](//news.stockstar.com/source\_list/%E6%A0%BC%E9%9A%86%E6%B1%87.shtml)
2026-03-26 12:40:27
[涉企侵权信息举报专区](http://info.stockstar.com/aboutus/report.htm)
（原标题：MiniMax 发布 M2.7 大模型 国泰海通梳理AI全产业链投资标的）
本周，MiniMax 发布新一代 Agent 旗舰大模型 M2.7，并首次展示“模型自我进化”路径。公司称，该模型通过构建 Agent Harness 体系，使模型能够参与自身训练与优化流程，在部分研发场景中可承担约 30%到 50%的工作量，并在
内部评测集上实现约 30%的效果提升。在编程与软件工程能力方面，在涵盖多种编程语言的 SWE-Pro 中，M2.7 以 56.22% 的正确率追平 GPT-5.3-Codex；在 Repo 级代码生成基准 VIBE-Pro 上，M2.7 得分 55.6%，几乎与Opus 4.6 持平。公司表示，该模型能够完成端到端项目交付、日志分析与Bug 排查等复杂任务。此外，M2.7 在专业办公场景中提升 Word、Excel、PPT 等复杂编辑能力，并在多轮任务中保持较高指令遵循率。MiniMax 表示，M2.7 正在加速公司向 AI Native 组织转型。
国泰海通秦和平团队认为，投资标的方面可关注
1）算力方向：推荐英伟达（NVDA.O）、台积电（TSM.N）、阿斯麦（ASML.O）、博通（AVGO.O）。
2）云厂商：推荐北美三大云厂商微软（MSFT.O）、亚马逊（AMZN.O）、谷歌（GOOGL.O）。
3）AI 应用：推荐 AI Agent 方向受益的苹果（AAPL.O）、高通（QCOM.O）、联想集团（0992.HK）、小米集团（1810.HK），Physical AI 方向受益的特斯
拉（TSLA.O）。
4）AI 社交：推荐 AI 赋能下的社交网络巨头腾讯控股（0700.HK）、Meta（META.O）、谷歌（GOOGL.O）。

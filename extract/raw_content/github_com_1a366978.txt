Video Transcript Skill
======================

**[OpenClaw Skill]** An automated tool to extract spoken content/subtitles from Bilibili video links.

[中文文档](/RayYeung1989/video-transcript/blob/main/README.zh.md)

> 💡 This is a **standalone CLI tool** that can be used directly or integrated with any AI Agent framework that supports skill registration (e.g., [OpenClaw](https://github.com/openclaw/openclaw), Claude Code, etc.)

> ⚠️ **Current Status:** Only supports **Bilibili** videos. Support for other platforms (Douyin, YouTube, etc.) is planned.

Features
--------

* 🎯 Supports BV ID or full URL
* 🚀 Automatically downloads audio and transcribes
* 📝 Uses OpenAI Whisper for speech recognition
* ⚡ Supports multiple models (tiny/base/small/medium)
* 📁 Standardized output to `video-extracts/` directory

Quick Start
-----------


### Dependencies


```
pip install -r requirements.txt
```

Requires ffmpeg:

```
# Ubuntu/Debian
sudo apt-get install ffmpeg

# macOS
brew install ffmpeg
```

### Usage

**Method 1: Direct execution**

```
cd /home/admin/openclaw/workspace/skills/video-transcript

# Using default configuration (base model)
python3 scripts/extract.py BV1GqZUBvENu

# Using small model (higher accuracy)
python3 scripts/extract.py BV1GqZUBvENu --model small

# Full URLs are also supported
python3 scripts/extract.py "https://www.bilibili.com/video/BV1GqZUBvENu/"
```

**Method 2: Convenient script (recommended)**

```
# Create symlink first
ln -s /home/admin/openclaw/workspace/skills/video-transcript/video-transcript.sh ~/bin/video-transcript

# Then use anytime
video-transcript BV1GqZUBvENu
video-transcript BV1GqZUBvENu small
```

Output
------

Transcription files are automatically saved to: `video-extracts/{BV_ID}_transcript.txt`

Model Selection
---------------


| Model | Size | Speed | Accuracy | Use Case |
| --- | --- | --- | --- | --- |
| tiny | 39MB | ⚡⚡⚡ Fastest | ⭐⭐ Fair | Quick preview |
| base | 74MB | ⚡⚡ Fast | ⭐⭐⭐ Good | Daily use ✅ |
| small | 244MB | ⚡ Medium | ⭐⭐⭐⭐ Better | High quality needs |
| medium | 769MB | 🐢 Slow | ⭐⭐⭐⭐⭐ Best | Professional terminology |

**Recommendations:**

* Daily use: `base` (balance of speed and quality)
* Important content: `small` (~30% accuracy improvement)
* Long videos (>10min): `base` is more cost-effective

How It Works
------------

1. Parse BV ID → Get video information
2. Obtain Bilibili audio download link
3. Download audio (m4s format)
4. Convert to WAV with ffmpeg (16kHz, mono)
5. Whisper speech recognition to text
6. Save to `video-extracts/` directory

Notes
-----

1. **Audio link expiration**: Bilibili audio links expire and need to be re-fetched
2. **First use**: Will automatically download Whisper model files (base ~74MB)
3. **Memory requirements**:
   * base model: ~500MB
   * small model: ~1.5GB
   * medium model: ~4GB

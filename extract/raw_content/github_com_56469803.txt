What's Changed
--------------

* Example for use in mac M\* by [@serome111](https://github.com/serome111) in [#40](https://github.com/resemble-ai/chatterbox/pull/40)

* Add discord to Readme by [@TediPapajorgji](https://github.com/TediPapajorgji) in [#75](https://github.com/resemble-ai/chatterbox/pull/75)

* Feature: Update example scripts, add example wavs, add info on watermarking, safetensor in VC model by [@piotrkawa](https://github.com/piotrkawa) in [#82](https://github.com/resemble-ai/chatterbox/pull/82)
* Update discord join link by [@TediPapajorgji](https://github.com/TediPapajorgji) in [#131](https://github.com/resemble-ai/chatterbox/pull/131)

* Enable usage of Min\_P Sampler, modify other sampler settings by [@askmyteapot](https://github.com/askmyteapot) in [#155](https://github.com/resemble-ai/chatterbox/pull/155)

### Changes
- Telegram: remove last `@ts-nocheck` from `bot-handlers.ts`, use Grammy types directly, deduplicate `StickerMetadata`. Zero `@ts-nocheck` remaining in `src/telegram/`. ( [#9206](https://github.com/openclaw/openclaw/pull/9206))
- Telegram: remove `@ts-nocheck` from `bot-message.ts`, type deps via `Omit`, widen `allMedia` to `TelegramMediaRef[]`. ( [#9180](https://github.com/openclaw/openclaw/pull/9180))
- Telegram: remove `@ts-nocheck` from `bot.ts`, fix duplicate `bot.catch` error handler (Grammy overrides), remove dead reaction `message\_thread\_id` routing, harden sticker cache guard. ( [#9077](https://github.com/openclaw/openclaw/pull/9077))
- Onboarding: add Cloudflare AI Gateway provider setup and docs. ( [#7914](https://github.com/openclaw/openclaw/pull/7914)) Thanks [@roerohan](https://github.com/roerohan).
- Onboarding: add Moonshot (.cn) auth choice and keep the China base URL when preserving defaults. ( [#7180](https://github.com/openclaw/openclaw/pull/7180)) Thanks [@waynelwz](https://github.com/waynelwz).
- Docs: clarify tmux send-keys for TUI by splitting text and Enter. ( [#7737](https://github.com/openclaw/openclaw/pull/7737)) Thanks [@Wangnov](https://github.com/Wangnov).
- Docs: mirror the landing page revamp for zh-CN (features, quickstart, docs directory, network model, credits). ( [#8994](https://github.com/openclaw/openclaw/pull/8994)) Thanks [@joshp123](https://github.com/joshp123).
- Messages: add per-channel and per-account responsePrefix overrides across channels. ( [#9001](https://github.com/openclaw/openclaw/pull/9001)) Thanks [@mudrii](https://github.com/mudrii).
- Cron: add announce delivery mode for isolated jobs (CLI + Control UI) and delivery mode config.
- Cron: default isolated jobs to announce delivery; accept ISO 8601 `schedule.at` in tool inputs.
- Cron: hard-migrate isolated jobs to announce/none delivery; drop legacy post-to-main/payload delivery fields and `atMs` inputs.
- Cron: delete one-shot jobs after success by default; add `--keep-after-run` for CLI.
- Cron: suppress messaging tools during announce delivery so summaries post consistently.
- Cron: avoid duplicate deliveries when isolated runs send messages directly.
### Fixes
- Heartbeat: allow explicit accountId routing for multi-account channels. ( [#8702](https://github.com/openclaw/openclaw/pull/8702)) Thanks [@lsh411](https://github.com/lsh411).
- TUI/Gateway: handle non-streaming finals, refresh history for non-local chat runs, and avoid event gap warnings for targeted tool streams. ( [#8432](https://github.com/openclaw/openclaw/pull/8432)) Thanks [@gumadeiras](https://github.com/gumadeiras).
- Shell completion: auto-detect and migrate slow dynamic patterns to cached files for faster terminal startup; add completion health checks to doctor/update/onboard.
- Telegram: honor session model overrides in inline model selection. ( [#8193](https://github.com/openclaw/openclaw/pull/8193)) Thanks [@gildo](https://github.com/gildo).
- Web UI: fix agent model selection saves for default/non-default agents and wrap long workspace paths. Thanks [@Takhoffman](https://github.com/Takhoffman).
- Web UI: resolve header logo path when `gateway.controlUi.basePath` is set. ( [#7178](https://github.com/openclaw/openclaw/pull/7178)) Thanks [@Yeom-JinHo](https://github.com/Yeom-JinHo).
- Web UI: apply button styling to the new-messages indicator.
- Onboarding: infer auth choice from non-interactive API key flags. ( [#8484](https://github.com/openclaw/openclaw/pull/8484)) Thanks [@f-trycua](https://github.com/f-trycua).
- Security: keep untrusted channel metadata out of system prompts (Slack/Discord). Thanks [@KonstantinMirin](https://github.com/KonstantinMirin).
- Security: enforce sandboxed media paths for message tool attachments. ( [#9182](https://github.com/openclaw/openclaw/pull/9182)) Thanks [@victormier](https://github.com/victormier).
- Security: require explicit credentials for gateway URL overrides to prevent credential leakage. ( [#8113](https://github.com/openclaw/openclaw/pull/8113)) Thanks [@victormier](https://github.com/victormier).
- Security: gate `whatsapp\_login` tool to owner senders and default-deny non-owner contexts. ( [#8768](https://github.com/openclaw/openclaw/pull/8768)) Thanks [@victormier](https://github.com/victormier).
- Voice call: harden webhook verification with host allowlists/proxy trust and keep ngrok loopback bypass.
- Voice call: add regression coverage for anonymous inbound caller IDs with allowlist policy. ( [#8104](https://github.com/openclaw/openclaw/pull/8104)) Thanks [@victormier](https://github.com/victormier).
- Cron: accept epoch timestamps and 0ms durations in CLI `--at` parsing.
- Cron: reload store data when the store file is recreated or mtime changes.
- Cron: deliver announce runs directly, honor delivery mode, and respect wakeMode for summaries. ( [#8540](https://github.com/openclaw/openclaw/pull/8540)) Thanks [@tyler6204](https://github.com/tyler6204).
- Telegram: include forward\\_from\\_chat metadata in forwarded messages and harden cron delivery target checks. ( [#8392](https://github.com/openclaw/openclaw/pull/8392)) Thanks [@Glucksberg](https://github.com/Glucksberg).
- macOS: fix cron payload summary rendering and ISO 8601 formatter concurrency safety.

- Security: require operator.approvals for gateway /approve commands. ( [#1](https://github.com/openclaw/openclaw/pull/1)) Thanks [@mitsuhiko](https://github.com/mitsuhiko), [@yueyueL](https://github.com/yueyueL).
- Security: Matrix allowlists now require full MXIDs; ambiguous name resolution no longer grants access. Thanks [@MegaManSec](https://github.com/MegaManSec).
- Security: enforce access-group gating for Slack slash commands when channel type lookup fails.

- TUI: block onboarding output while TUI is active and restore terminal state on exit.
- CLI/Zsh completion: cache scripts in state dir and escape option descriptions to avoid invalid option errors.
- fix(ui): resolve Control UI asset path correctly.
- fix(ui): refresh agent files after external edits.
- Docs: finish renaming the QMD memory docs to reference the OpenClaw state dir.
- Tests: stub SSRF DNS pinning in web auto-reply + Gemini video coverage. ( [#6619](https://github.com/openclaw/openclaw/pull/6619)) Thanks [@joshp123](https://github.com/joshp123).

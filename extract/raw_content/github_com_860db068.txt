## Introduction
[Permalink: Introduction](https://github.com/inclusionAI/dInfer#introduction)
dInfer is an efficient and extensible inference framework for dLLMs. As illustrated in the following architecture, it modularizes inference into four components:
\_model\_, \_diffusion iteration manager\_, \_decoder\_ and \_KV-cache manager\_. It provides well-designed APIs for
flexible algorithms combinations in each component. It now supports batched inference for improved throughput.
[![dInfer v0.1 architecture](https://github.com/inclusionAI/dInfer/raw/master/assets/Framework2.png)](https://github.com/inclusionAI/dInfer/blob/master/assets/Framework2.png)
\*\*Figure\*\*: Overall Architecture of dInfer
dInfer supports multiple dLLM variants, including LLaDA, LLaDA-MoE and LLaDA2.

## Quick Start
[Permalink: Quick Start](https://github.com/inclusionAI/dInfer#quick-start)
### Install dInfer
[Permalink: Install dInfer](https://github.com/inclusionAI/dInfer#install-dinfer)
```
git clone https://github.com/inclusionAI/dInfer.git
cd dInfer
pip install .
```
To use it with vLLM backend (it works with LLaDA and LLaDA-MoE), please install vLLM.
```
pip install vllm==0.10.2
```
To use it with SGLang backend (it works with LLaDA2), please install SGLang.
```
pip install sglang==0.5.3.post1
```
### Convert to FusedMoE (LLaDA-MoE only)
[Permalink: Convert to FusedMoE (LLaDA-MoE only)](https://github.com/inclusionAI/dInfer#convert-to-fusedmoe-llada-moe-only)
To run LLaDA-MoE model downloaded from HuggingFace, we need to first convert it to a format supported by dInfer. dInfer provides a script `tools/transfer.py` for the format conversion.
#### 1) Download and Convert
[Permalink: 1) Download and Convert](https://github.com/inclusionAI/dInfer#1-download-and-convert)
```
pip install -U huggingface\_hub hf\_transfer
export HF\_HUB\_ENABLE\_HF\_TRANSFER=1
# Download Instruct checkpoint
hf download inclusionAI/LLaDA-MoE-7B-A1B-Instruct \
--repo-type model \
--local-dir /path/to/LLaDA-MoE-7B-A1B-Instruct
# Convert to FusedMoE
python -m tools.transfer \
--input /path/to/LLaDA-MoE-7B-A1B-Instruct \
--output /path/to/LLaDA-MoE-7B-A1B-Instruct-fused
```
#### 2) Load the model
[Permalink: 2) Load the model](https://github.com/inclusionAI/dInfer#2-load-the-model)
```
from dinfer.model import AutoModelForCausalLM
from transformers import AutoTokenizer
m = "/path/to/LLaDA-MoE-7B-A1B-Instruct-fused"
tok = AutoTokenizer.from\_pretrained(m, trust\_remote\_code=True)
model = AutoModelForCausalLM.from\_pretrained(m, trust\_remote\_code=True, torch\_dtype="bfloat16")
```

#### Benchmark (speed only)
[Permalink: Benchmark (speed only)](https://github.com/inclusionAI/dInfer#benchmark-speed-only)
Measure throughput (TPS) only; predictions are saved under `--output\_dir` with no automatic scoring.
- \*\*LLaDA2 model\*\*
- LLaDA2-flash Dataset profiling (threshold decoder, TP across 4 GPUs):
```
python benchmarks/benchmark\_dataset\_sglang.py \
--model\_name inclusionAI/LLaDA2.0-flash \
--dataset dataset\_path \
--gen\_len 2048 \
--block\_length 32 \
--gpu 0,1,2,3 \
--output\_dir runs/llada2\_flash \
--use\_tp \
--parallel\_decoding threshold \
--threshold 0.9 \
--cache prefix \
--use\_bd
```
- LLaDA2-mini Dataset profiling (threshold decoder, TP across 4 GPUs):
```
python benchmarks/benchmark\_dataset\_sglang.py \
--model\_name inclusionAI/LLaDA2.0-mini \
--dataset dataset\_path \
--gen\_len 2048 \
--block\_length 32 \
--gpu 0,1,2,3 \
--output\_dir runs/llada2\_mini \
--use\_tp \
--parallel\_decoding threshold \
--threshold 0.9 \
--cache prefix \
--use\_bd
```
- \*\*LLaDA, LLaDA1.5 and LLaDA-MoE model\*\*
- LLaDA-MoE Dataset profiling (threshold decoder, TP across 4 GPUs):
```
python benchmarks/benchmark\_dataset.py \
--model\_name inclusionAI/LLaDA-MoE-7B-A1B-Instruct \
--model\_type llada\_moe \
--dataset dataset\_path \
--gen\_len 1024 \
--block\_length 64 \
--gpu 0,1,2,3 \
--output\_dir runs/llada\_moe\_threshold \
--use\_tp \
--parallel\_decoding threshold \
--threshold 0.8 \
--cache dual \
--prefix\_look 16 \
--after\_look 16 \
--warmup\_times 4 \
--cont\_weight 0.3
```
- LLaDA Single-sample profiling (threshold decoder, TP across 4 GPUs):
```
python benchmarks/benchmark.py \
--model\_name GSAI-ML/LLaDA-8B-Instruct \
--model\_type llada \
--gen\_len 2048 \
--block\_length 32 \
--gpu 0,1,2,3 \
--use\_tp \
--parallel\_decoding threshold \
--threshold 0.9 \
--cache prefix
```
- LLaDA, LLaDA1.5, LLaDA-MoE can use benchmark\\_dataset.py and benchmark.py.
#### Evaluation with lm-eval (speed + accuracy)
[Permalink: Evaluation with lm-eval (speed + accuracy)](https://github.com/inclusionAI/dInfer#evaluation-with-lm-eval-speed--accuracy)
- Built on HuggingFace `lm-eval-harness` to compute TPS and benchmark scores.
- Tasks provided:
- `gsm8k\_llada`: math reasoning.
- `mbpp\_sanitized\_llada`: sanitized Python code generation.

## Benchmark Results
[Permalink: Benchmark Results](https://github.com/inclusionAI/dInfer#benchmark-results)
### The inference speed (TPS) on LLaDA-MoE
[Permalink: The inference speed (TPS) on LLaDA-MoE](https://github.com/inclusionAI/dInfer#the-inference-speed-tps-on-llada-moe)
dInfer delivers over 1,100 TPS at batch size 1 on HumanEval and on average 800+ TPS across six benchmarks on a single node with 8×H800 GPUs.
[![dInfer v0.1 speedup](https://github.com/inclusionAI/dInfer/raw/master/assets/dinfer\_tps.png)](https://github.com/inclusionAI/dInfer/blob/master/assets/dinfer\_tps.png)
\*\*Figure\*\*: Benchmark results on LLaDA-MoE
\*\*Speedup comparisons:\*\*
- 10× faster than Fast-dLLM while maintaining accuracy
- 2-3× faster than Qwen2.5-3B on vLLM (LLaDA-MoE) with comparable quality
### The inference speed (TPS) on LLaDA2-flash-CAP
[Permalink: The inference speed (TPS) on LLaDA2-flash-CAP](https://github.com/inclusionAI/dInfer#the-inference-speed-tps-on-llada2-flash-cap)
The inference speed is measured on LLaDA2-flash-CAP (with 100B parameters) on 8 H20 GPUs (parallel decoding threshold=0.95, generation length=1000).

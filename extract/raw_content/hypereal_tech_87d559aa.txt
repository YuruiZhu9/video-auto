如何最大化利用免费 API 积分
----------------

1. **从最便宜的模型开始** — Flux 2 图像生成仅需 $0.001。在测试昂贵的视频模型前，先用这些模型进行原型设计。
2. **积极使用缓存** — 如果多个用户请求相似的输出，请缓存并重复使用结果。
3. **使用 Webhooks** — 避免频繁轮询，以免在状态检查上浪费 API 调用。
4. **批量处理请求** — 某些 API 针对批量处理提供折扣。
5. **监控使用情况** — 在达到免费层级上限前设置警报。

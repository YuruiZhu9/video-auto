## 前言
OpenClaw 支持 10+ 聊天渠道，其中国内最常用的是飞书、企业微信、钉钉和 QQ。本文手把手教你把 OpenClaw 接入这四个平台。
## 准备工作
- 已安装 OpenClaw（`npx openclaw`）
- 一台可公网访问的服务器
- 各平台的管理员权限
## 一、企业微信接入
### 1.1 创建应用
1. 登录 [企业微信管理后台](https://link.juejin.cn/?target=https%3A%2F%2Fwork.weixin.qq.com%2F "https://work.weixin.qq.com/")
2. 应用管理 → 自建 → 创建应用
3. 记录 \*\*AgentId\*\*、 \*\*Secret\*\*、 \*\*CorpId\*\*
### 1.2 配置回调
- URL: `https://你的服务器/webhook/wecom`
- Token 和 EncodingAESKey：自动生成，记录下来
### 1.3 OpenClaw 配置
```bash
bash
体验AI代码助手
代码解读
复制代码
openclaw config wecom \
--corp-id YOUR\_CORP\_ID \
--agent-id YOUR\_AGENT\_ID \
--secret YOUR\_SECRET \
--token YOUR\_TOKEN \
--aes-key YOUR\_AES\_KEY
```
### 1.4 测试
在企业微信里找到你的应用，发送一条消息，收到 AI 回复即成功。
## 二、钉钉接入
### 2.1 创建应用
1. 登录 [钉钉开放平台](https://link.juejin.cn/?target=https%3A%2F%2Fopen.dingtalk.com%2F "https://open.dingtalk.com/")
2. 应用开发 → 企业内部开发 → 创建应用
3. 记录 \*\*AppKey\*\* 和 \*\*AppSecret\*\*
### 2.2 配置机器人
1. 应用功能 → 机器人 → 开启
2. 消息接收地址：`https://你的服务器/webhook/dingtalk`
### 2.3 OpenClaw 配置
```bash
bash
体验AI代码助手
代码解读
复制代码
openclaw config dingtalk \
--app-key YOUR\_APP\_KEY \
--app-secret YOUR\_APP\_SECRET
```
### 2.4 测试
在钉钉群里 @你的机器人，或者私聊机器人。
## 三、QQ 接入
### 3.1 创建机器人
1. 登录 [QQ 开放平台](https://link.juejin.cn/?target=https%3A%2F%2Fq.qq.com%2F "https://q.qq.com/")
2. 创建机器人应用
3. 记录 \*\*AppID\*\* 和 \*\*Token\*\*
### 3.2 OpenClaw 配置
```bash
bash
体验AI代码助手
代码解读
复制代码
openclaw config qqbot \
--app-id YOUR\_APP\_ID \
--token YOUR\_TOKEN
```
### 3.3 注意事项
- QQ Bot 需要审核，审核周期 1-3 天
- 私聊和群聊权限需要分别申请
- 建议先在沙箱环境测试
## 四、飞书接入
详细教程见： [OpenClaw + 飞书完全教程](https://link.juejin.cn/?target=https%3A%2F%2Fopenclawguide.org%2Fzh%2Fintegrations%2Fopenclaw-feishu "https://openclawguide.org/zh/integrations/openclaw-feishu")

## 多渠道同时接入
OpenClaw 支持同时连接多个渠道，共享同一个 AI 智能体：
```yaml
yaml
体验AI代码助手
代码解读
复制代码
channels:
feishu:
appId: "cli\_xxx"
appSecret: "xxx"
wecom:
corpId: "xxx"
agentId: "xxx"
secret: "xxx"
dingtalk:
appKey: "xxx"
appSecret: "xxx"
qqbot:
appId: "xxx"
token: "xxx"
```
这样你的 AI 助手同时在飞书、企业微信、钉钉、QQ 上线，所有渠道共享记忆和知识库。
## 常见问题
\*\*Q: 消息收不到怎么办？\*\*
A: 检查服务器防火墙是否开放了 webhook 端口，检查回调 URL 是否正确。
\*\*Q: 能区分不同渠道的用户吗？\*\*
A: 可以，OpenClaw 会自动标记消息来源渠道和用户 ID。
\*\*Q: 群聊里怎么触发？\*\*
A: 默认需要 @机器人，可以在配置中修改为关键词触发。

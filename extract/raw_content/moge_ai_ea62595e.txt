Product Overview
----------------

### What is Verdent?

Verdent is a parallel agentic development environment that lets engineers coordinate multiple coding agents to work in isolated branches, plan changes up front, and verify results before merge. It combines multi-model orchestration, long-context understanding, and automated verification to deliver production-ready code changes, achieving top-tier performance on benchmarks like SWE-bench Verified. Verdent is available as a desktop app and as a VS Code extension, fitting directly into existing Git-based workflows.

---

### Key Features

* #### Parallel Multi-Agent Coding
  
  Run multiple coding agents in parallel on separate tasks, accelerating feature delivery while keeping each agent’s work clearly scoped.
* #### Isolated Git Worktrees
  
  Use isolated git worktrees so agents operate in clean branches, avoiding conflicts and keeping every experimental change contained and reviewable.
* #### DiffLens & Structured Code Review
  
  Inspect all agent-generated changes via DiffLens and built-in review flows, giving full visibility into edits before accepting or merging.
* #### Researcher and Verifier Subagents
  
  Leverage built-in Researcher and Verifier subagents to understand large codebases, cross-check implementations, and validate behavior against tests.
* #### Configurable Reasoning and Planning
  
  Control reasoning depth, toggle planning modes, and apply custom instructions so agents match team standards and project complexity.
* #### Desktop and VS Code Integration
  
  Use Verdent Desktop for an overview of all active projects and Verdent for VS Code to integrate planning and execution directly into your editor.

---

### Use Cases

* Shipping Features Faster : Engineering teams can break a feature into parallel subtasks handled by multiple agents, turning multi-day work into hours while preserving reviewable diffs.
* Working in Large Legacy Codebases : Developers can rely on Researcher and Verifier subagents to quickly understand unfamiliar repositories, propose changes, and validate them with tests.
* Refactoring and Cleanup at Scale : Teams can schedule agents to refactor modules, apply patterns, and improve code quality across services while reviewing all diffs in a single, focused view.
* Exploratory Prototyping and MVPs : Founders and individual developers can iterate on multiple implementation ideas in parallel worktrees, compare outcomes, and keep only what works.
* Continuous Verification in Development : Agents can be used to keep tests updated, run targeted checks, and highlight regressions early, improving reliability without adding manual overhead.

## 常见问题
关于 OpenClaw 的常见问题解答。
OpenClaw AI 是什么？+
OpenClaw 是 Peter Steinberger 开发的开源自主 AI 私人助理。它运行在你自己的电脑上（Mac、Windows 或 Linux），能执行真实任务——管理文件、控制浏览器、发送消息，还能在 WhatsApp、Telegram、Discord、Slack、Signal、iMessage 等应用间自动化工作流程。
怎么安装 OpenClaw？+
OpenClaw 需要 Node.js 22 或更高版本。用 npm 安装：'npm install -g openclaw@latest'，或用 pnpm：'pnpm add -g openclaw@latest'。然后运行 'openclaw onboard --install-daemon' 完成配置。Windows（WSL2）、Linux、macOS、iOS、Android 的安装指南都在 docs.openclaw.ai。
Mac mini 能跑 OpenClaw 吗？+
完全可以！OpenClaw 支持 macOS、Windows 和 Linux。Mac mini 特别适合做 OpenClaw 的常驻主机，7×24 小时在线，所有设备和聊天平台随时可用。
OpenClaw 支持哪些 AI 模型？+
OpenClaw 不挑模型。支持 Anthropic Claude、OpenAI GPT 系列，也能通过 Ollama 接入本地模型。API Key 自己配，费用和隐私完全可控。注意：用 Claude Pro/Max 订阅违反 Anthropic 服务条款，必须使用按量付费的 API Key。
运行 OpenClaw 要花多少钱？+
OpenClaw 软件完全免费开源（MIT 协议）。费用来自 AI 模型 API：轻度使用大概 $10-30/月，日常使用 $30-70/月，重度自动化可能达到 $100-150/月甚至更多。想省钱可以用 Ollama 跑本地模型，网页搜索可以用 Brave Search 免费套餐（每月 2000 次）。
OpenClaw 源码在哪？+
官方 GitHub 仓库：github.com/openclaw/openclaw，目前有 191,000+ 星标、32,400+ Fork、900+ 贡献者。包含完整源码、文档和问题追踪。这是有史以来增长最快的开源 AI 项目之一。
什么是 OpenClaw 技能？+
技能是扩展 OpenClaw 能力的插件。目前有 100+ 个预置 AgentSkills，能执行命令行、管理文件系统、自动化网页操作，还能对接 50+ 个第三方服务，包括智能家居、效率工具、音乐平台等。
能用 Discord 和 Telegram 吗？+
当然！OpenClaw 支持 WhatsApp（通过 Baileys）、Telegram（Bot API/grammY）、Discord（Bot API）、iMessage、Slack、Signal、Microsoft Teams、Matrix 等多种平台。私聊群聊都行，群里 @ 它就能触发。
我的数据安全吗？+
OpenClaw 生来注重隐私——完全运行在你自己的机器或服务器上，不经过第三方。数据留在本地，你来决定分享什么给 AI 模型。要最高隐私？把 memorySearch.provider 设成 'local'，用本地模型，零云端依赖。
怎么开始用 OpenClaw？+
用 npm 或 pnpm 安装 OpenClaw（需要 Node.js 22+），然后运行 'openclaw onboard --install-daemon'。配置向导会带你设置 API Key、配置聊天平台、安装可选技能。完整文档在 docs.openclaw.ai。
OpenClaw 和 ChatGPT 有什么区别？+
ChatGPT 是云端对话 AI，只能给建议。OpenClaw 是本地运行的自主代理，能在你电脑上执行操作。它有完整系统权限，能控制浏览器、发消息、安排任务、主动跑自动化——就算你没在跟它聊天也能干活。
能参与贡献吗？+
欢迎之至！github.com/openclaw/openclaw 随时欢迎贡献。看看 CONTRIBUTING.md 了解贡献指南。代码、文档、技能、社区支持都算贡献，AI 辅助的 PR 也欢迎！
Clawdbot 是什么？+
Clawdbot 是 OpenClaw 最初的名字，Peter Steinberger 在 2025 年 11 月创建，名字来自对 'Claude' 的谐音玩笑。后来 Anthropic 法务提出商标异议，项目先改名 Moltbot，最终在 2026 年 1 月 30 日定名 OpenClaw。搜 Clawdbot 的话，你找到它的继任者了！
Moltbot 是什么？+
Moltbot 是项目的第二个名字，Clawdbot 商标问题后在 Discord 社区凌晨五点脑暴出来的。'Molting' 意味着成长——龙虾蜕壳才能长大。吉祥物'太空龙虾 Molty'就是这时候诞生的。之后项目再次'蜕变'成了 OpenClaw。
OpenClaw 的 GitHub 仓库在哪？+
官方仓库：github.com/openclaw/openclaw，191,000+ 星标、32,400+ Fork、900+ 贡献者。openclaw 组织下共 16 个仓库。GitHub 历史上增长最快的开源项目之一。
有 OpenClaw 的 Wiki 或文档吗？+
有！官方文档在 docs.openclaw.ai，涵盖架构概览、配置参考、各平台安装指南（Windows/WSL2、Linux、macOS、iOS、Android）、Control UI 设置、SSH/Tailscale 远程访问、故障排查等。GitHub 仓库的 /docs 目录也有文档。
OpenClaw 社区在哪？+
官方 Discord：discord.com/invite/clawd，实时聊天和技术支持的好地方。技术问答也可以去 GitHub Discussions。2026 年 1 月项目在 X（Twitter）、TikTok、Reddit 上爆火。关注 @steipete（作者）获取最新动态。

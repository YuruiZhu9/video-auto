# Pricing and Rate Limits
There is no fixed concurrency limit for the platform, but when the server load is high, there may be a response delay or a 429 error returned. It is recommended to plan the frequency of requests reasonably.
> RPM: Requests Per Minute, refers to the maximum number of requests you can make to us within one minute. When calling a specific model, this is the total number of requests from all API Keys under a single account
>
> TPM: Tokens Per Minute, refers to the maximum number of tokens you can interact with us within one minute. When calling a specific model, this is the total number of request tokens from all API Keys under a single account

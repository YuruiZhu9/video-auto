OpenClaw 2026.3.24 更新速览：Teams 重大升级 + 技能安装优化 + 20+ 稳定性修复
=======================================================

发布日期：2026-03-26 14:55:18
浏览次数： 1786

作者：PM墨者
![]()

微信搜一搜，关注“PM墨者”





推荐语

OpenClaw 2026.3.24版本带来Teams深度集成优化和技能安装简化，大幅提升企业协作与开发体验。
核心内容：
1. Microsoft Teams集成升级，符合官方AI代理设计规范
2. 7个核心技能一键安装配置，降低使用门槛
3. OpenAI API兼容性增强，支持更广泛RAG应用集成


![]()

杨芳贤
53AI创始人/腾讯云(TVP)最具价值专家


 

> **发布日期**: 2026-03-25  
> **当前版本**: 2026.3.23-1 → **最新版本**: 2026.3.24  
> **更新优先级**: 🟡 中等（功能增强 + 稳定性修复）

---

📋 更新摘要
------

本次更新以**功能增强**和**稳定性修复**为主，重点改进了：

* • OpenAI API 兼容性（RAG 应用友好）
* • 工具可见性和管理体验
* • Microsoft Teams 集成重大升级
* • 技能安装流程优化
* • 多渠道稳定性修复

---

✨ 新增功能
------

### 1. OpenAI 兼容性增强 🔄

**变更内容**：

* • 新增 `/v1/models` 端点
* • 新增 `/v1/embeddings` 端点
* • 支持通过 `/v1/chat/completions` 和 `/v1/responses` 转发显式模型覆盖

**影响**：

* • 更广泛的客户端兼容性
* • RAG（检索增强生成）应用更容易集成
* • 使用标准 OpenAI SDK 的第三方工具可直接对接

---

### 2. 工具可见性改进 🛠️

**变更内容**：

* • `/tools` 命令现在显示**当前 Agent 实际可用**的工具
* • 新增紧凑默认视图 + 可选详细模式
* • Control UI 新增"Available Right Now"实时区域

**影响**：

* • 更容易在提问前确认哪些工具可用
* • 减少"这个工具为什么不能用"的困惑
* • 调试和开发体验提升

---

### 3. Microsoft Teams 重大升级 💼

**变更内容**：

* • 迁移到官方 Teams SDK
* • 新增 AI 代理 UX 最佳实践：

+ • 流式 1:1 回复
+ • 欢迎卡片 + 提示引导
+ • 反馈/反思机制
+ • 信息性状态更新
+ • 打字指示器
+ • 原生 AI 标识

* • 支持消息编辑和删除（包括线程内回退）

**影响**：

* • Teams 用户体验大幅提升
* • 企业部署更友好
* • 符合微软 AI 代理设计规范

---

### 4. 技能安装体验优化 📦

**变更内容**：

* • 7 个核心技能添加一键安装配置：

+ • coding-agent
+ • gh-issues
+ • openai-whisper-api
+ • session-logs
+ • tmux
+ • trello
+ • weather

* • Control UI 新增技能状态筛选标签：

+ • All / Ready / Needs Setup / Disabled
+ • 显示各状态数量

* • 技能详情页新增：

+ • 需求说明
+ • 开关切换
+ • 安装操作
+ • API Key 输入
+ • 源元数据
+ • 主页链接

* • CLI `openclaw skills info` 输出增强：

+ • API Key 获取指引
+ • 配置保存命令
+ • 存储路径提示

**影响**：

* • 技能安装门槛降低
* • 新手更容易上手
* • 配置问题更容易排查

---

### 5. Control UI markdown 预览增强 📝

**变更内容**：

* • Agent 工作区文件预览对话框重构
* • 集成 `@create-markdown/preview` v2 系统主题
* • 支持丰富 Markdown 渲染：

+ • 标题
+ • 表格
+ • 代码块
+ • 引用块
+ • 列表

* • 自动适配明/暗色设计令牌

**影响**：

* • 文档阅读体验提升
* • 技能文档、PRD、笔记等更易读

---

### 6. CLI 容器支持 🐳

**变更内容**：

* • 新增 `--container` 参数
* • 新增 `OPENCLAW_CONTAINER` 环境变量
* • 支持在运行中的 Docker/Podman OpenClaw 容器内执行命令

**影响**：

* • 容器化部署管理更方便
* • 无需进入容器即可执行命令

---

### 7. Discord 自动线程命名 🧵

**变更内容**：

* • 新增可选 `autoThreadName: "generated"` 配置
* • 支持 LLM 自动生成简洁线程标题
* • 默认仍使用基于消息的命名

**影响**：

* • 线程管理更清晰
* • 适合长期讨论的上下文

---

### 8. Node 22 兼容性放宽 🔧

**变更内容**：

* • 最低 Node 22 版本要求降至 `22.14+`
* • 仍推荐 Node 24
* • CLI 更新前会预检 npm 包的 `engines.node`

**影响**：

* • Node 22.14 用户不会被阻挡在旧版本
* • 更新失败时提示更清晰

---

🐛 重要修复
------

### 安全修复

* • **沙箱媒体访问修复**：关闭 `mediaUrl`/`fileUrl` 别名绕过，防止越权访问 (#54034)

### 渠道修复

* • **Telegram**：

+ • 论坛主题路由修复（#53699）
+ • 照片尺寸验证 + 回退文档发送（#52545）
+ • 出站错误详情保留（#53635）

* • **WhatsApp**：

+ • 群组消息回声抑制（#53624）
+ • 机器人回复检测修复

* • **Discord**：

+ • 超时回复机制改进（#53823）
+ • 网关错误处理集中化

* • **Feishu**：

+ • WebSocket 连接关闭修复（#52844）
+ • 入站时间戳修复（#52809）

* • **Slack**：

+ • 运行时默认值优化（#53957）
+ • 交互式回复恢复

### Agent 修复

* • 嵌入式运行失败时显示 429/过载错误（#50930）
* • 上下文压缩超时恢复机制（#46417）
* • SecretRef 配置崩溃修复（#45838）
* • 工具沙箱全局匹配修复（#54492, #54684）

### 其他修复

* • 网关重启后唤醒中断的 agent 会话（#53940）
* • Docker 安装初始化循环修复（#53385）
* • 渠道启动失败隔离（#54215）
* • 出站媒体文件访问策略对齐

---

📊 更新建议
------

### 推荐更新人群

* • ✅ 使用 **Microsoft Teams** 的企业用户
* • ✅ 使用 **RAG 应用** 的开发者
* • ✅ 遇到 **Telegram/WhatsApp/Discord** 稳定性的用户
* • ✅ 想体验 **技能安装优化** 的新手

### 可暂缓更新人群

* • ⏸️ 当前版本稳定，无上述需求
* • ⏸️ 生产环境建议观察 1-2 天

---

🚀 更新方法
------

```
# 方法 1：CLI 更新（推荐）  
openclaw update  
  
# 方法 2：npm 全局更新  
npm install -g openclaw  
  
# 方法 3：Docker 更新（如使用容器部署）  
docker pull openclaw/openclaw:latest  

```

**更新后验证**：

```
openclaw --version  
# 应显示：OpenClaw 2026.3.24
```

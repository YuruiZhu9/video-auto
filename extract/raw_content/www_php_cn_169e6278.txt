OpenClaw怎么关闭自动更新\_OpenClaw版本锁定设置教程【操作】

> OpenClaw后台自动更新导致配置重置或服务中断时，需关闭自动更新并锁定版本：一、修改配置文件中update.auto.enabled为false并重启；二、用CLI命令openclaw config set禁用并验证；三、npm全局安装指定版本；四、Windows下删除计划任务；五、hosts屏蔽更新域名。

如果您发现 OpenClaw 在后台自动执行更新操作，导致配置意外重置或服务中断，则可能是自动更新功能已启用。以下是关闭自动更新并实现版本锁定的具体操作步骤：

一、通过配置文件禁用自动更新
--------------

OpenClaw 的自动更新行为由 Gateway 配置文件中的 **update.auto.enabled** 字段控制。修改该字段可立即停用自动检查与安装逻辑。

1、使用文本编辑器打开配置文件路径：**~/.[openclaw](https://www.php.cn/zt/214490.html)/config.json**（Linux/macOS）或 **%APPDATA%\OpenClaw\config.json**（Windows）。

2、定位到 **update** 对象区块，将其中的 **auto.enabled** 值设为 **false**。

3、保存文件后，执行命令重启 Gateway 以使配置生效：**openclaw gateway restart**。

二、使用 CLI 命令行禁用自动更新
------------------

OpenClaw 提供了专用子命令用于动态修改自动更新状态，无需手动编辑 JSON 文件，适合脚本化或批量管理场景。

1、在终端中运行以下命令关闭自动更新功能：**openclaw config set update.auto.enabled false**。

2、确认设置已写入：**openclaw config get update.auto.enabled**，返回值应为 **false**。

3、重启服务确保变更加载：**openclaw gateway restart**。

三、通过 npm 锁定全局安装版本
-----------------

当 OpenClaw 以 npm 全局包方式安装时，禁用自动更新后仍需防止后续 `npm update -g` 意外升级。锁定版本可确保 CLI 始终运行指定 release。

1、停止 Gateway 服务：**openclaw gateway stop**。

2、卸载当前全局版本：**npm uninstall -g openclaw**。

3、安装并固定至目标稳定版本（例如 v2026.3.13）：**npm install -g openclaw@2026.3.13**。

4、验证安装版本：**openclaw --version**，输出应精确匹配 **2026.3.13**。

四、禁用系统级自动更新服务（仅限 Windows）
-------------------------

在 Windows 环境下，OpenClaw 可能注册为计划任务实现开机自启及自动更新。需单独清除该任务以彻底阻断后台触发机制。

1、以管理员身份打开 PowerShell 或 CMD。

2、执行命令列出所有 OpenClaw 相关任务：**schtasks /query | findstr /i "openclaw"**。

3、若存在名为 **OpenClaw AutoUpdate** 或类似名称的任务，运行：**schtasks /delete /tn "OpenClaw AutoUpdate" /f**。

4、再次运行查询命令确认任务已移除。

五、屏蔽更新检查域名（网络层防护）
-----------------

作为补充手段，可通过本地 hosts 文件阻止 OpenClaw 向更新服务器发起 HTTP 请求，从网络层面切断版本检测链路。

1、编辑系统 hosts 文件：**C:\Windows\System32\drivers\etc\hosts**（Windows）或 **/etc/hosts**（Linux/macOS）。

2、在文件末尾新增一行：**127.0.0.1 update.openclaw.dev**。

3、保存文件（Windows 下需管理员权限）。

4、清空 DNS 缓存：**ipconfig /flushdns**（Windows）或 **sudo dscacheutil -flushcache**（macOS）。

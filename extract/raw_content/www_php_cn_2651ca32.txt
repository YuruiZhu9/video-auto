如果您希望 OpenClaw 按照固定时间自动执行指定任务，例如每日抓取数据或同步日志，则需要通过其内置定时任务模块进行配置。以下是创建 OpenClaw 定时任务的具体操作步骤：

一、使用 OpenClaw Web 控制台配置 Cron 任务
-------------------------------

OpenClaw 提供图形化界面，支持在 Web 控制台中直接添加基于 Cron 表达式的定时任务，无需修改代码或重启服务。

1、登录 OpenClaw 管理后台，地址为 **http://localhost:8080/admin**（默认端口，若已修改请替换为实际端口）。

2、点击左侧导航栏中的**“任务调度”**菜单项，进入定时任务管理页面。

3、点击右上角的**“新建任务”**按钮，弹出配置表单。

4、在“任务名称”字段中输入描述性名称，例如**“每日凌晨3点采集用户行为日志”**。

5、在“Cron 表达式”字段中填写对应时间规则，如每日凌晨3点执行应填入：**0 0 0 3 \* ?**（注意：OpenClaw 使用 Quartz 风格 Cron，秒/分/时/日/月/周/年七位格式）。

6、在“执行脚本路径”中填写已上传至 OpenClaw scripts 目录下的 Python 或 Shell 文件相对路径，例如：**/scripts/daily\_log\_pull.py**。

7、勾选**“启用任务”**复选框，点击**“保存”**完成创建。

二、通过 CLI 命令行工具注册定时任务
--------------------

OpenClaw 自带命令行工具 clawctl，支持在服务器终端中快速注册定时任务，适用于批量部署或自动化运维场景。

1、确保已安装并配置 clawctl 工具，运行 **clawctl --version** 验证可用性。

2、切换至 OpenClaw 主程序所在目录，执行以下命令注册每日任务：

**clawctl schedule create --name "daily-report-gen" --cron "0 0 0 2 \* ?" --script "/opt/[openclaw](https://www.php.cn/zt/214490.html)/scripts/gen\_report.py"**

3、系统将返回任务 ID 和状态信息，确认输出中包含**"status: active"**表示注册成功。

4、如需查看当前所有定时任务，执行：**clawctl schedule list**。

5、若需立即触发某任务执行一次（跳过等待周期），运行：**clawctl schedule run --id "sch\_abc123"**（id 从上一步 list 输出中获取）。

三、手动编辑 config/scheduler.yaml 文件
-------------------------------

对于高级用户，OpenClaw 允许直接修改 YAML 配置文件定义定时任务，该方式在集群部署或版本控制环境中更利于统一管理。

1、打开 OpenClaw 安装目录下的**config/scheduler.yaml**文件。

2、在 jobs 列表下新增一个任务条目，结构如下：

**- name: "sync\_user\_data"**

 **cron: "0 0 0 1 \* ?"**

 **script: "/scripts/sync\_users.py"**

 **enabled: true**

3、确保缩进为两个空格，且每个字段值均用双引号包裹，避免 YAML 解析错误。

4、保存文件后，在终端中执行：**clawctl reload scheduler** 使配置生效。

5、检查服务日志输出是否出现类似**"Loaded 3 scheduled jobs"**提示，确认加载成功。

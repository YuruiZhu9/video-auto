OpenClaw低配机跑Skills优化\_OpenClaw轻量技能选择与配置【指南】

> 低配设备运行OpenClaw卡顿时，应精简技能加载、设资源限制、启用按需加载、替换为轻量技能、调低后台任务频率。具体包括禁用高耗技能、保留6个轻量技能、配置内存/CPU上限、开启on\_demand\_skills、安装weather-lite与summarize-tiny、延长心跳间隔。

如果您在低配置设备（如2核4GB内存的轻量服务器或老旧笔记本）上运行OpenClaw并加载Skills时出现卡顿、响应延迟、技能执行失败或内存溢出报错，则很可能是Skills资源占用超出硬件承载能力。以下是针对性优化与轻量技能选择的具体操作步骤：

一、精简默认技能加载集
-----------

OpenClaw启动时默认加载全部bundled skills，其中部分技能（如video-render、ai-audio-studio、large-pdf-processor）依赖高内存与GPU加速，在低配机上会持续占用资源并拖慢网关响应。需手动禁用非必要技能，仅保留基础可运行模块。

1、进入OpenClaw workspace目录，定位skills子文件夹路径：**/path/to/[openclaw](https://www.php.cn/zt/214490.html)/workspace/skills**。

2、将以下高资源消耗技能文件夹重命名添加“.disabled”后缀：agent-browser、pdf-llm-extract、image-gen-diffusion、code-executor-sandbox、web-crawler-pro。

3、确认剩余技能文件夹中仅包含以下轻量级技能：shell-exec、file-read-write、datetime-query、weather-basic、text-summarize-light、http-request-simple。

4、执行命令强制重新加载技能列表：**openclaw skill reload --force**。

二、调整Skills运行时资源限制
-----------------

通过CLI参数为每个Skill进程设置显式内存与CPU上限，防止单一Skill失控抢占全部系统资源，确保网关服务和其他基础组件稳定运行。

1、编辑OpenClaw主配置文件：**workspace/config.yaml**。

2、在skills节点下新增resource\_limits字段，填入以下内容：

resource\_limits:

max\_memory\_mb: 384

max\_cpu\_percent: 65

timeout\_seconds: 45

3、保存文件后重启网关服务：**openclaw gateway restart**。

4、验证限制生效：执行**openclaw skill list --verbose**，检查各技能状态栏是否显示“limited”标识。

三、启用技能按需加载模式
------------

避免所有Skills在OpenClaw启动时一次性初始化，改为仅在用户首次触发对应指令时动态加载并缓存，显著降低冷启动内存峰值，适用于长期运行但使用频次不高的低配环境。

1、打开workspace/config.yaml文件，在core节点下添加配置项：

on\_demand\_skills: true

2、确保skills目录中每个轻量技能子文件夹内均存在有效的SKILL.md文件（无缺失或语法错误）。

3、执行命令刷新技能注册表：**openclaw skill register --all**。

4、手动测试一个未加载过的技能，例如发送指令“查今天北京天气”，观察控制台日志中是否出现“loading skill: weather-basic”字样，确认按需加载已激活。

四、替换高开销Skill为轻量替代方案
-------------------

部分常用功能存在官方维护的轻量分支版本，其代码逻辑精简、依赖极简、无外部二进制调用，专为低资源场景设计，应优先选用替代原版。

1、卸载原weather-basic技能：**openclaw skill uninstall weather-basic**。

2、从ClawHub获取轻量版：**openclaw skill install https://clawhub.ai/skills/weather-lite@v2.1.0**。

3、卸载原text-summarize-light技能（注意：此为旧版轻量包，含冗余PDF解析逻辑）：**openclaw skill uninstall text-summarize-light**。

4、安装新版纯文本摘要技能：**openclaw skill install https://clawhub.ai/skills/summarize-tiny@v1.0.3**。

5、验证新技能可用性：**openclaw skill test summarize-tiny --input "OpenClaw是开源AI自动化工具"**。

五、关闭非必要后台任务与心跳频率
----------------

低配机上heartbeat定时任务（如每日记忆归档、技能健康检查）若按默认5分钟间隔运行，会周期性触发I/O与内存分配，加剧系统抖动。需延长间隔或禁用非核心任务以保主线程稳定。

1、编辑workspace/heartbeat.yaml文件。

2、将memory\_archive\_interval\_minutes值由默认300改为**1440**（即每日一次）。

3、将skill\_healthcheck\_enabled设为**false**。

4、将context\_refresh\_interval\_minutes由60改为**720**（12小时一次）。

5、保存后执行：**openclaw heartbeat reload**。

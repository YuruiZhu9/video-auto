OpenClaw怎么安装第一个Skill\_OpenClawClawhub一键添加技能【指南】

原创




> OpenClaw需通过Clawhub安装Skills才能具备实际操作能力；先验证或安装ClawHub CLI≥0.7.0，再依次安装并启用skill-vetter与tavily-search，最后通过WebUI调用@claw search验证生效。

如果您已完成 OpenClaw 基础安装并成功运行 **[openclaw](https://www.php.cn/zt/214490.html) onboard** 向导，但尚未为 AI Agent 添加任何可执行能力，则说明它目前尚不具备实际操作功能。Skills 是赋予 OpenClaw “动手能力” 的核心模块，必须通过 Clawhub 工具显式安装。以下是为 OpenClaw 安装第一个 Skill 的完整操作流程：

一、确认 ClawHub CLI 已就绪
--------------------

ClawHub 是官方认证的 Skills 管理工具，所有技能安装均需依赖其命令行接口。若未安装或版本过旧，将无法检索与部署技能。

1、在终端中执行 **clawhub --version** 检查是否已安装且版本不低于 **0.7.0**；

2、若提示命令未找到，运行 **npm install -g clawhub@latest** 进行全局安装；

3、安装完成后再次验证版本，确保输出形如 **clawhub-cli-version 0.7.0**。

二、安装安全前置技能 Skill-Vetter
-----------------------

Skill-Vetter 是社区强制推荐的首个安装项，它作为所有后续技能的安全审计网关，在安装任何第三方 Skill 前自动扫描代码逻辑、权限声明与可疑行为，防止恶意模块注入。

1、执行 **npx clawhub@latest install skill-vetter --force** 强制安装最新版；

2、启用自动审查机制：**openclaw skill config skill-vetter --auto-review true**；

3、激活该技能：**openclaw skill enable skill-vetter**。

三、安装首个功能性 Skill：Tavily Search
-----------------------------

Tavily Search 是最基础且高频使用的联网技能，它使 OpenClaw 能实时获取互联网信息，弥补大模型知识截止短板，是启动真实任务流的前提。

[![]()](/ai/1304)
[Copy Leaks](/ai/1304)

AI内容检测和分级，帮助创建和保护原创内容


[下载](/ai/1304) 

1、访问 **https://tavily.com** 注册账号并获取免费 API Key（每月 1000 次调用）；

2、执行安装命令：**npx clawhub@latest install tavily-search --force**；

3、配置 API 密钥：**openclaw config set tools web-search apikey "your\_tavily\_api\_key\_here"**；

4、验证安装结果：**openclaw skills list | grep tavily**，应返回非空输出。

四、验证 Skill 是否生效
---------------

安装完成后需通过最小可行指令触发技能调用，确认其上下文加载、权限配置与网络连通性均正常。

1、启动 OpenClaw Gateway：**openclaw gateway --port 18789**；

2、打开浏览器访问 **http://127.0.0.1:18789/chat** 进入 WebUI；

3、在对话框中输入：**@claw search OpenClaw 2026 最新特性**；

4、观察响应内容是否包含结构化摘要、可信来源链接及时间戳标识，而非“无法联网”或“技能未启用”类错误。

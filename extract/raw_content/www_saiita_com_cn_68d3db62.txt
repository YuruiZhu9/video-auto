AI摘要

OpenClaw v2026.4.2 正式发布，恢复了Task Flow核心功能并带来大量优化。主要更新包括：Task Flow支持托管与同步模式，新增状态追踪与管理命令；多平台（Android、Feishu等）功能增强；集中化安全配置以阻止不安全覆盖；并修复了多项重要Bug。建议所有用户尽快升级此维护版本。


OpenClaw v2026.4.2 正式发布，本次更新恢复了 Task Flow 核心功能，并带来了大量平台优化和 Bug 修复。

⚠️ 破坏性变更
--------

* **xAI 插件**：将 `x_search` 配置迁移到插件自有路径 `plugins.entries.xai.config.xSearch.*`，使用 `openclaw doctor --fix` 自动迁移
* **Firecrawl 插件**：将 `web_fetch` 配置迁移到插件自有路径，通过统一的 fetch-provider 边界路由

🔄 Task Flow 恢复
--------------

* 恢复核心 Task Flow 基础架构，支持托管与镜像同步模式
* 添加持久化流程状态/版本追踪
* 新增 `openclaw flows` 检查/恢复命令
* 支持托管子任务生成 + 粘性取消意图
* 插件可通过 `api.runtime.taskFlow` 接口创建和管理 Task Flow

📱 多平台改进
-------

### Android

* 添加助手角色入口 + Google Assistant App Actions 元数据
* 支持从 Google Assistant 启动 OpenClaw 并传入提示词

### Feishu

* 新增云文档评论事件流程，支持评论线程上下文解析
* 支持线程内回复和 `feishu_drive` 评论操作

### Matrix

* 符合规范的 `m.mentions` 元数据，在 Element 等客户端中可靠触发通知

### WhatsApp

* 添加 `reactionLevel` 指导
* 修复个人模式连接时推送通知丢失问题
* 添加 HTML/XML/CSS MIME 类型支持

🛡️ 安全增强
-------

* 集中化请求认证、代理、TLS 和 header 配置
* 阻止不安全的 TLS/运行时传输覆盖
* 本地文件路径限制在 QQ Bot 媒体存储根目录
* 阻止工作区 .env 文件覆盖受信任的解释器路径
* 使用时间安全的密钥比较替代临时实现

🐛 重要修复
------

* 修复本地 exec 和 node 客户端在配对后的权限错误
* 修复 `sessions_spawn` 在环回权限升级时的失败问题
* 修复 MS Teams 长回复内容重复问题
* 修复 ACP 网关重连后的提示词处理
* 修复 Windows 平台的 allowlist 执行策略
* 修复 Slack 线程上下文过滤问题
* 修复 Telegram 批准按钮回调数据长度限制
* 修复图片工具相对路径解析问题

这是一个重要的维护版本，建议所有用户尽快升级。

OpenClaw更新后版本号未变，原因是系统中存在多个安装路径且PATH优先级导致命令与更新目标不一致。通过which命令排查发现旧版本路径优先级更高，更新操作实际作用于其他路径。解决方案是删除旧路径软链接，确保命令指向正确的新版本安装位置，并建议统一包管理方式避免多路径冲突。

> 2025年，AI变现不再是玄学，而是可复制的工作流重构。从网文创作、短剧生产到本地商家赋能，12条已验证路径揭示：普通人靠国产AI工具赚钱的关键，在于将AI嵌入“人机耦合”的闭环流程，用20%的人类判断撬动80%的自动化产出。

![]()

如果你这两年认真刷过几次 AI 相关内容，心里大概率都问过一句——

**“普通人到底能不能，真的，靠 AI 多赚一点钱？”**

一边是铺天盖地的“某某用 AI 月入十万”“AI 写小说一天上架三本”；

另一边是你打开各种国产大模型，憋半天只憋出一段看起来很聪明、但完全不知道怎么变现的回答。

**现实是：2025 年，AI 已经真金白银地改写了一部分人的收入结构。**

残酷的是，这部分人不一定是“模型论文看得最多”的那批，而是最早把 AI 嵌进赚钱流程的人。

这篇不讲玄学，不讲“信息差致富学”。

只聊一件事：

> **2025 年，在中国大陆，普通人怎么用“国内能用的 AI 工具”，实打实多出一份可复制的收入？**

我把目前看到的、已经有人在实操、有真实现金流的方向，拆成了 **12 条“从 0 到 1”路径**。

每一条背后，我都用国内可用的模型和平台，帮你重新改写了一条完整工作流。

你完全可以只选一条，扎实干 3 个月，就足够把差距拉开。

路径一：AI 辅助网文创作——用 DeepSeek / 通义，把“写不动”变成“写得起”
--------------------------------------------

先讲最现实的一条：网文。

现在番茄、七猫这类平台，不缺“会写字的人”，缺的是\*\*“能稳定日更、世界观不崩、角色不塌”的人\*\*。

AI 在这里，绝不是“帮你生成一本书”，而是解决三个特别痛的点：

* 想不出新题材
* 世界观写着写着自己都乱了
* 每天更 1 万字精神状态爆炸

一个适合国内作者的组合是：

* 逻辑和大纲：DeepSeek、智谱清言、通义千问
* 长文本管理：飞书文档 / Notion 国内镜像 + 你自己的“世界观数据库”
* 最终连载：番茄小说、七猫、起点、再往外走是起点国际 / WebNovel / Amazon KDP

一个实际可跑通的流程，可以这样：

**第一步，用国产大模型做“题材 + 大纲”。**

不是那种“帮我写一本重生文”，而是直接让模型分析平台榜单：

> “你现在是番茄小说资深编辑，请你爬一下（或基于示例分析）最近 3 个月都市频道的热门文案，总结读者最吃哪几类爽点。然后围绕‘重生+职场+打脸’这个方向，给我设计一部 100 章的小说大纲，前三章必须高密度冲突、一定要有黄金三章节奏。”

DeepSeek 这类擅长推理的模型，特别适合做“编辑”而不是“代笔”。

**第二步，用飞书 / Notion + 模型搭一个自己的 Lorebook。**

国外用 NovelAI 的 Lorebook，我们在国内完全可以自己搭一个“设定本”：

用飞书多维表格 / 石墨文档建几张表——人物卡、势力卡、地理设定卡，再用 DeepSeek / 通义千问做检索和填充。

比如你在写的时候，选中“反派张总”，让模型把你之前设定的“人设 + 口头禅 + 外貌 + 黑历史”调出来，强制自己不崩设定。

**第三步，用“三明治写作法”把 AI 味一层层削掉。**

简单说，就是：

* 你写：核心冲突、反转点、关键对话大纲
* 模型写：环境描写、动作细节、情绪渲染
* 你再改：把那种“首先、其次、然而”等僵硬转折全干掉，改成网文读者习惯的扫读节奏

在具体执行上，你可以让通义千问 / Kimi 做一版扩写，然后用 DeepSeek 再当一次“苛刻编辑”，让它帮你挑出“AI 味最重的句子”，再人工重写。

只有一个原则：

> **别指望 AI 替你当作者，要把它当成“永远不喊累的实习写手”。**

你负责灵魂，AI 负责体力活。

路径二：AI 微短剧 / 漫剧——通义千问 + 万相 + 可灵，做一条“爽点流水线”
------------------------------------------

短剧现在是真正的“现金流战场”。

传统短剧成本动辄几十万起步，真人拍摄、场地、美术、剪辑，一环砸一个坑。

现在用国内一批视频、绘画模型，把这件事拆开，普通团队就能吃上一块肉。

一个适合国内团队的组合大概是：

* 剧本 / 分镜：DeepSeek、通义千问、智谱清言
* 角色视觉：通义万相、百度文心一格、字节即梦
* 视频生成：快手可图 / 可灵（Kling 国区）、腾讯混元视频、抖音剪映的“即影”能力
* 配音 + 口型：科大讯飞配音、火山引擎智能配音 + 火山数字人 / 魔搭数字人
* 剪辑：剪映专业版 / 剪映 App

一个可落地的流水线，是这样的：

**第一步，用国产大模型写“强冲突剧本 + 分镜脚本”。**

明确告诉模型：这是做给抖音 / 快手 / Reels 受众看的竖屏短剧，每集 40–60 秒，目标人群是谁，必须几秒一个爽点、每集尾部必须 Hook。

让通义千问帮你把每一集拆成：

* 文本剧情
* 镜头描述（远景 / 近景 / 特写）
* 画面情绪（压抑、爆发、暧昧…）

你在这里扮演的是“制片 + 总编剧”的角色，负责拍板爽点节奏，模型只是帮你把东西写完整。

**第二步，用国内绘画模型把角色和主场景定死。**

先用通义万相 / 文心一格 / 即梦，做出一组统一风格的主角图库：

不同表情、不同服装、不同角度。

这一步一定要通过“风格参考图”功能，让每一次生成都沿用上一组图的风格，这样角色才不会每集一张新脸。

**第三步，把关键分镜丢给视频模型做“图生视频”。**

比如用可灵、快手可图、混元视频，把一张张分镜图变成 3–5 秒的动态镜头，动作可以不用太复杂，但光影、表情、运动要流畅。

**第四步，用国产配音 + 数字人做“开口说话的画面”。**

科大讯飞、火山引擎都有比较成熟的情感配音和口型匹配能力，你只要把台词和角色形象给到，生成一段自然说话的视频，再丢进剪映里和主画面融合。

最后，还是要回到剪映里，人工调节节奏、音乐、转场。

AI 把“素材层”拉到了普通人能玩的级别，但节奏和爽点，还是你说了算。

路径三：小红书 AI 视觉号——用通义万相 / 即梦，把“好看”变成“好用”
--------------------------------------

小红书是一个极其讲究“审美 +情绪”的平台。

AI 绘画在这里真正的机会，不是“炫技术”，而是非常俗气但有效的四个字：**“好看、实用”。**

在工具层面，你完全可以用一套国产组合打穿：

* 画图：通义万相、文心一格、即梦（Jimeng）、字节即梦、腾讯混元大模型内置绘图
* 排版：黄油相机、稿定设计、Canva 大陆可用版
* 运营：小红书创作工具 + 数据分析后台

操作上我建议你走一条最现实的路子：

**第一步，选一个“用户愿意保存”的蓝海垂类。**

比如：

* 宫崎骏风 / 水彩风 / 极简风手机桌面、聊天背景
* 原木风、奶油风装修效果图
* “接好运”“招财”“护体”的好运壁纸、锁屏

这些内容的共同点是：**别人会真的存下来用**，不是刷完就忘的那种漂亮图。

**第二步，用“风格参考码”把画风锁死。**

像通义万相、即梦类产品，都已经有了风格参考 / 图生图功能。

你完全可以先花一周时间，只打磨出“账号专属画风”：

比如“克制的极简线条 + 轻柔渐变色 + 细金线点缀”，之后所有图都在这个风格上做微调。

久而久之，用户刷到你的图，会有一个感觉：

“啊，这又是那个号的图。”

**第三步，把“好看”变成“好用”的使用场景。**

每一张图发出去之前，都问自己一句：

* 这张图能当壁纸吗？
* 能当头像吗？
* 能用在发朋友圈 / 朋友圈背景上吗？
* 能配文案做情绪表达吗？

你可以在图上预留文字区域，或者直接配上一句很能戳人的短句，让用户一键“保存+转发”。

变现上，小红书已经给出了非常清晰的路径：

账号起来之后，接蒲公英商单；

用置顶笔记引导用户加微信 / 企微进群；

在群里卖高清无水印图包、定制头像、AI 绘画教程。

本质上，这条路是在用国产绘画模型，给自己做一个“移动视觉工作室”。

路径四：AI 表情包与贴图——用即梦 / 文心一格，慢慢养出一个小 IP
------------------------------------

表情包是中国互联网最被低估的一种“软资产”。

好消息是：以前做表情包需要会画画，现在**只要你懂什么好笑、会用一点点 AI，就能做出完整一套**。

在国内的工具组合是：

* 角色设计：通义万相、文心一格、即梦
* 动态化：剪映、快手可影、腾讯智影、阿里云视频工场
* 封装与上传：微信表情开放平台、QQ 表情平台、B 站/抖音特效中心

一个简单但很实在的流程：

**第一步，用 AI 造一个“有梗”的小角色。**

不要做一个“泛泛的可爱猫”，而是做一个有明确人设的小形象：

社恐土豆、加班熊猫、emo 小云朵、暴躁打工狗……

你可以用即梦 / 万相生成多组表情：开心、生气、无语、崩溃、社恐微笑等等。

**第二步，把它做成平台认可的表情格式。**

微信表情对尺寸、大小、白边都有严格要求。

你需要做的就是用 PS / 美图秀秀 / 在线 GIF 工具把每张图：

* 裁成统一尺寸（比如 240×240）
* 去掉多余白边，保证在聊天框里“干干净净”
* 控制动图小于 1MB，方便加载

这一步很多人嫌麻烦，但恰恰是你能和“随便玩玩 AI 的人”拉开差距的地方。

**第三步，上架、运营、慢慢养 IP。**

上架之后不要急着“赚钱”，先让它出现在各种场景里：自己用、朋友用、在小红书/B 站发“新表情包介绍”、找小博主试用。

一旦某个表情包系列被大家记住，你就拥有了一个可扩展的小 IP，可以做第二套、第三套，甚至联名、周边。

路径五：AI + POD 按需打印——用 1688 + 淘宝，把图变成实物
-------------------------------------

按需打印（POD）的逻辑非常简单：

**你只做设计和前端销售，生产和发货用工厂。**

在国内，这个闭环可以完全用本土生态打通：

* 设计：通义万相 / 文心一格 / 即梦 + PS / Photopea
* 供应链：1688 找一件代发工厂
* 前端：淘宝 / 抖音小店 / 小红书店铺 / 微店

具体可以这样操作：

**第一步，用国产绘图模型做出“穿得出去”的图。**

记住一句话：**好 T 恤不是插画展。**

真正卖得动的图案，往往非常简单、非常有梗、非常明确。

比如：一句话梗 + 一个极简图标；

一个姿势 + 一句打工人心声。

你可以用通义万相先探索几十个方向，然后从中挑出视觉最“利落”的那几条。

**第二步，用 AI 超分 / 矢量化把图放大到印刷级别。**

可以用 Photopea + 各类在线超分工具，把原来的 1K 图放到 4K、8K，再做干净的矢量勾边。

这一点非常重要，不然印在衣服上会糊成一块。

**第三步，用 1688 + 淘宝做一条最短闭环。**

去 1688 搜“POD T 恤 一件代发”“帆布包 一件代发”，选几家支持小批量、支持打样的供应商。

前端开一个淘宝 / 抖音小店，主打某一个垂类（比如“程序员梗 T”“猫奴梗帆布包”），慢慢把单品做深做精。

你会发现，AI 帮你做的是“从不会设计，到能稳定出图”；

电商帮你做的是“从不会做工厂，到只需对接一两个上游”。

路径六：AI 图库资产——用国产模型给图虫、站酷海洛供货
----------------------------

过去，图库是摄影师的世界。

现在，图库开始接受 AI 图，但也变得严苛：**不干净、不真实、没用的图，一律不过审。**

在国内，你可以考虑的渠道是：

* 图虫创意、站酷海洛、摄图网、千库网等国内图库
* 同时兼做 Adobe Stock / Shutterstock（需要科学方式访问，但分成较稳定）

工具层面，用的还是：通义万相、文心一格、即梦 等。

关键不是图好不好看，而是\*\*“这个图，设计师、运营、甲方会不会真的下载用”\*\*。

目前稀缺的方向包括：

* 真实、自然、不油腻的亚洲人职场照
* 高质量、通用的商务背景图、政策宣讲背景、科技风舞台背景
* 一整套风格一致的图标 / UI 元素 / 信息图元素

你可以选择一个小类目，比如“亚洲女性医生”或者“极简抽象背景”，用国产模型打磨出几百张干净、高质量作品，一点点把自己的图库“资产池”堆起来。

这条路的心态一定要放长：

你每天上几张图，半年、一年之后会慢慢感受到“啊，我不干活的时候也在产生一点钱”的感觉。

路径七：AI Agent 解决方案——用 Coze / Dify / AppBuilder 给老板造“数字员工”
--------------------------------------------------------

这一条，非常适合会一点点产品思维、懂业务逻辑、又不想深学编程的人。

国内现在已经有几套成熟的低代码 Agent 平台：

* Coze（扣子）：字节系，发到微信、飞书、抖音生态都很方便
* Dify：开源、可以私有化，适合稍微技术一点的团队
* 百度 AppBuilder：自带文心大模型与搜索
* 阿里云百炼 + 通义工作室：适合钉钉 / 阿里云生态

一个现实的切入点：**帮中小企业做“邮件/咨询自动处理助手”“常见问题自动回复助手”。**

你可以这样走：

**第一步，找一个你身边真正在“被信息淹没”的老板。**

外贸老板每天几百封邮件、教培机构每天几十条家长微信、美容院每天一堆咨询……

这些都是 Agent 天然适合介入的场景。

**第二步，在 Coze / AppBuilder 里搭一个最小可用版本。**

例如做一个“邮件归类和草拟回复”Agent：

* 触发：邮箱来新邮件（可以用飞书邮箱 / 企业邮箱 + Webhook）
* LLM 识别：判断这是垃圾、发票、客户咨询还是重要事项
* 动作： 垃圾 → 自动归档 发票 → 抽取金额 & 时间，丢进飞书多维表格或企业微信审批 咨询 → 草拟一封高情商回复，放进草稿箱给老板最后拍板

**第三步，用实际“省下的时间”跟老板谈钱。**

你不是卖“AI 技术”，你卖的是：

* 每天帮你省了多少个小时的机械回复
* 帮你少掉了多少漏回复的投诉
* 帮你让前台/助理的工作更聚焦

收费模式可以是：一次性搭建费 + 每月维护费，或者按年订阅。

一句话：

> **你用的是 Coze / Dify / AppBuilder，但你卖出去的，是“我们公司也有了一个 24 小时不下班的数字员工”。**

路径八：无脸视频频道——B 站 / 抖音上，用 AI 做高质二创
--------------------------------

无脸频道这个赛道，在国内同样经历了从“搬运+配音”到“深度二创”的升级。

现在 B 站、抖音、西瓜视频对低质 AI 内容都非常敏感，简单的“PPT+配音”已经走不远了。

你可以把 AI 当成一个效率加速器，而不是“内容替身”。

更现实的打法是：

* 选一个你真有话说的主题：悬疑故事、职场故事、历史冷知识、影视解构、读书笔记…
* 用 DeepSeek / 通义千问 做脚本初稿，把结构、论点写清楚
* 再人工改成你自己的语言，加上你的观点和经历

画面层面，可以组合：

* B 站可商用素材库 + 抖音/西瓜的视频模板
* 国产 AI 绘图生成一些辅助插画/氛围图
* 剪映加上恰到好处的字幕、动效、音效

你做的不是“全自动赚钱机器”，而是一个“高度自动化的内容工厂”：

AI 写底稿 + 你改稿 + AI 做画面 + 你剪辑。

路径九：AI 知识付费 / 数字产品——用小鹅通 / 知识星球，把你的“踩坑经验”卖出去
--------------------------------------------

如果你已经在某个垂直场景里，把 AI 用得还算顺手，那你手上已经握着一个可以变现的东西：**实战路径**。

普通人最大的痛点是：知道工具叫啥，但完全不知道怎么串起来用。

你能卖的，就是这条“从不会到会”的路线图。

国内可以用的承载工具包括：

* 小鹅通、知识星球、小报童、小宇宙会员、荔枝微课、腾讯课堂
* 淘宝咒语包 / 咨询服务、抖音小店课程

产品形态很灵活：

* 一份整理好的“某场景提示词合集”（例如“小红书爆款标题 50 条模板+AI 重写流程”）
* 一套 3–5 小时的“Coze 搭建实战课”“通义千问在职场 20 个用法”
* 一本认真打磨的 PDF《2025 打工人 AI 提效实战手册》

重点不是把自己包装成“专家”，而是**真诚地把你自己已经跑通、赚到过钱的流程拆给别人看**。

路径十：AI 辅助本地生活服务——你带着 DeepSeek / 通义，帮他们“上网赚钱”
--------------------------------------------

很多线下老板现在其实就卡在一句话上：

> “我线下还行，就是不会搞线上。”

你完全可以用 AI 做一件很接地气的事：

帮他们把“线上那一面”补起来。

例如你可以提供这样的服务：

* 用 DeepSeek / 通义千问 为他生成高情商的点评回复（美团 / 大众点评 / 小红书）
* 用通义万相 / 剪映 给他每周做 2–3 张海报、一个短视频文案
* 用国产模型帮他分析同城竞对的营销文案，给出更合适的版本

AI 就像你背后的一整支“内容+客服小团队”，而你是那个对接老板需求、把 AI 产出变成人话的人。

这条路最大的好处是：

**需求非常真实、客户就在你身边。**

路径十一：AI 音乐 / 音频——用国产音乐生成 + 讯飞配音，做“背景声生意”
----------------------------------------

助眠、白噪音、Lo-Fi、冥想音乐，这些内容在 B 站、网易云、QQ 音乐上有稳定的长尾流量。

现在国内也有不少 AI 音乐生成工具（包括各大公司的实验项目、第三方 App），配合科大讯飞、火山引擎这类配音/变声工具，你完全可以跑通一条“声音副业线”：

* 做一整套“学习专用 BGM”视频，放到 B 站、抖音直播间当背景
* 做品牌小店的“专属提示音”“广告 jingle”，在猪八戒网、闲鱼接单
* 用配音 + BGM 做有声书、公版经典导读音频

睡觉的时候，你的音频内容还在被播放，这就是最典型的小规模“被动收入”。

路径十二：微型 SaaS / 工具站——用通义灵码 / 百度 Comate，让 AI 帮你写一部分代码
---------------------------------------------------

最后一条，给愿意稍微碰一下技术的人。

以前做一个小工具网站，需要你至少是个前端 / 全栈。

现在有了通义灵码、百度 Comate、华为云 CodeArts Snap 这种 AI 编程助手，你只要会一点点逻辑，很多东西已经能在“聊天”中做出来了。

你可以从非常小的点切：

* 一个“Excel 公式生成器”：输入问题，输出函数
* 一个“文本清洗/格式转换小工具”：一键去空格、拆行、转 Markdown
* 一个“求职简历关键字优化器”：帮人把 JD 和简历匹配起来

变现方式很朴素：

挂广告、开会员、卖源码、接定制。

**你不需要成为高级工程师，你只需要比你服务的那群人，多懂一点点技术 + 多懂一点点 AI。**

说到底：AI 提高收入，不是玩工具，是重写你的“赚钱单位时间产出”
---------------------------------

把所有这些路径抽象一下，会发现：

**第一，AI 是放大器，不是印钞机。**

它放大的，是你本来就有的东西：写作、审美、沟通、产品、销售、洞察。

如果你没有任何一个“底座能力”，AI 会放大的，只是你的混乱。

**第二，真正赚钱的地方，全部是“人机耦合”。**

AI 做 60%–80% 机械工作；

你做最后 20%–40% 的判断、审美、情绪、风控。

**溢价就藏在这 20%–40% 里。**

**第三，合规和平台规则，是你能不能“活到明年”的底线。**

不管是微信表情的审核、小红书对原创度的要求，还是 B 站/抖音对 AI 内容的风控，你做的不是“钻空子”，而是在规则内做到极致。

**第四，真正拉开差距的，是你有没有把 AI 固化成自己的“赚钱工作流”。**

不是今天玩玩这个 App，明天试试那个网站，而是：

* 针对一个具体场景
* 设计一条从接单、生产、交付、复盘的完整流程
* 让这套流程，在你不太费力的时候，也能稳定跑起来

当你第一次发现：

“咦？这件事我以前要 4 小时，现在 40 分钟搞定，还做得更好”，那一刻其实你已经换了赛道。

2025 年，普通人和 AI 的最佳关系，不是“谁替代谁”，而是——**你学会管理一群不会喊累的数字员工，让他们在屏幕后面帮你，一点点抬高自己的单位时间价值。**

工具可以换很多个，但你只需要跑通一条属于自己的链路，就已经比大多数只会转发“AI 月入几万”的人，走在前面了。

\*\*前言\*\*
OpenClaw 于 2026 年 3 月 25 日发布了最新版本 2026.3.24（构建号 cff6dc9）。本文基于与 AI 助手 [Aro](https://zhida.zhihu.com/search?content\_id=272097830&content\_type=Article&match\_order=1&q=Aro&zd\_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3NzQ3ODYyMzQsInEiOiJBcm8iLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNzIwOTc4MzAsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.V193a6vOSUwNq7IahiQwmnATkEvcQ74P3vC5S6rPjs4&zhida\_source=entity) 的一次对话，整理该版本的核心变化，并分析这些更新对普通用户实际意味着什么。
\*\*一、平台兼容增强\*\*
[Gateway](https://zhida.zhihu.com/search?content\_id=272097830&content\_type=Article&match\_order=1&q=Gateway&zd\_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3NzQ3ODYyMzQsInEiOiJHYXRld2F5IiwiemhpZGFfc291cmNlIjoiZW50aXR5IiwiY29udGVudF9pZCI6MjcyMDk3ODMwLCJjb250ZW50X3R5cGUiOiJBcnRpY2xlIiwibWF0Y2hfb3JkZXIiOjEsInpkX3Rva2VuIjpudWxsfQ.Rv0ACRMku-8nvxcDNlHMJIAhfJl7JVsgrIh-mIrX4BE&zhida\_source=entity) 新增 [OpenAI](https://zhida.zhihu.com/search?content\_id=272097830&content\_type=Article&match\_order=1&q=OpenAI&zd\_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3NzQ3ODYyMzQsInEiOiJPcGVuQUkiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNzIwOTc4MzAsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.urVAi4-TPtj6OkI7klIdiEFBYH-AmfIvAepibqi5iQ0&zhida\_source=entity) 兼容端点
本次更新为 Gateway 新增了 /v1/models 和 /v1/embeddings 两个端点。这一改动显著提升了与第三方向量数据库和 RAG（检索增强生成）场景的兼容性。
实际意义： 如果你运营的知识库产品（如 [MarketGenius AI](https://zhida.zhihu.com/search?content\_id=272097830&content\_type=Article&match\_order=1&q=MarketGenius+AI&zd\_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3NzQ3ODYyMzQsInEiOiJNYXJrZXRHZW5pdXMgQUkiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNzIwOTc4MzAsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.XJEh8l2K1kROEfHBug5hg78bCUeeXCLos9AikR3KTYY&zhida\_source=entity)）需要接入向量检索，或者使用其他兼容 OpenAI API 的工具，配置流程会更加顺畅。对普通用户而言，这个改动目前感知不强，但为未来的扩展场景打下了基础。
[Microsoft Teams](https://zhida.zhihu.com/search?content\_id=272097830&content\_type=Article&match\_order=1&q=Microsoft+Teams&zd\_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3NzQ3ODYyMzQsInEiOiJNaWNyb3NvZnQgVGVhbXMiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNzIwOTc4MzAsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.L7SPpl-SBWpDf-kd1dDNnRFJNw-kfRYiQwznhVqe-ag&zhida\_source=entity) 深度集成
新版本迁移至 Microsoft Teams 官方 SDK，并加入了多项 AI Agent 最佳实践：
· 流式 1:1 回复
· 欢迎卡片与提示语
· 用户反馈机制
· 打字指示器和 AI 标签
· 实际意义： 面向企业协作场景，如果你不使用 Teams，可以忽略。
\*\*二、技能系统大幅优化\*\*
一键安装依赖
这是本次更新中最实用的改进之一。
旧流程： 安装技能 → 报错了说缺某个库 → 用户自行排查 → 装好了再试 → 可能还缺别的 → 循环
新流程： 安装技能 → 自动检测缺失依赖 → 直接提示一键安装 → 完成
以 coding-agent 技能为例，它依赖 codex 或 claude CLI。之前装完发现跑不起来，现在会直接告诉你缺什么、怎么装。
技能状态分级更清晰
技能现在有了明确的状态分类：
| | |
| --- | --- |
| 状态 | 含义 |
| ✓ Ready | 可直接使用 |
| △ Needs Setup | 需要配置或安装依赖 |
| ✗ Disabled | 已禁用 |
在控制面板中，技能卡片会显示具体需要的配置项、API Key 填写入口、文档链接等。
\*\*三、容器与\*\* \*\*CLI 改进\*\*
新增 --container 参数
现在可以通过 openclaw --container 直接在运行中的 [Docker](https://zhida.zhihu.com/search?content\_id=272097830&content\_type=Article&match\_order=1&q=Docker&zd\_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3NzQ3ODYyMzQsInEiOiJEb2NrZXIiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNzIwOTc4MzAsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.CNM6svP4XCpU3uJyD-eXImkJol\_dAk0wYSEKhEwPd8c&zhida\_source=entity) 或 [Podman](https://zhida.zhihu.com/search?content\_id=272097830&content\_type=Article&match\_order=1&q=Podman&zd\_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3NzQ3ODYyMzQsInEiOiJQb2RtYW4iLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNzIwOTc4MzAsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.WDKTVSOHtJNGBAaXvshWuPJjYkE7eFGXWUo6udJW-mU&zhida\_source=entity) 容器内操作 OpenClaw。对于在服务器上使用容器部署的用户，管理工作会更方便。
实际意义： 本地 Mac mini 用户暂时用不上，但如果你考虑将 OpenClaw 部署到云端，这个功能会很有用。
[Node](https://zhida.zhihu.com/search?content\_id=272097830&content\_type=Article&match\_order=1&q=Node&zd\_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3NzQ3ODYyMzQsInEiOiJOb2RlIiwiemhpZGFfc291cmNlIjoiZW50aXR5IiwiY29udGVudF9pZCI6MjcyMDk3ODMwLCJjb250ZW50X3R5cGUiOiJBcnRpY2xlIiwibWF0Y2hfb3JkZXIiOjEsInpkX3Rva2VuIjpudWxsfQ.F6ULx\_-pABVAOkXJvcuXtMrx\_9AVMSzLHBlISUoU\_Gc&zhida\_source=entity) 版本兼容修复
新版本将支持的 Node 最低版本从 22.22.0 调整为 22.14+，同时继续推荐 Node 24。这解决了因 Node 版本过旧导致升级失败的问题。
\*\*四、重要修复\*\*
| | |
| --- | --- |
| 修复内容 | 影响 |
| Docker 全新安装不再假死 | 容器部署用户受益 |
| Gateway 重启后 session 正确恢复 | 所有用户都受益 |
| WhatsApp 群组消息回声彻底抑制 | WhatsApp 用户受益 |
| 消息路由正确传递到 Telegram 话题/线程 | Telegram 用户受益 |
其中 Gateway 重启 session 恢复机制对普通用户影响最直观：之前如果 Mac mini 断电或重启，与 AI 助手的对话可能会丢失。现在重启后会通过心跳机制唤醒之前的 session，对话上下文尽量恢复，而非直接断掉。
\*\*五、对现有用户的影响评估\*\*
结合我的实际情况（我使用 Mac mini 部署，以飞书为主要沟通渠道），以下是各功能的实际价值评估：
| | |
| --- | --- |
| 功能 | 对普通用户的价值 |
| OpenAI 兼容端点 | ⭐⭐ 待 RAG 场景时用到 |
| Teams 集成 | ⭐ 用不上 |
| 技能一键安装 | ⭐⭐⭐ 最实用的新功能 |
| Gateway session 恢复 | ⭐⭐⭐ 最实用的新功能 |
| Docker/容器支持 | ⭐ 服务器部署时用到 |
总结：技能安装体验改善 \+ Gateway 重启恢复是本次更新对普通用户最有价值的两个改进。
其他更新主要面向平台级能力和未来扩展场景。
\*\*结语\*\*
OpenClaw 2026.3.24 是一个以体验打磨和兼容性提升为主的大版本。虽然没有颠覆性的新功能，但技能系统的人机交互和 session 恢复机制的完善，直接提升了日常使用体验。如果你正在使用 OpenClaw 作为个人 AI 助手，建议保持更新以获得更好的稳定性。

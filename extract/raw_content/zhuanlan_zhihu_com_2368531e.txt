## 四、本地全平台部署OpenClaw（Windows11/MacOS/Linux）
### （一）Windows11 部署（管理员PowerShell）
```text
Set-ExecutionPolicy Bypass -Scope Process -Force
iwr -useb https://openclaw.ai/install.ps1 | iex
openclaw onboard --install-daemon
openclaw gateway start
```
访问：`http://localhost:18789`
### （二）MacOS 部署
```text
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install docker node@22
open /Applications/Docker.app
docker pull openclaw/openclaw:2026.3.26
mkdir -p ~/OpenClaw/{config,skills,logs,memory,workspace}
docker run -d \
--name openclaw \
--restart always \
-p 18789:18789 \
-v ~/OpenClaw/config:/app/config \
-v ~/OpenClaw/skills:/app/skills \
-v ~/OpenClaw/logs:/app/logs \
-v ~/OpenClaw/memory:/app/memory \
-v ~/OpenClaw/workspace:/app/workspace \
-e TZ=Asia/Shanghai \
openclaw/openclaw:2026.3.26
docker exec -it openclaw bash
openclaw init --full
exit
```

## 九、新手必看：Skill安装避坑指南
1. \*\*先装Skill Vetter\*\*：所有技能安装前必须扫描，杜绝安全风险
2. \*\*不装重复功能\*\*：同类技能只装一个，避免冲突
3. \*\*安装后必重载\*\*：不执行skills reload，技能无法生效
4. \*\*警惕高权限技能\*\*：拒绝授予系统级权限的不明技能
5. \*\*定期清理\*\*：卸载30天未使用的技能，保持系统流畅
6. \*\*备份配置\*\*：修改技能配置前，先备份工作区文件
## 十、阿里云部署避坑指南
1. 必须选 \*\*应用镜像\*\*，系统镜像需手动配置环境，极易失败

## 十一、本地部署避坑指南
1. Windows必须用 \*\*管理员PowerShell\*\*，普通权限安装失败
2. Mac需先启动Docker，再执行部署命令
3. Linux命令必须加sudo，否则目录权限不足
4. 关闭防火墙或放行18789端口，避免无法访问控制台
5. 数据目录完整挂载，防止重启后配置与技能丢失
## 十二、常见问题解答（FAQ）
### 1\. Skill安装成功但无法使用
- 未启用技能：执行`openclaw skills enable 技能名`
- 未热重载：执行`openclaw skills reload`
- 模型配置错误：检查千问/Coding Plan API是否正常
- 权限不足：重新授予技能所需权限
### 2\. 安装技能后系统卡顿、内存占用高
- 技能安装过多：卸载不常用技能
- 内存不足：升级至2核4GB配置
- 日志过大：执行`openclaw logs --clear`清理日志
- 关闭后台自启技能：减少资源消耗
### 3\. Skill Vetter阻止正常技能安装
- 安全等级设置过高：临时调整为中等
- 技能版本过旧：更新至最新版
- 误报：确认技能来源可靠后，手动放行
### 4\. 搜索类技能无法联网
- 服务器地域问题：更换香港/新加坡地域
- 端口未放行：检查443端口是否开放
- 技能配置错误：重新安装搜索技能
### 5\. 模型调用失败，Skill无法生成内容
- API Key错误/过期：重新配置正确密钥
- 免费额度用尽：更换模型或充值
- BaseURL填写错误：核对官方接口地址
- 未重启网关：执行`openclaw gateway restart`
### 6\. 记忆类技能不生效、无法保存内容
- 工作区目录权限不足：修改目录权限为777
- 未启用记忆功能：在配置中开启记忆开关
- 技能冲突：卸载其他记忆类技能
- 重启服务：执行`openclaw gateway restart`

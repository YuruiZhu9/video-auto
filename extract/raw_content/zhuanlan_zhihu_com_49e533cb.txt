## OpenClaw 2026.3.22⁄23 更新：重大架构升级与安全加固
> 发布时间：2026年3月23日 版本：v2026.3.22 (重大更新) + v2026.3.23 (修复补丁)
\* \* \*
### 📌 版本概览
OpenClaw 在 3 月 23 日连续发布两个版本：
- \*\*v2026.3.22\*\*：重大架构升级，包含多个 Breaking Changes 和大量新功能
- \*\*v2026.3.23\*\*：修复补丁，解决 v2026.3.22 发布后发现的问题
本文将重点介绍这次更新的核心变化。
\* \* \*
### ⚠️ 重要变更（Breaking Changes）
### 1\. 插件安装优先级调整
```text
# 旧行为：优先 npm
openclaw plugins install 
# 新行为：优先 ClawHub，npm 作为备选
openclaw plugins install 
```
现在 `openclaw plugins install` 会优先从 ClawHub 查找包，只有 ClawHub 没有时才会回退到 npm。
### 2\. Chrome 扩展中继已移除
旧版 `driver: "extension"` 和 `browser.relayBindHost` 配置已被移除。请运行以下命令迁移：
```text
openclaw doctor --fix
```
### 3\. 配置环境变量重命名
所有 `CLAWDBOT\_\*` 和 `MOLTBOT\_\*` 环境变量已重命名为 `OPENCLAW\_\*`。
### 4\. SDK 迁移
插件开发者需要注意：
- `openclaw/extension-api` 已移除
- 新的公共 SDK 路径为 `openclaw/plugin-sdk/\*`
\* \* \*
### ✨ 核心新功能
### 🎯 ClawHub 集成
全新的技能市场集成：
```text
# 搜索技能
openclaw skills search 
# 安装技能
openclaw skills install 
# 更新技能
openclaw skills update 
```
### 🔌 多市场支持
支持从多个市场安装插件：
- ClawHub 市场
- Claude 市场
- npm 仓库
```text
# 从特定市场安装
openclaw plugins install clawhub:
openclaw plugins install claude:
```

### 🔒 安全加固
### 执行审批增强
- 空白韩文填充字符会被转义，防止视觉欺骗
- `time` 命令作为透明包装器处理
- 新增 `tools.exec.strictInlineEval` 严格控制内联解释器执行
### 网络安全
- 远程 `file://` URL 和 UNC 路径被阻止
- Webhook 签名验证使用恒定时间比较
- 严格 SSRF 策略应用于远程 CDP
### 配对安全
- iOS 设置码绑定到目标节点配置
- 拒绝请求超范围权限的配对请求
\* \* \*
### 🐛 重要修复
v2026.3.23 修复了以下问题：
- \*\*浏览器/MCP\*\*：修复现有会话标签页附加后的等待问题
- \*\*ClawHub/macOS\*\*：修复 macOS 上的认证配置
- \*\*消息工具\*\*：修复飞书文件/图片附件发送
- \*\*Mistral 模型\*\*：降低默认 token 限制，避免 422 错误
- \*\*子代理\*\*：修复快速完成的 worker 被误报超时的问题

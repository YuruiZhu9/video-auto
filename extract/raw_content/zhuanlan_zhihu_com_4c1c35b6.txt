论文《2013-DSSM-Learning Deep Structured Semantic Models for Web Search using Clickthrough Data》
## \*\*ABSTRACT\*\*
潜在的语义模型，如LSA，它想从语义的级别映射一个查询（query）到它的相关文档（document），因为基于关键词（keyword-based）的匹配经常会失败。在本研究中，我们努力开发一系列新的具有深层结构的潜在语义模型，该模型将query和document投射到一个普通的低维空间中，在这个空间中，给定一个query和document，就可以很容易的计算出它们之间的距离——即相似性。提出的深度结构化语义模型通过使用点击数据最大限度地提高给定查询中被点击文档的条件概率来进行区别训练。
\*\*目标函数：The proposed deep structured semantic models are discriminatively trained by maximizing the conditional likelihood of the clicked documents given a query using the clickthrough data.\*\*
为了使我们的模型适用于大型Web搜索应用程序，我们还使用了一种称为单词散列（word hashing）的技术，该技术可以有效地扩展我们的语义模型，以处理此类任务中常见的大型词汇表。在使用真实数据集的Web文档排序任务上对新模型进行评估。结果表明，我们的最佳模型显著优于其他潜在语义模型，在本文提出的工作之前，这些模型的性能被认为是最先进的。
## \*\*Keywords\*\*
Information Search and Retrieval
Deep Learning, Semantic Model, Clickthrough Data, Web Search
## \*\*1\. INTRODUCTION\*\*
现代搜索引擎主要通过将文档中的关键字与搜索查询中的关键字进行匹配来检索Web文档。然而，词汇匹配可能是不准确的，因为在文档和查询中，概念通常使用不同的词汇表和语言风格来表达。
潜在语义模型(如潜在语义分析(LSA))能够在词汇匹配经常失败的语义层将查询映射到相关文档。这些潜在的语义模型通过将出现在相似上下文中的不同术语分组到相同的语义集群中来解决Web文档和搜索查询之间的语言差异。因此，查询和文档在低维语义空间中表示为两个向量，即使它们不共享任何术语，它们仍然可以有很高的相似度评分。从LSA扩展而来的概率主题模型(probistic LSA, PLSA)和Latent Dirichlet Allocation (Latent Dirichlet Allocation, LDA)也被用于语义匹配。然而，这些模型通常使用与检索任务的评估度量松散耦合的目标函数，以 \*\*无监督的方式进行训练\*\*。因此，这些模型在Web搜索任务上的 \*\*性能并没有预期的那么好\*\*。
最近，有两种研究对上述潜在语义模型进行了扩展，下面将简要回顾。
首先，由查询及其所点击文档组成的点击数据被用于语义建模，以弥合搜索查询和Web文档之间的语言差异。例如，Gao et al.\[10\]提出了使用双语主题模型(BLTMs)和线性判别投影模型(DPMs)在语义级进行查询文档匹配。这些模型使用针对文档排序任务的目标对点击数据进行训练。更具体地说，BLTM是一种生成模型，它要求查询及其点击的文档不仅在主题上共享相同的分布，而且还包含分配给每个主题的相似的词汇派别。相比之下，DPM是使用S2Net算法\[26\]学习的，该算法遵循\[3\]中概述的两两学习-排序范式。将查询和文档的项向量投影到低维语义空间的概念向量中，查询和被点击文档的概念向量距离小于查询和未被点击文档的概念向量距离。Gao等人的\[10\]报告称，在文档排序任务中，BLTM和DPM都显著优于非监督潜在语义模型，包括LSA和PLSA。然而，BLTM的训练，尽管使用点击数据，是为了最大化一个对数似然标准，这是次优的评价指标的文件排名。另一方面，DPM的训练涉及到大规模的矩阵乘法。这些矩阵的大小通常会随着词汇表的大小迅速增长，在Web搜索任务中词汇表的大小可能达到数百万的数量级。为了使训练时间可以忍受，词汇被积极地删减了。尽管词汇量小可以使模型可训练，但它会导致性能欠佳。
在第二项研究中，Salakhutdinov和Hinton使用深度自动编码器\[22\]扩展了语义建模。他们证明了嵌入在查询和文档中的层次语义结构可以通过深度学习提取。性能优于传统的LSA报道为\[22\]。但是，他们采用的深度学习方法仍然是一种无监督学习方法，优化模型参数是为了对文档进行重构，而不是为了对给定的查询进行相关文档与不相关文档的区分。结果表明，深度学习模型并没有显著优于基于关键字匹配的基线检索模型。此外，语义哈希模型还面临大规模矩阵乘法的可扩展性挑战。在本文中，我们将说明学习具有大型词汇表的语义模型的能力对于在真实的Web搜索任务中获得良好的结果至关重要。
在本研究中，我们从上述两个研究方向出发，提出了一系列用于Web搜索的深度结构化语义模型(DSSM)。更具体地说，我们的最佳模型使用深度神经网络(DNN)对给定查询的一组文档进行如下排序。首先，执行非线性投影，将查询和文档映射到公共语义空间。然后，将给定查询的每个文档的相关性计算为其向量在该语义空间中的余弦相似度。通过使用点击数据对神经网络模型进行有区别的训练，使给定查询的点击文档的条件可能性最大化。与以前在无监督方式下学习的潜在语义模型不同，我们的模型直接针对Web文档排序进行了优化，因此提供了更好的性能，稍后我们将展示这一点。此外，针对词汇量较大的问题，我们提出了所谓的单词哈希方法，将查询或文档的高维词向量投影到基于字母的低维n-gram向量上，信息损失很小。在我们的实验中，我们表明，通过在语义模型中添加这一额外的表示层，单词散列使我们能够有选择地学习具有大型词汇表的语义模型，这对Web搜索是至关重要的。我们使用真实世界的数据集在一个Web文档排序任务上评估了所提议的dssm。结果表明，我们的最佳模型优于所有竞争方法，在NDCG@1中有显著的2.5-4.3%的差距。
在本文的其余部分，第2节回顾了相关工作。第3节描述了我们用于Web搜索的DSSM。第四节介绍实验结果，第五节总结全文。

## \*\*3\. DEEP STRUCTURED SEMANTIC MODELS FOR WEB SEARCH\*\*
### \*\*3.1 DNN for Computing Semantic Features\*\*
我们开发的将原始文本特征映射到语义空间中的特征的典型DNN体系结构如图1所示。DNN的输入(原始文本特征，raw text features)是高维词向量（high-dimensional term vector），例如查询或文档中未经标准化的词的原始计数，而DNN的输出是低维语义特征空间中的概念向量。
该DNN模型用于Web文档排序，如下所示：1)将项向量映射到对应的语义概念向量；2)以文档与查询对应语义概念向量的余弦相似度计算文档与查询之间的关联评分。参考式(3)到(5)。
![](https://pic2.zhimg.com/v2-b3b7b6a176cfe1b7c4054fe70392175d\_1440w.jpg)
通常，术语向量（term vector）(可以被视为信息检索中的原始词袋特性)的大小与用于索引Web文档集合的词汇表的大小相同。在真实的Web搜索任务中，词汇量通常非常大。因此，当使用term vector作为输入时，神经网络的输入层的大小对于推理和模型训练是无法控制的。为了解决这个问题，我们为DNN的第一层开发了一种叫做单词哈希的方法，如图1的下面部分所示。这一层仅由线性隐藏单元组成，其中不用学习非常大的权值矩阵。在下一节中，我们将详细描述单词哈希方法。
### \*\*3.2 Word Hashing\*\*
这里描述的词哈希方法旨在降低词袋词向量的维数。它是以字母n-gram为基础的，是专门为我们的任务而开发的一种新方法。给定一个单词(例如good)，我们首先给单词加上起尾标记(例如#good#)。然后，我们把这个单词分成字母n-gram(例如字母三元组合:#go, goo, ood, od#)。最后，用字母的 \_n\_-grams组成的向量表示单词。
这种方法的一个问题是冲突（ \_collision\_），即两个不同的单词可能有相同的字母n-gram向量表示。表1显示了两个词汇表上的单词散列的一些统计信息。与单一热点向量的原始大小相比，单词哈希允许我们使用维数低得多的向量来表示查询或文档。以40字的词汇为例。每个单词都可以用一个10306维向量表示，使用字母三元组，可以在很少冲突的情况下减少四维。当该技术应用于更大的词汇表时，维数的减少就更加重要了。如表1所示，500K-word词汇表中的每个单词都可以用字母三元组表示为30,621维向量，维数减少了16倍，碰撞率为0.0044%(22/500,000)，可以忽略不计。
![](https://pic3.zhimg.com/v2-ffc85940c5516ed8dc7469bf6c83f560\_1440w.jpg)
虽然英语单词的数量是无限的，但英语(或其他类似语言)中字母 \_n\_-grams的数量通常是有限的。此外，单词哈希能够将相同单词的形态变化映射到字母n-gram空间中彼此靠近的点。更重要的是，虽然在训练集中看不到的单词总是会在基于单词的表示中造成困难，但在使用基于字母ngram的表示时却不是这样。唯一的风险是表1中量化的较小的表示冲突。因此，基于字母ngram的单词哈希对词汇表外的问题是健壮的，允许我们将DNN解决方案扩展到需要非常大的词汇表的Web搜索任务。我们将在第4节中演示该技术的好处。
在我们的实现中，基于字母 \_n\_-gram的单词哈希可以被看作是一种固定的(即非自适应的)线性变换，通过这种变换，输入层中的项向量被投影到上一层的字母n元向量上，如图1所示。由于字母n-gram向量的维数较低，因此可以有效地进行DNN学习。

### \*\*3.4 Implementation Details\*\*
为了确定训练参数并避免过拟合，我们将点击数据分为两个不重叠的部分，分别称为训练数据集和验证数据集。在实验中，模型在训练集上进行训练，并在验证数据集上优化训练参数。在DNN实验中，我们使用了如图1所示的带有三个隐藏层的体系结构。第一个隐藏层是单词哈希层，包含约30k个节点(如表1所示的字母三元组大小)。接下来的两个隐藏层各有300个隐藏节点，输出层有128个节点。单词哈希是基于一个固定的投影矩阵。相似性度量基于维度为128的输出层。
![](https://pic2.zhimg.com/v2-284806818090ac8775f0595b6350dd9b\_1440w.jpg)
从经验上看，我们没有观察到做分层的前训练会有更好的表现。在训练阶段，我们使用基于小批量的随机梯度下降(SGD)优化模型。每个小批由1024个训练样本组成。我们观察到DNN训练通常在整个训练数据的20个epochs内收敛。
## \*\*4\. EXPERIMENTS\*\*
我们使用真实世界的数据集来评估在第3节中提出的DSSM对Web文档排名任务的评估。在本节中，我们首先描述用于评估模型的数据集。然后，我们比较了我们的最佳模型与其他先进的排名模型的性能。我们还调查了在第3节中提出的技术的分解影响。
### \*\*4.1 Data Sets and Evaluation Methodology\*\*
我们在一个大规模的真实世界数据集上评估了检索模型，此后称之为评估数据集。评估数据集包含了从某商业搜索引擎的1年查询日志文件中取样的16510个英语查询。平均而言，每个查询与15个Web文档(url)相关联。 \*\*每个query-title对都有一个相关标签。标签是人工生成的，有5个级别的相关性，从0到4，其中4级表示文档与查询最相关，0表示不相关。\*\* 所有查询和文档都经过预处理，文本被空格分割并转为小写，数字被保留，并且没有词干化/词形变化。
训练数据集：英文数据集，从检索日志中抽取query-title对（title为页面的标题），数据集中去掉点击信息较少的新页面和长尾页面，只使用点击比较丰富的页面作为训练数据。
评估数据集：含有所有页面（包括没有点击信息的新页面，长尾页面）
评估方法：使用训练集训练数据，使用评估数据集评估模型的ranking效果，评估指标为NDCG（Normalized Discounted Cumulative Gain）

## \*\*5\. CONCLUSIONS\*\*
我们提出并评估了一系列新的潜在语义模型，特别是那些具有深度架构的模型，我们称之为DSSM。主要贡献在于我们在三个关键方面对先前的潜在语义模型(如LSA)进行了重要的扩展。首先，我们通过直接针对文档排序的目标，利用点击数据优化模型所有版本的参数。其次，受深度学习框架的启发，最近在语音识别\[5\]\[13\]\[14\]\[16\]\[18\]中表现得非常成功，我们使用多个隐藏表示层将线性语义模型扩展到它们的非线性对应对象。采用的深层架构进一步增强了建模能力，以便能够捕获和表示查询和文档中更复杂的语义结构。第三，我们使用基于字母n-gram的单词哈希技术，证明它有助于扩大深度模型的训练，以便在现实的网络搜索中使用非常大的词汇。在我们的实验中，我们表明，与上述三个方面相关的新技术可以显著提高文档排序任务的性能。这三种新技术的组合产生了一种新的、最先进的语义模型，它以极大的优势击败了以前开发的所有竞争模型。

### DSSM正负样本如何构建
每个query对应几个正样本，随机再采样4个没点击的负样本

### DSSM如何做推理
![](https://pic3.zhimg.com/v2-236b3a7a4751d4fe6b2fbe36a41b5ce2\_1440w.jpg)
训练好的模型可以计算出所有doc的语义特征，先进行存储。
当有新的query的时候，就直接生成对应的语义特征，然后计算和全量doc的余弦相似度，然后倒排展示，期间可以使用facebook的fasis加速索引过程。
### DSSM的缺点
词袋表示法：没有考虑上下文的特征，难以捕获文本的真正意图。可以考虑CLSM之类的模型。

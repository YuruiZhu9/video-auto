4. 复制并保存密钥（仅创建时可完整查看Access Key Secret，丢失需重新创建）；

（二）OpenClaw对接阿里云百炼API（全环境通用）
\# 1\. 配置百炼API密钥（替换为你的凭证） openclaw config set models.providers.bailian.accessKeyId "你的Access Key ID" openclaw config set models.providers.bailian.accessKeySecret "你的Access Key Secret" # 2. 配置国内接口地址（降低延迟） openclaw config set models.providers.bailian.baseUrl " [https://dashscope.aliyuncs.com/compatible-mode/v1](https://link.zhihu.com/?target=https%3A//dashscope.aliyuncs.com/compatible-mode/v1)" # 3\. 设置默认模型（推荐qwen3.5，免费额度足够使用） openclaw config set models.default "qwen3.5" # 4. 配置Skill协同优化参数 openclaw config set models.providers.bailian.contextWindow 32768 openclaw config set models.providers.bailian.skillCooperation true # 5. 重启网关生效（不同环境重启命令） # 阿里云/Linux openclaw gateway restart # MacOS pkill -f openclaw && nohup openclaw gateway start > ~/.openclaw/logs/gateway.log 2>&1 & # Windows11（PowerShell） openclaw gateway stop openclaw gateway start
（三）API配置验证与避坑要点
1. 验证方法：登录OpenClaw Web控制台，输入测试指令：`帮我搜索2026年AI自动化趋势，总结3条核心结论`，返回结构化回复即为配置成功；
2. 避坑要点：
- 密钥复制错误→逐字符核对，避免多余空格或换行，区分Access Key ID与Secret；
- 接口地址错误→国内部署必须使用指定地址，否则调用超时；
- 免费额度耗尽→登录百炼控制台查看，及时调整Skill调用频率；
- 服务未重启→配置后必须重启网关，否则配置不生效。
四、10款核心Skill分阶段实战（安装+配置+使用）
（一）第一阶段：安全打底（1款）
1\. skill-vetter（安全扫描工具）
\*\*核心功能\*\*：安装新Skill前自动扫描代码、检测恶意程序、排查权限风险，是新手必备的安全防护工具，安装量350+，社区口碑极佳。
\# 1\. 安装Skill（全环境通用） clawhub install skill-vetter # 2. 配置扫描规则（默认高安全级别） openclaw config set skills.skill-vetter.scanLevel "high" # 高/中/低三档 openclaw config set skills.skill-vetter.autoBlockMalicious true # 自动拦截恶意Skill # 3. 重启网关生效 openclaw gateway restart # 4. 实战场景：扫描待安装Skill 在Web控制台输入：“帮我扫描ClawHub上的‘xxx-skill’是否安全，若安全则安装” # 预期结果：返回安全扫描报告，无风险则自动完成安装
\*\*避坑要点\*\*：始终在安装新Skill前启用扫描，避免安装来源不明的插件；扫描结果显示“高风险”的Skill直接放弃安装。
（二）第二阶段：基础必备（3款）
2\. self-improving-agent（自我迭代代理）
\*\*核心功能\*\*：ClawHub热门榜首位（98.5K安装量），记录使用中的错误、修正方法与学习成果，实现AI持续自我优化，逐步贴合用户操作习惯。
\# 1\. 安装Skill（全环境通用） clawhub install self-improving-agent # 2. 配置迭代参数 openclaw config set skills.self-improving-agent.learningRate "medium" # 学习速率：中 openclaw config set skills.self-improving-agent.saveLearnings true # 保存学习成果 # 3. 重启网关生效 openclaw gateway restart # 4. 实战场景：反馈优化建议 在Web控制台输入：“刚才的回复格式不符合我的要求，我希望用 bullet points 呈现核心要点” # 预期结果：AI记录反馈，后续回复自动适配格式要求
\*\*避坑要点\*\*：学习成果本地存储，隐私安全可控；如需重置学习记录，执行`openclaw config delete skills.self-improving-agent.learnings`。
3\. tavily-search（智能联网搜索）
\*\*核心功能\*\*：83.7K安装量的基础刚需技能，基于Tavily API优化，获取实时资讯、最新数据，避免AI因信息滞后出现错误回答。
\# 1\. 安装Skill（全环境通用） clawhub install tavily-search # 2. 配置Tavily API Key（替换为你的密钥） clawhub config set TAVILY\\_API\\_KEY "你的Tavily API Key" # 3. 重启网关生效 openclaw gateway restart # 4. 实战场景：查询实时资讯 在Web控制台输入：“帮我查询2026年Q2 AI自动化工具的热门榜单” # 预期结果：返回结构化搜索结果，包含工具名称、核心功能、用户评价
\*\*避坑要点\*\*：免费额度足够新手使用，额度耗尽后可登录Tavily官网续费；搜索结果仅作参考，重要决策需交叉验证。
4\. find-skills（技能自寻与安装）
\*\*核心功能\*\*：被社区称为“元技能”（80.7K安装量），解决新手“不知道装什么技能”的痛点，能自主检索、推荐并自动安装适配技能。
\# 1\. 安装Skill（全环境通用） clawhub install find-skills # 2. 重启网关生效 openclaw gateway restart # 3. 实战场景：寻找适配技能 在Web控制台输入：“我想让AI帮我编辑Excel表格，需要安装什么Skill？” # 预期结果：AI推荐适配的Excel相关Skill，询问是否自动安装
\*\*避坑要点\*\*：自动安装前会触发skill-vetter安全扫描，确保无风险；安装后建议验证Skill功能，避免冗余插件。
（三）第三阶段：生产力提升（4款）
5\. gog（Google Workspace全家桶集成）
\*\*核心功能\*\*：80K安装量的办公辅助技能，联动Gmail、日历、Drive、Docs、表格等工具，实现邮件收发、日程管理、文档编辑等自动化操作。

\*\*避坑要点\*\*：确保Google账号已开启API访问权限；国内用户需确保网络可正常访问Google服务。

五、新手高频问题解答
（一）部署与API类问题
1. 问题1：OpenClaw启动提示“Node.js版本过低”？
- 解决方案：执行`node -v`验证版本，确保≥22.0.0；Windows重新运行Node.js安装命令，Linux/MacOS执行`sudo npm install -g n && sudo n 22.0.0`升级。
1. 问题2：阿里云百炼API调用提示“密钥无效”？
- 解决方案：逐字符核对Access Key ID与Secret，删除多余空格；登录百炼控制台，确认密钥未过期、未被禁用；若丢失，重新创建密钥并更新配置。
1. 问题3：Mac M系列芯片安装Skill后无法使用？
- 原因：依赖工具未适配ARM架构；
- 解决方案：执行`arch -arm64 brew install 依赖工具名`，指定ARM架构安装依赖；或选择标注“支持M系列芯片”的Skill。
（二）Skill类问题
1. 问题1：安装Skill后，AI未触发使用？
- 解决方案：① 确认已重启网关（`openclaw gateway restart`）；② 检查Skill是否在可用列表（`openclaw skills list --eligible`）；③ 优化指令表述，让需求更贴合Skill功能（如“用tavily-search搜索”而非“帮我查查”）。
1. 问题2：skill-vetter扫描提示“权限风险”，如何处理？
- 解决方案：① 查看风险详情，若为“完全文件系统访问”等高危权限，直接放弃安装；② 若为必要权限，限制Skill访问范围（`openclaw config set skills.技能名.allowedPaths '["指定目录"]'`）。
1. 问题3：tavily-search提示“API Key无效”？
- 解决方案：① 核对API Key是否正确，避免多余空格；② 登录Tavily官网，确认API Key未过期、免费额度未耗尽；③ 重新配置API Key（`clawhub config set TAVILY\_API\_KEY "新密钥"`）。
1. 问题4：批量安装Skill时出现“限流”提示？
- 解决方案：① 执行`clawhub login --no-browser --token 你的令牌`登录ClawHub；② 分批次安装，每批间隔5分钟；③ 切换网络环境（如手机热点）后重试。
1. 问题5：Skill过多导致OpenClaw卡顿？
- 解决方案：① 卸载不常用Skill（`rm -rf ~/.openclaw/skills/技能名`）；② 关闭后台未使用的Skill（`openclaw skill disable 技能名`）；③ 低配设备仅保留前7款核心Skill，进阶技能按需安装。
（三）安全与隐私类问题
1. 问题1：如何确保Skill不泄露隐私数据？
- 解决方案：① 优先选择本地存储记忆的Skill（如agent-memory）；② 限制Skill访问权限，避免授予全系统访问；③ 定期清理敏感记忆数据（`openclaw config delete skills.agent-memory.data`）。
1. 问题2：未知来源的Skill能否安装？
- 解决方案：① 不建议安装来源不明的Skill，风险极高；② 若必须安装，先通过skill-vetter扫描，确认无恶意代码；③ 安装后隔离运行，观察无异常再正常使用。
六、总结
10款核心Skill覆盖安全防护、基础能力、生产力提升、高级优化四大维度，是新手搭建OpenClaw自动化工作流的基础。通过分阶段安装策略，既能避免性能过载，又能逐步熟悉Skill使用逻辑，从“被动响应”到“主动辅助”稳步进阶。
核心要点总结：
1. 部署选择：阿里云适合长期运行、多设备访问，本地部署适合隐私敏感场景，MacOS/Linux兼容性更佳；
2. Skill安装：遵循“安全-基础-生产力-进阶”顺序，优先选择社区强维护、高安装量的插件；
3. 配置核心：API密钥妥善保管，Skill权限合理限制，安装后必须重启网关；
4. 避坑关键：确保Node.js版本≥22.0.0，启用skill-vetter安全扫描，定期清理冗余插件与过期记忆。
通过本文的流程与技巧，你可快速构建OpenClaw的核心技能体系，让AI真正融入日常学习与工作，实现信息检索、文档处理、任务规划等场景的自动化，大幅提升效率。

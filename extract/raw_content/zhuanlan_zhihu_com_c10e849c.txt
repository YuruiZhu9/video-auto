\*\*漏洞描述\*\*：OpenClaw 的 \`isValidMedia()\` 函数未充分限制媒体路径，允许传入绝对路径、家目录路径及目录穿越序列。攻击者可诱导 agent 输出 \`MEDIA:/path/to/file\` 一类路径，从而读取系统上的任意本地文件，造成敏感信息泄露。
\*\*修复建议\*\*：优先升级到官方已修复版本（OpenClaw 2026.1.30 及以上，具体以官方公告/发行说明为准）；在升级前应禁用不可信媒体路径输入，仅允许受控目录下的相对路径，并阻断绝对路径、\`~\` 与 \`..\` 等逃逸写法。
来源： [https://nvd.nist.gov/vuln/detail/CVE-2026-25475](https://link.zhihu.com/?target=https%3A//nvd.nist.gov/vuln/detail/CVE-2026-25475)
## 75\. CNNVD-202603-628 / CVE-2026-28451

\*\*风险等级\*\*：中危

来源： [https://nvd.nist.gov/vuln/detail/CVE-2026-28451](https://link.zhihu.com/?target=https%3A//nvd.nist.gov/vuln/detail/CVE-2026-28451)
## 76\. CNNVD-202603-629 / CVE-2026-28452
\*\*漏洞类型\*\*：其他
\*\*风险等级\*\*：中危
\*\*漏洞影响版本\*\*：OpenClaw < 2026.2.14
\*\*漏洞描述\*\*：OpenClaw 的 \`extractArchive\` 解压逻辑缺少对高膨胀 ZIP/TAR 归档的资源约束。攻击者可构造压缩炸弹或高展开归档，诱导系统在解压过程中大量消耗 CPU、内存和磁盘空间，造成拒绝服务。
\*\*修复建议\*\*：优先升级到官方已修复版本（OpenClaw 2026.2.14 及以上，具体以官方公告/发行说明为准）；在升级前应禁止处理不可信归档文件，为解压过程设置总展开大小、文件数量、层级深度和执行超时上限。
来源： [https://nvd.nist.gov/vuln/detail/CVE-2026-28452](https://link.zhihu.com/?target=https%3A//nvd.nist.gov/vuln/detail/CVE-2026-28452)
## 77\. CNNVD-202602-586 / CVE-2026-25157
\*\*漏洞类型\*\*：操作系统命令注入
\*\*风险等级\*\*：中危
\*\*漏洞影响版本\*\*：OpenClaw < 2026.1.29
\*\*CWE\*\*：CWE-78
\*\*漏洞描述\*\*：OpenClaw 2026.1.29 之前版本在 SSH 远程连接处理中存在两处命令注入问题：一是 \`sshNodeCommand\` 在生成 shell 脚本时，未对项目路径在错误输出中的插值做安全转义，导致 \`cd\` 失败时可在远端主机执行任意命令；二是 \`parseSSHTarget\` 未阻止以短横线开头的目标字符串，攻击者可构造类似 \`-oProxyCommand=...\` 的参数，使其被当作 SSH 选项解析并在本地触发命令执行。
\*\*修复建议\*\*：优先升级到官方已修复版本（OpenClaw 2026.1.29 及以上，具体以官方公告/发行说明为准）；在升级前应禁止将项目路径或 SSH 目标等不可信输入直接拼接进 shell/ssh 调用，拦截以短横线开头的 SSH 目标参数，并限制高危远程执行能力。
来源： [https://nvd.nist.gov/vuln/detail/CVE-2026-25157](https://link.zhihu.com/?target=https%3A//nvd.nist.gov/vuln/detail/CVE-2026-25157) \| [https://github.com/openclaw/openclaw/security/advisories/GHSA-q284-4pvr-m585](https://link.zhihu.com/?target=https%3A//github.com/openclaw/openclaw/security/advisories/GHSA-q284-4pvr-m585)

## 79\. CNNVD-202603-632 / CVE-2026-28394
\*\*漏洞类型\*\*：其他
\*\*风险等级\*\*：中危
\*\*漏洞影响版本\*\*：OpenClaw < 2026.2.15
\*\*漏洞描述\*\*：OpenClaw 的 \`web\\_fetch\` 工具在解析超大或深度嵌套的 HTML 响应时缺少足够的资源限制。攻击者可通过恶意网页响应诱导 Gateway 进程发生内存耗尽并崩溃，造成拒绝服务。
\*\*修复建议\*\*：优先升级到官方已修复版本（OpenClaw 2026.2.15 及以上，具体以官方公告/发行说明为准）；在升级前应限制 \`web\\_fetch\` 可访问来源，对响应体大小、解析深度和处理时长设置硬上限，并避免抓取不受信网页。
来源： [https://nvd.nist.gov/vuln/detail/CVE-2026-28394](https://link.zhihu.com/?target=https%3A//nvd.nist.gov/vuln/detail/CVE-2026-28394)
## 80\. CNNVD-202602-001 / CVE-2026-25253
\*\*漏洞类型\*\*：其他
\*\*风险等级\*\*：中危
\*\*漏洞影响版本\*\*：OpenClaw < 2026.1.29
\*\*漏洞描述\*\*：OpenClaw 会从查询字符串读取 \`gatewayUrl\` 并在未充分提示用户的情况下自动建立 WebSocket 连接，同时携带访问令牌。攻击者可诱导用户打开特制链接，使客户端主动连接到恶意网关并泄露令牌或进一步暴露会话数据。
\*\*修复建议\*\*：优先升级到官方已修复版本（OpenClaw 2026.1.29 及以上，具体以官方公告/发行说明为准）；在升级前应禁用从 URL 查询参数自动接管网关连接的行为，对新网关连接增加显式确认，并避免在不可信链接中传递连接参数。
来源： [https://nvd.nist.gov/vuln/detail/CVE-2026-25253](https://link.zhihu.com/?target=https%3A//nvd.nist.gov/vuln/detail/CVE-2026-25253)
## 81\. CNNVD-202602-3712 / CVE-2026-27007
\*\*漏洞类型\*\*：其他
\*\*风险等级\*\*：低危
\*\*漏洞影响版本\*\*：OpenClaw < 2026.2.15
\*\*漏洞描述\*\*：OpenClaw 的 \`normalizeForHash\` 在处理仅含原始值的数组时会递归排序，导致本应保留顺序语义的沙箱配置数组在哈希后出现碰撞。攻击者可利用这一点让不同顺序的安全配置与不安全配置共用同一缓存键，从而复用错误的沙箱状态。
\*\*修复建议\*\*：优先升级到官方已修复版本（OpenClaw 2026.2.15 及以上，具体以官方公告/发行说明为准）；在升级前应避免依赖顺序敏感数组生成沙箱缓存键，并在升级后清理旧的沙箱配置缓存，防止错误状态继续被复用。
来源： [https://nvd.nist.gov/vuln/detail/CVE-2026-27007](https://link.zhihu.com/?target=https%3A//nvd.nist.gov/vuln/detail/CVE-2026-27007)
## 82\. CNNVD-202603-607 / CVE-2026-28471
\*\*漏洞类型\*\*：其他
\*\*风险等级\*\*：低危
\*\*漏洞影响版本\*\*：2026.1.14-1 <= OpenClaw < 2026.2.2（安装并启用 Matrix 插件）
\*\*漏洞描述\*\*：OpenClaw 的 Matrix 插件在私聊 allowlist 匹配时，会对发送者显示名和 localpart 做精确匹配，但未校验 homeserver 归属。远程 Matrix 用户可伪装为与白名单用户同名或同 localpart 的跨服务器身份，从而绕过私聊白名单限制。
\*\*修复建议\*\*：优先升级到官方已修复版本（OpenClaw 2026.2.2 及以上，具体以官方公告/发行说明为准）；在升级前应停止仅按显示名或 localpart 做放行判断，改为同时校验完整 Matrix 用户标识与 homeserver，并临时收紧 DM allowlist 规则。

## AI Guitar Tab Transcriber 项目 — Guitar + Bass 双轨 MVP 完成

### 项目地址
https://github.com/YuruiZhu9/AI-music-score-featch

### 完成时间
2026-03-24（本次 session 完成）

### 需求背景
用户想转行推荐系统算法工程师，同时关注大模型。该项目是其个人兴趣项目：从音频/视频自动扒取吉他谱 + Bass 谱。

### 技术方案（Guitar + Bass 双轨）

**Guitar 轨：**
- librosa 和弦识别（chromagram + beat sync）
- CREPE 音高检测（fallback：librosa pyin）
- Demucs 音频分离出 guitar 轨（GPU）或原文件 fallback（CPU）

**Bass 轨：**
- `detect_bass_pitch()`：Bass 低频范围 E1~C4，CREPE / librosa pyin fallback
- `recognize_bass_notes()`：Bass 单音符检测 + 根音推断
- Demucs 分离出 bass 轨

**乐谱输出：**
- GTA 文本谱：Guitar 6弦 + Bass 4弦 双轨 ASCII 六线谱
- PDF：fpdf2 生成可打印文档
- MIDI：mido 生成双轨 MIDI（Guitar音色ch0 + Bass音色ch1），可导入 Guitar Pro

**视频下载：**
- yt-dlp 支持 YouTube / B站 / 抖音 等100+平台
- B站需 SESSDATA cookie（当前 fallback：无 cookie 模式）

### 已完成的功能

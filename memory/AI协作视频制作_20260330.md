## 四、AI视频制作全流程工作流（2026年3月最新版）

### 工作流概览

```
【第一阶段】文案生成
    ↓ 文案脚本（大模型）
【第二阶段】视觉生成
    ├→ PPT/动画（Gamma / MotionGo）
    ├→ 配图（Midjourney / SD4 / 通义万相）
    └→ 视频片段（Seedance 2.0 / Kling 3.0 / Grok Imagine）
【第三阶段】音频生成
    ├→ 配音（MiniMax T2A / 通义TTS / ElevenLabs）
    ├→ 背景音乐（Mureka V8 / Suno v5 / 海螺AI）
    └→ 音效（AI音效工具）
【第四阶段】视频合成
    ├→ 剪映专业版（手动/自动剪辑）
    └→ FFmpeg（自动化脚本批量合成）
【第五阶段】发布与分发
```

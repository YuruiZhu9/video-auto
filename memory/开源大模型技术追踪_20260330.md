# 一、TurboQuant：KV Cache的"3-bit极限定律"

> 💡 **核心洞察**：TurboQuant的意义不是"又一种量化方法"，而是**证明了KV Cache可以被压缩到3-bit而完全不损失精度**——这打破了"3-bit量化必然带来精度损失"的行业共识。其技术路径（极坐标旋转 + 1-bit误差修正）的数学优雅性，堪比FlashAttention对注意力计算的重新设计。对于推荐系统，这意味着：在不改变模型精度的情况下，可以用消费级显卡服务企业级的推荐推理任务。

## 1.1 问题背景：为什么KV Cache必须量化？

### KV Cache的内存困境（定量分析）

KV Cache存储的是Transformer中每个注意力层的Key和Value矩阵：

```
KV Cache内存 = 2 × n_layers × n_heads × head_dim × seq_len × bytes_per_param
```

以Llama-3.1-8B为例（n_layers=32，n_heads=32，head_dim=128）：

| 上下文长度 | FP16 KV Cache | INT4 KV Cache（理论） | TurboQuant 3-bit |
|-----------|-------------|---------------------|-----------------|
| 4K tokens | 2GB | 0.5GB | **~0.19GB** |
| 32K tokens | 16GB | 4GB | **~1.5GB** |
| 128K tokens | 64GB | 16GB | **~6GB** |
| 1M tokens | 512GB | 128GB | **~48GB** |

**关键问题**：当上下文达到128K tokens时，KV Cache本身就消耗64GB显存——这已经超过了大多数单卡的容量。

### 现有量化方法的局限

| 方法 | 压缩原理 | 精度损失 | 额外开销 | 训练需求 |
|------|--------|--------|--------|--------|
| INT8量化 | 逐通道缩放 | 无（通常） | 低 | 无 |
| KIVI | 2-bit + 缩放因子 | 轻微 | 中 | 校准集 |
| DuQuant | 分组旋转量化 | 部分 | 中 | 校准集 |
| **TurboQuant** | 极坐标+1-bit校正 | **零** | **接近零** | **无** |

## 1.2 PolarQuant：极坐标变换的核心数学

### 为什么需要随机旋转？

传统向量量化的核心问题是：**原始向量的各分量往往具有不同的方差和相关性**。直接量化会放大"方向失真"（direction distortion），因为大分量主导量化步长，小分量被忽略。

**随机旋转的核心思想**：通过一个正交矩阵P将向量旋转到一个"各分量方差更均匀"的空间，使得量化误差在各维度上均匀分布，从而在固定比特数下实现最小均方误差（MSE）。

```python
# 随机旋转（预计算，一次生成，反复使用）
import numpy as np

def generate_rotation_matrix(d: int) -> np.ndarray:
    """生成 d×d 的随机正交矩阵（QR分解保证正交性）"""
    G = np.random.randn(d, d)
    P, _ = np.linalg.qr(G)  # QR分解：P是正交矩阵
    return P                 # P @ P.T = I（单位阵）

# 旋转操作（推理时执行）
def rotate(x: np.ndarray, P: np.ndarray) -> np.ndarray:
    return P @ x              # 线性变换，无额外开销（矩阵乘法）
```

### 极坐标量化的数学原理

**两两分组策略**：将d维向量按配对分组（d必须是偶数），每组包含2个标量(x₁, x₂)，变换为极坐标(r, θ)：

```
r     = √(x₁² + x₂²)           （半径，非负标量）
θ     = arctan2(x₂, x₁)        （角度，∈ [-π, π]）
```

**关键洞察**：对半径r不量化（因为r的分布跨度太大），**只量化角度θ**。

- **角度θ的范围**：固定在[-π, π]（或[0, 2π]），与向量模长无关
- **角度θ的分布**：在d维超球面上均匀分布时，角度θ的边缘分布是已知的（Beta分布），可以用Lloyd-Max算法预计算最优量化质心
- **旋转后的角度分布**：通过随机旋转P，原始向量的各分量相关性被打破，旋转后的角度分布更接近理论Beta分布假设

```python
# Beta分布（角度θ的边缘分布）
# f_X(x) = Γ(d/2) / (√π · Γ((d-1)/2)) × (1 - x²)^((d-3)/2)
# 其中 x = cos(θ)，θ ∈ [-π, π]

from scipy.special import gamma
import numpy as np

def beta_distribution_pdf(x, d):
    """d维向量的角度边缘分布pdf"""
    coeff = gamma(d/2) / (np.sqrt(np.pi) * gamma((d-1)/2))
    return coeff * (1 - x**2)**((d-3)/2)
```

**极坐标量化的核心优势**：
- 取消所有per-block全精度常数（无需存储缩放因子）
- 角度量化与向量模长解耦
- 旋转后各组独立量化，互不干扰

## 1.3 QJL：1-bit残差校正的数学优雅

### 问题的引入

即使通过极坐标旋转+角度量化，向量化后的误差仍然存在。对于注意力计算：

```
原始注意力：  softmax(Q · Kᵀ / √d) · V
量化后注意力：softmax(Q · K̂ᵀ / √d) · V̂
```

量化误差来自两个部分：
1. **Key向量量化误差**（PolarQuant部分已压缩）
2. **量化误差在内积空间中累积**（旋转后仍残留）

### QJL（1-bit Johnson-Lindenstrauss Sketch）的核心思想

QJL是一种**无偏内积估计器**。给定两个高维向量y和x̂（x̂是x的量化版本），QJL用1-bit的压缩表示来估计它们的内积⟨y, x̂⟩：

```python
class QJL:
    """
    1-bit Johnson-Lindenstrauss Sketch
    用途：消除量化误差在内积空间的累积
    """
    def __init__(self, d: int, sketch_dim: int):
        # sketch_dim: 草图维度（远小于d，但保证估计精度）
        self.sketch_dim = sketch_dim
        # 生成随机投影矩阵 S ∈ {-1, +1}^{sketch_dim × d}
        # 使用稀疏投影（避免全矩阵乘法开销）
        self.S = self._generate_sign_matrix(sketch_dim, d)
    
    def sketch(self, x):
        """将d维向量压缩为sketch_dim维"""
        # 核心操作：sign(x @ S.T)
        # 结果是 {-1, +1}^sketch_dim 的向量（每维仅需1 bit）
        return np.sign(x @ self.S.T)
    
    def inner_product_estimate(self, y, x_sketch):
        """
        无偏内积估计
        E[⟨y, x⟩] = √(π/2) · ⟨sign(y @ S.T), x_sketch⟩
        """
        y_sketch = self.sketch(y)
        # 期望 E[sign(yᵢ) · x_sketchᵢ] = √(2/π) · x̂ᵢ（当x服从正态分布时）
        raw = y_sketch * x_sketch  # element-wise
        return np.sqrt(np.pi / 2) * raw.sum()
```

**数学保证**：QJL的理论基础是JL引理（Johnson-Lindenstrauss Lemma）——"在高维空间中，随机投影几乎保持点间距离"。具体到内积估计：

```
|E[⟨y, x̂⟩_QJL - ⟨y, x̂⟩]| ≤ ε · ||y|| · ||x̂||    （概率 ≥ 1 - δ）
```

**QJL的1-bit特性**：
- 存储成本：sketch_dim bits（vs. 原始d维FP32）
- 计算成本：O(sketch_dim)（vs. O(d)）
- 在注意力计算中，sketch_dim通常取64-128，远小于d（4096）

## 1.4 完整Pipeline：TurboQuant的三阶段架构

```
原始Key向量 x ∈ R^d（FP16）
        ↓
[阶段1: 随机旋转]
x' = P @ x                （P是预计算的d×d正交矩阵）
        ↓
[阶段2: 极坐标变换 + 角度量化]
(x₁', x₂') → (r, θ) → quantize(θ) → idx  （只量化角度，半径r保留FP16）
        ↓
存储：(idx, r)            （idx = 3-bit，r = FP16标量）
        ↓
[阶段3: QJL Sketch（可选，用于注意力校正）]
s = sign(P @ x)           （1-bit sketch，sketch_dim = 64-128）
存储：s                   （sketch_dim bits = 64-128 bits << d × 16 bits）
```

## 1.5 代码实现：TurboQuant核心原语

```python
import torch
import numpy as np

class TurboQuant:
    """
    TurboQuant KV Cache量化器
    核心原理：PolarQuant（极坐标旋转量化）+ QJL（1-bit残差校正）
    """
    def __init__(self, d_model: int, n_heads: int, bits: int = 3):
        self.d_model = d_model
        self.n_heads = n_heads
        self.head_dim = d_model // n_heads
        self.bits = bits
        self.n_centroids = 2 ** bits
        
        # 预计算旋转矩阵（一次生成，推理时复用）
        self.rotation_matrices = self._generate_rotation_matrices()
        
        # 预计算Lloyd-Max质心（离线计算，推理时查表）
        self.centroids = self._compute_lloyd_max_centroids()
    
    def _generate_rotation_matrices(self):
        """
        为每个注意力头生成独立的随机正交矩阵
        使用QR分解保证正交性（数值稳定性优于Gram-Schmidt）
        """
        matrices = []
        for _ in range(self.n_heads):
            G = torch.randn(self.head_dim, self.head_dim)
            Q, _ = torch.linalg.qr(G)  # Q是正交矩阵
            matrices.append(Q)
        return matrices  # 存储成本：n_heads × head_dim² × 2B = 可接受
    
    def quantize(self, x: torch.Tensor) -> tuple:
        """
        输入: x ∈ [batch, seq_len, n_heads, head_dim] (FP16)
        输出: (quantized_indices, radii, qjl_sketches)
        """
        B, S, H, D = x.shape
        indices_list = []
        radii_list = []
        sketches_list = []
        
        for h in range(H):
            x_h = x[:, :, h, :]  # [B, S, D]
            P_h = self.rotation_matrices[h].to(x.device)
            
            # Step 1: 旋转
            x_rot = x_h @ P_h  # [B, S, D]
            
            # Step 2: 两两分组 → 极坐标
            indices_h = []
            radii_h = []
            for i in range(0, D, 2):
                x1, x2 = x_rot[..., i], x_rot[..., i+1]
                r = torch.sqrt(x1**2 + x2**2)     # 半径（保留FP16）
                theta = torch.atan2(x2, x1)       # 角度（量化）
                
                # 角度量化（查找最近质心）
                theta_norm = theta / np.pi  # 归一化到[-1, 1]
                idx = self._quantize_theta(theta_norm, h, i//2)
                indices_h.append(idx)
                radii_h.append(r)
            
            indices_list.append(torch.stack(indices_h, dim=-1))
            radii_list.append(torch.stack(radii_h, dim=-1))
            
            # Step 3: QJL sketch（可选，用于注意力校正）
            sketch = torch.sign(x_h @ self.qjl_matrix[h].T)
            sketches_list.append(sketch)
        
        return (torch.stack(indices_list, dim=2),
                torch.stack(radii_list, dim=2),
                torch.stack(sketches_list, dim=2))
    
    def _quantize_theta(self, theta_norm, head, pair_idx):
        """查表量化（O(1)复杂度）"""
        # centroids[head][pair_idx]: [n_centroids] 维张量
        c = self.centroids[head][pair_idx].to(theta_norm.device)
        # 找最近质心：broadcast + min
        diff = torch.abs(theta_norm.unsqueeze(-1) - c)  # [B, S, n_centroids]
        return torch.argmin(diff, dim=-1)  # 返回质心索引（3-bit）
```

- 视觉编码阶段：并行处理
- 扩散生成阶段：并行迭代

三者可以**流水线并行**：当LLM在"构思"下一句时，视觉编码器已经在处理下一批图像。

**2. 统一KV Cache管理**
```python
# vLLM-Omni的关键设计：所有模态共享统一的KV Cache池
class UnifiedKVCache:
    """
    文本token、图像patch token、音频mel token
    统一使用PagedAttention的分页管理
    """
    def alloc(self, token_type, num_tokens):
        # 不同模态的token可能用不同的page size优化
        page_size = {
            "text": 16,        # 文本token
            "image_patch": 64, # 图像patch（较大）
            "audio_frame": 32  # 音频帧
        }[token_type]
        return self._allocate_pages(num_tokens, page_size)
```

**3. 非自回归架构支持**
vLLM-Omni是首个支持**扩散Transformer + LLM混合推理**的框架：
- 扩散模型（图像/视频生成）：并行去噪迭代
- LLM（文本生成）：自回归生成
- 两者通过Omni Scheduler统一编排

# 三、推理框架支持进展（2026年3月更新）

## 3.1 vLLM v0.18 对Llama 4 MoE的官方支持

vLLM v0.18（2026年3月正式版）带来了对Llama 4系列的完整支持：

```python
# vLLM v0.18 部署 Llama 4 Scout 示例
from vllm import LLM, SamplingParams

llm = LLM(
    model="meta-llama/Llama-4-Scout-17B-16E-Instruct",
    tensor_parallel_size=1,  # 单卡H100（Int4量化）
    max_model_len=10_000_000,  # 10M上下文
    enforce_eager=False,  # 使用CUDA Graph加速
)

sampling_params = SamplingParams(temperature=0.7, max_tokens=4096)
# Llama 4 Scout 支持10M上下文，但需要足够的显存
# Int4量化下，10M上下文约需 60GB 显存
```

### Llama 4 MoE的特殊配置

```python
# Llama 4 Maverick（400B MoE / 128专家）的vLLM配置
llm = LLM(
    model="meta-llama/Llama-4-Maverick-17B-128E-Instruct",
    tensor_parallel_size=2,  # 2×H100（FP8）
    max_model_len=128_000,
    enforce_eager=False,
    # MoE专用配置
    task="generate",
)
```

**vLLM v0.18 对Llama 4的关键改进**：
- ✅ 原生支持MoE架构的专家路由
- ✅ 10M上下文支持（PagedAttention扩展）
- ✅ FP8/INT4量化兼容
- ⚠️ 10M上下文需要足够的KV Cache显存（建议配合PagedAttention使用）

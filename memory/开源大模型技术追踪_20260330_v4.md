## 2.3 两大技术创新解析

### 创新1：推理时计算（Inference-time Computing）

```
传统范式：训练时消耗大量算力，推理时固定计算
o3范式：推理时动态分配计算资源（对难问题分配更多"思考"Token）

类比推荐系统：
- 传统：固定排序模型（计算量固定）
- o3：难Case自动调用更多特征和推理路径（如o3先"分析"用户行为模式再排序）
```

### 创新2：自然语言程序搜索（Nature Language Program Search）

```
核心思想：
1. 让模型先生成"解题程序"（用自然语言描述解题策略）
2. 然后执行该程序解决问题
3. 自我验证并修正

这对推荐系统的启发：
- 传统推荐：基于embedding相似度排序
- o3式推荐：先生成"用户画像分析报告"→ 基于报告做排序决策 → 自我验证排序效果
```

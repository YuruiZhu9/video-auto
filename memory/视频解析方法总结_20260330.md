#### 长视频理解技术路线（三足鼎立）

```
1. 流式推理（Streaming）
   └→ StreamingVLM（MIT&NVIDIA）：无限长视频流式处理

2. 压缩记忆（Compression+Memory）
   └→ VideoMem：视频帧压缩+外部记忆存储

3. 分段级联（Chunking）← InternVideo2.5/LongVLM采用
   └→ HiCo分层令牌压缩：自适应处理万帧以上视频

4. 视觉对齐RAG ← VideoRAG路线（新增！）
   └→ 文本语义+视觉内容双重匹配，无需训练
```

#### VCR-Bench：视频推理能力评估新基准

- **发布方**：中科大团队
- **规模**：859个视频，1034组问答，7个维度（时空推理/因果推断等）
- **核心发现**：最优o1模型CoT得分仅62.8，准确率56.7%；大多数模型<40分
- **关键洞察**：视觉感知能力是瓶颈，而非推理能力
- **最佳视频长度**：中等长度视频表现最佳；短视频和长视频推理能力均较弱

### 1.2 视频分割与跟踪（Video Segmentation & Tracking）

#### SAM2 核心能力

- **Streaming Memory**：将图像视为单帧视频，通过流内存机制扩展至动态视频
- **视频实时分割**：对任意目标像素级跟踪分割
- **零样本泛化**：无需训练即可分割新类别
- **SAM2-Hiera**：推理速度比SAM1快3-6倍

#### VOST（Video Object Segmentation & Tracking）技术进展

| 进展 | 说明 |
|------|------|
| **Sa2VA** | SAM2 + LLaVA，文本驱动的视频分割 |
| **CoTracker** | Meta AI，密集点跟踪，支持遮挡和重入 |
| **OSTrack** | Transformer在线跟踪，VIDOT数据集 |
| **Molmo 2 VideoTrack** | 自然语言查询驱动多目标跟踪，持久ID跨遮挡 |
| **Video Depth Anything** | ByteDance (CVPR 2025)，时序一致深度估计，任意长度视频，A100仅23.6GB |

### 1.5 视频检索与 RAG

#### VideoRAG 详解（NeurIPS 2025，港大×百度）

**核心创新**：将视觉对齐的辅助文本（语音转录、OCR文字）与视觉内容双重匹配，无需训练，单RTX 3090可处理数百小时视频。

**三大技术模块**：
1. 知识驱动的语义索引
2. 视觉-文本对齐辅助检索
3. 多模态融合生成

**优势**：
- 单张RTX 3090（24GB）即可运行
- 支持数百小时超长视频
- 在LongerVideos基准测试中超越现有RAG和长视频方法

#### 视频RAG技术对比

| 方案 | 核心方法 | 硬件需求 | 适用场景 |
|------|---------|---------|---------|
| **VideoRAG** | 视觉对齐RAG，无需训练 | RTX 3090 | 超长视频（数百小时） |
| **Gemini Embedding 2** | 多模态向量检索 | API调用 | 语义检索 |
| **FAISS/Milvus** | 高维向量最近邻 | 本地GPU | 大规模特征存储 |
| **Video-RAG（厦大等）** | 视觉对齐辅助文本，无微调 | 单卡 | 长视频理解 |

**全链路Pipeline**：
```
视频 → 帧提取+语音转录+OCR → 向量化 → FAISS/Milvus索引
用户Query → 编码 → 向量检索 → Top-K片段 → LLM生成答案
```

## 三、工具选型决策树（2026年3月版）

```
视频解析任务
│
├─ 视频时长 ≤ 2分钟
│   ├─ 需要语义理解 → videos_understand ⭐⭐⭐⭐⭐
│   ├─ 需要字幕稿 → audios_understand / Faster-Whisper ⭐⭐⭐⭐⭐
│   └─ 需要画面文字 → FFmpeg帧提取 → images_understand ⭐⭐⭐⭐
│
├─ 视频时长 2分钟 ~ 1小时
│   ├─ 需要完整理解 → videos_understand（分段） + Gemini API ⭐⭐⭐⭐
│   ├─ 需要语义检索 → Gemini Embedding 2 RAG ⭐⭐⭐⭐
│   └─ 需要字幕稿 → yt-dlp + WhisperX ⭐⭐⭐⭐
│
├─ 视频时长 > 1小时（超长视频）
│   ├─ 需要语义检索问答 → VideoRAG（RTX 3090即可）⭐⭐⭐⭐⭐
│   ├─ 需要万帧"大海捞针" → InternVideo2.5 ⭐⭐⭐⭐⭐
│   └─ 需要全局摘要 → FFmpeg分段 + videos_understand（批量）⭐⭐⭐⭐
│
└─ 批量处理/定时监控
    └→ n8n自动化工作流 + YouTube Transcript API ⭐⭐⭐⭐
```

## 六、关键问题解答

**Q1：超长视频（>1小时）用什么方案？**
> 首选 **VideoRAG**（NeurIPS 2025，港大×百度开源）：单RTX 3090可处理数百小时，支持自然语言问答；备选 InternVideo2.5（万帧"大海捞针"能力）。

**Q2：视频推理能力哪家最强？**
> 根据 VCR-Bench（859个视频，7个维度），闭源模型中 **o1** 最高（CoT 62.8/Acc 56.7%），但整体视频推理仍是全行业瓶颈，大多数模型<40分。

**Q3：视频分割最新工具是什么？**
> SAM2仍是视频分割最佳工具，配合 CoTracker（密集点跟踪）或 Sa2VA（SAM2+LLaVA文本驱动分割）使用。

**Q4：国内有什么值得关注的视频理解模型？**
> **Doubao-VL**（字节跳动火山引擎）：豆包App深度集成，视频理解+语义推理；**InternVideo2.5**（上海AI Lab）：万帧"大海捞针"，开源可商用。

> ⚠️ **名称区分**：**港大VideoRAG**（HKUDS）和**厦大Video-RAG**（XMU+NJU+U of Rochester）是两个不同的工作：
> - **港大VideoRAG**：双通道架构（基于图的知识锚定 + 多模态特征压缩），专注数百小时超长视频
> - **厦大Video-RAG**：视觉对齐辅助文本（OCR+ASR+目标检测），零训练即插即用，7B模型额外推理仅5秒

#### Qwen3-VL 深度解析（⭐新增）

**发布**：2025年9月24日，阿里云云栖大会

**核心突破**：
- **100万Token上下文**（约2小时视频）：原生256K，扩展至100万
- **2小时会议视频时间戳定位准确率 99.5%**（测试场景："第15分钟穿红衣人物的动作"）
- **MRoPE-Interleave**：交错分布时间、高度和宽度编码，提升长视频理解
- **DeepStack机制**：视觉特征分层注入语言模型各层，增强跨模态对齐
- **T-RoPE升级**：文本时间戳对齐，通过"时间戳-帧"交错输入实现帧级细粒度时序建模

**性能**：
- 46项多模态基准测试全面领先
- 32种语言OCR，复杂场景识别率>70%，古籍竖排文字F1达94.5%

**部署**：
- API：通义千问QwenChat免费体验 + 阿里云百炼平台
- 本地：A100/H100，FP16推理速度15 tokens/s
- 显存优化：动态分块+混合精度，10GB显存可处理512×512图像

#### Seed1.5-VL / Doubao-VL 深度解析（⭐新增）

**发布**：2025年，火山引擎

**核心能力**：
- **视觉深度思考**：类似CoT的逐步推理能力
- **视频时序定位**：动态帧率采样，显著增强时序定位能力
- **向量搜索集成**：结合向量数据库精准定位视频片段
- **仅20B激活参数**：高效推理，适合生产部署

**应用**：豆包App深度集成，实时场景问答（扫码识物、读报告、读代码）

#### 长视频理解技术路线（三足鼎立 → 四足鼎立）

```
1. 流式推理（Streaming）
   └→ StreamingVLM（MIT&NVIDIA）：无限长视频流式处理

2. 压缩记忆（Compression+Memory）
   └→ VideoMem：视频帧压缩+外部记忆存储

3. 分段级联（Chunking）← InternVideo2.5/LongVLM采用
   └→ HiCo分层令牌压缩：自适应处理万帧以上视频

4. 视觉对齐RAG ← VideoRAG路线
   ├→ 港大VideoRAG（知识图谱双通道，无需训练，RTX 3090）
   └→ 厦大Video-RAG（视觉对齐辅助文本，零成本，7B模型+5秒）

5. 原生长上下文 ← Qwen3-VL路线（新增！）
   └→ 100万Token原生上下文，MRoPE-Interleave+T-RoPE
```

### 1.2 视频分割与跟踪（Video Segmentation & Tracking）

#### SAM2 核心能力

- **Streaming Memory**：将图像视为单帧视频，通过流内存机制扩展至动态视频
- **视频实时分割**：对任意目标像素级跟踪分割
- **零样本泛化**：无需训练即可分割新类别
- **SAM2-Hiera**：推理速度比SAM1快3-6倍

#### VOST（Video Object Segmentation & Tracking）技术进展

| 进展 | 说明 |
|------|------|
| **Sa2VA** | SAM2 + LLaVA，文本驱动的视频分割 |
| **CoTracker** | Meta AI，密集点跟踪，支持遮挡和重入 |
| **OSTrack** | Transformer在线跟踪，VIDOT数据集 |
| **Molmo 2 VideoTrack** | 自然语言查询驱动多目标跟踪，持久ID跨遮挡 |
| **Video Depth Anything** | ByteDance (CVPR 2025 Highlight)，时序一致深度估计，任意长度视频，A100仅23.6GB |

#### DisTime 框架（CVPR 2025，⭐新增）

**发布方**：美团技术团队

**核心创新**：
- 使用**单个可学习的时间标记**创建连续的时间嵌入空间
- 结合基于分布的时间解码器，生成时间概率分布
- 有效缓解边界模糊性问题并保持时间连续性

**数据集贡献**：
- 提出自动化标注模式，创建 **InternVidTG 数据集**
- 包含 **17.9万个视频**
- **125万个时间定位事件**
- 是 ActivityNet-Caption 的 **55倍**

**意义**：为视频时间理解提供了大规模自动化标注数据基础

### 1.5 视频检索与 RAG（⭐全面升级）

#### VideoRAG 两大流派对比（⭐新增重要区分）

| 对比维度 | 港大VideoRAG | 厦大Video-RAG |
|----------|-------------|--------------|
| **发布时间** | NeurIPS 2025 | NeurIPS 2025 |
| **机构** | 港大数据科学实验室×百度 | 厦大×南大×罗切斯特大学 |
| **核心技术** | 动态知识图谱+多模态特征压缩 | 视觉对齐辅助文本（OCR+ASR+检测） |
| **检索方式** | 双通道（图结构知识锚定+多模态压缩） | Contriever+FAISS（单轮并行） |
| **硬件需求** | RTX 3090（24GB） | 极低，7B模型额外推理仅5秒 |
| **成本** | 低（单卡） | 极低（零训练成本） |
| **即插即用** | 支持 | ✅ 完全即插即用 |
| **最强性能** | LongVideoBench等 | Video-MME 77.4%（超越GPT-4o） |

> 💡 **选型建议**：追求最强性能选**厦大Video-RAG**（77.4%超越GPT-4o），追求超长视频（数百小时）选**港大VideoRAG**

#### 厦大Video-RAG技术栈详解（⭐新增）

**三阶段Pipeline**：
```
1. 查询解耦：LVLM生成结构化JSON检索请求（ASR/DET/TYPE）
2. 辅助文本生成+检索：
   - EasyOCR → OCR文本库
   - Whisper → ASR音频文本库  
   - APE → 开放词汇目标检测库
   - CLIP → 关键帧筛选
   - Contriever + FAISS → 向量检索
3. 整合生成：按时间顺序合并辅助文本，与查询+采样帧一起输入LVLM
```

**性能亮点**：
- LLaVA-Video-72B + Video-RAG = **77.4%**（Video-MME，超越GPT-4o 77.2%）
- LLaVA-Video-72B + Video-RAG = **65.4%**（LongVideoBench，超越Gemini 1.5-Pro 64.0%）
- GPU显存节省 **150GB+**
- 相比VideoAgent的2000美元API费用：**零成本**

#### 视频RAG技术对比（更新版）

| 方案 | 核心方法 | 硬件需求 | 适用场景 |
|------|---------|---------|---------|
| **港大VideoRAG** | 知识图谱双通道，无需训练 | RTX 3090 | 超长视频（数百小时） |
| **厦大Video-RAG** | 视觉对齐辅助文本，零成本 | 极低（7B+5秒） | 通用长视频，SOTA性能 |
| **InternVideo2.5** | HiCo令牌压缩，万帧"大海捞针" | 单卡 | 万帧以上长视频 |
| **Qwen3-VL** | 原生100万Token上下文 | A100推荐 | 2小时级别长视频 |
| **Gemini Embedding 2** | 多模态向量检索 | API调用 | 语义检索 |
| **FAISS/Milvus** | 高维向量最近邻 | 本地GPU | 大规模特征存储 |

**全链路Pipeline**：
```
视频 → 帧提取+语音转录+OCR → 向量化 → FAISS/Milvus索引
用户Query → 编码 → 向量检索 → Top-K片段 → LLM生成答案
```

### 1.6 视频生成模型（Wan2.2，⭐新增章节）

#### Wan2.2（开源视频生成，⭐新增）

**发布方**：Wan-AI（GitHub开源）

**核心能力**：

| 模式 | 模型 | 分辨率 | 说明 |
|------|------|--------|------|
| Text-to-Video | T2V-A14B | 480P/720P | 文本生成视频 |
| Image-to-Video | I2V-A14B | 480P/720P | 图片生成视频 |
| Text-Image-to-Video | TI2V-5B | 720P | 文本+图片生成 |
| Speech-to-Video | S2V-14B | 480P/720P | 语音驱动视频 |
| Character Animation | Animate-14B | — | 角色动画替换 |

**技术亮点**：
- **MoE架构**：双专家设计（高噪声专家+低噪声专家），SNR自动切换

- **RTX 4090单卡运行**：TI2V-5B在单卡RTX 4090上，720P 5秒视频生成 <9分钟
- **训练数据增长**：图像+65.6%，视频+83.2%（相比Wan2.1）

**集成支持**：HuggingFace Diffusers、ComfyUI、ModelScope、LoRA微调

## 六、关键问题解答（v2更新）

**Q1：超长视频（>1小时）用什么方案？**
> - **追求最强性能**：厦大Video-RAG + LLaVA-Video-72B（77.4%，超越GPT-4o，零训练成本）
> - **追求超长支持**：港大VideoRAG（数百小时，单RTX 3090）
> - **万帧"大海捞针"**：InternVideo2.5

**Q2：2小时级别长视频用什么方案？**
> **首选 Qwen3-VL**（阿里，2025年9月发布）：256K→100万Token上下文，2小时会议视频时间戳定位准确率99.5%，阿里云百炼平台API可用。

**Q3：视频推理能力哪家最强？**
> 根据 VCR-Bench（859个视频，7个维度），闭源模型中 **o1** 最高（CoT 62.8/Acc 56.7%）；厦大Video-RAG在Video-MME上 **77.4%** 超越GPT-4o（77.2%）。

**Q4：视频分割最新工具是什么？**
> SAM2仍是视频分割最佳工具，配合 CoTracker（密集点跟踪）或 Sa2VA（SAM2+LLaVA文本驱动分割）使用；CVPR 2025 Video Depth Anything（A100仅23.6GB，任意长度视频）。

**Q5：港大VideoRAG和厦大Video-RAG有什么区别？**
> 两个不同的NeurIPS 2025工作。**港大VideoRAG**侧重知识图谱双通道+多模态压缩，适合数百小时超长视频；**厦大Video-RAG**侧重视觉对齐辅助文本（OCR+ASR+检测），即插即用，7B模型推理仅增5秒，在Video-MME上达77.4%超越GPT-4o。

**Q6：国内有什么值得关注的视频理解模型？**
> - **Qwen3-VL**（阿里）：100万Token，2小时视频99.5%定位，MRoPE-Interleave
> - **Seed1.5-VL**（字节跳动）：20B激活参数，视觉深度思考，视频时序定位
> - **InternVideo2.5**（上海AI Lab）：万帧"大海捞针"，开源可商用
> - **厦大Video-RAG**（NeurIPS 2025）：77.4%超越GPT-4o，零成本

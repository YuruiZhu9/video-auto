#### Qwen3-VL 深度解析（⭐ v3新增技术细节）

**发布**：2025年9月24日，阿里云云栖大会；技术报告 arXiv:2511.21631（2025年11月26日）

**模型规格**（技术报告新增）：

| 类型 | 规格 |
|------|------|
| Dense | 2B / 4B / 8B / 32B |
| MoE | 30B-A3B / 235B-A22B |

**核心突破**：
- **100万Token上下文**（约2小时视频）：原生256K，YaRN扩展至100万

- **Enhanced interleaved-MRoPE**：更强时空建模能力
- **DeepStack机制**：多层ViT特征融合，增强跨模态对齐
- **Text-based Time Alignment**：从T-RoPE升级为显式文本时间戳对齐

| 参数 | 功能 | 默认值 | 说明 |

**发布**：2025年4月11日，OpenGVLab（上海AI Lab×南大×多机构）

- **Pixel Unshuffle**：视觉Token压缩至1/4

#### 长视频理解技术路线（v3更新版）

```
1. 流式推理（Streaming）
   └→ StreamingVLM（MIT&NVIDIA）：无限长视频流式处理

2. 压缩记忆（Compression+Memory）
   └→ VideoMem：视频帧压缩+外部记忆存储

3. 分段级联（Chunking）← InternVideo2.5/LongVLM采用
   └→ HiCo分层令牌压缩：自适应处理万帧以上视频

4. 视觉对齐RAG ← VideoRAG路线
   ├→ 港大VideoRAG（知识图谱双通道，无需训练，RTX 3090）
   └→ 厦大Video-RAG（视觉对齐辅助文本，零成本，7B模型+5秒）

5. 原生长上下文 ← Qwen3-VL路线
   └→ 256K→100万Token，MRoPE-Interleave+T-RoPE

6. 多Agent结构化推理 ← MMCTAgent路线（新增！）
   └→ Planner-Critic双Agent，GPT-4o VideoMME +4.6%
```

### 1.2 视频分割与跟踪（Video Segmentation & Tracking）

## 六、关键问题解答（v3更新）

**Q1：超长视频（>1小时）用什么方案？**
> - **追求最强性能**：厦大Video-RAG + LLaVA-Video-72B（77.4%，超越GPT-4o，零训练成本）
> - **追求超长支持**：港大VideoRAG（数百小时，单RTX 3090）
> - **万帧"大海捞针"**：InternVideo2.5

**Q2：6小时以上超长视频用什么方案？**
> - **6小时级别**：**Gemini 2.5 Pro**（多模态综合SOTA，2025年5月发布）
> - **数十小时~百小时级别**：**Gemini 3.0**（Google，2026年3月，1000万Token上下文，统一潜空间原生跨模态推理）

**Q3：最强开源视频理解模型是哪个？**
> **Molmo2-8B**（Allen AI，2026年1月）：视频指向F1=38.4（Gemini 3 Pro=20.0），视频跟踪J&F=56.2（Gemini 3 Pro=41.1），全面超越Gemini 3 Pro

**Q4：如何增强现有GPT-4o的视频理解能力？**
> **MMCTAgent**（微软研究院）：Planner-Critic双Agent架构，GPT-4o VideoMME从72.1%→76.7%（+4.6%），基于AutoGen开源

**Q5：Qwen3-VL和Qwen3.5有什么区别？**
> **Qwen3-VL**（2025年9月）：视频理解专用模型，100万Token上下文，2小时视频99.5%定位；**Qwen3.5**（2026年3月）：通用原生多模态智能体（0.8B~397B），Gated DeltaNet+MoE混合架构，支持视觉理解但不专门针对长视频

**Q6：国内有什么值得关注的视频理解模型？**
> - **Qwen3.5**（阿里，2026.03）：Gated DeltaNet+MoE，0.8B可手机端跑视频，262K上下文
> - **Qwen3-VL**（阿里）：100万Token，2小时视频99.5%定位，MRoPE-Interleave
> - **InternVL3-78B**（OpenGVLab）：78.7% MVBench，72.7% Video-MME，开源综合最强
> - **Seed1.5-VL**（字节跳动）：20B激活参数，视觉深度思考，视频时序定位
> - **厦大Video-RAG**（NeurIPS 2025）：77.4%超越GPT-4o，零成本

**Q7：视频理解Benchmark最新格局？**
> - **Video-MME**：综合视频理解，含字幕/无字幕双版本（GPT-4o=72.1%，厦大Video-RAG=77.4%，InternVL3-78B=72.7%，Gemini-1.5-Pro=75.0%）
> - **MVBench**：视频特定能力多维度评估（InternVL3-78B=78.7%最高）
> - **MLVU**：长视频理解（InternVL3-78B=79.5%最高）
> - **LongVideoBench**：长视频（厦大Video-RAG=65.4%，Gemini-1.5-Pro=64.0%）
> - **Video-MMMU**（2026.01新增）：专家视频理解，300视频/900问题/6学科
> - **MMVU**（2026.01新增）：27学科专家级多学科视频理解
> - **MMMU**（2026.03新增）：15K问题/9038视频/13技能类别的多模态长视频问答

### 🧭 框架二：AI 代码 Review 清单

**针对 AI 生成代码的专项检查：**

| 检查项 | 具体操作 | 危险信号 |
|--------|----------|----------|
| **包验证** | 在 npm/PyPI 官网验证每个依赖包是否真实存在 | 包名有拼写变体、从未见过的冷门包 |
| **意图对齐** | 对照原始 prompt，检查 AI 输出是否跑偏 | 代码功能正确但方向完全不对 |
| **幻觉识别** | 检查 import 结构、方法名是否符合文档 | 文档中找不到该 API |
| **许可证** | 检查依赖包的许可证类型（GPL→风险高） | 包含 AGPL 代码、版权声明可疑 |
| **上下文理解** | AI 是否正确使用了项目已有模块/变量 | 用了不存在的全局变量或常量 |
| **性能反模式** | 循环嵌套、重复计算、N+1 查询 | 列表推导式内嵌循环、缺少缓存 |
| **安全漏洞** | SQL/命令注入、未校验用户输入 | 直接拼接字符串作为 SQL/Shell 命令 |

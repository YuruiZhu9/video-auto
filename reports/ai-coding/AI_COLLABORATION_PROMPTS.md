## 六、高级协作技巧

### 让 AI 自我审查

```
在你给出代码之前，请先自己审查一遍：
1. 这个方案是否最优？
2. 有什么潜在的问题我没有考虑？
3. 如果我是维护者，我会有什么困难？

然后再给出代码和审查结果。
```

### 要求多方案对比

```
请用 2-3 种不同的方式实现 [功能]，并对比：
| 维度 | 方案A | 方案B | 方案C |
|------|-------|-------|-------|
| 性能 | | | |
| 可读性 | | | |
| 可维护性 | | | |
| 适用场景 | | | |

推荐方案：[说明理由]
```

### 触发幻觉自我纠正

```
如果 AI 给出了看起来"过于完美"的方案，追问：
"请再检查一遍，确认你没有：
1. 使用不存在的包或 API
2. 引用不准确的文档
3. 忽略边界情况"

这可以有效触发 AI 的自我纠正机制。
```

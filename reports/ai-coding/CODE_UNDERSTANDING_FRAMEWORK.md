# AI 代码理解框架

> 适用场景：当你拿到一段 AI 生成的代码，不知道从哪里开始理解时，使用此框架。

---

## 第一步：整体把握

回答三个问题：

1. **这个代码要解决什么问题？**
   - 描述问题的输入和期望输出
   - 对应到业务/算法层面是什么？

2. **整体架构是怎样的？**
   - 用一句话描述：`输入` → `[处理模块]` → `输出`
   - 有哪些核心文件？它们之间的关系是什么？

3. **AI 生成这段代码的上下文是什么？**
   - 你给 AI 的原始 prompt 是什么？
   - AI 的输出和你的意图是否对齐？

---

## 第二步：核心逻辑

1. **最重要的函数/类是哪个？**
   - 找到代码的"心脏"，从这里入手
   - 不要从工具函数开始（会被细节淹没）

2. **数据流是怎样的？**
   - 追踪一个具体数据（输入）从头到尾的完整路径
   - 标注每个转换节点

3. **关键的算法逻辑是什么？**
   - 用自然语言重写核心算法（AI 能帮你做这个）
   - 查文档确认：不熟悉的 API 立即查，不要猜

---

## 第三步：逐行理解

**对每个关键行/块追问：**

| 问题 | 含义 |
|------|------|
| `这行代码做了什么？` | 用一句话解释 |
| `如果不这样写会怎样？` | 理解设计意图 |
| `边界条件是什么？` | 空值、0、超大输入 |
| `AI 为什么要这样写？` | 结合训练数据推断原因 |

**重点关注 AI 代码的特殊陷阱：**
- 看起来"过于完美"的注释或变量命名
- 不熟悉的标准库用法
- 超出你预期的复杂实现

---

## 第四步：Review 要点

### 逻辑正确性
- [ ] AI 的假设成立吗？
- [ ] 边界条件（0/1/空/极大值）处理了吗？
- [ ] 异常情况会崩溃吗？

### 性能考虑
- [ ] 有没有 O(n²) 的嵌套循环？
- [ ] 是否有重复计算可以缓存？
- [ ] 内存使用是否合理？

### 安全问题
- [ ] 有注入风险吗？（SQL/命令/代码注入）
- [ ] 敏感数据是否暴露？
- [ ] 权限控制是否正确？

### 上下文对齐
- [ ] 代码和原始需求对齐吗？
- [ ] 用了项目中不存在的变量/模块吗？
- [ ] 包依赖真实存在吗？（AI 幻觉包）

---

## 推荐系统代码理解专项

如果你在看推荐系统相关代码，额外关注：

| 模块 | 关键问题 |
|------|----------|
| **样本构建** | 特征如何生成？负样本策略是什么？ |
| **模型训练** | embedding 维度、loss 设计、正则化 |
| **在线 serving** | 特征获取延迟、模型加载方式 |
| **效果评估** | 用了哪些指标？线上线下如何对齐？ |

---

## 使用示例

```
场景：我用 AI 生成了协同过滤推荐代码，但不确定它是否正确

使用框架：

Step 1：整体把握
→ 解决问题：为用户推荐相似用户喜欢的物品
→ 架构：用户-物品矩阵 → 相似度计算 → Top-K 推荐
→ 原始 prompt：生成一个基于用户的协同过滤推荐

Step 2：核心逻辑
→ 心脏：similarity_score() 函数
→ 数据流：ratings_matrix → cosine_similarity → argtopk
→ 核心算法：余弦相似度，用于找相似用户

Step 3：逐行理解
→ np.dot(u, v) / (norm(u) * norm(v))：余弦相似度公式
→ 边界：用户无评分时矩阵为 0，相似度为 NaN → 检查到有处理

Step 4：Review
→ 逻辑：✅ 正确处理了冷启动（无相似用户时降级策略）
→ 性能：⚠️ 全量计算 O(m²n)，大数据集需要优化
→ 安全：✅ 无外部输入，无注入风险
→ 对齐：⚠️ 输出格式与原需求一致
```

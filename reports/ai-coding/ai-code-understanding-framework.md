# AI 代码理解框架

## 1. 整体把握（30 秒扫描）
- 这个代码要解决什么问题？（看文件名 + 注释）
- 整体架构是怎样的？**输入 → 处理 → 输出**
- 有多少个函数/类，哪个是核心？

## 2. 核心逻辑（5 分钟深挖）
- 最重要的函数是哪个？（通常是最长或被调用最多的）
- 数据流是怎样的？（参数是什么，返回什么）
- 关键算法逻辑（为什么这样做而不是那样？）

## 3. 逐行理解（遇到不懂的）
- 这行代码做了什么？（大白话翻译）
- 为什么不这样写？（有没有替代方案）
- 这个变量的类型和来源是什么？

## 4. Review 要点检查清单

### 功能正确性
- [ ] 代码是否解决了它声称要解决的问题？
- [ ] 正常流程走得通吗？
- [ ] 核心路径有没有遗漏？

### 边界条件（AI 代码最容易翻车的地方）
- [ ] 空输入 `[]`, `""`, `{}`, `null` 会怎样？
- [ ] 零值、负数、最大整数会怎样？
- [ ] 单元素、两个元素这种最小 case 呢？

### 性能考虑
- [ ] 有没有循环内的低效操作？（字符串拼接、重复计算）
- [ ] 数据结构选择合理吗？（list vs set vs dict）
- [ ] 有没有可以缓存的结果被重复计算？

### 安全问题
- [ ] 用户输入有没有验证？
- [ ] 有没有 SQL/命令注入风险？
- [ ] 错误信息会不会泄露敏感信息？

### 代码质量
- [ ] 变量命名清晰吗？
- [ ] 有没有 magic number / magic string？
- [ ] 错误处理是真实的还是只打了个日志？

## 5. 快速理解陌生语言/框架的技巧

```
遇到不懂的代码：
1. 找入口函数（通常是 main / handler / render）
2. 顺着调用链往下追（别想一次看懂全部）
3. 不懂的函数名：让 AI 翻译成大白话
4. 不懂的语法：查 30 秒文档或直接问 AI
```

## 6. AI 代码特殊检查项

- [ ] 依赖的库真的存在吗？（npm / PyPI 查一下）
- [ ] API 用法是最新的吗？（有没有 deprecated？）
- [ ] 类型定义和实际数据匹配吗？
- [ ] 环境变量 / 配置都有默认值或说明吗？

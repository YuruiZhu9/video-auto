# 高效 AI 协作提示词模板库

> 适用工具：Claude Code / Cursor / ChatGPT / Copilot  
> 原则：越具体越好，越有结构越有效

---

## 一、代码理解类

### 1.1 整体解释

```
你是一个高级算法工程师。请逐行解释下面这段代码，重点说明：
1. 每个函数的作用（用一句话概括）
2. 数据的流向（输入→处理→输出）
3. 关键的算法逻辑（用简单例子说明）
4. 我可能忽略的边界情况

[粘贴代码]
```

### 1.2 针对特定行的追问

```
我不太理解第 X 行代码：
[粘贴那一行]
- 这一行具体做了什么？
- 如果输入是 [某个值]，输出是什么？
- 为什么要这样写，而不是 [替代方案]？
```

### 1.3 找出潜在问题

```
你是一个偏执的代码审查员。请审查以下代码，找出：
1. 逻辑错误
2. 边界条件漏洞
3. 性能问题
4. 安全风险

对于每个问题，请：
- 指出具体行号
- 描述失败场景
- 给出修复代码

[粘贴代码]
```

## 二、代码生成类

### 2.1 算法实现（生产级别）

```
请为以下问题写一个生产级别的 Python 实现：

【问题】
[详细描述要解决的问题]

【输入】
- 参数名：[类型] — [说明]

【输出】
- 返回值：[类型] — [说明]

【要求】
1. 使用 Python 3.11+，有完整类型注解
2. 在模块 docstring 中解释算法思路
3. 时间复杂度 ≤ [指定]（如果重要）
4. 不要使用第三方库
5. 附上单元测试（正常用例 + 边界用例）
6. 说明时间和空间复杂度
```

### 2.2 重构已有代码

```
请重构以下代码，重点改进：
1. 可读性（变量名、函数长度、结构）
2. 错误处理
3. 类型安全

约束：
- 不要改变函数签名（对外接口不变）
- 保留原有逻辑
- 重构后代码必须有测试覆盖

[粘贴代码]
```

### 2.3 补全缺失的测试

```
为一个函数生成测试，覆盖以下场景：
1. 正常输入
2. 空输入 / None 输入
3. 边界值（如有）
4. 异常输入
5. 性能测试（输入大小的合理上限）

【函数签名】
[粘贴函数]

【已知边界情况】
[如有，列出]
```

## 三、调试类

### 3.1 分析报错

```
我遇到了以下错误，请帮助分析：

【错误信息】
[粘贴完整错误信息，包括 stack trace]

【相关代码】
[粘贴出错的代码片段]

请说明：
1. 这个错误的根本原因是什么？
2. 触发这个错误需要什么条件？
3. 有哪几种修复方式？各有什么优缺点？
```

### 3.2 定位性能问题

```
请分析以下代码的性能瓶颈：

[粘贴代码]

请找出：
1. 时间复杂度最高的地方（O(n²)、嵌套循环等）
2. 内存分配过多的地方
3. N+1 查询风险
4. 可缓存但未被缓存的计算

对于每个问题，请给出：
- 具体位置
- 优化方案
- 优化后的预期性能提升
```

## 四、审查类（可直接复制使用）

### 4.1 Pull Request 全面审查

```
你正在审查一个 Pull Request。请使用以下 10 项清单进行生产就绪审查：

[1] 正确性 & 隐含假设
[2] 错误处理 & 失败模式  
[3] 数据完整性 & 幂等性
[4] 安全漏洞
[5] 并发 & 异步安全
[6] 性能 & 可扩展性
[7] API 边界契约
[8] 测试覆盖
[9] 可观测性（日志/监控）
[10] 依赖管理

对每个发现的问题返回：
- 类别
- 具体代码片段 + 行号
- 失败场景
- 影响程度（高/中/低）
- 修复方案

最后总结：
- Top 5 最高风险问题
- 部署后需要监控什么
```

### 4.2 安全专项审查

```
你是一个安全审查员。请审查以下代码，找出：
1. SQL 注入风险
2. 命令注入风险
3. 权限绕过漏洞
4. 敏感数据泄露（日志、错误信息）
5. 不安全的加密/哈希

对每个漏洞返回：
- 严重程度（Critical/High/Medium/Low）
- 利用场景
- 具体修复代码
```

## 五、AI 自我纠正技巧

| 场景 | 追加提示词 |
|------|-----------|
| AI 回答太快、太自信 | `"are you sure?"`（触发自我审查） |
| 需要更详细的分析 | `"think step by step"`（链式思考） |
| 第一次回答不够好 | `"给出另一种方案"` / `"这个思路有什么问题？"` |
| 担心幻觉 | `"请引用你提到的任何库函数或 API 的文档"` |

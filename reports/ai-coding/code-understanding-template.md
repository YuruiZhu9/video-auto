# AI 代码理解框架

## 1. 整体把握
- 这个代码要解决什么问题？
- 整体架构是怎样的？（输入 → 处理 → 输出）
- 这个函数/模块在系统中的位置？

## 2. 核心逻辑
- 最重要的函数/类是哪个？
- 数据流是怎样的？（参数如何传递，返回什么）
- 关键算法逻辑：用自然语言描述一遍
- 如果是 AI 生成的：AI 在这里用了什么"套路"（如循环、递归、装饰器、设计模式）？

## 3. 细节理解
- 这行代码做了什么？（不懂就标注，回头问 AI）
- 为什么不这样写？（追问替代方案，对比理解）
- 边界条件是什么？
  - 空输入
  - 单元素
  - 极端值
  - 重复输入

## 4. Review 要点
- [ ] 逻辑正确性：这个算法实现对吗？
- [ ] 边界条件：空值、极端值处理了吗？
- [ ] 性能考虑：大数据量下会崩吗？O(n²) 还是 O(n)？
- [ ] 安全问题：有注入风险吗？硬编码密钥？
- [ ] 风格一致性：和项目其他代码风格统一吗？
- [ ] 依赖问题：引入了不必要的库吗？

## 5. 理解验证（可选）
用自己话写 3 行：
```

边界条件：_______________
```

## 推荐系统代码理解示例

假设 AI 生成了这段协同过滤代码：

```python
def compute_similarity(user_vecs, top_k=10):
    # 计算用户相似度矩阵
    sim_matrix = np.dot(user_vecs, user_vecs.T)
    norms = np.linalg.norm(user_vecs, axis=1)
    sim_matrix = sim_matrix / np.outer(norms, norms)
    np.fill_diagonal(sim_matrix, 0)
    return sim_matrix
```

用框架分析：
```
1. 整体把握：计算用户-用户相似度矩阵，使用余弦相似度
2. 核心逻辑：user_vecs @ user_vecs.T 计算点积，然后归一化
3. 细节：fill_diagonal(0) 去除用户和自己的相似度
4. Review：norms 可能为0？数据稀疏时相似度都为0？
```

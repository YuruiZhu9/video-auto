## 一、代码解释类

### 请求逐行解释
```
请逐行解释以下代码，重点说明：
1. 每个函数/方法的作用（用一句话描述）
2. 数据的流向（输入 → 中间处理 → 输出）
3. 关键的算法逻辑
4. 可能的边界条件（什么情况下会出问题）

代码语言：[Python/Java/SQL/...]
代码：
[粘贴代码]
```

### 请求类比解释（适合复杂算法）
```
请用推荐系统的业务语言解释这段代码，不要用"调用"、"实例化"这类词，
用"用户点击行为如何被处理"这样的语言来描述。

代码：
[粘贴代码]
```

### 请求总结摘要（适合大文件）
```
请总结这个文件的核心内容，包括：
1. 主要功能（一句话）
2. 暴露的公共接口（函数/API）
3. 数据依赖（输入什么，输出什么）
4. 我需要重点关注的函数（3个）

文件：[粘贴文件内容]
```

代码语言：[Python/Java/...]

[粘贴代码]

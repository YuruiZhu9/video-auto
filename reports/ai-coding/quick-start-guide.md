## 一、理解 AI 代码的框架

### 1.1 拿到 AI 代码后，先问这三个问题

| 问题 | 为什么要问 |
|------|------------|
| **这段代码要解决什么问题？** | 理解目标才能理解实现 |
| **整体架构是怎样的？** | 先看全局，再看细节 |
| **数据是怎么流动的？** | 追踪输入→处理→输出 |

### 1.2 代码理解检查清单

```python
# 拿到一段代码，按这个顺序理解：

# Step 1: 整体把握
- 这是什么类型的代码？（脚本/工具/服务/算法实现）
- 入口点在哪里？（main 函数、API endpoint）

# Step 2: 核心逻辑
- 最重要的 1-2 个函数是什么？
- 它们接收什么？返回什么？

# Step 3: 细节理解
- 不懂的代码行，记录下来
- 查文档或问 AI

# Step 4: Review 要点
- [ ] 逻辑正确性
- [ ] 边界条件
- [ ] 性能考虑
- [ ] 安全问题
```

### 2.2 请求代码 Review

```
请审查这段代码（语言：XXX），重点关注：
1. 逻辑错误和潜在 bug
2. 边界条件和异常处理
3. 性能问题
4. 安全漏洞
5. 代码规范问题
```

### 2.3 请求优化建议

```
请分析这段代码的性能瓶颈，给出：
1. 当前可能存在的性能问题
2. 具体的优化建议
3. 优化后的代码示例
```

### 2.4 请求补全测试

```
请为这段代码生成单元测试，重点覆盖：
1. 正常输入
2. 边界条件
3. 异常输入
```

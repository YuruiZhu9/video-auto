# AI Coding 实用模板工具包

> 持续更新，每次任务后补充新的高效模板

---

## 一、代码理解框架（AlgoCademy + Stack Overflow 融合版）

```
## 第一步：整体扫描（2分钟）
- 这个代码要解决什么问题？
- 输入 → 处理 → 输出 的流程是什么？
- 用一句话概括代码功能

## 第二步：结构定位（5分钟）
- 主要函数/类是哪个？入口点在哪？
- 文件结构和模块依赖
- 数据如何在这段代码中流动？

## 第三步：逐行理解
- 每行代码在做什么？
- 变量名是否清晰？不清晰则重命名！
- 调用的方法是什么？跳转到定义查看文档

## 第四步：Review 要点检查
□ 逻辑正确性：条件分支覆盖所有情况？
□ 边界条件：空值、极值、并发处理？
□ 性能：有无 O(n²) 或重复计算？
□ 安全：输入验证、敏感信息泄露？
□ AI 陷阱：幻觉函数、缺失类型、API 版本错误？
```

## 二、代码解释提示词（Claude / GPT 通用）

```
你是资深软件工程师。请帮我详细解释以下代码：

```[语言]
[粘贴代码]
```

要求：
1. 逐行/逐函数解释，重点说明每个部分的作用
2. 说明数据的流向（从输入到输出的全过程）
3. 指出这段代码的关键算法或核心逻辑
4. 标注你认为可能的问题或改进点
5. 如果有 AI 生成代码的常见陷阱，请特别指出
```

## 三、代码 Review 提示词

```
你是资深代码审查员，有10年+经验。请审查以下代码片段：

```[语言]
[粘贴代码]
```

审查维度（请逐项给出评价）：
1. **逻辑正确性** - 条件、循环、返回值是否有问题？
2. **边界条件** - 空值、极值、异常输入是否处理？
3. **性能** - 有无时间/空间复杂度问题？
4. **安全** - 输入验证、SQL注入、敏感信息硬编码？
5. **可读性** - 命名、注释、代码组织是否清晰？
6. **工程实践** - 错误处理、资源管理、依赖规范？
7. **AI 陷阱** - 幻觉调用、API 版本错误、缺失类型提示？

对每个问题，请给出：
- 问题描述
- 严重程度（高/中/低）
- 具体修复建议
```

## 四、Debug 辅助提示词

```
## 问题描述
[描述你遇到的具体问题，如：登录接口返回 500 错误]

## 错误信息
```
[粘贴完整错误堆栈]
```

## 相关代码
```[语言]
[粘贴相关代码片段，3-50行]
```

请帮我：
1. 根据错误堆栈，定位最可能的根因（3个以内）
2. 给出每种可能性的判断依据
3. 提供具体的修复代码
4. 说明如何验证修复是否有效
```

## 五、Vibe Coding 上下文模板

每次让 AI 生成代码前，先交代以下信息：

```
## 我的项目背景
- **技术栈**：Python 3.11 + FastAPI + SQLAlchemy + PostgreSQL
- **项目类型**：RESTful API 服务
- **我来实现**：用户登录接口，含 JWT token 认证
- **约束条件**：不能使用第三方认证库，必须兼容 Python 3.10
- **安全要求**：密码必须 bcrypt 加密，token 设置过期时间

## 我的需求
[具体描述你想要的功能]

## 请这样生成
1. 先给出完整代码
2. 然后用 3-5 句话解释核心逻辑
3. 指出需要安装的依赖
```

## 六、AI 代码自检三问

生成代码后，用这三个问题要求 AI 自查：

```
请检查你刚才生成的代码，自问自答以下三个问题：

1. **运行测试** - 这段代码能直接运行吗？有没有语法错误或缺失依赖？
2. **边界测试** - 如果输入是空值、空数组、或极端情况，会崩溃吗？
3. **版本检查** - 使用的 API 在目标 Python/Node 版本中是否存在？
```

**理解程度**：[完全理解 / 大部分理解 / 仍有困惑]
**核心收获**：[1-3条最有价值的理解]

**下一步**：[如何验证/深入]

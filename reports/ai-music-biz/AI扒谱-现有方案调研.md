# AI自动扒谱 - 现有方案调研

> 本文档调研当前市场上已有的AI扒谱产品和开源项目

## 一、商业产品

### 1.1 Klangio（德国）

**基本信息：**
- 官网：https://klang.io/zh-hans/
- 成立：德国
- 特点：多乐器AI转谱

**产品功能：**

| 应用名称 | 功能描述 |
|---------|---------|
| Piano2Notes | 钢琴音乐转乐谱 |
| Guitar2Tabs | 吉他和贝斯转TAB |
| Sing2Notes | 人声/歌唱转音符 |
| Drum2Notes | 鼓转换为音符 |
| Violin2Notes | 弦乐器转乐谱 |
| Wind2Notes | 铜管和木管乐器转音符 |
| Transcription Studio | 多乐器综合转录（适合乐队、作曲家、制作人） |

**支持输入：**
- 音频文件（MP3、WAV、MP4、MIDI、FLAC等）
- YouTube/Instagram/TikTok链接
- 直接录制

**支持输出：**
- PDF（乐谱/吉他谱）
- MIDI（量化和非量化）
- MusicXML
- Guitar Pro

**定价：**
- 免费试用：前20秒免费
- Pro订阅：完整歌曲转录，无限导出

**统计数据：**
- 超过1000万次应用评分
- 应用评分：4.2
- 已创建转录数：1100万+次

**优势：**
- 德国制造，产品质量稳定
- 支持多平台（Web、iOS、Android）
- 可作为DAW插件使用

## 二、开源项目

### 2.1 guitar2midi

**GitHub：** https://github.com/samueldemoura/guitar2midi

**功能：**
- 将DI吉他音频转换为MIDI文件

**技术特点：**
- 需要DI（Direct Input）吉他音频
- 不支持效果器处理过的音色

**使用方式：**
```bash
# 编译
make

# 运行
./guitar2midi input.wav output.mid
```

### 2.2 piano_transcription_inference

**GitHub：** https://github.com/qiuqiangkong/piano_transcription_inference

**功能：**
- 钢琴音频转MIDI
- 字节跳动开源

**技术：**
- 基于CRNN深度学习模型
- 钢琴转谱准确率高

**预训练模型：**
- CRNN_note_F1=0.9677_pedal_F1=0.9186.pth

### 2.3 Basic Pitch

**来源：** Spotify开源

**功能：**
- 音频自动转音符（MIDI）
- 音符检测和追踪

**特点：**
- 易于集成
- 支持多种音频格式

### 2.4 madmom

**GitHub：** https://github.com/Teora/madmom

**功能：**
- Python音频和音乐信号处理库
- 强大的MIR（音乐信息检索）能力

**应用场景：**
- 节拍跟踪
- 音符检测
- 和弦识别
- 调性分析

### 2.5 Spleeter

**来源：** Deezer开源

**功能：**
- 音乐源分离

**分轨能力：**
- 2stems：人声 + 伴奏
- 4stems：人声 + 鼓 + 贝斯 + 其他
- 5stems：人声 + 鼓 + 贝斯 + 钢琴 + 其他

**安装使用：**
```bash
pip install spleeter
spleeter separate -i input.wav -p spleeter:2stems -o output
```

## 四、市场机会分析

### 4.1 现有方案的不足

1. **视频转谱空白**：没有成熟的视频转吉他谱产品
2. **中文支持弱**：Klangio无中文界面
3. **吉他专用模型少**：现有方案多为通用音乐转谱
4. **实时性差**：大多需要等待处理

### 4.2 差异化机会

| 方向 | 机会点 | 竞争优势 |
|------|--------|---------|
| 视频扒谱 | 填补市场空白 | 技术壁垒 |
| 中文优化 | 庞大的中国用户群体 | 本地化优势 |
| 吉他垂直 | 专注吉他/贝斯/鼓 | 深度优化 |
| 社交功能 | 谱友社区 | 用户粘性 |
| 实时演奏 | 现场扒谱 | 创新场景 |

### 4.3 目标用户画像

**核心用户：**
- 吉他/贝斯/鼓爱好者（会演奏想翻奏）
- 琴行教师（需要快速准备教学谱子）
- 音乐制作人（需要提取演奏素材）

**需求强度：**
- 🔥 高：看到喜欢的演奏想翻奏
- 🔥 高：找不到现成谱子的冷门歌曲
- 🔥 中：教学需要快速出谱

## 五、竞品总结

### 5.1 关键发现

1. **音频转谱已商业化**：Klangio、妙音AI等已实现商业化
2. **视频转谱是蓝海**：暂无成熟的视频转吉他谱产品
3. **开源方案可集成**：多个高质量开源项目可作为技术基础
4. **中国市场空白**：国际产品缺乏中文支持

### 5.2 建议策略

**短期（验证市场）：**
- 基于开源项目快速推出音频转谱MVP
- 专注吉他/贝斯垂直领域
- 中文界面，本地化服务

**中期（建立壁垒）：**
- 开发视频手势识别技术
- 积累用户数据优化模型
- 社区运营增加粘性

**长期（生态构建）：**
- 扩展到教学、创作等场景
- 工具+社区+内容生态
- B端授权（琴行、培训机构）

## 一、产品定位

### 1.1 核心定位

**"你的专属扒谱助手——从视频到琴弦，只需一键"**

差异化定位：
- 现有产品做"通用音乐转谱"
- 我们做**"吉他翻奏一站式服务"**（含谱子+演奏示范）
- 别人卖工具，我们卖"谱子+内容+陪伴"

### 1.2 用户故事

```
作为吉他爱好者，
我想把抖音/B站看到的演奏视频转成吉他谱，
这样我可以跟着练习并翻奏。

作为翻奏UP主，
我想找到高准确率的扒谱工具，
这样我可以更快产出翻奏内容。

作为鼓手，
我想把一首歌的鼓谱快速分离出来，
这样我可以跟着练鼓。
```

### 4.2 核心API设计

```python
# 扒谱任务接口
POST /api/v1/transcribe
{
  "input_type": "url" | "file",
  "input_value": "https://...",  # 链接或base64音频
  "instruments": ["guitar", "drums", "bass"],
  "options": {
    "tempo_adjust": 1.0,
    "key_adjust": 0,  # 升降半音
    "tuning": "standard"  # 调弦方式
  }
}
Response: { "task_id": "xxx", "status": "processing" }

# 查询任务状态
GET /api/v1/transcribe/{task_id}
Response: {
  "status": "done" | "processing" | "failed",
  "result": {
    "guitar": { "pdf_url": "...", "midi_url": "...", "gp_url": "..." },
    "drums": { ... },
    "bass": { ... },
    "stems": { "vocals": "...", "drums": "...", "guitar": "...", "bass": "..." }
  }
}

# 导出接口
GET /api/v1/export/{task_id}/{instrument}/{format}
# format: pdf | midi | gp | musicxml
```

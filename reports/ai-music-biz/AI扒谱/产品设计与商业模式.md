# AI自动扒谱 — 产品设计与商业模式

> 更新日期：2026-03-28

---

## 一、核心产品构想

### 1.1 产品定位

**"从演奏视频到吉他谱，只需10秒"**

- 核心用户：想翻奏但找不到谱子的吉他/贝斯爱好者
- 差异化：唯一专注**视频扒谱**的主流产品
- 技术护城河：视频手势识别 × 音频分析 × 指法消歧

### 1.2 产品形态

```
MVP阶段：
  Web应用（最轻）
  ┌─────────────────────────────────────┐
  │  粘贴B站/YouTube链接  或  上传视频   │
  │           ↓                          │
  │  AI分析（10-30秒）                   │
  │           ↓                          │
  │  生成吉他谱（可编辑）                 │
  │           ↓                          │
  │  导出：PDF / MIDI / GuitarPro / 图片  │
  └─────────────────────────────────────┘

V2阶段：
  Web + iOS/Android App
  + 社区（用户校对+分享）
  + AI教学（演奏对比分析）
```

### 1.3 功能优先级

| 优先级 | 功能 | 说明 | 开发难度 |
|--------|------|------|---------|
| P0 | 音频→吉他谱 | 最基础，先跑通核心流程 | ★★☆ |
| P0 | 导出GuitarPro格式 | 行业标准格式，实用性强 | ★★☆ |
| P1 | 视频→吉他谱 | 核心差异化 | ★★★★ |
| P1 | 多轨分离（吉他/贝斯/鼓） | 提升准确率 | ★★★☆ |
| P2 | 社区校对系统 | 护城河构建 | ★★★☆ |
| P2 | AI指法优化建议 | LLM+乐理 | ★★★☆ |
| P3 | AI教学对比 | 演奏评测 | ★★★★ |

## 二、商业模式

### 2.1 推荐模式：免费+订阅+企业授权

```
┌────────────────────────────────────────────────────────┐
│                    商业模式画布                         │
├──────────────────┬──────────────────┬──────────────────┤
│    免费用户       │    个人订阅      │    企业授权      │
│   （流量入口）     │  （核心收入）     │   （B2B增量）    │
├──────────────────┼──────────────────┼──────────────────┤
│ • 每月3次扒谱     │ • ¥29/月         │ • ¥299/月        │
│ • 基础导出格式    │ • 无限次扒谱      │ • 5个团队账号    │
│ • 水印预览        │ • 全格式导出     │ • API调用        │
│                  │ • 无水印        │ • 优先处理        │
│                  │ • 历史记录       │                  │
└──────────────────┴──────────────────┴──────────────────┘
```

### 2.2 盈利模式细化

**① 订阅制（核心收入，预计占70%）**
- 个人版：¥29/月 或 ¥199/年
- 权益：无限扒谱 + 全格式导出 + 无水印 + 优先队列
- 定价依据：对比Guitar Pro ¥499一次性，¥29/月更易接受

**② 按次付费（低门槛获客）**
- ¥5/次扒谱（不订阅用户）
- 适合尝鲜用户，降低决策门槛

**③ 企业授权（B2B增量收入）**
- 音乐教育机构：批量账号 + 专属功能
- 乐器品牌：白标合作（"XX吉他官方扒谱工具"）
- API调用：大厂AI音乐平台集成

**④ 内容变现（B站/抖音联动）**
- 平台内嵌广告（扒谱结果页展示相关产品广告）
- 吉他/音箱/效果器品牌赞助

**⑤ 数据资产（长期价值）**
- 积累的扒谱数据库 → 可授权给AI音乐研究机构
- 用户校对的高质量谱面库 → 可商业售卖

## 三、MVP开发路径

### 阶段一：最小可行产品（2-3个月）

```
目标：验证核心需求和技术可行性

技术栈：
- Python + Flask/FastAPI (后端)
- Basic Pitch (Spotify开源，音高检测)
- Demucs (Meta开源，音轨分离)
- VexFlow/VexTab (渲染吉他谱)
- 部署：阿里云/腾讯云 GPU服务器

核心流程：
音频上传 → Demucs吉他轨分离 → Basic Pitch音高检测
→ 规则指法消歧 → VexFlow渲染 → GuitarPro格式导出

验证指标：
- 50首测试歌曲平均准确率 > 70%
- 用户满意度 > 3.5/5
```

### 阶段二：视频扒谱（6-9个月）

```
目标：建立核心差异化壁垒

技术栈：
- MediaPipe Hands (Google，实时手势识别)
- TapToTab论文方法 (IEEE 2024)
- 微调SynthTab数据集的模型

核心流程：
视频上传 → MediaPipe手势检测 → 音频提取
→ 音频分析(同阶段一) → 手势+音频融合指法推理
→ 生成吉他谱 + 演奏动作可视化

差异化验证：
- 从B站演奏视频扒谱 vs 纯音频扒谱的准确率对比
- 用户偏好测试
```

### 阶段三：社区+AI增强（12-18个月）

```
目标：构建UGC护城河

功能矩阵：
- 用户上传/校对/分享谱子
- AI根据校对数据持续优化
- 社区打赏/积分机制
- B站/抖音内容联动（扒谱视频一键发布）

商业模式成熟化：
- 订阅收入 > $10万/月
- 启动B2B企业合作
- 探索乐器品牌联名
```

## 五、风险与应对

| 风险 | 概率 | 影响 | 应对策略 |
|------|------|------|---------|
| 版权争议（扒流行歌曲） | 高 | 高 | 定位"个人学习工具"，参考YouTube政策 |
| 准确率不够高，用户流失 | 中 | 高 | 社区校对系统，快速迭代 |
| 大厂入局（腾讯/字节） | 低 | 高 | 垂直深耕 + 本地化 + 用户关系 |
| 技术难点（视频手势识别） | 中 | 中 | 先做音频版，视频为差异化高级功能 |

## 六、与用户自身优势结合

用户会演奏吉他/架子鼓，这是天然优势：

**立即可做的事：**
1. 用自己的演奏视频测试现有工具（Basic Pitch / Remusic），验证"看视频扒谱"需求真实存在
2. 在B站发布"AI扒谱实测"内容，测试用户需求
3. 联系吉他社区（吉他中国、百度吉他吧）做早期用户调研

**长期护城河：**
- 个人演奏IP + AI工具 = 内容+工具双轮驱动
- 参考：YouTube吉他博主 × 自建工具的垂直生态

## 一、技术全景图

```
输入类型          核心技术                输出格式
─────────────────────────────────────────────────────
音频文件  ───→  音高检测（Pitch）  ───→  MIDI音符
              乐器分离（Source）  ───→  各乐器轨道
              鼓组识别（Drums）   ───→  鼓谱
              和弦识别（Chords）  ───→  和弦谱
─────────────────────────────────────────────────────
视频文件  ───→  手部检测（MediaPipe）──→  指法位置
              手指追踪（Tracking）──→  按弦/拨弦
              音画同步（Sync）    ───→  时序对齐
─────────────────────────────────────────────────────
哼唱      ───→  哼唱识别（Query）  ───→  主旋律
              调式识别（Key）     ───→  主调
─────────────────────────────────────────────────────
```

## 二、现有开源方案详解

### 2.1 音频→乐谱

#### basic-pitch（Spotify）⭐推荐
- **GitHub**: github.com/spotify/basic-pitch
- **能力**: 钢琴/吉他音高检测，输出MIDI+钢琴卷帘谱
- **准确率**: 单音符95%+
- **许可**: MIT，完全免费商用
- **优点**: 轻量、易集成、Spotify背书
- **缺点**: 不支持多声部分离（需配合Demucs）

#### Omnizart（台湾MIR Lab）⭐推荐
- **GitHub**: github.com/Music-and-Culture-Technology-Lab/omnizart
- **能力**:
  - 音乐转谱（钢琴谱/鼓谱/和弦/节拍）
  -哼唱检索
  - 乐器识别
- **准确率**: 鼓谱~85%，和弦~80%
- **许可**: Apache 2.0
- **优点**: 全链路覆盖，中文文档
- **缺点**: 上次更新2023年，维护较少

#### Demucs（Meta）⭐必备
- **GitHub**: github.com/facebookresearch/demucs
- **能力**: 音乐源分离（人声/鼓/贝斯/其他）
- **准确率**: SOTA级别
- **许可**: MIT
- **优点**: 开源最强乐器分离
- **用法**: 先用Demucs分离，再用basic-pitch处理各轨道

#### Guitar Tablature Transcription System
- **GitHub**: github.com/trimplexx/music-transcription
- **专注**: 多声部吉他谱转录
- **技术**: polyphonic guitar transcription
- **状态**: 个人项目，实验性

#### RiffScribe
- **GitHub**: github.com/abdul-hamid-achik/riffscribe-django
- **技术栈**: Django + HTMX + basic-pitch
- **能力**: 音频→吉他TAB谱
- **意义**: 已有完整Web产品原型可参考

### 2.2 视频→指法谱

#### TapToTab（arXiv 2409.08618）⭐关键
- **论文**: https://arxiv.org/abs/2409.08618
- **任务**: Video → Guitar Tabs（端到端）
- **技术路线**:
  1. 视频帧 → MediaPipe手部关键点检测
  2. 指尖位置 + 指节角度 → 预测按弦品格
  3. 音频音高信息辅助校准
  4. 生成TAB格式输出
- **准确率**: 学术数据集上有效，生产环境未知
- **局限性**: 
  - 依赖特定拍摄角度
  - 遮挡情况下效果差
  - 未产品化
- **可借鉴**: MediaPipe手部检测路线可复用

#### MediaPipe Hands
- **来源**: Google
- **能力**: 21个手部3D关键点实时检测
- **许可**: Apache 2.0
- **用途**: 视频中吉他手部追踪
- **优点**: 成熟、跨平台、性能好

## 三、技术难点深度分析

### 难点1：吉他指法推断（最难）

**问题**：同一音高可能有多种指法
- 例如：第5品A音 = 第7品G音空弦 = 第3品D弦+推弦
- 视频中看到手指按了某品，但不知道是哪个音

**解法思路**：
1. **音频优先**：先用音频确定音高
2. **视频辅助**：用视频指法验证/美化呈现
3. **规则推理**：基于调弦信息，推断最合理指法
4. **LLM修正**：用Qwen3.5-9B做指法合理性校验

**成熟度**: ⭐⭐（学术问题，未解决）

### 难点2：多乐器混音分离

**问题**：真实歌曲中吉他+贝斯+鼓+钢琴+人声混在一起

**主流解法**：
1. Demucs（Meta）：4轨分离，开源最强
2. Spleeter（Deezer）：5轨分离，但效果略逊Demucs
3. MDX（Music Demixing）：最新模型，品目分离SOTA

**成熟度**: ⭐⭐⭐⭐（相对成熟）

### 难点3：实时性

**问题**：用户希望"录完即出谱"，不要等太久

**优化路径**：
- 模型压缩：basic-pitch可量化INT8
- 本地推理：Qwen3.5-9B INT4可在Mac本地跑
- 云端加速：NVIDIA GPU批量处理

**目标**：音频1分钟→3秒出谱

### 难点4：导出格式兼容

**需求**：生成的谱子要能用Guitar Pro打开

**方案**：
- 使用 `guitarpro` Python包（pip install guitarpro）
- 解析/写入.gp/.gp5/.gp6/.gpx格式
- Verovio库：可渲染MusicXML到PNG/PDF

## 五、技术选型汇总

| 功能 | 推荐技术 | 备选 | 备注 |
|-----|---------|------|------|
| 音频音高检测 | basic-pitch | CREPE | Spotify背书，MIT许可 |
| 乐器分离 | Demucs v4 | Spleeter | Meta开源，效果好 |
| 鼓组识别 | Omnizart-drums | beatdetektor | Omnizart更全面 |
| 和弦识别 | madmom | ChordCNN | madmom更成熟 |
| 手部检测 | MediaPipe Hands | OpenPose | Google方案，性能好 |
| 指法识别 | TapToTab路线 | 自研CNN | 需数据标注 |
| LLM后处理 | Qwen3.5-9B（INT4） | GLM-4-Flash | 本地可跑，省成本 |
| Web框架 | FastAPI | Flask | 异步支持好 |
| 前端 | React/Taro | UniApp | 跨端移动App |
| 谱子导出 | guitarpro（pip） | music21+Verovio | .gp格式直接支持 |
| 视频下载 | yt-dlp | N/A | YouTube/B站下载 |

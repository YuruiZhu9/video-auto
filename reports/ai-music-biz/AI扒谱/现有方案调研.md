## 二、核心竞品深度分析

### 2.1 TabIt（tabbitt.app）⭐推荐研究

**为什么值得研究：**
- 100%免费，基于Spotify开源Basic Pitch
- 浏览器本地处理（隐私保护好）
- 支持YouTube/音频/MIDI多输入
- 产品极简，用户体验好

**核心局限：**
- 只能输出MIDI/频谱图，不能直接生成专业TAB
- 无手型/指法信息
- 无多乐器支持
- 无中文界面

### 2.2 Songsterr（songsterr.com）⭐行业标杆

**为什么值得研究：**
- AI转谱 + 人工校正结合（质量较高）
- YouTube直链解析（极大降低用户门槛）
- 支持吉他/贝斯/鼓三种乐器
- Plus订阅模式验证了付费意愿
- 已积累大量用户和社区

**核心局限：**
- 无视频→谱面能力
- 收费较高（Plus约$9.99/月）
- 中文支持差
- 生成的是播放式谱面，非可导出文件

### 2.3 Klangio（klang.io）⭐技术标杆

**为什么值得研究：**
- 产品线最完整（Guitar2Tabs/Piano2Notes/Drum2Notes等）
- 10M+次转谱（数据证明市场需求）
- API可用（可接入其他产品）
- 支持五线谱/TAB/MIDI/MusicXML/GuitarPro全格式
- 14天退款保证（对质量有信心）

**核心局限：**
- 付费产品（具体定价需注册查看）
- 德国公司，中文支持弱
- 无视频→谱面

### 2.4 昆仑万维 Mureka V9（mureka.com）

**为什么值得研究：**
- 人声+器乐双榜全球第一（Artificial Analysis数据）
- 中文歌曲韵律贴合度最强
- MusiCoT音乐思维链技术（生成有结构/叙事性的歌曲）
- 全球8000+客户
- API已开放

**局限性：**
- 这是音乐「生成」工具，不是「扒谱」工具
- 适合做音乐创作，不适合做翻奏扒谱

## 三、开源技术方案对比

### 3.1 Basic Pitch（Spotify）

```
✅ 优势：
- 完全开源免费（MIT协议）
- 本地运行，隐私好
- 支持Mac CoreML优化（M芯片推理快）
- 可输出 MIDI + 频谱图 + 音符时间序列

⚠️ 局限：
- 只能做旋律提取（单音）
- 不适合复杂多乐器混音
- 需要Python工程能力

适合场景：个人使用/小规模商业产品概念验证
```

### 3.2 spleeter（Deezer）

```
✅ 优势：
- 音频分离效果好（人声/伴奏/鼓/贝斯）
- 开源（MIT协议）
- 支持GPU加速

⚠️ 局限：
- 分离≠转谱
- 需要配合音符检测模型才能做转谱

适合场景：作为转谱pipeline的预处理步骤
```

### 3.3 madmom

```
✅ 优势：
- 学术界认可度高
- 节拍跟踪/音符检测效果好
- Python原生

⚠️ 局限：
- 生产级需要大量工程化
- 文档相对少

适合场景：学术研究/功能集成
```

| 机会 | 描述 | 技术可行性 | 商业价值 |

| **视频→吉他TAB** | 看到手在弹什么→直接输出谱 | ⭐⭐⭐（可做但有挑战） | ⭐⭐⭐⭐⭐ |

### 4.2 差异化角度

1. **语言本地化**：全中文界面，中文歌曲专项优化
2. **移动端优先**：现有竞品都是Web版，做移动App
3. **社交化**：用户上传谱子可互相校正（类似Songsterr社区）
4. **内容结合**：扒谱+翻奏展示一体化
5. **AI教学联动**：扒谱后给出练习建议

## 五、技术验证方案

### 5.1 第一步：音频转谱验证（1周）

**目标：验证Basic Pitch能否满足基本需求**

```bash
# 安装
pip install basic_pitch

# 测试代码
from basic_pitch.inference import predict
from basic_pitch import ICASSP_2026_MODEL_PATH

model = torch.load(ICASSP_2026_MODEL_PATH)
note_events, note MIDI, piano_roll = predict(audio_path)
```

**验证集：20首不同风格歌曲（流行/摇滚/爵士/金属）**
- 统计旋律识别准确率
- 识别对吉他的适用性

### 5.2 第二步：TAB格式转换（2周）

**目标：把MIDI音符序列转换为吉他TAB格式**

吉他TAB的特殊处理：
- 同一音符可能有多个把位（需要选择最合理的）
- 需要考虑空弦音（优化指法）
- 需要处理击弦/勾弦等技巧标注

**可参考的开源项目：**
- `guitarpro` (Python包)：可读写GuitarPro格式
- `music21` (MIT)：音乐理论分析

### 5.3 第三步：视频手型分析（长期）

**目标：实现视频→谱面（差异化核心）**

技术路线：
```
MediaPipe Hands → 手部21个关键点
↓ 
手指弯曲程度 → 按弦/空弦判断
↓
手部移动轨迹 → 击弦/勾弦/滑音
↓
吉他指板标定（需要吉他图作为参考系）
↓
和弦/音符识别 → LLM推理优化
```

**可参考项目：**
- GuitarTrainer (GitHub)：视频分析基础
- Guitar-Chord-Analyzer (GitHub)：手型识别基础

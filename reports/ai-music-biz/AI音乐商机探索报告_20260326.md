## 一、🔥 AI自动扒谱：重点方向（持续验证）

### 1.1 竞品动态更新（2026年3月）

#### AudioJam v3.8.5 — 国内最强扒谱工具再进化

**最新版本**：v3.8.5（2026-02-24更新）  
**开发商**：广州市奇乐库科技有限公司  
**平台**：Windows/Mac/iOS/Android/Web

**核心能力**：
- **伴奏分离**：Spleeter AI，提取人声/鼓/贝斯/钢琴/吉他/其他
- **和弦分析**：700+种和弦识别，准确率**90%+**（此前约80%）
- **音调/BPM分析**：智能节拍器音轨生成
- **变速/升降调**：降速播放、AB循环
- **Guitar Pro预览**：支持导入Guitar Pro/MusicXML附件预览播放 ← **新增**

**商业模式**：
- 基础版免费（含核心AI功能）
- Pro版订阅（具体定价见官方）
- Windows PC版130MB，永久免费

**对用户的启示**：
> AudioJam目前是国内市场最接近"一站式AI扒谱"的工具，但它做的是**辅助扒谱**（通过分离+分析降低人工难度），而非全自动转谱。它的存在恰恰证明了市场需求旺盛，同时反衬全自动AI转谱仍是蓝海。

#### 爱扒谱（aibapu.cn）— 音频转五线谱平台

**功能**：
- 音频上传 → AI生成五线谱
- 乐器音轨分离（人声/鼓/贝斯/伴奏四大轨道）
- 五线谱转MIDI
- AI歌曲生成

**平台现状**：2026年3月持续运营中，提供在线工具

#### Chord AI — 多乐器和弦识别

**能力**：
- 吉他/钢琴/尤克里里多乐器支持
- 700+种和弦识别（含sus/bend/7th等高级和弦）
- **倒转和弦检测**：C/E、Am7/G等
- 离线运行（基础功能）
- v2.7.36版本持续更新

#### Klangio Guitar2Tabs（德国）

- 支持YouTube链接直转吉他谱
- 订阅制，€9.9/月起
- 国际竞品参考

## 五、🚀 更新后的MVP路线图（2026年3月版）

### 核心差异化定位更新

```
差异化定位（精化版）：
不做通用AI音乐工具，做"中文语境吉他翻奏AI"

定位要素：
1. 中文界面 + B站登录（降低门槛）
2. 视频/音频双输入（B站/YouTube链接直解析）
3. 输出：Guitar Pro格式 + PDF吉他谱 + MIDI
4. 叠加：谱子市场（用户转谱成果可上架售卖）
```

### 阶段一：技术验证（第1-4周）

```
✅ 可立即验证：
1. 用AudioJam测试B站吉他演奏视频
   → 评估当前辅助扒谱的效率提升
2. 用Tabby（开源）测试同一视频的自动转谱效果
   → 评估全自动路线的可行性
3. 用yt-dlp + Demucs + Basic Pitch搭建自动化管道
   → 验证端到端流程

验证指标：
• 人工扒谱：30-120分钟/首
• AI辅助（AudioJam）：5-20分钟/首
• AI全自动（Tabby）：5-15分钟/首（但需人工校正）
```

### 阶段二：产品构建（第5-12周）

```
核心功能：
• B站/YouTube链接解析（yt-dlp）
• 音频分离（Demucs v4）
• 音符检测（Basic Pitch + TART）
• 吉他TAB/Guitar Pro输出（music21/guitarpro库）
• 注册+分享（谱子市场功能）

技术栈确认：
• 后端：Python FastAPI
• 前端：React 或 Gradio（快速MVP）
• 部署：Railway/Render（最低成本）

发布渠道：
• B站吉他UP主合作（内容即推广）
• Product Hunt中文版
• 吉他社群（贴吧/QQ群/小红书）
```

### 阶段三：商业化（第3-6个月）

```
收入模型：
• 免费：每月3次转谱（引流）
• Pro订阅：¥29/月（无限转谱+导出GP/PDF格式）
• 谱子市场：¥1-5/份下载，平台抽成30%
• 企业API：¥2000/月起（琴行/教育机构）

增长策略：
• "漫游会议室"模式：用AI翻奏内容做B站内容营销
```

### 1.1 TapToTab 论文深度解析（学术里程碑）

**论文信息：**
- 标题：*TapToTab: Video-Based Guitar Tabs Generation using AI and Audio Analysis*
- 发表：arXiv cs.SD / cs.CV / eess.AS（2024年9月13日）
- 作者：Ali Ghaleb et al.

**技术方案：**

```
输入：吉他演奏视频
    ↓
[1] YOLO模型 → 实时检测琴颈区域（fretboard detection）
    ↓
[2] Fourier Transform音频分析 → 精确识别音符
    ↓
[3] 视频+音频融合 → 生成吉他TAB谱
    ↓
输出：吉他六线谱（Tablature）
```

**关键创新点：**
- 首次将 YOLO 用于**琴颈区域检测**（fretboard detection）
- 将音频频谱分析与视频视觉检测结合
- 解决了"纯音频扒谱无法还原指法"的根本问题

**局限性（论文未公开）：**
- 准确率具体数值未披露（需读完整PDF）
- 未公开模型权重/数据集
- 商业化路径不明确

### 1.4 MediaPipe 注意事项（2025-2026 更新）

> ⚠️ **MediaPipe Python API 重大变化（2025年）**
>
> MediaPipe 在 2024-2025 年进行了 API 迁移：
> - ❌ `mp.solutions.hands` 已在部分版本中移除
> - ✅ **新 API：** `mediapipe.tasks.python.vision.hands`
>
> 迁移代码示例：
> ```python
> # 旧版（可能不可用）
> import mediapipe as mp
> mp_hands = mp.solutions.hands
> hands = mp_hands.Hands()
>
> # 新版（2025+ 推荐）
> from mediapipe.tasks.python.vision import HandsLandmarker
> base_options = BaseOptions(model_asset_path='hand_landmarker.task')
> options = HandsLandmarkerOptions(base_options=base_options, num_hands=2)
> landmarker = HandsLandmarker.create_from_options(options)
> ```
>
> **安装注意：** MediaPipe Python版需 Python ≤ 3.12，不支持 Python 3.13

### 2.2 为什么对吉他项目重要

传统方案（你之前的路线）：
```
音频 → Basic Pitch（音符检测）→ LLM（指法推理）→ TAB输出
视频 → MediaPipe Hands（手部检测）→ 分类器（指法分类）→ TAB输出
```

LongCat-Next 的新可能：
```
LongCat-Next（统一多模态）
    ↓
音频 + 视频 → 统一Token → 联合推理 → 指法+TAB（端到端）

优势：
- 音频音符检测 + 视频手部位置 = 联合建模
- 不需要分阶段手工拼接Pipeline
- 可直接输出带手型标注的TAB
```

**LongCat-AudioDiT**（LongCat的音频组件）可能是关键技术：
- 端到端音频理解（音符检测+乐器识别）
- 融入统一多模态框架

## 📎 附录：Veo 3.1 Lite 调用指南

**申请地址**：aistudio.google.com → API Keys

**调用示例（Python）**：
```python
import google.genai as genai

client = genai.Client(api_key="YOUR_API_KEY")

response = client.models.generate_videos(
    model="veo-3.1-lite",
    prompt="Close-up of guitarist's left hand playing an Am chord on acoustic guitar, "
           "natural lighting, realistic finger positions, upper body shot"
)

print(response.generated_videos[0].video.uri)
```

**吉他相关Prompt模板**：
```
正面手部特写：
"Close-up of guitarist fretting hand, playing [和弦名] chord on acoustic guitar, 
natural room lighting, realistic finger movement"

琴颈区域：
"Fretboard shot of electric guitar, fingers pressing strings at 2nd fret, 
detailed view of guitar neck, realistic"

全身演奏：
"Guitarist playing fingerstyle arrangement on acoustic guitar, 
natural pose, upper body visible, studio lighting"
```

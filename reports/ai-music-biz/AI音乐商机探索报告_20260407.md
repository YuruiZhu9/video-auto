## 一、FretCoach 架构深度解析（重点）

### 1.1 产品定位

FretCoach 是目前**工程化程度最高**的开源AI吉他教学项目，代表了"实时演奏检测+AI教练"方向的最新进展。

**官网**：[fretcoach.ai](https://www.fretcoach.ai/) | [GitHub](https://github.com/padmanabhan-r/FretCoach)

### 1.2 三模块架构

```
┌─────────────────────────────────────────────────┐
│              PostgreSQL 中央数据库                │
│         (会话数据/演奏指标/教练对话)              │
└─────────────────────────────────────────────────┘
        ↓                    ↓                    ↓
┌──────────────────┐  ┌──────────────┐  ┌────────────────┐
│  FretCoach Studio │  │ Web Frontend │  │ AI Coach Agent │
│  (Electron桌面端)  │  │  (Web回顾端)  │  │  (LLM教练)     │
│  实时演奏录制+反馈  │  │  趋势分析     │  │  个性化指导     │
└──────────────────┘  └──────────────┘  └────────────────┘
```

**三个模块详解：**

| 模块 | 技术栈 | 核心功能 |
|------|--------|---------|
| **Studio（桌面）** | Electron + Python | 麦克风录制 → 实时分析 → 音高/节奏/时值评分 |
| **Web Frontend** | React + Tailwind | 历史会话回放、趋势图表、进度追踪 |
| **AI Coach Agent** | LLM (GPT-4o/Claude) + Comet Opik | 个性化练习计划、演奏诊断、对话式辅导 |

### 1.3 四大演奏指标体系

FretCoach 在演奏过程中实时追踪四个维度：

| 指标 | 说明 | 检测方式 |
|------|------|---------|
| **音高准确度** (Pitch Accuracy) | 音准是否正确 | 音频→MIDI对比 |
| **节奏稳定性** (Rhythm Stability) | 节拍是否稳定 | 节拍检测 |
| **练习覆盖** (Practice Coverage) | 练习了哪些段落 | 时间轴对齐 |
| **难度适配** (Difficulty Calibration) | 曲目难度是否匹配当前水平 | 错误率统计 |

### 1.4 LLM教练的三种模式（FretCoach AI Coach Engine）

FretCoach 的AI教练基于 LLM 构建，提供三种对话模式：

**模式1：诊断型**
- 用户上传演奏录音
- LLM 分析四个指标的得分
- 输出："你的节奏在第23-45秒不稳定，建议先分手练习"

**模式2：计划型**
- 用户输入："我是初学者，想学Fingerstyle"
- LLM 结合用户水平评估 + 曲目库 → 生成7天练习计划

**模式3：实时干预型**（最前沿）
- 在"关键可塑性窗口"（演奏中）实时分析
- 每一次音符立即评估
- 错误未形成肌肉记忆前就给出反馈

### 1.5 工程启示（对用户最有价值的参考）

**为什么 FretCoach 值得深入研究：**

1. **完整的数据流**：录音 → 分析 → 反馈 → 存储 → 回顾 → 改进
2. **Comet Opik 可观测性**：所有AI交互可追踪，方便迭代优化
3. **PostgreSQL 中央存储**：三个模块共享数据，支持长期趋势分析
4. **开源可复用**：GitHub 有完整代码，可作为教学功能的架构模板

**用户可以借鉴的点：**

```
扒谱工具（输入） → MIDI参考 → FretCoach架构（演奏检测）
                                      ↓
                              AI教练反馈生成
                                      ↓
                              个性化练习计划（输出）
```

→ **扒谱 + 演奏纠错 = 完整的学习闭环**，这是值得整合的方向

## 二、AI吉他硬件：新赛道的机会与参考

### 2.1 TemPolor Melo-D（趣丸科技）

**产品定位**：全球首款生成式AI吉他，Melo-D系列，2026年8月发货

**官网**：[tempolorguitar.cn](https://www.tempolorguitar.cn/) | [tempolorguitar.com](https://tempolorguitar.com/)

**核心功能：**
- 内置高清触摸屏 + AI音乐大模型（自研Tunee）
- **哼唱生成旋律**（Hum a melody）→ 实时LED引导指法
- **上传歌曲** → LED跟随演奏
- 无需手机，独立运行（现场演出可用）
- 专业级音色还原

**三种演奏模式：**

| 模式 | 说明 | 技术 |
|------|------|------|
| **哼唱模式** | 哼一段旋律，AI生成吉他指法 |哼唱识别+生成式AI |
| **跟灯模式** | LED灯在琴颈上显示指法位置 | LED引导+实时渲染 |
| **上传模式** | 上传任意歌曲 → 生成演奏方案 | 音频分析+指法生成 |

**价格**：官网显示预购中，2026年8月发货

**商业意义**：这不是一把吉他，这是一个**AI+硬件的入口**，用户演奏数据可以持续优化AI模型，形成数据壁垒

### 2.2 LiberLive C2（CES 2026）

**产品定位**：无弦智能吉他，搭载 Liber AOS 系统，CES 2026 首次亮相

**官网**：[liberlive.com](https://liberlive.com/pages/ces2026)

**核心特点：**
- 无需换和弦（触控感应替代传统琴弦）
- 任意位置按弦均可发声（消除初学者最大的门槛）
- 内置AI节拍器、自动伴奏、录音功能
- 支持 iOS/Android App 连接

**商业定位**：面向完全零基础用户的"第一款吉他"，定位与 TemPolor 不同（一个面向有基础想提升，一个面向零基础想快速体验）

## 七、本周新洞察

### 洞察1：扒谱+纠错 = 下一个整合机会

**FretCoach 的架构**证明：演奏检测 + LLM教练 → 个性化练习，是一条可行的产品路径。

**与扒谱工具的整合价值：**
```
演奏视频上传
     ↓
  扒谱（输出TAB/MIDI）→ 参照乐谱
     ↓
  FretCoach式实时检测 → 对比参照 → 指出错误
     ↓
  LLM教练生成改进建议
     ↓
  个性化练习计划（从扒谱曲库中提取练习片段）
```

**为什么这对用户有价值**：用户最终目的不是"拿到谱子"，而是"学会弹这首歌"。整合扒谱+纠错，才能形成真正的用户价值闭环。

### 洞察2：硬件+软件的数据飞轮

**TemPolor 的商业模式启示**：

吉他硬件（TemPolor/LiberLive）→ 采集演奏数据 → 优化AI模型 → 更好的演奏检测 → 更精准的扒谱/纠错

**用户独特的优势**：你会弹吉他+架子鼓，可以自己录制训练数据，不需要依赖硬件厂商的数据。这正是"技能+技术"结合的核心价值。

### 洞察3：卡拉OK评分 → 演奏评分

Wondera 的卡拉OK评分功能，实际上是"演奏错误检测"的简化版民用化。

**迁移思路**：将卡拉OK的"唱对/唱错"评分，迁移到"弹对/弹错"评分，技术路径类似：
- 音频输入 → 哼唱/演奏
- 与参考MIDI对比 → 逐音评分
- 高亮错误段落 → 反馈改进

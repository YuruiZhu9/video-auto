## 依赖注入示例

```python
# main.py
from fastapi import FastAPI
from repositories.user_repo import UserRepository
from services.recommendation import RecommendationService

app = FastAPI()

# 依赖注入容器
def get_recommendation_service():
    user_repo = UserRepository()
    return RecommendationService(user_repo)

@app.get("/recommend/{user_id}")
def recommend(user_id: int, service: RecommendationService = Depends(get_recommendation_service)):
    items = service.get_personalized_recommendations(user_id)
    return {"items": items}
```

## 架构要点

| 层级 | 职责 | 技术选型 |
|------|------|----------|
| API层 | 请求路由、参数校验 | FastAPI |
| Service层 | 业务逻辑、推荐算法 | Python |
| Repository层 | 数据访问 | SQLAlchemy |
| Data层 | 数据存储 | MySQL/Redis |

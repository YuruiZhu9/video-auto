# 代码架构学习路径 — 基础模式

## 概述

代码架构模式是前辈们总结出的"解题套路"，帮你把一团乱麻的代码整理成可维护、可扩展的结构。
本阶段聚焦三个最核心的模式：**MVC**、**MVVM**、**三层架构**。

---

## 1. MVC 模式

### 是什么

**MVC = Model（模型） + View（视图） + Controller（控制器）**

- **Model**：数据 + 业务逻辑（和数据库打交道）
- **View**：展示层，用户看到的页面/界面
- **Controller**：调度者，接收请求、调用逻辑、返回数据

### 通俗理解

把代码分成"仓库管理员"（Model）、"前台接待"（View）、"项目经理"（Controller）三类角色，各干各的，互不干扰。

### 经典应用场景

- Web 应用（Flask、Django 经典结构）
- REST API 后端服务
- 中小型前后端不分离项目

### Python (Flask) 示例

```python
# ── Model ──────────────────────────────────────────────
from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()

class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    email = db.Column(db.String(120), nullable=False)

    def to_dict(self):
        return {"id": self.id, "username": self.username, "email": self.email}


# ── Controller ─────────────────────────────────────────
from flask import Blueprint, request, jsonify

user_bp = Blueprint("users", __name__)

@user_bp.route("/users", methods=["GET"])
def list_users():
    """查询所有用户"""
    users = User.query.all()
    return jsonify([u.to_dict() for u in users])

@user_bp.route("/users", methods=["POST"])
def create_user():
    """创建用户"""
    data = request.get_json()
    user = User(username=data["username"], email=data["email"])
    db.session.add(user)
    db.session.commit()
    return jsonify(user.to_dict()), 201


# ── View ────────────────────────────────────────────────
# 在 Flask 中，View 通常是返回 JSON 的 API 端点，或 Jinja2 模板
# 这里示例返回 JSON（API 风格），模板引擎处理则是模板文件
```

### TypeScript (Express) 示例

```typescript
// ── Model ──────────────────────────────────────────────
interface User {
  id: number;
  username: string;
  email: string;
}

// 模拟数据库
const users: User[] = [
  { id: 1, username: "alice", email: "alice@example.com" }
];


// ── Controller (路由层) ─────────────────────────────────
import { Request, Response, Router } from "express";
const router = Router();

// GET /users
router.get("/users", (req: Request, res: Response) => {
  res.json(users);
});

// POST /users
router.post("/users", (req: Request, res: Response) => {
  const { username, email } = req.body;
  const newUser: User = { id: Date.now(), username, email };
  users.push(newUser);
  res.status(201).json(newUser);
});

export default router;
```

### MVC 的优缺点

| 优点 | 缺点 |
|------|------|
| 职责清晰，易于分工协作 | Controller 容易变胖（变成"万能控制器"） |
| 适合团队开发 | View 和 Model 仍可能耦合 |
| 便于单元测试 | 大型项目需要额外架构约束 |

## 2. MVVM 模式

### 是什么

**MVVM = Model + View + ViewModel**

核心变化：引入 **ViewModel**，实现**数据绑定**（View 的变化自动反映到 Model，反之亦然）。

### MVC vs MVVM 对比

| 维度 | MVC | MVVM |
|------|-----|------|
| 数据更新 | 手动控制 | 双向绑定自动同步 |
| 适用场景 | 后端/API | 前端/桌面应用 |
| 绑定机制 | 无 | 响应式数据绑定 |
| 复杂度 | 较低 | 较高 |

### 适用场景

- **前端框架**：Vue.js、Angular、React（配合 Hooks）
- **桌面应用**：WPF、Qt
- **需要实时数据同步**的场景

### Vue.js 示例（MVVM 典型）

```html
<!-- View 层：模板 -->
<template>
  <div>
    <input v-model="username" placeholder="用户名" />
    <button @click="fetchUser">查询</button>
    <p v-if="user">ID: {{ user.id }}, 邮箱: {{ user.email }}</p>
  </div>
</template>

<script setup lang="ts">
// ViewModel 层
import { ref } from "vue";

const username = ref("");
const user = ref<User | null>(null);

interface User { id: number; email: string; }

// Model 层（实际项目中通常是 API 调用）
async function fetchUser() {
  const res = await fetch(`/api/users/${username.value}`);
  user.value = await res.json();
}
</script>
```

### MVVM 的优缺点

| 优点 | 缺点 |
|------|------|
| 数据绑定减少样板代码 | 学习曲线较陡 |
| 前端开发效率高 | 响应式可能带来性能问题 |
| View 和 Model 完全解耦 | 复杂双向绑定调试困难 |

## 3. 三层架构

### 是什么

将系统分成三个层次：
- **表现层（UI Layer）**：接收请求、返回响应
- **业务层（Service Layer）**：处理业务逻辑
- **数据层（Repository/DAL）**：数据存取

### 通俗理解

想象餐厅：
- **服务员** = 表现层（接待顾客、端菜）
- **厨师** = 业务层（炒菜、调味）
- **仓库管理员** = 数据层（取食材、存食材）

### 三层 vs MVC 对比

| 维度 | 三层架构 | MVC |
|------|----------|-----|
| 关注点 | 纵向分层 | 横向分离 |
| 粒度 | 粗粒度 | 中粒度 |
| 主要应用 | 企业级后端 | Web 应用 |
| 通信方向 | 上层调用下层 | Controller 调用 Model |

### Python (FastAPI) 三层架构示例

```python
# ── 数据层 (Repository) ─────────────────────────────────
from sqlalchemy.orm import Session
from models import User

class UserRepository:
    def __init__(self, db: Session):
        self.db = db

    def find_by_id(self, user_id: int) -> User | None:
        return self.db.query(User).filter(User.id == user_id).first()

    def find_all(self) -> list[User]:
        return self.db.query(User).all()

    def create(self, username: str, email: str) -> User:
        user = User(username=username, email=email)
        self.db.add(user)
        self.db.commit()
        self.db.refresh(user)
        return user


# ── 业务层 (Service) ────────────────────────────────────
from schemas import UserCreate, UserResponse

class UserService:
    def __init__(self, db: Session):
        self.repo = UserRepository(db)

    def get_user(self, user_id: int) -> UserResponse:
        user = self.repo.find_by_id(user_id)
        if not user:
            raise ValueError(f"用户 {user_id} 不存在")
        return UserResponse.model_validate(user)

    def list_users(self) -> list[UserResponse]:
        return [UserResponse.model_validate(u) for u in self.repo.find_all()]

    def create_user(self, data: UserCreate) -> UserResponse:
        # 业务逻辑：检查用户名唯一性
        existing = self.repo.find_by_username(data.username)
        if existing:
            raise ValueError("用户名已存在")
        user = self.repo.create(data.username, data.email)
        return UserResponse.model_validate(user)


# ── 表现层 (API 路由) ────────────────────────────────────
from fastapi import APIRouter, Depends, HTTPException
from database import get_db

router = APIRouter()

def get_user_service(db: Session = Depends(get_db)) -> UserService:
    return UserService(db)

@router.get("/users/{user_id}", response_model=UserResponse)
def get_user(user_id: int, svc: UserService = Depends(get_user_service)):
    try:
        return svc.get_user(user_id)
    except ValueError as e:
        raise HTTPException(status_code=404, detail=str(e))

@router.get("/users", response_model=list[UserResponse])
def list_users(svc: UserService = Depends(get_user_service)):
    return svc.list_users()

@router.post("/users", response_model=UserResponse, status_code=201)
def create_user(data: UserCreate, svc: UserService = Depends(get_user_service)):
    try:
        return svc.create_user(data)
    except ValueError as e:
        raise HTTPException(status_code=400, detail=str(e))
```

## 学习建议

1. **从小项目开始**：先把一个 Flask/Express 小项目按 MVC 拆一遍
2. **画图辅助**：用流程图把数据流向画出来
3. **不要过度设计**：小型项目不必强求三层架构，MVC 足够
4. **对比学习**：尝试把同一个功能分别用 MVC、MVVM、三层架构实现，感受差异

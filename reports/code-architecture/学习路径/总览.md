# 代码架构思维提升 - 学习路径总览

> 目标：从"能跑的代码"升级到"有架构的代码"

---

## 🚀 三阶段学习路径

### 第一阶段：基础架构模式（2-3周）
掌握三大经典模式，理解"分离关注点"的核心思想。

| 模式 | 核心理念 | 适用场景 |
|------|----------|----------|
| **MVC** | Model-View-Controller 分离 | Web后端、全栈应用 |
| **MVVM** | 数据绑定驱动视图 | 前端框架、移动端 |
| **三层架构** | 表现层/业务层/数据层 | 企业级应用、微服务 |

### 第二阶段：设计原则（2-3周）
SOLID + DRY + KISS，让代码更健壮、更易维护。

- **S**ingle Responsibility（单一职责）
- **O**pen/Closed（开闭原则）
- **L**iskov Substitution（里氏替换）
- **I**nterface Segregation（接口隔离）
- **D**ependency Inversion（依赖倒置）

### 第三阶段：重构实战（持续）
从坏味道识别到渐进式重构，建立架构直觉。

### 第四阶段：模型服务化（进阶）
推荐系统上线最后一公里——如何把训练好的模型高效稳定地部署为在线推理服务。

| 主题 | 核心理念 | 适用场景 |
|------|----------|----------|
| **Triton Inference Server** | GPU批量推理 + 模型版本管理 | 推荐系统精排/粗排 |
| **Ray Serve 在线学习** | 增量更新 + 实时反馈 | 实时反馈驱动的推荐 |
| **三级降级策略** | 模型 → 缓存 → 规则兜底 | 线上稳定性保障 |
| **A/B 灰度路由** | 用户哈希分流 + 版本切换 | 新模型上线验证 |
| **自适应架构** | 混沌工程/弹性伸缩/灰度发布/自适应限流 | 进阶级韧性设计 |

### 第五阶段：自适应与韧性（进阶级）
当系统无法依赖人工干预时，如何让它自动适应变化。

| 主题 | 核心理念 | 适用场景 |
|------|----------|----------|
| **混沌工程** | 主动注入故障，验证降级链路 | 生产环境韧性验证 |
| **弹性伸缩** | K8s HPA + 预测式扩容 | 流量潮汐应对 |
| **灰度发布** | 金丝雀 + A/B 实验自动决策 | 新模型/策略上线 |
| **自适应限流** | 动态阈值 + 分级降级 | 突发流量保护 |

## 🎯 学习建议

1. **动手优先**：每个模式都手写一遍
2. **对比学习**：先写坏代码，再对比改进
3. **项目实战**：用所学重构一个已有项目
4. **代码审查**：主动参与他人代码 review

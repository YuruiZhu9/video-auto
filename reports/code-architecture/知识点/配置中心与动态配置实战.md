# 配置中心与动态配置实战

> 推荐系统上线最后一公里：如何让模型切换、召回策略调整、功能开关在不重启服务的情况下实时生效。

---

## 1. 什么是配置中心？为什么推荐系统必须用？

### 1.1 硬编码配置的灾难

```python
# ❌ 反例：硬编码配置
class RecallEngine:
    def __init__(self):
        self.top_k = 100          # 写死
        self.embedding_dim = 256  # 写死
        self.enable_new_user_strategy = False  # 写死

    def recall(self, user_id):
        if self.enable_new_user_strategy:  # 改这个要重新部署
            ...
```

**问题**：
- 改一个参数要重新部署 → 推荐系统是不可接受的
- 无法做灰度 → 新策略直接全量上线，风险极高
- 无法做实验 → 无法对比不同策略的效果
- 配置分散在代码里 → 审计困难

### 1.2 配置中心核心理念

```
配置中心 = 中心化配置存储 + 实时推送 + 版本管理 + 灰度发布 + 权限控制
```

**核心价值**：
- **热更新**：改配置不用重启服务
- **灰度发布**：新策略先给 5% 用户看
- **实验驱动**：同时运行多组配置，对比效果
- **故障止血**：出问题立即关闭开关

### 1.3 推荐系统配置分类

| 配置类型 | 示例 | 更新频率 | 影响范围 |
|---------|------|---------|---------|
| **模型配置** | 模型版本、推理参数 | 低（换模型时） | 全流量 |
| **召回配置** | 召回路数、top_k、各路权重 | 中 | 全/部分流量 |
| **业务开关** | 功能上线/下线、实验开关 | 高 | 按灰度规则 |
| **阈值配置** | 曝光去重窗口、热门打压系数 | 中 | 部分流量 |
| **限流配置** | QPS上限、并发限制 | 高（紧急限流） | 全流量 |

```python
# config/settings.py
import json
import os
from pathlib import Path
from typing import Any
from functools import lru_cache

CONFIG_DIR = Path(__file__).parent / "configs"

@lru_cache()
def get_config(key: str, default: Any = None) -> Any:
    """从本地配置文件读取配置（带缓存）"""
    config_file = os.getenv("ENV", "dev") + ".json"
    config_path = CONFIG_DIR / config_file

    with open(config_path) as f:
        all_config = json.load(f)

    # 支持点号分隔的嵌套读取，如 "recall.embedding_dim"
    keys = key.split(".")
    value = all_config
    for k in keys:
        value = value.get(k, default)
    return value
```

### 2.2 第二层：Redis 动态配置（团队协作方案）

```python
# config/dynamic_config.py
import json
import redis
import os
from typing import Any, Optional, Callable
from threading import Thread
import time
import hashlib

class DynamicConfig:
    """基于 Redis 的动态配置中心（简化版）"""

    def __init__(self, redis_url: str = "redis://localhost:6379/1"):
        self.redis = redis.from_url(redis_url)
        self._cache: dict[str, tuple[Any, float]] = {}
        self._cache_ttl = 5  # 秒
        self._listeners: list[Callable[[str, Any], None]] = []
        self._pubsub = self.redis.pubsub()

    # ========== 基础操作 ==========

    def set(self, key: str, value: Any, env: str = "prod") -> None:
        """设置配置（发布变更通知）"""
        full_key = f"config:{env}:{key}"
        serialized = json.dumps(value)
        self.redis.set(full_key, serialized)
        self.redis.publish(f"config:{env}:change:{key}", serialized)
        # 清除本地缓存
        self._cache.pop(key, None)

    def get(self, key: str, default: Any = None, env: str = "prod") -> Any:
        """读取配置（带本地缓存）"""
        # 检查本地缓存
        if key in self._cache:
            value, timestamp = self._cache[key]
            if time.time() - timestamp < self._cache_ttl:
                return value

        # 从 Redis 读取
        full_key = f"config:{env}:{key}"
        raw = self.redis.get(full_key)
        if raw is None:
            return default

        value = json.loads(raw)
        self._cache[key] = (value, time.time())
        return value

    def delete(self, key: str, env: str = "prod") -> None:
        """删除配置"""
        full_key = f"config:{env}:{key}"
        self.redis.delete(full_key)
        self.redis.publish(f"config:{env}:change:{key}", None)
        self._cache.pop(key, None)

    # ========== 灰度发布 ==========

    def set_with_percentage(
        self, key: str, value: Any, percentage: int, env: str = "prod"
    ) -> None:
        """设置灰度配置：percentage% 的用户使用新值"""
        self.set(f"{key}:default", value, env)
        self.set(f"{key}:percentage", percentage, env)

    def get_for_user(self, key: str, user_id: str, env: str = "prod") -> Any:
        """根据用户ID获取配置（支持灰度）"""
        full_key = f"config:{env}:{key}"
        default_key = f"{full_key}:default"
        percentage_key = f"{full_key}:percentage"

        percentage = int(self.redis.get(percentage_key) or 0)

        if percentage == 0:
            return json.loads(self.redis.get(default_key) or "null")

        # 用一致性哈希决定用户分组
        hash_val = int(hashlib.md5(f"{key}:{user_id}".encode()).hexdigest(), 16)
        in_experiment = (hash_val % 100) < percentage

        if in_experiment:
            exp_key = f"{full_key}:experiment"
            exp_value = self.redis.get(exp_key)
            if exp_value:
                return json.loads(exp_value)

        return json.loads(self.redis.get(default_key) or "null")

    # ========== 监听变更 ==========

    def watch(self, key: str, callback: Callable[[str, Any], None]) -> None:
        """监听配置变更（热更新）"""
        def _listener(msg):
            if msg["type"] == "message":
                value = json.loads(msg["data"]) if msg["data"] else None
                callback(key, value)

        channel = f"config:{os.getenv('ENV', 'prod')}:change:{key}"
        self._pubsub.subscribe(channel)
        self._pubsub.on_message(_listener)

    def start_listener(self) -> Thread:
        """启动后台监听线程"""
        thread = Thread(target=self._pubsub.listen, daemon=True)
        thread.start()
        return thread
```

## 3. 功能开关（Feature Flag）实战

### 3.1 为什么推荐系统必须有关键开关？

| 场景 | 没有开关 | 有开关 |
|------|---------|--------|
| 新召回策略上线出问题 | 全量用户受影响 | 立即关闭，问题用户 <5% |
| 模型推理超时 | 整条链路崩溃 | 降级到缓存/规则 |
| 某个地区流量异常 | 紧急回滚（30分钟+） | 点一下关闭（1秒） |
| A/B 测试 | 无法做 | 同时运行两组策略 |

### 3.2 功能开关类型

```
功能开关
├── 发布开关（Release Flag）
│   └── 新功能灰度上线，先给 5%，没问题再全量
├── 实验开关（Experiment Flag）
│   └── A/B 测试，不同用户看到不同策略
├── 运营开关（Ops Flag）
│   └── 紧急止血，限流/关闭某功能
└── 权限开关（Permission Flag）
    └── 某类用户专属功能（VIP/内测用户）
```

### 3.3 推荐系统功能开关完整实现

```python
# feature_flags/manager.py
import hashlib
import json
import time
from dataclasses import dataclass, field
from typing import Any, Optional, Callable
from enum import Enum

class FlagType(Enum):
    BOOLEAN = "boolean"
    PERCENTAGE = "percentage"
    USER_LIST = "user_list"
    RULE = "rule"

@dataclass
class FeatureFlag:
    key: str
    flag_type: FlagType
    default_value: Any
    enabled: bool = True
    percentage: int = 100          # 灰度百分比
    user_list: list[str] = field(default_factory=list)  # 白名单
    rule: Optional[dict] = None  # 规则引擎
    description: str = ""

class FeatureFlagManager:
    """推荐系统功能开关管理器"""

    def __init__(self, config_client=None):
        self._flags: dict[str, FeatureFlag] = {}
        self._cache: dict[str, tuple[Any, float]] = {}
        self._cache_ttl = 10  # 秒
        self._config_client = config_client  # Apollo/Redis/Nacos

    # ========== 注册开关 ==========

    def register(
        self,
        key: str,
        flag_type: FlagType = FlagType.BOOLEAN,
        default: Any = False,
        description: str = ""
    ) -> None:
        self._flags[key] = FeatureFlag(
            key=key,
            flag_type=flag_type,
            default_value=default,
            description=description
        )

    def load_from_config(self, config: dict) -> None:
        """从配置中心批量加载开关"""
        for key, cfg in config.items():
            if isinstance(cfg, dict):
                self._flags[key] = FeatureFlag(
                    key=key,
                    flag_type=FlagType(cfg.get("type", "boolean")),
                    default_value=cfg.get("default", False),
                    enabled=cfg.get("enabled", True),
                    percentage=cfg.get("percentage", 100),
                    user_list=cfg.get("user_list", []),
                    rule=cfg.get("rule"),
                    description=cfg.get("description", "")
                )

    # ========== 核心判断逻辑 ==========

    def is_enabled(
        self,
        key: str,
        user_id: Optional[str] = None,
        context: Optional[dict] = None
    ) -> bool:
        """判断功能开关是否启用"""
        flag = self._flags.get(key)
        if not flag or not flag.enabled:
            return flag.default_value if flag else False

        # 优先级：白名单 > 规则 > 百分比

        # 1. 白名单用户直接通过
        if user_id and user_id in flag.user_list:
            return True

        # 2. 规则引擎判断
        if flag.rule:
            return self._evaluate_rule(flag.rule, user_id, context or {})

        # 3. 百分比分流
        if flag.flag_type == FlagType.PERCENTAGE:
            return self._evaluate_percentage(key, user_id, flag.percentage)

        return flag.default_value

    def _evaluate_percentage(self, key: str, user_id: str, percentage: int) -> bool:
        """一致性哈希百分比分流"""
        if not user_id:
            return False
        if percentage >= 100:
            return True
        if percentage <= 0:
            return False
        hash_val = int(hashlib.md5(f"{key}:{user_id}".encode()).hexdigest(), 16)
        return (hash_val % 100) < percentage

    def _evaluate_rule(self, rule: dict, user_id: str, context: dict) -> bool:
        """简单规则引擎"""
        op = rule.get("op")
        field_name = rule.get("field")
        threshold = rule.get("threshold")

        # 从 context 获取字段值
        field_value = context.get(field_name, 0)

        ops = {
            "gt": lambda a, b: a > b,
            "gte": lambda a, b: a >= b,
            "lt": lambda a, b: a < b,
            "lte": lambda a, b: a <= b,
            "eq": lambda a, b: a == b,
            "in": lambda a, b: a in b,
        }
        return ops.get(op, lambda a, b: False)(field_value, threshold)

    def get_value(
        self,
        key: str,
        user_id: Optional[str] = None,
        context: Optional[dict] = None,
        default: Any = None
    ) -> Any:
        """获取开关值（支持非布尔类型）"""
        flag = self._flags.get(key)
        if not flag:
            return default

        if flag.flag_type == FlagType.BOOLEAN:
            return self.is_enabled(key, user_id, context)

        # 百分比实验：返回不同变体值
        if flag.flag_type == FlagType.PERCENTAGE:
            variants = flag.rule.get("variants", {}) if flag.rule else {}
            hash_val = int(hashlib.md5(f"{key}:{user_id}".encode()).hexdigest(), 16)
            variant_names = list(variants.keys())
            variant = variant_names[hash_val % len(variant_names)]
            return variants[variant]

        return flag.default_value

    # ========== 开关状态管理 ==========

    def enable(self, key: str) -> None:
        if key in self._flags:
            self._flags[key].enabled = True

    def disable(self, key: str) -> None:
        """紧急关闭开关（止血用）"""
        if key in self._flags:
            self._flags[key].enabled = False

    def set_percentage(self, key: str, percentage: int) -> None:
        """调整灰度比例"""
        if key in self._flags:
            self._flags[key].percentage = percentage

    def add_user_to_whitelist(self, key: str, user_id: str) -> None:
        """添加白名单用户"""
        if key in self._flags:
            if user_id not in self._flags[key].user_list:
                self._flags[key].user_list.append(user_id)

    def list_all_flags(self) -> list[dict]:
        """列出所有开关状态"""
        return [
            {
                "key": f.key,
                "type": f.flag_type.value,
                "enabled": f.enabled,
                "percentage": f.percentage,
                "user_count": len(f.user_list),
                "description": f.description
            }
            for f in self._flags.values()
        ]
```

### 3.5 推荐引擎集成功能开关

```python
# recommend/engine.py
import asyncio
from feature_flags.manager import FeatureFlagManager, FlagType

class RecommendEngine:
    def __init__(self, flags: FeatureFlagManager):
        self.flags = flags

    async def recommend(self, user_id: str, context: dict) -> list[dict]:
        user_context = {
            "click_count": context.get("click_count", 0),
            "region": context.get("region", "unknown"),
            "is_vip": context.get("is_vip", False),
            "days_since_signup": context.get("days_since_signup", 0)
        }

        # ========== 召回阶段 ==========
        candidates = []

        # Embedding 召回
        if self.flags.is_enabled("recall.embedding.enabled", user_id, user_context):
            top_k = self.flags.get_value(
                "recall.embedding.top_k", user_id, default=100
            )
            candidates.extend(await self.embedding_recall(user_id, top_k))

        # ItemCF 召回
        if self.flags.is_enabled("recall.item_cf.enabled", user_id, user_context):
            candidates.extend(await self.item_cf_recall(user_id, top_k=50))

        # 热门召回
        if self.flags.is_enabled("recall.hot_content.enabled", user_id):
            candidates.extend(await self.hot_content_recall(top_k=30))

        # 新用户专属召回
        if user_context["days_since_signup"] < 7:
            if self.flags.is_enabled("recall.new_user.enabled", user_id, user_context):
                candidates.extend(await self.new_user_recall(user_id))

        # ========== 排序阶段 ==========
        # 选择排序策略（A/B 实验）
        ranking_version = self.flags.get_value(
            "experiment.new_ranking_model",
            user_id=user_id,
            context=user_context,
            default="rank_v1"
        )

        if ranking_version == "rank_v2":
            ranked = await self.ranking_v2(candidates, user_id)
        else:
            ranked = await self.ranking_v1(candidates, user_id)

        # ========== 重排阶段 ==========
        final = ranked
        if self.flags.is_enabled("rerank.diversity_mmr", user_id):
            final = await self.diversity_rerank(ranked, user_id)

        if self.flags.is_enabled("rerank.exposure_limit", user_id):
            final = await self.exposure_limit_filter(final, user_id)

        return final[:20]
```

## 4. 实验平台：A/B 测试框架设计

### 4.1 分层实验模型（Traffic Allocation）

**问题**：如果所有实验都共享流量，会产生流量不够用的问题。

**分层实验**：
```
流量（100%）
├── Layer 0: 召回策略实验（40%）
│   ├── Exp A: Embedding V2 召回
│   ├── Exp B: ItemCF 召回
│   └── Control: 混合召回
├── Layer 1: 排序策略实验（30%）
│   ├── Exp C: 多目标排序
│   └── Control: 点击率排序
└── Layer 2: 重排策略实验（30%）
    ├── Exp D: MMR 多样性
    └── Control: 无重排
```

**关键约束**：同层实验互斥，不同层实验正交

### 4.2 分层实验实现

```python
# experiment/allocator.py
import hashlib
from dataclasses import dataclass
from typing import Optional

@dataclass
class ExperimentAssignment:
    experiment_id: str
    variant: str        # "control" / "treatment"
    layer: str          # "recall" / "ranking" / "rerank"

class ExperimentAllocator:
    """分层实验分配器"""

    def __init__(self, experiment_config: dict):
        # 实验配置：layer_id -> [experiment_id -> {variants, traffic}]
        self.layers = experiment_config

    def assign(
        self,
        user_id: str,
        layers: Optional[list[str]] = None
    ) -> dict[str, ExperimentAssignment]:
        """给用户分配实验分组"""
        assignments = {}

        for layer_id, experiments in self.layers.items():
            if layers and layer_id not in layers:
                continue

            for exp_id, exp_config in experiments.items():
                if not exp_config.get("enabled", True):
                    continue

                variant = self._assign_variant(
                    user_id=user_id,
                    exp_id=exp_id,
                    layer_id=layer_id,
                    variants=exp_config["variants"]
                )
                if variant:
                    assignments[exp_id] = ExperimentAssignment(
                        experiment_id=exp_id,
                        variant=variant,
                        layer=layer_id
                    )

        return assignments

    def _assign_variant(
        self, user_id: str, exp_id: str, layer_id: str, variants: dict
    ) -> Optional[str]:
        """一致性哈希分配变体"""
        hash_input = f"{layer_id}:{exp_id}:{user_id}"
        hash_val = int(hashlib.md5(hash_input.encode()).hexdigest(), 16)
        bucket = hash_val % 100

        cumulative = 0
        for variant_name, config in variants.items():
            cumulative += config.get("traffic", 0)
            if bucket < cumulative:
                return variant_name

        return None  # 未命中任何变体
```

### 4.3 实验指标采集

```python
# experiment/metrics.py
from dataclasses import dataclass
import json
import redis
import time

@dataclass
class ExperimentMetrics:
    exp_id: str
    variant: str
    user_id: str
    timestamp: float
    metrics: dict

class ExperimentMetricsCollector:
    """实验指标采集器"""

    def __init__(self, redis_url: str = "redis://localhost:6379/2"):
        self.redis = redis.from_url(redis_url)

    def log_exposure(
        self,
        exp_id: str,
        variant: str,
        user_id: str,
        rec_list: list
    ) -> None:
        """记录一次推荐曝光（实验样本）"""
        key = f"exp:exposure:{exp_id}:{variant}"
        event = json.dumps({
            "exp_id": exp_id,
            "variant": variant,
            "user_id": user_id,
            "timestamp": time.time(),
            "rec_count": len(rec_list)
        })
        self.redis.lpush(key, event)
        self.redis.ltrim(key, 0, 9999)  # 只保留最近1万条

    def log_action(
        self,
        exp_id: str,
        variant: str,
        user_id: str,
        action: str,  # click / view / purchase
        item_id: str
    ) -> None:
        """记录用户行为（实验转化）"""
        key = f"exp:action:{exp_id}:{variant}:{action}"
        event = json.dumps({
            "exp_id": exp_id,
            "variant": variant,
            "user_id": user_id,
            "action": action,
            "item_id": item_id,
            "timestamp": time.time()
        })
        self.redis.lpush(key, event)
        self.redis.ltrim(key, 0, 9999)

    def compute_stats(self, exp_id: str) -> dict:
        """计算实验统计指标"""
        cutoff = time.time() - 86400  # 最近24小时

        exposures = self._get_events(f"exp:exposure:{exp_id}", cutoff)
        clicks = self._get_events(f"exp:action:{exp_id}:click", cutoff)

        variants = set()
        for e in exposures:
            variants.add(e["variant"])

        stats = {}
        for variant in variants:
            exp_list = [e for e in exposures if e["variant"] == variant]
            click_list = [e for e in clicks if e["variant"] == variant]

            stats[variant] = {
                "exposure_count": len(exp_list),
                "click_count": len(click_list),
                "ctr": len(click_list) / len(exp_list) if exp_list else 0
            }

        return stats

    def _get_events(self, key: str, cutoff: float) -> list[dict]:
        events = self.redis.lrange(key, 0, -1)
        result = []
        for e in events:
            event = json.loads(e)
            if event["timestamp"] >= cutoff:
                result.append(event)
        return result
```

## 5. 配置版本管理与审计

### 5.1 为什么要版本管理？

```
推荐系统事故时间线：
T+0:00  工程师修改 top_k = 200 → 100，P99 从 50ms → 300ms
T+0:05  监控报警，但找不到是谁改的配置
T+0:15  回滚到旧版本，但不知道旧版本具体值
T+0:30  恢复服务，损失 30 分钟
```

**Apollo 内置版本历史**：每次修改自动记录版本号，支持一键回滚。

### 5.2 配置回滚实现

```python
# config/rollback.py
import json
import time
import redis
from typing import Any, Optional

class ConfigVersionManager:
    """轻量级配置版本管理（基于 Redis）"""

    def __init__(self, redis_url: str = "redis://localhost:6379/3"):
        self.redis = redis.from_url(redis_url)
        self._prefix = "config:version"

    def save_version(
        self, key: str, value: Any, operator: str, env: str = "prod"
    ) -> str:
        """保存配置版本快照"""
        version_id = f"v{int(time.time() * 1000)}"
        snapshot = json.dumps({
            "version_id": version_id,
            "key": key,
            "value": value,
            "operator": operator,
            "timestamp": time.time()
        })
        self.redis.hset(f"{self._prefix}:{env}:{key}", version_id, snapshot)
        return version_id

    def list_versions(self, key: str, env: str = "prod") -> list[dict]:
        """列出所有版本历史"""
        versions = self.redis.hgetall(f"{self._prefix}:{env}:{key}")
        result = []
        for vid, snapshot in versions.items():
            data = json.loads(snapshot)
            result.append({
                "version_id": data["version_id"],
                "operator": data["operator"],
                "timestamp": data["timestamp"],
                "preview": str(data["value"])[:50]
            })
        return sorted(result, key=lambda x: x["timestamp"], reverse=True)

    def rollback(self, key: str, version_id: str, env: str = "prod") -> Any:
        """回滚到指定版本"""
        snapshot = self.redis.hget(f"{self._prefix}:{env}:{key}", version_id)
        if not snapshot:
            raise ValueError(f"版本 {version_id} 不存在")

        data = json.loads(snapshot)
        return data["value"]
```

### 6.3 常见误区

| 误区 | 后果 | 正确做法 |
|------|------|---------|
| 把配置当代码改 | 配置被覆盖 | 配置归配置，代码归代码 |
| 所有配置放一个地方 | 难以分类管理 | 按业务域分离 Namespace |
| 不做配置变更通知 | 不知道谁改了 | Apollo/Redis Pub/Sub 实时推送 |
| 配置没有版本 | 无法回滚 | 每次修改记录版本快照 |
| 灰度比例随意调 | 效果数据不稳定 | 灰度稳定 24-48h 再分析 |
| 开关注册在代码里 | 新增开关要发版 | 开关应从配置中心动态加载 |

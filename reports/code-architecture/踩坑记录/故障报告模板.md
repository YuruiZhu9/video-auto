# 推荐系统故障报告模板

> 用于每次故障后的复盘记录
> 要求：故障发生后 24 小时内填写
> 存放路径：`/workspace/reports/code-architecture/踩坑记录/故障报告/`

---

## 基础信息

| 字段 | 内容 |
|------|------|
| **故障编号** | INC-YYYYMMDD-NNN |
| **故障名称** | 简述故障（如：Milvus 查询超时导致召回降级） |
| **发现时间** | YYYY-MM-DD HH:MM |
| **恢复时间** | YYYY-MM-DD HH:MM |
| **总耗时** | X 小时 X 分钟 |
| **严重程度** | P0 / P1 / P2 / P3 |
| **影响范围** | X% 用户受影响 / 哪个功能受损 |
| **报告人** | 值班工程师 |
| **审查人** | 团队负责人 |

---

## 故障现象

> 用一句话描述：发生了什么？

> 详细描述：
1. 用户侧表现（APP 上推荐结果变少/变慢/出现异常内容？）
2. 系统侧表现（哪个指标先告警？延迟/成功率/召回率？）
3. 影响规模（影响了多少用户？损失了多少 GMV/CTR？）

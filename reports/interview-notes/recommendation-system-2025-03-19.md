## 三、逐题详细解析

### 3.1 推荐系统基础

#### Q1: 推荐系统的流程是什么？召回、粗排、精排、重排的区别？

**参考答案：**

工业推荐系统一般包含四个环节：**召回 → 粗排 → 精排 → 重排**

| 阶段 | 目的 | 模型复杂度 | 候选集大小 | 特点 |
|------|------|------------|------------|------|
| **召回** | 从海量候选集召回用户可能感兴趣的物品 | 简单（双塔、CF、Embedding等） | 万级~百万级 | 速度快、相关性优先、保证召回多样性 |
| **粗排** | 对召回结果进行初步排序 | 中等（轻量级DNN、双塔） | 千级 | 承上启下、兼顾效果与效率 |
| **精排** | 精准排序，预测CTR/CVR | 复杂（DeepFM、DIN、DIEN等） | 百级 | 特征最丰富、模型最精准 |
| **重排** | 多样性、频次控制、商业化 | 规则+轻量模型 | 十级~百级 | 考虑用户体验、平台收益 |

**面试话术：** 推荐系统是一个多阶段漏斗，从全量的 millions 级候选逐步筛选到最终展示的几十条。召回负责"海选"，快速从全量候选中拉回千~万级别的候选；粗排是召回的"粗筛"，进一步缩减到千级别；精排是"精挑细选"，用复杂模型精准预测用户兴趣；重排则负责"最终展示策略"，保证多样性、频次控制以及商业化需求。

---

#### Q2: 召回和排序比较大的差异点是什么？

**参考答案：**

| 维度 | 召回 | 排序 |
|------|------|------|
| **目标** | 从全量候选中快速找到用户可能感兴趣的候选 | 对召回的候选进行精准排序 |
| **模型复杂度** | 简单、轻量级 | 复杂、精细 |
| **特征** | 用户行为序列、基础属性 | 丰富特征（用户、物品、交叉特征） |
| **速度要求** | 极高（毫秒级） | 较高（可接受更长推理时间） |
| **候选集规模** | millions级 | 千~万级 |
| **典型模型** | 双塔、协同过滤、Embedding | DeepFM、DIN、DIEN |

**核心差异：** 召回要"快"且"泛"，排序要"准"且"精"。召回模型受限于在线推理时延，必须使用简单的双塔结构或基于Embedding的向量检索；排序阶段可以用更复杂的模型和更多特征。

---

#### Q3: 排序为什么比召回的结果更准？

**参考答案：**

1. **特征更丰富**：排序阶段可以使用用户完整行为序列、上下文特征、交叉特征，而召回受限于双塔结构难以做特征交叉
2. **模型更复杂**：排序可以使用DeepFM、DIN、DIEN等复杂模型，捕捉高阶特征交叉和序列模式
3. **样本更精准**：精排的样本是曝光过的，标签更准确；召回的负样本多为未曝光的采样样本，存在噪声
4. **实时性更好**：排序可以在线更新，召回的Item塔通常是离线更新（如隔天更新）

---

### 3.2 双塔模型

#### Q4: 双塔模型的正负样本如何构造？（召回 vs 粗排）

**参考答案：**

**召回阶段：**
- **正样本**：曝光且点击的用户-物品二元组（用户对物品感兴趣）
- **负样本**：
  - 简单负样本：从全体物品中随机采样（未召回的物品 ≈ 全体物品）
  - Batch内负样本：一个batch内，user和其他n-1个物品组成负样本
  - 困难负样本：召回结果中排名靠后但未点击的样本

**粗排阶段：**
- **正样本**：与精排一致，曝光且点击
- **负样本**：与精排一致，曝光未点击
- **核心区别**：粗排样本要尽量接近精排，因为粗排是精排的"预备筛选"

**面试话术：** 召回的负样本构造非常关键，需要让模型"见见世面"，不只是曝光未点击的样本，还要包含大量未曝光的样本，这样模型才能区分"完全不感兴趣"和"感兴趣但未曝光"。常用策略包括全局随机负采样、Batch内负采样、Hard Negative Mining等。

---

#### Q5: 双塔模型线上如何做召回和预测？

**参考答案：**

**离线训练阶段：**
1. 分别训练User塔和Item塔，得到用户向量和物品向量
2. 通过向量相似度（内积/余弦）计算用户-物品相关性

**在线召回阶段：**
1. **Item向量离线存储**：所有Item的向量导入Faiss，建立索引
2. **User向量实时计算**：用户请求时，用当前用户特征通过User塔得到向量
3. **近邻检索**：在Faiss中检索与User向量最相似的Top-N Item向量
4. **返回候选**：将召回的Item返回给下游粗排/精排

**核心优势：** Item塔可以离线计算，通过Faiss实现毫秒级百万级检索；User塔轻量，可以实时计算。

---

#### Q6: 双塔模型存在什么问题？如何解决？

**参考答案：**

**主要问题：**

1. **特征交叉能力受限**
   - User和Item塔分别输入，缺少用户-物品交叉组合特征
   - 两侧塔最后一层向量内积时已是高层特征，一些细粒度特征信息损失

2. **向量检索精度损失**
   - 离散特征映射为Embedding后有信息损失
   - 一次性计算全部向量的内积 vs 逐个计算有精度差异

**解决方案：**

| 方案 | 原理 |
|------|------|
| **SENet双塔** | 引入Squeeze-Excitation模块，对特征进行通道注意力加权 |
| **并联双塔** | 多路并联不同结构的双塔，结果融合 |
| **蒸馏学习** | 用精排模型指导粗排/召回模型训练 |
| **对偶增强双塔** | 引入对比学习增强表征 |
| **阿里COLD** | 去掉特征交叉限制，用更复杂结构 |

---

#### Q7: 双塔模型用内积还是余弦相似度？

**参考答案：**

**工业界常用内积**，原因如下：

1. **计算效率**：内积比余弦多一个归一化操作，在Faiss中内积检索更高效
2. **等价性**：当User和Item向量都做L2归一化后，内积等价于余弦相似度
3. **训练稳定性**：内积形式更简单，梯度计算更稳定

**注意**：如果User和Item向量分布差异大，可以考虑归一化后再内积，或者直接用余弦相似度。

### 3.3 经典模型原理

#### Q8: DeepFM模型的原理和结构？

**参考答案：**

**模型结构：**

```
输入特征 → FM Component + Deep Component → Output
              ↓                        ↓
        二次项特征交叉          DNN高阶特征交叉
```

**核心组成：**

1. **FM Component（Factorization Machines）**：
   - 捕获**一阶特征**和**二阶特征交叉**
   - 公式：y = w₀ + Σwᵢxᵢ + Σᵢ<ⱼ(vᵢ·vⱼ)xᵢxⱼ
   - 优势：可以处理稀疏特征、自动学习特征交叉

2. **Deep Component**：
   - 使用DNN捕获**高阶特征交叉**
   - Embedding层 + 多层全连接网络

3. **共享Embedding**：
   - FM和Deep共享同一个Embedding层，减少参数计算量

**vs Wide&Deep：**
- Wide&Deep需要人工设计"Wide"部分的交叉特征
- DeepFM自动学习一阶和二阶特征，更自动化

---

#### Q9: DIN模型中的Attention是如何做的？Score怎么得到的？

**参考答案：**

**背景：** DIN（Deep Interest Network）针对用户行为序列建模，引入Attention机制对不同历史行为赋予不同权重。

**Attention Score计算：**

1. **输入**：候选Item的Embedding + 用户历史行为序列中每个Item的Embedding
2. **计算方式**：
   ```
   attention_score = Activation(W · concat(item, behavior_item) + b)
   weight = softmax(attention_score)
   weighted_sum = Σ(weight * behavior_item)
   ```
3. **Activation**：使用Dice激活函数（一种自适应的PRelu）

**核心思想：** 候选Item与历史行为Item越"相关"，权重越高。例如用户历史点击过"手机"，候选商品是"手机壳"时权重高；候选是"零食"时权重低。

**面试话术：** DIN的亮点在于"因材施教"，对不同的候选商品，用户历史行为的贡献不同。传统方法对所有候选都用同一个用户向量，DIN根据候选动态调整注意力权重，这正是"深度兴趣"的来源。

---

#### Q10: DIEN模型的结构和原理？

**参考答案：**

**DIEN（Deep Interest Evolution Network）** 在DIN基础上引入**序列建模**，捕捉用户兴趣的动态演变。

**模型结构：**

```
用户行为序列 → Interest Extractor Layer → Interest Evolving Layer → Output
                  (GRU)                        (GRU + Attention)
```

1. **Interest Extractor Layer（兴趣抽取层）**：
   - 使用GRU对用户行为序列建模
   - 提取每个时刻的兴趣状态 hₜ

2. **Interest Evolving Layer（兴趣演化层）**：
   - 引入Attention机制（AUGRU），根据候选Item动态调整兴趣演化方向
   - 捕捉"浏览路径"对最终兴趣的影响

**vs DIN：** DIEN额外建模了兴趣的**时序演变**，不仅仅是"加权求和"。

---

#### Q11: Wide&Deep模型的原理？

**参考答案：**

**模型结构：**

```
Wide Component (线性模型) + Deep Component (DNN) → Output
        ↓                              ↓
    记忆能力                      泛化能力
```

1. **Wide Component**：
   - 线性模型，直接记忆特征组合
   - 擅长学习历史数据的"老套路"

2. **Deep Component**：
   - DNN，Embedding + 全连接
   - 擅长泛化，学习新特征组合

**核心价值：** 兼顾"记忆"和"泛化"——既记住经典模式，又有泛化到新组合的能力。

### 3.4 负样本策略

#### Q12: 召回和精排的负样本有何不同？

**参考答案：**

| 维度 | 召回负样本 | 精排负样本 |
|------|------------|------------|
| **来源** | 随机采样（未曝光+曝光未点击） | 曝光未点击（真实负样本） |
| **数量** | 多（百万级负样本） | 少（曝光样本有限） |
| **质量** | 噪声大，但更符合真实分布 | 准确但有选择性偏差 |
| **目的** | 区分"感兴趣"vs"完全不感兴趣" | 区分"点击"vs"未点击" |

**核心区别：** 召回需要区分"相关"vs"不相关"，负样本要覆盖"完全不感兴趣"的样本；精排只需区分"点击"vs"未点击"，负样本是曝光但未点击的样本。

---

#### Q13: 简单负样本有哪些？Batch内负采样是什么？

**参考答案：**

**简单负样本类型：**

1. **全局随机负采样**：从全体Item中随机采样作为负样本
2. **Batch内负采样**：一个Batch内，User和其他N-1个Item构成负样本
3. **曝光负样本**：召回但未点击的样本

**Batch内负采样详解：**

- 假设Batch有N个正样本(user, item)
- 对每个user，除了它对应的正item，其他N-1个item都是负样本
- 优点：无需额外计算负样本，效率高
- 缺点：Batch小效果差（负样本不够）

**面试话术：** 召回阶段负样本的核心是"让模型见见世面"，不只是曝光未点击的样本，还包括从未曝光的样本。Batch内负采样是工业界最常用的策略，核心是利用其他样本的Item作为当前用户的负样本。

---

#### Q14: 负采样如何加速？

**参考答案：**

1. **Cross-Batch Negative Sampling (CBNS)**：
   - 思想：利用历史Batch中编码过的Item Embedding作为负样本
   - 原理：训练稳定后，Embedding变化不大，可以复用历史Embedding

2. **Faiss加速**：
   - 负样本量大时，用Faiss近似最近邻检索筛选

3. **GPU负采样**：
   - 大Batch内负采样，利用GPU并行计算

4. **Word2Vec负采样**：
   - 用概率分布（词频的3/4次幂）替代均匀采样，优先采样高频词

### 3.5 机器学习基础

#### Q15: 逻辑回归的损失函数？手写交叉熵

**参考答案：**

**逻辑回归损失函数（交叉熵）：**

```
L = -[y·log(σ(w·x+b)) + (1-y)·log(1-σ(w·x+b))]
```

其中 σ(z) = 1/(1+exp(-z)) 是sigmoid函数

**Python伪代码：**

```python
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def cross_entropy_loss(y_true, y_pred):
    """
    y_true: 真实标签 [0, 1]
    y_pred: 预测概率 [0, 1]
    """
    eps = 1e-15  # 防止log(0)
    y_pred = np.clip(y_pred, eps, 1 - eps)
    loss = -np.mean(y_true * np.log(y_pred) + 
                   (1 - y_true) * np.log(1 - y_pred))
    return loss
```

**面试话术：** 逻辑回归的损失函数是交叉熵，本质是最大似然估计。Sigmoid将线性输出映射到[0,1]区间，交叉熵衡量真实分布与预测分布的差异。交叉熵优于MSE，因为梯度更稳定（不会在sigmoid两端消失）。

#### Q16: L1和L2正则的区别？

**参考答案：**

| 维度 | L1正则 (Lasso) | L2正则 (Ridge) |
|------|----------------|----------------|
| **形式** | λ‖w‖₁ = λΣ\|wᵢ\| | λ‖w‖₂² = λΣwᵢ² |
| **导数** | λ·sign(w) | 2λw |
| **稀疏性** | ✅ 会让部分权重为0 | ❌ 权重趋近0但不为0 |
| **特征选择** | 可做特征选择 | 无特征选择能力 |
| **解的唯一性** | 可能不唯一 | 唯一 |
| **权重衰减** | 等速衰减 | 减速衰减（梯度随w减小而减小） |

**面试话术：** L1正则会生成稀疏解，相当于自动做特征选择，适合高维稀疏特征；L2正则让权重趋近0但不为0，擅长处理特征共线性问题。实际应用中，L2更常用；如果需要稀疏性或特征选择，用L1或ElasticNet。

---

#### Q17: XGBoost的原理？

**参考答案：**

**XGBoost核心思想：** 加法模型 + 梯度提升

**目标函数：**

```
Obj = ΣL(yi, ŷi) + ΣΩ(fk)
     = 损失函数 + 正则项
```

**Boosting过程：**

1. 初始化模型预测为常数
2. 对每轮m，计算负梯度（伪残差）：r_im = -∂L(yi, ŷi)/∂ŷi
3. 用决策树拟合残差，得到f_m(x)
4. 更新模型：ŷi^(m) = ŷi^(m-1) + η·f_m(x)
5. 重复直到收敛

**核心优势：**

- **正则化**：防止过拟合
- **列采样**：随机选择特征子集
- **缺失值处理**：自动学习最优分裂方向
- **并行计算**：特征排序后并行寻找最优分裂

### 3.6 代码/算法题

#### Q18: 链表对折问题

**题目：** 链表 1->2->3->4->5 变成 1->5->2->4->3

**思路：**
1. 找到链表的中点
2. 翻转后半部分链表
3. 依次合并前后两部分

**核心代码（找到中点 + 翻转）：**

```python
# 找到链表中间节点（偶数取后半部分起点）
def find_mid(head):
    slow, fast = head, head.next
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow

# 翻转链表
def reverse(head):
    prev = None
    curr = head
    while curr:
        next_node = curr.next
        curr.next = prev
        prev = curr
        curr = next_node
    return prev
```

#### Q19: 判断链表有环，找到环入口

**思路：** Floyd判圈算法（双指针）

1. **判断有环**：快慢指针相遇则有环
2. **找入口**：相遇后，一个指针从头出发，一个从相遇点出发，每次走1步，再次相遇即为环入口

**公式证明：**
- 设环入口距离头结点为a
- 环入口到相遇点距离为b
- 环剩余距离为c (c = 环长 - b)
- 快指针走了：a + b + n·(b+c)
- 慢指针走了：a + b
- 快是慢的2倍：a + b + n·(b+c) = 2(a+b)
- 化简得：a = c(n-1) + (c-b)
- 当n=1时，a = c-b，即从头到环入口距离 = 相遇点到环入口距离

#### Q20: 矩阵的最小路径和

**题目：** m×n矩阵，只能往右或往下走，求路径和最小值

**动态规划解法：**

```python
def min_path_sum(grid):
    m, n = len(grid), len(grid[0])
    dp = [[0] * n for _ in range(m)]
    
    dp[0][0] = grid[0][0]
    
    # 第一行
    for j in range(1, n):
        dp[0][j] = dp[0][j-1] + grid[0][j]
    
    # 第一列
    for i in range(1, m):
        dp[i][0] = dp[i-1][0] + grid[i][0]
    
    # 其他位置
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
    
    return dp[m-1][n-1]

# 空间优化 O(n)
def min_path_sum_optimized(grid):
    m, n = len(grid), len(grid[0])
    dp = [0] * n
    
    for i in range(m):
        for j in range(n):
            if i == 0 and j == 0:
                dp[j] = grid[i][j]
            elif i == 0:
                dp[j] = dp[j-1] + grid[i][j]
            elif j == 0:
                dp[j] = dp[j] + grid[i][j]
            else:
                dp[j] = min(dp[j], dp[j-1]) + grid[i][j]
    
    return dp[n-1]
```

**时间复杂度：** O(m×n)
**空间复杂度：** O(n)（优化后）

## 三、逐题详细解析

### 3.1 机器学习基础

#### Q1: LR（逻辑回归）原理推导

**核心原理**：
逻辑回归是经典的二分类算法，本质是线性回归+sigmoid函数，将输出映射到(0,1)区间表示概率。

**数学推导**：

1. **模型定义**：
$$h_\theta(x) = \sigma(\theta^T x) = \frac{1}{1 + e^{-\theta^T x}}$$

2. **损失函数（对数损失）**：
$$J(\theta) = -\frac{1}{m}[\sum_{i=1}^{m}y^{(i)}\log h_\theta(x^{(i)}) + (1-y^{(i)})\log(1-h_\theta(x^{(i)}))]$$

3. **梯度求解**：
$$\frac{\partial J(\theta)}{\partial \theta_j} = \frac{1}{m}\sum_{i=1}^{m}(h_\theta(x^{(i)}) - y^{(i)})x_j^{(i)}$$

**面试Tips**：
- 面试官常让现场手写loss和梯度
- 要能解释为什么用对数损失（概率最大化推导）
- 要能对比SVM的合页损失

---

#### Q2: XGBoost原理推导

**核心原理**：
XGBoost是Boosting集成算法，通过加法模型逐步拟合残差，目标函数包含损失函数+正则项。

**数学推导**：

1. **目标函数**：
$$L(\phi) = \sum_{i=1}^{n}l(y_i, \hat{y}_i) + \sum_{k=1}^{K}\Omega(f_k)$$

其中 $\Omega(f) = \gamma T + \frac{1}{2}\lambda||w||^2$

2. **第t棵树的学习目标**：
$$\mathcal{L}^{(t)} = \sum_{i=1}^{n}[g_i f_t(x_i) + \frac{1}{2}h_i f_t^2(x_i)] + \Omega(f_t)$$

3. **分裂增益**：
$$Gain = \frac{1}{2}[\frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{(G_L+G_R)^2}{H_L+H_R+\lambda}] - \gamma$$

**XGBoost如何处理缺失值**：
- 训练时：分别枚举缺失值在左子树和右子树的情况，选择增益更大的方向
- 预测时：默认分到默认方向（通常为右子树）

---

#### Q3: L1/L2正则的区别

| 特性 | L1正则（Lasso） | L2正则（Ridge） |
|------|-----------------|-----------------|
| 形式 | $\lambda\sum\|w\|$ | $\lambda\sum w^2$ |
| 解稀疏性 | ✅ 会产生稀疏解 | ❌ 不会稀疏 |
| 特征选择 | ✅ 可做特征选择 | ❌ 不做选择 |
| 解空间 | 方形顶点 | 圆形 |
| 梯度 | 常数 $\lambda$ | $2\lambda w$ |

**面试话术**：
> L1正则因为使用常数梯度，在零点附近容易"跨过去"产生稀疏解，适合特征选择；L2正则对大权重惩罚更重，适合防止过拟合。实际工程中经常L1+L2结合使用（Elastic Net）。

### 3.2 推荐系统模型

#### Q4: 推荐系统整体流程

**四阶段漏斗**：

```
┌─────────────────────────────────────────────────────────┐
│                    推荐系统全链路                         │
├─────────────────────────────────────────────────────────┤
│  召回 → 粗排 → 精排 → 重排                               │
│  1000万+  → 1万 → 1000 → 10-20                         │
└─────────────────────────────────────────────────────────┘
```

1. **召回（Matching）**：
   - 目标：从海量候选中快速召回相关item
   - 特点：模型简单、特征少、速度快、多路召回
   - 方法：协同过滤、FM、双塔、DSSM、Graph Embedding

2. **粗排（Pre-Ranking）**：
   - 目标：缩减精排计算量
   - 特点：轻量级排序模型
   - 方法：独立建模或对齐精排

3. **精排（Ranking）**：
   - 目标：精准排序
   - 特点：复杂模型、丰富特征、耗时较长
   - 方法：LR→FM→DeepFM→DIN→DIEN

4. **重排（Re-Ranking）**：
   - 目标：多样性/业务规则调整
   - 特点：打散、插入广告、运营干预
   - 方法：MMR、DPP、RL

#### Q5: 双塔模型原理

**模型结构**：

```
用户塔(User Tower)          物品塔(Item Tower)
    │                          │
  MLP/Transformer          MLP/Transformer  
    │                          │
  user_embedding         item_embedding
         \                  /
            Dot Product
                 │
            Score/Top-K
```

**核心思想**：
- 左侧：用户特征→用户向量（包含历史行为序列）
- 右侧：物品特征→物品向量（离线预先计算）
- 线上：实时计算用户向量，与预计算的物品向量做ANN检索

**优势**：
1. ✅ 离线计算item embedding，支持亿级候选
2. ✅ 线上只计算user embedding，速度快
3. ✅ 支持实时更新user embedding

**缺点**：
1. ❌ 只能做向量内积，无法做复杂特征交叉
2. ❌ user和item特征交互太晚，损失信息

**优化方向**：
- hard negative mining：构建难负样本
- 负采样策略：batch负采样 vs 全局负采样
- 对比学习
- 引入更多交互特征

#### Q6: DIN（Deep Interest Network）模型

**核心创新**：
引入Attention机制，对用户历史行为序列进行加权处理，"关注"与当前item相关的历史行为。

**模型结构**：

```
用户行为序列 [i1, i2, i3, ..., in]
       │
    Attention
   (对每个历史item与target item计算相似度)
       │
  加权序列向量
       │
    与其他特征拼接
       │
     DNN → Click Probability
```

**Attention实现**：

$$a_i = \frac{\exp(V^T \cdot ReLU(W \cdot x_i + b))}{\sum_{j=1}^{T} \exp(V^T \cdot ReLU(W \cdot x_j + b))}$$

其中：
- $x_i$：第i个历史行为（item embedding + position encoding）
- $target$：目标item embedding
- $W, V, b$：可学习参数

**面试话术**：
> DIN的核心思想是"因人而异"的推荐。之前的方法对所有用户使用相同的历史行为表示，但不同用户兴趣不同，我们应该关注与当前候选item相关的历史行为。Attention机制就是用来学习这个相关性强弱的。

#### Q7: MMOE（Multi-gate Mixture-of-Experts）多任务学习

**背景**：
推荐系统中经常需要同时预测多个目标（点击+转化+收藏+分享），多任务学习可以共享特征表示，但任务间可能存在冲突（跷跷板现象）。

**模型结构**：

```
输入特征x
    │
┌───┴───┐
│       │
Expert1 Expert2 Expert3 ... ExpertN  (多个专家网络)
│       │
┌─┴─┐ ┌─┴─┐ ┌─┴─┐
│Gate│ │Gate│ │Gate│ (每个任务独立的门控)
└───┘ └───┘ └───┘
    │     │     │
  输出1  输出2  输出N
```

**核心公式**：
$$y_k = \sum_{i=1}^{N} G_k(x)_i \cdot E_i(x)$$

其中 $G_k(x)$ 是第k个任务的门控网络输出（softmax概率分布）。

**优势**：
- 共享特征表示，同时学习多个任务
- 每个任务有独立门控，可以自适应选择专家
- 缓解任务间冲突

#### Q8: 协同过滤（User-CF vs Item-CF）

| 对比维度 | User-CF | Item-CF |
|----------|---------|---------|
| 核心思想 | 相似的用户喜欢相同物品 | 相似的物品被相同用户喜欢 |
| 相似度矩阵 | User-User | Item-Item |
| 适用场景 | 用户数量少、用户兴趣稳定 | 物品数量少、物品变化慢 |
| 冷启动 | 新用户难 | 新物品难 |
| 解释性 | 相似用户推荐 | "看过XX的也看过YY" |

**面试话术**：
> 实际工业界更多用Item-CF，因为用户兴趣相对稳定，而物品（如商品、内容）更新频率高，Item-CF可以离线计算。但现在主流都是向量召回（Embedding-based），协同过滤更多作为一路召回策略。

### 3.3 深度学习

#### Q9: Attention机制原理

**核心思想**：
注意力机制模拟人类注意力，选择性地关注重要信息，忽略无关信息。

**数学定义**：

$$Attention(Q, K, V) = softmax(\frac{QK^T}{\sqrt{d_k}})V$$

- $Q$ (Query)：查询向量，当前要关注的目标
- $K$ (Key)：键向量，表示信息的"关键字"
- $V$ (Value)：值向量，实际要提取的信息
- $\sqrt{d_k}$：缩放因子，防止梯度消失

**面试话术**：
> Attention的本质是软寻址。Q和K的相似度决定了从V中取什么、取多少。就像人在看书时，会根据当前问题去重点关注相关段落，而不是逐字阅读。

---

#### Q10: Transformer原理

**核心架构**：

```
输入embedding + 位置编码
       │
  ┌────┴────┐
  │ Encoder │ ×N层
  └────┬────┘
       │
  ┌────┴────┐
  │ Decoder │ ×N层
  └────┬────┘
       │
    输出概率
```

**核心组件**：

1. **Multi-Head Attention**：并行多个注意力头
   $$MultiHead(Q,K,V) = Concat(head_1, ..., head_h)W^O$$
   其中 $head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)$

2. **FFN（前馈神经网络）**：
   $$FFN(x) = ReLU(xW_1 + b_1)W_2 + b_2$$

3. **残差连接 + LayerNorm**

**面试Tips**：
- 手撕Transformer代码是高频题
- 要能解释为什么需要多头注意力
- 要理解QKV的作用

### 3.4 工程实践

#### Q11: 推荐系统评估指标

| 指标 | 公式 | 适用场景 |
|------|------|----------|
| AUC | ROC曲线下面积 | 整体模型排序能力 |
| GAUC | 分用户AUC平均 | 考虑用户间差异 |
| Recall@K | 命中数/实际正例数 | 召回阶段 |
| Precision@K | 命中数/推荐数 | 排序阶段 |
| MRR | 第一个正例倒数平均值 | 位置敏感 |
| NDCG | 折损累计增益 | 综合排序质量 |

**面试话术**：
> AUC是离线评估最常用的指标，它衡量的是模型对正负样本的排序能力，与阈值无关。线上A/B测试看的是实际业务指标如CTR、CVR、用户停留时长等。

#### Q12: 冷启动问题解决方案

**用户冷启动**：
1. 引导用户填写兴趣问卷
2. 利用社交网络（微信/通讯录）推荐
3. 新用户热门推荐
4. 探索与利用（ε-greedy）

**物品冷启动**：
1. 利用物品内容特征做内容推荐
2. 专家/运营人工干预
3. 探索用户中测试

**系统冷启动**：
1. 预先构建知识图谱
2. 引入外部数据

### 📄 综述类

#### 1. A Survey on Large Language Models for Recommendation
- **arXiv:** https://arxiv.org/abs/2305.19860
- **代码:** https://github.com/WLiK/LLM4Rec-Awesome-Papers
- **核心内容：** 全面综述 LLM 在推荐系统中的应用，分为判别式 LLM（微调/提示调优）和生成式 LLM（非调优/提示学习/指令调优）两条路线，涵盖模型偏差、推荐提示设计、评估问题等关键挑战。
- **标签：** #综述 #LLM4Rec #推荐系统

---

### 📄 推荐系统 + LLM

#### 2. NoteLLM: A Retrievable Large Language Model for Note Recommendation
- **arXiv:** https://arxiv.org/abs/2403.01744
- **会议：** WWW 2024
- **核心内容：** 提出可检索 LLM 用于笔记推荐，通过对比学习将笔记映射到稠密向量空间，同时优化语言模型损失和检索质量。
- **标签：** #笔记推荐 #对比学习 #WWW2024

#### 3. CTRL-Rec: Controlling Recommender Systems With Natural Language
- **arXiv/来源：** CSDN 2025 推荐系统论文汇总
- **核心内容：** 允许用户通过自然语言实时控制传统推荐系统，LLM 模拟用户对物品的偏好，将预测信号集成到推荐权重中。
- **标签：** #可控推荐 #自然语言交互 #LLM辅助推荐

#### 4. LLM-I2I: Boost Your Small Item2Item Recommendation Model with Large Language Model
- **arXiv:** https://arxiv.org/abs/2512.21595（2025年12月）
- **核心内容：** 提出 LLM-I2I 数据中心框架，利用 LLM 为长尾 Item 生成用户-物品交互数据，缓解数据稀疏问题，降低 I2I 推荐模型的训练成本。
- **标签：** #I2I推荐 #长尾物品 #数据增强 #LLM

#### 5. RecGOAT: Graph Optimal Adaptive Transport（复旦大学 × 快手，2026）
- **来源：** 企鹅号/QQ搜索，发表于 Under Review（2026）
- **核心内容：** 复旦大学与快手联合提出 RecGOAT 框架，解决推荐系统中的用户真实偏好挖掘难题，引入图最优自适应传输机制。
- **标签：** #图神经网络 #推荐系统 #快手 #2026新工作

#### 6. Language Ranker: 从推荐系统视角优化 LLM 解码
- **来源：** 企鹅号，北京大学林宙辰/王奕森团队，NeurIPS 2025
- **arXiv 链接：** 待查（建议搜索 "Language Ranker NeurIPS 2025"）
- **核心内容：** 将 LLM 解码过程类比为推荐系统排序阶段，提出轻量级排序框架 Language Ranker，揭示了现有解码方法的局限并提出高效改进方案。
- **标签：** #NeurIPS2025 #LLM解码 #推荐系统视角 #北京大学

### 📄 LLM 微调 / PEFT / LLaMA Factory 生态

#### 7. MARFT: Multi-Agent Reinforcement Fine-Tuning
- **arXiv:** https://arxiv.org/abs/2504.16129
- **GitHub:** https://github.com/jwliao-ai/MARFT
- **核心内容：** 针对以 LLM 为基础的多智能体系统，提出强化微调（RFT）新范式，填补了 LLM 多智能体强化微调的研究空白。
- **标签：** #多智能体 #强化学习微调 #LLM Agent #PEFT

#### 8. TinyLLaVA Factory: 模块化重构多模态大模型
- **arXiv:** https://arxiv.org/abs/2405.11788
- **GitHub:** https://github.com/TinyLLaVA/TinyLLaVA_Factory
- **机构：** 清华大学 MSIIP 实验室 × 北京航空航天大学
- **核心内容：** 以工厂模式模块化重构 LLaVA 代码库，替换组件只需添加 1-2 个文件，大幅提升可读性、扩展性和实验可复现性。
- **标签：** #多模态 #TinyLLaVA #模块化 #清华 #北航

#### 9. Knowledge Circuits in Pretrained Transformers
- **arXiv:** https://arxiv.org/abs/2405.17969
- **GitHub:** https://github.com/zjunlp/KnowledgeCircuits
- **Demo:** http://knowledgecircuits.zjukg.cn
- **核心内容：** 提出"知识回路"假说——大模型处理知识时，实体、概念和关系通过参数激活形成闭合回路，为构建可靠、可控的大模型知识学习框架提供新思路。
- **标签：** #知识表示 #Transformer可解释性 #知识回路

#### 10. Number Cookbook: 大模型数字理解能力
- **arXiv:** https://arxiv.org/abs/2411.03766
- **机构：** 北京大学张牧涵团队（ICLR 2025 投稿）
- **核心内容：** 系统评估 LLM 的数字理解与处理能力（NUPA），揭示 BPE tokenizer 对数字分词的固有缺陷，提出改进方向。
- **标签：** #LLM能力评估 #Tokenizer缺陷 #北京大学 #ICLR2025

## 四、LlamaFactory 使用技巧速查

> 本周补充 LlamaFactory 常见问题解决方案

### 常用微调命令
```bash
# 安装
git clone --depth 1 https://github.com/hiyouga/LLaMA-Factory
cd LLaMA-Factory && pip install -e ".[torch,metrics]"

# 启动 Web UI
llamafactory-cli webchat

# 数据集格式（Alpaca）
{
  "instruction": "用户指令",
  "input": "用户输入(选填)",
  "output": "模型回答"
}
```

### 高频问题（来源：Lab4AI 官方答疑系列）
- 如何自定义数据集？→ 修改 `data/dataset_info.json`
- 如何使用 DeepSpeed？→ `pip install deepspeed==0.15.4`
- 多卡训练？→ 同步 LoRA 参数，全参数微调需梯度累积

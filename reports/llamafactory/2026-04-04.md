## 一、核心论文：LLaMA-Factory 框架

### 1. LLaMA-Factory 论文（必读）
> **LLAMAFACTORY: Unify Efficient Fine-Tuning of 100+ LLMs**  
> arXiv: [2403.13372](https://arxiv.org/abs/2403.13372) | 代码: [GitHub](https://github.com/hiyouga/LLaMA-Factory)

- **来源**：北京航空航天大学 & 北京大学联合开发
- **核心贡献**：统一框架，整合多种高效微调方法，支持 100+ LLM，无需编码即可通过 Web UI 定制微调
- **支持的训练方式**：
  - Pre-training（增量预训练）
  - SFT（指令监督微调）
  - Reward Modeling（奖励模型训练）
  - PPO / DPO / KTO / ORPO（对齐训练）
- **支持的 PEFT 方法**：LoRA、QLoRA（全参数/冻结/Lora + AQLM/AWQ/GPTQ/LLM.int8 量化）
- **对推荐系统工程师的价值**：掌握此框架 = 掌握大模型微调核心技能

### 2. PEFT 综合调查（深度理解）
> **A Survey on Parameter-Efficient Fine-Tuning Techniques for Large-Scale Pre-trained Language Models**  
> arXiv: [2403.14608](https://arxiv.org/html/2403.14608v1)

- **分类体系**：
  - 添加剂 PEFT：Adapter、Soft Prompt（LAPT/Prefix Tuning/Prompt Tuning）、SSF/IPA 等
  - 选择性 PEFT：Diff剪枝、PaFi、FishMask 等
  - 重新参数化 PEFT：**LoRA**（最主流）、QLoRA、DoRA 等
- **系统设计考量**：各方法的计算开销与实现成本对比
- **对推荐系统工程师的价值**：全面理解 PEFT 家族，可根据场景选型

### 3. LoRA 原论文（奠基性）
> **LoRA: Low-Rank Adaptation of Large Language Models**  
> Microsoft Research（2021）

- **核心思想**：假设权重更新具有低秩本质维度，用 A、B 两个低秩矩阵近似增量 ΔW = BA
- **公式**：训练后 W = W₀ + ΔW = W₀ + BA，推理时合并，不增加推理延迟
- **效果**：GPT-3 微调需更新参数量可低至全量的 0.01%
- **对推荐系统工程师的价值**：LoRA 是实战首选，理解其原理是基础

## 二、大模型 + 推荐系统 论文

### 4. LLM 在推荐系统中的应用调查
> **How Can Recommender Systems Benefit from Large Language Models: A Survey**  
> arXiv: [2306.05817](https://arxiv.org/abs/2306.05817)

- **核心问题**：LLM 能应用在推荐系统的哪些环节？如何应用？
- **应用层次**：特征工程、用户/物品表示、排序模型、对话推荐
- **优势**：强泛化能力、零样本/少样本、冷启动、语义理解
- **挑战**：推理延迟、推荐是"行为建模"而非"语言任务"

### 5. 基于 LLM 的高效推荐数据微调
> **Data-efficient Fine-tuning for LLM-based Recommendation**  
> arXiv（2024）

- **问题**：在大量推荐数据上微调 LLM 成本极高
- **解决方案**：数据修剪任务（Data Pruning），识别代表性样本用于少样本微调
- **对推荐系统工程师的价值**：如何在有限资源下微调推荐大模型

### 6. LLM-Rec：提示大模型做个性化推荐
> **LLM-Rec: Personalized Recommendation via Prompting Large Language Models**  
> arXiv: [2307.15780](https://arxiv.org/abs/2307.15780)

- **方法**：通过 Prompt 利用 LLM 生成内容增强推荐系统输入
- **核心思想**：用 LLM 理解和生成 item 描述、用户偏好摘要，补充协同过滤的稀疏性问题

### 7. ARAG：沃尔玛 AI 团队的 Agentic RAG 推荐
> **ARAG: Agentic Retrieval-Augmented Generation for Personalized Recommendation**

- **核心观点**：传统推荐 = 行为建模，LLM = 语言建模，两者存在根本差异
- **ARAG 方法**：将 RAG 框架与 Agent 能力结合做推荐
- **亮点**：挑战"大模型真的能做推荐系统吗"，论文给出了新思路
- **对推荐系统工程师的价值**：了解 RAG + 推荐的前沿融合方式

### 8. AAAI 2025：LLM 用户模拟器
> **LLM-based Recommendation User Simulator**  
> arXiv: [2412.16984](https://arxiv.org/abs/2412.16984) | 代码: [GitHub](https://github.com/Applied-Machine-Learning-Lab/LLM_User_Simulator)

- **创新点**：用 LLM 模拟用户行为，解决在线交互数据稀缺问题
- **应用场景**：推荐系统持续优化，用户偏好模拟
- **对推荐系统工程师的价值**：数据增强 + 离线评估的新范式

## 三、LLaMA-Factory 生态相关

### 9. TinyLLaVA Factory（多模态微调）
> **TinyLLaVA Factory: A Modular Framework for Lightweight Multimodal LLM**  
> arXiv: [2405.11788](https://arxiv.org/abs/2405.11788)  
> 清华 + 北航联合开发

- **设计理念**：工厂模式（Factory），模块化重构 LLaVA，替换组件只需 1-2 个文件
- **对推荐系统工程师的价值**：快速微调多模态推荐模型（商品图片/视频理解）

### 10. Llama-Nemotron 系列（推理 + 对齐）
> **Llama-Nemotron: Efficient Reasoning Models**  
> arXiv: [2505.00949](https://arxiv.org/pdf/2505.00949) | NVIDIA 开源

- **特点**：超强的推理能力 + 企业友好开放许可
- **配套**：完整训练数据和代码开源（NeMo）
- **对推荐系统工程师的价值**：可用作推理增强的推荐基座

### 11. Light-R1（低成本推理模型）
> **Light-R1-32B** | Qihoo 360 开源 | [HF 仓库](https://huggingface.co/qihoo360/Light-R1-32B)

- **亮点**：仅用 7 万条数学数据、1000 美元成本，从零训练超越 DeepSeek-R1-Distill-Qwen-32B
- **技术路径**：两阶段课程学习 SFT + GRPO
- **对推荐系统工程师的价值**：低成本打造领域推理模型的方法论参考

## 四、训练框架对比速查

| 框架 | 特点 | PEFT 支持 | 上手难度 |
|------|------|-----------|---------|
| **LLaMA-Factory** | 零代码 + WebUI，100+模型，完整后训练流程 | LoRA / QLoRA / 全参数 | ⭐ 最低 |
| **Axolotl** | YAML 配置，支持多种模型和微调方式 | LoRA / QLoRA / 全参数 | ⭐⭐ 中 |
| **XTuner** | 低显存支持，8GB 显存跑 7B，多模态强 | LoRA / QLoRA | ⭐⭐ 较低 |
| **Swift/ms-swift** | 450+纯文本 + 150+多模态模型，全链路 | LoRA / QLoRA / 全参数 | ⭐⭐⭐ 较高 |
| **Firefly** | 与官方聊天模板对齐，数据集丰富 | LoRA / DPO | ⭐⭐ 中 |

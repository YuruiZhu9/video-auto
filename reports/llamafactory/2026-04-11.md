## 🔬 核心论文：LLaMA Factory 论文详解

### 1. LlamaFactory: Unified Efficient Fine-Tuning of 100+ Language Models

| 字段 | 内容 |
|------|------|
| **作者** | Yaowei Zheng, Richong Zhang, Junhao Zhang, Yanhan Ye, Zheyan Luo, Yongqiang Ma |
| **发表** | ACL 2024 (System Demonstrations), arXiv:2403.13372 |
| **引用** | 🔥 1,460+ 次（高影响力） |
| **GitHub** | [hiyouga/LLaMA-Factory](https://github.com/hiyouga/LLaMA-Factory)（⭐ 25k+ stars） |

**摘要核心**：  
LLaMAFactory 是一个统一框架，集成了一套尖端的高效训练方法，提供了一个灵活的解决方案，可用于**无代码定制 100+ 语言模型的微调**，通过内置的 Web UI **LlamaBoard** 实现。

**主要贡献**：

1. **统一微调框架**：集成 LoRA、QLoRA、PEFT 等多种高效微调方法
2. **LlamaBoard 可视化**：无需编码，通过 Web UI 灵活定制 100+ LLM 的微调
3. **多任务验证**：在语言建模和文本生成任务上验证了框架的效率和有效性
4. **开源影响力**：GitHub 25,000+ stars，3,000+ forks（截至 2024 ACL）

**核心技术覆盖**：

- LoRA / QLoRA / DoRA / LoRA+ / LoftQ / PiSSA
- LongLoRA / LLaMA Pro / Mixture-of-Depths
- GaLore / BAdam / APOLLO / Adam-mini / Muon
- FlashAttention / 梯度累积 / 混合精度训练
- SFT / RLHF / DPO / PPO / Reward Modeling

## 📚 PEFT / LoRA 相关核心论文（2023-2025）

### 2. QLoRA: Efficient Finetuning of Quantized LLMs ⭐ 必读

| 字段 | 内容 |
|------|------|
| **作者** | Tim Dettmers, Artidoro Pagnoni, Ari Holtzman, Luke Zettlemoyer |
| **发表** | arXiv:2305.14314（2023-05） |
| **引用** | 🔥 极高（LoRA 量化微调里程碑论文） |

**摘要核心**：  
QLoRA 通过**4位 NormalFloat (NF4) 量化** + **双量化** + **分页优化器**，实现在**单张 48GB GPU** 上微调 65B 参数模型，同时保持完整的 16 位微调性能。Guanaco 模型在 Vicuna 基准上达到 **ChatGPT 性能水平的 99.3%**。

**核心技术**：
- **NF4 数据类型**：对正态分布权重信息论最优
- **双量化（Double Quantization）**：量化量化常数，节省内存
- **分页优化器（Paged Optimizers）**：管理内存峰值

## 📋 本周发现：推荐系统工程师可重点关注

### 高价值方向

1. **LLM 微调 + 推荐系统融合**
   - InstructRec / TALLRec 证明微调 LLM 可显著提升推荐效果
   - 适合做：垂类推荐模型微调、冷启动推荐、对话推荐

2. **PEFT 在推荐中的应用**
   - LoRA/QLoRA 低成本微调，**推荐系统场景数据量充足**，非常适合微调
   - 用 LLaMA Factory 快速微调，推荐系统工程师可低成本上手 LLM

3. **推荐数据增强**
   - LLMRec 等工作用 GPT/LLaMA 生成推荐解释、用户画像
   - 可探索：用 LLaMA Factory 微调中文 LLM 做推荐数据生成

### 推荐学习路径

```
第1步：熟悉 LLaMA Factory 基本操作（LoRA 微调）
第2步：了解 PEFT 核心方法（LoRA/DoRA/QLoRA）
第3步：尝试用 LLaMA Factory 微调小型推荐模型
第4步：探索 InstructRec / TALLRec 论文复现
```

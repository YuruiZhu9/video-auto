### 1.2 核心技术创新

#### 1.2.1 Multi-Head Latent Attention (MLA)

传统Transformer的Attention机制存在KV缓存过大的问题。MLA通过**低秩投影**将Key和Value压缩到潜在空间：

```python
# MLA核心实现示意
class MultiHeadLatentAttention(nn.Module):
    def __init__(self, d_model, n_heads, latent_dim):
        super().__init__()
        self.n_heads = n_heads
        self.latent_dim = latent_dim
        
        # Q单独投影，KV共享潜在空间
        self.W_Q = nn.Linear(d_model, d_model)
        self.W_KV = nn.Linear(d_model, latent_dim * 2)
        self.W_O = nn.Linear(d_model, d_model)
        
    def forward(self, x, cache=None):
        Q = self.W_Q(x).view(-1, self.n_heads, self.d_head)
        KV = self.W_KV(x).chunk(2, dim=-1)  # 共享压缩
        
        # 潜在空间注意力计算
        attn_weights = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_head)
        attn_weights = F.softmax(attn_weights, dim=-1)
        output = torch.matmul(attn_weights, V)
```

**数学原理**：传统MHA需要缓存2×n_heads×seq_len×d_head的KV，而MLA只需缓存latent_dim，大幅降低推理显存。

#### 1.2.2 DeepSeekMoE架构

采用**稀疏激活**策略，总参数671B但实际激活仅36B：

```
专家分配策略：
- 共享专家：始终激活，捕获通用知识
- 路由专家：基于门控分数Top-K选择
- 损失函数：负载均衡损失 + 专家多样性损失
```

```python
class DeepSeekMoELayer(nn.Module):
    def __init__(self, d_model, n_experts, top_k):
        super().__init__()
        self.experts = nn.ModuleList([nn.Linear(d_model, d_model) for _ in range(n_experts)])
        self.gate = nn.Linear(d_model, n_experts)
        self.top_k = top_k
        
    def forward(self, x):
        # 门控计算
        gates = self.gate(x)
        top_gates, top_experts = torch.topk(gates, self.top_k, dim=-1)
        
        # 归一化门控分数
        top_gates = F.softmax(top_gates, dim=-1)
        
        # 稀疏激活专家
        results = torch.zeros_like(x)
        for i, expert_idx in enumerate(top_experts.unbind(-1)):
            expert_output = self.experts[expert_idx](x)
            results += expert_output * top_gates[..., i:i+1]
        
        return results
```

## 二、混合专家模型(MoE)：大模型扩展范式

### 2.1 MoE的数学框架

MoE的核心是**稀疏条件计算**：

```
输出公式：y = Σ_{i=1}^{n} G(x)_i · E_i(x)

其中：
- E_i(x)：第i个专家网络
- G(x)：门控函数输出，ΣG(x)_i = 1
- 典型设置：n=64~128个专家，激活top-k=8~16
```

### 2.2 门控机制详解

#### 2.2.1 Switch Transformer式门控

```python
class SwitchGate(nn.Module):
    def __init__(self, d_model, n_experts):
        super().__init__()
        self.linear = nn.Linear(d_model, n_experts)
        
    def forward(self, x):
        # 硬路由：只选择一个专家
        logits = self.linear(x)
        expert_idx = torch.argmax(logits, dim=-1)
        expert_weight = F.softmax(logits, dim=-1)
        return expert_idx, expert_weight
```

#### 2.2.2 负载均衡损失

为避免专家利用不均，引入辅助损失：

```python
def load_balancing_loss(gates):
    """
    gates: [batch, num_experts]
    理想情况：每个专家被选中的概率相等
    """
    # 计算每个专家被选择的频率
    expert_usage = gates.sum(dim=0) / gates.sum()
    # 均匀分布
    target = torch.ones_like(expert_usage) / gates.size(-1)
    # KL散度作为损失
    return F.kl_div(expert_usage.log(), target)
```

## 三、GRPO：无需Critic的强化学习训练

### 3.1 从PPO到GRPO的演进

传统PPO需要Actor-Critic双网络：

```
PPO目标：L(θ) = E[min(r(θ)·A, clip(r(θ), 1-ε, 1+ε)·A)]

其中：
- r(θ) = π_θ(a|s) / π_old(a|s)：新旧策略概率比
- A：优势函数，需要Critic估计
- ε：裁剪范围，通常0.2
```

**问题**：LLM场景中，状态空间巨大，训练Critic模型成本高且不稳定。

### 3.2 GRPO核心原理

GRPO(Group Relative Policy Optimization)利用**组内相对排序**计算优势：

```python
def compute_grpo_loss(logprobs, old_logprobs, rewards, group_size):
    """
    logprobs: [batch, seq_len] 当前策略的log概率
    old_logprobs: [batch, seq_len] 旧策略的log概率
    rewards: [batch] 每个样本的奖励
    group_size: 每组样本数
    """
    # 计算每个token的对数概率比
    ratio = torch.exp(logprobs - old_logprobs)
    
    # 将rewards按组归一化（相对排序）
    rewards = rewards.view(-1, group_size)
    advantages = (rewards - rewards.mean(dim=-1, keepdim=True)) / (rewards.std(dim=-1, keepdim=True) + 1e-8)
    advantages = advantages.view(-1, 1)
    
    # GRPO损失
    surr1 = ratio * advantages
    surr2 = torch.clamp(ratio, 1-0.3, 1+0.3) * advantages
    return -torch.min(surr1, surr2).mean()
```

### 3.3 GRPO vs DPO vs PPO

| 方法 | 是否需要Reward Model | 是否需要Critic | 样本效率 | 适用场景 |
|------|---------------------|----------------|----------|----------|
| PPO | 可选 | 必须 | 中等 | 通用RLHF |
| DPO | 必须（偏好数据） | 不需要 | 高 | 人类偏好对齐 |
| GRPO | 不需要 | 不需要 | 高 | 推理/验证任务 |

### 3.4 GRPO应用场景

1. **数学推理**：奖励正确解题过程
2. **代码生成**：奖励通过测试的代码
3. **事实性**：奖励符合事实的回复

## 四、线性注意力：突破O(N²)瓶颈

### 4.1 问题背景

标准Attention的计算复杂度：

```
Time: O(N²·d)  — N为序列长度，d为特征维度
Memory: O(N²)  — 注意力矩阵存储
```

处理100K上下文时，N²=10¹⁰，显存爆炸。

### 4.2 线性注意力核化方法

核心思想：将softmax注意力转化为**核函数**的线性组合：

```
Attention(Q,K,V) = Σ_i φ(Q_i)·φ(K_i)ᵀ·V / Σ_i φ(Q_i)·φ(K_i)ᵀ

其中 φ(·) 是核函数

若满足：κ(a,b) = φ(a)·φ(b)ᵀ
则：Σ_i κ(q_i,k_j) = (Σ_i φ(q_i)φ(k_i)ᵀ)·1
```

### 4.3 典型实现：Flash Linear Attention

```python
class LinearAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        self.d_head = d_model // num_heads
        self.head_dim = d_model // num_heads
        
        # 使用元素级非线性映射
        self.query_proj = nn.Linear(d_model, d_model)
        self.key_proj = nn.Linear(d_model, d_model)
        self.value_proj = nn.Linear(d_model, d_model)
        
    def forward(self, x):
        Q = self.query_proj(x).view(-1, self.num_heads, self.d_head)
        K = self.key_proj(x).view(-1, self.num_heads, self.d_head)
        V = self.value_proj(x).view(-1, self.num_heads, self.d_head)
        
        # 线性注意力核心：KV特征累积
        # 保持O(N)复杂度
        kv_feat = torch.einsum('bhd,bhm->bdm', K, V)
        q_feat = K.sum(dim=1, keepdim=True)
        
        output = torch.einsum('bhd,bdm->bhm', Q, kv_feat) / (q_feat + 1e-8)
        return output.view(-1, self.d_model)
```

### 4.5 Mamba状态空间模型

Mamba通过**选择性状态空间(SSM)** 实现线性复杂度：

```python
class SSMBlock(nn.Module):
    def __init__(self, d_model, d_state=128):
        super().__init__()
        # 投影
        self.x_proj = nn.Linear(d_model, d_state * 2)
        self.dt_proj = nn.Linear(d_state, d_model)
        
        # 状态矩阵（可学习）
        self.A_log = nn.Parameter(torch.randn(d_state))
        self.B = nn.Linear(d_model, d_state)
        self.C = nn.Linear(d_state, d_model)
        
    def forward(self, x):
        """
        离散化后的SSM前向传播
        核心：用卷积实现RNN
        """
        # 获取门控参数
        s, dt = self.x_proj(x).chunk(2, dim=-1)
        dt = F.softplus(self.dt_proj(dt))
        
        # 状态空间离散化
        A = -torch.exp(self.A_log.float())
        B = self.B(x)
        
        # 卷积核计算
        kernel_len = x.size(1)
        kernel = torch.exp(torch.arange(kernel_len, device=x.device).unsqueeze(0) * A.unsqueeze(1))
        
        # 线性注意力：通过卷积实现
        output = F.conv1d(B.transpose(1,2), kernel.flip(1), padding=kernel_len-1)
        output = self.C(output.transpose(1,2))
        
        return output * dt.sigmoid()
```

## 五、LoRA/QLoRA：大模型高效微调

### 5.1 LoRA数学原理

LoRA的核心是**低秩适配**：

```
原始权重更新：W_new = W_old + ΔW
LoRA近似：ΔW = B·A，其中B∈R^{d×r}, A∈R^{r×d}，r << min(d,k)

前向传播：
h = W_old·x + BA·x = [W_old, B]·[x; A·x]
```

### 5.2 代码实现

```python
class LoRALayer(nn.Module):
    def __init__(self, d_model, d_ff, r=8):
        super().__init__()
        self.r = r
        # 降维矩阵 A
        self.lora_A = nn.Parameter(torch.randn(r, d_model))
        # 升维矩阵 B
        self.lora_B = nn.Parameter(torch.zeros(d_model, r))
        # 缩放因子
        self.scaling = r ** -0.5
        
        # 冻结原始权重
        self.weight.requires_grad = False
        
    def forward(self, x):
        # 原始FFN前向
        output = F.linear(x, self.weight, self.bias)
        # LoRA适配
        lora_output = torch.matmul(x, self.lora_A.t())
        lora_output = torch.matmul(lora_output, self.lora_B.t())
        return output + lora_output * self.scaling
```

### 5.3 QLoRA：量化+LoRA双剑合璧

```python
# QLoRA核心：4-bit NF4量化
from bitsandbytes import QuantizedLinear

class QLoRALayer(nn.Module):
    def __init__(self, d_model, d_ff, r=8):
        super().__init__()
        # 量化线性层（4-bit）
        self.quant_fc = QuantizedLinear(d_model, d_ff, bits=4)
        # LoRA适配器（非量化）
        self.lora_A = nn.Parameter(torch.randn(r, d_model))
        self.lora_B = nn.Parameter(torch.zeros(d_ff, r))
        
    def forward(self, x):
        # 量化前向传播
        output = self.quant_fc(x)
        # LoRA残差
        lora = torch.matmul(x, self.lora_A.t())
        lora = torch.matmul(lora, self.lora_B.t())
        return output + lora
```

### 1.2 GRPO (Group Relative Policy Optimization) 原理

**传统PPO的问题:**
- 需要4个模型(Critic, Actor, Reward, Reference)
- 显存占用大，训练不稳定

**GRPO的创新:**
```
PPO目标: max E[min(r(θ)*A, clip(r(θ), 1-ε, 1+ε)*A)]

GRPO目标: 
- 从旧策略采样G个输出
- 计算组内相对排名奖励
- 优势 = (r_i - μ_组) / σ_组
```

**核心优势:**
1. 无需Value网络，显存减少约40%
2. 组内相对比较，更稳定
3. 支持结果监督(Outcome Supervision)和过程监督(Process Supervision)

### 1.3 数学推导

设从旧策略π_θ_old采样G个输出{O_1, O_2, ..., O_G}，奖励为{r_1, r_2, ..., r_G}：

**标准化奖励:**
```
A_i = (r_i - μ) / σ
其中:
μ = (1/G) * Σr_j
σ = sqrt((1/G) * Σ(r_j - μ)²)
```

**GRPO目标函数:**
```
L_GRPO = (1/G) * Σ_i Σ_t min(
    π_θ(a_t|o_{i,<t}) / π_θ_old(a_t|o_{i,<t}) * A_i,
    clip(π_θ(a_t|o_{i,<t}) / π_θ_old(a_t|o_{i,<t}), 1-ε, 1+ε) * A_i
)
```

### 1.4 RLVR (Reinforcement Learning with Verifiable Rewards)

2025年最重要的技术趋势之一，特别适合推理模型：

- **可验证奖励**: 答案可判定的任务(如数学、代码)
- **无需Reward Model**: 直接验证输出正确性
- **训练更稳定**: 奖励信号清晰无噪声

### 2.2 Mamba核心原理

**状态空间方程:**
```
h'(t) = A*h(t) + B*x(t)  (状态更新)
y(t) = C*h(t) + D*x(t)   (输出)
```

**离散化形式 (Zero-Order Hold):**
```
h_t = Ā*h_{t-1} + B̄*x_t
y_t = C*h_t + D*x_t

其中:
Ā = exp(A*Δ)
B̄ = (A⁻¹ * (Ā - I)) * B * Δ
```

### 2.3 选择性机制 (Selective State Space)

Mamba的核心创新是引入了输入依赖的选择性：

```python
# 简化实现
class SelectiveSSM(nn.Module):
    def __init__(self, d_model, d_state=128):
        self.A = nn.Parameter(torch.randn(d_model, d_state))
        self.B = nn.Parameter(torch.randn(d_model, d_state))
        self.C = nn.Parameter(torch.randn(d_model, d_state))
        self.D = nn.Parameter(torch.zeros(d_model))
        
        # 选择性门控
        self.ssm_proj = nn.Linear(d_model, d_model * 3)
    
    def forward(self, x):
        # x: (batch, seq, d_model)
        s, i, o = self.ssm_proj(x).chunk(3, dim=-1)
        
        # 门控选择 - 关键创新
        B = i.unsqueeze(-1) * self.B  # 输入依赖
        C = s.unsqueeze(-1) * self.C  # 输入依赖
        
        # 扫描计算 (线性复杂度 O(n*d*d_state))
        h = torch.zeros_like(B[:, 0])
        ys = []
        for t in range(x.shape[1]):
            h = A_bar * h + B[:, t] * x[:, t]
            y = torch.sum(C[:, t] * h, dim=-1) + self.D * x[:, t]
            ys.append(y)
        
        return torch.stack(ys, dim=1)
```

## 三、混合专家模型(MoE)

### 3.1 DeepSeek-V3 MoE架构

**核心参数:**
- 总参数: 671B
- 激活参数: 37B (约5.5%)
- 专家数: 256个路由专家 + 1个共享专家
- 专家选择: Top-K (K=8)

### 3.2 架构图

```
输入Token
    ↓
[Router门控网络] → 选择Top-8专家
    ↓
┌────────────────────────────────────┐
│  共享专家(1个) - 始终激活           │
│  处理通用知识                        │
├────────────────────────────────────┤
│  路由专家(256个) - 选择性激活       │
│  处理特定任务                        │
└────────────────────────────────────┘
    ↓
专家输出加权求和
    ↓
输出
```

### 3.3 门控路由机制

**负载均衡损失:**
```
L_load = Σ_i (max_i / mean_i)²

目的: 防止某些专家被过度使用
```

**辅助损失 (Auxiliary Loss):**
```
L_aux = α * L_load + β * L_z_loss

z_loss: 防止logit数值爆炸
```

## 四、高效注意力机制

### 4.1 线性注意力发展

```
标准Attention: O(n²) → Flash Attention: O(n) → 线性注意力: O(n)
```

**线性注意力核近似:**
```
Attention(Q,K,V) = φ(Q) * (φ(K)ᵀ * V)ᵀ / (φ(K)ᵀ * 1)

其中 φ 是特征映射函数

常见选择:
- 指数核: φ(x) = exp(x)
- 随机特征: φ(x) = cos(Wx + b)
```

### 4.2 Flash Linear Attention (FLA)

2025年MLSys研究热点：

**Tiled Flash Attention:**
- 将序列分块处理
- 块内使用标准Attention
- 块间使用线性Attention

**门控注意力 (Gated Attention):**
- 引入非线性门控
- 稀疏性与非线性兼得
- Attention-Sink-Free

### 4.3 TurboAttention

**核心创新:**
1. **Token稀疏化**: 动态选择重要Token
2. **维度压缩**: K/V通道维度压缩
3. **与FlashAttention兼容**: 无缝集成

**性能提升:**
- 推理速度: 2-3x提升
- 显存: 减少40-60%

### 5.2 AWQ (Activation-aware Weight Quantization)

**核心思想:**
- 传统静态量化忽视激活值分布
- AWQ根据激活值分布调整量化参数
- 保护显著权重(Salient Weights)

**算法步骤:**
```python
def awq_quantize(W, scales=None):
    # 1. 计算每个通道的激活统计
    act_scale = torch.mean(torch.abs(W), dim=1)
    
    # 2. 根据激活缩放调整权重
    W_scaled = W / act_scale.unsqueeze(1)
    
    # 3. 量化到4-bit
    W_int = torch.round(W_scaled / scale).clamp(-8, 7)
    
    # 4. 反量化
    W_dequant = W_int * scale * act_scale.unsqueeze(1)
    
    return W_dequant
```

**实验结果:**
- 4-bit量化误差 < 1.2%
- 显存减少75%
- 推理速度提升3x

### 5.3 GPTQ (Generative Post-Training Quantization)

**核心创新:**
- 逐层量化，最小化输出重构误差
- 贪心优化每个权重
- 支持OPT-175B等超大模型

**数学推导:**
```
min ||W*X - W_q*X||²

其中 W_q 是量化后的权重
通过二阶泰勒展开近似优化
```

## 六、推理优化技术

### 6.1 投机解码 (Speculative Decoding)

**核心思想:**
- 用小模型(Draft)预测多个Token
- 大模型(Verify)批量验证
- 加速比可达2-3x

**流程图:**
```
Step 1: Draft模型生成 K 个候选Token
        [t1, t2, t3, ..., tK]
                  ↓
Step 2: Verify模型批量验证
        [✓, ✓, ✗, t4', ...]
                  ↓
Step 3: 接受正确Token，修正错误
        [t1, t2, t3, t4', ...]
```

### 6.2 2025年新进展

**Dovetail (EMNLP 2025):**
- CPU/GPU异构投机解码
- CPU处理轻量Draft
- GPU专注Verify

**关键挑战:**
1. Draft模型接受率低
2. 多模型通信开销大
3. 自回归与并行的平衡

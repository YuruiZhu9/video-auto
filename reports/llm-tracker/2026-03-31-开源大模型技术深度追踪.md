## 1.2 Gated DeltaNet 深度解析：线性注意力的"门控复兴"

### 1.2.1 从标准注意力到线性注意力的数学推导

**标准自注意力（O(n²)）：**

```
Attention(Q, K, V) = softmax(Q · K^T / √d) · V

展开形式：
o_t = Σᵢ₌₁ᵗ [exp(q_t^T k_i / √d) / Σⱼ exp(q_t^T k_j / √d)] · v_i
```

**线性注意力的核心：用核函数替换softmax**

引入核函数 φ(q) = elu(q) + 1，φ(k) = elu(k) + 1：

```
状态空间 S_t = Σᵢ₌₁ᵗ φ(k_i) ⊗ v_i    ← 累积kv信息
输出 o_t = φ(q_t)^T · S_t            ← O(n)复杂度
```

**但标准线性注意力有致命问题：** φ(k_i)对所有历史token等权重，无法区分"重要"和"不重要"的信息。

### 1.2.2 状态空间视角：递归形式的直观理解

```python
# 标准线性注意力（等权累积）
S_t = S_{t-1} + φ(k_t) ⊗ v_t    # 所有历史token被等权混合
```

**问题**：越早期的token被后续token不断"冲淡"，S_t中早期信息几乎不可见——这就是"精确检索困难"的数学本质。

### 1.2.3 Mamba-2的选择性状态空间（SSM）机制

Mamba-2引入了**选择性衰减**：

```python
# Mamba-2状态更新
h_t = Ā_t · h_{t-1} + B̄_t · x_t
Ā_t = exp(Δ_t · A)   # 选择性衰减，Δ_t是输入的函数
```

**关键洞察**：A不是固定值，而是通过Δ_t控制的输入函数。模型学会"选择性遗忘"不重要信息。

### 1.2.4 Gated DeltaNet的三重创新

Qwen3.5在Mamba-2基础上做了三个关键改进：

#### 创新一：L2归一化替代核函数

```python
# 替代传统ELU核函数
q_norm = normalize(q, p=2)   # q / √(Σq_i²)
k_norm = normalize(k, p=2)   # k / √(Σk_i²)
```

**数学性质**：
- 内积有界：q_norm^T · k_norm ∈ [-1, 1]
- 数值稳定：避免ELU在大值时饱和
- 本质：用向量方向（余弦相似度）而非模长来计算注意力

#### 创新二：双重门控机制（核心！）

**第一重：β门控（遗忘决策）**
```python
β_t = σ(W_β · x_t)    # sigmoid，输出∈(0,1)，决定是否保留
```

**第二重：g门控（精细衰减）**
```python
g_t = -exp(A_log) · softplus(W_g · x_t + d_bias^t)
λ_t = β_t · exp(g_t)    # 双重门控的乘积
```

**状态更新变为：**
```python
S_t = λ_t · S_{t-1} + k_t ⊗ v_t    # 有选择性的指数衰减
```

展开形式：
```
S_t = k_t⊗v_t + λ_t·k_{t-1}⊗v_{t-1} + λ_t²·k_{t-2}⊗v_{t-2} + ...
```

**直观理解**：
- β门控：决定"是否记住这个token"（开/关）
- g门控：决定"记住多少"（衰减速度）
- λ = β · exp(g)：既有硬开关，又有软衰减

#### 创新三：RMSNorm + Z-Gate输出门控

```python
o_t = RMSNorm(q_t^T · S_t) ⊙ silu(W_z · x_t)
```

- **RMSNorm vs LayerNorm**：只除以均方根，不计算均值，节省约50%归一化计算
- **Z-Gate（silu激活）**：对输出做动态缩放

### 1.2.5 Causal Conv1D：局部感知的必要补充

```python
# 在进入注意力之前，先做局部卷积
qkv_t = Conv1D(W_qkv · x_t)
# 参数：kernel_size=4，Depthwise，Causal padding=3
```

- 让每个token能"看到"最近4个token的局部上下文
- **类比**：Conv1D = "局部扫描仪"，Gated DeltaNet = "全局压缩仪"

### 1.2.6 并行训练：Chunk Parallel Scan

Gated DeltaNet的递归形式天然串行，GPU流水线有空泡。**Chunk Parallel Scan**解决：

```
原始序列: [x1 x2] [x3 x4] [x5 x6] [x7 x8]
           Chunk1  Chunk2  Chunk3  Chunk4

第一步（块内并行）: [S1-4] [S5-8]    ← 每个chunk内部并行
第二步（块间合并）: [S1-8]            ← 合并相邻chunk
```

- **串行步数**：n步 → **并行步数**：O(log n)
- 对8个token：从8步降到3步

### 1.2.7 Gated DeltaNet vs Mamba-2完整对比

| 维度 | Mamba-2 | Gated DeltaNet（Qwen3.5） |
|------|---------|--------------------------|
| Q/K处理 | ELU核函数 | L2归一化 |
| 门控机制 | 单一Δ参数 | 双重门控（β + g） |
| 衰减控制 | exp(Δ·A)，单一参数 | β · exp(g)，双重独立 |
| 输出门控 | 无 | RMSNorm + Z-Gate |
| 局部感知 | 可选Conv1D | 必选Causal Conv1D（kernel=4） |
| 验证规模 | 基础验证（<10B） | **大规模LLM验证（Qwen3.5-397B）** |
| 应用 | 独立模型 | Qwen3.5、Kimi Linear混合注意力 |

### 1.2.8 核心代码实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class GatedDeltaNetLayer(nn.Module):
    """
    Gated DeltaNet核心实现
    参考：Qwen3.5 + Mamba-2 + Gated Delta Networks
    """
    def __init__(self, d_model, d_state=128):
        super().__init__()
        self.d_model = d_model
        
        # 输入投影
        self.input_proj = nn.Linear(d_model, d_model * 3)  # QKV
        self.beta_proj = nn.Linear(d_model, 1)             # β门控
        self.g_proj = nn.Linear(d_model, 1)               # g门控
        self.z_proj = nn.Linear(d_model, d_model)         # Z-Gate
        self.A_log = nn.Parameter(torch.randn(d_model)) # 可学习衰减基准
        
        # Causal Conv1D
        self.conv = nn.Conv1d(d_model, d_model, kernel_size=4, 
                             padding=3, padding_mode='zeros')
        
    def forward(self, x):
        # 1. Causal Conv1D增强局部感知
        x_conv = self.conv(x.transpose(1,2)).transpose(1,2)[:, :x.size(1), :]
        
        # 2. QKV投影
        qkv = self.input_proj(x_conv)
        q, k, v = qkv.chunk(3, dim=-1)
        
        # 3. L2归一化（Qwen3.5核心创新）
        q = F.normalize(q, p=2, dim=-1)
        k = F.normalize(k, p=2, dim=-1)
        
        # 4. 双重门控
        beta = torch.sigmoid(self.beta_proj(x_conv))
        g = -torch.exp(self.A_log) * F.softplus(self.g_proj(x_conv))
        decay = beta * torch.exp(g)    # λ = β · exp(g)
        
        # 5. 递归状态更新（简化版本）
        outputs = []
        S_prev = torch.zeros_like(q)
        for t in range(x.size(1)):
            S_t = decay[:, t:t+1, :] * S_prev + k[:, t:t+1, :] * v[:, t:t+1, :]
            outputs.append(q[:, t:t+1, :] @ S_t.transpose(-2, -1))
            S_prev = S_t
        
        out = torch.cat(outputs, dim=1)
        
        # 6. RMSNorm + Z-Gate输出门控
        out_norm = out / (out.pow(2).mean(-1, keepdim=True).sqrt() + 1e-8)
        z = torch.silu(self.z_proj(x_conv))
        
        return out_norm * z
```

## 1.3 Gated Attention（全注意力层）：精度校验点

每4层Gated DeltaNet后，插入1层Gated Attention：

```python
class GatedAttention(nn.Module):
    """Qwen3.5的Gated Attention = 标准MHA + Q/K Norm + Output Gate"""
    def __init__(self, d_model, n_heads):
        super().__init__()
        self.attn = nn.MultiheadAttention(d_model, n_heads, batch_first=True)
        self.q_norm = RMSNorm()   # Q归一化
        self.k_norm = RMSNorm()   # K归一化
        self.gate_proj = nn.Linear(d_model, d_model)
        
    def forward(self, x):
        q = self.q_norm(self.q_proj(x))
        k = self.k_norm(self.k_proj(x))
        v = self.v_proj(x)
        
        attn_out, _ = self.attn(q, k, v)
        # Gated残差连接
        return torch.silu(self.gate_proj(attn_out)) * x + attn_out
```

**Q/K Norm的核心作用**：
- 训练稳定性提升
- 与Gated DeltaNet的L2归一化形成呼应
- 避免注意力分数数值爆炸

## 2.2 极坐标量化的几何直觉

### 从笛卡尔坐标到极坐标

**笛卡尔坐标系（标准表示）：**
```
v = (x, y, z, ...)     # 每个维度混在一起量化
```

**极坐标系（TurboQuant）：**
```
v → (θ₁, θ₂, ..., θ_{d-1}, r)
  - θ_i：方向角，近似均匀分布
  - r：模长，呈指数衰减分布
```

**几何直觉**：
- 方向角（θ）：近似均匀分布，量化误差=球面上微小位移，有界
- 模长（r）：呈指数分布，可用非均匀（log域）量化精确表示
- **关键发现**：极坐标变换后，量化误差与向量"重要性"解耦！

## 2.3 QJL无偏估计器：两行代码的革命性改进

### 问题

```
真实内积：q · k = ||q||·||k||·cos(θ_q - θ_k)
量化内积：q̂ · k̂ ≠ q · k（系统误差）
```

### Jensen-Logit-Joint估计器

```python
class QJLEstimator:
    """
    核心洞察：q·k的量化期望偏差 = sign(Δ · q^T) · bias
    bias是全局参数（每个量化bin一个），从验证集自动学习
    """
    def __init__(self, n_bins, d_model):
        self.bias = nn.Parameter(torch.zeros(n_bins))  # O(1)参数！
        
    def correct(self, q_quant, k_quant, q_mag, k_mag):
        joint_key = (q_quant * self.n_bins + k_quant).long()
        bias = self.bias[joint_key]  # 从全局bias表查表
        # E[q̂ · k̂] = q·k + bias（数学证明的无偏估计）
        return q_mag * k_mag * self.angular_part + bias
```

**为什么只用O(1)参数？** 传统方法对每个向量单独存储校准参数（O(n)存储）。QJL发现：旋转角度的方向偏差可以用一个**全局bin-level偏置表**建模，与向量数量无关！

## 3.2 RWKV-6核心方程

```python
# RWKV-6状态更新
# output_t = σ(W_r · x_t) ⊙ (W_k · x_t) + (1 - σ(W_r · x_t)) ⊙ state_{t-1}

def rwkv_step(x_t, state_prev, W_r, W_k, W_v, W_o):
    """
    x_t: 当前token嵌入向量
    state_prev: 上一时刻隐藏状态
    """
    r = torch.sigmoid(W_r @ x_t)           # 接收门控
    k = W_k @ x_t                          # 键向量
    v = W_v @ x_t                          # 值向量
    f = torch.sigmoid(W_f @ x_t)          # 遗忘门控
    
    # 选择性遗忘 + 选择性接受
    new_state = f * state_prev + r * v
    output = W_o @ new_state
    return output, new_state
```

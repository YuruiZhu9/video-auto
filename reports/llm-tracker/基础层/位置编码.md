# 位置编码（Positional Encoding）

## 一句话概括
位置编码通过为序列中的每个token添加位置信息，使Transformer能够理解词的顺序关系，是Attention机制能够处理序列数据的关键组件。

## 背景与动机

### 解决的问题
- **Attention的位置不变性**：标准的Self-Attention计算 $Attention(Q,K,V) = softmax(\frac{QK^T}{\sqrt{d_k}})V$ 中，注意力权重只与内容相关，与位置无关
- **序列顺序丢失**：如果没有位置信息，"狗咬人"和"人咬狗"对Attention来说是完全相同的
- **词序建模**：自然语言中词序承载着语法和语义信息

### 之前方法的不足
- **Learned Positional Embedding**：可学习但外推能力差，无法处理训练时未见过的更长序列
- **Sinusoidal编码**：固定不变，外推时存在位置编码值域问题

### 核心贡献
1. **Transformer原始Sinusoidal编码**：数学上优雅，可外推到任意长度
2. **RoPE旋转位置编码**：通过旋转矩阵实现位置信息，更适合自回归生成
3. **ALiBi线性偏置**：通过线性偏置实现位置信息，的外推能力强

## 数学原理

### 1. Sinusoidal位置编码（Transformer原始）

```math
PE_{(pos,2i)} = \sin(pos / 10000^{2i/d})
PE_{(pos,2i+1)} = \cos(pos / 10000^{2i/d})
```

其中：
- $pos$：token在序列中的位置（0, 1, 2, ...）
- $d$：embedding维度
- $i$：维度索引（0, 1, ..., d/2-1）

**物理意义**：不同频率的正弦波叠加，高频编码精细位置，低频编码粗糙位置。

### 2. RoPE旋转位置编码（2021）

**核心思想**：将位置信息编码为旋转矩阵，施加到Query和Key上。

```math
\begin{aligned}
\mathbf{q}_m^{(rot)} &= \mathbf{W}_q \mathbf{x}_m \cdot e^{im\theta} \\
\mathbf{k}_n^{(rot)} &= \mathbf{W}_k \mathbf{x}_n \cdot e^{in\theta}
\end{aligned}
```

更常用的向量形式：
```math
\mathbf{q}_m^{(rot)} = \mathbf{R}_m \mathbf{q}_m, \quad \mathbf{k}_n^{(rot)} = \mathbf{R}_n \mathbf{k}_n
```

其中旋转矩阵：
```math
\mathbf{R}_m = \begin{pmatrix}
\cos(m\theta) & -\sin(m\theta) \\
\sin(m\theta) & \cos(m\theta)
\end{pmatrix}
```

**相对位置性质**：
```math
\langle \mathbf{q}_m^{(rot)}, \mathbf{k}_n^{(rot)} \rangle = \langle \mathbf{q}_m, \mathbf{k}_n \rangle \cdot e^{i(m-n)\theta}
```

这意味着RoPE编码的注意力只依赖于相对位置 $(m-n)$！

### 3. ALiBi位置编码（2022）

**核心思想**：通过简单的线性偏置实现位置信息。

```math
Attention(Q,K,V) = softmax(\frac{QK^T}{\sqrt{d_k}} + m \cdot \mathbf{P})
```

其中：
- $\mathbf{P}_{i,j} = -|i-j|$：位置距离矩阵
- $m$：可学习的斜率参数（每层不同）

**无参数设计**：ALiBi不需要学习任何位置嵌入，天然支持超长序列外推。

### 复杂度分析

| 方法 | 参数量 | 外推能力 | 计算开销 |
|------|--------|---------|---------|
| Sinusoidal | 0 | 可外推 | 低 |
| Learned | d | 差 | 低 |
| RoPE | 0 | 中等 | 中等 |
| ALiBi | 0 | 强 | 低 |

## 代码实现

### RoPE完整实现

```python
import torch
import torch.nn as nn
import math

class RotaryPositionalEmbedding(nn.Module):
    """
    RoPE旋转位置编码实现
    
    核心原理：通过旋转矩阵将位置信息编码到Q/K向量中
    """
    def __init__(self, dim, max_seq_len=2048, base=10000):
        super().__init__()
        self.dim = dim
        self.base = base
        self.max_seq_len = max_seq_len
        
        # 预计算旋转角度 inv_freq = 1 / (base^(2i/dim))
        inv_freq = 1.0 / (self.base ** (torch.arange(0, self.dim, 2).float() / self.dim))
        self.register_buffer('inv_freq', inv_freq)
        
        # 预计算位置编码
        self._set_cos_sin_cache(max_seq_len)
    
    def _set_cos_sin_cache(self, seq_len):
        """预计算cos和sin值，避免重复计算"""
        self.max_seq_len_cached = seq_len
        t = torch.arange(self.max_seq_len_cached, device=self.inv_freq.device)
        
        # 外积：t[:, None] * inv_freq[None, :] 形成完整的位置×频率矩阵
        freqs = torch.einsum('i,j->ij', t, self.inv_freq)  # (seq_len, dim/2)
        
        # 拼接cos和sin
        emb = torch.cat([freqs, freqs], dim=-1)  # (seq_len, dim)
        
        self.register_buffer('cos_cached', emb.cos(), persistent=False)
        self.register_buffer('sin_cached', emb.sin(), persistent=False)
    
    def forward(self, seq_len):
        """返回cos和sin编码"""
        if seq_len > self.max_seq_len_cached:
            self._set_cos_sin_cache(seq_len)
        return self.cos_cached[:seq_len], self.sin_cached[:seq_len]


def rotate_half(x):
    """旋转半向量"""
    x1, x2 = x[..., :x.shape[-1]//2], x[..., x.shape[-1]//2:]
    return torch.cat([-x2, x1], dim=-1)


def apply_rotary_pos_emb(q, k, cos, sin, position_ids):
    """
    应用RoPE到Query和Key
    
    关键：位置编码需要根据position_ids动态选取
    """
    # Gather cos/sin at specific positions
    cos = cos[position_ids].unsqueeze(1)  # (batch, 1, seq_len, dim)
    sin = sin[position_ids].unsqueeze(1)
    
    # 应用旋转：q * cos + rotate_half(q) * sin
    q_embed = (q * cos) + (rotate_half(q) * sin)
    k_embed = (k * cos) + (rotate_half(k) * sin)
    
    return q_embed, k_embed


class RoPEMultiHeadAttention(nn.Module):
    """带RoPE的多头注意力"""
    def __init__(self, d_model, num_heads, dropout=0.1):
        super().__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        self.head_dim = d_model // num_heads
        
        self.q_proj = nn.Linear(d_model, d_model)
        self.k_proj = nn.Linear(d_model, d_model)
        self.v_proj = nn.Linear(d_model, d_model)
        self.o_proj = nn.Linear(d_model, d_model)
        
        self.rope = RotaryPositionalEmbedding(self.head_dim)
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, position_ids=None, attention_mask=None):
        batch_size, seq_len, _ = x.shape
        
        # 投影到Q/K/V
        q = self.q_proj(x).view(batch_size, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        k = self.k_proj(x).view(batch_size, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        v = self.v_proj(x).view(batch_size, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        
        # 应用RoPE
        cos, sin = self.rope(seq_len)
        q, k = apply_rotary_pos_emb(q, k, cos, sin, position_ids)
        
        # 计算注意力
        attn_weights = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(self.head_dim)
        
        if attention_mask is not None:
            attn_weights = attn_weights + attention_mask
        
        attn_weights = F.softmax(attn_weights, dim=-1)
        attn_weights = self.dropout(attn_weights)
        
        output = torch.matmul(attn_weights, v)
        output = output.transpose(1, 2).contiguous().view(batch_size, seq_len, self.d_model)
        
        return self.o_proj(output)
```

### ALiBi实现

```python
def build_alibi_bias(seq_len, num_heads, device='cuda'):
    """
    构建ALiBi注意力偏置矩阵
    
    ALiBi的核心：位置距离的负指数衰减
    """
    # 创建位置索引
    positions = torch.arange(seq_len, device=device)
    distance_matrix = positions.unsqueeze(0) - positions.unsqueeze(1)  # (seq_len, seq_len)
    distance_matrix = distance_matrix.abs().float()  # 取绝对值
    
    # 计算斜率（每层/头不同）
    # 论文中使用 2^(-8/n), 2^(-16/n), ... 几何级数
    slopes = torch.tensor([2 ** (-(2 ** -(math.log2(num_heads) - i))) 
                          for i in range(num_heads)], device=device)
    
    # 构建偏置：-|i-j| * slope
    alibi = -distance_matrix.unsqueeze(0) * slopes.view(1, num_heads, 1, 1)
    
    return alibi  # (1, num_heads, seq_len, seq_len)
```

## 架构分析

### RoPE数据流

```
输入Token序列
     ↓
[Embedding Layer]
     ↓
    x = [x_0, x_1, x_2, ..., x_n]
     ↓
[Q/K投影] → Q, K
     ↓
[RoPE旋转] → Q_rot, K_rot（乘旋转矩阵）
     ↓
[注意力计算] → attention(Q_rot, K_rot, V)
     ↓
[输出]
```

### 不同位置编码对比

| 特性 | Sinusoidal | Learned | RoPE | ALiBi |
|------|------------|---------|------|-------|
| 可学习 | 否 | 是 | 否 | 否 |
| 外推能力 | 好 | 差 | 好 | 最好 |
| 相对位置 | 否 | 隐式 | 是 | 是 |
| 计算开销 | 低 | 低 | 中 | 低 |
| 适用场景 | 编码器 | 短序列 | 自回归 | 超长上下文 |

# 激活函数（Activation Functions）

## 一句话概括
激活函数为神经网络引入非线性，是深度学习模型能够拟合复杂函数的关键组件。在大语言模型中，激活函数的选择直接影响模型的表达能力、训练稳定性和推理效率。

## 背景与动机

### 解决的问题
- **非线性建模**：没有激活函数，多层神经网络退化为单层线性变换
- **梯度流动**：合适的激活函数确保深层网络的梯度有效传播
- **稀疏表示**：某些激活函数可以产生稀疏激活，提高效率和泛化

### 之前方法的不足
- **Sigmoid/Tanh**：饱和梯度消失，计算开销大
- **ReLU**： Dying ReLU问题，负区间输出为0

### 核心贡献
1. **SwiGLU**：门控机制 + Swish激活，Meta LLaMA采用
2. **GeGLU**：GELU门控，PaLM采用
3. **GeLU**：Gaussian Error Linear Unit，Transformer标配

## 数学原理

### 1. GELU (Gaussian Error Linear Unit)

**Transformer标准激活函数**：

```math
\text{GELU}(x) = x \cdot \Phi(x)
```

其中 $\Phi(x)$ 是标准正态分布的CDF：

```math
\Phi(x) = \frac{1}{2}[1 + \text{erf}(\frac{x}{\sqrt{2}})]
```

**近似形式**（实际使用）：
```math
\text{GELU}(x) \approx 0.5x(1 + \tanh[\sqrt{2/\pi}(x + 0.044715x^3)])
```

**物理意义**：GELU根据输入值动态决定激活程度，类似于一种"软"的ReLU。

### 2. Swish

**Google Brain 2017提出**：

```math
\text{Swish}(x) = x \cdot \sigma(\beta x) = \frac{x}{1 + e^{-\beta x}}
```

其中 $\beta$ 是可学习参数（通常设为1）。

**特点**：
- 平滑、非单调
- 在深层网络中效果优于ReLU
- 计算开销略大于ReLU

### 3. SwiGLU（门控线性单元 + Swish）

**Meta LLaMA采用**：

```math
\text{SwiGLU}(x) = \text{Swish}(x) \odot \sigma(W_3 x)
```

完整实现：
```math
\text{SwiGLU}(x) = (W_1 x) \odot \sigma(W_2 x)
```

**核心思想**：用Swish作为门控激活函数，类似于LSTM的门机制。

### 4. GeGLU

**PaLM采用**：

```math
\text{GeGLU}(x) = \text{GELU}(W_1 x) \odot (V x)
```

### 5. SiLU (Sigmoid Linear Unit)

**Swish的另一种叫法**：
```math
\text{SiLU}(x) = x \cdot \sigma(x) = \frac{x}{1 + e^{-x}}
```

## 代码实现

### GELU实现

```python
import torch
import torch.nn as nn
import math

class GELU(nn.Module):
    """
    GELU激活函数的两种实现
    """
    def __init__(self, approximate='none'):
        super().__init__()
        self.approximate = approximate
    
    def forward(self, x):
        if self.approximate == 'none':
            # 精确实现（较慢）
            return 0.5 * x * (1 + torch.erf(x / math.sqrt(2)))
        elif self.approximate == 'tanh':
            # 快速近似（常用）
            return 0.5 * x * (1 + torch.tanh(math.sqrt(2 / math.pi) * 
                              (x + 0.044715 * torch.pow(x, 3))))
        else:
            raise ValueError(f"Unknown approximate: {self.approximate}")


# PyTorch内置实现
gelu = nn.GELU()  # 等价于上面的精确实现
fast_gelu = nn.GELU(approximate='tanh')  # 快速版本
```

### SwiGLU实现

```python
class SwiGLU(nn.Module):
    """
    SwiGLU激活函数
    
    公式：SwiGLU(x) = (W_1 x) ⊙ σ(W_2 x)
    
    特点：
    - 需要三个投影矩阵（W_1, W_2, W_3）
    - 类似于LSTM的门控机制
    - Meta LLaMA系列采用
    """
    def __init__(self, d_model, ffn_dim, bias=True):
        super().__init__()
        # 三个线性层
        self.w1 = nn.Linear(d_model, ffn_dim, bias=bias)  # Swish门控
        self.w2 = nn.Linear(d_model, ffn_dim, bias=bias)  # Sigmoid门控
        self.w3 = nn.Linear(ffn_dim, d_model, bias=bias)  # 输出投影
    
    def forward(self, x):
        """
        前向传播
        
        Args:
            x: (batch, seq_len, d_model)
        Returns:
            (batch, seq_len, d_model)
        """
        # Swish: silu(x) = x * sigmoid(x)
        swish = F.silu(self.w1(x))  # (batch, seq_len, ffn_dim)
        
        # Sigmoid门控
        sigmoid = self.w2(x)  # (batch, seq_len, ffn_dim)
        sigmoid = torch.sigmoid(sigmoid)
        
        # 逐元素相乘（门控）
        hidden = swish * sigmoid  # (batch, seq_len, ffn_dim)
        
        # 输出投影
        return self.w3(hidden)


class SwiGLUWithBias(nn.Module):
    """
    更高效的SwiGLU实现（合并投影）
    """
    def __init__(self, d_model, ffn_dim, bias=True):
        super().__init__()
        # 合并w1和w2为一个投影，更节省显存
        self.gate_proj = nn.Linear(d_model, ffn_dim * 2, bias=bias)
        self.up_proj = nn.Linear(ffn_dim, d_model, bias=bias)
    
    def forward(self, x):
        # 一次投影得到门控和输入
        gate_and_up = self.gate_proj(x)  # (batch, seq_len, ffn_dim * 2)
        
        # 分割
        gate, up = gate_and_up.chunk(2, dim=-1)
        
        # SwiGLU: silu(gate) * up
        return self.up_proj(F.silu(gate) * up)
```

### GeGLU实现

```python
class GeGLU(nn.Module):
    """
    GeGLU激活函数
    
    公式：GeGLU(x) = GELU(W_1 x) ⊙ (V x)
    
    特点：
    - Google PaLM采用
    - 两套投影
    """
    def __init__(self, d_model, ffn_dim, bias=True):
        super().__init__()
        self.w1 = nn.Linear(d_model, ffn_dim, bias=bias)
        self.v1 = nn.Linear(d_model, ffn_dim, bias=bias)
        self.w3 = nn.Linear(ffn_dim, d_model, bias=bias)
    
    def forward(self, x):
        # GELU门控
        gelu = F.gelu(self.w1(x))
        # 线性变换
        up = self.v1(x)
        # 逐元素相乘
        hidden = gelu * up
        return self.w3(hidden)
```

### FFN层对比实现

```python
class StandardFFN(nn.Module):
    """标准FFN: GELU(W_2 * GELU(W_1 x))"""
    def __init__(self, d_model, ffn_dim):
        super().__init__()
        self.w1 = nn.Linear(d_model, ffn_dim)
        self.w2 = nn.Linear(ffn_dim, d_model)
    
    def forward(self, x):
        return self.w2(F.gelu(self.w1(x)))


class SwiGLUFFN(nn.Module):
    """SwiGLU FFN: (W_1 x) ⊙ σ(W_2 x) → W_3"""
    def __init__(self, d_model, ffn_dim):
        super().__init__()
        self.w1 = nn.Linear(d_model, ffn_dim, bias=False)
        self.w3 = nn.Linear(ffn_dim, d_model, bias=False)
        # QLoRA等场景可能保留bias
        self.w2 = nn.Linear(d_model, ffn_dim, bias=True)
    
    def forward(self, x):
        return self.w3(F.silu(self.w1(x)) * self.w2(x))


class GeGLUFFN(nn.Module):
    """GeGLU FFN: GELU(W_1 x) ⊙ (V x) → W_3"""
    def __init__(self, d_model, ffn_dim):
        super().__init__()
        self.w1 = nn.Linear(d_model, ffn_dim)
        self.v1 = nn.Linear(d_model, ffn_dim)
        self.w3 = nn.Linear(ffn_dim, d_model)
    
    def forward(self, x):
        return self.w3(F.gelu(self.w1(x)) * self.v1(x))
```

## 架构分析

### FFN中的激活函数位置

```
输入 x
  ↓
[W1] → GELU/SwiGLU → ⊙ [W2] → [W3] → 输出
  ↓                      ↑
  +----------------------+
  (门控机制)
```

### 不同FFN配置对比

| 配置 | 激活函数 | 投影数 | 典型模型 |
|------|---------|--------|---------|
| 标准 | GELU | 2 | BERT, GPT |
| SwiGLU | SiLU | 3 | LLaMA, Qwen |
| GeGLU | GELU | 3 | PaLM |
| SwiGLU(合并) | SiLU | 2 | 高效实现 |

### 参数量对比

假设 d_model=4096, ffn_dim=11008：

| FFN类型 | 参数量 | 相对比例 |
|---------|--------|---------|
| 标准GELU | 4096×11008 + 11008×4096 ≈ 90M | 1.0x |
| SwiGLU | 3×4096×11008 ≈ 135M | 1.5x |
| GeGLU | 3×4096×11008 ≈ 135M | 1.5x |

## 代表模型

### 1. LLaMA系列
- **激活函数**：SwiGLU
- **FFN维度**：4 × d_model
- **特点**：高效的门控机制

### 2. Qwen系列
- **激活函数**：SwiGLU（Qwen2开始）
- **特点**：支持长上下文

### 3. DeepSeek系列
- **激活函数**：GELU（V2开始支持SwiGLU可切换）
- **特点**：MLA + SwiGLU

### 4. GPT系列
- **激活函数**：GELU
- **特点**：标准配置

### 5. PaLM
- **激活函数**：GeGLU
- **特点**：Google最强模型

## 📰 TechCrunch / 海外 AI 动态（今日重点）

### 🔴 OpenAI × Anthropic：codex-plugin-cc 世纪联手
**发布时间：2026年3月30日**
OpenAI 在 GitHub 悄然上线 codex-plugin-cc 插件，首次主动将自家编程工具 Codex 接入 Anthropic 的 Claude Code 生态：

- `/codex: review` — 标准代码审查，支持分支对比和后台运行
- `/codex: adversarial-review` — 对抗性审查，主动挑战代码实现思路和隐藏假设
- `/codex: rescue` — 任务移交，可将整个任务交给 Codex 接管

**市场背景**：Claude Code 年收入25亿美元（占 Anthropic 总收入13%），月访问量176万，VS Code 数据显示41%专业开发者使用 Claude Code，在200人以下公司比例飙升至75%。

**战略意义**：OpenAI 通过插件触达 Claude Code 庞大用户群；另透露计划将 Codex 和 ChatGPT 合并为"超级应用"，预计2026年下半年推出。

### 🔴 OpenAI 正式关停 Sora
**发布时间：2026年3月24-25日**
OpenAI 宣布关闭 Sora、Sora 2 以及相关 API 接口，Sora app 和 sora.com 均将停用：
- 核心原因：算力成本极高，盈利前景不明朗
- 运营时长：约7个月（Sora 2 于2025年9月底上线）
- 市场影响：留下视频生成市场空白，xAI Grok Imagine、字节 Seedance、快手可灵等迎来机会

### 🟡 微软 Copilot 升级：多模协作智能体
**发布时间：2026年3月**
微软推出"多模协作"深度研究智能体：
- **Critique 工作流**：一个模型起草，一个模型审查
- **Council 功能**：并排对比多个模型输出
- 扩展 Copilot Cowork 访问权限，GPT 与 Claude 可并肩干活

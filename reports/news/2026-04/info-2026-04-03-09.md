- 目标：从"人操作手机"→"AI 代为操作"的交互范式转变
- TOP 5 手机大厂也在洽谈类似合作

- 上下文窗口 200k，深度适配 Claude Code / OpenClaw 龙虾框架
- 在 AndroidWorld、WebVoyager 等基准测试领先，已开放 MaaS 平台接入

## 🌍 海外 AI 动态（重点公司）

### Google — Gemma 4 突袭发布（4月2日）
- **Gemma 4** 系列：2B / 4B / 27B (MoE) / 31B 四种规格
- **31B 版本性能**：位列全球开源榜单第三，以小博大超越 20 倍参数量对手
- **许可变更**：首次全面切换 **Apache 2.0**（此前为限制性自研协议），真正开源
- **端侧支持**：量化后消费级显卡可跑，手机离线部署成为可能
- 同期有 Gemma 4 官宣预告（参数量翻 4 倍）信息提前泄露

### Microsoft — MAI 三款模型全面商用（4月2日）
| 模型 | 能力 | 亮点 |
|------|------|------|
| MAI-Transcribe-1 | 语音转文字 | 多语言错误率 3.9%，优于 OpenAI GPT-Transcribe (4.2%) |
| MAI-Voice-1 | 语音生成 | 单 GPU 1秒生成60秒音频，支持定制语音克隆 |
| MAI-Image-2 | 文生图 | Copilot 已上线，"大模型竞技场"排名第三 |

- 目标：**2027年实现完全自主的前沿大模型**（不再依赖 OpenAI）
- 背景：去年10月与 OpenAI 重构合作协议，获独立追求 AGI 权利
- 资本支出：2026年 **349 亿美元**，AI 算力拟提升超 80%

### Anthropic — Claude Code 源码泄露事件（4月1~2日）
- **事故原因**：3月31日发布 Claude Code v2.1.88 时，npm 包中附带了未清理的 .map 文件，指向云存储完整源码
- **泄露规模**：512,000 行 TypeScript，1900 个文件
- **暴露秘密**：发现 44 个隐藏功能，包括代号"KAIROS"的永远在线代理、多代理协调架构等
- **安全风险**：GitHub 上出现冒名钓鱼陷阱，黑客借机攻击开发者
- **一周二次事故**：此前因 CMS 配置错误，近 3000 份内部文件（含未发布 Claude Mythos 模型）已泄露
- 社区反响：GitHub 已出现 `catyans/claude-code-source-analysis` 逆向分析项目

### OpenAI — 收购 TBPN 播客（4月2日）
- 宣布收购科技商业播客 **TBPN**（Technology Business Programming Network），交易金额**数亿美元**
- TBPN 曾专访马克·扎克伯格、纳德拉、山姆·奥特曼、詹姆斯·卡梅隆等
- 收购后保持编辑独立性，团队加入 OpenAI 市场传播部门
- 同时：**OpenAI 在二级市场热度下滑**，投资者转向 Anthropic

### Nvidia — 传收购 Groq（4月2日）
- 据 TechCrunch 报道，Nvidia 拟以 **200 亿美元**收购 AI 芯片挑战者 Groq
- Nvidia 将获得 Groq 技术并聘请其 CEO，强化 AI 推理芯片布局
- Groq 以 LPU（语言处理单元）著称，在推理速度上对标 Nvidia

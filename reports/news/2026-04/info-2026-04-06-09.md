## 📡 AIbase 实时资讯（4月5–6日）

### 今日热点

**🔴 Anthropic 封杀 OpenClaw：AI Coding 生态战白热化**
- **事件**：Anthropic 自 4月4日（美东15:00）起，禁止第三方 Agent（包括 OpenClaw"龙虾"）使用 Claude 订阅额度调用接口，用户须切换为单独按量付费
- **时机**：OpenClaw 创始人 Peter Steinberger 刚宣布加入 OpenAI，双方正面交锋
- **评价**：OpenAI 反而开门——明确允许 Codex 订阅在 OpenClaw 等第三方客户端使用，并宣布向开源维护者免费提供 Pro 权限
- **影响**：订阅"无限畅吃"时代终结，AI Coding 工具之战从产品竞争升级为生态控制权争夺

**🟡 Meta Llama 4：4000亿参数开源，向闭源宣战**
- **发布时间**：4月4日深夜
- **规格**：4000亿参数 / 170亿激活参数 / 128个专家模块 / MoE 架构
- **许可证**：Apache 2.0（完全免费可商用）
- **亮点**：支持千万级 Token 超长上下文（Scout 版），支持 AI 编程等垂直场景深度微调
- **意义**：企业可基于 Llama 4 构建完全独立的 AI Coding 基础设施，彻底绕开 Anthropic/OpenAI 授权体系

**🟡 OpenAI Codex 插件 for Claude Code：精准接盘**
- **发布**：4月4日，codex-plugin-cc 开源（Apache 2.0）
- **功能**：让 Claude Code 用户直接在工具流中调用 OpenAI Codex 处理代码审查和任务委托
- **数据**：上线半天 GitHub 获 3200+ Stars

**🟢 阿里通义 Wan2.7-Video 视频生成模型发布**
- **核心**：支持文本/图像/视频/音频全模态输入，用户可精准控制视频元素（删除路人、替换物体）
- **意义**：视频创作自由度大幅提升

**🟢 红果短剧 AI 短剧《桃花簪》下架**
- **原因**：涉及未经授权使用博主面部形象（"盗脸"侵权）
- **处罚**：出品方被暂停上传15天
- **意义**：AI 肖像权侵权法律边界引发行业讨论

**🟢 腾讯云推出 OpenClaw"龙虾"记忆服务**
- **服务名**：TencentDB Agent Memory
- **架构**：四层渐进式记忆系统
- **效果**：OpenClaw 回答准确率达 76.10%，较原记忆系统提升约 59%

## 📰 TechCrunch / The Verge（4月5–6日）

> 来源：The Verge（4月3日）、博客园 AI 资讯速递

**🔴 Nvidia GTC 2026：发布 Agent Toolkit，17 家企业签约**
- Jensen Huang 在 GTC 大会上发布开源 AI Agent 平台 Agent Toolkit
- 包含：Nemotron 开放模型、AI-Q 混合推理蓝图、OpenShell 安全运行时、cuOpt 优化库
- 17 家企业签约：Adobe、Salesforce、SAP、ServiceNow、Siemens、CrowdStrike 等
- AI-Q 混合架构：复杂任务路由至前沿模型，研究任务委托给 Nemotron，号称降低 50%+ 查询成本

**🟡 微软自研三款 AI 模型，直指 OpenAI**
- **MAI-Transcribe-1**：语音转文字，25种语言词错率 3.8%，超越 Whisper-large-v3
- **MAI-Voice-1**：文本转语音，1秒生成60秒自然语音，支持数秒音频克隆
- **MAI-Image-2**：图像生成，速度提升2倍，已部署至 Bing 和 PowerPoint
- **背景**：Mustafa Suleyman 透露，去年9月与 OpenAI 重签合同后，微软首次获得独立研发 AGI 的权利

**🟡 AI 数据供应商 Mercor 遭安全入侵**
- 疑似 TeamPCP 组织通过 LiteLLM 漏洞发起攻击
- 可能泄露 OpenAI、Anthropic 等客户的专有训练数据和模型训练方式
- Meta 已无限期暂停与 Mercor 合作；OpenAI 正在评估影响
- 被泄露数据含 200+ GB 数据库、近 1 TB 源代码、3 TB 视频

**🟢 Google Gemma 4 改用 Apache 2.0 许可证**
- 放弃此前受争议的自定义许可证，商业使用更自由
- 性能：单 GPU 环境声称优于 Llama、DeepSeek、OpenAI 同类模型

**🟢 Arcee 开源 Trinity-Large-Thinking**
- 3990亿参数推理模型（Apache 2.0），仅30人团队
- MoE 架构，每 Token 仅激活 156亿参数，推理速度为同类模型 2–3 倍

**🟢 Slack 发布最大规模 AI 更新**
- Slackbot 新增 30 项 AI 功能
- Salesforce 内部估算：员工每周节省最多 20 小时，生产力价值超 640 万美元

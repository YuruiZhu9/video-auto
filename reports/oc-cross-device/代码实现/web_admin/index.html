📚 接口文档

📰 REST API 示例

# 发送钉钉消息 curl -X POST http://localhost:18790/api/v1/message \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{"channel":"dingtalk","message":"Hello from OC-Ctrl!"}'

🌏 发送飞书卡片

curl -X POST http://localhost:18790/api/v1/notify \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{"channel":"feishu","template":"task_complete","task_name":"测试","duration":3.2}'

 触发 Agent

curl -X POST http://localhost:18790/api/v1/spawn \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{"task":"生成今日技术简报","runtime":"subagent"}'

⏰ 创建定时任务

curl -X POST http://localhost:18790/api/v1/scheduler/jobs \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{"name":"晨报","template_id":"quick_fetch","cron_expr":"0 8 * * *"}'

📋 获取任务列表

curl http://localhost:18790/api/v1/tasks \ -H "Authorization: Bearer YOUR_API_KEY"

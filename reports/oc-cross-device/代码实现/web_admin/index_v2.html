📷 iOS 快捷指令 URL 方案

在 iOS 快捷指令中使用「打开 URL」调用：

# 触发快速抓取 clawctl://run?template=quick_fetch&api_key=YOUR_KEY # 发送钉钉消息 clawctl://message?text=Hello&channel=dingtalk&api_key=YOUR_KEY # 查看状态 clawctl://status?api_key=YOUR_KEY
📱 Android Tasker 场景

使用 HTTP Request Tasker 插件：

URL: http://YOUR_SERVER:18790/api/v1/spawn Method: POST Headers: Authorization: Bearer YOUR_KEY Body: {"template_id":"quick_fetch","task_name":"快速抓取"}

- **生产环境**：Ubuntu 20.04 / CentOS 7.9+，建议创建专用用户 `openclaw`

### 2.2 定时任务（Cron）配置
- **四种配置方式**：
  1. `openclaw cron add` 命令（推荐）
  2. 手动编辑 `~/.openclaw/cron/jobs.json`
  3. Web 控制台 → 任务调度 → Quartz 七位格式 Cron 表达式
  4. CLI 工具 `clawctl sch`
- **三种定时任务类型**：
  - 独立 Cron 任务（最简单，推荐）
  - Heartbeat 心跳机制（适合高频监控）
  - 专属 OpenClaw Extension（适合高稳定性需求）

### 2.3 SubAgent 子代理（多 Agent）

## 三、高频问题汇总

| 问题类型 | 解决方案 |
|---------|---------|
| CUDA 初始化失败 | 检查 nvidia-smi、nvcc 版本及 torch.cuda.is_available() |
| ClawModule 加载失败 | 确认安装方式，重新安装对应模块 |
| Node.js 版本不兼容 | 升级到 v22.14+ 或 v24 |
| npm 权限问题（EACCES） | 使用 nvm 或调整 npm prefix 路径 |
| 端口 18789 被占用 | 检查进程 `lsof -i :18789`，确认防火墙配置 |
| 百炼 API-Key 格式错误 | 核对 API Key 格式与权限配置 |
| 插件迁移崩溃 | 2026.3.7 新版本已知问题，建议回退或等补丁 |

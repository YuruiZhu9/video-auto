# OpenClaw 配置周刊 - 2026-03-05

## 📖 官方文档更新

### 核心架构
OpenClaw 是一个适用于任何操作系统的 AI 智能体 Gateway 网关，支持 WhatsApp、Telegram、Discord、iMessage 等多种渠道。通过单个 Gateway 网关进程将聊天应用连接到 Pi 等编程智能体。

**快速开始（三步走）：**
```bash
# 1. 安装
npm install -g openclaw@latest

# 2. 新手引导并安装服务
openclaw onboard --install-daemon

# 3. 配对渠道并启动
openclaw channels login
openclaw gateway --port 18789
```

### 配置文件位置
- 主配置：`~/.openclaw/openclaw.json`
- 环境变量：`~/.openclaw/.env`
- Workspace：`~/.openclaw/workspace/`

## 🔧 配置技巧

### 国内大模型配置

**方案 A：阿里云百炼（通义千问）**
```bash
# 设置百炼 API 密钥
openclaw config set models.providers.bailian.accessKeyId "your_id"
openclaw config set models.providers.bailian.accessKeySecret "your_secret"

# 设置默认模型
openclaw config set agents.defaults.model.primary "bailian/qwen3-turbo-2026-01-23"
```

**方案 B：DeepSeek**
```bash
# 配置默认模型
openclaw config set agents.defaults.model.primary "deepseek/deepseek-reasoner"
```

**方案 C：Moonshot (Kimi)**
```bash
# 编辑配置文件
openclaw configure --section models
```
配置示例：
```json
{
  "env": { "MOONSHOT_API_KEY": "sk-你的key" },
  "models": {
    "providers": {
      "moonshot": {
        "baseUrl": "https://api.moonshot.cn/v1",
        "apiKey": "${MOONSHOT_API_KEY}",
        "models": [{ "id": "kimi-k2.5", "name": "Kimi K2.5", "contextWindow": 256000 }]
      }
    }
  }
}
```

### 非交互模式（自动化部署）
```bash
openclaw onboard --non-interactive \
  --mode local \
  --auth-choice moonshot-api-key \
  --moonshot-api-key "$MOONSHOT_API_KEY" \
  --gateway-port 18789 \
  --gateway-bind loopback \
  --install-daemon \
  --daemon-runtime node \
  --skip-skills
```

## ❓ 常见问题与解决

| 问题 | 解决方案 |
|------|----------|
| 发消息没反应 | 检查 Gateway 运行状态：`openclaw gateway status` |
| 能回复但执行报错 | 检查模型 API Key 有效性、sandbox 配置 |
| Gateway 启动失败 | 检查 18789 端口是否被占用 |
| 安装卡住/Network Error | 使用国内镜像：`npm config set registry https://registry.npmmirror.com` 或安装 `openclaw-cn` |
| Invalid API Key | 确认云服务商账户有余额，阿里云需完成实名认证 |

### 故障排查清单
1. ✅ Node.js 版本 >= 22？
2. ✅ Gateway 是否在运行？
3. ✅ 模型 API Key 是否有效？
4. ✅ Channel 是否连接？
5. ✅ Pairing 是否已批准？
6. ✅ 运行 `openclaw doctor` 检查配置

### 安全建议
1. **最小权限原则**：使用 sandbox 配置限制 Agent 权限
2. **不暴露公网**：Gateway 绑定 127.0.0.1（本地）
3. **敏感信息管理**：使用环境变量，不要把 Key 写进公开配置
4. **高风险动作二次确认**：配置审批流程
5. **定期安全检查**：`openclaw security audit --deep`

## 🔧 配置技巧

### 快速安装（1 分钟搞定）
```bash
# 使用国内镜像
npm config set registry https://registry.npmmirror.com
npm install -g openclaw@latest
openclaw onboard --install-daemon
```

### 多实例部署
```bash
# 隔离配置和端口
OPENCLAW_CONFIG_PATH=~/.openclaw/a.json \
OPENCLAW_STATE_DIR=~/.openclaw-a \
openclaw gateway --port 19001
```

### 常用命令
- `openclaw status` - 查看状态
- `openclaw health` - 健康检查
- `openclaw gateway start/stop/restart` - Gateway 管理
- `openclaw doctor` - 诊断问题
- `openclaw security audit --deep` - 安全审计

### 配置文件位置
- 主配置：`~/.openclaw/openclaw.json`
- 环境变量：`~/.openclaw/.env`

## ❓ 常见问题与解决

### 1. 安装卡住
**解决方案**: 使用国内 npm 镜像
```bash
npm config set registry https://registry.npmmirror.com
```

### 2. 报错：auth.profiles.ollama:default.mode: Invalid input
**来源**: 博客园 - 念槐聚
**解决方案**: 检查配置文件格式，确保 JSON 语法正确

### 3. 浏览器功能 token 校验失败
**解决方案**: 重装 gateway-service 服务
```bash
openclaw gateway restart
```

### 4. Control UI 访问报错 (4008)
**解决方案**: 
- 清理 Chrome 缓存
- 或改用 Safari 浏览器
- 检查 Gateway 服务状态

### 5. 长任务易卡死
**说明**: OpenClaw 处理复杂任务的能力取决于所接入的大模型。长任务易卡死是其架构固有的局限，它更像一个"任务编排框架"，最终表现看背后模型的"工具调用"稳定性。

### 钉钉配置完整步骤

1. **安装钉钉插件**
   ```bash
   openclaw plugins install dingtalk
   ```

2. **配置权限**
   - 需要添加权限点：`Card.Streaming.Write`、`Card.Instance.Write`、`qyapi_robot_sendmsg`
   - 获取 Client ID 和 Client Secret

3. **手动编辑配置**
   ```bash
   vim ~/.openclaw/openclaw.json
   ```
   在 `channels/dingtalk-connector`、`gateway/auth`、`gateway/http/endpoints` 中添加配置

4. **重启验证**
   ```bash
   openclaw gateway restart
   curl http://127.0.0.1:18789/health
   ```

### 浏览器扩展配置

1. 在 Chrome 应用商店搜索「OpenClaw Browser Relay」并安装
2. 在 OpenClaw Web UI → Overview 中获取 Gateway Token
3. 打开插件并输入 Token
4. 开启 Chrome 开发者模式：`chrome://extensions/`
5. 验证：访问任意页面，点击插件图标显示「ON」即正常工作

## ❓ 常见问题与解决

| 问题 | 解决方案 |
|------|----------|
| 安装卡住 | 使用国内镜像：`npm config set registry https://registry.npmmirror.com` |
| 发消息没反应 | 检查 Gateway 状态：`openclaw gateway status` |
| 钉钉 405 错误 | 在配置中启用 chatCompletions 端点 |
| 钉钉 401 错误 | 检查 gateway.auth 中的 token/password |
| AI Card 不显示 | 开通权限 `Card.Streaming.Write` 和 `Card.Instance.Write` |
| 升级后插件异常 | 清除旧插件并重新安装 dingtalk |
| 图片不显示 | 确认 `enableMediaMediaUpload: true` |

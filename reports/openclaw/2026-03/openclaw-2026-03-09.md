## 🔧 配置技巧

### 1. 定时任务 (Cron Jobs) 最佳实践

**存储位置：**
- 任务存储：`~/.openclaw/cron/jobs.json`
- 运行历史：`~/.openclaw/cron/runs/.jsonl`

**三种调度类型：**
| 类型 | 参数 | 适用场景 |
|------|------|----------|
| `at` | `--at` | 一次性提醒 |
| `every` | `--every` | 固定间隔轮询 |
| `cron` | `--cron` | 周期性任务 |

**CLI 快速创建定时任务：**
```bash
# 每日早上7点运行隔离任务，推送到 Slack
openclaw cron add \
  --name "Morning brief" \
  --cron "0 7 * * *" \
  --tz "Asia/Shanghai" \
  --session isolated \
  --message "Summarize today's AI news" \
  --announce \
  --channel slack \
  --to "channel:C1234567890"

# 20分钟后提醒
openclaw cron add \
  --name "Reminder" \
  --at "2026-03-09T22:50:00+08:00" \
  --session main \
  --system-event "Reminder: check the cron docs" \
  --wake now \
  --delete-after-run
```

### 2. 多 Agent 路由配置

**核心概念：**
- `agentId`: 独立的大脑（workspace + auth + session）
- `accountId`: 渠道账号实例
- `binding`: 消息路由规则

**快速开始：**
```bash
# 创建 Agent 工作空间
openclaw agents add coding
openclaw agents add social

# 绑定到不同渠道
openclaw channels login --channel whatsapp --account work
```

**路由优先级：**
1. peer 匹配（精确 DM/群组 ID）
2. accountId 匹配
3. 渠道级别匹配
4. 回退到默认 Agent

### 3. 钉钉配置（国内用户）

**配置示例：**
```json
{
  "channels": {
    "dingtalk": {
      "enabled": true,
      "allowFrom": ["会话ID1", "会话ID2"]
    }
  }
}
```

**常见问题：**
- 405 错误：确保启用 chatCompletions 端点
- 401 错误：检查 gateway.auth 中的 token/password

## ❓ 常见问题与解决

### 1. 权限问题（2026.3.2+ 新版）
- **症状**：工具调用被拒绝
- **解决**：
```bash
openclaw config set tools.profile coding
openclaw config set tools.allow '[]'
openclaw gateway restart
```

### 2. 浏览器功能未启用
- **症状**：browser 相关工具不可用
- **解决**：
```bash
openclaw config set browser.enabled true
openclaw config set browser.defaultProfile "chrome"
```

### 3. 定时任务不运行
- 检查 `cron.enabled` 配置
- 确认 Gateway 连续运行
- 验证时区设置（`--tz`）与主机一致

### 4. Telegram 传递到错误位置
- 论坛主题使用格式：`-1001234567890:topic:123`

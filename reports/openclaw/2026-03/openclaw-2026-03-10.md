## 🔧 配置技巧

### 定时任务快速创建
```bash
# 每天早上 7 点运行，投递到钉钉
openclaw cron add \
  --name "Morning status" \
  --cron "0 7 * * *" \
  --tz "Asia/Shanghai" \
  --session isolated \
  --message "Summarize inbox + calendar for today." \
  --announce \
  --channel dingtalk \
  --to "03003745585526383319"

# 每周一早上 6 点深度分析
openclaw cron add \
  --name "Weekly deep analysis" \
  --cron "0 6 * * 1" \
  --tz "Asia/Shanghai" \
  --session isolated \
  --message "Weekly deep analysis of project progress." \
  --model "opus" \
  --thinking high \
  --announce \
  --channel dingtalk
```

### 常用 Cron 表达式
| 表达式 | 说明 |
|--------|------|
| `0 7 * * *` | 每天早上 7 点 |
| `0 22 * * *` | 每天晚上 10 点 |
| `0 6 * * 1` | 每周一早上 6 点 |
| `0 9 * * 1-5` | 工作日早上 9 点 |

### 核心参数说明
- `--session isolated`：隔离任务，每次运行启动全新会话
- `--announce`：投递摘要到指定渠道
- `--wake now`：立即唤醒（默认是下次心跳时运行）

## ❓ 常见问题与解决

### Q1: 定时任务没收到通知？
- 检查是否使用 `--announce` 参数
- 确认 `--channel` 和 `--to` 配置正确
- 查看运行历史：`openclaw cron runs --id <job-id> --limit 50`

### Q2: 任务执行失败怎么办？
- 使用 `--force` 手动重试：`openclaw cron run <job-id> --force`
- 检查日志：`~/.openclaw/cron/runs/<jobId>.jsonl`

### Q3: 如何编辑现有任务？
```bash
openclaw cron edit <job-id> --message "Updated prompt" --model "opus"
```

## 🚀 最佳实践

### 多代理任务分配
- 绑定任务到特定智能体：`openclaw cron edit <job-id> --agent <agent-name>`
- 清除绑定：`openclaw cron edit <job-id> --clear-agent`

### 配置选项
```json
{
  "cron": {
    "enabled": true,
    "store": "~/.openclaw/cron/jobs.json",
    "maxConcurrentRuns": 1
  }
}
```

### 禁用定时任务
- 配置：`cron.enabled: false`
- 环境变量：`OPENCLAW_SKIP_CRON=1`

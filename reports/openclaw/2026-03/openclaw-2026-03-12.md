## 🔧 配置技巧

### 1. Cron 定时任务配置（飞书渠道）

**完整命令模板**：
```bash
openclaw cron add \
  --name "任务名称" \
  --at "2026-03-12T17:40:00+08:00" \
  --account main \
  --channel feishu \
  --to "chat:oc_xxx" \
  --message "提醒内容" \
  --delete-after-run
```

**关键参数**：
| 参数 | 必填 | 说明 |
|------|------|------|
| `--account` | ✅ | 飞书账户名（需与配置一致，如"main"） |
| `--channel` | ✅ | 渠道类型（feishu/telegram等） |
| `--to` | ✅ | 目标ID（chat:群ID 或 user:用户OpenID） |
| `--at` | ✅ | ISO 8601 时间格式（带时区） |

**循环任务示例**：
```bash
openclaw cron add \
  --name "每日晨报" \
  --cron "0 8 * * *" \
  --tz "Asia/Shanghai" \
  --account main \
  --channel feishu \
  --to "chat:oc_xxx" \
  --message "☀️ 早上好！"
```

### 2. 多 Agent 配置最佳方案

**推荐：sessions_spawn 动态子 Agent**

```javascript
// 直接调用，无需预配置
sessions_spawn({
  label: '代码助手',
  task: '检查项目的TypeScript错误，列出所有错误并给出修复建议',
  mode: 'run',
  runTimeoutSeconds: 180
})
```

**优势**：
- ✅ 无需 `openclaw agents add` 预创建
- ✅ 无需配置 `subagents.allowlist`
- ✅ 任务描述越详细，结果越好
- ✅ 支持并行执行，效率提升 3 倍

**并行执行示例**：
```javascript
const [code, docs, research] = await Promise.all([
  sessions_spawn({label: '代码', task: '...'}),  
  sessions_spawn({label: '文档', task: '...'}),
  sessions_spawn({label: '研究', task: '...'})
]);
```

## ❓ 常见问题与解决

### Q1: Cron 任务创建了但不执行？
**检查**：
1. 查看日志：`tail -100 /tmp/openclaw/openclaw-2026-03-12.log | grep -i cron`
2. 确认有 `cron: job added` 和 `cron: timer armed` 日志

### Q2: 任务执行了但没收到消息？
**常见原因**：
- 未指定 `--to` 参数 → 添加 `chat:群ID`
- `--account` 账户名错误 → 需与配置一致（可能是"main"而非"default"）
- 飞书 Bot 权限不足

### Q3: 时间格式错误？
**错误**：`--at "17:30"` 或 `--at "+1m"`
**正确**：`--at "2026-03-12T17:30:00+08:00"`（ISO 8601格式）

### Q4: 多 Agent 任务超时？
**解决**：合理设置超时时间
- 简单查询：60-120秒
- 中等任务：180-300秒  
- 复杂任务：300-600秒

|----------|----------|
| 个人任务分工 | sessions_spawn |
| 小团队协作 | sessions_spawn |
| 大团队/多渠道 | agents add + bindings |

### 3. 飞书群聊定时任务避坑
- 必须指定 `--account main`（而非 default）
- 必须指定 `--channel feishu`
- 必须指定 `--to "chat:群ID"`

### 4. 子 Agent 管理
```javascript
// 查看所有子Agent
subagents({action: 'list'})

// 终止子Agent
subagents({action: 'kill', target: 'session-id'})

// 发送消息给子Agent
subagents({action: 'steer', target: 'session-id', message: '加快速度'})
```

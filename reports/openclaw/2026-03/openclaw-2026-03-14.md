
## 🔧 配置技巧

### 定时任务（Cron Jobs）
OpenClaw 支持三种定时任务方式：

1. **内置独立 Cron 任务**（最简单，推荐）
   - 通过配置文件直接定义定时规则
   
2. **Heartbeat**（适合高频监控）
   - 适合需要持续监控的场景
   
3. **编写专属 Extension**（适合重度玩家）
   - 需要极高稳定性的场景

### 性能优化配置
当 OpenClaw 性能未达预期时，可调优：
- 限定 CUDA 设备与显存分配
- 提升 gRPC 并发与 KeepAlive 参数
- 启用 MMAP 模型加载
- 降低日志级别并禁用 metrics
- 绑定 NUMA 优化

### 多实例配置
```bash
OPENCLAW_CONFIG_PATH=~/.openclaw/a.json \
OPENCLAW_STATE_DIR=~/.openclaw-a \
openclaw gateway --port 19001
```

## ❓ 常见问题与解决

### 常见报错及解决方案

| 报错 | 原因 | 解决方案 |
|------|------|----------|
| HTTP 401 Authorization | OpenClaw 本身 bug | 等待官方修复 |
| EACCES: permission denied | 安装权限不足 | 使用 sudo 或修复 npm 权限 |
| 启动失败 | Node.js 版本不足 | 升级到 Node ≥ 22 |
| Web UI 无法加载 | 计划任务工作目录错误 | 检查 .env 配置格式 |
| Control UI 访问报错 | 配置问题 | 检查 channels 和安全设置 |

### 更新问题
- 如果 `openclaw update` 中断，可能导致启动失败
- 解决方案：`npm install -g openclaw@latest` 重装

### 安全漏洞预警
- **2026.2.25** 版本修复了一个高危漏洞
- 建议立即升级至 2026.2.25 或更高版本
- 审计并撤销不必要凭证和 API 密钥

## 🚀 最佳实践

### 渠道配置
**DingTalk 配置：**
- 支持 inlineButtons（dm|group|all|allowlist）
- 建议通过配置文件设置安全访问

**安全配置示例：**
```json
{
  "channels": {
    "whatsapp": {
      "allowFrom": ["+15555550123"],
      "groups": { "*": { "requireMention": true } }
    }
  }
}
```

### 自动更新配置
可通过配置文件启用自动更新：
- CLI 命令行更新（支持 dry-run、--yes 等参数）
- Web 界面图形化更新
- 配置文件启用自动更新

### Subagent 多代理配置
- 支持 subagent 模式运行
- 可配置 runtime="subagent" 或 "acp"
- 支持 thread 模式实现持久会话

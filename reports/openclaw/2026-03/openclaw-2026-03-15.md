## 🔧 配置技巧

### 1. 配置文件最佳实践
```json
{
  "gateway": { "port": 18789 },
  "agents": { "$include": "./agents.json5" },
  "broadcast": { "$include": ["./clients/*.json5"] }
}
```
使用 `$include` 拆分配置为多个文件，便于管理。

### 2. 环境变量配置
```json
{
  "env": {
    "OPENROUTER_API_KEY": "sk-or-...",
    "vars": { "GROQ_API_KEY": "gsk-..." }
  }
}
```
使用 `${VAR_NAME}` 语法在配置中引用环境变量。

### 3. 多渠道配置速查

| 渠道 | 关键配置项 |
|------|-----------|
| WhatsApp | `dmPolicy`: pairing/allowlist/open/disabled |
| Telegram | `botToken` + `dmPolicy` |
| Discord | `token` + `guilds` 频道白名单 |
| Slack | `botToken` + `appToken` |

### 4. Cron 定时任务配置
```json
{
  "cron": {
    "enabled": true,
    "maxConcurrentRuns": 2
  }
}
```

## ❓ 常见问题与解决

### 问题1: No API key found for provider
**原因**: 智能体认证存储为空或缺少凭证  
**解决**: 
```bash
openclaw models auth setup-token --provider anthropic
openclaw models status
```

### 问题2: Gateway start blocked
**解决**:
```bash
openclaw configure
# 或直接设置：
openclaw config set gateway.mode local
```

### 问题3: 服务运行但端口未监听
**检查项**:
- `gateway.mode` 必须为 `local`
- 检查 `gateway.bind` 设置
- 确认 `gateway.auth.token` 已配置

### 问题4: 沙箱中Skill缺少API密钥
**原因**: Docker沙箱不继承主机 `process.env`  
**解决**: 设置 `agents.defaults.sandbox.docker.env`

### 问题5: 高内存使用
**解决**:
```json
{
  "session": {
    "historyLimit": 100
  }
}
```

### 问题6: Discord不回复
**修复清单**:
1. 设置 `channels.discord.groupPolicy: "open"` 或添加guild白名单
2. 使用数字频道ID
3. 将 `requireMention: false` 放在 `channels.discord.guilds` 下
4. 确保机器人有 Message Content Intent

## 🚀 最佳实践

### 1. 多Agent配置（2026年最新）
```json
{
  "agents": {
    "list": [
      {
        "id": "main",
        "default": true,
        "workspace": "~/.openclaw/workspace-main",
        "model": { "primary": "anthropic/claude-opus-4-5" },
        "identity": {
          "name": "Samantha",
          "emoji": "🦥"
        }
      }
    ]
  },
  "bindings": [
    { "agentId": "home", "match": { "channel": "whatsapp", "accountId": "personal" } },
    { "agentId": "work", "match": { "channel": "whatsapp", "accountId": "biz" } }
  ]
}
```

### 2. 更新最佳实践
**推荐方式**: 重新运行安装程序（原地升级）
```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```
**更新后必做**:
```bash
openclaw doctor
openclaw gateway restart
openclaw health
```

### 3. 工具策略配置
```json
{
  "tools": {
    "profile": "coding",
    "allow": ["read", "write", "exec"],
    "deny": ["browser", "canvas"]
  }
}
```
工具组简写: `group:runtime`, `group:fs`, `group:sessions`, `group:messaging`, `group:web`, `group:ui`

### 4. 日志配置
```json
{
  "logging": {
    "level": "info",
    "file": "/tmp/openclaw/openclaw.log",
    "consoleLevel": "info",
    "redactSensitive": "tools"
  }
}
```

### 5. 健康检查命令
```bash

openclaw status --all              # 完整诊断（隐藏令牌）
openclaw status --deep             # 健康检查+提供商探测
openclaw gateway probe             # Gateway发现和可达性
openclaw channels status --probe    # 渠道状态查询
openclaw logs --follow              # 实时日志
```

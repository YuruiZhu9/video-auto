## 🔧 配置技巧

### 快速安装（推荐）
```bash
npm install -g openclaw@latest
openclaw onboard --install-daemon
```

### 启用完整权限（必做）
```bash
openclaw config set tools.profile coding
openclaw config set browser.enabled true
openclaw config set browser.defaultProfile "chrome"
openclaw config set tools.allow '[]'
openclaw gateway restart
```

### 定时任务配置
- 任务存储：`~/.openclaw/cron/jobs.json`
- 支持三种调度：at（一次性）/ every（间隔）/ cron（定时）
- 常用命令：
  - `openclaw cron add` - 创建任务
  - `openclaw cron list` - 查看任务
  - `openclaw cron run --force` - 手动执行

### 更新方式
1. 内置命令：`openclaw update`
2. npm 全局更新：`npm install -g openclaw@latest`
3. Git 源码拉取
4. 切换更新渠道：`openclaw update --channel beta/dev/stable`

## ❓ 常见问题与解决

### 15个高频报错解决方案
1. **npm error code 128**（安装失败）
   - 解决：配置国内镜像 `npm config set registry https://registry.npmmirror.com`
   - Windows 用户可使用一键安装脚本

2. **Web 界面无法访问**
   - 检查端口占用：`lsof -i :18789`
   - 检查防火墙/安全组配置
   - 确认绑定地址是否为 127.0.0.1

3. **认证失败**
   - 补全 auth-profile 配置
   - 检查 API Key 格式与权限

4. **钉钉 405 错误**
   - 启用 chatCompletions 端点

5. **钉钉 401 错误**
   - 检查 gateway.auth 中的 token/password

### 常见问题排查
- 命令不可识别：检查 Node/npm 版本、全局安装及 PATH 配置
- 服务异常：按五步排查（Node≥v18、端口占用、API-Key、插件卸载、重装）

## 📖 官方文档更新

### 定时任务（Cron Jobs）配置详解
OpenClaw 官方文档更新了定时任务的完整配置说明：

**三种调度类型：**
| 类型 | CLI 参数 | 说明 |
|------|----------|------|
| `at` | `--at` | 一次性时间戳（ISO 8601 格式） |
| `every` | `--every` | 固定间隔（毫秒） |
| `cron` | `--cron` | 5 字段 cron 表达式 |

**核心特性：**
- 任务持久化存储在 `~/.openclaw/cron/jobs.json`，重启不丢失
- 支持多渠道消息投递（WhatsApp/Telegram/Discord/Slack）
- 两种执行模式：`main`（主会话）和 `isolated`（隔离会话）

### 快速安装命令
```bash
npm install -g openclaw@latest
openclaw onboard --install-daemon
```

## 🔧 配置技巧

### 1. 定时任务配置模板

**每日早报（投送到 WhatsApp）：**
```bash
openclaw cron add \
  --name "Morning brief" \
  --cron "0 7 * * *" \
  --tz "Asia/Shanghai" \
  --session isolated \
  --message "Summarize inbox + calendar for today." \
  --announce \
  --channel whatsapp \
  --to "+15551234567"
```

**投送到钉钉：**
```bash
openclaw cron add \
  --name "Daily report" \
  --cron "0 22 * * *" \
  --session isolated \
  --message "生成今日技术周报" \
  --announce \
  --channel dingtalk \
  --to "03003745585526383319"
```

### 2. 权限配置（必做！）
```bash
openclaw config set tools.profile coding
openclaw config set browser.enabled true
openclaw config set browser.defaultProfile "chrome"
openclaw config set tools.allow '[]'
openclaw gateway restart
```

## ❓ 常见问题与解决

### 1. 钉钉 405 错误
**症状：** 消息发送返回 405 错误码
**解决：** 启用 chatCompletions 端点
```json
{
  "channels": {
    "dingtalk": {
      "chatCompletions": true
    }
  }
}
```

### 2. 钉钉 401 错误
**症状：** 认证失败
**解决：** 检查 `gateway.auth` 中的 token/password 配置

### 3. npm install 卡住
**解决：** 配置国内镜像
```bash
npm config set registry https://registry.npmmirror.com
```

### 4. 定时任务没收到通知
**检查：**
- 是否添加 `--announce` 参数
- 是否指定 `--channel` 和 `--to`
- 隔离会话模式（isolated）才能投递消息

## 🚀 最佳实践

### 1. 安全配置
- Gateway 绑定 `127.0.0.1`（本地）
- 使用环境变量管理 API Key
- 定期执行 `openclaw security audit --deep`
- 限制文件操作：`tools.fs.workspaceOnly: true`

### 2. 定时任务最佳实践
- 周期性任务使用 `--session isolated` 避免上下文污染
- 重要任务添加 `--announce` 确保消息投递
- 使用命名会话 `session:custom-id` 保持跨运行上下文

### 3. 多渠道配置
支持渠道：WhatsApp、Telegram、Discord、iMessage、Mattermost（插件）

## 🔧 配置技巧

### 定时任务配置（4种方式）

**方式一：`openclaw cron add` 命令**
```bash
# 一次性任务（30分钟后触发）
openclaw cron add --name "临时提醒" --at "30m" --message "准备项目评审材料"

# 每日早上7点执行
openclaw cron add --name "每日日报" --cron "0 7 * * *" --tz "Asia/Shanghai" --announce --channel dingtalk --to "03003745585526383319"

# 每小时执行
openclaw cron add --name "健康检查" --every "1h" --session isolated
```

**方式二：手动编辑 jobs.json**
```bash
cd ~/.openclaw/cron
nano jobs.json
```

**方式三：系统 crontab**
```bash
30 6 * * * /home/username/bin/run-openclaw-task.sh
```

**方式四：Workflow 时间触发**
```yaml
trigger:
  type: time
  schedule: "0 18 * * 1-5"
```

### 任务存储位置
- 任务配置：`~/.openclaw/cron/jobs.json`
- 运行历史：`~/.openclaw/cron/runs/`

## ❓ 常见问题与解决

### 本周高频报错 TOP 5

| 报错类型 | 原因 | 解决方案 |
|---------|------|----------|
| **CUDA 初始化失败** | 驱动未加载/CUDA 未安装 | `nvidia-smi` 检查驱动，`nvcc --version` 确认 CUDA |
| **ClawModule 加载失败** | PYTHONPATH 缺失 | `pip install -e .` 可编辑安装 |
| **图像预处理断言失败** | RGB 顺序/分辨率不匹配 | `cv2.cvtColor(..., cv2.COLOR_BGR2RGB)` 转换 |
| **多线程崩溃** | CUDA 上下文跨线程共享 | 线程独立创建 model，`torch.set_num_threads(1)` |
| **GPU 内存超时** | 显存碎片化 | `torch.cuda.empty_cache()`，`with torch.no_grad()` |

### 钉钉配置常见问题
- **405 错误**：启用 `chatCompletions` 端点
- **401 错误**：检查 `gateway.auth` 中的 token/password
- **权限问题**：`tools.profile` 需设为 `coding`

# OpenClaw 配置周刊 - 2026年3月20日

## 📖 官方文档更新

### 核心功能特性
OpenClaw 是一个适用于任何操作系统的 AI 智能体 Gateway 网关，支持 WhatsApp、Telegram、Discord、iMessage 等主流通讯平台。通过插件还可扩展 Mattermost 等更多渠道。

**核心功能清单：**
- 多渠道 Gateway 网关 - 单进程连接多平台
- 多智能体路由 - 按智能体、工作区或发送者隔离会话
- 媒体支持 - 图片、音频、文档收发
- Web 控制界面 - 浏览器仪表板管理
- 移动节点 - iOS/Android 配对支持 Canvas

### 快速开始步骤
```bash
# 1. 安装
npm install -g openclaw@latest

# 2. 引导配置
openclaw onboard --install-daemon

# 3. 渠道登录
openclaw channels login

# 4. 启动网关
openclaw gateway --port 18789
```

### 配置文件位置
- 主配置：`~/.openclaw/openclaw.json`
- 定时任务：`~/.openclaw/cron/jobs.json`
- 环境变量：`~/.openclaw/.env`

## 🔧 配置技巧

### 权限配置（2026.3.2+ 安全增强）
⚠️ 新版本默认权限从 `messaging` 开始，如需完整权限需手动配置：

```bash
openclaw config set tools.profile coding
openclaw config set browser.enabled true
openclaw config set browser.defaultProfile "chrome"
openclaw config set tools.allow '[]'
openclaw gateway restart
```

### 定时任务配置（三种方式）
1. **CLI 命令**
   ```bash
   openclaw cron add --name "Daily report" --cron "0 22 * * *" --session isolated --message "生成今日技术周报" --announce --channel dingtalk --to "用户ID"
   ```

2. **手动编辑** `~/.openclaw/cron/jobs.json`
   ```json
   {
     "jobs": [{
       "name": "早报",
       "schedule": "0 7 * * *",
       "command": "生成早报",
       "channel": "dingtalk"
     }]
   }
   ```

3. **系统 crontab + Shell 脚本**

### 常用 Cron 表达式
| 表达式 | 含义 |
|--------|------|
| `0 7 * * *` | 每天早上 7 点 |
| `0 22 * * *` | 每天晚上 10 点 |
| `0 6 * * 1` | 每周一早上 6 点 |
| `0 */2 * * *` | 每隔 2 小时 |

## ❓ 常见问题与解决

### 高频报错解决方案

| 错误代码 | 原因 | 解决方案 |
|----------|------|----------|
| npm error code 128 | Git 访问问题 | 配置国内镜像：`npm config set registry https://registry.npmmirror.com` |
| 钉钉 405 | 端点配置错误 | 启用 chatCompletions 端点 |
| 钉钉 401 | Auth 凭证错误 | 检查 gateway.auth 中的 token/password |
| CUDA 初始化失败 | 驱动问题 | 运行 `nvidia-smi` + `nvcc --version` 检查 |
| ClawModule 加载失败 | 依赖未安装 | `pip install -e .` |
| Web 界面无法访问 | 端口/防火墙 | 检查 18789 端口是否开放 |

### 安全建议
- Gateway 绑定本地：`"gateway": {"host": "127.0.0.1"}`
- 使用环境变量管理 API Key
- 定期执行 `openclaw security audit --deep`
- 限制文件操作：`tools.fs.workspaceOnly: true`

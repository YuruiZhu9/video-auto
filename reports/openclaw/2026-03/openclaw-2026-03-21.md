# OpenClaw 配置周刊 - 2026-03-21

## 📖 官方文档更新

### 本周重大发现：Pi 是唯一 Coding Agent 路径
根据官方文档（docs.openclaw.ai），**旧的 Claude/Codex/Gemini/Opencode 路径已全部移除**，Pi 是当前唯一的 coding-agent 路径。这意味着：
- 配置 `coding-agent` Skill 时统一调用 Pi
- Pi 支持 RPC 模式工具流式传输
- 想接入 Claude/Codex 需通过官方 Provider 订阅（Anthropic Claude Pro/Max / OpenAI ChatGPT/Codex）

### 官方支持的平台
- **消息平台**：WhatsApp（Baileys）、Telegram（grammY）、Discord（discord.js）、iMessage（macOS imsg CLI）、飞书（插件）
- **客户端**：WebChat + macOS App + iOS/Android 节点（配对后暴露 Canvas/Chat/Camera）
- **节点支持**：iOS 节点 → Canvas 界面；Android 节点 → Canvas + Chat + Camera

### 官方安全配置示例
```json
{
  "channels": {
    "whatsapp": {
      "allowFrom": ["+15555550123"],
      "groups": { "*": { "requireMention": true } }
    }
  },
  "messages": {
    "groupChat": { "mentionPatterns": ["@openclaw"] }
  }
}
```

### 关键配置路径
- 主配置：`~/.openclaw/openclaw.json`
- 网关默认端口：**18789**（WS）/ **18793**（HTTP Canvas）
- 仪表板本地访问：`http://127.0.0.1:18789/`
- ⚠️ 远程访问必须配置 HTTPS 或 Tailscale，HTTP 直连 IP 会触发 `device identity required` 错误

## 🔧 配置技巧

### 定时任务：三种配置方式详解

**方式一：CLI 命令（推荐）**
```bash
openclaw cron add --name "日报推送" \
  --cron "0 22 * * *" \
  --session isolated \
  --message "生成今日技术周报" \
  --announce --channel dingtalk \
  --to "03003745585526383319"
```

**方式二：手动编辑任务文件**
```bash
# 任务持久化存储位置
~/.openclaw/cron/jobs.json
# 三种调度类型：at（一次性）/ every（间隔）/ cron（定时）
```

**方式三：系统 Crontab + Shell 脚本**
适合需要调用外部脚本的复杂任务，配合 `openclaw message send` 投送结果。

### 多飞书机器人配置（新发现）
一个 OpenClaw 实例可以绑定多个飞书机器人，每个绑定到不同 Agent，实现物理级隔离：
```json
{
  "channels": {
    "feishu": {
      "accounts": {
        "researcher": {
          "appId": "cli_xxx",
          "appSecret": "xxx",
          "botName": "研报助手"
        }
      }
    }
  },
  "bindings": [
    {
      "agentId": "researcher-subagent",
      "match": { "channel": "feishu", "accountId": "researcher" }
    }
  ]
}
```

### 钉钉 405 报错：chatCompletions 端点配置
若钉钉消息返回 405，需在配置中启用 chatCompletions 端点。这是钉钉渠道的已知兼容问题，参考官方 channels 配置文档。

## ❓ 常见问题与解决

### 15个高频报错（按阶段分类）

| 报错关键词 | 阶段 | 解决方案 |
|-----------|------|---------|
| `EBADENGINE` | 安装 | Node.js 需 ≥22，升级： `brew install node@22` |
| `command not found` | 安装 | npm 全局 bin 不在 PATH：`export PATH="$(npm prefix -g)/bin:$PATH"` |
| `sharp: Installation error` | 安装 | Windows 跳过编译：`$env:SHARP_IGNORE_GLOBAL_LIBVIPS=1` |
| `Gateway start blocked` | 网关 | 配置文件添加 `"mode": "local"` |
| `EADDRINUSE :::18789` | 网关 | 查进程 `lsof -i :18789`，杀旧进程或改端口 |
| `HTTP 429` | API | 禁用 `context1m` 或升级账户等级 |
| `AUTH_TOKEN_MISMATCH` | API | 重新 `openclaw configure` |
| `openclaw.extensions` missing | 插件 | package.json 添加 `"openclaw": { "extensions": ["dist/index.js"] }` |
| `mention required` | 渠道 | 消息加 @机器人 或配置 `"requireMention": false` |
| `pairing request pending` | 渠道 | `openclaw pairing approve <CODE>` |
| `blocked: not in allowlist` | 渠道 | 配置文件添加用户 ID 到 `allowFrom` |
| `device identity required` | 仪表板 | 必须用 `http://127.0.0.1:18789/` 本地访问 |
| `device nonce mismatch` | 仪表板 | 清除浏览器缓存 + `openclaw devices approve <id>` |
| `cron scheduler disabled` | 定时 | 配置中启用 `"cron": { "enabled": true }` |
| CUDA/GPU 报错 | 推理 | 参见下方 GPU 专题 |

### GPU/推理问题专题（CUDA 高频报错）

| 报错 | 根因 | 解决 |
|------|------|------|
| `cuInit failed` | 驱动/CUDA未安装 | `nvidia-smi` + `nvcc --version` 检查 |
| `No module named 'openclaw.claw'` | PYTHONPATH 缺失 | `pip install -e .` |
| 张量shape不匹配 | RGB顺序/分辨率/归一化 | cv2 转换 + 统一归一化至 [0,1] |
| `Segmentation fault` | CUDA上下文跨线程共享 | 线程独立创建 model + `torch.set_num_threads(1)` |
| `Timeout waiting for GPU memory` | 显存碎片化 | `torch.cuda.empty_cache()` + `with torch.no_grad()` |

## 🚀 最佳实践

### SubAgent 五种启用方式（本周专题）

**1. 命令行 spawn（最适合定时任务）**
```
/subagents spawn --task "调研Qwen开源生态" --model qwen-portal/coder-model
```
返回 runId（如 `agent::subagent:8a3f9c2e`），不阻塞主会话，结果自动推送。

**2. AGENTS.md 规则触发（自动化调度）**
在 AGENTS.md 顶部添加 Orchestration Contract，含"对比/搜集/整理/生成"等动词时自动触发。

**3. agentToAgent 工具（精确控制）**
主 Agent 可向子 Agent 发送结构化指令，结果以 JSON 格式返回：
```javascript
agentToAgent(target:"coder", message:"请分析 ./src/auth.js 漏洞")
```

**4. Coding Team Setup v2.0（批量初始化）**
```bash
claw skill install coding-team-setup@v2.0
coding-team-setup --size 3 --template react-fullstack --name frontend-team
```
自动创建 architect / developer / tester 三个子 Agent，各有独立 workspace。

**5. 飞书多账户物理隔离（生产环境推荐）**
每个子 Agent 拥有独立飞书机器人身份，从通信入口完成分流，杜绝上下文污染。

### OpenClaw + 钉钉 AI 表格联动（本周新玩法）
通过钉钉 AI 表格可让 OpenClaw 直接读写表格数据，适合：
- 自动汇总抓取结果到钉钉文档
- 多 Agent 协同填写任务进度
- 定时推送数据报表到群

## 🔧 配置技巧

### 定时任务（官方文档新详解）

支持**三种调度类型**，任务持久化存储在 `~/.openclaw/cron/jobs.json`：

| 类型 | 参数 | 说明 |
|------|------|------|
| `at` | `schedule.at` | 一次性时间戳（ISO 8601） |
| `every` | `schedule.everyMs` | 固定间隔（毫秒） |
| `cron` | `schedule.expr` + `schedule.tz` | 5字段Cron表达式，支持IANA时区 |

**执行模式两种：**
- `main`：系统事件入队，下个心跳时运行
- `isolated`：独立 `cron:` 会话，并行执行，结果自动回传

**CLI 创建隔离任务示例（钉钉推送）：**
```bash
openclaw cron add \
  --name "Daily Report" \
  --cron "0 22 * * *" \
  --tz "Asia/Shanghai" \
  --session isolated \
  --message "生成今日技术周报" \
  --announce \
  --channel dingtalk \
  --to "03003745585526383319"
```

**JSON 持久化格式示例：**
```json
{
  "name": "Morning brief",
  "schedule": { "kind": "cron", "expr": "0 7 * * *", "tz": "Asia/Shanghai" },
  "sessionTarget": "isolated",
  "wakeMode": "next-heartbeat",
  "payload": {
    "kind": "agentTurn",
    "message": "Summarize overnight updates."
  },
  "delivery": {
    "mode": "announce",
    "channel": "dingtalk",
    "to": "03003745585526383319",
    "bestEffort": true
  }
}
```

### 多代理路由（官方文档新详解）

单个 Gateway 可运行**多个完全隔离的代理**（独立 workspace + agentDir + sessions）：

**创建代理：**
```bash
openclaw agents add coding
openclaw agents add social
```

**路径速查：**
- 配置：`~/.openclaw/openclaw.json`
- Workspace：`~/.openclaw/workspace` 或 `~/.openclaw/workspace-<agentId>`
- 代理目录：`~/.openclaw/agents/<agentId>/agent`
- 会话：`~/.openclaw/agents/<agentId>/sessions`

**路由优先级（最具体优先）：**
1. `peer` 精确匹配
2. `parentPeer`（线程继承）
3. `guildId + roles`（Discord 角色）
4. `guildId` / `teamId`
5. `accountId` 匹配
6. 频道级匹配
7. 回退默认代理

**按渠道路由示例（钉钉 + Telegram）：**
```json
{
  "agents": {
    "list": [
      { "id": "main", "workspace": "~/.openclaw/workspace-main" },
      { "id": "work", "workspace": "~/.openclaw/workspace-work" }
    ]
  },
  "bindings": [
    { "agentId": "main", "match": { "channel": "dingtalk" } },
    { "agentId": "work", "match": { "channel": "telegram" } }
  ]
}
```

## ❓ 常见问题与解决

### 本周高频问题

**Q：定时任务"不触发"怎么办？**
A：按以下顺序排查：
1. 确认 Gateway 持续运行（cron 在 Gateway 进程内运行）
2. 检查 `cron.enabled: true` 配置和 `OPENCLAW_SKIP_CRON` 环境变量
3. 确认时区 `--tz` 与主机时区一致（用 `Asia/Shanghai`）
4. 指数退避：连续失败后延迟 30s → 1m → 5m → 15m → 60m

**Q：Telegram/钉钉消息传递到错误位置？**
A：使用明确格式指定主题：
- 钉钉：直接用 chat_id（如 `03003745585526383319`）
- Telegram：`chatId:topicId` 格式明确指定主题

**Q：工具调用报 EBADENGINE 错误？**
A：确认 Node ≥ 22：`node -v`，旧版本路径已全部移除

**Q：安装 npm error code 128？**
A：配置国内镜像：
```bash
npm config set registry https://registry.npmmirror.com
```

**Q：钉钉 401 / 405 错误？**
- 401：gateway.auth token/password 与钉钉后台不一致
- 405：`channels.dingtalk.compatibilityMode: true` 启用兼容模式

## 🚀 最佳实践

### 1. 多代理架构推荐（本周更新）

生产环境推荐**按职能拆分代理**：
- `main`：日常对话 + 记忆管理
- `coding`：代码任务（Pi agent）
- `work`：工作相关任务（独立 workspace）
- `monitor`：监控告警（轻量级）

每个代理可独立配置：
```json
{
  "id": "family",
  "workspace": "~/.openclaw/workspace-family",
  "sandbox": { "mode": "all", "scope": "agent" },
  "tools": {
    "allow": ["read"],
    "deny": ["exec", "write", "edit", "apply_patch"]
  }
}
```

### 2. 定时任务最佳实践

- **日报/周报**：用 `--session isolated` + `--announce` + `--channel dingtalk`
- **一次性提醒**：用 `--delete-after-run` 自动清理
- **高频监控**：用 `everyMs`（如每 30 分钟一次）
- **时区**：生产环境建议用 IANA 时区（`Asia/Shanghai`）而非 UTC

### 3. 安全加固（必做）

```bash
# 启用完整权限
openclaw config set tools.profile coding
openclaw config set browser.enabled true
openclaw config set tools.allow '[]'

# Gateway 绑定本地
openclaw config set gateway.host 127.0.0.1

# 重启生效
openclaw gateway restart
```

## 🔧 配置技巧

### Telegram Bot 接入四法

1. **BotFather 创建** → 手动配置 Token
2. **`openclaw onboard` 向导**（推荐新手）
3. **环境变量注入**：`TELEGRAM_BOT_TOKEN=xxx`
4. **手动 JSON 配置**：`channels.telegram.botToken`

### 多渠道配置模板

```json
{
  "channels": {
    "telegram": { "botToken": "xxx" },
    "dingtalk": {
      "compatibilityMode": true,
      "auth": { "token": "xxx", "password": "xxx" }
    },
    "discord": { "botToken": "xxx" }
  }
}
```

### 多实例部署

```bash
OPENCLAW_CONFIG_PATH=~/.openclaw/a.json \
OPENCLAW_STATE_DIR=~/.openclaw-a \
openclaw gateway --port 19001
```

### WhatsApp 安全配置

## ❓ 常见问题与解决

### CNNVD 高危漏洞应对（本周重点）

**2026.2.25/2.26 版本修复了高危漏洞，已在 CNNVD 备案：**

```bash
# 立即升级
npm install -g openclaw@latest
openclaw update

# 深度安全审计
openclaw security audit --deep

# 检查当前版本
openclaw --version
```

### 钉钉 401 / 405 速查

| 错误码 | 原因 | 解决 |
|--------|------|------|
| 401 | gateway.auth token 或 password 与钉钉后台不一致 | 核对两个平台的 auth 配置 |
| 405 | 未启用兼容模式 | 设置 `channels.dingtalk.compatibilityMode: true` |
| 无响应 | Gateway 未运行或端口 18789 未通 | 检查 `openclaw gateway status` |

### npm EACCES 权限问题（macOS/Linux）

```bash
# 方法1：修复 npm 全局目录权限
mkdir -p ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

# 方法2：使用 nvm 管理 Node
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.0/install.sh | bash
nvm install 22 && nvm use 22
```

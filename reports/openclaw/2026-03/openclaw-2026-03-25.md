## ❓ 常见问题与解决

### 高频报错 TOP 5
| 报错 | 原因 | 解决方案 |
|------|------|----------|
| npm error code 128 | npm 权限/网络问题 | 配置国内镜像：`npm config set registry https://registry.npmmirror.com` |
| 钉钉 401 | gateway.auth token 与钉钉后台不一致 | 检查 `openclaw.json` 中的 auth 配置 |
| 钉钉 405 | 未启用兼容模式 | `channels.dingtalk.compatibilityMode: true` |
| CUDA 初始化失败 | NVIDIA 驱动未加载 | 执行 `nvidia-smi` + `nvcc --version` 检查 |
| EADDRINUSE 18789 | 端口被占用 | `kill` 旧进程或改端口 |

### 钉钉专项排查
- **401 错误**：gateway.auth 中的 token/password 与钉钉后台设置不一致
- **405 错误**：启用 `channels.dingtalk.compatibilityMode: true`
- **无响应**：确认 Gateway 正在运行，检查 18789 端口

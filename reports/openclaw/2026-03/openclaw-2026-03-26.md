### 2.5 钉钉接入（最新配置）

**两种接入方式**：

| 方式 | 说明 |
|------|------|
| 钉钉开放平台（推荐） | 正式 channel，走统一路由、会话管理、权限控制 |
| 自定义机器人 | 仅支持文字，图片发送受限（需公网URL） |

**钉钉接入关键坑点（2026-03-26 更新）**：

| 坑点 | 原因 | 解决方案 |
|------|------|---------|
| 只能收到第一条消息 | ACK 太慢 | 先 ACK，再异步处理 |
| authFailed 401 | 环境变量未继承 | 直接写入 `openclaw.json` |
| Hook 无效/未执行 | event.type 实际是 `gateway` | 判断 `event.type === "gateway"` |
| zod toJSONSchema 报错 | 插件依赖 zod 但版本无此方法 | 改用手写 JSON schema |

**钉钉配置示例**：
```json
{
  "channels": {
    "dingtalk": {
      "enabled": true,
      "clientId": "YOUR_CLIENT_ID",
      "clientSecret": "YOUR_CLIENT_SECRET",
      "compatibilityMode": true
    }
  }
}
```

### 4.2 创建每日晚间报告任务（推荐配置）

```bash
openclaw cron add \
  --name "OpenClaw配置专家日报" \
  --cron "0 22 * * *" \
  --session isolated \
  --message "生成今日OpenClaw技术周报" \
  --announce \
  --channel dingtalk \
  --to "03003745585526383319"
```

### 4.3 常用 Cron 表达式

| 表达式 | 执行时间 |

| `0 7 * * *` | 每天早上 7:00 |

| `0 6 * * 1` | 每周一早上 6:00 |

## 六、常见问题速查表（FAQ）

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| npm error code 128 | 网络/权限问题 | `npm config set registry https://registry.npmmirror.com` |
| Web 界面无法访问 | 端口未放通/防火墙 | 检查 18789 端口 + 防火墙配置 |
| 钉钉 401 错误 | auth token/password 不一致 | 核对 `gateway.auth` 中的凭证 |

| 定时任务不执行 | Cron scheduler disabled | `openclaw cron list` 检查状态 |
| 插件迁移崩溃 | 2026.3.7 已知问题 | 回退版本或等补丁 |
| 服务端口被占用 | 18789 端口冲突 | `lsof -i:18789` 查看进程 |
| Pi 编码能力受限 | Node 版本低 | 升级到 Node ≥ 22 |

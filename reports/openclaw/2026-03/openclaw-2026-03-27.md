OpenClaw 在 3 月 23-25 日连续发布三个版本，这是自发布以来最密集的更新周期之一。

---

### v2026.3.22（3月23日）— 重大架构升级

**⚠️ Breaking Changes（需手动处理）**

| 变更项 | 旧行为 | 新行为 |
|--------|--------|--------|
| 插件安装优先级 | npm 优先 | **ClawHub 优先**，无时才回退 npm |
| Chrome 扩展中继 | `driver: "extension"` 可用 | **已移除**，需用 `openclaw doctor --fix` 迁移 |
| 环境变量前缀 | `CLAWDBOT_*` / `MOLTBOT_*` | **全部重命名**为 `OPENCLAW_*` |
| SDK 路径 | `openclaw/extension-api` | 改为 `openclaw/plugin-sdk/*` |

**✨ 新功能**

- **ClawHub 官方集成**：`openclaw skills search` / `install` / `update` 一条龙
- **多市场支持**：`openclaw plugins install clawhub:<pkg>` 或 `claude:<pkg>`
- **模型升级**：默认升 GPT-5.4，新增 gpt-5.4-mini/nano；MiniMax 升至 M2.7
- **飞书增强**：交互卡片（审批/快捷操作）、ACP 绑定、流式推理卡片
- **Android 增强**：系统暗色主题、短信搜索、通话记录搜索
- **新搜索提供商**：Exa（AI 搜索）、Tavily（专业搜索）、Firecrawl（网页抓取）

**🔒 安全加固**
- 空白韩文填充字符转义（防视觉欺骗攻击）
- `tools.exec.strictInlineEval` 严格内联解释器控制
- 远程 `file://` URL 和 UNC 路径被阻止
- Webhook 签名验证改用恒定时间比较
- SSRF 策略应用于远程 CDP

### v2026.3.24（3月25日）— 功能增强

**✨ 新功能**

- **OpenAI API 兼容性大升级**：新增 `/v1/models` 和 `/v1/embeddings` 端点
  - 支持标准 OpenAI SDK 直接对接，**RAG 应用集成门槛大幅降低**
- **工具可见性改进**：`/tools` 命令显示当前 Agent **实际可用**的工具，减少困惑
- **Microsoft Teams 重大升级**：迁移到官方 Teams SDK，支持流式回复、欢迎卡片、反馈机制、typing 指示器等 AI 代理最佳实践
- **Skill 安装体验优化**：7 个核心技能（coding-agent、gh-issues、weather 等）一键安装
- **CLI 容器支持**：新增 `--container` 参数，在 Docker/Podman 容器内直接执行命令
- **Discord 自动线程命名**：可选 `autoThreadName: "generated"` 让 LLM 自动生成标题
- **Node 版本要求放宽**：最低 Node 22.14+（之前要求更严格）

**🐛 重要修复**

- 沙箱媒体访问修复（关闭 `mediaUrl`/`fileUrl` 别名绕过）
- Telegram 论坛主题路由修复
- WhatsApp 群组消息回声抑制
- Docker 安装初始化循环修复

## 🔧 配置技巧

### ⚡ 紧急处理：本周 Breaking Changes

如果你的配置中有以下内容，需要立即更新：

```bash
# 1. 环境变量重命名
# 搜索旧变量并替换
grep -r "CLAWDBOT_\|MOLTBOT_" ~/.openclaw/
# 替换为 OPENCLAW_* 前缀

# 2. Chrome 扩展中继迁移
openclaw doctor --fix
# 之后检查 browser.driver 是否改为 openclaw/chrome

# 3. 插件安装验证（ClawHub 优先）
openclaw plugins list
```

### 💡 ClawHub 新用法（v2026.3.22+）

```bash
# 搜索技能

# 安装技能（ClawHub 优先）

# 更新所有技能
openclaw skills update

# 指定市场安装
openclaw plugins install clawhub:tavily-search
openclaw plugins install claude:self-improving-agent
```

## ❓ 常见问题与解决

### Q1：更新后第三方插件全部失效？
**A**：v2026.3.22 改变了插件加载逻辑，v2026.3.23 已修复。执行：
```bash
openclaw update && openclaw gateway restart
```

### Q2：控制台 Web UI 打不开？
**A**：v2026.3.22 打包遗漏，v2026.3.23 已修复。升级后重启即可。

### Q3：钉钉配置还在用 CLAWDBOT_ 环境变量？
**A**：立即改为 `OPENCLAW_DINGTALK_*` 前缀，旧变量不再生效。

### Q4：需要兼容旧版 Chrome 扩展？
**A**：已无法使用。请切换到 `browser.driver: "openclaw"` 或 `profile: "chrome"`（需 OpenClaw Browser Relay Chrome 扩展）。

### Q5：Mistral 模型报 422 错误？
**A**：v2026.3.23 已降低默认 token 限制，重新尝试即可。

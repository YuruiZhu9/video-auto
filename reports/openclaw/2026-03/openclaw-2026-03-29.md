### Memory autoCapture 默认禁用
- **原因：** 安全防护，防止意外捕获 PII 数据
- **如需开启：**
```json
// openclaw.json
{
  "agents": {
    "defaults": {
      "memorySearch": {
        "autoCapture": true
      }
    }
  }
}
```

## 🔧 配置技巧

### 1. 隔离 Cron 任务的 announce 投递（新功能）
v2026.2.3 起，隔离任务默认使用 announce 投递，成功后自动删除一次性任务：

```bash
# 创建每日定时任务，投递到钉钉
openclaw cron add --name "配置专家日报" \
  --cron "0 22 * * *" \
  --session isolated \
  --message "生成今日OpenClaw技术周报" \
  --announce --channel dingtalk \
  --to "03003745585526383319" \
  --keep-after-run   # 保留任务，不自动删除
```

### 2. Moonshot（.cn）中国版配置
向导新增 Moonshot 认证选项，中国区用户更易接入：
```json
{
  "providers": {
    "moonshot-cn": {
      "apiKey": "your-api-key",
      "region": "cn"
    }
  }
}
```

### 3. Cloudflare AI Gateway（新增）
支持通过 Cloudflare Workers AI 作为代理层访问大模型：
```json
{
  "providers": {
    "cloudflare": {
      "accountId": "your-account-id",
      "gatewayId": "your-gateway-id"
    }
  }
}
```

### 4. 沙箱隔离模式（安全加固）
使用 `agents.defaults.sandbox.mode: "non-main"` 隔离群组/渠道会话：
```json
{
  "routing": {
    "agents": {
      "main": {
        "workspace": "~/.openclaw/workspace",
        "sandbox": { "mode": "off" }
      }
    }
  }
}
```

## ❓ 常见问题与解决

### Q1：Cron 任务执行成功但没有收到钉钉通知？
**原因**：announce 投递默认启用，但 `--channel` 和 `--to` 参数必须显式指定
**解决**：
```bash
openclaw cron add --name "xxx" --cron "0 22 * * *" \
  --session isolated --announce \
  --channel dingtalk --to "03003745585526383319"
```

### Q2：GitHub release 页面显示版本较旧？
GitHub Releases 页面可能缓存了旧版本，建议使用 CLI 确认：
```bash
npm show openclaw version   # 最新稳定版
openclaw --version          # 本地已安装版本
openclaw update             # 升级到最新版
```

### Q3：WhatsApp 登录失败 / 媒体接收异常？
v2026.2.3 已沙盒化消息附件媒体路径，检查配置：
```json
{
  "channels": {
    "whatsapp": {
      "allowFrom": ["+86xxxxxxxxxxx"]
    }
  }
}
```

### Q4：Discord/Slack 元数据进入提示词？
v2026.2.3 已阻止不受信任的 Slack/Discord 渠道元数据。若仍有问题，检查 `session.dmScope = "per-channel-peer"` 配置。

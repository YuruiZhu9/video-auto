## 📖 官方文档更新

### 🔥 v2026.3.31 发布（2026-03-31，最新版！）

**史诗级架构更新 + QQ Bot 原生接入**

#### 破坏性变更（Breaking Changes）

| 变更项 | 影响说明 |
|--------|----------|
| **插件安装安全收紧** | 危险代码检测默认拦截，Critical 级别直接阻止安装，需 `--dangerously-force-unsafe-install` 才能强制 |
| **Gateway 认证强化** | `trusted-proxy` 拒绝混用共享令牌配置，本地直连也需令牌，不再隐式信任同主机调用者 |
| **Node 命令权限收紧** | 设备配对不足以暴露 Node 命令，必须完成配对审批（pairing approval）才能使用 |
| **插件 SDK 路径迁移** | `openclaw/extension-api/*` → `openclaw/plugin-sdk/*`，旧路径将在未来大版本中完全移除 |

#### 核心新功能

**① 后台任务系统重构（最大架构变化）**
- ACP、子代理、定时任务、后台 CLI 执行统一由 SQLite 驱动分类账管理
- 新增 `openclaw flows list|show|cancel` 任务流控制命令
- 孤立任务自动检测修复（Doctor 工具）
- 支持任务阻塞状态持久化，避免碎片化

**② QQ Bot 官方插件（首个国内社交平台原生支持）**
- 完整支持：私聊、群聊、频道三大场景
- 功能：多账号配置、SecretRef 凭证管理、斜杠命令、定时提醒
- 支持：图片/语音/视频/文件收发（富媒体）
- 腾讯云轻量协同 QQ 团队贡献代码，已合入主仓库

**③ MCP 远程服务器支持**
- `mcp.servers` 支持配置 HTTP/SSE 远程地址
- 支持认证请求头

**④ Matrix 生态增强**
- 新增 `channels.matrix.historyLimit` 配置，支持群组历史上下文
- HTTP 代理支持：`channels.matrix.proxy`
- 流式回复草稿（部分回复可原地更新同一消息）

**⑤ 其他平台更新**
- WhatsApp 支持 Emoji 回应
- Slack 执行审批直接在 Slack 内完成，无需回退 Web UI
- LINE 富媒体发送（图片/视频/音频）
- Android 通知转发支持应用过滤、静默时段、速率限制

### 📦 v2026.3.28 更新（2026-03-28/29）

#### 破坏性变更

| 变更项 | 说明 |
|--------|------|
| **Qwen portal-auth 彻底移除** | 旧版 `portal.qwen.ai` OAuth 集成删除，需切换至 Model Studio API Key：`openclaw onboard --auth-choice modelstudio-api-key` |
| **配置迁移规则调整** | 超过 2 个月的旧版配置不再自动迁移，直接报错；需手动清理 `openclaw.json` 中遗留字段 |

#### 核心新功能

- **xAI / Grok → Responses API**：原生支持联网搜索，配置密钥后自动启用
- **MiniMax 图像生成**：新增 `image-01` 模型支持，支持图像生成和编辑
- **插件执行审批机制**：`requireApproval` 钩子支持暂停工具执行并等待审批（支持 Telegram 按钮、Discord 交互）
- **Slack 文件上传**：`upload-file` 操作增强
- **Matrix E2EE 优化**：加密图像缩略图改用 `thumbnail_file`，更安全

## ❓ 常见问题与解决

### Q1: 升级 v2026.3.31 后插件无法安装？
A: 新版默认拦截危险代码，Critical 级别直接阻止。如确认安全，手动加 `--dangerously-force-unsafe-install`。

### Q2: Node 命令突然无法使用？
A: v2026.3.31 收紧权限，设备配对不足以使用 Node 命令。需完成完整的 pairing approval 流程。

### Q3: Qwen Bot 无响应？
A: `qwen-portal-auth` 在 v2026.3.28 中已彻底移除。运行 `openclaw onboard --auth-choice modelstudio-api-key` 重新认证。

### Q4: 旧配置升级后报错？
A: v2026.3.28+ 停止自动迁移超过 2 个月的旧配置。手动清理 `openclaw.json` 中过时的字段。

### Q5: 设备令牌需要轮换吗？
A: 建议轮换。v2026.3.31 改进了令牌旋转机制，轮换后旧会话立即失效。

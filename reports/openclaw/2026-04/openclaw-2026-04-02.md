## 🔒 安全专栏：CNCERT + 工信部联合预警（最高级别）

### 新漏洞：CVE-2026-32914（CVSS 8.7 高危）

| 项目 | 详情 |
|------|------|
| 漏洞类型 | 未授权访问（/config、/debug 接口权限校验缺失） |
| 影响版本 | openclaw ≤ 2026.3.11 |
| 修复版本 | openclaw ≥ 2026.3.12 |
| 利用难度 | 低（无需用户交互） |
| 在野利用 | 未发现 |

**漏洞原理**：/config、/debug 等敏感接口仅校验 command-authorized 权限，未验证 owner 身份，导致具备基础命令执行权限的账号可读取/篡改系统关键配置。

### v2026.3.31 安全三大收紧

| 收紧项 | 说明 |
|--------|------|
| **插件安装默认拒绝** | 含 critical 级安全发现的插件默认阻止安装（需 `--dangerously-force-unsafe-install` 显式强制） |
| **网关认证强化** | trusted-proxy 拒绝混合共享令牌，本地直连也需配置令牌 |
| **节点命令权限收紧** | 配对后仍需完成审批才可使用节点命令 |

### 工信部四大安全红线（必读）

1. **严禁公网裸奔**：18789 端口禁止直接暴露，使用防火墙/VPN/SSH tunnel
2. **凭证加密管理**：API Key 禁止明文存储，定期轮换，留存操作日志 ≥ 6 个月
3. **严控插件来源**：仅装 ClawHub 签名插件，拒绝任何要求"执行shell/输入密码/下载未知包"的插件
4. **及时打补丁**：第一时间更新，建议订阅 GitHub releases

## 🔧 配置技巧

### 定时任务四种配置方式（官方最新）

```bash
# 方式一：CLI（推荐）
openclaw cron add --name "配置专家日报" \
  --cron "0 22 * * *" \
  --session isolated \
  --message "生成今日OpenClaw技术周报" \
  --announce --channel dingtalk \
  --to "03003745585526383319" \
  --tz "Asia/Shanghai"

# 方式二：手动编辑 jobs.json
~/.openclaw/cron/jobs.json

# 方式三：系统 crontab + Shell 脚本
0 22 * * * openclaw cron run --name "配置专家日报"

# 方式四：Workflow YAML（复杂多步骤任务）
```

## ❓ 常见问题与解决

| 问题 | 解决方案 |
|------|----------|
| 钉钉 401 | 检查 `gateway.auth` 中的 token/password 与钉钉后台一致 |
| 钉钉 405 | 设置 `channels.dingtalk.compatibilityMode: true` |
| 插件安装被拒 | v2026.3.31 默认拒绝含 critical 安全问题的插件，检查插件来源 |
| 定时任务未执行 | 检查 `~/.openclaw/cron/jobs.json` 状态，用 `openclaw cron run --force` 手动重试 |
| Gateway 无法访问 | 确认 `gateway.bind=127.0.0.1`，用 `http://127.0.0.1:18789/` 访问 |
| 子代理超时 | v2026.3.23 已修复，更新后重试 |
| Qwen 无法连接 | v2026.3.28 彻底移除 qwen-portal-auth，需切换 Model Studio API Key |

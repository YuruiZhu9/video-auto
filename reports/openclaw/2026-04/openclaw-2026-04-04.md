1. `@BotFather` 创建机器人，获取 Token
2. `/setprivacy` → Disable（群聊必需）
3. CLI 配置：`openclaw channels add` → Telegram Bot API → 粘贴 Token

## ❓ 常见问题与解决

### Q1: Anthropic 切断 Claude 订阅后，我的 OpenClaw 还能用 Claude 吗？
**A：** 可以，但需要换成独立的 Claude API Key。在 [Anthropic 开发者平台](https://console.anthropic.com/) 申请，通过 `OPENCLAW_API_KEY` 环境变量注入，OpenClaw 会自动路由。

### Q2: Task Flow 功能之前消失，现在恢复了吗？
**A：** 是的，v2026.4.2 正式恢复了 Task Flow 核心功能，支持托管和镜像同步两种模式。可通过 `openclaw flows list` 查看状态。

### Q3: v2026.4.2 的 xAI 配置迁移会影响我吗？
**A：** 如果你使用 xAI Grok 模型，会受影响。运行 `openclaw doctor --fix` 可自动迁移配置，无需手动修改。

### Q4: macOS 语音唤醒功能怎么开启？
**A：** 这是 v2026.4.1 新增功能，需在 macOS 端安装 OpenClaw 客户端并开启 Voice Wake 参数。具体配置见官方文档。

### Q5: 钉钉接入还是报 401/405 错误？
**A：** 最新方案：
- **401**：检查 `gateway.auth` 中的 token/password 与钉钉后台一致
- **405**：`channels.dingtalk.compatibilityMode: true` 启用兼容模式
- 确认 Gateway 运行在 18789 端口

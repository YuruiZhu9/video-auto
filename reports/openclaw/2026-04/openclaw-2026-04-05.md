# OpenClaw 配置周刊 - 2026年4月5日

## 🚨 本期头条：Anthropic 正式切断 OpenClaw Claude 订阅支持

**来源：Business Insider（2026-04-03）**

Anthropic 于 4月3日（周五）晚间宣布：Claude 订阅（Claude Max/Pro 等）将不再支持 OpenClaw 等第三方工具，太平洋时间 4月4日中午12点（即北京时间 4月5日凌晨）正式生效。

**Anthropic 官方理由：**
- "第三方工具对我们的系统造成了过大压力（outsized strain）"
- "订阅服务并非为这类第三方工具的使用模式而设计"
- Claude 正面临巨大算力需求，需优先保障直接用户

**OpenClaw 创始人 Peter Steinberger 回应：**
- 曾与 Dave Morin（OpenClaw 基金会董事）共同谈判，争取到了一周缓冲期
- 批评 Anthropic "选择在周五晚间悄悄发布消息"
- 指出许多用户是因为 OpenClaw 才订阅 Claude，这将造成用户流失

**用户应对方案：**
1. **申请独立 Claude API Key** → Anthropic 开发者平台（console.anthropic.com），按量付费
2. **切换国内大模型** → DeepSeek / 智谱 GLM / 通义千问 / MiniMax（均已原生支持）
3. **Claude Max 用户** → 可使用"额外用量包"（extra usage bundles）绑定原账号

## 🔧 配置技巧

### Anthropic 断供后的紧急迁移方案

**立即检查当前模型配置：**
```bash
openclaw config get | grep -A5 "model"
```

**推荐国内模型一键切换（按场景）：**

```bash
# 通用对话 → 豆包/火山引擎（性价比最高）
openclaw config set agents.defaults.model.primary "volcengine/doubao-pro-32k"

# 长文档/代码 → 智谱 GLM-5.1
openclaw config set agents.defaults.model.primary "glm/glm-5.1"

# 推理/分析 → DeepSeek R1
openclaw config set agents.defaults.model.primary "deepseek/deepseek-r1"

# 创意写作/角色扮演 → MiniMax M2.7
openclaw config set agents.defaults.model.primary "minimax/MiniMax-M2.7"

# 重启 Gateway 生效
openclaw gateway restart
```

**保留 Claude 订阅的过渡方案（仅限订阅未完全切断前）：**
```bash
# 如果你仍有有效的 Claude API Key（非订阅），直接配置：
openclaw config set agents.anthropic.key "sk-ant-..."
```

### QQ Bot 配置（v2026.3.31+ 新增国内原生支持）

QQ Bot 现已支持私聊/群聊/频道/多媒体，是首个国内社交平台原生支持：

```bash
# 安装 QQ Bot 插件
openclaw plugins install @openclaw/openclaw-qq

# 配置 QQ Bot Token（在 QQ 开放平台获取）
openclaw config set channels.qq.botToken "YOUR_QQ_BOT_TOKEN"

# 重启
openclaw gateway restart
```

## ❓ 常见问题与解决

### Q1：Anthropic 断供后 OpenClaw 还能用 Claude 吗？
**可以**，但需要独立的 Claude API Key（开发者平台购买，非订阅）。订阅凭证已不可用。

### Q2：国内模型哪个最适合替代 Claude？
- **通用对话/日常任务** → 豆包/火山引擎（延迟低、成本低）
- **长文档理解/代码生成** → 智谱 GLM-5.1
- **复杂推理/分析** → DeepSeek R1
- **创意写作/角色扮演** → MiniMax M2.7

### Q3：QQ Bot 收不到消息怎么办？
1. 检查 botToken 是否正确配置
2. 确认 QQ 开放平台 Webhook 已指向 `https://你的域名/qq`
3. 验证 `channels.qq.enabled: true`

### Q4：定时任务突然不执行了？
```bash
# 检查 cron 是否启用
openclaw cron list

# 手动触发测试
openclaw cron run --force <job-id>

# 查看 cron 运行历史
openclaw cron runs
```

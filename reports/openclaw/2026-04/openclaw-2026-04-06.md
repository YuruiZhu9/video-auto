## 🚨 超级重磅：Anthropic 正式封禁 OpenClaw（本期头条）

### 事件始末

**2026年4月4日（太平洋时间中午12点）**，Anthropic 正式切断 OpenClaw 等所有第三方工具对 Claude 订阅额度的调用权限。这是 AI 发展史上首次头部模型厂商公开封禁热门开源生态工具。

### 完整时间线

| 时间 | 事件 |
|------|------|

| 2026-03-28 | Peter Steinberger 与 Anthropic 谈判，**仅成功推迟一周** |
| **2026-04-04 12:00 PT** | **正式断供**——Claude 订阅不再覆盖任何第三方工具 |

### Anthropic 复制的"对标功能"

| OpenClaw 原生功能 | Anthropic 复制时间 | 新产品名称 |
|-----------------|-----------------|-----------|
| 移动端 → 桌面端持久线程 | 2026-02 | **Dispatch** |

> Peter Steinberger：「我和 Dave Morin 尽力去说服 Anthropic，最终只是成功将此事推迟了一周。先将流行功能复制到封闭框架，再将开源软件拒之门外。」

### 真实原因

Claude Max $200/月订阅被 OpenClaw 用户用出了 **$5,000 实际算力**（25倍超额）。OpenClaw 用户是最重度使用者：多 Agent 并行、7×24 不停机、高度压缩请求数。对 Anthropic 而言是结构性亏损。

## 🔧 配置技巧

### 方案一：继续用 OpenClaw + 国内兼容端点（推荐）

将 `providers.anthropic.baseUrl` 指向国内兼容端点，无需翻墙：

```json
{
  "providers": {
    "anthropic": {
      "baseUrl": "https://api.qnaigc.com",
      "apiKey": "your-api-key"
    }
  }
}
```

### 方案二：申请独立 Claude API Key

```bash
# 获取 sk-ant-api03- 前缀 Key，不受 OAuth 封锁
# 费用：按量计费，无订阅补贴
```

### 方案三：迁移到 LobeHub（开源替代）

LobeHub 优势：
- 完全自研 Agent 基础设施，不依赖 Anthropic
- 模型无关（Claude/GPT/Gemini 可混用）
- 无订阅透传，政策变化无感知
- Community Edition 免费开源，自托管部署

```bash
# 官网：https://lobehub.com
# GitHub：https://github.com/lobehub/lobe-chat
```

### 方案四：Linclaw（七牛云桌面版）

- macOS/Windows 双端开箱即用
- 内置国产大模型
- 不依赖 Claude OAuth 认证链路

## ❓ 常见问题与解决

### Q1：Claude 订阅被封了，OpenClaw 还能用吗？
**A：** 可以。OpenClaw 本身是框架，支持接入任意兼容 API 的模型。推荐切换到 MiniMax、DeepSeek、GLM-4 等国内模型。

### Q2：Google Gemini 还能用吗？
**A：** ⚠️ 2026年2月起，多名 OpenClaw 用户因绕过 Gemini CLI 配额被 Google **永久封号且无法申诉**。建议 Gemini 用户仅使用标准付费 API Key。

### Q3：Peter Steinberger 现在去哪了？
**A：** 据 SegmentFault 报道，Peter Steinberger 今年初已加入 **OpenAI**。用 Claude 全程构建的工具，其创始人现已效力于 Anthropic 最直接的竞争对手。

### Q4：OpenClaw GitHub Star 现在多少？
**A：** 约 **31万+**，但封禁事件可能导致增长放缓或社区分流。

### Q5：国内替代模型推荐？

## 🔧 配置技巧

### 升级避坑五问（来自社区实战）

**问题一：双版本共存导致 PATH 缓存**
```
# 检查实际安装位置
which openclaw
npm list -g openclaw
# 彻底卸载所有版本
sudo npm uninstall -g openclaw
npm uninstall -g openclaw
# 清理 shell 缓存
hash -r && rehash
```

**问题二：配置文件被自动覆盖**
- 升级时 OpenClaw 会自动备份旧配置（`.clobbered` 结尾）
- **升级前务必备份**：`cp ~/.openclaw/openclaw.json ~/.openclaw/openclaw.json.bak`

**问题三：路由绑定丢失**
- `openclaw agents bind` 是临时性的，升级后丢失
- **正确做法**：直接将绑定写入配置文件 JSON

**问题四：插件重复注册**
- 日志中出现 `channel already registered` 警告
- 检查 `plugins.allow` 配置，移除重复条目

**问题五：不查阅文档就动手**
- 维护前先：`openclaw docs llms.txt` + `openclaw doctor`

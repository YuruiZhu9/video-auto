## 🔧 配置技巧

### 1. 非 git 安装手动升级步骤
由于当前系统 OpenClaw 由 npm 全局安装，`openclaw update` 会跳过，需：
```bash
# 1. 备份配置
cp ~/.openclaw/openclaw.json ~/.openclaw/openclaw.json.bak-$(date +%Y%m%d)

# 2. 升级
npm install -g openclaw@latest

# 3. 修复配置迁移
openclaw doctor --fix

# 4. 重启
openclaw gateway restart

# 5. 确认版本
openclaw --version
```

## ❓ 常见问题与解决

### 🔴 当前发现的安全问题
| 问题 | 严重度 | 说明 |
|------|--------|------|
| `/root/.openclaw` 权限 777 | **CRITICAL** | 所有人可写，同机器其他进程可篡改状态 |
| `/root/.openclaw/agents` 权限 770 | **CRITICAL** | agents 目录权限过宽 |

**立即修复：**
```bash
chmod 700 /root/.openclaw
chmod 700 /root/.openclaw/agents
chmod 700 /root/.openclaw/sessions
```

### 其他高频问题
| 问题 | 解决 |
|------|------|
| `channel already registered` | 检查 `plugins.allow` 移除重复条目 |
| 钉钉无响应 | 确认 Gateway 运行 + 检查 `gateway.bind=127.0.0.1` |
| 钉钉 401 | 检查 `gateway.auth` token/password 与后台一致 |
| 钉钉 405 | 启用 `channels.dingtalk.compatibilityMode: true` |
| 双版本共存 | `sudo npm uninstall -g openclaw && npm install -g openclaw@latest` |

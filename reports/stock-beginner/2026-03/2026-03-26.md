## 基础概念讲解

### 📚 今日科普：什么是"均线"？

**均线 = 过去N天的平均价格连成的线**

| 均线 | 含义 |
|------|------|
| **5日均线**（MA5） | 最近5个交易日的平均价格，反映短期趋势 |
| **10日均线**（MA10） | 最近10天的平均价格，反映中期趋势 |
| **20日均线**（MA20） | 最近一个月的平均价格，月线 |

**怎么看？**
- 股价在均线上方 → 短期偏强 ✅
- 股价在均线下方 → 短期偏弱 ❌
- 均线多头排列（5日 > 10日 > 20日）→ 上涨趋势
- 均线空头排列（5日 < 10日 < 20日）→ 下跌趋势

**今日行情对应**：
> 上证指数目前约在3900点附近，对应均线系统在相对高位，说明市场近期整体偏强，但今天有所回落，说明短线有调整压力。

## 入局建议（新手必读）

### ⚖️ 风险承受能力自测

开始投资前，先问自己：

| 问题 | 参考答案 |
|------|----------|
| 你能承受多少本金损失？ | 建议最多承受投入金额的20%-30% |
| 亏损会影响生活质量吗？ | 如果会，建议先不要实盘 |
| 这笔钱多久不用？ | 至少1-3年不用的闲钱 |

### 📝 模拟盘练习计划

**强烈建议新手先练3-6个月模拟盘！**

模拟盘练习重点：
1. **记录每次买卖理由**（哪怕只是模拟，也要认真对待）
2. **对比自己的判断和市场实际走势**
3. **总结错误**，形成自己的投资逻辑

### 💰 资金分配原则

如果决定开始实战，遵守以下原则：

| 原则 | 说明 |
|------|------|
| **只用闲钱** | 至少1-3年不用的钱，绝不用生活费 |
| **单只仓位≤20%** | 任何一只股票不超过总资金20% |
| **分散3-5只** | 不要all in一只，分散风险 |
| **分批买入** | 不要一把梭，分2-3次买入 |

### 重要论文/报告（近7天，来源：arXiv）

#### 1. LLMTailor：大模型高效检查点的逐层裁剪工具
- **作者**：Minqiu Sun 等（2026-02-25）
- **摘要**：训练大模型时，检查点保存（Checkpointing）是容错的关键机制，但开销巨大。LLMTailor 提出了逐层裁剪的方法，能够根据每一层的重要性动态决定保存精度，大幅降低存储和通信成本，同时保证训练恢复质量。
- **工程意义**：对于需要大规模分布式训练的算法工程师，这类工程优化工具直接关系到训练成本和稳定性。

#### 2. Dynamic Personality Adaptation via State Machines（状态机驱动的大模型动态人格适应）
- **作者**：Leon Pielage 等（2026-02-25）
- **摘要**：当前 LLM 在多轮对话中难以保持一致且动态变化的"人格"。该工作引入有限状态机来建模 LLM 的对话状态，使其能够根据对话流程自然切换角色状态，提升对话体验。
- **工程意义**：对话系统、推荐 agent 的个性化设计有参考价值。

#### 3. Multi-Objective Safe LLM Alignment via Optimistic Primal-Dual（多目标安全对齐新方法）
- **作者**：Yining Li 等（2026-02-25）
- **摘要**：RLHF（人类反馈强化学习）是当前 LLM 对齐的主流方法。该论文将多目标约束的 RLHF 建模为原始-对偶优化问题，提出"乐观原始-对偶"算法，理论上证明了最后迭代收敛性（Last-Iterate Convergence），解决了标准方法只能保证平均收敛的问题。
- **工程意义**：对需要在多个目标（安全、有用、无害）之间权衡的 LLM 对齐研究有直接指导价值。

#### 4. NoLan：动态压制语言先验以减少视觉大模型幻觉
- **作者**：Lingfeng Ren 等（2026-02-25）
- **摘要**：多模态 LLM（MLLM）在图像理解时容易"幻觉"出图中不存在的物体。NoLan 通过动态识别并压制语言先验（语言模型的惯性偏见），让模型更关注视觉信息，显著降低幻觉率。
- **工程意义**：多模态推荐系统（图文内容理解）的基础能力提升。

#### 5. Confidence-Driven Multi-Scale Model Selection for Cost-Efficient Inference（置信度驱动的多尺度模型选择）
- **作者**：Bo-Wei Chen 等（2026-02-25）
- **摘要**：在推理阶段，根据输入难度动态选择大/小模型（"级联推理"），对于简单输入用小模型，对于复杂输入才调用大模型，大幅降低推理成本同时保持准确率。
- **工程意义**：工业落地中的推理成本优化，推荐系统中的多级召回/排序有类似思路可借鉴。

- **关键词**：Pre-Ranking、生成式伪标签、数据增强

#### 4. From Logs to Language: Learning Optimal Verbalization for LLM-Based Recommendation in Production
- **作者**：Yucheng Shi 等（2026-02-24）

## 🤖 推荐系统 × 大模型 最新研究

### 推荐阅读论文（来自 arXiv / ICLR 2026）

**1. RankMixer: Scaling Up Ranking Models in Industrial Recommenders**（2026-02-21）
- **核心问题：** 工业级推荐排序在 LLM 时代的规模化部署困境
- **两大挑战：** ① 严格时延与高QPS约束下成本受限；② 现有排序模型扩展时效果增益有限
- **意义：** 直击工业落地痛点，为面试"大规模推荐系统设计"提供最新参考

**2. Generative Recommendation for Large-Scale Advertising（arXiv）**
- 生成式推荐在广告系统的大规模部署实践
- 实时生成推荐的可行性探索，潜力巨大

**3. Fine-grained Semantics Integration for LLM-based Recommendation（arXiv）**
- 将 LLM 语义能力细粒度融入推荐系统
- 解决 LLM 理解用户意图 vs. 协同过滤信号整合问题

**4. Turning Semantics into Topology: LLM-Driven Attribute Augmentation for Collaborative Filtering（arXiv）**
- LLM 驱动的图拓扑增强，提升协同过滤效果
- **对转型重点：** 图神经网络 + LLM 是当前热点融合方向

**5. Offline Reasoning for Efficient Recommendation: LLM-Empowered Persona-Profiled Item Indexing（arXiv）**
- 离线 LLM 推理生成用户画像索引，规避在线推理延迟
- **工程视角：** 工业可落地的 LLM+推荐 架构思路

**6. AgentLTV: Agent-Based Framework for Automated Lifetime Value Prediction（arXiv）**
- Agent框架用于用户生命周期价值预测
- 推荐 × Agent 的新范式，与广告系统深度结合

**7. ICLR 2026 | LightRetriever：把 LLM Embedding 算力瓶颈从 Query 侧移走**
- SOTA LLM Embedding Model 参数量普遍 7B+，部署成本极高
- LightRetriever 创新架构，大幅降低在线 Query 计算负担
- **直接相关：** 向量召回（Embedding Recall）是推荐系统核心模块

**8. ICLR 2026 | LightMem：大模型长期记忆的低成本方案**
- 解决 Agent 多轮对话中上下文窗口溢出、"lost in the middle"问题
- 为 LLM 推荐系统中的用户历史序列建模提供新思路

### 推荐系统算法工程师 - 核心技能要求

**必备（入门门槛）：**
- 深度学习基础：PyTorch/TensorFlow，熟悉 Transformer 架构
- 推荐系统基础管道：召回（ANN/双塔）→ 粗排 → 精排 → 重排
- 特征工程：用户/物品 Embedding，行为序列建模
- 分布式训练：Spark/Flink 大规模数据处理
- 经典模型：DIN、DSSM、DeepFM、SASRec

**进阶（竞争力提升）：**
- LLM 与推荐融合：语义召回、LLM 排序、提示词工程
- 图神经网络：GraphSAGE、LightGCN 用于协同过滤增强
- 多任务学习：MMoE、PLE 框架
- 强化学习：用户长期价值优化（LTV）
- 工程优化：TensorRT、量化剪枝、低延迟推理部署

**新兴热点（差异化竞争力）：**
- **生成式推荐：** LLM 直接生成 Item ID / 语义检索
- **Agentic 推荐：** 多步推理 + 工具调用的用户意图理解
- **多模态推荐：** 图文视频统一 Embedding（与 Gemini 3.1 类技术对接）
- **LLM Embedding / 向量检索优化：** 参考 LightRetriever 架构
- **MCP（Model Context Protocol）：** 2026年最热新标准，用于 Agent 工具集成

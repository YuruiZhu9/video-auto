## 避坑总纲

1. **音频质量差**：优先使用字幕文件（CC），而非 ASR 转写
2. **长视频分段**：超过 30 分钟的视频建议分段处理，防止 LLM 上下文溢出
3. **画面信息为主**：选择 `videos_understand` 多帧输入，而非单帧截图
4. **版权风险**：转录和总结仅供个人学习，避免大规模传播原始内容
5. **中文视频**：B站/抖音等平台优先使用官方字幕接口，ASR 对中文口音识别率低

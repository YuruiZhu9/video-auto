# 开源项目演示类 - Doubao Video Analyzer 多模态视频解析技能

## 核心工具/API

| 工具 | 作用 | 备注 |
|------|------|------|
| **Doubao 2.0（豆包大模型）** | 视频多模态理解核心 | 字节跳动大模型 |
| **doubao-video-analyzer Skill** | OpenClaw集成技能 | ClawHub安装 |
| **视频文件/URL** | 支持本地路径或网络链接 | 需视频可访问 |

---

## 步骤流程

### 安装

```bash
# 通过 clawhub 安装
clawhub install doubao-video-analyzer
# 或
npx skills add doubao-video-analyzer
```

### 在OpenClaw中调用

```
/video-analyze <本地视频路径或网络URL>
```

### 适用条件

- 持有本地视频路径或网络视频链接
- 视频格式需为常见格式（mp4/mov/avi等）
- 网络视频需可公网访问

---

## 适用场景

- ✅ **开源项目演示视频**：理解UI操作、代码演示、效果展示
- ✅ **技术Demo解析**：提取关键操作步骤和实现逻辑
- ✅ **产品演示分析**：理解产品功能、用户旅程、亮点卖点
- ✅ **多模态综合理解**：视觉+语音+字幕联合分析，适合复杂视频
- ✅ **视频问答**：对视频内容进行自由问答式查询

---

## 避坑指南

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 视频无法访问 | 网络视频需要公网可访问 | 下载到本地，使用本地路径 |
| 视频格式不支持 | 罕见编码格式 | 转码为H.264 |
| 视频太长超时 | 单次分析长度有限制 | 建议分段处理（每段<10分钟） |
| 分析结果与预期不符 | prompt不够具体 | 补充分析要求，如"重点关注代码实现部分" |
| 无声音频 | 视频无音频轨道 | 豆包仍可分析画面，但效果有限 |

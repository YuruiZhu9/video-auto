# 开源项目演示类 - 分步骤拆解法

## 核心工具/API
- **videos_understand**: 提取演示关键步骤和操作流程
- **browser**: 获取项目文档、GitHub 页面信息
- **read**: 读取项目 README、文档进行对照
- **web_search**: 搜索项目相关资料和版本信息

## 步骤流程
1. **初步观看**：了解演示的整体结构和目标
2. **步骤提取**：
   - 使用 videos_understand 提取关键操作步骤
   - 记录每一步的点击位置、输入内容、命令参数
3. **文档对照**：
   - 获取项目官方文档（README、docs）
   - 对照验证操作步骤的准确性
4. **环境确认**：
   - 记录所需的依赖环境
   - 确认软件版本要求
5. **整理输出**：
   - 整理成可执行的安装/使用指南
   - 补充文档中遗漏的细节
   - 添加常见问题说明

## 适用场景
- GitHub 项目演示视频
- 开源工具/框架使用教程
- Demo 展示和功能介绍视频
- 产品功能演示视频

## 避坑指南
- **环境依赖**：详细记录所有依赖和环境配置要求
- **版本差异**：注意演示版本与当前版本的差异，可能导致操作不同
- **初始化步骤**：演示中可能跳过了初始化/配置步骤，需要补充
- **权限配置**：演示中可能涉及权限配置，需要单独说明
- **网络要求**：注意是否有特殊的网络要求（如访问特定资源）

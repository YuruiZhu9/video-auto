# 开源项目演示类 - 多工具组合方案

## 组合方案总览

开源项目 Demo 视频通常包含：代码演示 + 界面操作 + 口述讲解。单一工具难以完整提取，需要**多工具串联**。

```
视频文件/URL
    │
    ├─ 方案A（推荐）: 全自动一站式
    │       └─▶ summarize + videos_understand → 综合报告
    │
    ├─ 方案B: 音频优先 → 文字稿 + 画面补充
    │       ├─▶ whisper/whisper-api → 完整文字稿
    │       ├─▶ video-frames → 关键帧截图
    │       └─▶ images_understand → 画面技术信息
    │
    └─ 方案C: 分步精细处理
            ├─▶ yt-dlp → 本地视频
            ├─▶ ffmpeg → 提取音频 + 截帧
            ├─▶ whisper-api → 转录
            ├─▶ videos_understand → 深度分析
            └─▶ 结构化输出
```

## 方案A：summarize + videos_understand（推荐）

### 适用场景
技术教程、开源项目 README 配套视频、Bilibili 技术 UP 主内容

### 执行步骤
```bash
# Step 1: 快速摘要（获取整体结构）
summarize "https://youtu.be/xxxxx" --youtube auto --length medium

# Step 2: 深度分析（提取技术细节）
# 通过 videos_understand 传入视频路径 + 详细 Prompt

# Prompt 示例：
"""
请深度分析这个开源项目演示视频：
1. 项目名称和定位（一句话描述）
2. 核心功能演示（按时间顺序列出）
3. 技术栈（列出所有使用的技术/框架/工具）
4. 关键代码片段（截取的画面中展示的代码）
5. 亮点与创新点（3条以内）
6. 适用场景与目标用户
7. 可改进之处（作为reviewer的建议）
"""
```

### 输出质量
- ✅ 结构完整、语义理解准确
- ✅ 无需下载，快速执行
- ⚠️ 依赖字幕/语音质量，无字幕时质量下降

## 方案B：whisper + video-frames + images_understand

### 适用场景
无字幕但有代码演示的技术视频；需要精确代码片段

### 执行步骤
```bash
# Step 1: 下载视频（如果是在线视频）
yt-dlp -f "bestvideo+bestaudio/best" "VIDEO_URL" -o "video.%(ext)s"

# Step 2: 提取音频 → 转录
ffmpeg -i video.mp4 -vn -acodec pcm_s16le -ar 16000 audio.wav
whisper audio.wav --model medium --output_format json --output_dir transcripts/

# Step 3: 批量截帧（每30秒一帧）
mkdir -p frames
ffmpeg -i video.mp4 -vf "fps=1/30,scale=1280:720" "frames/frame_%04d.jpg"

# Step 4: 批量分析帧（提取代码/UI信息）
# 通过 images_understand 并行分析所有帧
# Prompt: "描述这张图片中的代码或界面，提取技术关键词"
```

### 输出质量
- ✅ 完整文字稿（whisper 转录）
- ✅ 代码片段精确（截帧分析）
- ✅ 不依赖视频字幕
- ⚠️ 流程较长，约 10-20 分钟/视频

## 方案C：完整 Pipeline（工业级）

### 适用场景
需要产出高质量结构化报告；多视频批量处理

```python
# Python Pipeline 示例伪代码
import subprocess
import json

def video_analysis_pipeline(video_path_or_url):
    results = {}
    
    # 1. 本地化
    if video_path_or_url.startswith("http"):
        subprocess.run(["yt-dlp", "-f", "best", "-o", "temp.mp4", video_path_or_url])
        video_path = "temp.mp4"
    else:
        video_path = video_path_or_url
    
    # 2. 提取音频
    subprocess.run([
        "ffmpeg", "-y", "-i", video_path,
        "-vn", "-acodec", "pcm_s16le", "-ar", "16000", "audio.wav"
    ])
    
    # 3. 转录
    subprocess.run([
        "whisper", "audio.wav",
        "--model", "medium",
        "--output_format", "json",
        "--output_dir", "transcripts/"
    ])
    
    # 4. 截帧（每60秒1帧）
    subprocess.run([
        "ffmpeg", "-y", "-i", video_path,
        "-vf", "fps=1/60,scale=1280:720",
        "frames/frame_%04d.jpg"
    ])
    
    # 5. videos_understand 综合分析
    # 调用 videos_understand Tool，传入 video_path + 结构化 Prompt
    
    return results
```

## 避坑指南

| 问题 | 解决方案 |
|------|---------|
| 视频代码一闪而过 | 提高截帧频率（fps=1/10），并在 Prompt 中说"注意快速出现的代码" |
| 音频和画面不同步 | whisper 生成时间戳，截帧时间对应校验 |
| 多视频批量处理 | 统一输出目录结构：video_id/frames/, video_id/transcript.txt |
| 视频有水印 | 截帧时用 ffmpeg crop 参数裁掉水印区域 |
| 中文技术术语 | 在所有 Prompt 中提供术语表（中英对照）|

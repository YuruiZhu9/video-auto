# 开源项目演示类 - 字幕 + 结构化解析方案

## 适用条件

> **前提**：视频已有字幕文件（SRT/VTT/ASS）或视频平台提供 CC 字幕

---

## 核心工具/API

| 工具 | 功能描述 |
|------|----------|
| `summarize --extract-only` | 从 YouTube/B 站 URL 直接提取字幕/文稿 |
| `ffmpeg` | 提取内嵌字幕流（将 ASS/SRT 从视频中导出） |
| `whisper` | 无字幕视频的语音转文字（作为兜底） |
| LLM（任意） | 将纯文本字幕结构化为知识点、技术细节 |

---

## 步骤流程

### 场景 1：YouTube/B站视频（有字幕 URL）

**最简路径：**
```bash
# 直接提取字幕 + 摘要
summarize "https://youtu.be/dQw4w9WgXcQ" \
  --youtube auto \
  --extract-only \
  --json \
  --out /tmp/transcript.json

# 完整摘要
summarize "https://youtu.be/dQw4w9WgXcQ" \
  --youtube auto \
  --length long
```

**字幕提取后结构化 Prompt：**
```
请将以下视频字幕整理为结构化笔记，包含：
1. 章节摘要（按时间戳划分）
2. 核心概念和定义
3. 关键技术点（含代码/命令）
4. 参考资源链接（演讲中提到的）
5. 待实践的操作步骤

字幕内容：
[粘贴字幕文本]
```

### 场景 2：本地视频（含内嵌字幕流）

```bash
# 查看字幕流
ffprobe -i video.mp4 -select_streams s -show_entries stream=index,codec_name,language,tags -of json

# 提取字幕（假设第一个字幕流）
ffmpeg -i video.mp4 -map 0:s:0 subtitles.srt

# 转换为纯文本（去除时间戳）
grep -v "^$" subtitles.srt | sed 's/^[0-9]*$//g' | tr '\n' ' ' > transcript.txt
```

### 场景 3：无字幕 → Whisper 转写

```bash
# 提取音频
ffmpeg -i video.mp4 -vn -acodec pcm_s16le -ar 16000 -ac 1 audio.wav

# 本地 Whisper 转写（推荐 medium 模型，中文更准）
whisper audio.wav \
  --model medium \
  --language zh \
  --output_format srt \
  --output_dir /tmp

# 或用 API（更快，费用低）
{baseDir}/scripts/transcribe.sh audio.wav --model whisper-1 --language zh --out /tmp/transcript.txt
```

### 场景 4：字幕 + LLM 结构化输出

**分步骤处理（适合1小时以上长视频）：**

1. 按字幕时间戳切分段落（每5-10分钟一段）
2. 每段生成摘要
3. 合并所有摘要 → 完整章节大纲
4. 针对感兴趣的章节深度展开

**结构化输出模板：**

```markdown
# [视频标题] - 结构化笔记

## 基本信息
- 时长：xx:xx
- 演讲者：xxx
- 频道/平台：xxx
- 视频链接：xxx

## 章节大纲
| 时间 | 章节 | 核心内容 |
|------|------|---------|
| 00:00-05:00 | 开场介绍 | 项目背景、解决的问题 |
| 05:00-15:00 | 核心架构 | 技术方案、模块划分 |
| ... | ... | ... |

## 关键技术点
### 1. [知识点名称]
- 说明：...
- 代码/命令：...
- 参考：时间戳 mm:ss

## 实践步骤
1. 第一步...
2. 第二步...

## 参考资源
- GitHub：...
- 文档：...
- 相关视频：...
```

## 适用场景

- ✅ YouTube 教程视频（有自动字幕）
- ✅ B站视频（UP主上传字幕或 AI 字幕）
- ✅ 会议/峰会演讲视频（有官方字幕）
- ✅ Coursera/edX 课程视频
- ✅ 公司技术分享（内部知识库整理）

---

## 避坑指南

| 坑点 | 解决方案 |
|------|----------|
| YouTube 自动字幕质量差（口音/术语错误） | 开启 Apify fallback：`APIFY_API_TOKEN` 环境变量；或用 Whisper 转写替代 |
| B站字幕是弹幕格式，非 SRT | 解析 ASS 格式，提取纯文本层；用 `ffmpeg -i video.mp4 -map 0:s:0` 导出 |
| 字幕时间轴不准（延迟/超前） | 手动微调或用 `aeneas` 自动对齐；也可忽略时间戳，只提取纯文本 |
| 视频有多语言字幕 | 指定语言：`--youtube auto --language zh`，或用 Whisper 指定 `--language en` |
| 转写结果太大（>50k tokens） | 分段处理：按字幕文件天然段落切分，逐段摘要再合并 |

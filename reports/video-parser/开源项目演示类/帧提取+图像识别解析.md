# 开源项目演示类 - 帧提取 + 图像识别解析方案

## 核心工具/API

| 工具 | 功能描述 |
|------|----------|
| `frame.sh` (ffmpeg) | 按时间戳或帧索引抽取视频画面，支持 PNG/JPG 输出 |
| `images_understand` | 批量图像理解，支持 OCR、代码识别、UI 分析（最多20张图） |
| `whisper` / `openai-whisper-api` | 音频转文字，提取 README 中未提及的旁白信息 |
| `extract_content_from_websites` | 解析项目 GitHub 首页/文档，获取上下文信息 |

---

## 步骤流程

### Phase 1：事前准备

1. **获取项目信息**（辅助理解视频）
   ```bash
   # 提取视频描述中的 GitHub 链接
   # 用 extract_content_from_websites 获取 README
   ```

2. **了解视频结构**
   - 看视频时长和章节（YouTube 视频描述通常有 timestamps）
   - 识别主要模块：Demo → Architecture → Code → Q&A

### Phase 2：关键帧提取策略

**按时间节点采样：**

```bash
# 项目介绍类（00:00-02:00）→ 抽1帧
# 架构图展示（02:00-05:00）→ 每30s抽1帧
# 代码演示（05:00-15:00）→ 每分钟抽1帧 + 关键代码帧
# 效果演示（15:00-20:00）→ 每分钟抽1帧
# 总结（最后1分钟）→ 1帧

for t in 00:00 00:30 01:00 02:00 03:00 05:00 07:00 10:00 15:00 20:00; do
  frame.sh demo.mp4 --time "00:$t" --out "/tmp/frame_${t}.jpg"
done
```

**智能抽帧（针对代码展示段）：**
```bash
# 识别变化剧烈的帧（场景切换检测）
ffmpeg -i demo.mp4 -vf "select='gt(scene,0.3)',showinfo" -frames:v 20 /tmp/scene_%03d.jpg
```

### Phase 3：批量图像分析

调用 `images_understand`（最多20张，分批）：

**Prompt 模板：**
> "你是开源项目分析专家。这个视频帧展示了[架构图/代码/UI/效果]。请提取：1）图中展示的内容；2）关键技术栈/框架/库；3）代码片段（如可识别）；4）性能数据（如有）"

**分类型 prompt：**

| 帧类型 | Prompt 重点 |
|--------|------------|
| 架构图 | 组件名称、关系、数据流、部署方式 |
| 代码 | 编程语言、框架、核心逻辑、代码行号 |
| UI 界面 | 功能模块、交互流程、界面技术 |
| 效果展示 | 性能指标、对比数据、可视化结果 |

### Phase 4：音频补充（如有旁白）

```bash
# 提取音频
ffmpeg -i demo.mp4 -vn -acodec pcm_s16le -ar 16000 -ac 1 audio.wav

# 转写
whisper audio.wav --model medium --output_format txt --output_dir /tmp
```

### Phase 5：合并输出

将多帧分析结果 + 音频转写 → LLM 汇总 → 结构化文档

## 避坑指南

| 坑点 | 解决方案 |
|------|----------|
| 代码帧文字太小看不清 | 提高输出分辨率：`frame.sh` 输出 PNG，用 2K 分辨率；或贴近屏幕录制时放大字体 |
| 抽帧数量太多，分析成本高 | 先用场景检测 `select='gt(scene,0.3)'` 过滤，再人工筛选关键帧 |
| 视频含大量动画/过渡效果 | 跳过动画段，专注代码/架构静态展示帧 |
| GitHub 链接失效 | 用 `extract_content_from_websites` 的 Wayback Machine 回溯 |
| 代码高亮颜色被压成纯色 | 优先找浅色背景的代码帧；视频录制时建议用浅色 IDE 主题 |

## 自动化 Pipeline（脚本化）

```bash
#!/bin/bash
# auto-extract-frames.sh
VIDEO="$1"
OUTPUT_DIR="$2"
mkdir -p "$OUTPUT_DIR"

# 每30秒抽一帧 + 场景切换帧
ffmpeg -i "$VIDEO" -vf "fps=1/30,scale=1920:1080" "$OUTPUT_DIR/frame_%04d.jpg"
ffmpeg -i "$VIDEO" -vf "select='gt(scene,0.4)',scale=1920:1080" -vsync vfr "$OUTPUT_DIR/scene_%04d.jpg"
echo "提取完成：$(ls $OUTPUT_DIR | wc -l) 帧"
```

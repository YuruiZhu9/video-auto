# [开源项目演示类] - 开源工具全链路解析方案

## 核心工具/API

- **video-analyzer**：Llama3.2 Vision + Whisper 端到端开源工具
  - GitHub：https://github.com/byjlw/video-analyzer
  - 特点：完全本地运行，支持 Ollama / OpenRouter 推理
  - 输出：JSON（视频元数据 + 音频转录 + 逐帧分析 + 整体描述）
  - 支持长视频处理，自动关键帧采样
- **HearSight**：智能音视频内容分析工具
  - GitHub：https://github.com/li-xiu-qi/HearSight
  - 多语言字幕生成 + NLP 结构化分析
  - 适合跨语言开源项目演示解析
- **video-frames + images_understand 组合**（OpenClaw 内置）：
  - `frame.sh`：FFmpeg 按时间戳/帧号提取帧
  - `images_understand`：视觉模型批量分析帧内容
  - 零依赖（无需 Ollama），直接调用云端 API
- **DeepSeek VL + FFmpeg 方案**（博客园实践）：
  - FFmpeg 提取关键帧 → DeepSeek VL 分析图片
  - TypeScript 脚本串联，适合有开发能力的团队

## 步骤流程

### 方案A：video-analyzer 完整链路（推荐）

```bash
# 1. 准备环境
git clone https://github.com/byjlw/video-analyzer.git
cd video-analyzer
python3 -m venv .venv && source .venv/bin/activate
pip install -e .
brew install ffmpeg      # macOS
# choco install ffmpeg   # Windows
# sudo apt install ffmpeg  # Ubuntu

# 2. 启动 Ollama（本地模型推理）
ollama serve
ollama pull llama3.2-vision  # 首次运行下载模型

# 3. 分析开源项目演示视频
video-analyzer opensource-demo.mp4

# 4. 查看输出（JSON 格式）
cat output/video-analysis.json
```

### 方案B：OpenClaw frame + images_understand 链路（零配置）

```bash
# 1. 提取关键帧（按时间点）
frame.sh demo.mp4 --time 00:01:00 --out /tmp/frame1.jpg
frame.sh demo.mp4 --time 00:03:30 --out /tmp/frame2.jpg
frame.sh demo.mp4 --time 00:07:00 --out /tmp/frame3.jpg

# 2. OpenClaw images_understand 批量分析
# （在 Agent 中调用 images_understand 工具）
```

### 方案C：Whisper 转录 + 开源代码解析

```bash
# 1. 下载并提取音频
yt-dlp -f best -o demo.mp4 "https://github.com/user/repo"
ffmpeg -i demo.mp4 -vn -acodec pcm_s16le -ar 16000 audio.wav

# 2. Whisper 转录（中文演示推荐 medium 模型）
whisper audio.wav --model medium --language Chinese --output_format srt

# 3. 结合开源项目 README + 字幕 → 结构化分析
```

## 适用场景

- GitHub 开源项目 README 配套视频演示解析
- 技术博主/大厂 B站/YouTube 开源项目发布视频

- 构建开源项目知识库（视频演示 → 功能清单）
- 竞品开源项目功能对比分析

## 避坑指南

- **video-analyzer 硬件要求**：Llama3.2 Vision 11B 至少需要 16GB 显存；建议使用 Ollama 量化版（q4_K_M）
- **Ollama 模型选择**：英文演示用 `llava`，中文演示用支持中文的视觉模型
- **长视频分段**：超过 30 分钟的演示视频建议先按功能模块分段，再分别解析
- **Whisper 中文噪音**：演示视频含大量代码旁白时，建议用 `--prompt` 参数注入专业术语上下文
- **GitHub 视频下载**：部分 GitHub 配套视频托管在 YouTube/B站，需用 yt-dlp 提取
- **帧采样策略**：开源演示视频节奏通常不均匀，建议优先用场景检测（scene detection）而非均匀采样

# 开源项目演示类 - 开源项目演示视频解析

> 适合对象：GitHub README 演示视频、Demo 录像、技术 demo 类视频

---

## 方法一：yt-dlp 提取项目视频 + FFmpeg 提取关键帧

### 核心工具/API
- **下载**：yt-dlp（支持 GitHub Release 页、B站、Github Gist）
- **帧提取**：FFmpeg / video-frames-skill
- **说明**：GitHub 项目通常附带 README 演示 GIF/MP4，可直接下载分析

### 步骤流程
```
1. 查找 README 中的视频/GIF 链接
   - GitHub raw 文件 / releases 附件 / Gist 视频

2. 用 yt-dlp 下载：
   yt-dlp "https://github.com/user/repo/releases/download/v1.0/demo.mp4" \
     -o "%(title)s.%(ext)s"

3. 关键帧提取（每3秒一帧）：
   frame-extractor sample -i demo.mp4 -o keyframes -t 3
```

### 适用场景
- 分析开源项目的 README Demo 视频
- 快速了解项目功能和使用界面

### 避坑指南
- ⚠️ 部分项目用 Loom / ScreenToGif 生成 GIF，需先转换为 MP4
- ⚠️ 提取帧建议 3-5 秒一帧，避免遗漏关键步骤

## 方法二：VideoPipe（开源视频分析框架）

### 核心工具/API
- **GitHub**：https://github.com/sherlockchou86/VideoPipe
- **语言**：C++，跨平台（x86_64/aarch64）
- **说明**：类 DeepStream 架构的轻量级视频分析框架，管道式节点设计

### 架构设计
```
VideoPipe 管道：
  [视频输入] → [解码节点] → [AI推理节点] → [业务逻辑节点] → [结构化输出]
       ↓
  每个节点独立，可自由组合
```

### 支持节点类型
| 节点类型 | 功能 |
|---------|------|
| 解码节点 | 支持 RTSP/HTTP/MP4 等多种视频流协议 |
| 目标检测节点 | YOLO 等目标检测模型集成 |
| OSD 节点 | 在画面上叠加文字/框标注 |
| 输出节点 | JSON/文件/消息队列输出 |

### 步骤流程
```
1. 安装（Ubuntu / NVIDIA GPU）：
2. 编写管道配置 JSON
3. ./videopipe --config pipeline.json
4. 获取结构化输出（目标类别、置信度、边界框）
```

### 适用场景
- 大量开源 demo 视频的自动化结构化分析
- 人脸/物体识别类 demo 视频的定量统计

### 避坑指南
- ⚠️ 需要 C++ 开发能力，门槛较高
- ⚠️ 主要针对计算机视觉任务，不擅长理解语义内容

## 方法三：summarize 一键分析（最简方案）

### 核心工具/API
- **工具**：summarize（OpenClaw 内置）
- **说明**：最简单快速的方案，适合只需要了解 Demo 内容的场景

### 步骤流程
```
1. 找到 Demo 视频 URL
2. 执行：summarize "https://youtube.com/watch?v=xxx" --youtube auto
```

### 适用场景
- 快速了解某个开源项目的 Demo 视频内容
- 不需要精确分析，只需要概览

### 避坑指南
- ⚠️ summarize 分析 README 页面内容，而非内嵌视频本身
- ⚠️ 内嵌 Loom/GitHub 视频可能无法提取

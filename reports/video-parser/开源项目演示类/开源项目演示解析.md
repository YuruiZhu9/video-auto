# 开源项目演示类 - 解析方案

## 核心特点

开源项目演示视频通常包含：
- **项目介绍**：背景、解决的问题、技术选型
- **界面展示**：Web UI / CLI 界面操作演示
- **核心代码**：关键模块的代码片段
- **效果展示**：运行结果、Demo 演示
- **GitHub 信息**：Star 数、贡献者、License、安装命令

解析重点：**还原演示步骤 + 提取可运行代码 + 整理项目信息**

## 推荐工具组合

| 工具 | 作用 | 优先级 |
|------|------|--------|
| **videos_understand** | 整体理解项目定位和功能 | ⭐⭐⭐⭐⭐ |
| **FFmpeg** | 提取界面截图、代码截屏 | ⭐⭐⭐⭐⭐ |
| **images_understand** | OCR 提取代码、命令、链接 | ⭐⭐⭐⭐ |
| **Whisper** | 讲解旁白转文字（无字幕时） | ⭐⭐⭐ |
| **summarize** | 快速摘要 + 字幕提取 | ⭐⭐⭐ |

## 步骤流程

### 完整解析流程

```bash
# Step 1: 整体视频理解
videos_understand(videos_info=[
  {
    "file": "/path/to/demo.mp4",
    "prompt": "这是一个开源项目演示视频。请提取：1. 项目名称和定位；2. 解决的问题/场景；3. 核心技术栈；4. 主要功能模块；5. 效果展示结果；6. GitHub/官网链接（如有）；7. 安装和使用命令（如有）"
  }
])

# Step 2: 提取关键帧（代码 + 界面）
ffmpeg -i demo.mp4 -vf "fps=1/15,scale=1920:-1" -q:v 2 frame_%04d.jpg -y

# Step 3: 批量 OCR 分析（识别代码片段）
images_understand(image_info=[
  {"file": "frame_0001.jpg", "prompt": "这是演示开始界面，提取项目名称、主界面元素、导航菜单"},
  {"file": "frame_0010.jpg", "prompt": "这是代码配置截图，完整提取所有代码内容和命令"},
  {"file": "frame_0020.jpg", "prompt": "这是运行效果截图，描述展示的结果和关键数据"},
  {"file": "frame_0030.jpg", "prompt": "提取图中所有文字、链接、GitHub 地址、命令"}
])

# Step 4: Whisper 转录旁白（还原演示步骤）
ffmpeg -i demo.mp4 -vn -acodec pcm_s16le audio.wav -y
whisper audio.wav --model medium --language auto \
  --output_format json --output_dir ./transcripts

# Step 5: 整合输出结构化笔记
```

### 快速路径（URL 视频）

```bash
# 直接 summarize 获取摘要和字幕
summarize "https://youtu.be/xxxx" --youtube auto --length long

# 结合 videos_understand 深度分析
videos_understand(videos_info=[
  {
    "file": "",
    "url": "https://youtu.be/xxxx",
    "prompt": "分析这个开源项目 Demo 视频，输出：项目简介、技术栈、核心功能、代码示例、运行结果、相关链接"
  }
])
```

## 避坑指南

### ❌ 常见问题 1：代码截屏 OCR 质量差
**原因**：代码字体小、背景色深、反锯齿导致识别错误
**解决**：
- 放大帧图：`scale=3840:-1`（4K 提取再分析）
- prompt 明确说明代码语义：`"这是一个 Python 配置文件，请识别并还原原始代码"`
- 对照 Whisper 旁白中的命令交叉验证

### ❌ 常见问题 2：GitHub 链接一闪而过
**问题**：视频中快速展示链接但没时间看清
**解决**：
- 定位链接展示时间：`videos_understand` prompt "找出所有出现链接的时间点"
- 逐帧提取该时段：`ffmpeg -ss 00:05:30 -i demo.mp4 -frames:v 10 frame_link_%03d.jpg`

### ❌ 常见问题 3：演示中途操作太快
**问题**：命令执行、文件编辑一闪而过
**解决**：
- 慢速播放提取：`ffmpeg -i demo.mp4 -vf "setpts=2*PTS" -af "atempo=0.5" slow_demo.mp4`
- 逐帧分析：`ffmpeg -i demo.mp4 -ss 00:03:20 -frames:v 30 frame_seq_%03d.jpg`

### ❌ 常见问题 4：项目名称/版本未明确说明
**问题**：视频中口头提及，容易遗漏
**解决**：在整体分析 prompt 中明确要求输出 "项目名称 + 版本号 + License"

## 结构化输出模板

```json
{
  "project": {
    "name": "项目名称",
    "description": "一句话描述",
    "github": "https://github.com/xxx",
    "language": "主要语言",
    "license": "MIT/Apache 2.0/...",
    "stars": "Star 数（如视频中提及）",
    "version": "版本号"
  },
  "problem_solved": "解决的问题/场景",
  "tech_stack": ["技术1", "技术2"],
  "features": [
    {"name": "功能1", "description": "描述", "code": "关键代码（可运行）"}
  ],
  "demo_steps": [
    {"step": 1, "action": "操作描述", "command": "命令", "timestamp": "mm:ss"}
  ],
  "results": "效果展示结果描述",
  "getting_started": "快速上手命令"
}
```

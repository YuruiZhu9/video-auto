# 开源项目演示类 - 视频解析方案

## 核心工具/API

- **videos_understand**：提取开源项目的架构图、代码演示、命令输出等视觉信息
- **browser**：访问开源项目主页（GitHub/GitLab）、README，找到视频对应的仓库
- **exec**：克隆仓库、运行演示命令，补充视频未覆盖的细节
- **yt-dlp**：下载技术分享/项目演示视频（GitHubAE Conf、PyCon、开源中国等）
- **Whisper**：提取视频中的口语化讲解（补充 README 文字版缺失的临场感）

---

## 步骤流程

```
Step 1：定位项目
  → browser 搜索视频中提到的项目名/公司名
  → 找到对应的 GitHub/GitLab 仓库

Step 2：获取项目信息
  → 读取 README.md、CHANGELOG.md
  → 查看 Issue/PR 了解项目背景

Step 3：视频深度分析
  → videos_understand 提取：项目定位、核心功能、技术亮点、代码片段、命令演示、效果展示

Step 4：运行验证（可选）
  → exec 克隆仓库，按视频步骤运行演示
  → 记录实际遇到的问题

Step 5：综合输出
  → 整合视频内容 + README + 运行结果
```

---

## 适用场景

- 开源工具/框架演示视频（GitHub 官方 Demo）
- 技术大会演讲视频（PyCon、GitHub Universe、QCon）
- GitHub Trending 项目介绍视频
- 开发者工具评测视频（IDE 插件、AI 编程工具等）
- 开源社区 Conference Talk（深入讲解某个技术点）

---

## 避坑指南

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 视频版本与仓库代码不一致 | 录制时间较早 | 查看仓库 commit 时间，确认视频版本 |
| 命令行一闪而过 | 视频节奏太快 | 用 Whisper 提取字幕，找到时间戳再截帧分析 |
| 项目依赖复杂难以复现 | 开源项目本身配置繁琐 | 重点记录视频中的关键步骤，跳过完整安装 |
| 视频无字幕难以理解 | 演讲者口语化/技术术语多 | 用 Whisper 提取字幕辅助，或搜索演讲稿文字版 |
| 开源协议未说明 | 视频未提及 | 主动查询仓库 LICENSE 文件 |
| 视频是宣传片而非技术演示 | 偏营销内容 | prompt 中要求区分"宣传话术"和"技术事实" |

# 开源项目演示类视频解析方法

## 核心工具/API

| 工具 | 功能描述 |
|------|---------|
| **FFmpeg** | 提取操作演示帧、生成缩略图序列 |
| **videos_understand** | 理解UI演示步骤、提取命令操作 |
| **Whisper** | 语音转文字，记录讲解词 |
| **summarize** | 快速获取项目介绍要点 |
| **yt-dlp** | 下载高质量演示视频 |

## 步骤流程

### 开源项目演示解析工作流

```
开源项目演示视频（GitHub README/项目官网/YouTube）
    │
    ├─→ 1. summarize ──→ 项目背景与功能概述
    │
    ├─→ 2. videos_understand ──→ 深度分析UI操作/命令执行
    │
    ├─→ 3. FFmpeg ──→ 提取关键截图+操作步骤序列
    │
    └─→ 4. 整合输出 ──→ 完整的演示解读报告
```

### Step 1：快速了解项目背景

```bash
# 获取YouTube视频概述
summarize "https://youtu.be/xxxxx" --youtube auto --length medium

# 若有GitHub仓库，配合README理解上下文
# summarize "https://github.com/xxx/yyy" --length medium
```

### Step 2：深度理解演示内容（videos_understand）

分析prompt模板：
```
分析这个开源项目演示视频，提取：

## 项目基本信息
- 项目名称与定位
- 官方链接/Star数（如能获取）
- 演示者身份

## 功能演示流程（按时间顺序）
| 时间 | 操作 | 关键命令/步骤 | 效果展示 |
|------|------|-------------|---------|
| 00:02:30 | 安装 | pip install xxx | 成功安装 |
| 00:05:10 | 配置 | xxx config | 初始化完成 |
| 00:08:45 | 核心功能 | python xxx --arg1 val | 功能演示 |
| ... | ... | ... | ... |

## 命令/代码片段
提取演示中所有命令，逐条附上用途说明

## UI/交互关键帧
列出每5分钟一个关键帧，描述UI当前状态

## 优缺点观察
- 优点（易用性/性能/功能）
- 缺点/不足（配置复杂/性能问题/兼容性）

## 适用场景评估
- 适合什么样的用户
- 替代方案对比
```

### Step 3：提取操作截图（FFmpeg）

```bash
# 按时长均匀取帧（每30秒一个截图）
ffmpeg -i demo.mp4 -vf "fps=1/30" frame_%04d.jpg

# 提取包含明显UI变化的帧（通过阈值检测）
ffmpeg -i demo.mp4 -vf "select='gt(scene,0.3)',showinfo" -vsync vfr keyframes/

# 切分每个操作步骤（手动标注时间点后）
ffmpeg -i demo.mp4 -ss 00:05:00 -t 00:02:00 -c copy step1.mp4
```

## 适用场景

- GitHub项目官方演示视频（README中的视频链接）
- 开源工具使用教程（官方或社区制作）
- 新版本功能展示视频
- Conference Demo视频（PyCon/KubeCon等）
- 创作者工具/框架介绍

## 避坑指南

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 演示速度快，来不及截帧 | 快速操作过帧 | 用 `ffmpeg -framerate 2` 低帧率提取，或用 `setpts=4*PTS` 慢放 |
| 命令滚动快OCR无法识别 | 终端滚动 | 降低播放速度：`ffmpeg -i demo.mp4 -vf "setpts=2*PTS" slowed.mp4` |
| 终端白字黑底，对比度低 | 颜色问题 | 用 `eq=brightness=0.1:saturation=1.5` 增强对比度 |
| 多个工具串场演示，无法分段 | 演示结构混乱 | 用 videos_understand 自动识别场景切换时间点 |
| 背景音乐干扰语音识别 | 音频混音 | `ffmpeg -i demo.mp4 -af "pan=mono|c0=c0" -vn audio.wav` 单独提取人声 |

## 进阶工具链

```bash
# 完整提取管道
# 1. 提取音频用于Whisper转写
ffmpeg -i demo.mp4 -vn -acodec pcm_s16le audio.wav

# 2. Whisper转写
whisper audio.wav --model medium --language zh --output_format srt

# 3. FFmpeg烧录字幕（生成带字幕视频）
ffmpeg -i demo.mp4 -vf "subtitles=audio.srt" final.mp4

# 4. 生成缩略图序列（每30秒一张）
ffmpeg -i demo.mp4 -vf "fps=1/30,scale=320:-1" thumbs_%04d.jpg
```

# 开源项目演示类 - 智能视频摘要系统

## 核心工具/API

- **Whisper**：语音识别（提取解说/旁白内容）
- **FFmpeg**：抽帧、降采样、视频切割
- **OpenCV / scenedetect**：镜头边界检测
- **LangChain LCEL**：Chain of 关键帧分析 → 结构化输出
- **Ollama / GPT-4o**：LLM 综合总结
- **文本向量化 + FAISS**：视频内容语义检索

## 完整系统架构

```
┌─────────────────────────────────────────────────────────────────┐
│                    智能视频摘要系统 Pipeline                      │
├─────────────────────────────────────────────────────────────────┤
│  视频输入（本地/URL/YouTube）                                     │
│       ↓                                                          │
│  [模块1: 预处理]                                                  │
│  ├─ yt-dlp / HTTP 下载 → 本地 MP4                               │
│  ├─ FFmpeg 降采样（1080p → 720p）                               │
│  └─ MediaInfo 提取元数据（时长/编码/帧率）                         │
│       ↓                                                          │
│  [模块2: 语音提取]                                                │
│  ├─ FFmpeg 提取音频流 → audio.mp3                               │
│  └─ Whisper 转写 → transcript.json（含时间戳）                   │
│       ↓                                                          │
│  [模块3: 视觉分析]                                                │
│  ├─ scenedetect 镜头检测 → 场景列表                             │
│  ├─ 光流法运动检测 → 高动作帧索引                                 │
│  └─ 关键帧抽图（每场景首帧 + 高动作帧）→ keyframes/              │
│       ↓                                                          │
│  [模块4: 多模态 AI 分析]                                          │
│  ├─ images_understand 批量分析关键帧                             │
│  └─ 语音+关键帧 → GPT-4o / Claude 综合理解                       │
│       ↓                                                          │
│  [模块5: 结构化输出]                                              │
│  ├─ 完整摘要（Markdown / JSON）                                  │
│  ├─ 章节时间轴                                                   │
│  ├─ 关键知识点列表                                               │
│  └─ 相关资源链接提取                                             │
└─────────────────────────────────────────────────────────────────┘
```

## 避坑指南

### ⚠️ Whisper 模型选择：速度 vs 精度
- `tiny`/`base`：快（~1x实时），精度一般，适合粗筛
- `small`/`medium`：平衡，适合大多数场景
- `large-v3`：最准，慢（~10x实时），需 GPU

### ⚠️ 关键帧数量控制
- 场景过多时（>100个场景）→ 限制每场景 1 帧，或仅提取 top 20 高动作帧
- 存储预算：每帧 JPEG 约 100KB，20帧 = 2MB，合理

### ⚠️ Whisper 输出时间戳不准确
- Whismer 的 word_timestamps 可用，但有 1-3秒误差
- 如需精确时间戳 → 使用专为字幕设计的工具（如 autosub、whisperX）

### ⚠️ API 成本控制
- GPT-4o 图文混合输入 Token 消耗大
- 策略：每 30 秒视频只抽 1 帧 + 60 秒字幕片段，控制在 8K tokens 以内

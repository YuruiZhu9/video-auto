## 📋 本次新增内容

本次更新新增了4个之前未收录的视频解析方法，覆盖技术教程、开源项目演示、行业分享三类：

### 1️⃣ FFmpeg 8.0 Whisper集成（技术教程类）
FFmpeg官方于2025年8月宣布在8.0版本中集成Whisper音频过滤器，可直接在FFmpeg管道中将视频音频转为SRT字幕或JSON结构化数据，无需Python中间层。
- 一行命令完成音频提取→Whisper转录→字幕输出
- 支持whisper.cpp本地运行（无需GPU，适合服务器部署）
- 与yt-dlp/FFmpeg其他滤镜链无缝结合
- 避坑：需使用medium/large模型提升中文识别准确率

### 2️⃣ DeepParseX 多模态文档解析（技术教程类）
开源多模态解析平台，支持视频+音频+PDF+图片统一处理，内置RAG知识库构建能力。
- 视频 → 关键帧 + 语音文字稿 + 场景描述，一站式完成
- API+Python SDK双接口，支持本地Docker部署
- 适合企业视频内容归档和知识库批量构建
- 避坑：长视频需分段（≤10分钟/段），需要GPU支持

### 3️⃣ TikHub API — Bilibili专用API（开源项目演示类）
TikHub提供Bilibili官方API代理，支持通过BV号批量获取视频元数据、字幕直链、UP主视频列表等。
- 支持无Cookie获取公开元数据（播放量/点赞/时长等）
- 字幕API需B站登录Cookie（免费获取SESSDATA即可）
- Python SDK + REST API双接口
- 避坑：B站AI字幕返回空时自动fallback到Whisper转录

### 4️⃣ 阿里云Media Video Understanding（行业分享类）
阿里云Model Studio内置"影视传媒视频理解"轻应用，整合ASR+VLM+LLM三大能力，支持视频结构化标签、内容摘要、任意问答。
- 中文ASR识别率高，专为中文视频优化
- 支持OSS直链，HTTP API调用
- 适合企业视频内容审核、B站/中文视频知识库构建
- 避坑：使用内网OSS传输减少费用；视频太大先切分

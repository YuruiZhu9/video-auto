### 1️⃣ video-analyzer — 开源本地视频分析工具（开源项目演示类）

**一句话定位**：Llama3.2 Vision + Whisper，零 API 成本本地运行。

**核心架构**：
```
FFmpeg/OpenCV → 智能关键帧提取
       ↓
Whisper → 音频转录（处理低质量音频）
       ↓
Llama3.2 Vision（11B）→ 帧级视觉分析（考虑前后帧上下文）
       ↓
整合输出 → 时间序号的完整视频描述
```

**适用场景**：
- 开源项目演示视频（功能截图 + 代码演示识别）
- 隐私敏感场景（完全本地，无需数据上云）
- 教学视频知识点提取（关键帧 + 对应转录）

**OpenClaw 集成**：
- 思路与 video-analyzer 一致，但用 `videos_understand` 替代本地 Llama Vision
- `FFmpeg 帧提取` + `videos_understand` + `audios_understand` = OpenClaw 版 video-analyzer

### 2️⃣ Qwen2.5-Omni — 阿里端到端全模态视频理解（技术教程类）

**一句话定位**：首个支持视频流 + 音频流 + 文本流统一输入，**流式输出自然语音**的端到端多模态模型。

**三大核心突破**：
| 能力 | 说明 |
|------|------|
| **原生视频流输入** | 直接喂视频帧序列，无需提前提取关键帧，保留完整时空信息 |
| **音视频同步理解** | 视觉+听觉联合建模，比"分别调用 Whisper + VLMs"更懂视频 |
| **流式 TTS 输出** | 唯一支持流式生成自然语音的多模态模型，可直接做"视频解说生成" |

**部署方式**：
- Docker（推荐）：`docker pull qwenllm/qwen-omni:2.5-cu121`
- 轻量版：Qwen2.5-Omni-3B（8GB GPU 即可运行）

**适用场景**：
- 中文技术教程视频（中文理解最强）
- 播客/访谈（音视频同步分析）
- 会议演讲（流式摘要生成）
- 实时视频流分析（流式输入）

## 🔬 本次研究主题总结

### 本地化/开源趋势：视频解析的第三条路

除了"云端 API"（videos_understand）和"手动工具链"（FFmpeg + Whisper），2025-2026 年出现**第三条路**：

**本地开源工具**：video-analyzer、Qwen2.5-Omni
- 优势：隐私保障、零 API 成本、可离线运行
- 劣势：需要 GPU 算力、部署复杂度高

**macOS 原生应用**：Whisper Mate
- 优势：零门槛 UI 操作，适合非技术用户
- 劣势：平台限制，仅 macOS 可用

## 核心工具/API

- **AutoGaze 模块**：基于自回归注视（Autoregressive Gazing）的视觉token筛选器，在 ViT/MLLM 处理前自动去除冗余 patch
- **HLVid 基准**：首个高分辨率、长形式视频问答基准（5分钟 4K 分辨率视频）
- **自回归筛选机制**：多尺度 patch 选择，最小化重构误差下保留关键视觉信息
- **兼容性**：可叠加于任何 ViT 或 MLLM（视频理解大模型）之上

## 步骤流程

1. **输入视频帧序列** → 传入 AutoGaze 模块
2. **自回归注视采样**：AutoGaze 逐帧评估每个 patch 的语义重要性
3. **Token 压缩**：压缩视觉 token 4x～100x（根据视频复杂度自适应）
4. **MLLM 推理**：压缩后的 token 输入下游视频理解模型
5. **输出答案**：最终视频 QA 回答或结构化摘要

## 避坑指南

- **压缩率与精度权衡**：压缩率越高，推理越快但细节可能丢失；建议 4x-16x 压缩为精度-速度最佳平衡点
- **高动态场景**：帧间变化剧烈的视频（如体育、快速剪辑）需降低压缩率
- **多模态模型兼容性**：AutoGaze 需配合支持视频输入的 MLLM 使用，纯文本模型不兼容

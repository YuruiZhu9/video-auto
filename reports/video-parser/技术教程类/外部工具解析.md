## 开源工具

### 1. video-analyzer

**功能**：本地视频分析，结合视觉模型和音频转录

**特点**：
- 支持 Ollama 本地模型
- 支持 OpenRouter 云端 API
- 自动关键帧提取
- Whisper 音频转录

**安装**：
```bash
pip install video-analyzer
```

**使用**：
```bash
video-analyzer /path/to/video.mp4 --model ollama/llama3.2
```

**官网**：https://github.com/byjlw/video-analyzer

---

### 2. TLDW (Too Long; Didn't Watch)

**功能**：面向长视频信息高效提取的开源应用

**特点**：
- 专注于长视频处理
- 自动提取关键信息
- 支持结构化输出
- 支持本地部署

**官网**：https://github.com/username/tldw

---

### 3. FFmpeg + Whisper 本地方案

**步骤**：

```bash
# 1. 提取音频
ffmpeg -i video.mp4 -vn -acodec libmp3lame audio.mp3

# 2. 转录
whisper audio.mp3 --model large-v3 --language zh

# 3. 分析转录文本
# 使用 LLM 分析转录内容
```

## 🚀 推荐组合方案

### 场景 1：B站/YouTube 技术教程（一键总结）
```
summarize "URL" --youtube auto --extract-only
summarize "URL" --model gemini-3-flash-preview --length medium
```

### 场景 2：构建个人知识库（批量处理）
```
yt-dlp + ffmpeg(音频提取) + faster-whisper(转写) + Gemini(结构化)
```

### 场景 3：行业分享演讲（多模态理解）
```
videos_understand → 核心观点 + 关键数据 + 金句
summarize --extract-only → 字幕原文
弹幕提取（B站） → 观众互动反馈
```

### 场景 4：开源项目 Demo（GitHub + 视频联动）
```
gh repo view → README
yt-dlp 演示视频 → ffmpeg 截帧 → Whisper 转写 → 文档化
```

### 场景 5：长视频深度理解（学术/课程类）
```
VideoMiner / Gemini 2.0 → 整体理解
WhisperX → 带时间戳转写
分段 summarize → 分话题总结
```

### 场景 6：企业视频资产治理
```
百度VCA / VideoPipe → 预分类打标
路由到专业工具 → 深度解析
```

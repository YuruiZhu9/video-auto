## 🔧 工具总览

| 工具 | 类型 | 适用场景 | 核心能力 |
|------|------|---------|---------|
| **summarize (OpenClaw Skill)** | CLI + LLM | 所有视频URL | 摘要/字幕提取/结构化输出 |
| **Whisper (OpenAI / 本地)** | ASR模型 | 音频/无字幕视频 | 高精度多语言转录 |
| **ffmpeg** | 命令行工具 | 所有本地视频 | 截帧/转码/音频提取 |
| **videos_understand** | 多模态LLM API | 所有视频 | 内容理解/关键信息提取 |
| **VideoCaptioner** | GUI工具 | 技术教程 | 字幕生成+视频理解 |
| **yt-dlp / bilili** | 下载工具 | 特定平台 | 视频下载/元数据提取 |
| **LMSKE** | 学术方法 | 长视频 | 关键帧序列提取 |
| **LLMVS** | 学术方法 | 技术演讲 | 多模态摘要生成 |

## 📌 使用建议

1. **优先尝试 summarize skill**：最简单，一行命令搞定 YouTube/B站视频摘要
2. **需要高精度转录**：使用 Whisper 本地模型或 API
3. **提取视觉信息**：ffmpeg 截帧 + 多模态 LLM 分析
4. **长视频结构化**：[LMSKE] + LLM 二次分析
5. **项目演示类视频**：yt-dlp 提取元数据 + 截帧 + README 风格输出

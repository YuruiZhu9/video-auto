## 核心工具/API

### 1. ProactiveVideoQA — 视频主动交互评估基准

| 属性 | 详情 |
|------|------|
| **发布机构** | 北京大学王选计算机研究所 |
| **会议** | ICLR 2026 |
| **核心能力** | 首个视频多模态"主动交互"评估基准 |
| **评估指标** | PAUC（主动理解准确率）|
| **解决的问题** | 视频播放过程中，AI何时该主动发言？说什么？|
| **Benchmark规模** | 覆盖多种视频场景（生活/教育/影视）|

**核心洞察**：传统视频QA是被动的——用户问，AI答。ProactiveVideoQA提出新范式：AI在视频播放过程中自主决定何时发起回复，实现真正的"边看边讲"。

### 2. MMDuet2 — 强化学习驱动视频主动交互训练

| 属性 | 详情 |
|------|------|
| **发布机构** | 北京大学王选计算机研究所 |
| **会议** | ICLR 2026 |
| **核心能力** | 无需精确时间标注的强化学习训练方法，实现SOTA主动交互性能 |
| **关键创新** | 双模块协同，无需逐帧标注"何时说话" |
| **训练数据** | 自构建数据集，支持多场景泛化 |

**MMDuet2技术路线**：
```
视频帧序列 ──┐
             ├──→ 双编码器协同 ──→ 主动决策模块 ──→ 何时说话+说什么
音频信号 ───┘
```

**对视频解析的启示**：
- MMDuet2展示了视频+音频双模态联合推理的最高水平
- 其双编码器协同架构可用于**多模态视频结构化提取**
- 可作为OpenClaw `videos_understand` 能力的进阶参考

## 步骤流程

### 应用流程：基于主动交互原理的视频深度解析

```
Step 1: 视频分段处理
  → FFmpeg 按场景/语义分段（每段 ≤ 5分钟）

Step 2: 双模态特征提取
  → 视觉编码器：ResNet/ViT 提取每帧特征
  → 音频编码器：Whisper 提取语音+背景音特征

Step 3: 主动决策分析
  → 输入：双模态特征序列
  → 判断：本段是否包含关键信息点？
  → 输出：(时刻, 事件类型, 置信度)

Step 4: 结构化提取
  → 高置信度事件 → 详细记录（时间戳+摘要）
  → 低置信度事件 → 汇总过滤

Step 5: 生成解析报告
  → 核心观点 + 时间线 + 关键帧描述
```

## 适用场景

- **教学视频自动笔记**：AI边播放教程边标注重点，无需用户手动暂停
- **会议记录自动化**：主动识别关键决策点和讨论节点
- **影视/综艺内容分析**：自动识别高光片段和关键情节转折
- **监控视频异常检测**：实时主动识别异常事件并预警
- **视频知识库构建**：自动化从视频中提取可检索的事实节点

## 避坑指南

| 场景 | 常见问题 | 解决方案 |
|------|---------|---------|
| 视频场景切换频繁 | 误判为主动交互时机 | 引入场景切换检测（FFmpeg scene detection），切换后重置置信度 |
| 背景音乐干扰 | 音频编码器将音乐误识别为语音 | 使用 Whisper 的语音活动检测（VAD）过滤非语音音频 |
| 长视频计算成本高 | 全程帧级别分析计算量巨大 | 分段处理+稀疏采样（每隔 N 帧分析一次） |
| 学术论文方法难落地 | MMDuet2 尚未公开发布代码 | 关注北大王选所 GitHub，暂用 OpenClaw `videos_understand` 替代 |

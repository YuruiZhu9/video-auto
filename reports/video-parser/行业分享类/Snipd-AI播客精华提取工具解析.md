## 核心工具/API

- **Snipd APP**：AI播客播放器，自动捕捉精华、智能对话、节目摘要
- **Whisper**：底层转录引擎（OpenAI Whisper / ChatGPT集成）
- **LLM 摘要生成**：GPT-4o 等大模型生成章节摘要与高光
- **YouTube 导入**：支持将 YouTube 视频导入 Snipd，像播客一样处理

---

## 核心能力

### 1. 智能精华捕捉（Smart Snippets）
- AI 自动识别播客/视频中的"高光时刻"
- 基于语义理解而非简单音量检测
- 自动生成每个高光的文字摘要

### 2. 全自动转录
- 集成 OpenAI Whisper 自动生成逐字稿
- 支持多语言（英语为主，中文支持持续优化）
- 可导出为 txt/srt/pdf

### 3. AI 对话与问答
- 对播客内容进行自然语言提问
- AI 基于转录内容回答，可追问
- 类似 Perplexity 风格的播客版体验

### 4. 章节与摘要自动生成
- 自动识别章节边界（无需人工标注）
- 生成节目级别的结构化摘要
- 支持一键分享到社交媒体

### 5. YouTube 视频导入
- 将 YouTube 视频作为"播客"导入 Snipd
- 自动捕捉精华、生成摘要
- 适合处理：技术演讲、会议talk、产品演示类视频

### 6. 笔记导出
- 导出到 Notion / Obsidian / Readwise
- 保留时间戳链接，可回听原始片段
- 支持导出 Markdown 格式

## 步骤流程

### 基础使用流程（YouTube 视频）

```
1. 打开 Snipd APP 或网页版
2. 粘贴 YouTube 视频链接
3. Snipd 自动下载音频并转录（~5-15分钟）
4. AI 自动生成：
   ├── 节目摘要（3-5个核心要点）
   ├── 章节标记（自动识别）
   └── 精华片段（5-10个高光时刻）
5. 用户可对任意片段添加个人笔记
6. 导出到笔记工具（Notion/Readwise/Markdown）
```

### 批量处理流程（技术教程场景）

```
1. 收集目标 YouTube 播放列表链接
2. 逐个导入 Snipd（或使用 RSS 批量订阅）
3. 等待 AI 完成转录+摘要（可后台进行）
4. 批量导出所有摘要到本地
5. 用 LLM 合并整理为结构化笔记
```

## 避坑指南

| 坑 | 问题 | 解决方案 |
|---|------|---------|
| **中文支持弱** | 英文播客效果好，中文转录质量差 | 英文视频优先；中文视频用 Whisper 本地转录后导入 |
| **YouTube 导入限速** | 连续导入多条可能触发限流 | 间隔5分钟导入，或使用 RSS 订阅方式 |
| **无桌面版** | 只能手机APP或网页版 | 移动端体验最佳；网页版适合截图分享 |
| **付费墙** | 免费版功能有限（导出限次） | 免费版适合尝鲜；付费 $8.99/月 适合深度用户 |
| **无 API** | 无法程序化批量处理 | 暂无解决方案，可关注官方路线图 |
| **内容版权** | 播客版权保护，转录内容不保证合规 | 仅用于个人学习，商业使用需授权 |

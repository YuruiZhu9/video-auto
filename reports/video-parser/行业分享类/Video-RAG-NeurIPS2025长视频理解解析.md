# Video-RAG - NeurIPS 2025 长视频理解解析

> **来源**：NeurIPS 2025 | **一句话定位**：用视觉对齐辅助文本（OCR+ASR+目标检测）赋能任意 LVLM，无需微调即可实现 SOTA 长视频理解

---

## 核心工具/API

- **OCR 通道**：PaddleOCR / EasyOCR，逐帧检测画面文字
- **ASR 通道**：Whisper / FFmpeg-Whisper，将音频转文字
- **目标检测通道**：Grounding DINO / SAM，分割画面物体/人物
- **视觉对齐引擎**：将 OCR/ASR/检测结果与视频时间戳对齐，生成"辅助文本"
- **RAG 检索引擎**：FAISS / ChromaDB，向量检索 + 文本匹配

---

## 步骤流程

```
用户问题（自然语言）
  ↓ LLM 查询解耦
生成多个检索子请求
  ↓
┌─ 并行三通道辅助文本生成
│  ├─ OCR 通道：逐帧文字检测 → 时间戳对齐文本
│  ├─ ASR 通道：音频转文字 → 时间戳对齐文本
│  └─ 目标检测通道：物体/人物识别 → 标签序列
│
├─ 视觉对齐
│  辅助文本 + 视频帧特征 → 对齐存储
│
├─ RAG 检索
│  查询向量 → 相似度检索 → Top-K 候选片段
│
└─ 生成阶段
   LLM（任意 LVLM）+ 检索结果 → 最终回答
```

---

## 适用场景

- **无字幕电影/剧集理解**：纯视觉信息 + 目标检测
- **监控视频分析**：OCR（车牌/标签）+ ASR（环境音）+ 目标检测（行为识别）
- **学术报告（无声 PPT）理解**：OCR 提取幻灯片文字
- **外语视频理解**：OCR + ASR 联合处理，无需翻译 API
- **复杂场景**：多物体、多人物、长时序关系推理

## 避坑指南

**问题1：OCR 误检导致检索噪声**
- 解答：设置置信度阈值（>0.8），低置信度 OCR 结果不进入 RAG 索引

**问题2：长视频（>2h）OCR 计算成本高**
- 解答：关键帧采样（每 5-10 秒一帧）而非全帧 OCR；或先用场景检测筛选关键片段

**问题3：如何选择辅助文本类型？**
- 解答：优先 ASR（有声音轨），次选 OCR（文字画面），最后目标检测（复杂视觉场景）

## 与 OpenClaw 工具链的结合

```
视频 → yt-dlp 下载
  ↓
视频 → FFmpeg 截帧（关键帧）
  ↓ ├→ Whisper 转录（ASR 辅助文本）
  ├→ OCR（PaddleOCR/EasyOCR）逐帧检测
  └→ 目标检测（Grounding DINO）
  ↓
辅助文本集合 + 向量嵌入
  ↓
RAG 检索 + videos_understand 理解
  ↓
最终结构化输出
```

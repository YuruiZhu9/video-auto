# VideoStir - ACL 2026 时空结构化 RAG 解析

> **来源**：ACL 2026 | **一句话定位**：将视频建模为时空图，通过多跳检索和意图感知评分，实现从"扁平语义匹配"到"结构化推理"的范式转变

---

## 核心工具/API

- **时空图构建器**：将视频内容建模为图结构
  - 节点：角色（人脸/声音）、物体（目标检测）、事件（动作识别）、场景（镜头检测）
  - 边：时空关系（before/during/after）、因果关系、语义关联
- **多跳检索引擎**：支持 2-3 跳推理检索，追踪角色/事件的跨时间关系
- **MLLM 意图评分器**：评估检索结果与用户查询意图的匹配度
- **图数据库**：支持 Neo4j 存储和查询时空图

---

## 步骤流程

```
长视频输入
  ↓
┌─ 时空图构建阶段
│  ├─ 节点提取：
│  │  ├─ 角色节点（人脸 + 声纹 + OCR 标注）
│  │  ├─ 物体节点（目标检测 + 分割）
│  │  ├─ 事件节点（动作识别 + 镜头边界检测）
│  │  └─ 场景节点（场景分类 + 语义分割）
│  │
│  └─ 边构建：
│     ├─ 时序边（t1-before-t2 / t1-during-t2）
│     ├─ 因果边（动作→结果）
│     └─ 语义边（同一角色跨场景出现）
│
├─ 多跳检索阶段
│  用户查询 → 查询分解 → 跳1检索 → 跳2检索 → ... → 结果融合
│
└─ 意图感知评分阶段
   MLLM 评估检索结果与意图的匹配度 → 重排序 → Top 结果
   ↓
最终回答（含引用来源节点）
```

## 适用场景

- **电影深度问答**："主角第二次拿起那把刀的场景是什么"（多跳推理）
- **体育赛事分析**：追踪战术演变、球员间互动链
- **监控视频多步查询**："目标人物进入大楼后从哪个出口离开"
- **会议记录**：追踪议题讨论中的多方观点演变
- **法庭视频分析**：证人证词时间线追踪

## 避坑指南

**问题1：时空图构建的计算成本**
- 解答：对长视频使用场景检测预处理，只在镜头切换点重新建图；避免对每帧单独建节点

**问题2：多跳检索的误差累积**
- 解答：每跳检索后用 MLLM 意图评分筛选，丢弃低相关结果；最多 3 跳

**问题3：图数据库存储开销**
- 解答：使用属性图压缩（多个同类节点合并为超级节点）；Neo4j Aura 免费层可支持 ~10 小时视频

## 核心洞察：范式转变

```
传统视频 RAG：                     VideoStir（结构化 RAG）：
─────────────────                 ───────────────────────────
视频 → 文本片段 → 扁平存储          视频 → 时空图 → 结构化存储
查询 → 相似度匹配 → 单跳            查询 → 分解 → 多跳检索
结果 → 语义相关 → 可能遗漏          结果 → 意图评分 → 精准召回

本质区别：
传统方法问"哪个片段提到X"（单跳）
VideoStir 问"哪个片段的X导致了Y"（多跳）
```

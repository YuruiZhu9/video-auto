# 行业分享类视频 - 会议演讲解析

## 核心工具/API

| 工具 | 功能描述 |
|------|----------|
| **videos_understand** | LLM直接理解视频内容 |
| **summarize** | YouTube/B站直解析，快速摘要 |
| **whisper (本地/API)** | 提取演讲逐字稿 |
| **ffmpeg** | 提取PPT帧（Conference视频通常有PPT画面） |

---

## 步骤流程

### 行业分享解析标准流程

```
1. 视频获取
   yt-dlp <conference-talk-url>   # 下载视频

2. 关键帧提取（识别PPT内容）
   frame.sh video.mp4 --time 00:03:00 --out slide1.jpg  # 开场PPT
   frame.sh video.mp4 --time 00:10:00 --out slide2.jpg  # 核心内容页
   frame.sh video.mp4 --time 00:30:00 --out slide3.jpg  # 总结页

3. 图像内容提取
   images_understand(images=[
     {file:"slide1.jpg", prompt:"提取这张PPT的标题、副标题、关键词"},
     {file:"slide2.jpg", prompt:"提取这张PPT的数据、图表要点"},
     {file:"slide3.jpg", prompt:"提取结论和行动项"}
   ])

4. 完整内容理解（可选字幕转录）
   whisper audio.mp3 --model medium --output_format txt
   videos_understand(video_file="transcript.txt", prompt="从演讲稿中提取：1.背景与问题 2.核心观点 3.数据证据 4.行业趋势判断")

5. 汇总输出
   综合帧分析 + 全文理解 → 结构化报告
```

---

## 适用场景

- **技术大会演讲**：CVPR/NeurIPS/ SIGIR 等顶会分享
- **行业报告发布**：Gartner/IDC/艾瑞咨询等报告视频
- **公司技术分享**：大厂工程团队技术博客视频
- **产品发布会**：Apple/Google/NVIDIA等发布会视频
- **创业路演**：Demo Day / YC 演示视频

---

## 解析维度清单

| 维度 | 提取内容 |
|------|----------|
| **背景** | 什么问题催生了这项技术/产品？ |
| **核心创新** | 主要技术突破或方法是什么？ |
| **数据支撑** | 有哪些关键数字/指标？ |
| **应用场景** | 落地案例有哪些？ |
| **竞品对比** | 与现有方案有何差异？ |
| **未来趋势** | 演讲者对行业走向的判断 |
| **行动建议** | 对从业者的具体建议 |

## 避坑指南

### 问题1：演讲者语速快/口音重，转录质量差
**解决方案**：
- 使用 `whisper --model large` 最高精度模型
- 在 prompt 中提供上下文：`--prompt "AI conference talk about recommendation systems"`
- 结合PPT画面交叉验证关键术语

### 问题2：会议视频含多个演讲（Panel/Workshop）
**解决方案**：
- 先 `ffmpeg -i video.mp4` 查看时长和结构
- 分段提取：`ffmpeg -ss 00:30:00 -i video.mp4 -t 00:20:00 -c copy segment1.mp4`
- 分段独立解析

### 问题3：PPT画面文字过小/模糊
**解决方案**：
- 用 `ffmpeg` 放大关键帧：`ffmpeg -i slide.jpg -vf scale=1920:1080 slide_hd.jpg`
- 使用 `images_understand` 的高分辨率模式
- 结合语音解说补充PPT未覆盖的信息

### 问题4：视频有背景音乐干扰转录
**解决方案**：
- 音频降噪：`ffmpeg -i audio.mp3 -af "highpass=f=200,lowpass=f=3000" clean.mp3`
- 或使用 `--audio-format wav` 获取无损音频再降噪

### 方案A：GPT-4V 帧采样分析（精细化）

```python
import cv2
import base64
import openai
from pathlib import Path

def extract_frames(video_path, interval_sec=10):
    """提取视频帧"""
    cap = cv2.VideoCapture(video_path)
    fps = cap.get(cv2.CAP_PROP_FPS)
    frames = []
    timestamps = []
    count, interval = 0, int(fps * interval_sec)
    
    while cap.isOpened():
        ret, frame = cap.read()
        if not ret: break
        if count % interval == 0:
            ts = count / fps
            p = f"/tmp/frame_{len(frames):04d}.jpg"
            cv2.imwrite(p, frame)
            frames.append(p)
            timestamps.append(ts)
        count += 1
    cap.release()
    return frames, timestamps

def encode_image(image_path):
    with open(image_path, "rb") as f:
        return base64.b64encode(f.read()).decode("utf-8")

def analyze_video_gpt4v(video_path, api_key, prompt="详细描述这个视频的技术内容"):
    """GPT-4V 视频帧分析"""
    client = openai.OpenAI(api_key=api_key)
    frames, timestamps = extract_frames(video_path, interval_sec=15)
    
    # 分批发送（每批5帧，避免token超限）
    batch_size = 5
    all_results = []
    
    for i in range(0, len(frames), batch_size):
        batch_frames = frames[i:i+batch_size]
        batch_ts = timestamps[i:i+batch_size]
        
        messages = [
            {"role": "user", "content": [
                {"type": "text", "text": f"视频时间戳 {batch_ts[0]:.0f}s-{batch_ts[-1]:.0f}s。请分析以下画面：\n{prompt}"}
            ] + [
                {"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{encode_image(f)}"}}
                for f in batch_frames
            ]}
        ]
        
        response = client.chat.completions.create(
            model="gpt-4o",
            messages=messages,
            max_tokens=1000
        )
        all_results.append((batch_ts, response.choices[0].message.content))
    
    return all_results
```

### 方案B：Gemini 1.5 长视频直接解析

```python
import subprocess
import google.generativeai as genai

def prepare_video_for_gemini(video_path, output_path="video_for_gemini.mp4"):
    """Gemini对视频格式有要求，转码为标准H.264"""
    subprocess.run([
        "ffmpeg", "-i", video_path,
        "-c:v", "libx264", "-preset", "fast",
        "-crf", "28", "-c:a", "aac",
        output_path, "-y"
    ], check=True, capture_output=True)

def analyze_video_gemini(video_path, api_key, prompt="详细总结这个技术分享视频的要点"):
    """Gemini 1.5 Pro 原生视频理解（可直接输入视频文件）"""
    genai.configure(api_key=api_key)
    
    # 先转码为Gemini兼容格式
    prepare_video_for_gemini(video_path)
    
    video_file = genai.upload_file("video_for_gemini.mp4")
    
    model = genai.GenerativeModel("gemini-1.5-pro")
    response = model.generate_content([
        video_file,
        prompt
    ])
    return response.text
```

## 避坑指南

### ⚠️ 问题1：视频token费用爆炸
**原因**：GPT-4o/GPT-4V按帧收费，1小时视频按5秒/帧=720帧，费用极高
**解决方案**：
- 控制采样频率：非重要内容降低到30秒/帧
- 使用 Gemini 1.5 Flash：成本低10倍
- 先Whisper转录定位重点片段，再对关键帧做VLM分析

### ⚠️ 问题2：Gemini 视频格式兼容问题
**解决方案**：
- 必须转码为 H.264 + AAC/MP3
- 视频时长建议<20分钟（API限制）
- 分段上传后拼接结果

### ⚠️ 问题3：开源模型中文理解差
**解决方案**：
- 使用 Qwen-VL-72B（阿里，开源中文最强）
- 对 InternVL 使用中文微调版
- 用 GPT-4o/Gemini 做翻译+总结作为中转

### ⚠️ 问题4：API调用频率限制
**解决方案**：
- 添加指数退避重试逻辑
- 使用并发+速率限制器（asyncio + aiolimits）
- 本地缓存已分析过的帧，避免重复调用

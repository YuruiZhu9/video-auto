# 行业分享类 — 多模态平台解析

## 核心工具/API

| 工具 | 类型 | 核心能力 | 适合场景 |
|------|------|----------|----------|
| **Descript** | 桌面+云端 | 转录+文字编辑视频、填充词删除 | 内容创作者 |
| **Google Video Intelligence API** | 开发者API | 标签检测、物体跟踪、品牌Logo识别 | 竞品分析 |
| **Twelve Labs** | 开发者API | 自然语言语义搜索视频档案 | 大规模视频库检索 |
| **ScreenApp** | 云端 | 情感分析、互动问答、多语言字幕 | 用户访谈分析 |

## 步骤流程

### Descript 工作流（适合内容创作者）

1. **导入视频**：拖拽上传，自动转录（Whisper驱动）
2. **文字编辑**：像编辑文档一样编辑视频——删除文字=删除对应片段
3. **填充词清理**：一键删除 "嗯"、"啊" 等语气词
4. **导出**：生成带字幕的成品视频

```
适用场景：
- 将行业分享视频转化为博客文章（"Export as Article"）
- 快速生成短视频高光片段（"Create Shorts"）
- 演讲者替换（Overdub功能）
```

### 竞品视频分析工作流（Google Video Intelligence）

1. **批量下载**：`yt-dlp --batch-file urls.txt` 批量下载竞品视频
2. **调用API**：
   ```python
   from google.cloud import videointelligence
   
   video_context = videointelligence.VideoContext(
       linguistic_model_config=videointelligence.LinguisticModelConfig(
           model="builtin/latest"
       )
   )
   
   features = [
       videointelligence.Feature.LABEL_DETECTION,       # 标签
       videointelligence.Feature.OBJECT_TRACKING,        # 物体跟踪
       videointelligence.Feature.LOGO_RECOGNITION,       # Logo识别
       videointelligence.Feature.SPEECH_TRANSCRIPTION,   # 语音转录
   ]
   
   operation = videointelligence.annotate_video(
       input_uri="gs://bucket/video.mp4",
       features=features,
       video_context=video_context
   )
   result = operation.result(timeout=300)
   ```
3. **结构化输出**：解析JSON结果，提取品牌提及、时间戳、标签
4. **对比分析**：与自有视频数据对比，生成竞品差距报告

## 适用场景

- ✅ 内容创作者将行业分享视频二次创作为图文/短视频
- ✅ 竞品分析：提取竞品视频中的功能特性、UI设计、品牌露出
- ✅ 媒体监控：跟踪品牌在视频中的曝光频次和情感倾向
- ✅ 大型视频档案的语义检索（Twelve Labs）
- ✅ 用户访谈研究：提取用户痛点、需求、情感信号

## 避坑指南

- **Descript免费版限制**：仅支持1小时视频，导出带水印
  - 解决：付费个人版约$15/月，或用OpenClaw内置工具替代
- **Google API费用**：视频内容分析（Content Moderation / Shot Detection）较贵
  - 解决：仅启用必要特征，避免全量开启；长视频分段处理
- **Twelve Labs定价**：无免费层级，按视频分钟数计费
  - 解决：适合有预算的企业级视频库分析，小规模项目用本地方案
- **情感分析局限**：AI情绪判断准确率约70-80%，不宜作为唯一决策依据
  - 解决：仅作参考，重要判断需人工复核
- **Logo识别误差**：小尺寸/遮挡Logo识别率低
  - 解决：结合OCR补充识读屏幕文字

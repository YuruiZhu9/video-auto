# 行业分享类 - 大模型直接理解法

## 核心工具/API
- **videos_understand**: OpenClaw 内置视频内容理解工具
- **browser**: 获取视频相关信息（发布平台、背景资料）
- **web_search**: 搜索相关行业背景信息

## 步骤流程
1. **获取视频**：获取视频 URL 或本地文件路径
2. **设计提示词**：
   - 明确分析目标（提取核心观点、关键数据、行业趋势）
   - 指定输出格式（结构化大纲、要点列表）
3. **调用分析**：使用 videos_understand 进行内容理解
4. **信息整理**：
   - 提取核心观点和论据
   - 记录关键数据和统计数字
   - 识别行业趋势和预测
5. **交叉验证**：使用 web_search 验证重要数据
6. **输出整理**：形成结构化笔记

## 适用场景
- 行业峰会主题演讲
- 投资人/CEO 公开分享
- 市场趋势分析报告
- 行业洞察类视频内容
- 专家访谈和对话

## 避坑指南
- **观点与事实区分**：注意区分视频中的主观观点和客观事实
- **数据验证**：重要数据和建议进行二次核实
- **时效性检查**：注意视频发布时间，过于陈旧的信息可能过时
- **立场识别**：注意演讲者的背景和立场，可能影响观点倾向
- **完整理解**：避免断章取义，确保理解完整上下文

## 关键提取维度
| 维度 | 说明 |
|------|------|
| 核心观点 | 作者最主要的论述 |
| 支撑论据 | 支持观点的数据和案例 |
| 关键数据 | 具体数字、百分比、预测 |
| 行动建议 | 对观众的指导性意见 |
| 行业趋势 | 未来的发展方向预测 |

# 行业分享类 - 多模态联合解析方案

## 核心工具/API

- **videos_understand**：一站式视频理解（Gemini API 驱动）
- **audios_understand**：音频内容分析（Deepgram / Groq / OpenAI）
- **Whisper**：音频转文字（结构化文本，便于 LLM 分析）
- **images_understand**：关键帧视觉分析
- **LLM（GPT-4o / Claude / Gemini）**：多模态结果 + 文本联合总结

## 步骤流程

### 方案一：Gemini 一站式分析（推荐）

```
1. 直接传入视频 URL / 本地文件
2. videos_understand(prompt="总结这场行业分享的核心观点、数据亮点和结论")
3. 返回结构化内容（演讲要点 + 数据 + 观点）
```

**Prompt 示例**：
```
请分析这个行业分享视频：
1. 演讲主题是什么？
2. 核心观点（列出 3-5 个）
3. 关键数据和统计
4. 涉及的行业趋势
5. 演讲者身份和背景
```

### 方案二：Whisper + LLM 深度分析（适合长视频）

```
1. ffmpeg -i video.mp4 audio.mp3
2. whisper audio.mp3 --model medium --output_format txt
3. LLM 分析 transcript.txt：
   - 提取核心论点
   - 识别数据引用
   - 总结结论和行动项
```

### 方案三：联合多模态（最完整）

```
1. videos_understand（快速摘要）
2. audios_understand + Whisper（详细转录）
3. FFmpeg 提取关键帧（数据图表、产品截图）
4. images_understand（分析图表数据）
5. LLM 整合所有输出 → 结构化报告
```

## 适用场景

- ✅ **行业峰会 / 论坛演讲** - 提取核心观点和数据
- ✅ **公司发布会** - 产品功能、技术规格
- ✅ **专家访谈 / Podcast** - 话题洞察和关键引述
- ✅ **市场研究报告视频** - 数据图表解读
- ✅ **竞品分析视频** - 功能和策略对比

## 避坑指南

- ⚠️ **行业黑话**：prompt 中可指定"用通俗语言解释专业术语"
- ⚠️ **视频中图表数据**：Whisper 转录可能遗漏，优先用 FFmpeg 提取帧 + images_understand
- ⚠️ **多段视频**：先分割再各自分析，最后汇总
- ⚠️ **演讲者身份识别**：视频本身可能不包含简介，需要额外搜索补充
- ⚠️ **版权注意**：行业分享内容分析仅供个人学习使用

# 行业分享类 - 综合解析方案

## 核心工具/API

行业分享视频（如 Conference 演讲、公司发布会、行业洞察分享）有其独特特点：
- **信息密度高**：观点、数据、案例密集
- **时长较长**：通常 20~60 分钟
- **口述为主**：PPT 辅助，少有屏幕操作
- **数据图表多**：图表、统计数据需要准确还原

推荐工具组合：
| 工具 | 作用 | 优先级 |
|------|------|--------|
| **summarize** | 快速获取演讲摘要 | ⭐⭐⭐⭐⭐ |
| **videos_understand** | 深度理解观点和逻辑 | ⭐⭐⭐⭐⭐ |
| **Whisper** | 提取完整文字稿（无字幕时） | ⭐⭐⭐⭐ |
| **FFmpeg** | 提取 PPT 关键帧 | ⭐⭐⭐ |

## 步骤流程

### 快速路径：YouTube/URL 行业分享

```bash
# Step 1: 快速获取摘要（3分钟完成）
summarize "https://youtu.be/xxxx" --youtube auto --length long

# Step 2: 提取字幕原文（供深度分析）
summarize "https://youtu.be/xxxx" --youtube auto --extract-only --json > transcript.json

# Step 3: 多模态深度理解
videos_understand(videos_info=[
  {
    "file": "",
    "url": "https://youtu.be/xxxx",
    "prompt": "这是一个[行业名称]行业分享演讲。请分析：1. 演讲者身份和背景；2. 核心观点（按时间顺序列出）；3. 引用数据和案例（附来源）；4. 行业趋势判断；5. 对从业者的建议"
  }
])
```

### 深度路径：本地处理（含 PPT 提取）

```bash
# Step 1: 下载视频（yt-dlp）
yt-dlp -f "bestvideo[ext=mp4]+bestaudio[ext=m4a]/best[ext=mp4]/best" \
  -o "%(title)s.%(ext)s" "https://youtu.be/xxxx"

# Step 2: 提取音频供 Whisper 转录
ffmpeg -i "video.mp4" -vn -acodec pcm_s16le audio.wav -y

# Step 3: Whisper 转录
whisper audio.wav --model medium --language zh \
  --output_format json --output_dir ./transcripts

# Step 4: 提取 PPT 关键帧（每30秒一帧）
ffmpeg -i "video.mp4" -vf "fps=1/30,scale=1280:-1" -q:v 2 ppt_frames_%04d.jpg -y

# Step 5: 批量分析 PPT 截图
images_understand(image_info=[
  {"file": "ppt_frames_0001.jpg", "prompt": "提取这张 PPT 的标题和关键内容要点"},
  {"file": "ppt_frames_0002.jpg", "prompt": "提取这张 PPT 的标题和关键内容要点"}
])
```

## 适用场景

- ✅ Conference 演讲（SIGIR、RecSys、CVPR 等顶会分享）
- ✅ 公司发布会（产品发布、战略分享）
- ✅ 行业洞察报告（券商研报解读、投资人分享）
- ✅ 播客/访谈节目（多嘉宾对话结构化）
- ✅ 政策解读视频（监管动态、政策影响分析）

## 避坑指南

### ❌ 常见问题 1：演讲无字幕 + 口音重
**问题**：Whisper 识别准确率低
**解决**：设置 --language en 强制英文识别；使用 medium/large 模型；加入 prompt 提示上下文

### ❌ 常见问题 2：图表数据难以从帧中还原
**问题**：PPT 截图中的柱状图/折线图难以精确提取数据
**解决**：images_understand prompt："请尽可能精确描述图表的数值和趋势"；参考演讲字幕中的数据播报

### ❌ 常见问题 3：长视频分析质量下降
**问题**：60 分钟视频一次性分析，遗漏大量细节
**解决**：按自然段落（每 10 分钟）分段分析；用 Whisper 时间戳切分内容

### ❌ 常见问题 4：多嘉宾对话区分
**问题**：summarize/Whisper 不区分说话人
**解决**：选择支持说话人分离的工具（如 AssemblyAI）；或通过 videos_understand 场景分析辅助判断

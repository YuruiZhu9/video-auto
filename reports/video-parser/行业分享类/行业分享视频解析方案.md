# 行业分享类 - 视频解析方案

## 核心工具/API

- **videos_understand**：多模态视频内容理解，提取核心观点、趋势判断、商业案例
- **@steipete/summarize**：快速获取视频大意和关键信息，适合长视频
- **browser**：抓取视频发布平台（36氪、虎嗅、B站）的评论区和相关资料补充
- **batch_web_search**：搜索视频相关的行业报告、新闻，交叉验证视频中提到的数据和趋势
- **yt-dlp**：下载视频 + 提取评论区文字（部分平台支持）

---

## 步骤流程

### 完整解析流程

```
Step 1：获取视频信息
  → browser 打开视频页面，提取标题、UP主、发布时间、标签
  → yt-dlp --dump-json 获取完整元数据

Step 2：视频内容分析
  → videos_understand 传入视频，要求提取：
    • 核心观点（3-5条）
    • 数据引用（时间/数字/排名）
    • 案例分析
    • 结论与趋势判断

Step 3：补充信息（交叉验证）
  → batch_web_search 搜索视频中提到的关键词/公司/数据
  → 验证视频中的信息是否最新

Step 4：结构化输出
  → 按"观点层-数据层-案例层-趋势层"整理
```

### prompts 示例

**videos_understand 分析行业分享视频：**
```
请分析这个行业分享/趋势解读视频，提取：
1. 【主题】视频核心主题是什么
2. 【核心观点】3-5个核心观点（每条附上时间戳）
3. 【数据引用】视频中提到的关键数据、排名、百分比（注明时间点）
4. 【案例分析】1-3个提到的公司/产品/人物案例
5. 【趋势判断】视频对未来趋势的预测
6. 【金句摘录】值得记录的精彩表述
7. 【可信度评估】哪些信息需要进一步核实
```

## 适用场景

- 行业趋势分析视频（大厂战略解读、市场洞察）
- 商业案例拆解视频（公司/产品分析）
- 政策解读视频（行业政策影响分析）
- 投资分享视频（赛道分析、项目推荐）
- 媒体采访视频（CEO 访谈、专家对话）

## 避坑指南

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 视频观点主观性强 | 行业分享常含个人判断 | prompt 中要求区分"事实陈述"和"主观观点" |
| 数据可能过时 | 视频录制时间较早 | 用 browser 搜索最新数据交叉验证 |
| 观点过于碎片化 | 嘉宾自由发挥，缺乏结构 | 提取"开头-中间-结尾"三层逻辑，用时间戳串联 |
| 视频涉及未公开信息 | 行业内幕无法核实 | 在"可信度评估"中明确标注，无法核实的内容注明 |
| 多嘉宾观点冲突 | 访谈类视频各方立场不同 | 分别提取各嘉宾观点，标注发言时间 |

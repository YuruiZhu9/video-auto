# 行业分享类视频解析方法

## 核心工具/API

| 工具 | 功能描述 |
|------|---------|
| **summarize CLI** | 快速抓取分享内容要点，提取演讲摘要 |
| **videos_understand** | 多模态深度分析，获取结构化观点 |
| **FFmpeg** | 切分演讲精彩段落 |
| **Whisper** | 语音转文字，生成完整文字稿 |
| **视频理解Skill** | 解析YouTube/Bilibili等平台元信息 |

## 步骤流程

### 方案：行业分享深度解析工作流

```
视频/链接
    │
    ├─→ 1. summarize CLI ──→ 快速摘要（3分钟）
    │       └─→ 提取：核心观点/数据点/结论
    │
    ├─→ 2. videos_understand ──→ 深度内容解析（5-10分钟）
    │       └─→ 结构化：演讲框架/论点/论据/案例
    │
    └─→ 3. Whisper转写 ──→ 完整文字稿（可选）
            └─→ 用于：深度学习/引用/多语言翻译
```

### Step 1：快速扫描（summarize）
```bash
# YouTube/B站链接直接总结
summarize "https://youtu.be/xxxxx" --youtube auto --length medium

# 获取字幕稿
summarize "URL" --youtube auto --extract-only --json > transcript.json
```

### Step 2：深度理解（videos_understand）

分析prompt模板：
```
请分析这个行业分享/演讲视频，提取：

## 基本信息
- 演讲者身份/背景
- 分享主题
- 所属领域/行业
- 时长与难度

## 核心观点（3-5条）
- [观点1]: [简述]（来自 XX:XX）
- [观点2]: [简述]（来自 XX:XX）

## 数据与案例
- 关键数据引用
- 实际案例

## 演讲结构
- 开场切入点
- 论证逻辑链
- 结尾行动号召

## 个人收获与行动项
- 最有价值的3个点
- 可立即执行的行动
```

### Step 3：精彩片段切分（FFmpeg）
```bash
# 切分核心观点段落（需先找到时间戳）
ffmpeg -i share.mp4 -ss 00:15:30 -t 00:08:00 -c copy highlight.mp4

# 提取所有关键帧用于速览
ffmpeg -i share.mp4 -vf "select='between(t,300,600)+between(t,1200,1500)+between(t,2400,2700)',setpts=N/FRAME_RATE/TB" -vsync vfr frames_%03d.jpg
```

## 适用场景

- 行业峰会/论坛演讲（WAIC/GTC/数博会等）
- 大厂技术分享（阿里/腾讯/字节/百度等）
- 创业分享/路演（Y Combinator/TED/混沌等）
- 投资人对谈/播客（42章经/疯投圈等）
- 政策解读/专家访谈

## 避坑指南

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 演讲太长 videos_understand 遗漏细节 | 视频>15分钟 | 分段处理：`ffmpeg -t 600 -ss 0 video.mp4` |
| summarize 结论太泛 | 没有指定长度 | 加 `--length long` 或 `--max-output-tokens 2000` |
| 多人对话视频无法区分说话人 | Whisper默认不分说话人 | 用 `whisper --diarize` 或 pyannote 做说话人分离 |
| 行业术语AI理解有误 | 专业领域知识不足 | 在prompt中补充上下文（如：这是AI行业的分享） |
| 视频有背景音乐干扰转写 | 音频质量差 | 先 `ffmpeg -af "highpass=f=200,lowpass=f=3000"` 降噪 |

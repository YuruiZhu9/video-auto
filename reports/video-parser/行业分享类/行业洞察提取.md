# 行业分享类视频解析 - 方法总结

## 核心工具/API

### 视频内容分析
| 工具名称 | 功能描述 |
|---------|---------|
| **videos_understand** | 深度理解视频内容，提取核心观点、行业洞察 |
| **audios_understand** | 分析演讲者语音，提取情绪、重点强调内容 |
| **extract_content_from_websites** | 配合视频相关网页内容补充分析 |

### 信息提取维度
| 维度 | 说明 |
|-----|------|
| **主题识别** | 视频核心主题和子主题 |
| **观点提取** | 演讲者的主要观点和论据 |
| **数据收集** | 统计数字、研究报告引用 |
| **趋势分析** | 行业趋势和未来预测 |
| **金句提取** | 关键引用和名言警句 |

---

## 步骤流程

### 行业分享视频解析流程

```
1. 视频基本信息获取
   ├── 视频标题、时长、发布时间
   ├── 演讲者信息（职位、公司）
   └── 视频来源和背景

2. 内容深度理解
   ├── 使用videos_understand分析视频
   ├── 输入提示词：
   │   "请提取视频中的：
   │   1. 核心主题
   │   2. 主要观点（3-5个）
   │   3. 关键数据和统计
   │   4. 行业趋势判断
   │   5. 重要引用和结论"

3. 结构化输出
   ├── 主题分类
   ├── 要点提炼
   ├── 价值总结
   └── 行动建议

4. 补充信息获取
   ├── 搜索相关报道
   ├── 查找引用来源
   └── 补充背景信息
```

## 适用场景

- **商业洞察提取**：从行业分享中获取商业机会
- **竞品分析**：分析竞争对手CEO/CTO演讲
- **投资研究**：从技术/行业分享中获取投资线索
- **学习提升**：提取行业大咖的核心观点
- **内容创作**：获取写作素材和行业素材

## 避坑指南

### 问题1：视频内容过于松散
**解决方案**：
- 使用结构化提示词引导分析
- 分段处理（每5-10分钟一段）
- 关注视频描述中预告的要点

### 问题2：专业术语理解偏差
**解决方案**：
- 补充搜索相关术语解释
- 查找演讲者的其他资料
- 提取术语后单独搜索确认

### 问题3：观点与数据混淆
**解决方案**：
- 明确区分事实数据和个人观点
- 对关键数据溯源确认
- 标注推断性内容

### 问题4：信息过载
**解决方案**：
- 设定优先级（核心观点 > 支撑论据 > 细节）
- 使用金字塔结构组织信息
- 聚焦3-5个关键要点

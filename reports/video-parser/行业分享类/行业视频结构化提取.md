# 行业分享类 - 行业视频结构化提取方法

> 适合对象：行业分享、大会演讲、产品发布会、投资人访谈类视频

---

## 方法一：yt-dlp 提取字幕 + LLM 总结（轻量首选）

### 核心工具/API
- **下载工具**：yt-dlp（https://github.com/yt-dlp/yt-dlp）
- **AI 总结**：summarize（OpenClaw 内置）
- **说明**：yt-dlp 可从 YouTube/B站等平台提取字幕文件，配合 LLM 快速生成摘要

### 步骤流程
```
1. 安装 yt-dlp：pip install yt-dlp 或 brew install yt-dlp
2. 查看可用字幕格式：
   yt-dlp --list-subs https://youtu.be/xxxxx
3. 下载字幕：
   yt-dlp --write-subs --write-auto-subs --sub-lang zh-Hans,en \
     --skip-download --output subtitles/%(title)s https://youtu.be/xxxxx
4. 配合 LLM 总结字幕内容
```

### 适用场景
- YouTube / Bilibili / 知乎视频 等主流平台
- 有字幕的投资人访谈、行业大会演讲
- 需要批量处理多个视频

### 避坑指南
- ⚠️ 部分视频没有字幕，或字幕不完整（需 Whisper 补充）
- ⚠️ B站需要登录 Cookie 才能下载字幕，设置 --cookies-from-browser chrome
- ⚠️ 使用 --write-auto-subs 获得自动字幕（质量较低但覆盖全面）

## 方法二：阿里云视频理解 API（商业方案）

### 核心工具/API
- **平台**：阿里云视觉智能开放平台
- **API**：`https://vision.aliyun.com/videorecog`
- **功能**：视频镜头分析、精彩片段提取、视频封面生成

### 步骤流程
```
1. 开通阿里云视觉智能服务
2. 获取 AccessKey（RAM 用户授权）
3. 调用视频理解 API：
   POST https://vision.aliyun.com/videorecog/api/v1/video/analysis
   Body: {"VideoUrl": "https://xxx.mp4", "Types": ["scene", "highlight"]}
4. 获取结构化结果：镜头列表、精彩片段时间戳、推荐封面帧
```

### 适用场景
- 需要商业化视频分析（发布会、路演视频）
- 生成视频封面图和精彩片段（用于社交媒体二次传播）
- 快速剪辑素材选取

### 避坑指南
- ⚠️ 按调用量计费，成本需评估
- ⚠️ 不提供语音/字幕内容理解，需配合 ASR 服务

## 方法三：视频场景切分 + 语义聚类（进阶方案）

### 核心工具/API
- **镜头检测**：FFmpeg（`ffmpeg -i video.mp4 -vf select='gt(scene,0.3)' -vsync vfr`）
- **关键帧提取**：video-frames-skill
- **语义聚类**： CLIP 模型（OpenAI 开源） + 简单聚类

### 步骤流程
```
Step 1 - 镜头边界检测
  ffmpeg -i video.mp4 -vf "select='gt(scene,0.3)',showinfo" \
    -vsync vfr frames_%04d.jpg

Step 2 - 关键帧 CLIP 向量化
  # 用 CLIP 对每帧生成 512 维向量
  from PIL import Image
  from CLIP import clip
  model, preprocess = clip.load("ViT-B/32")
  
  features = []
  for frame in frames:
      img = preprocess(Image.open(frame)).unsqueeze(0)
      feat = model.encode_image(img)
      features.append(feat)

Step 3 - 语义聚类（K-Means）
  from sklearn.cluster import KMeans
  import numpy as np
  
  kmeans = KMeans(n_clusters=8)
  labels = kmeans.fit_predict(np.array(features))

Step 4 - 每类代表性帧 + 人类理解
  # 每类取最接近质心的帧作为代表
  # → 发送给 LLM 理解每个场景的主题
```

### 适用场景
- 长视频（数小时大会演讲）的自动章节划分
- 快速定位特定内容在视频中的位置
- 生成视频的"语义地图"（semantic map）

### 避坑指南
- ⚠️ `gt(scene,0.3)` 的阈值需要根据视频类型调参（纪录片低一些，广告要高一些）
- ⚠️ CLIP 推理速度较慢，大批量帧需要 GPU 加速

## 方法四：直播/无字幕视频 - Whisper + 时间轴对齐

### 核心工具/API
- **转录**：OpenAI Whisper（openai-whisper Skill）
- **对齐**：FFmpeg 提取音频 + Whisper 转录
- **工具**：ffmpeg、whisper CLI

### 步骤流程
```
1. 提取音频：ffmpeg -i video.mp4 -vn -acodec pcm_s16le -ar 16000 audio.wav
2. Whisper 转录（带时间戳）：
   whisper audio.wav --model medium --output_format json --output_dir .
3. 得到带时间轴的 JSON，包含每句话的起止时间
4. 用 LLM 总结每个时间段的要点
```

### 输出 JSON 示例
```json
{
  "segments": [
    {
      "start": 0.0,
      "end": 5.2,
      "text": "大家好，欢迎参加本次产品发布会..."
    },
    {
      "start": 5.2,
      "end": 12.8,
      "text": "今天我要介绍的是我们最新一代的智能推荐系统..."
    }
  ]
}
```

### 适用场景
- 直播回放、行业发布会（通常无字幕）
- 录音转文字并保留时间戳
- 后续可快速定位特定内容的原始时间点

### 避坑指南
- ⚠️ 直播回放常有背景音乐干扰，降低 Whisper 准确率
- ⚠️ 中英文混杂场景需要 medium 或 large 模型
- ⚠️ 专业术语需人工校正（可用 Whisper + 术语词典修正）

## 行业视频分类解析策略

| 视频类型 | 推荐方案 | 核心目标 |
|---------|---------|---------|
| **投资人访谈** | Whisper 转录 + LLM 总结 | 提取投资观点和关键判断 |
| **产品发布会** | 阿里云镜头分析 + 字幕提取 | 提取核心发布亮点 + 封面图 |
| **行业大会演讲** | 镜头切分 + CLIP 聚类 + LLM | 自动章节划分 + 语义定位 |
| **访谈/Q&A** | Whisper + 时间轴对齐 | 提取问答对，形成结构化内容 |
| **科普短视频** | summarize 一键总结 | 快速获取核心知识点 |

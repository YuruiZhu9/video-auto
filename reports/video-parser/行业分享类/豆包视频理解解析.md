### 方案二：火山引擎 VeML API（开发者）

```python
import requests

# 1. 获取 Access Token（火山引擎控制台）
# https://console.volcengine.com/

url = "https://liveplatform.volcengine.com/v1/video_understand"

headers = {
    "Authorization": f"Bearer {ACCESS_TOKEN}",
    "Content-Type": "application/json"
}

payload = {
    "model": "doubao-vision-pro",
    "video_url": "https://example.com/video.mp4",
    "prompt": """请作为专业的行业分析师，分析这个视频：
    1. 视频主题和核心观点
    2. 关键数据和引用
    3. 商业价值和启示
    4. 目标受众和适用场景
    请用中文回答。"""
}

response = requests.post(url, headers=headers, json=payload)
result = response.json()
print(result["data"]["analysis"])
```

## 避坑指南

| 问题 | 解决方案 |
|------|----------|
| 视频时长超限（>10分钟） | FFmpeg 切割分段：`ffmpeg -i input.mp4 -f segment -segment_time 600 -c copy part_%03d.mp4` |
| API 认证失败 | 检查 Access Token 是否过期，在火山引擎控制台续期 |
| 视频画质太低 | 上传 720P 以上视频，低画质视频识别效果差 |
| 中文理解不够专业 | 使用更详细的 prompt，提供专业术语背景 |
| 调用频率超限 | 申请企业账号提高 QPS，或用 FFmpeg 预处理减少调用次数 |

## 四大类视频解析方法总览

### 1. 技术教程类

**核心特点**：内容结构化（步骤/代码/概念），重点提取"怎么做"

| 方法 | 工具 | 适合场景 | 费用 |
|------|------|---------|------|
| YouTube字幕提取 | summarize / yt-dlp | 有字幕的技术教程 | 免费 |
| 音频转写 | Whisper CLI/API | 无字幕本地教程 | 免费/API费 |
| 关键帧提取 | FFmpeg / keyframe-scout | PPT演示/代码演示 | 免费 |
| 深度理解 | videos_understand / GPT-4o | 复杂概念/多模态内容 | API费 |

**推荐 Pipeline**：
```
YouTube → summarize --youtube auto --extract-only → WhisperX → LLM结构化
本地视频 → FFmpeg关键帧 → Whisper → videos_understand → 结构化输出
```

### 2. 行业分享类

**核心特点**：信息密度高（数据/观点/趋势），重点提取"洞察"

| 方法 | 工具 | 适合场景 |
|------|------|---------|
| 多模态LLM分析 | GPT-4o / Gemini / GLM-4V | Keynote/路演/发布会 |
| 字幕+要点 | yt-dlp + summarize | 有字幕的分享 |
| 视频结构化 | VideoPipe | 安防/监控类 |

**推荐 Pipeline**：
```
视频 → 关键帧提取（8-10帧）→ 多模态LLM分析 → 核心观点输出
```

### 3. 开源项目演示类

**核心特点**：实操导向（命令/界面/功能），重点提取"可复现"

| 方法 | 工具 | 适合场景 |
|------|------|---------|
| 智能关键帧 | keyframe-scout | Demo视频关键操作 |
| 自动剪辑 | AutoCut | 静音+无用片段过滤 |
| 端到端Pipeline | FFmpeg+Whisper+videos_understand | 完整解析 |

**推荐 Pipeline**：
```
Demo视频 → 关键帧(10-15帧) → 音频转写(medium模型) → LLM提取命令+功能 → 报告
```

### 4. 通用方法（OpenClaw 内置）

OpenClaw 提供了开箱即用的视频解析工具，无需额外安装：

- `summarize`：URL/YouTube/本地文件 summarization，YouTube 字幕自动提取
- `video-frames`：FFmpeg 封装，提取单帧/缩略图
- `videos_understand`：多模态 LLM 视频深度理解，最大10个视频并发
- `audios_understand`：音频文件深度分析

## 避坑高频问题 Top5

1. **YouTube 无字幕** → 设 `APIFY_API_TOKEN` fallback / Whisper 重转写
2. **视频太长超出 LLM 上下文** → 等间隔提取 8-10 帧，足够理解内容
3. **关键帧太少或太多** → 用 keyframe-scout 的 content 策略自适应
4. **FFmpeg 未安装** → macOS: `brew install ffmpeg`
5. **API 费用高** → 国内优先用智谱 GLM-4V（免费额度）

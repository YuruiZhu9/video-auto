## 🔬 本周工具发现深度解析

### 1. YouTube-to-Knowledge-Doc Skill（技术教程类）

**一句话定位**：将YouTube视频转换为具有MECE结构、Mermaid图表和可点击时间戳的专业知识框架文档

**核心价值**：
- **yt-dlp** 提取字幕 → 清理去重 → 结构化文档
- **MECE原则**：确保文档结构互斥且完备（1.0/2.0/3.0 + ¶1/¶2编号）
- **双Mermaid图表**：复杂主题同时包含 Continuant(TD) + Occurrent(LR)
- **可点击时间戳**：`?t=SECONDS` 格式，链接到YouTube精确时间点
- **会话追溯**：Claude Code 会话ID嵌入文档，支持来源回溯
- **Notion集成**（可选）：使用内置 `youtube_to_notion.py` 库上传

**避坑重点**：禁止创建临时脚本上传Notion，必须用内置库

### 2. Langbase Video Wisdom Extraction Tool（技术教程类）

**一句话定位**：通过8个专业化AI Pipes，一次提取视频的多维度内容（摘要/问答/金句/社媒）

**8个专业AI Pipes**：
```
Q/A Pipe → 问答（针对视频内容追问）
Summarize Pipe → 摘要
MainIdeas Pipe → 主要观点
Facts Pipe → 有趣事实
Wow Moments Pipe → 高光时刻
Tweets Pipe → 社媒推文
Recommendations Pipe → 参考资源
Quotes Pipe → 名言引述
```

**技术架构**：Next.js + Langbase SDK + 8个Pipe API Key + Zod请求校验 + 流式响应

### 3. LLMVS（CVPR 2025论文，行业分享类）

**一句话定位**：Local-to-Global 三阶段视频摘要框架，将语言置于核心，用LLM推理生成更连贯的摘要

**三阶段架构**：
1. M-LLM 为每帧生成 Caption（文字描述）
2. LLM + In-Context Learning + 中间层嵌入 → 局部重要性评分
3. Self-Attention 全局聚合 → 精炼分数 → 关键帧选择

**核心发现**：
- 中间层嵌入优于直接生成答案（CVPR 2025 验证）
- 通用M-LLM提示优于区域特定提示
- LLM数值评分优于文字摘要型输出

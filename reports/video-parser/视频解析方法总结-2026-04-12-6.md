### 2. Video Watcher（2026-02-24）— 综合视频分析

```
安装：npx clawhub@latest install video-watcher
依赖：yt-dlp + ffmpeg + openai-whisper
功能：下载+音频+转录+字幕+截图+AI总结
输出：video.mp4 + audio.mp3 + transcript.txt + transcript.srt + frames/
```

**优势**：一键完整Pipeline，截图捕获
**劣势**：需多依赖，学习曲线

---

### 3. YouTube Factory（v1.3.0）— AI视频生成

```
安装：npx clawhub@latest install youtube-factory
依赖：ffmpeg + edge-tts + Pexels API Key
功能：提示词→完整视频（脚本+TTS+B-Roll+字幕+封面）
输出：MP4视频 + SRT字幕 + PNG封面
```

**优势**：100%免费，5分钟出片
**劣势**：素材拼接非AI生成，需Pexels密钥

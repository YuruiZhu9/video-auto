### 1. FFmpeg 8.0 Whisper 原生集成 — 里程碑升级

FFmpeg 8.0（2024年8月发布）将 Whisper 直接集成进过滤器链，实现**视频→字幕一步完成**：

```
# 最简命令：视频直接输出字幕SRT
ffmpeg -i input.mp4 -af "whisper=model=base" output.srt

# 完整参数示例
ffmpeg -i input.mp4 \
  -af "whisper=model=medium,language=zh" \
  -map 0:s:0 output.srt
```

**支持的参数：**
| 参数 | 说明 |
|------|------|
| `model` | whisper模型（tiny/base/small/medium/large） |
| `language` | 目标语言（auto/中文zh/英文en） |
| `task` | transcribe（转录）或 translate（翻译） |
| `beam_size` | beam size参数 |

**技术原理：** 通过 `libwhisper`（whisper.cpp C bindings）实现，无需Python，直接在FFmpeg进程内完成ASR。

**优势：**
- 🚀 **零Python依赖**：一个命令完成视频→字幕
- ⚡ **流式处理**：边解码边转录，内存占用低
- 🔗 **滤镜链集成**：可与降噪(`afftdn`)、音量(`volume`)等滤镜组合

**劣势：**
- 仅输出字幕，不生成完整transcript JSON
- 模型需额外下载（FFmpeg自动拉取）
- 长视频处理速度依赖Whisper模型大小

**→ 文档路径：** `技术教程类/FFmpeg 8.0 Whisper原生集成深度解析.md`

### 2. video-understand Skill — HeyGen开源视频理解工具

HeyGen（AI视频生成平台）开源的专业Skill，定位为**本地视频内容理解**：

```

依赖：ffmpeg + ffmpeg（brew install ffmpeg）+ Whisper（可选）
评分：⭐ 4.7/5（65条评价）
周安装：241 | 总安装：1.7K | GitHub ⭐91
```

**三种提取模式对比：**

| 模式 | 原理 | 适用场景 |
|------|------|---------|
| `scene`（默认） | `select='gt(scene,0.3)'`场景变化检测 | 演讲/教程/PPT切换场景 |
| `keyframe` | 提取I帧（编码关键帧） | 已压缩视频，精准关键帧 |
| `interval` | 均匀时间间隔采样 | 固定节拍视频，规律性内容 |

**核心流程（Python脚本）：**
```
输入视频 → ffmpeg场景/关键帧检测 → 帧图像提取
                        ↓
              Whisper音频转录（可选）
                        ↓
              输出JSON（帧路径+时间戳+文字）
```

**JSON输出结构：**
```json

  "frames": [
    {"path": "/path/frame_0001.jpg", "timestamp": 0.0, "timestamp_formatted": "00:00"}
  ],
  "transcript": [
    {"start": 0.0, "end": 2.5, "text": "Hello and welcome..."}

}
```

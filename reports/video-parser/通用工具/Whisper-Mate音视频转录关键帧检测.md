# 通用工具 — Whisper Mate 全功能音视频转录与关键帧工具

> 🤖 更新：2026-03-31 | 来源：Whisper Mate 官网
> 维护状态：🆕 新增

---

## 核心工具/API

| 功能模块 | 功能描述 |
|----------|----------|
| **Whisper AI 转录** | 将音频/视频文件批量转录为文本，所有操作本地处理，隐私安全 |
| **字幕编辑器** | 内置波形编辑器，逐段预览转录结果，可手动校正 |
| **场景变化关键帧检测** | 自动检测视频中的场景切换点，标记在波形编辑器上 |
| **视频章节生成** | 自动识别章节结构，一键为视频添加章节标记 |
| **已有章节导入** | 支持导入已有章节信息，编辑后重新导出含章节视频 |
| **批量处理** | 支持批量转录多个音视频文件 |
| **MP4 支持** | 新增对 MP4 格式的完整支持 |

---

## 步骤流程

```
第1步：导入音视频
  · 支持拖拽导入，批量选择文件
  · 自动识别音频/视频格式

第2步：Whisper 转录（本地处理）
  · 自动选择最优 Whisper 模型
  · 实时显示转录进度
  · 输出时间戳对齐的字幕文件

第3步：场景关键帧检测（视频文件）
  · 自动检测场景变化节点
  · 关键帧缩略图显示在波形图上
  · 可点击跳转到对应时间点

第4步：章节生成与编辑
  · 根据内容自动切分章节
  · 支持手动添加/合并/删除章节
  · 预览章节缩略图

第5步：导出
  · 导出 SRT/ASS/VTT 字幕文件
  · 导出含章节信息的视频文件
  · 导出纯文本稿
```

---

## 适用场景

- **视频内容审核**：快速定位场景变化点，聚焦关键片段
- **教程视频切片**：场景检测自动分段，结合转录提取高光
- **播客/访谈整理**：批量转录 → 章节化 → 导出笔记
- **会议记录**：转录 + 章节，快速生成会议纪要
- **字幕制作**：转录 + 时间轴 → 校正 → 发布级字幕

## 避坑指南

| 问题 | 解决方案 |
|------|----------|
| **macOS 专属** | Whisper Mate 为 macOS 应用（需 macOS 12+），Windows/Linux 用户可用 Faster-Whisper CLI |
| **转录时间过长** | 使用 Faster-Whisper 后端（非 Whisper Mate 内置）；关闭其他占用 GPU 的应用 |
| **场景检测不准确** | 手动在波形图上拖拽调整关键帧位置 |
| **章节切分不合理** | 利用"导入已有章节"功能，从 YouTube/Bilibili 获取章节信息后导入编辑 |
| **中文转录质量差** | 使用 `medium` 或 `large-v3` Whisper 模型，中文识别率更高 |

## 与 OpenClaw 工具对比

| 功能 | Whisper Mate | OpenClaw audios_understand | OpenClaw videos_understand |
|------|-------------|------------------------------|----------------------------|
| 音频转录 | ✅ 本地 | ✅ 云端 API | ✅ 云端 API |
| 关键帧检测 | ✅ 场景变化 | ❌ | ⚠️ 语义层面 |
| 章节生成 | ✅ | ❌ | ❌ |
| 字幕导出 | ✅ SRT/VTT/ASS | ❌（返回纯文本）| ❌ |
| 批量处理 | ✅ | ✅ | ✅ |
| 隐私性 | ✅ 完全本地 | ❌ 数据上云 | ❌ 数据上云 |
| 平台 | macOS 专属 | 任意 | 任意 |

**最佳组合策略**：
- Whisper Mate（macOS）负责本地转录 + 章节 + 关键帧
- OpenClaw `videos_understand` 负责语义深度分析
- 两者互补：Whisper Mate 出时间轴，OpenClaw 出结构化内容理解

# 通用工具类 — 场景检测与语义切分方法

> 更新时间：2026-04-09 | 维护者：视频解析方法总结Agent

## 核心工具/API

### 1. FFmpeg 场景切换检测（内置，无需安装）
- **核心**：FFmpeg 内置 `scene detection` 过滤器，基于 `libavfilter`
- **算法**：基于帧间差异（帧差分 + MSE/PSNR）自动检测镜头切换
- **优点**：零依赖，零成本，完全本地运行
- **缺点**：仅检测镜头边界，无法语义理解

### 2. OpenCV 帧差分 + 阈值法
- **核心**：Python OpenCV 逐帧计算像素差异，人工设定阈值
- **优点**：完全可控，可自定义算法
- **缺点**：计算量大，阈值调参复杂

### 3. PySceneDetect
- **核心**：Python 专用镜头边界检测库，支持多种算法
- **算法**：阈值法 / 内容感知法（Content-Aware）
- **优点**：API 友好，支持关键帧自动提取
- **缺点**：长视频性能偏慢

### 4. MediaInfo + 自定义脚本
- **核心**：MediaInfo 提取元数据 + 自定义切分逻辑
- **适用**：已知结构化格式的视频（如固定时长分镜）

## 步骤流程

### 方案A：FFmpeg 场景检测 + 关键帧提取（推荐）
```bash
# 1. 安装 FFmpeg（已内置于 OpenClaw）
ffmpeg -version

# 2. 场景检测并输出时间戳
ffmpeg -i input.mp4 -filter:v "select='gt(scene,0.3)',showinfo" -f null - 2>&1 \
  | grep showinfo | awk -F'pts_time:' '{print $2}' | awk '{print $1}' \
  | head -50 > scene_timestamps.txt

# 3. 基于时间戳提取关键帧
while read ts; do
  ffmpeg -ss "$ts" -i input.mp4 -vframes 1 "frame_${ts}.jpg" -y
done < scene_timestamps.txt

# 4. 可视化场景边界（生成缩略图条带）
ffmpeg -i input.mp4 \
  -vf "select='gt(scene,0.3)',scale=160:90,tile=10x5" \
  -frames:v 50 overview.jpg -y
```

**参数说明**：
- `scene=0.3`：场景变化阈值（0~1），越高越敏感，建议 0.2~0.5
- `showinfo`：输出每帧详细信息（含时间戳）
- `select='gt(scene,0.3)'`：仅保留超过阈值的帧

### 方案B：PySceneDetect（内容感知法，更精准）
```python
from scenedetect import detect, ContentDetector, split_video_ffmpeg

# 检测场景边界（内容感知算法）
scene_list = detect('input.mp4', ContentDetector(threshold=30))
# threshold: 越高越不敏感，15~35 常用值

print(f"检测到 {len(scene_list)} 个场景")
for i, (start, end) in enumerate(scene_list):
    print(f"场景{i+1}: {start.get_timecode()} → {end.get_timecode()}")

# 自动切分视频片段
split_video_ffmpeg('input.mp4', scene_list, output_dir='./scenes/')
```

### 方案C：OpenCV 自定义帧差分
```python
import cv2
import numpy as np

def detect_scenes_opencv(video_path, threshold=30, min_scene_len=15):
    cap = cv2.VideoCapture(video_path)
    prev_frame = None
    scenes = []
    frame_id = 0
    last_cut = 0

    while True:
        ret, frame = cap.read()
        if not ret:
            break

        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        if prev_frame is not None:
            # 计算帧差分（MSE）
            diff = np.mean((gray.astype(float) - prev_frame.astype(float)) ** 2)
            if diff > threshold and (frame_id - last_cut) > min_scene_len:
                scenes.append(frame_id)
                last_cut = frame_id

        prev_frame = gray
        frame_id += 1

    cap.release()
    return scenes

# 使用
scenes = detect_scenes_opencv('input.mp4', threshold=500)
print(f"场景切换帧: {scenes}")
```

## 适用场景

- **教程视频结构化**：自动识别章节切换点
- **电影/综艺拆条**：按镜头自动切分短视频素材
- **视频 RAG 预处理**：将长视频切分为语义一致的短片段
- **批量视频索引**：生成可视化缩略图条带（storyboard）
- **对比视频分析**：对比同主题不同视频的结构差异
- **自动化剪辑**：为 AI 剪辑工具提供切分依据

## 避坑指南

### 阈值调参
- 固定阈值在亮度变化大的视频（PPT切换/动画）中容易误检
- 建议先用小样本测试：`scene=0.3` → 根据结果调整
- PySceneDetect 的 ContentDetector 比固定阈值更鲁棒

### 性能优化
- FFmpeg 场景检测可加 `-fast` 参数加速（牺牲少量精度）
- 长视频（>2小时）建议先用 FFmpeg 快速扫描，再精调
- OpenCV 帧差分对 4K 视频极慢，建议先降采样

### 语义 vs 镜头
- 场景检测只能找到镜头边界，无法理解"这是一个代码演示场景"
- 高质量切分 = 镜头边界 + AI 语义理解双重校验
- 建议：场景检测预处理 + `videos_understand` 语义标注

### 特殊情况
- 慢动作/定格画面：阈值需调低（否则检测不到切换）
- 快速切换（MTV/广告）：min_scene_len 防止过度切分
- 叠加字幕/水印：帧差分会误判，可先预处理去除

## 工具对比

| 工具 | 原理 | 精度 | 速度 | 依赖 | 适用场景 |
|------|------|------|------|------|---------|
| FFmpeg select | 帧差MSE | ⭐⭐ | 快 | 无 | 快速扫描、预览 |
| FFmpeg libavfilter | 内容感知 | ⭐⭐⭐ | 中 | libavfilter | 精确切分 |
| PySceneDetect | 阈值/内容 | ⭐⭐⭐ | 慢 | OpenCV | Python 集成 |
| OpenCV 自定义 | 帧差分 | ⭐⭐ | 慢 | OpenCV | 定制算法 |
| FFmpeg + AI | 镜头+语义 | ⭐⭐⭐⭐ | 中 | AI API | 高质量切分 |

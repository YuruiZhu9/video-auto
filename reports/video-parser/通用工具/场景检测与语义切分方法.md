# 场景检测与语义切分方法

## 核心工具/API

| 工具 | 功能描述 |
|------|---------|
| **FFmpeg scene detection** | 基于帧差异均值的镜头边界检测 |
| **FFmpeg select filter** | 按场景/帧率截取特定帧 |
| **OpenCV scene detection** | Python自定义精确场景检测 |
| **Whisper JSON output** | 带时间戳的段落级转录 |
| **videos_understand** | 多模态章节生成 |
| **Python (scikit-image)** | 高级特征匹配场景检测 |

## 步骤流程

### 流程概览

```
视频文件
  │
  ├─ 轨道A: FFmpeg场景检测 ─→ 时间戳列表
  │    └─ ffmpeg -vf "select='gt(scene,0.5)'" ...
  │
  ├─ 轨道B: Whisper转录 ─→ 段落时间戳
  │    └─ whisper video.mp4 --output_format json
  │
  └─ 轨道C: videos_understand ─→ AI章节摘要
       └─ 整体理解 + 自动分章
       
↓ 三轨融合
最终切片输出
```

### 第一步：FFmpeg 场景检测

**方法一：基础场景切换检测**

```bash
# 检测场景切换点，阈值0.5（越高越敏感）
ffmpeg -i video.mp4 \
  -vf "select='gt(scene,0.5)',showinfo" \
  -f null - 2>&1 | grep showinfo | head -30
```

输出解析（提取pts时间）：

```bash
# 提取场景切换时间点（秒）
ffmpeg -i video.mp4 \
  -vf "select='gt(scene,0.5)',showinfo" \
  -f null - 2>&1 | grep showinfo | \
  awk -F'pts_time:' '{print $2}' | awk '{print $1}' | head -20
```

**方法二：按时间间隔截帧（保底策略）**

```bash
# 每30秒一帧
ffmpeg -i video.mp4 -vf "fps=1/30" scene_%03d.jpg

# 每5分钟一帧（长视频用）
ffmpeg -i video.mp4 -vf "fps=1/300" chapter_%03d.jpg
```

**方法三：每个场景首帧提取**

```bash
# 输出为马赛克图（便于快速浏览）
ffmpeg -i video.mp4 \
  -vf "select='gt(scene,0.5)',scale=320:180,tile=4x4" \
  scenes_grid.jpg

# 输出为独立文件
ffmpeg -i video.mp4 \
  -vf "select='gt(scene,0.5)',scale=1280:720" \
  -vsync vfr scene_%04d.jpg
```

### 第二步：Whisper 段落切分

```bash
# 输出JSON（含时间戳和段落信息）
whisper video.mp4 \
  --model medium \
  --output_format json \
  --output_dir ./transcripts

# 查看输出结构
cat transcripts/video.json | python -m json.tool | head -60
```

**JSON输出结构示例：**

```json
{
  "text": "完整文字稿...",
  "segments": [
    {
      "start": 0.0,
      "end": 32.5,
      "text": "大家好，今天我们来介绍...",
      "id": 0
    },
    {
      "start": 32.5,
      "end": 75.3,
      "text": "首先，我们需要安装依赖包...",
      "id": 1
    }
  ]
}
```

### 第三步：双轨融合切分

```python
import json
import subprocess
import os

def merge_scenes_and_transcript(video_path, transcript_json, scene_threshold=0.5):
    """融合FFmpeg场景检测 + Whisper段落"""
    
    # 1. 获取Whisper段落
    with open(transcript_json) as f:
        whisper_data = json.load(f)
    segments = whisper_data["segments"]
    
    # 2. 获取FFmpeg场景切换点
    result = subprocess.run([
        "ffmpeg", "-i", video_path,
        "-vf", f"select='gt(scene,{scene_threshold})',showinfo",
        "-f", "null", "-"
    ], capture_output=True, text=True)
    
    scene_times = []
    for line in result.stderr.split('\n'):
        if 'pts_time:' in line:
            ts = line.split('pts_time:')[1].split()[0]
            scene_times.append(float(ts))
    
    # 3. 将场景点映射到Whisper段落
    chapters = []
    for i, scene_time in enumerate(scene_times):
        # 找包含此场景的Whisper段落
        for seg in segments:
            if seg["start"] <= scene_time < seg["end"]:
                chapters.append({
                    "chapter_id": i + 1,
                    "time": scene_time,
                    "whisper_segment": seg["text"][:100],
                    "start": seg["start"],
                    "end": seg["end"]
                })
                break
    
    return chapters

# 输出示例
chapters = merge_scenes_and_transcript("video.mp4", "transcripts/video.json")
for ch in chapters:
    print(f"[{ch['start']:.1f}-{ch['end']:.1f}] {ch['whisper_segment']}")
```

## 避坑指南

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 场景过于碎片 | 阈值0.3太低 | 调整至0.5-0.7 |
| 镜头切换漏检 | 淡入淡出变化小 | 改用 `decayscale=0.5` 降低基准 |
| Whisper段落不准 | 背景音乐干扰 | 加 `--audio_offset 0` 校准 |
| 截帧时间不准 | 编码延迟 | 用 `-vsync vfr` + 帧号反推 |
| 长视频场景过多 | 60fps帧率太细 | 先 `fps=2` 降采样再检测 |

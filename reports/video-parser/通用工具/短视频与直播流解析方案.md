## yt-dlp 全面命令参考

### 抖音（Douyin）

```bash
# 基本下载（自动获取最高画质）
yt-dlp "https://www.douyin.com/video/7291234567890123456"

# 下载并自动获取字幕
yt-dlp "URL" \
  --write-auto-sub \
  --write-subs \
  --sub-lang zh-Hans,en

# 仅获取元数据（不下载）
yt-dlp --dump-json "URL"

# 指定输出格式
yt-dlp "URL" \
  -o "%(title)s_%(id)s.%(ext)s" \
  --write-description \
  --write-info-json
```

### TikTok

```bash
# 下载（无需登录）
yt-dlp "https://www.tiktok.com/@username/video/12345678901234567890" \
  -o "tiktok_%(id)s.%(ext)s"

# 带字幕下载
yt-dlp "URL" \
  --write-auto-sub \
  --write-subs

# 更新 yt-dlp（TikTok反爬更新快）
yt-dlp -U
```

### B站（Bilibili）

```bash
# 下载单个视频（最高画质）
yt-dlp "https://www.bilibili.com/video/BV1xx411c7XD" \
  -f "bestvideo+bestaudio/best" \
  -o "%(title)s.%(ext)s"

# 下载整个系列（合集）
yt-dlp "https://www.bilibili.com/bangumi/play/ep123456" \
  -f "bestvideo+bestaudio/best"

# 下载弹幕（XML）
yt-dlp "URL" --write-binfo

# 下载字幕
yt-dlp "URL" --write-subs --write-auto-subs
```

### 快手

```bash
# 快手视频下载
yt-dlp "https://www.kuaishou.com/short-video/xxxxx" \
  -o "kuaishou_%(id)s.%(ext)s"
```

## 完整解析流程（以抖音为例）

```python
import subprocess
import json
import os

def parse_douyin_video(url, output_dir="./output"):
    """抖音视频完整解析流程"""
    os.makedirs(output_dir, exist_ok=True)
    
    # 1. 下载视频
    print("📥 下载视频中...")
    result = subprocess.run([
        "yt-dlp", url,
        "-o", f"{output_dir}/%(id)s.%(ext)s",
        "--write-info-json",
        "--write-auto-sub",
        "--write-subs",
        "--sub-lang", "zh-Hans"
    ], capture_output=True, text=True)
    
    # 2. 读取元数据
    info_file = [f for f in os.listdir(output_dir) if f.endswith('.info.json')]
    if info_file:
        with open(os.path.join(output_dir, info_file[0])) as f:
            metadata = json.load(f)
        print(f"✅ 标题: {metadata.get('title')}")
        print(f"✅ 时长: {metadata.get('duration')}秒")
        print(f"✅ 作者: {metadata.get('uploader')}")
    
    # 3. Whisper转录
    video_file = [f for f in os.listdir(output_dir) 
                  if f.endswith(('.mp4', '.flv', '.mkv')) and not f.startswith('.')]
    if video_file:
        video_path = os.path.join(output_dir, video_file[0])
        print("🎙️ 转录中...")
        subprocess.run([
            "whisper", video_path,
            "--model", "medium",
            "--language", "zh",
            "--output_format", "json",
            "--output_dir", output_dir
        ])
    
    return output_dir

# 使用
parse_douyin_video("https://www.douyin.com/video/7291234567890123456")
```

## 二、直播流解析方案

### 核心工具/API

| 工具 | 功能描述 |
|------|---------|
| **streamlink** | 多平台直播流获取（抖音/B站/Twitch/YouTube） |
| **FFmpeg** | 直播流转码/录制/截图 |
| **Whisper** | 直播录后转录 |
| **python-livestream** | 直播流Python封装 |

### streamlink 使用

```bash
# 安装
pip install streamlink

# 查看平台支持
streamlink --plugins

# 抖音直播
streamlink "https://live.douyin.com/xxxxx" best -o douyin_live.ts

# B站直播
streamlink "https://live.bilibili.com/123456" best -o bilibili_live.mp4

# Twitch
streamlink "https://twitch.tv/channel_name" best -o twitch.ts

# YouTube直播
streamlink "https://www.youtube.com/watch?v=xxx" best -o youtube_live.mp4
```

### FFmpeg 直接拉流

```bash
# HLS流录制
ffmpeg -i "https://example.com/live.m3u8" \
  -c copy -bsf:a aac_adtstoasc output.mp4

# RTMP流录制（抖音部分直播）
ffmpeg -i "rtmp://stream.example.com/live/stream_key" \
  -c copy live_record.mp4

# DASH流录制
ffmpeg -i "https://example.com/manifest.mpd" \
  -c copy dash_record.mp4
```

### 直播流解析流程

```
直播URL
  │
  ├─ streamlink 获取真实流地址
  │    └─ streamlink "URL" best -o temp.ts
  │
  ├─ 分段录制（避免中途断开丢失全部内容）
  │    └─ 每5分钟一段: ffmpeg -i input -f segment -segment_time 300
  │
  ├─ 实时截图（每30秒）
  │    └─ ffmpeg -i live.mp4 -vf "fps=1/30" frame_%03d.jpg
  │
  └─ 录后转录（全量Whisper）
       └─ whisper full_recording.mp4 --model medium --output_format json
       
最终输出：
- 完整录制文件（分片段）
- 实时截图合集
- 全场文字稿（SRT）
- 关键片段列表（截帧+对应时间点）
- AI全场总结
```

### 直播流质量监控

```bash
# 录制时实时监控音视频质量
ffmpeg -i "streamlink_url" \
  -vf "signalstats" \
  -f null - 2>&1 | grep -E "YB|UB|VB|AN"

# 检查直播流信息
ffprobe -v quiet -print_format json \
  -show_streams "https://live.example.com/stream.m3u8"
```

## 适用场景

| 场景 | 推荐方案 | 说明 |
|------|---------|------|
| **抖音短视频分析** | yt-dlp + Whisper + videos_understand | 单视频 <60s，全量处理 |
| **TikTok海外分析** | yt-dlp + Whisper + 翻译 | 加NLLB/DeepL翻译 |
| **B站教程视频** | yt-dlp + 场景检测 + 结构化 | B站画质好，支持字幕 |
| **抖音/B站直播** | streamlink录制 + Whisper | 分段录制防止断流 |
| **快手带货分析** | yt-dlp + 评论抓取 + 情感分析 | 分析带货话术 |
| **多平台批量监控** | n8n + yt-dlp定时任务 | 定时抓取+存储 |

## 避坑指南

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 抖音视频403错误 | IP被识别/无Cookie | 用cookies + 代理IP池 |
| TikTok下载失败 | 反爬策略更新 | `yt-dlp -U` 更新 + cookies |
| 直播流中途断开 | 网络/平台限流 | 用 `-reconnect 1` 参数 |
| 无水印提取失败 | 抖音改版 | 改用官方DouyinToolkit |
| 直播转录延迟高 | 非流式Whisper | 换 Faster-Whisper C++版 |
| B站弹幕提取乱码 | XML编码问题 | 用 `danmu2srt.py` 转SRT |

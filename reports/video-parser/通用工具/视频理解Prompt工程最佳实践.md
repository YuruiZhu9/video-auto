## 一、为什么 Prompt 决定解析质量

视频理解模型的输出质量，**70% 取决于 Prompt 设计**，30% 取决于模型能力。视频信息密度高、时长变化大，没有针对性的 Prompt，模型容易输出：

- ❌ 过于笼统的"这个视频讲了一些关于X的主题"
- ❌ 遗漏关键步骤和代码示例
- ❌ 时间顺序混乱，难以还原学习路径
- ❌ 混入了模型自己的推测而非视频实际内容

## 二、技术教程类 Prompt 模板

### 模板 A：知识点提取型（适合教学视频）

```
请作为专业技术教程分析师，详细分析这个视频并输出结构化笔记。

分析维度：
1. 【主题定位】视频标题/主题，一句话描述
2. 【前置知识】学习本视频需要哪些基础（列出2-4项）
3. 【核心步骤】按时间顺序列出关键操作步骤（每步注明时间段）
4. 【代码片段】提取所有出现的命令和代码（注明时间戳）
5. 【关键概念】用通俗语言解释视频中的核心概念（3-5个）
6. 【资源链接】视频中提到的工具/文档/链接（如有）
7. 【总结】3句话概括本视频的核心价值

⚠️ 重要：请基于视频实际内容回答，不要编造未出现的信息。
```

### 模板 B：深度评估型（适合开源项目演示）

```
你是一个严格的技术评审员。请评估这个开源项目演示视频：

评估维度：
1. 【项目概况】项目名称、技术栈、解决的问题（2-3句话）
2. 【核心功能】按重要性排序，列出演示的前3个功能
3. 【架构亮点】技术架构设计中值得学习的地方
4. 【代码质量】代码风格、可维护性、可扩展性评估
5. 【局限性】视频中暴露的缺点或未解决的场景
6. 【学习价值】本视频对以下人群的价值：初级开发者 / 中级开发者 / 架构师
7. 【复现难度】根据视频内容，估计复现该项目需要的时间和难度（1-10分）
8. 【推荐指数】综合评分（1-10分）及理由

请直接输出，不要说"根据视频..."这类话。
```

### 模板 C：快速摘要型（适合长视频/系列视频）

```
用300字以内概括这个视频的核心内容，包含：
- 一句话主题
- 3个关键要点
- 目标受众
- 推荐指数（1-5⭐）
```

## 三、行业分享类 Prompt 模板

### 模板 A：观点提炼型（适合TED/行业峰会）

```
作为专业行业分析师，请深度解读这个视频：

1. 【核心观点】提炼3-5个最重要观点，每个观点用一句话概括
2. 【数据引用】提取视频中所有具体数字、排名、案例（注明时间点）
3. 【趋势判断】视频传达的行业发展趋势是什么
4. 【商业机会】从内容中可以看出哪些商业机会或创业方向
5. 【可信度评估】信息来源的权威性（高/中/低）及理由
6. 【受众画像】这个视频最适合哪类人群观看
7. 【金句摘录】视频中最值得记录的一句话（带时间戳）

请用中文回答，引用视频中的原话而非你的推测。
```

```
4. 【核心代码】演示中最关键的代码片段（带文件名）
5. 【常见问题】复现时可能遇到的坑及解决方案
6. 【延伸学习】深入理解项目推荐阅读的资料

⚠️ 只输出视频中实际出现的内容，不要推测未展示的步骤。
```

### 模板 B：技术评估型

```
从技术角度看，这个开源项目演示视频透露了哪些信息？

评估维度：
- 技术选型（语言/框架/工具）
- 架构设计（模块划分、数据流）
- 代码规范（命名/注释/测试）
```

## 五、通用技巧

### 1. 指定输出格式（避免自由发挥）

❌ 差：`请分析这个视频讲了什么`
✅ 好：`请按以下JSON格式输出：{"title":"","steps":[],"code":[],"summary":""}`

### 2. 要求引用时间戳（便于回溯）

✅ 好：`提取视频中的关键步骤，每步注明大致时间点，如 [02:30]`

### 3. 限制模型推测空间

❌ 差：`视频还提到了哪些相关内容？`
✅ 好：`只基于视频内容回答，不要补充视频未提及的信息。无法确定的内容请注明"未明确"。`

### 4. 中文优先（避免语言混乱）

✅ 好：`请全部使用中文回答，避免在回答中夹杂英文术语（专有名词除外）。`

### 5. 针对长视频分段分析

```
第一部分（前10分钟）：
[上述Prompt模板]

第二部分（10-30分钟）：
[上述Prompt模板]

第三部分（30分钟以后）：
[上述Prompt模板]

最后综合三部分，输出完整总结。
```

### 6. 给模型"角色"（提升专业度）

✅ 好：`你是一位有10年经验的后端工程师，请从这个角度分析视频中的代码`

## 六、常见问题与修正

| 问题现象 | 原因 | 修正 Prompt |
|---------|------|------------|
| 输出太笼统 | Prompt 太宽泛 | 添加具体维度要求 |
| 遗漏代码 | 视频一闪而过没注意 | `请特别注意捕捉代码和命令` |
| 时间戳不准 | 视频无字幕模型估计 | `时间戳为估算，可接受±30秒误差` |
| 内容过于推测 | 模型自由发挥 | `请只引用视频中实际出现的原话` |
| 输出语言混乱 | 未指定语言 | `请全部用中文回答` |
| 结构不清晰 | 未要求固定格式 | 要求输出固定 JSON 或 Markdown 格式 |

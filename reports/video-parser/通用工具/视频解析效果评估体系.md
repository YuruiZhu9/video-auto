## 一、为什么需要评估体系

视频解析不像 API 调用有客观返回值——它输出的是结构化笔记、摘要、时间戳，这些内容的质量高度主观且依赖下游用途。同一个解析结果，对"快速浏览"够用，对"写教程文章"可能不够。

建立评估体系的价值：
1. **选型依据**：量化对比不同工具/方法的效果
2. **Prompt 迭代**：验证 Prompt 改动的实际提升
3. **质量门槛**：自动化判断解析结果是否达到发布标准
4. **持续监控**：跟踪解析质量随时间的变化

## 三、逐维度评估方法

### 3.1 完整性评估（Completeness）

**评估方法**：与人工标注对比

**人工标注流程**：
1. 人工观看视频，记录所有关键点（概念/数据/步骤/引用）
2. 统计人工标注要点数 N_human
3. 解析结果提取要点数 N_parse
4. 计算召回率：Recall = N_parse / N_human × 100%

**打分标准**：
| 召回率 | 评分 | 说明 |
|--------|------|------|
| ≥90% | ⭐⭐⭐⭐⭐ (5分) | 几乎无遗漏 |
| 75%-90% | ⭐⭐⭐⭐ (4分) | 少量遗漏 |
| 60%-75% | ⭐⭐⭐ (3分) | 有明显遗漏 |
| 40%-60% | ⭐⭐ (2分) | 遗漏较多 |
| <40% | ⭐ (1分) | 严重遗漏 |

**自动化辅助**：
```python
def evaluate_completeness(human_labels: list[str], parse_result: str) -> dict:
    """评估解析完整性"""
    from difflib import SequenceMatcher
    
    scores = []
    for label in human_labels:
        # 计算标签与解析结果的最大相似度
        similarity = SequenceMatcher(None, label, parse_result).ratio()
        scores.append(similarity)
    
    recall = sum(1 for s in scores if s > 0.6) / len(human_labels)
    avg_similarity = sum(scores) / len(scores)
    
    return {
        "recall": recall,
        "avg_similarity": avg_similarity,
        "score": 5 if recall >= 0.9 else 4 if recall >= 0.75 else 3 if recall >= 0.6 else 2 if recall >= 0.4 else 1,
        "missing_topics": [human_labels[i] for i, s in enumerate(scores) if s < 0.5]
    }
```

### 3.2 准确性评估（Accuracy）

**评估方法**：多角度事实核查

**核查项目**：
| 类别 | 核查方法 | 工具 |
|------|---------|------|
| 数值/日期 | 显式核查 | 视频帧 + 字幕对比 |

| 命令行 | 实际执行 | Docker/终端 |

**打分标准**：
| 错误类型 | 扣分 | 说明 |
|---------|------|------|
| 关键事实错误（数据/结论） | -2分/处 | 严重影响可用性 |
| 次要细节错误（人名/版本） | -1分/处 | 不影响理解 |
| 歧义性表达（语气过强/模糊） | -0.5分/处 | 不影响操作 |
| 无错误 | 5分 | 零错误 |

**自动化辅助**：
```python
def extract_claims(parse_result: str) -> list[dict]:
    """从解析结果中提取可核查声明"""
    import re
    # 提取数字声明：增长200% / 2024年 / 3.5倍
    numbers = re.findall(r'([+-]?\d+\.?\d*%|[+-]?\d+\.?\d*倍)', parse_result)
    # 提取引用：GitHub / 论文名
    links = re.findall(r'https?://[^\s]+', parse_result)
    # 提取代码块
    code_blocks = re.findall(r'```[\s\S]*?```', parse_result)
    return {"numbers": numbers, "links": links, "code_blocks": code_blocks}
```

## 四、综合评分计算

```python
def compute_overall_score(
    completeness: float,    # 0.0-1.0
    accuracy: float,       # 0.0-1.0
    temporal: float,       # 0.0-1.0
    structured: float,     # 0.0-1.0
    actionability: float,  # 0.0-1.0
    efficiency: float,     # 0.0-1.0
) -> dict:
    weights = [0.25, 0.25, 0.15, 0.15, 0.10, 0.10]
    scores = [completeness, accuracy, temporal, structured, actionability, efficiency]
    
    weighted = sum(w * s for w, s in zip(weights, scores))
    
    # 等级划分
    if weighted >= 0.9:
        grade = "A+ (卓越)"
    elif weighted >= 0.8:
        grade = "A (优秀)"
    elif weighted >= 0.7:
        grade = "B+ (良好)"
    elif weighted >= 0.6:
        grade = "B (及格)"
    elif weighted >= 0.5:
        grade = "C (需改进)"
    else:
        grade = "D (不合格)"
    
    return {
        "overall_score": round(weighted, 3),
        "grade": grade,
        "dimension_scores": {
            "completeness": completeness,
            "accuracy": accuracy,
            "temporal": temporal,
            "structured": structured,
            "actionability": actionability,
            "efficiency": efficiency
        },
        "weakest_dimension": min(zip(scores, ['completeness','accuracy','temporal','structured','actionability','efficiency']))
    }
```

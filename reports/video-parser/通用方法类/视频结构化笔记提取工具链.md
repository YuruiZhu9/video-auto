## 概述

视频结构化笔记提取工具是一类专门从视频中生成**可读笔记、时间戳章节、关键要点、行动项**的工具。相比纯字幕提取，这类工具额外做了：
1. **语义压缩**：将长篇转录文本浓缩为结构化要点
2. **章节切分**：基于语义自动划分时间章节
3. **格式美化**：Markdown / Notion / PDF 等可读格式输出

## 一、video-note-extractor（Sachi1312）

**⭐ 推荐指数：★★★★★**

### 核心工具/API
- **Groq Whisper API**：超低延迟（~30x 实时）转录，零排队
- **Groq Llama**：结构化笔记生成，支持章节+要点+行动项
- **yt-dlp**：YouTube 视频下载/音频提取
- **ffmpeg**：本地音视频处理

### 步骤流程
```bash
# 1. 安装
git clone https://github.com/Sachi1312/video-note-extractor.git
cd video-note-extractor
pip install -r requirements.txt

# 2. 设置 API Key（Groq 免费，无需信用卡）
export GROQ_API_KEY="gsk_xxxx"

# 3. 运行
python app.py
# 或 CLI 模式
python cli.py --url "https://youtu.be/xxxx"

# 4. 输出：timestamped_notes.md + searchable_transcript.txt
```

### 适用场景
- YouTube 技术教程 → 带时间戳的步骤笔记
- 播客/访谈 → 关键引述 + 话题总结
- 会议演讲 → 章节 + 要点 + 行动项
- 学术讲座 → 结构化讲稿

### 避坑指南
- ⚠️ **Groq API 免费额度的限制**：500+ 分钟/天，超出后需申请更多配额
- ⚠️ **长视频（>3h）**：建议分段处理，避免单次超时
- 💡 **优化技巧**：设置 `MAX_SEGMENT_MINUTES=30` 分段处理长视频

## 二、Video Note Generator（Humble-Librarian）

**⭐ 推荐指数：★★★★☆**

### 核心工具/API
- **Groq Whisper API**：高速转录
- **Groq Llama 3**：Cinematic 风格笔记生成（更像人类编辑的格式）
- **YouTube DL**：视频源获取

### 步骤流程
```bash
git clone https://github.com/Humble-Librarian/Video-Note-Generator
cd Video-Note-Generator
pip install -r requirements.txt
streamlit run app.py
# 打开 http://localhost:8501，输入 YouTube URL
```

### 适用场景
- 追求**高可读性**笔记的用户（类似 Notion 风格）
- 视频学习场景（课程、演讲）
- 生成**可直接分享**的笔记文档

### 避坑指南
- ⚠️ 依赖 Groq API，免费 Key 申请：https://console.groq.com/keys
- ⚠️ 不支持本地视频文件上传（仅支持 YouTube URL）
- 💡 可 fork 定制 prompt，改为自己喜欢的笔记风格

## 三、ai-video-note-extractor（heba-mans）

**⭐ 推荐指数：★★★★☆**

### 核心工具/API
- **FastAPI**：异步 API 后端
- **Celery + Redis**：任务队列，支持并发长视频处理
- **Whisper**：本地转录（保护隐私）
- **PostgreSQL**：结构化存储笔记
- **Groq Llama**：笔记生成

### 步骤流程
```bash
# Docker 快速启动（推荐）
git clone https://github.com/heba-mans/ai-video-note-extractor
cd ai-video-note-extractor
cp .env.example .env  # 配置 GROQ_API_KEY 等
docker-compose up -d

# API 调用
curl -X POST "http://localhost:8000/api/extract" \
  -d '{"url": "https://youtu.be/xxxx"}'
```

### 适用场景
- **团队/企业内部部署**：数据不上传到第三方
- **批量处理**：Celery 队列支持多视频并发
- **生产级应用**：FastAPI 标准，适合集成到现有系统

### 避坑指南
- ⚠️ Docker 环境要求较高，内存建议 4GB+
- ⚠️ Celery 需要 Redis，首次配置较复杂
- 💡 推荐先用 Docker compose 体验，后续按需拆分服务

## 四、groqnotes（wuzhenhuo）

**⭐ 推荐指数：★★★☆☆**

### 核心工具/API
- **Groq Whisper API**：超快转录
- **Llama 3 8B + 70B**：两阶段生成（70B 建结构，8B 填内容）
- **Streamlit**：Web 界面

### 步骤流程
```bash
git clone https://github.com/wuzhenhuo/groqnotes
cd groqnotes
pip install -r requirements.txt
export GROQ_API_KEY="gsk_xxxx"
streamlit run app.py
```

### 适用场景
- **学术讲座**：讲稿结构笔记
- 法学/医学/工程类视频：专业术语笔记
- 喜欢迭代精炼笔记的用户（groqnotes 支持多轮生成）

### 避坑指南
- ⚠️ Llama 70B 生成结构，8B 生成内容，两次 API 调用成本略高
- ⚠️ UI 相对简单，不如视频-note-extractor 功能完整
- 💡 适合需要**高质量讲稿**而非快速摘要的场景

## 五、YouTube AI Notes（VegaStack，SaaS）

**⭐ 推荐指数：★★★☆☆**

### 核心工具/API
- **YouTube Transcript API**：官方字幕提取（最快，无需 Whisper）
- **OpenAI GPT**：笔记生成

### 步骤流程
```
1. 打开 https://youtube-notes.vegastack.com/
2. 粘贴 YouTube URL
3. 自动生成笔记（约 30 秒）
```

### 适用场景
- **零配置快速体验**：不想搭任何环境
- YouTube 视频（必须有字幕或自动字幕）
- 一次性使用

### 避坑指南
- ⚠️ 依赖 YouTube 自动字幕，无字幕视频无法处理
- ⚠️ SaaS 收费，有免费次数限制
- ⚠️ 数据隐私（视频内容上传到第三方）

## 六、与 OpenClaw 工具链的整合

### 组合方案：summarize CLI + video-note-extractor

```bash
# Step 1: 快速获取摘要（~30秒）
summarize "https://youtu.be/xxxx" --length short

# Step 2: 深入提取结构化笔记（~2分钟）
git clone https://github.com/Sachi1312/video-note-extractor.git
cd video-note-extractor
python cli.py --url "https://youtu.be/xxxx"

# Step 3: 导入 OpenClaw Memory
# 将生成的 markdown 笔记存入 workspace/memory/
cp timestamped_notes.md /workspace/memory/video-notes-$(date +%Y%m%d).md
```

### OpenClaw 内置替代方案：summarize Skill

```bash
# 快速摘要（YouTube / 本地文件 / URL）
summarize "https://youtu.be/xxxx" --youtube auto --length medium

# 提取字幕（无 GPT 处理）
summarize "https://youtu.be/xxxx" --youtube auto --extract-only
```

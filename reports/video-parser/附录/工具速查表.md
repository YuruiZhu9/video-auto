# 附录 — 工具速查表

## 一、OpenClaw 内置工具

| 工具 | 功能 | 输入 | 备注 |
|------|------|------|------|
| `videos_understand` | 视频多模态理解（视觉+音频） | 本地视频路径/URL，最多10个并行 | 核心工具 |
| `images_understand` | 图片/帧内容分析 | 本地图片/URL，最多20个并行 | 配合帧提取使用 |
| `batch_web_search` | 网络搜索 | 关键词，最多10个并发 | 免费 |
| `extract_content_from_websites` | 提取网页正文 | URL，最多10个并发 | 免费 |
| `browser` | 浏览器截屏/交互 | URL | 可截取在线视频画面 |

## 二、命令行工具

| 工具 | 安装状态 | 功能 | 常用命令 |
|------|----------|------|----------|
| ffmpeg | ✅ 已安装 | 音视频处理（转码/提取/切割） | `ffmpeg -i in.mp4 -vn audio.wav` |
| yt-dlp | ✅ 已安装 | 下载在线视频 | `yt-dlp "URL"` |
| ffprobe | ✅ 已安装 | 查看视频元信息 | `ffprobe -v error -show_entries video=duration -of json in.mp4` |
| frame.sh | ✅ OpenClaw内置 | 快速提取单帧 | `frame.sh video.mp4 --time 00:01:00 --out frame.jpg` |

## 三、Python 库（需 pip install）

| 库 | 用途 | 安装命令 |
|---|------|----------|
| faster-whisper | 快速离线语音转写（推荐）| `pip install faster-whisper` |
| openai-whisper | OpenAI Whisper 转写 | `pip install openai-whisper` |
| moviepy | Python 视频处理 pipeline | `pip install moviepy` |
| opencv-python | 视频帧处理/计算机视觉 | `pip install opencv-python` |

## 四、云端 API

| API | 用途 | 限制 |
|-----|------|------|
| Google Gemini API | 视频多模态分析 | 20MB/请求 |
| OpenAI Whisper API | 云端语音转写 | 按分钟计费 |
| Apify YouTube Scraper | YouTube 数据提取 | 需 API Token |
| Firecrawl | 反爬网页内容提取 | 需 API Key |

## 五、按场景快速选型

| 场景 | 推荐工具链 |
|------|-----------|
| 技术教程视频 → 结构化笔记 | `videos_understand` + `images_understand` 关键帧 |
| YouTube 视频 → 快速摘要 | `summarize --youtube auto` |
| 开源 Demo → 命令行提取 | `ffmpeg` 提取音频 → `faster-whisper` 转写 → 正则提取命令 |
| B站视频 → 摘要 | `yt-dlp` 下载 → `summarize` 本地文件 |
| 超长视频 → 分段处理 | `ffmpeg` 切割 → 并行 `videos_understand` |
| 精准结构化 JSON 输出 | Gemini API（支持 JSON Schema）|
| 完全离线处理 | `ffmpeg` + `faster-whisper` |

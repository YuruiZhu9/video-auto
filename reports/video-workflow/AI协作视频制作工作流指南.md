## 📋 四阶段详解

### 第一阶段：文案生成

**目标**：产出完整视频脚本、台词、字幕文本

**流程**：
1. **主题确定**：明确视频目标受众、核心信息、传播平台
2. **脚本撰写**：结构化叙事（开头钩子 → 正文 → 结尾CTA）
3. **台词准备**：口语化表达，预留配音时间轴标注

**提示词模板**：
```
请为[主题]创作一条[时长]秒的短视频脚本
目标受众：[受众描述]
核心信息：[要传达的观点]
风格：[幽默/正式/感人/科技感]
平台：[抖音/B站/小红书/微信]
```

### 第四阶段：视频合成

#### 方案对比

| 工具 | 难度 | 适合场景 | 自动化程度 |
|------|------|----------|------------|
| **剪映专业版** | ⭐ 简单 | 短视频、自媒体 | 半自动（手动剪辑+AI辅助）|
| **FFmpeg** | ⭐⭐⭐⭐ 复杂 | 批量处理、专业级 | 全自动脚本化 |
| **Canva** | ⭐ 简单 | 社媒内容、快速剪辑 | 模板化 |
| **InVideo** | ⭐⭐ 简单 | 在线协作、模板丰富 | 较高 |

#### FFmpeg 核心命令速查

```bash
# 合并视频和音频
ffmpeg -i video.mp4 -i audio.mp3 -c:v copy -c:a aac output.mp4

# 视频加水印
ffmpeg -i input.mp4 -i watermark.png -filter_complex "overlay=10:10" output.mp4

# 调整分辨率和码率（压缩）
ffmpeg -i input.mp4 -vf "scale=1920:1080" -b:v 5000k output.mp4

# 批量提取音频
for f in *.mp4; do ffmpeg -i "$f" -vn -ab 192k "${f%.mp4}.mp3"; done

# 音画同步修复（需先运行PrismAudio）
ffmpeg -i video.mp4 -i audio.wav -c:v copy -c:a aac -async 1 output_synced.mp4
```

## 💡 效率优化技巧

### 提示词工程

**视频生成提示词模板**：
```
[镜头类型：特写/中景/全景] + [主体描述] + [动作/情绪] + [场景背景] + [风格要求]
示例："Close-up of a young woman smiling in a modern office, natural lighting, cinematic style"
```

**语音克隆质量要点**：
- 安静环境录制，5-30秒即可
- 避免背景音乐、人声重叠
- 多种情感/语速的样本效果更好
- 生成后用 PrismAudio 做音画同步检测

### 批量化生产

- **多视频并行**：Seedance 2.0 / Kling API 支持并发请求
- **模板复用**：剪映项目模板，一键换图换音频
- **音频流水线**：MAI-Transcribe-1 批量生成字幕 → 导入剪映自动对轨

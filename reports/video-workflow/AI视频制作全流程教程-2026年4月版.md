### 阶段②：文案生成

**首选：Qwen3.5-Max（LM Arena 全球第一）**

调用智谱AI示例：
```python
import requests

url = "https://open.bigmodel.cn/api/paas/v4/chat/completions"
headers = {"Authorization": "Bearer YOUR_ZHIPU_KEY"}
data = {
    "model": "glm-4-flash",
    "messages": [{
        "role": "user",
        "content": "为一个AI技术科普视频写一份3分钟解说脚本，主题是'大模型如何理解你的意图'，要求：开头有钩子，中间有3个要点，最后有总结和行动号召。"
    }]
}
resp = requests.post(url, headers=headers, json=data)
print(resp.json()["choices"][0]["message"]["content"])
```

**脚本结构模板**：
```
【开场钩子】（0-10秒）：痛点/悬念/惊人数据
【正文要点1】（10-40秒）：核心论点 + 视觉对应
【正文要点2】（40-70秒）：案例/数据支撑
【正文要点3】（70-100秒）：深度解析/反直觉发现
【总结+行动号召】（100-120秒）：核心收获 + 关注/评论引导
```

#### 6.2 视频剪辑

**首选：剪映专业版**（免费，AI功能丰富）

**核心AI功能**：
- ✂️ 智能剪接：AI自动识别精彩片段，一键成片
- 🎙️ 语音转字幕：自动识别中文/英文，生成SRT字幕
- 🎵 AI音乐推荐：根据视频节奏匹配BGM
- ✨ AI特效：转场、滤镜、动态效果
- 🗣️ 音色克隆：支持个人声音克隆（会员）

**FFmpeg 自动化合成**：
```bash
# 合并视频片段
ffmpeg -f concat -safe 0 -i filelist.txt -c copy output.mp4

# 视频+音频+字幕合成
ffmpeg -i video.mp4 -i audio.wav -i subtitles.srt \
  -c:v libx264 -c:a aac -c:s mov_text \
  -map 0:v -map 1:a -map 2:s \
  final_output.mp4

# 抖音竖屏（9:16）
ffmpeg -i input.mp4 -vf "scale=1080:1920" -b:v 3000k \
  -b:a 128k -r 30 output_9x16.mp4

# 添加封面
ffmpeg -i final.mp4 -i cover.jpg -map 0 -map 1 \
  -c:v libx264 -c:a aac -c:v:1 copy output_cover.mp4
```

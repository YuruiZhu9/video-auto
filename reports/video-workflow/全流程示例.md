## 第一阶段：文案生成

### 1.1 主题确定

**工具**：ChatGPT / Claude 4.6 / 智谱GLM-4-Flash（免费）

**方法**：
1. 确定视频目标受众和传播平台（抖音/小红书/B站/微信视频号）
2. 用LLM进行选题头脑风暴，输出5-10个备选主题
3. 评估维度：话题热度、受众覆盖面、商业转化潜力、制作难度

```python
# 智谱AI免费API调用示例
import requests
url = "https://open.bigmodel.cn/api/paas/v4/chat/completions"
headers = {"Authorization": "Bearer YOUR_KEY"}
data = {
    "model": "glm-4-flash",
    "messages": [{"role": "user", "content": "为一个AI科技博主策划5期短视频选题，涵盖AI前沿、大模型应用、职场干货"}]
}
```

### 1.2 脚本撰写

**推荐工具**：Claude 4.6 / GPT-5.4（长文本能力强）

**脚本结构（短视频模板，60秒内）**：
```
[开场钩子 0-5秒]
"你知道吗？AI正在颠覆一个你每天都在用的功能……"

[核心内容 5-45秒]
- 痛点引入（5秒）
- 解决方案（20秒）
- 案例/数据佐证（15秒）

[结尾引导 45-60秒]
"如果你觉得有用，点赞+关注，我们下期见！"
```

**进阶：多版本A/B测试**
同时生成3个不同风格的脚本版本（专业型/娱乐型/情感型），通过数据反馈选择最优版本。

### 1.3 字幕/台词准备

- 使用Whisper或Cohere Transcribe（开源，Apache 2.0）对参考视频进行语音识别，生成台词稿
- 台词字数控制：每分钟180-220字（适合快速阅读）

## 第二阶段：视觉生成

### 2.1 PPT / 动画生成

#### Gamma.app（推荐指数：⭐⭐⭐⭐⭐）

**核心能力**：AI生成PPT，支持Markdown导入，自动排版，支持在线演示

**使用流程**：
1. 注册登录 gamma.app
2. 点击"新建" → "导入内容" → 粘贴脚本或Markdown
3. 选择主题风格（商务/创意/学术等）
4. AI自动生成10-15页PPT，可手动调整
5. 导出为PDF或在线分享链接

**技巧**：
- 在Markdown中使用`## 标题`标记每页主题
- 加入数据时使用表格语法，Gamma会智能转换为图表
- 配合GIF动图可大幅提升观看体验

#### Motion Go（推荐指数：⭐⭐⭐⭐）

**核心能力**：PPT一键生成动画，支持嘴型同步

**使用流程**：
1. 上传静态PPT或使用Gamma生成
2. 选择动画模板（入场动画/强调动画/转场动画）
3. AI自动分析内容，匹配合适动画效果
4. 支持导出为视频格式

#### AiPPT / Beautiful.ai

- **AiPPT**：国产AI PPT工具，中文支持好，适合国内平台
- **Beautiful.ai**：海外工具，国际化风格，适合YouTube/LinkedIn内容

### 2.2 配图生成

#### Hypereal AI（推荐指数：⭐⭐⭐⭐⭐，首选推荐）

**特点**：35免费积分，图片+视频+3D+语音统一API，无需多平台注册

**API调用示例（图片生成）**：
```bash
curl -X POST https://api.hypereal.ai/v1/generate/image \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "flux-2",
    "prompt": "futuristic AI data center, neon lighting, holographic displays, cinematic lighting",
    "width": 1024,
    "height": 1024,
    "style_preset": "cinematic"
  }'
```

**适用场景**：
- 视频封面图（16:9或9:16）
- 脚本配图（信息图、概念图、场景图）
- 人物角色图（使用参考图进行风格迁移）

#### Midjourney V7 / DALL-E 4

- **Midjourney V7**：高画质艺术风格，适合高端创意内容
- **DALL-E 4**：多模态理解能力强，适合图文混合内容

**提示词技巧（配图生成）**：
```
主体描述 + 风格标签 + 光线 + 构图 + 比例
例："A robot teaching human students in a futuristic classroom, 
    soft cinematic lighting, wide angle shot, 16:9 aspect ratio"
```

**核心能力**：最逼真的语音克隆，支持30+语言，可调节情感/语速/音调

**使用流程**：

2. AI训练专属语音模型（约5-10分钟）
3. 调用API生成克隆语音

**API调用**：

```python
        "style": 0.3,
        "speed": 1.0
    }
}
```

## 第四阶段：视频合成

### 4.1 剪映专业版（推荐指数：⭐⭐⭐⭐⭐）

**AI功能**：
- AI图生视频（一键将静态图转为动态视频）
- AI配音（文字转语音，多音色可选）
- AI识别字幕（自动生成+对齐）
- AI成片（输入文案自动生成完整视频）

**使用流程**：
1. 导入生成的配图/视频片段
2. 按脚本顺序排列时间轴
3. 添加AI配音和背景音乐
4. 使用AI自动字幕
5. 添加转场效果（推荐：闪切/溶解/推拉）
6. 导出（推荐设置：1080P/60fps/H.264）

**AI成片功能**：
```
输入文案 → 剪映自动：
1. 匹配相关素材
2. 生成配音
3. 添加背景音乐
4. 输出完整视频
→ 适合快速生产资讯类/解说类视频
```

### 4.2 FFmpeg（自动化剪辑，推荐指数：⭐⭐⭐⭐）

**适用场景**：批量处理、标准化流程、CI/CD自动化

**常用命令示例**：

```bash
# 合并多个视频片段
ffmpeg -f concat -safe 0 -i filelist.txt -c copy output.mp4

# 添加音频轨道
ffmpeg -i video.mp4 -i audio.mp3 -c:v copy -c:a aac output.mp4

# 调整视频分辨率和码率（压缩）
ffmpeg -i input.mp4 -vf "scale=1920:1080" -b:v 5000k output.mp4

# 添加字幕
ffmpeg -i video.mp4 -vf subtitles=subtitle.srt output.mp4

# 截取片段
ffmpeg -i input.mp4 -ss 00:00:10 -to 00:00:30 -c copy clip.mp4
```

**进阶：Python+FFmpeg自动化脚本**
```python
import subprocess

def assemble_video(video_clips, audio_file, output):
    """批量合并视频+音频"""
    # 生成文件列表
    with open("filelist.txt", "w") as f:
        for clip in video_clips:
            f.write(f"file '{clip}'\n")
    
    # 合并视频
    subprocess.run([
        "ffmpeg", "-f", "concat", "-safe", "0",
        "-i", "filelist.txt", "-c", "copy", "video_only.mp4"
    ])
    
    # 合并音频
    subprocess.run([
        "ffmpeg", "-i", "video_only.mp4", "-i", audio_file,
        "-c:v", "copy", "-c:a", "aac", "-shortest", output
    ])
```

## 常见问题

**Q：免费额度够用吗？**
A：Hypereal AI的35积分可生成数千张图片+数十个视频+语音，足够个人创作者初期使用。智谱GLM-4-Flash（200万Tokens/天）可覆盖所有文案生成需求。

**Q：如何保证AI生成的视频内容一致性？**
A：使用风格参考图（Style Reference），在Hypereal AI等工具中传入参考图像，保持视觉风格统一；人物类内容建议使用同一个人物的多张图片做参考。

**Q：语音克隆需要多长时间？**
A：ElevenLabs约5-10分钟训练；Hypereal AI约1-3分钟；Fish Audio（开源）需要自己部署，时间视硬件而定。

**Q：哪些平台支持直接上传AI生成视频？**
A：抖音/快手/小红书/视频号/B站/YouTube均支持，建议输出为MP4格式（H.264编码）。

## 第一阶段：文案生成

### 工具配置

**首选：智谱GLM-4-Flash（永久免费）**
- 注册地址：https://open.bigmodel.cn/
- 模型：glm-4-flash
- 上下文：200K tokens
- 调用格式：OpenAI兼容

```python
import requests

url = "https://open.bigmodel.cn/api/paas/v4/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
data = {
    "model": "glm-4-flash",
    "messages": [
        {
            "role": "user",
            "content": """帮我写一份AI科普短视频脚本：
- 主题：AI在日常生活中的应用
- 时长：2分钟
- 风格：轻松易懂，适合大众
- 格式：时间码 | 画面描述 | 旁白文字
"""
        }
    ],
    "temperature": 0.7
}
response = requests.post(url, headers=headers, json=data)
print(response.json()["choices"][0]["message"]["content"])
```

**备选：硅基流动（12个模型免费）**
- 注册：https://account.siliconflow.cn/zh/login
- 模型：Qwen3.5-4B / DeepSeek-R7-Distill-Qwen-7B 等

## 第二阶段：视觉生成

### PPT/动画工具配置

#### Gamma
| 参数 | 推荐值 |
|------|--------|
| 幻灯片比例 | 16:9（横版）/ 9:16（竖版） |
| 风格 | Professional / Creative |
| 每页字数 | ≤50字 |
| 字体 | Google Sans / Satoshi |
| 导出格式 | PDF / PPTX |

**Gamma使用技巧：**
- 输入"/"唤起AI命令
- 用"生成"关键词让AI自动填充内容
- 右键批量调整布局
- 支持嵌入YouTube视频/网页

#### Motion Go
- 安装：Gamma插件市场搜索"Motion Go"
- 动画类型：进入动画 / 强调动画 / 退出动画
- 时长控制：0.25s / 0.5s / 1s
- 推荐预设：Fade In / Slide In / Scale Up

#### Beautiful.ai
- 特点：智能自动排版
- 适合：企业演示/商务汇报
- 缺点：自定义程度较低

#### AiPPT
- 特点：中文友好，本土化
- 支持：Word/PDF直接导入生成PPT

### 配图工具配置

#### Hypereal AI（免费首选）
| 参数 | 推荐值 |
|------|--------|
| 模型 | flux-2（最高质量）/ sd-xl（快速） |
| 分辨率 | 1024×1024 / 1920×1080 |
| 步数 | 30-50步 |
| 宽高比 | 16:9（视频）/ 1:1（社交）|

```bash
# 批量生成示例（bash脚本）
API_KEY="your_key"
for prompt in "AI robot assistant" "futuristic city" "tech workspace"; do
  curl -X POST https://api.hypereal.ai/v1/generate/image \
    -H "Authorization: Bearer $API_KEY" \
    -H "Content-Type: application/json" \
    -d "{\"model\":\"flux-2\",\"prompt\":\"$prompt\",\"width\":1920,\"height\":1080}" \
    -o "img_$prompt.png"
  sleep 2
done
```

## 第四阶段：视频合成

### 剪映专业版配置

| 参数 | 推荐值 |
|------|--------|
| 分辨率 | 1920×1080（1080P）/ 3840×2160（4K）|
| 帧率 | 30fps / 60fps |
| 码率 | 20-50 Mbps |
| 格式 | MP4（H.264/H.265）|
| 音频 | AAC 320kbps |

**自动字幕设置：**
- 识别语言：中文/英文
- 批量处理：最多50个文件
- 导出格式：SRT / TXT

### FFmpeg配置

```bash
# 基础合成
ffmpeg -i video.mp4 -i audio.mp3 -i subtitle.srt \
  -c:v libx264 -preset medium -crf 23 \
  -c:a aac -b:a 192k \
  -c:s mov_text \
  output.mp4

# 加速渲染（并行处理）
ffmpeg -i input.mp4 -vf "setpts=0.5*PTS" -af "atempo=2" output.mp4

# 添加水印
ffmpeg -i input.mp4 -i watermark.png \
  -filter_complex "overlay=W-w-10:10" \
  output.mp4

# 批量截取片段
ffmpeg -i source.mp4 -ss 00:00:10 -to 00:00:25 \
  -c copy segment1.mp4
```

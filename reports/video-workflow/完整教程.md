## ⑥ 音频合成

**工具**：FFmpeg（免费开源）/ 剪映专业版

**FFmpeg音画对齐命令**：
```bash
# 视频+配音混合
ffmpeg -i video.mp4 -i voiceover.wav -c:v copy -c:a aac -b:a 192k output.mp4

# 背景音乐降音量（混音）
ffmpeg -i video.mp4 -i voiceover.wav -i bgm.wav
  -filter_complex "[1:a]volume=0.8[vo];[2:a]volume=0.3[bg];[vo][bg]amix=inputs=2[aout]"
  -map 0:v -map "[aout]" -c:v copy output.mp4
```

## ③ 语音克隆（5分钟）

**首选**：Hypereal AI 语音克隆（35积分全含，10秒样本即可）

### Step 1：准备语音样本

录制一段30秒的自我介绍音频（清晰、无背景音乐、语气平稳），保存为 `voice_sample.wav`

### Step 2：克隆语音

```bash
# Hypereal AI 语音克隆 API
curl -X POST https://api.hypereal.ai/v1/clone/voice \
  -H "Authorization: Bearer YOUR_KEY" \
  -F "audio=@voice_sample.wav" \
  -F "name=AI_科普主播" \
  -F "language=zh"
```

### Step 3：TTS生成配音

```bash
# 使用克隆声音合成脚本

    "voice_id": "克隆后的voice_id",
    "text": "别划走！这周AI圈发生的事，可能会改变你明年的工作方式。",
    "output_file": "voice_01.wav"
```

## ⑥ 音频合成（10分钟）

**工具**：FFmpeg（免费开源，适合自动化）

### 基础命令

```bash
# ① 视频 + 配音 合成
ffmpeg -i video.mp4 -i voiceover.wav -c:v copy -c:a aac -b:a 192k output.mp4

# ② 视频 + 配音 + 背景音乐（混音）
ffmpeg -i video.mp4 -i voiceover.wav -i bgm.wav \
  -filter_complex "[1:a]volume=1.0[vo];[2:a]volume=0.25[bg];[vo][bg]amix=inputs=2:duration=first[aout]" \
  -map 0:v -map "[aout]" \
  -c:v copy output_with_music.mp4

# ③ 添加字幕（自动生成ASS格式）
ffmpeg -i output_with_music.mp4 -vf "subtitles=subtitle.srt" final_output.mp4
```

## 💡 效率提升技巧

### 1. 批量生成配图

```bash
# 使用Hypereal AI批量生成（bash循环）
for i in 1 2 3; do
  curl -X POST https://api.hypereal.ai/v1/generate/image \
    -H "Authorization: Bearer YOUR_KEY" \
    -d "{\"prompt\":\"your_prompt_$i\",\"output_file\":\"image_$i.png\"}"
done
```

### 2. FFmpeg批量混音

```bash
# 批量处理多个视频的音频合成
for f in *.mp4; do
  ffmpeg -i "$f" -i voice.wav -i bgm.wav \
    -filter_complex "[1:a]volume=1.0[vo];[2:a]volume=0.25[bg];[vo][bg]amix=inputs=2[aout]" \
    -map 0:v -map "[aout]" -c:v copy "processed_$f"
done
```

### 3. 剪映自动化

- 使用"图文成片"功能：粘贴文案 → 自动匹配配图 + AI配音（零基础）
- 使用"提词器"模式：对着提词器念稿，减少背稿压力

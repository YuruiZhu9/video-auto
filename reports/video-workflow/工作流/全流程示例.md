## 第三阶段：音频生成

### 3.1 语音克隆（ElevenLabs）

```python
# Step 1: 上传参考音频创建克隆
voice = elevenlabs.voice_clone(
    name="my-voice",
    files=["reference_audio.wav"]
)

# Step 2: 使用克隆声音生成配音
```

## 第四阶段：视频合成

### 4.1 方案A：剪映专业版（推荐新手）

**操作步骤**：
1. 新建项目，导入所有素材（视频片段/图片/音频）
2. 将图片拖入时间轴，设置每张图片展示时长（建议3-5秒）
3. 将语音文件拖入音轨
4. 点击**"自动字幕"**→ MAI-Transcribe-1 识别生成字幕
5. 选择**"朗读书面稿"**模式（避免口语病句）
6. 调整字幕样式（字体/颜色/位置）
7. 添加背景音乐（降低主音量至20%）
8. 导出：1080P，H.264，60fps

### 4.2 方案B：FFmpeg（自动化）

```bash
#!/bin/bash
# video_pipeline.sh - 全自动视频合成脚本

VIDEO_DIR="clips"
AUDIO_DIR="audio"
OUTPUT="final_output.mp4"

# Step 1: 合并图片+音频为视频片段
ffmpeg -loop 1 -i "clips/slide1.png" -i "audio/segment1.mp3" \
  -c:v libx264 -tune stillimage -pix_fmt yuv420p \
  -c:a aac -shortest clips/segment1.mp4

# Step 2: 合并所有片段
cat > filelist.txt
for f in clips/*.mp4; do echo "file '$f'" >> filelist.txt; done

ffmpeg -f concat -safe 0 -i filelist.txt -c copy temp_merge.mp4

# Step 3: 添加背景音乐
ffmpeg -i temp_merge.mp4 -i "audio/bgm.mp3" \
  -filter_complex "[1:a]volume=0.2[bgm];[0:a][bgm]amix=inputs=2:duration=first[aout]" \
  -map 0:v -map "[aout]" final_output.mp4

# Step 4: 添加字幕（ASS格式）
ffmpeg -i final_output.mp4 -vf ass="subtitles.ass" final_with_subs.mp4

rm temp_merge.mp4
echo "✅ 视频合成完成：final_with_subs.mp4"
```

#### Seedance 2.0 API（豆包，2026年最新）

```python
# 完整视频生成代码
import requests

SEEDANCE_API_KEY = "your_key_here"

def generate_video(prompt, duration=6, aspect="16:9"):
    response = requests.post(
        "https://api.seedance.com/v2/generate/video",
        headers={
            "Authorization": f"Bearer {SEEDANCE_API_KEY}",
            "Content-Type": "application/json"
        },
        json={
            "model": "seedance-2.0",
            "prompt": prompt,
            "duration": duration,
            "resolution": "1080P" if duration <= 6 else "720P",
            "aspect_ratio": aspect,
            "seed": -1  # 随机种子，固定则复现
        },
        timeout=120
    )
    result = response.json()
    return result["data"]["video_url"]

# 示例调用
url = generate_video(
    prompt="Cinematic shot of a robot helping a human at a desk, 
            warm office lighting, 4K quality",
    duration=6,
    aspect="16:9"
)
print(f"Generated: {url}")
```

## 🎬 第四阶段：视频合成配置

### 4A. 剪映专业版配置

| 设置项 | 推荐值 |
|--------|--------|
| 分辨率 | 1920×1080（1080P）|
| 帧率 | 60fps |
| 码率 | 15-20 Mbps |
| 编码 | H.264 |
| 音频 | AAC 320kbps |
| 字幕 | SRT导入 或 自动识别 |

**剪映自动化工作流**：
1. 项目设置 → 开启"自动保存"
2. 素材库 → 按标签分类（视频/图片/音频）
3. 时间轴 → 吸附开启（精准对齐）
4. 音频混合 → 背景音乐音量20-30%
5. 导出设置 → 开启"硬件加速"（速度快3倍）

### 4B. FFmpeg 高质量配置

```bash
# 最高质量输出（H.265，HEVC）
ffmpeg -i input.mp4 \
  -c:v libx265 -crf 18 -preset slow \
  -c:a aac -b:a 192k \
  -movflags +faststart \
  output_high_quality.mp4

# 快速压缩（适合短视频平台）
ffmpeg -i input.mp4 \
  -c:v libx264 -crf 23 -preset fast \
  -vf "scale=1920:-2" \
  -c:a aac -b:a 128k \
  output_compressed.mp4

# 添加字幕（SRT）
ffmpeg -i input.mp4 -vf subtitles=subs.srt \
  -c:a copy output_with_subs.mp4

# 截取片段
ffmpeg -i input.mp4 -ss 00:00:10 -t 00:00:30 \
  -c copy clip_output.mp4
```

## ⚙️ 端到端自动化配置（API流水线）

```python
# video_pipeline.py - 全流程自动化脚本

import requests
import time

class VideoPipeline:
    def __init__(self, config):
        self.config = config
        self.steps = []
    
    def add_step(self, name, func):
        self.steps.append({"name": name, "func": func})
    
    def run(self, script):
        results = {}
        for step in self.steps:
            print(f"🔄 执行: {step['name']}")
            try:
                results[step["name"]] = step["func"](script, results)
            except Exception as e:
                print(f"❌ 失败: {step['name']} - {e}")
                raise
        return results

# 使用示例
pipeline = VideoPipeline(config)

pipeline.add_step("生成配图", generate_images)
pipeline.add_step("生成AI视频", generate_video_clip)
pipeline.add_step("语音合成", synthesize_speech)
pipeline.add_step("生成BGM", generate_background_music)
pipeline.add_step("音画同步", sync_audio_video)
pipeline.add_step("合成最终视频", merge_final)

final_video = pipeline.run(script_text)
print(f"✅ 完成: {final_video['url']}")
```

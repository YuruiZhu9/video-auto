# Gamma — AI驱动PPT生成详细教程

> 更新日期：2026-04-04

## 核心能力

Gamma 是当前最强的AI驱动PPT生成工具，输入文案即可自动生成专业演示文稿，支持嵌入视频、图表、GIF，适合作为AI视频制作的视觉素材来源。

**官网：** `gamma.app`

2. 使用 Google 账号 或 邮箱注册

## 核心使用流程

### 方法一：AI生成模式（推荐）

```
1. 点击 "Create with AI" 或 "New gamma"
2. 选择 "Presentation"
3. 输入视频主题/脚本内容（建议200-500字）
4. 选择模板：
   - "Blank"（空白，自由度高）
   - "Guided"（AI引导，每步确认）
5. 点击 "Generate" 等待AI生成（约30秒）
6. 编辑后点击 "Share" → "Export"
```

### 方法二：粘贴文本模式

```
1. 点击 "Import" → "Paste text"
2. 粘贴完整脚本（Gamma会自动分页）
3. 选择配色方案（推荐：Auto-matched to content）
4. 一键生成PPT
```

## 参数设置推荐

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 每页内容 | ≤3个要点 | 保持简洁，符合"演讲者思维" |
| 总页数 | 8-20页 | 按视频时长调整（1分钟≈5页）|
| 风格 | Minimal / Corporate | 干净专业，适合知识类视频 |
| 配色 | 自动或深蓝/科技风 | 与AI主题契合 |
| 字体 | Inter / Poppins | 现代感强 |

## 导出设置

| 格式 | 适用场景 |
|------|----------|
| **PDF** | 存档、打印 |
| **PPTX** | 导入剪映/Keynote进一步编辑 |
| **PNG/JPG（逐页）** | 作为分镜图片导入FFmpeg |
| **分享链接** | 嵌入网站/视频描述栏 |

**导出为图片（推荐用于视频制作）：**
1. 在Gamma中打开PPT
2. 右键页面 → "Copy slide as image"
3. 或使用浏览器开发者工具（F12）截图

## 高级技巧

### 1. 嵌入视频/网页
- 在PPT页面中点击 "Insert" → "Video embed"
- 支持 YouTube / Vimeo / 本地视频
- 视频会直接播放，适合展示demo

### 2. 生成图表
- 点击 "Insert" → "Chart"
- 支持 Excel数据粘贴自动生成图表
- 支持折线图、柱状图、饼图等

### 3. AI内容优化
- 选中文字 → "Rewrite with AI"
- 支持改写、缩短、加长、改变语气

### 4. 多语言支持
- 界面支持中文输入
- 可生成英文PPT（导出时设置语言）

## 与视频制作管线的衔接

```
Gamma 生成PPT（导出为PNG/JPG序列）
    ↓
每页作为分镜图片导入剪映
    ↓
或 FFmpeg 将图片序列转为视频：
ffmpeg -y -framerate 1 -pattern_type glob -i 'gamma_slides/*.png' \
  -i voiceover.wav -c:v libx264 -pix_fmt yuv420p -shortest output.mp4
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 生成内容太泛 | 在输入框中提供更具体的脚本/大纲 |
| 页数过多 | 分段输入，每次生成5-10页 |
| 图片模糊 | 导出时选择最高分辨率（需要Pro）|
| 版权问题 | Gamma生成的PPT可商用，无需担心 |
| 免费额度用完 | 使用通义万相/Canva作为替代方案 |

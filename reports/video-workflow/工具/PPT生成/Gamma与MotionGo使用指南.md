## Gamma：AI智能PPT

### 产品简介

Gamma（gamma.app）是AI驱动的新一代演示文稿工具，支持网页模式和演示模式，自动排版、智能配色、一键生成。

### 快速开始

**注册登录**
1. 访问 gamma.app
2. 使用 Google / 邮箱账号注册
3. 免费版：400 Credits（可生成约20张PPT）

**核心使用流程**

```
Step 1: 选择创建方式
  ├─ "Generate" → AI自动生成（输入主题即可）
  └─ "Create from scratch" → 手动编辑

Step 2: 输入主题描述
  示例："AI在职场中的应用：效率提升指南，面向25-35岁职场人群"

Step 3: 选择风格模板
  - Starlight（科技感）
  - Editorial（杂志风）
  - Obsidian（暗黑专业）
  - Custom（自定义）

Step 4: 编辑与导出
  - 在线协作编辑
  - 导出：PDF / PPTX
  - 或直接发布为网页（无需下载）
```

### AI生成参数

```markdown
| 参数 | 说明 | 推荐值 |
|------|------|--------|
| 幻灯片数量 | 自动生成张数 | 8-15张 |
| 详细程度 | AI内容深度 | Medium |
| 品牌色 | 可自定义 | 企业VI优先 |
| 动画 | 全局过渡动画 | Subtle |
| 图片 | AI配图开关 | ON（自动匹配）|
```

### 技巧与快捷操作

- **批量修改样式**：选中多张幻灯片 → 右键"Apply Theme"
- **AI Reflow**：选中文字 → Cmd/Ctrl+Shift+R → AI重新排版
- **嵌入互动元素**：支持嵌入 YouTube / Code Block / Chart
- **快速克隆**：复制现有PPT URL → 粘贴 → AI学习风格生成新版

### 常见问题

| 问题 | 解决方案 |
|------|----------|
| 中文乱码 | 选择"中文"语言设置，或导出前检查字体 |
| 生成内容不准确 | 点击幻灯片 → Edit → 手动调整AI内容 |
| 额度不足 | 等次月重置（免费400/月），或升级Pro |

## Motion Go：PPT动画插件

### 产品简介

Motion Go 是 PPT 动画插件（pipiupins.com），安装后内置150+预设动画，一键套用，告别动画小白。

### 安装

```bash
# Windows: 下载安装包 → 双击运行 → 自动识别WPS/Office
# Mac: 需WPS（Office暂不支持）

下载地址: https://pipiupins.com/motion-go
```

### 核心功能

**1. Motion 动画库**
- 预设动画：入场动画（60+）/ 强调动画（40+）/ 退出动画（30+）/ 路径动画（20+）
- 分类浏览：基础 / 商务 / 科技 / 创意

**2. AI Motion（AI自动编排）**
- 输入文案 → AI自动匹配动画
- 适用：时间轴、数据对比、流程展示

**3. Preset 预设**
- 整页动画预设：一键应用整套动画（封面→内容→结尾）
- 推荐预设组合：
  ```
  封面: Zoom In + Fade
  内容: Slide In Left + Bounce
  图表: Draw In + Scale
  结尾: Fade Out + Zoom Out
  ```

### 使用技巧

```markdown
# 快速动画（推荐组合）
1. 选中文本框 → Motion GO → "Animate In" → "Fade In"
2. 按住 Ctrl → 选中多个元素 → 右键 "Format" → "Animation Painter"（复制动画）

# AI自动编排
1. 点击 "AI Motion" 标签
2. 输入："这段文案需要在5秒内展示，包含开场和数据图表"
3. AI自动分配入场顺序和动画类型

# 导出视频
1. File → Export → MP4
2. 设置：1080P，60fps
3. 勾选 "Record Timings"（保留动画时间轴）
```

AiPPT（aippt.cn）是国产AI PPT工具，中文理解好，支持本地文档导入（Word/PDF转PPT）。

### 快速开始

```markdown

  - 网址: https://aippt.cn
  - 支持: 微信扫码 / 手机号 / 邮箱

Step 2: 选择创建方式
  - AI智能生成（输入主题）
  - 文档转换（Word/PDF → PPT）
  - 导入Markdown（技术文档直接转PPT）

Step 3: 模板选择
  - 商务蓝 / 简约白 / 科技深色 / 活泼橙
  - 可上传品牌Logo

Step 4: 导出
  - PPTX（可二次编辑）
  - PDF（演示用）
```

# Motion Go — PPT动画增强插件

> 更新日期：2026-03-29

## 核心能力

Motion Go是Gamma/Canva等平台的动画增强插件，可为静态PPT添加电影级预设动画，大幅提升视觉冲击力。

## 安装

1. 访问 gamma.app/plugins 或 canva.com/apps
2. 搜索「Motion Go」
3. 点击「安装」
4. 授权后即可使用

## 动画类型

| 类型 | 效果 | 适用场景 |
|------|------|---------|
| 进入动画 | Fade In / Slide / Scale / Bounce | 元素出现 |
| 强调动画 | Pulse / Shake / Glow | 重点内容 |
| 退出动画 | Fade Out / Slide Out / Scale Down | 元素消失 |
| 转场动画 | Crossfade / Wipe / Zoom | 页面切换 |
| 3D动画 | 3D Rotate / 3D Flip | 高级视觉效果 |

## 推荐预设组合

### 科技风演示
```
第1页入场：Stagger Slide In（从左到右依次出现）
重点数据：Counter（数字滚动动画）
页面转场：Smooth Zoom
```

### 故事叙述型
```
文字：Typewriter（打字机效果）
图片：Parallax（视差滚动）
背景：Floating（悬浮效果）
```

### 商务汇报型
```
图表：Draw In（描线动画）
数据：Counter Up（数字递增）
要点：Stagger Fade In（依次淡入）
```

## 使用技巧

1. **批量添加动画**：选中多个元素 → 应用同一动画
2. **调整时序**：拖动时间轴上的标记调整先后顺序
3. **动画时长**：默认0.5s，快速感用0.25s，优雅感用1s
4. **缓动函数**：`ease-out`适合进入，`ease-in-out`适合强调

## 导出

- 导出为MP4：保留完整动画效果
- 导出为GIF：适合嵌入网页/PPT
- 导出为PPTX：动画可能丢失，建议用前者

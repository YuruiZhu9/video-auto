## 一、剪映专业版（手动精剪）

### 1.1 快速工作流

```
① 新建项目 → 导入素材（图片/视频/音频）
② 音频轨：拖入配音 + 背景音乐
③ 视频轨：拖入图片或视频片段
④ AI功能：自动字幕 / AI成片 / 智能竹节
⑤ 字幕：对齐配音文字
⑥ 转场：相邻片段间添加转场效果
⑦ 调色：套用滤镜
⑧ 预览 → 导出（1080P/4K）
```

### 1.2 核心AI功能

| 功能 | 入口 | 说明 |
|------|------|------|
| **AI成片** | 首页 → AI成片 | 输入文案，自动匹配素材生成视频 |
| **AI翻译** | 剪辑 → AI工具 → AI翻译 | 自动翻译字幕（多语言）|
| **智能竹节** | 首页 → 智能竹节 | 上传素材，AI自动剪辑 |
| **AI克隆音色** | 音频 → AI克隆 | 上传人声，克隆专属音色 |
| **自动字幕** | 文本 → 自动字幕 | 识别配音，自动生成字幕 |

### 1.3 快捷操作

| 操作 | 快捷键 |
|------|--------|
| 分割片段 | `S` |
| 删除片段 | `Delete` |
| 撤销 | `Ctrl+Z` |
| 放大时间轴 | `Ctrl+鼠标滚轮` |
| 静音 | `M` |
| 导出一键 | `Ctrl+E` |

## 二、FFmpeg 自动化脚本

### 2.1 完整自动化脚本

```bash
#!/bin/bash
# ai-video-pipeline.sh
# AI视频全流程自动化脚本

set -e

# ============ 配置区 ============
INPUT_DIR="./input"
OUTPUT_DIR="./output"
mkdir -p "$OUTPUT_DIR"

AUDIO_FILE="$INPUT_DIR/voiceover.mp3"
MUSIC_FILE="$INPUT_DIR/bgm.mp3"
IMAGE_DIR="$INPUT_DIR/images"
SUBTITLE_FILE="$INPUT_DIR/subtitle.srt"
FRAMERATE=1  # 每张图片持续秒数

# ============ Step 1: 合成音频 ============
echo "[1/5] 合成配音+背景音乐..."
ffmpeg -y -i "$AUDIO_FILE" -i "$MUSIC_FILE" \
  -filter_complex "[0:a]volume=1.0,aformat=sample_fmts=fltp:sample_rates=44100:channel_layouts=stereo[vo];[1:a]volume=0.3,aformat=sample_fmts=fltp:sample_rates=44100:channel_layouts=stereo[bg];[vo][bg]amix=inputs=2:duration=first[out]" \
  -map "[out]" "$OUTPUT_DIR/final_audio.mp3"

# ============ Step 2: 获取音频时长 ============
echo "[2/5] 计算视频总时长..."
AUDIO_DURATION=$(ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 "$OUTPUT_DIR/final_audio.mp3")
echo "音频时长：${AUDIO_DURATION}s"

# ============ Step 3: 图片生成视频片段 ============
echo "[3/5] 图片生成视频片段..."
cd "$IMAGE_DIR"
IMAGE_FILES=(*.png *.jpg *.jpeg)
NUM_IMAGES=${#IMAGE_FILES[@]}
DURATION_PER_IMAGE=$(echo "scale=2; $AUDIO_DURATION / $NUM_IMAGES" | bc)

echo "共${NUM_IMAGES}张图，每张持续${DURATION_PER_IMAGE}s"

for i in "${!IMAGE_FILES[@]}"; do
  IMG="${IMAGE_FILES[$i]}"
  OUTPUT="${OUTPUT_DIR}/clip_$(printf '%03d' $i).mp4"
  ffmpeg -y -loop 1 -i "$IMG" -t "$DURATION_PER_IMAGE" \
    -vf "scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080,fps=30" \
    -c:v libx264 -preset fast -pix_fmt yuv420p \
    -an "$OUTPUT"
  echo "  生成: clip_$(printf '%03d' $i).mp4"
done

# ============ Step 4: 合并所有视频片段 ============
echo "[4/5] 合并视频片段..."
cat > "$OUTPUT_DIR/filelist.txt"
for f in $(ls "$OUTPUT_DIR"/clip_*.mp4 | sort); do
  echo "file '$f'" >> "$OUTPUT_DIR/filelist.txt"
done

ffmpeg -y -f concat -safe 0 -i "$OUTPUT_DIR/filelist.txt" \
  -c:v libvpx-vp9 -b:v 0 -crf 30 -pix_fmt yuv420p \
  "$OUTPUT_DIR/video_only.mp4"

# ============ Step 5: 合并音视频 ============
echo "[5/5] 合并音视频..."
if [ -f "$SUBTITLE_FILE" ]; then
  ffmpeg -y -i "$OUTPUT_DIR/video_only.mp4" -i "$OUTPUT_DIR/final_audio.mp3" \
    -vf "subtitles=$SUBTITLE_FILE:force_style='FontSize=24,PrimaryColour=&HFFFFFF&,Outline=1'" \
    -c:v libx264 -preset medium -crf 23 -c:a aac -b:a 192k \
    -shortest "$OUTPUT_DIR/final_with_subs.mp4"
  echo "✅ 完成（含字幕）：$OUTPUT_DIR/final_with_subs.mp4"
else
  ffmpeg -y -i "$OUTPUT_DIR/video_only.mp4" -i "$OUTPUT_DIR/final_audio.mp3" \
    -c:v libx264 -preset medium -crf 23 -c:a aac -b:a 192k \
    -shortest "$OUTPUT_DIR/final.mp4"
  echo "✅ 完成：$OUTPUT_DIR/final.mp4"
fi

# 清理临时文件
rm -f "$OUTPUT_DIR"/clip_*.mp4 "$OUTPUT_DIR"/filelist.txt "$OUTPUT_DIR/video_only.mp4"

echo ""
echo "🎉 全部完成！输出文件：$OUTPUT_DIR"
```

### 2.2 常用FFmpeg命令速查

**基础操作**
```bash
# 视频信息查看
ffprobe -v error -show_format -show_streams input.mp4

# 视频转码
ffmpeg -i input.mp4 -c:v libx264 -crf 23 output.mp4

# 音频提取
ffmpeg -i video.mp4 -vn -acodec copy audio.aac

# 视频截图（每10秒一张）
ffmpeg -i video.mp4 -vf "fps=0.1" thumb%03d.png
```

**格式转换**
```bash
# 图片序列合成视频
ffmpeg -framerate 30 -pattern_type glob -i '*.png' \
  -c:v libx264 -pix_fmt yuv420p slideshow.mp4

# 视频转GIF
ffmpeg -i video.mp4 -vf "fps=10,scale=480:-1" output.gif

# 竖屏转横屏（加黑边）
ffmpeg -i vertical.mp4 -vf "pad=1920:1080:(ow-iw)/2:(oh-ih)/2" output.mp4
```

**字幕处理**
```bash
# 添加字幕（SRT格式）
ffmpeg -i video.mp4 -vf "subtitles=subtitle.srt" output.mp4

# 字幕样式自定义
ffmpeg -i video.mp4 \
  -vf "subtitles=subtitle.srt:force_style='FontSize=24,PrimaryColour=&HFFFFFF&,Bold=1,Outline=1,OutlineColour=&H000000&'" \
  output.mp4

# 烧录ASS字幕
ffmpeg -i video.mp4 -vf "ass=subtitle.ass" output.mp4
```

**音频处理**
```bash
# 音频淡入淡出（开头1秒淡入，结尾2秒淡出）
ffmpeg -i audio.mp3 -af "afade=t=in:st=0:d=1,afade=t=out:st=58:d=2" output.mp3

# 降噪
ffmpeg -i noisy.mp3 -af "hcadess=1" clean.mp3

# 混音（配音1.0 + BGM 0.3）
ffmpeg -i voice.mp3 -i bgm.mp3 \
  -filter_complex "[0:a][1:a]amix=inputs=2:duration=first:weights=1.0 0.3" \
  mixed.mp3

# 音频加速（1.5倍速）
ffmpeg -i audio.mp3 -filter:a "atempo=1.5" fast.mp3
```

**高级处理**
```bash
# 视频加速（2倍速）
ffmpeg -i input.mp4 -filter:v "setpts=0.5*PTS" -c:a copy output.mp4

# 画面裁剪
ffmpeg -i input.mp4 -vf "crop=1920:800:0:140" output.mp4

# 添加水印
ffmpeg -i input.mp4 -i watermark.png \
  -filter_complex "overlay=W-w-10:H-h-10" \
  output.mp4

# 视频稳定
ffmpeg -i shaky.mp4 -vf "deshake" stable.mp4
```

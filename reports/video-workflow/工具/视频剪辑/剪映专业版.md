# 剪映专业版使用指南

> 更新时间：2026-03-08

## 工具概述

**剪映** 是字节跳动旗下的免费视频编辑工具，AI功能强大，适合短视频创作。

- **下载**：https://www.capcut.cn（专业版）
- **平台**：Windows / Mac / iOS / Android
- **费用**：免费（部分功能付费）

## 基础工作流

### 1. 新建项目

1. 打开剪映专业版
2. 点击 "新建项目"
3. 设置比例：
   - 16:9（横版视频）
   - 9:16（竖版抖音/快手）
   - 1:1（方形）
4. 设置分辨率：1080P / 4K

### 2. 导入素材

**方式**：
- 拖拽文件到素材区
- 点击 "导入" 按钮
- 快捷键 `Ctrl+I`

**支持格式**：
- 视频：mp4, mov, avi, mkv
- 音频：mp3, wav, aac
- 图片：jpg, png, gif

### 3. 剪辑操作

**基础快捷键**：
| 功能 | 快捷键 |
|------|--------|
| 分割 | `Ctrl+B` |
| 删除 | `Delete` |
| 复制 | `Ctrl+C` |
| 粘贴 | `Ctrl+V` |
| 撤销 | `Ctrl+Z` |
| 导出 | `Ctrl+E` |

**操作技巧**：
- 播放头定位 + 分割 = 精准裁剪
- 鼠标悬停轨道边缘可拖拽调整时长
- 多轨道可分别调整顺序

### 4. 添加转场

1. 点击 "转场" 标签
2. 选择转场效果（基础/高级/特效）
3. 拖拽到两个片段之间
4. 调整时长

**推荐转场**：
- 溶解（淡入淡出）
- 推拉（电影感）
- 模糊（平滑过渡）

### 5. 添加字幕

**自动字幕**：
1. 点击 "文本" → "智能字幕"
2. 选择 "同时清空已有字幕"（可选）
3. 点击 "开始识别"
4. 识别完成后可编辑

**手动字幕**：
1. 点击 "文本" → "添加文本"
2. 输入文字内容
3. 在预览窗口拖拽调整位置
4. 在轨道上调整时长

### 6. 添加音频/音乐

**添加背景音乐**：
1. 点击 "音频" 标签
2. 选择 "音乐" 或 "音效"
3. 搜索或浏览
4. 添加到音频轨道

**声音调节**：
- 选中音频片段
- 在右侧面板调节：
  - 音量
  - 淡入/淡出
  - 变声（可选）

### 7. 导出

1. 点击 "导出" 按钮 或 `Ctrl+E`
2. 设置导出参数：
   - 格式：MP4（推荐）
   - 分辨率：1080P / 4K
   - 帧率：30fps / 60fps
   - 码率：推荐"高"
3. 选择保存路径
4. 点击 "导出"

## AI 功能

### 智能抠像

1. 选中视频片段
2. 点击 "抠像" → "智能抠像"
3. 自动去除背景
4. 可调整边缘

### 智能追踪

1. 选择要追踪的元素
2. 点击 "智能追踪"
3. 自动生成跟随效果

### 运镜卡点

1. 导入素材
2. 点击 "一键成片" 或 "AI运镜"
3. 选择模板
4. 自动生成效果

### 文案匹配

- 输入文案
- 自动匹配相关素材
- 适合快速出片

## 进阶技巧

### 调色

1. 选中片段
2. 点击 "调节" 面板
3. 调整：
   - 亮度/对比度
   - 饱和度
   - 色温
   - 色调

### 关键帧动画

1. 选中片段/元素
2. 在时间轴上定位
3. 点击 "添加关键帧"
4. 移动时间轴到另一位置
5. 修改属性（位置/缩放/旋转）
6. 自动生成动画

### 蒙版

1. 选中片段
2. 点击 "蒙版"
3. 选择形状（矩形/椭圆/自定义）
4. 调整位置和羽化

## 常见问题

**Q：导出失败？**
A：检查磁盘空间，更换保存路径，重启软件

**Q：卡顿怎么办？**
A：降低预览分辨率，减少轨道数量，清理缓存

**Q：如何去除水印？**
A：付费版可去除，或使用其他工具

**Q：支持多轨吗？**
A：支持，适合复杂项目

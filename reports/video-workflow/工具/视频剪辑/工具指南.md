官网：https://www.capcut.cn

### 核心功能

#### 1. AI 功能

| 功能 | 说明 |
|------|------|
| AI配音 | 多种音色，支持克隆 |

#### 2. 基本操作流程

**步骤1：导入素材**
- 拖拽文件到素材区
- 支持格式：MP4, MOV, AVI, MKV

**步骤2：剪辑**
- 分割：Ctrl+B
- 删除：Delete
- 变速：右键 → 变速

**步骤3：添加音频**
- 音乐库搜索
- 配音录制
- 音效添加

**步骤4：字幕**
- 自动生成：点击 "文本" → "智能字幕"
- 手动添加：点击 "文本" → "添加字幕"

**步骤5：导出**
- 格式：MP4
- 分辨率：1080P/4K
- 帧率：30fps/60fps


## 🔧 FFmpeg 详解

### 安装

**Windows**：
```bash
# 使用 Chocolatey
choco install ffmpeg

# 或下载预编译版本
# https://www.gyan.dev/ffmpeg/builds/
```

**Mac**：
```bash
brew install ffmpeg
```

**Linux**：
```bash
sudo apt install ffmpeg
```

### 常用命令

#### 1. 视频合并

```bash
# 合并多个视频
ffmpeg -f concat -safe 0 -i filelist.txt -c copy output.mp4

# filelist.txt 内容示例：
# file 'video1.mp4'
# file 'video2.mp4'
# file 'video3.mp4'
```

#### 2. 添加音频

```bash
# 替换音频
ffmpeg -i video.mp4 -i audio.mp3 -c:v copy -c:a aac -map 0:v:0 -map 1:a:0 output.mp4

# 混合背景音乐
ffmpeg -i video.mp4 -i music.mp3 -filter_complex "[0:a][1:a]amix=inputs=2:duration=first[a]" -map 0:v -map "[a]" output.mp4
```

#### 3. 视频压缩

```bash
# 压缩视频（CRF方式）
ffmpeg -i input.mp4 -vcodec libx264 -crf 23 -preset fast output.mp4

# 参数说明：
# -crf 23: 质量参数，18-28之间，越小越好
# -preset: 编码速度 ultrafast->veryslow
```

#### 4. 视频裁剪

```bash
# 裁剪片段
ffmpeg -i input.mp4 -ss 00:00:10 -to 00:00:30 -c copy output.mp4

# 从第10秒开始，截取20秒
```

#### 5. 视频缩放

```bash
# 缩放到1080P
ffmpeg -i input.mp4 -vf "scale=1920:1080" output.mp4

# 保持纵横比
ffmpeg -i input.mp4 -vf "scale=-2:1080" output.mp4
```

#### 6. 调整帧率

```bash
# 转换为30fps
ffmpeg -i input.mp4 -r 30 output.mp4
```

#### 7. 添加字幕

```bash
# 添加SRT字幕
ffmpeg -i input.mp4 -vf "subtitles=subtitle.srt" output.mp4
```

### 批量处理脚本

```bash
#!/bin/bash
# batch_process.sh

# 批量压缩
for file in *.mp4; do
    ffmpeg -i "$file" -vcodec libx264 -crf 23 -preset fast "compressed_$file"
done
```

```powershell
# batch_process.ps1 (Windows)

Get-ChildItem -Filter *.mp4 | ForEach-Object {
    ffmpeg -i $_.FullName -vcodec libx264 -crf 23 -preset fast "compressed_$($_.Name)"
}
```

### Python 集成

```python
import subprocess
import os

def compress_video(input_path, output_path, crf=23):
    """压缩视频"""
    cmd = [
        "ffmpeg", "-i", input_path,
        "-vcodec", "libx264",
        "-crf", str(crf),
        "-preset", "fast",
        "-acodec", "aac",
        output_path
    ]
    subprocess.run(cmd)

def merge_videos(video_list, output_path):
    """合并视频"""
    # 创建临时文件列表
    with open("filelist.txt", "w") as f:
        for video in video_list:
            f.write(f"file '{video}'\n")
    
    cmd = [
        "ffmpeg", "-f", "concat", "-safe", "0",
        "-i", "filelist.txt", "-c", "copy", output_path
    ]
    subprocess.run(cmd)
    os.remove("filelist.txt")

# 使用示例
compress_video("input.mp4", "output.mp4", crf=23)
merge_videos(["video1.mp4", "video2.mp4", "video3.mp4"], "merged.mp4")
```

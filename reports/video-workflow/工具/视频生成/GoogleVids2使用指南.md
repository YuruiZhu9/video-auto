# Google Vids 2.0 使用指南

> 更新时间：2026-04-10
> 工具类型：企业视频生成（Workspace 内置）
> 适用场景：企业培训、营销视频、新手入门

---

## 📌 工具概述

Google Vids 2.0 于 **2026-04-09** 在 Product Hunt 斩获 **405票**，现已深度集成至 Google Workspace（Drive/Gmail/Slides），无需切换工具，直接在 Google 环境内完成视频制作。

| 维度 | 详情 |
|------|------|
| **入口** | Google Drive → 新建 → Google Vids / app.vids.google.com |
| **定价** | Google Workspace 订阅用户免费（无额外费用）|
| **语言** | 中文界面，英文配音为主 |
| **视频时长** |最长 60 秒（免费版）/ 5分钟（Workspace Plus）|
| **输出分辨率** | 1080p |
| **核心优势** | 与 Google Slides/Drive 原生集成，企业用户零学习成本 |

## 🔥 核心功能亮点

### 1. AI 一键生成视频（Storyboard 模式）

```
入口：Google Vids → "Help me create"（帮我创作）

Step 1：输入视频主题或粘贴文案
  示例："介绍我们公司新产品AI助手的功能与优势"

Step 2：选择视频风格
  ├── 宣传片（Promotional）
  ├── 培训教学（Training）
  ├── 故事叙述（Storytelling）
  └── 信息汇报（Report）

Step 3：选择配音语言
  └── 支持 12 种语言（含中文），但中文 AI 配音目前为测试版

Step 4：选择背景音乐
  └── Google 版权音乐库（商用安全），可直接替换

Step 5：点击"生成" → AI 自动生成完整视频
  └── 自动包含：分镜、配图、文字动画、字幕、配音、BGM
```

**生成时间：** 通常 2-5 分钟（取决于视频长度）

### 2. 手动制作（从头开始）

```
入口：Google Vids → "Create" → "Start from scratch"

工具面板：
┌──────────────────────────────────────────────────┐
│  📝 文案层    │  🖼️ 图片/视频库  │  🎵 音乐库    │
│  📐 画布      │  🎬 场景切换    │  🎙️ 配音录制  │
│  ⏱️ 时间轴    │  📊 图表嵌入    │  🤖 AI 生成   │
└──────────────────────────────────────────────────┘
```

### 3. Google Slides 导入（⭐企业最强功能）

```
操作路径：
  Google Slides → 文件 → 制作视频 → 选择"在 Vids 中打开"
  ↓
自动将每一页幻灯片转为视频的一个场景（Scene）
  ↓
手动调整每页时长、转场效果
  ↓
添加配音、BGM、动画
  ↓
导出 MP4

优势：✅ 零迁移成本  ✅ 企业培训材料直接转视频  ✅ 无水印
```

## 🛠️ 详细使用步骤

### 方法一：AI 生成模式（适合快速出片）

**Step 1：进入 Google Vids**

```
方式 A：app.vids.google.com（推荐，无需翻墙）
方式 B：Google Drive → 新建 → 更多 → Google Vids
方式 C：Google Workspace 侧边栏
```

**Step 2：选择"Help me create"**

```
点击紫色"Help me create"按钮
↓ 输入视频主题
↓ 选择视频类型（见上方）
↓ 设置时长（15s / 30s / 60s）
```

**Step 3：等待 AI 生成（约 2-5 分钟）**

```
AI 自动完成：
  ✅ 分镜脚本撰写
  ✅ 从 Google 图库选取配图/视频片段
  ✅ 自动添加字幕和文字动画
  ✅ 生成配音（可选择不同音色）
  ✅ 匹配版权背景音乐
```

**Step 4：编辑与调整**

```
▸ 替换图片/视频：点击场景 → 搜索替换
▸ 修改文案：点击文字层 → 直接编辑
▸ 调整配音：点击配音轨道 → 重新生成或录制
▸ 调整时长：拖动场景边缘 → 增减时长
▸ 添加转场：点击两场景之间 → 选择转场效果
```

**Step 5：导出**

```
导出格式：MP4（1080p）
导出位置：Google Drive（自动保存）
分享方式：
  ├── Google Drive 分享链接
  ├── 直接嵌入 Google Sites
  ├── 下载到本地
  └── 一键分享至 Meet/YouTube
```

---

### 方法二：Slides 转视频（适合企业培训）

```
适用场景：已有培训 PPT，想快速转为视频

Step 1：打开现有 Google Slides
  └── 示例：公司产品介绍培训.pptx

Step 2：文件 → 制作视频 → 在 Google Vids 中打开
  ↓
  每一页自动变为 Vids 中的一个场景
  ↓
  每页默认时长：5 秒（可调整）

Step 3：在 Vids 中优化
  ├── 添加 BGM（右侧工具栏 → 音乐）
  ├── 添加配音（录制旁白）
  ├── 调整动画（点击场景 → 动画效果）
  └── 添加转场（场景间过渡效果）

Step 4：导出
```

---

### 方法三：手动制作完整视频

```
适合：高度定制化需求

Step 1：新建空白项目 → 设置视频比例（16:9 / 9:16 / 1:1）
Step 2：添加素材
  ├── 本地上传图片/视频 → Google Drive
  ├── Google 图库（版权免费图片）
  └── 搜索网络图片（需确认版权）
Step 3：添加到时间轴
  ├── 拖拽素材到时间轴
  ├── 调整每段素材的入点/出点
  └── 添加文字标题
Step 4：添加配音
  ├── AI 配音：输入文字 → 选择音色 → 生成
  └── 人工配音：点击"录制旁白" → 实时录制
Step 5：添加背景音乐
  └── Google 版权音乐库（商用安全）
Step 6：导出
```

## 🎨 推荐配置参数

### 企业培训视频（最优设置）

```
时长：60 秒（1分钟版本）
风格：Training
比例：16:9（电脑端） / 9:16（手机端）
配音：中文女声（温暖型）
BGM：Corporate Light（Google 版权库）
动画：Fade + Slide（简洁专业）
字体：Roboto（默认）+ 深色背景
```

### 产品宣传视频（最优设置）

```
时长：30 秒
风格：Promotional
比例：16:9（主）+ 9:16（手机版）
配音：中文男声（权威型）
BGM：Upbeat Corporate
动画：Dynamic（强调动感）
字幕：底部字幕条（白色背景）
CTA：最后 3 秒叠加联系信息
```

## ⚠️ 已知限制与避坑

| 问题 | 解决方案 |
|------|---------|
| 中文 AI 配音质量一般 | 建议先用英文配音 + 字幕，中文配音用 MAI-Voice-1 替代 |
| 视频最长 60 秒（免费版）| 企业版（Workspace Plus）可至 5 分钟 |
| 部分特效仅付费版可用 | Teams 标准版：基础特效全免费；Plus 版：高级特效 |
| 无法导出无水印（部分模板）| 使用"空白项目"手动制作则无水印 |
| Google 图库版权合规 | 均为 Google 授权版权，商用安全 |

## 🔄 与其他工具的协作工作流

### Google Vids 2.0 + Kling 3.0 组合

```
Google Vids 2.0（脚本/分镜/配音参考）
    ↓ 生成视频脚本和配音稿
Kling 3.0（高质量视频生成）
    ↓ 用 Kling 生成视频片段
剪映专业版（最终剪辑）
    ↓ 合并+字幕+BGM
成品 ✅
```

### Google Vids 2.0 + MAI-Voice-1 组合

```
Google Vids 2.0（生成视频框架和字幕）
    ↓ 导出无配音版本
MAI-Voice-1（专属克隆声音配音）
    ↓ 导入配音
成品 ✅（专属声音 + 完整字幕）
```

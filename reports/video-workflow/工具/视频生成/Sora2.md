## Sora 2 详细指南

### 核心功能
- **文本生成视频**：输入提示词生成视频
- **图片生成视频**：上传图片生成动态视频
- **角色一致性**：保持角色外观一致
- **20秒时长**：业界最长
- **横竖屏输出**：支持16:9和9:16

### 使用流程

#### 1. 访问方式
- 官网：sora.com
- API：开发者平台

#### 2. 生成视频

```bash
# API调用示例（Python）
import openai

response = client.videos.create(
    model="sora-2",
    prompt="A serene mountain landscape at sunrise, golden light illuminating the peaks, cinematic quality",
    duration=20,
    aspect_ratio="16:9"
)
```

#### 3. 关键参数
| 参数 | 说明 | 推荐值 |
|------|------|--------|
| prompt | 视频描述 | 详细具体 |
| duration | 时长 | 10-20秒 |
| aspect_ratio | 比例 | 16:9/9:16 |
| fps | 帧率 | 24/30 |

### 技巧分享

#### 提示词技巧
1. **主体明确**：描述主要对象
2. **动作描述**：说明动态变化
3. **场景设定**：背景、光线、氛围
4. **风格指定**：电影感、动漫风等

#### 好的示例
```
A friendly robot walking through a futuristic city at night, neon lights reflecting on wet streets, cyberpunk style, cinematic shot, slow motion
```

#### 避免
- 过于复杂的动作描述
- 矛盾的元素（如火焰中的冰）
- 过长的时间线

### 适用场景
- AI短剧创作
- 产品展示视频
- 概念可视化
- 创意内容

## 常见问题

### Q1：生成的视频模糊
A：选择高分辨率选项，或使用修复工具增强

### Q2：视频生成失败
A：检查提示词是否包含敏感词，简化描述

### Q3：如何保持角色一致
A：Sora 2支持角色参考图功能

### Q4：商业使用版权
A：大多数工具支持商业使用，建议查看具体条款

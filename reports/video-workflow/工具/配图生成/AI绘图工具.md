## Midjourney 完全指南

### 1. 注册与使用

1. 加入 Discord：https://discord.com/invite/midjourney
2. 在频道中使用 /imagine 命令

### 2. 基础命令

```
/imagine prompt: [描述文本] --ar 16:9 --v 6 --s 250 --q 2
```

### 3. 参数详解

| 参数 | 说明 | 示例 |
|------|------|------|
| `--ar` | 宽高比 | 16:9, 9:16, 1:1 |
| `--v` | 模型版本 | 6 (最新) |
| `--s` | 风格化 | 0-1000 |
| `--q` | 质量 | 0.25-2 |
| `--no` | 排除元素 | --no text |
| `--iw` | 图片权重 | 0-2 |

### 4. 常用宽高比

| 用途 | 比例 |
|------|------|
| 短视频封面 | 9:16 |
| 横版视频 | 16:9 |
| 社交媒体 | 1:1 |
| 头像 | 1:1 |

### 5. 提示词结构

```
[主体] [场景] [动作] [风格] [光线] [构图] [质量]

示例：
一位穿汉服的年轻女子，江南古镇，雨天，青油伞，电影灯光，侧光肖像，8k画质
```

## AI配图工作流建议

### 短视频配图

1. 确定画面需求
2. 用 Midjourney 生成初稿
3. 选中满意的一张
4. Upscale 提升清晰度
5. 下载使用

### 批量生成

- 用同一提示词+不同种子
- 或调整 --iw 参数混合参考图

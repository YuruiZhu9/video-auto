## Hypereal AI（免费首选）

### 注册与API Key
1. 访问 https://hypereal.ai/dashboard → API Keys
2. 一键创建API Key
3. 获得35免费积分（可生成数千张）

### API调用（Python示例）

```python
import requests
import base64

API_URL = "https://api.hypereal.ai/v1/generate/image"
API_KEY = "your_api_key"

def generate_image(prompt, width=1920, height=1080, model="flux-2"):
    response = requests.post(
        API_URL,
        headers={
            "Authorization": f"Bearer {API_KEY}",
            "Content-Type": "application/json"
        },
        json={
            "model": model,
            "prompt": prompt,
            "width": width,
            "height": height,
            "num_images": 1
        }
    )
    data = response.json()
    # 返回图片URL或base64
    return data.get("images", [{}])[0].get("url")

# 示例调用
prompts = [
    "AI neural network visualization, blue neon glow, dark background",
    "Futuristic city with flying cars, golden hour lighting",
    "Robot helping human at computer, warm office, cinematic"
]
for p in prompts:
    url = generate_image(p)
    print(f"Generated: {url}")
```

## Midjourney V7（高质量付费方案）

### 使用方法
1. 加入 Discord 服务器
2. 在#general 频道输入 `/imagine`
3. 描述画面
4. 使用 U1-U4 选择变体，V 重新生成

### 进阶参数
```
--ar 16:9      # 宽高比
--s 750       # 风格化程度（0-1000）
--v 7         # 使用V7模型
--style raw   # 减少过度美化
--no XX       # 排除某元素
```

client = openai.OpenAI(
    api_key="YOUR_DASHSCOPE_KEY",

    model="wanx2.1",

# 配图生成工具对比

## Midjourney V7 ⭐推荐

### 注册与使用

1. 加入 Discord：discord.com/invite/midjourney
2. 在 `#general` 或 `#newbies` 频道
3. 使用 `/imagine` 命令

### 核心指令

```
/imagine prompt: [描述]
参数说明：
--ar 16:9        # 宽高比
--v 7            # 版本号
--q 2            # 质量(0.25-2)
--s 750          # 风格化(0-1000)
--iw 0.5         # 图像权重(0-2)
--no [元素]      # 排除元素
```

### 提示词结构

```
[主体] [环境] [光照] [色彩] [情绪] [风格] [技术参数]
示例：A cyberpunk city street at night, neon lights, rainy atmosphere, 
blue and pink color scheme, cinematic, 8k, unreal engine 5 render
```

### 技巧总结

1. **权重控制**：使用 :: 分隔元素，如 `cat::2 dog::1`
2. **图像参考**：使用 `--iw 0.5` 调整参考强度
3. **持续优化**：用 🔄 按钮生成变体
4. ** upscale**：用 U1-U4 按钮放大

### 常见问题

- **Q: 如何避免版权问题？**
  A: Midjourney生成图像可商用，但避免直接复制艺术家风格
- **Q: 提示词不生效？**
  A: 检查语法，使用逗号分隔，避免过长

## DALL-E 4

### 使用方式

1. 访问 chat.openai.com
2. 选择 DALL-E 模型
3. 输入提示词

### 特点

- 与ChatGPT集成，可对话式调整
- 多模态理解更强
- 版权合规有保障

### 参数

- 尺寸：1024×1024 / 1792×1024 / 1024×1792
- 质量：Standard / HD

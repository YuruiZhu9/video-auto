**API文档：** `mureka.com/developers`

### 1.1 注册与API Key

1. 访问 `mureka.com` → 注册账号
2. 进入 "开发者中心" → 创建应用 → 获取 API Key
3. 查看API文档：`mureka.com/developers`

### 1.2 API 调用示例

```python
import requests
import time

MUREKA_API_KEY = "YOUR_MUREKA_KEY"

def generate_music(prompt, duration=60, output_file="bgm.mp3", lang="zh"):
    """AI生成背景音乐"""
    url = "https://api.mureka.com/v1/music/generate"
    
    headers = {
        "Authorization": f"Bearer {MUREKA_API_KEY}",
        "Content-Type": "application/json"
    }
    
    payload = {
        "prompt": prompt,
        "duration": duration,  # 秒，最大300秒
        "model": "mureka-v8",
        "lang": lang,
        "format": "mp3"
    }
    
    print("🎵 正在生成音乐（预计30秒）...")
    response = requests.post(url, headers=headers, json=payload)
    
    if response.status_code == 200:
        data = response.json()
        task_id = data["data"]["task_id"]
        print(f"📋 任务ID：{task_id}")
        
        # 轮询获取结果（通常30-60秒）
        result_url = poll_task(task_id)
        if result_url:
            download_audio(result_url, output_file)
            return output_file
    else:
        print(f"❌ 生成失败：{response.status_code} - {response.text}")
        return None

def poll_task(task_id, max_wait=120):
    """轮询任务状态"""
    status_url = f"https://api.mureka.com/v1/music/status/{task_id}"
    headers = {"Authorization": f"Bearer {MUREKA_API_KEY}"}
    
    for _ in range(max_wait // 5):
        response = requests.get(status_url, headers=headers)
        status = response.json()["data"]["status"]
        print(f"  状态：{status}")
        
        if status == "completed":
            return response.json()["data"]["audio_url"]
        elif status == "failed":
            return None
        
        time.sleep(5)

def download_audio(url, output_file):
    """下载音频文件"""
    response = requests.get(url)
    with open(output_file, "wb") as f:
        f.write(response.content)
    print(f"✅ 音乐已保存：{output_file}")

# 使用示例
generate_music(
    prompt="科技感背景音乐，轻盈电子风格，无人声，60秒循环，适合知识科普视频",
    duration=60,
    output_file="/workspace/video_project/bgm_tech.mp3"
)
```

## 二、Lyria 3 Pro（Google DeepMind）— 完整结构歌曲

**官网：** `deepmind.com/lyria`  
**适用：** 需要完整结构（前奏→主歌→副歌→桥段→尾奏）的视频音乐  
**核心升级：** 歌曲时长从30秒→3分钟

### 2.1 主要特点

- **3分钟完整结构**：支持前奏/主歌/副歌/桥段/尾奏完整歌曲
- **多语言支持**：英文为主，中文支持逐步完善
- **情感模拟**：可指定情感类型（欢快/忧伤/紧张/平静）

### 2.2 使用方式

**方式一：Google AI Studio（在线体验）**
```
访问：ai.google.dev/lyria
注册 Google 账号即可使用
```

**方式二：API 调用**

## 三、Suno v5 — 全场景AI音乐社区

**官网：** `suno.ai`  
**优势：** 社区活跃，音乐风格最丰富，支持多语言  
**特点：** 操作简单，适合快速生成不同风格BGM

### 4.1 Pixabay Music（免费可商用）

**官网：** `pixabay.com/music`  
**特点：** 50万+音乐/音效，全部免费可商用，无需署名

```python
import requests

def search_pixabay_music(query, api_key="YOUR_PIXABAY_KEY"):
    """搜索Pixabay免费音乐"""
    url = "https://pixabay.com/api/"
    params = {
        "key": api_key,
        "q": query,
        "media_type": "music"
    }
    response = requests.get(url, params=params)
    results = response.json()["hits"]
    
    for r in results[:5]:
        print(f"🎵 {r['tags']} | 时长：{r['duration']}s | URL: {r['previewURL']}")
    
    return results

# 搜索科技感背景音乐
results = search_pixabay_music("technology ambient")
```

## 五、音量调整与混音

```bash
# BGM音量降低到30%（避免盖过人声）
ffmpeg -y -i bgm.mp3 -af "volume=0.3" bgm_30pct.mp3

# 人声 + BGM 混音
ffmpeg -y \
  -i voiceover.wav \
  -i bgm.mp3 \
  -filter_complex "[1:a]volume=0.3[mix];[0:a][mix]amix=inputs=2:duration=longest[out]" \
  -map "[out]" \
  mixed_audio.mp3

# 最终混音参数建议
# 人声：100%（清晰可辨）
# BGM：20-30%（背景氛围，不抢人声）
# 音效：50-80%（点缀，不喧宾夺主）
```

## 七、工作流集成

```
视频旁白（ElevenLabs/Fish Audio）
    ↓
Whisper 生成 SRT 字幕
    ↓
背景音乐（Mureka/Suno/剪映）
    ↓
FFmpeg 混音合成
ffmpeg -i video_frames -i voiceover.wav -i bgm.mp3 \
  -filter_complex "[1:a]volume=1.0[v];[2:a]volume=0.3[b];[v][b]amix=inputs=2:duration=longest[aout]" \
  -map "[aout]" -shortest final.mp4
```

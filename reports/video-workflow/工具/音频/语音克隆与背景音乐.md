# 语音克隆与背景音乐

## 一、语音合成

### ElevenLabs（推荐）

#### 注册与设置
1. **访问**：elevenlabs.io
2. **注册**：支持Google/Apple/邮箱注册
3. **初始设置**：
   - 选择使用目的（个人/商业）
   - 设定默认语言（推荐English）

#### 标准语音使用
1. **选择声音**：
   - Browse Voice Library
   - 预览不同声音
   - 选择适合的风格

2. **生成配音**：
   - 输入文本
   - 选择模型（eleven_multilingual_v2）
   - 调整参数：
     - Stability: 0.5（稳定性）
     - Similarity Boost: 0.75（相似度）
     - Style: 0.5（风格化程度）

#### 语音克隆流程

**准备音频样本**：
- 时长：5-30分钟
- 格式：MP3, WAV
- 质量：清晰无噪音
- 内容：多样化的句子

**克隆步骤**：
```
1. 进入 "Voice Lab"
2. 点击 "Add a new voice"
3. 选择 "Professional Voice Cloning"
4. 上传音频样本
5. 等待处理（5-15分钟）
6. 验证克隆效果
7. 保存voice_id
```

#### API调用

```python
import requests

url = "https://api.elevenlabs.io/v1/text-to-speech/{voice_id}"

headers = {
    "Accept": "audio/mpeg",
    "Content-Type": "application/json",
    "xi-api-key": "YOUR_API_KEY"
}

data = {
    "text": "Hello, this is a test.",
    "model_id": "eleven_multilingual_v2",
    "stability": 0.5,
    "similarity_boost": 0.75
}

response = requests.post(url, json=data, headers=headers)
# 保存音频
with open('output.mp3', 'wb') as f:
    f.write(response.content)
```

## 二、背景音乐生成

### Suno v5（2026年3月更新）

#### 快速开始
1. **访问**：suno.ai
2. **注册**：邮箱或Google账号
3. **创建**：点击 "Create"

#### 生成音乐

**模式选择**：
- **Instrumental**：纯音乐
- **Custom**：带歌词

**提示词技巧**：
```
英文模板：
[音乐类型], [节奏], [情绪], [乐器], [用途]
例：upbeat corporate, 120 BPM, positive, piano and drums, for presentation

中文模板：
轻快企业风，120BPM，正能量，钢琴和鼓，用于演示
```

**参数设置**：
- Duration: 60-180秒
- Style: 自定义或选择预设
- Instrumental: 是否有人声

#### 进阶技巧

1. **风格匹配**：
   - 视频节奏快 → 选择快节奏音乐
   - 视频节奏慢 → 选择舒缓音乐

2. **版权说明**：
   - 免费版：仅供个人使用
   - 付费版：支持商用（查看具体条款）

3. **生成技巧**：
   - 描述越具体越好
   - 指定具体乐器
   - 说明应用场景

## 四、工作流集成

### 推荐流程

```
1. 文案脚本 → 确定总时长
2. 语音克隆 → ElevenLabs生成配音
3. 背景音乐 → Suno生成纯音乐
4. 音量平衡 → 背景音乐音量 < 配音音量
5. 导入剪映 → 合成最终视频
```

### 音量建议
- 配音音量：-3dB to 0dB
- 背景音乐：-12dB to -6dB
- 音效：-6dB to -3dB

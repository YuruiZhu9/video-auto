## 一、ElevenLabs（⭐ 首选 — 工业级语音合成）

**官网：** `elevenlabs.io`  
**优势：** 语音克隆质量最高、情感丰富、支持28+语言  
**免费额度：** 每月10,000字符

### 1.1 注册与获取API Key

1. 访问 `elevenlabs.io` → Sign Up（Google/GitHub登录）
2. 登录后点击右上角头像 → "Profile"
3. 复制 "API Key"（格式：`sk_xxxx...`）

### 1.2 语音克隆流程

**Step 1：创建自定义声音**
```
1. 左侧菜单 → "Voice Library" → "Add a new voice"
2. 选择 "Professional Voice Cloning"
3. 上传5-30分钟清晰音频（MP3/WAV，建议人声纯净无背景音）
4. 填写声音名称和描述
5. 等待训练完成（约10分钟）
6. 复制 Voice ID（如：a1b2c3d4-e5f6-...）
```

**Step 2：API 调用**

```python
import requests
import json

ELEVENLABS_API_KEY = "YOUR_API_KEY"
VOICE_ID = "your_voice_id"

def text_to_speech(text, output_file="output.mp3"):
    """文本转语音"""
    url = f"https://api.elvenlabs.com/v1/text-to-speech/{VOICE_ID}"
    
    headers = {
        "Accept": "audio/mpeg",
        "Content-Type": "application/json",
        "xi-api-key": ELEVENLABS_API_KEY
    }
    
    data = {
        "text": text,
        "model_id": "eleven_v2",
        "voice_settings": {
            "stability": 0.5,           # 稳定性（越高越稳定，越低越有表现力）
            "similarity_boost": 0.75,   # 与原声相似度
            "style": 0.3,               # 风格化程度
            "use_speaker_boost": True   # 增强说话者特征
        }
    }
    
    response = requests.post(url, headers=headers, json=data)
    
    if response.status_code == 200:
        with open(output_file, "wb") as f:
            f.write(response.content)
        print(f"✅ TTS成功：{output_file}")
    else:
        print(f"❌ 失败：{response.status_code} - {response.text}")

# 使用示例
text_to_speech(
    text="欢迎观看本期视频，今天我们来聊一聊AI推荐系统的工作原理...",
    output_file="/workspace/video_project/voiceover.mp3"
)
```

## 二、Fish Audio（⭐ 免费中文TTS — 开源自托管）

**官网：** `fish.audio`  
**GitHub：** `github.com/fishaudio/fish-speech`  
**优势：** 完全开源免费、中文支持好、支持语音克隆

### 2.1 快速使用（云端API）

```python
import requests

# 使用 Fish Audio 公共模型（无需API Key）
def fish_tts(text, output="output.wav"):
    url = "https://api.fish.audio/v1/tts"
    headers = {"Content-Type": "application/json"}
    
    data = {
        "text": text,
        "model": "zh妹子",  # 中文女声模型
        "format": "wav"
    }
    
    response = requests.post(url, headers=headers, json=data)
    
    if response.status_code == 200:
        with open(output, "wb") as f:
            f.write(response.content)
        print(f"✅ 成功：{output}")

fish_tts("今天我们来讲一讲AI推荐系统的原理。", "voice_fish.wav")
```

### 2.2 本地部署（进阶）

```bash
# 克隆仓库
git clone https://github.com/fishaudio/fish-speech
cd fish-speech

# 使用 conda 环境
conda create -n fish-speech python=3.10
conda activate fish-speech
pip install -r requirements.txt

# 下载预训练模型
python -m fish_speech.models.vqgan.download

# TTS 推理
python -m fish_speech.tools.tts \
  --text "你的旁白文本" \
  --speaker "zh_female" \
  --output result.wav
```

## 四、语音识别 + 字幕生成

### Whisper（开源，自动生成SRT字幕）

```bash
# 安装
pip install openai-whisper

# 命令行使用（自动生成字幕）
whisper audio.wav --model medium --language Chinese --output_format srt

# 生成SRT文件
whisper audio.wav --model medium --language Chinese \
  --output_dir ./subtitles \
  --output_format srt
```

### Python 调用

```python
import whisper
import srt  # pip install srt

model = whisper.load_model("medium")  # tiny/base/small/medium/large

# 转录
result = model.transcribe(
    "voiceover.mp3",
    language="zh",
    task="transcribe",
    verbose=True
)

# 生成SRT字幕
subtitle_list = []
for i, segment in enumerate(result["segments"]):
    start = segment["start"]
    end = segment["end"]
    text = segment["text"].strip()
    subtitle_list.append(
        srt.Subtitle(index=i+1, 
                     start=srt.timedelta(seconds=start),
                     end=srt.timedelta(seconds=end),
                     content=text)
    )

srt_content = srt.compose(subtitle_list)
with open("subtitle.srt", "w", encoding="utf-8") as f:
    f.write(srt_content)

print("✅ 字幕已生成：subtitle.srt")
```

## 六、集成到视频制作管线

```
脚本文案
    │
    ├──→ ElevenLabs/Fish Audio ──→ 语音克隆 ──→ voiceover.wav
    │
    ├──→ Whisper ──→ 自动生成字幕 ──→ subtitle.srt
    │
    └──→ FFmpeg 合成
        ffmpeg -i video.mp4 -i voiceover.wav -i subtitle.srt \
          -map 0:v -map 1:a -vf "subtitles=subtitle.srt" \
          final_output.mp4
```

## 七、常见问题

| 问题 | 解决 |
|------|------|
| 克隆声音不像 | 上传更多音频（至少10分钟），确保人声纯净无背景音 |
| 中文发音不准 | ElevenLabs用中文音频训练克隆；Fish Audio选中文模型 |
| 音频太长 | 分段TTS，再用FFmpeg拼接 |
| 情感不足 | ElevenLabs调高 `style` 参数（0.5-0.8）|
| API超时 | 分段处理，每段不超过500字 |

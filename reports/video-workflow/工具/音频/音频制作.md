## 🎤 语音合成 - ElevenLabs 详解

### 访问方式

官网：https://elevenlabs.io

### 注册流程

1. 访问官网，点击 Sign Up
2. 选择 Google 或 Email 注册
3. 免费账号自动获得 10,000 字符/月的额度

### 核心功能

#### 1. AI配音（Text to Speech）

**操作步骤**：
1. 登录后进入工作台
2. 点击 "Text to Speech"
3. 输入文本
4. 选择或克隆音色
5. 调整参数
6. 生成并下载

**推荐参数**：
```
- Stability: 0.5（稳定性）
- Similarity Boost: 0.75（相似度）
- Style: 0.0（风格化程度）
- Speaker Boost: 开启
```

#### 2. 语音克隆（Voice Clone）

**步骤**：
1. 点击 "Voice Library" → "Add Voice"
2. 选择 "Instant Voice Clone"
3. 上传 1-30 分钟音频
4. 等待训练（1-5分钟）
5. 保存 voice_id

**要求**：
- 音频时长：1-30分钟
- 格式：MP3/WAV
- 质量：清晰无噪音
- 内容：多样化的语音样本

**注意**：克隆需要用户同意，不可克隆他人声音

#### 3. API 调用

```python
from elevenlabs import generate, play, clone

# 基础生成
audio = generate(
    text="你好，欢迎观看AI视频制作教程",
    voice="Rachel",
    model="eleven_multilingual_v2"
)
play(audio)

# 使用克隆声音
cloned_voice = clone(
    audio_path="sample.mp3",
    name="my_voice"
)
```

## 🎵 背景音乐 - Suno v5 详解

### 访问方式

官网：https://suno.ai

### 注册流程

1. 访问官网，点击 "Sign In"
2. 选择 Google/Microsoft 账号
3. 免费账号：50 credits/月

### 核心功能

#### 1. AI音乐生成

**操作步骤**：
1. 点击 "Create"
2. 在 "Prompt" 中描述音乐
3. 可选：上传参考音频
4. 设置时长（15-180秒）
5. 点击 "Generate"

**提示词技巧**：

```
格式：[情绪] [风格] [节奏] [乐器] [BPM]

示例：
- "Uplifting corporate music, piano and strings, 120 BPM, optimistic"
- "Cinematic epic trailer, orchestral, powerful, 90 BPM"
- "Lo-fi chill beat, hip hop, relaxed, 80 BPM"
```

#### 2. 参数设置

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| Duration | 时长 | 30-60秒 |
| Instrumental | 纯音乐 | true |
| Model | 模型版本 | chirp-v5-0 |

#### 3. API 调用

```python
import requests

def generate_music(prompt, duration=30):
    response = requests.post(
        "https://api.suno.ai/generate",
        headers={"Authorization": "Bearer YOUR_API_KEY"},
        json={
            "prompt": prompt,
            "duration": duration,
            "instrumental": True
        }
    )
    return response.json()
```

## 🔄 音频合成工作流

### 完整流程

```
1. 准备文案脚本
2. ElevenLabs 生成配音
   - 选择/克隆音色
   - 调整语速和情感
3. Suno v5 生成背景音乐
   - 匹配视频情绪
   - 调整时长
4. 音效添加
   - 转场音效
   - 重点强调音
5. 音频合并
   - 剪映专业版
   - 或 FFmpeg
```

### 常见问题

| 问题 | 解决方案 |
|------|----------|
| 语音不够自然 | 降低 Stability 值到 0.3-0.4 |
| 音乐太长 | 使用 Audacity 剪辑 |
| 音画不同步 | 剪映中手动对齐 |

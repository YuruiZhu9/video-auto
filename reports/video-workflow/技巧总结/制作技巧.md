# AI协作视频制作 - 技巧总结

## ⚡ 效率提升技巧

### 1. 提示词工程
- **视频生成提示词**：英文 > 中文，详细描述动作、场景、光线、情绪
  ```
  Good: A robot arm carefully assembles circuit boards in a clean room, 
        cinematic lighting, wide shot, slow motion, --ar 16:9 --v 7
  Bad:  robot working
  ```
- **GPT脚本生成**：提供具体格式模板，减少后期修改
- **Suno音乐**：情绪词 + 乐器组合 + BPM，比风格标签更精准

### 2. 批量生产
- 用Claude/GPT一次性生成多集脚本
- 视频片段统一规格（如统一1080P 30fps），便于FFmpeg批量拼接
- 背景音乐生成后，在Audacity中裁剪到精确时长

### 3. 音画同步
- AI配音先生成，再按语音时长调整视频片段
- 剪映中使用「波纹对齐」功能自动对齐音频节点
- FFmpeg混音时用 `-shortest` 参数自动截断

---

## 🎨 视觉质量技巧

### 4. 保持视觉一致性
- 用同一AI绘图工具生成所有配图（统一风格）
- 视频生成时上传参考图，保证角色/场景一致性
- 调色时先确定一个「主滤镜」，全片统一应用

### 5. 动态感增强
- 图片转视频时，使用 Motion 风格（让静态图产生运动效果）
- 用Ken Burns效果（缓慢缩放+平移）为静态图片增加动感
- 善用剪映「关键帧」做文字进场动画

### 6. 字幕设计
- 字体：选用无衬线字体（如思源黑体/Poppins）
- 颜色：白色带黑色描边（任何背景都清晰可见）
- 位置：底部留10-15%边距，不要紧贴画面边缘
- 样式：片头用大气标题，片内用简洁说明字幕

## 🎵 音频质量技巧

### 7. 音量层次
```
顶级音量：语音/旁白 70-80%
次级音量：背景音乐 20-35%
点缀音量：音效 10-20%
```
在剪映中：语音轨道 > 音乐轨道 > 音效轨道

### 8. AI配音自然度
- 避免超长句子，控制在15字/秒以内
- 加入适当停顿（标点符号用逗号/句号控制节奏）
- 情感表达：在提示词中加入情绪标签

### 9. BGM与内容匹配
| 视频类型 | 推荐BPM | 情绪 | 乐器 |
|----------|---------|------|------|
| 知识科普 | 80-100 | 专注/好奇 | Piano/Electronic |
| 产品宣传 | 100-120 | 活力/信任 | Orchestral/Pop |
| Vlog生活 | 90-110 | 轻松/自在 | Acoustic/Indie |
| 悬疑解说 | 60-80 | 紧张/期待 | Strings/Synth |
| 温情故事 | 70-90 | 温暖/感动 | Piano/Guitar |

## 🔧 技术技巧

### 10. FFmpeg vs 剪映选择
| 场景 | 推荐工具 |
|------|----------|
| 快速剪辑（少量素材） | 剪映 |
| 批量自动化生产 | FFmpeg |
| 精确时间轴控制 | FFmpeg |
| 添加复杂转场/特效 | 剪映 |
| 服务器端自动处理 | FFmpeg |

### 11. 工作流优化
```
推荐顺序（避免返工）：
文案确定 → AI配音生成 → 配音时长确认 → 视频片段生成（按配音长度切割）→ 剪辑合成
```
而非：先生成视频 → 再配音 → 发现时长不匹配

### 12. 存储管理
- 素材命名规范：`日期_项目_类型_序号`（如 `20260324_ai科普_视频_01.mp4`）
- 中间文件定期清理（保留原素材，删除临时渲染文件）
- 成品按平台命名（YouTube版/抖音版/B站版）

## 💰 成本优化

### 13. 工具选型建议
| 需求 | 推荐免费工具 | 付费升级选项 |
|------|-------------|-------------|
| 视频生成 | Sora 2（免费） | Seedance 2.0（专业） |
| 语音克隆 | Fun-CineForge（开源） | ElevenLabs（更自然） |
| 背景音乐 | Suno（免费额度） | Suno Pro / MiniMax |
| 视频剪辑 | 剪映（免费） | 剪映专业版（功能更多） |
| 全模态订阅 | — | MiniMax Token Plan（性价比最高） |

### 14. API调用优化
- 批量请求时设置合理延迟，避免触发限流
- 缓存常用模型输出，减少重复生成
- 长视频分多段生成，比一次性生成更稳定

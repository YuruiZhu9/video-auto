## 一、提示词技巧

### 图像生成提示词
```
[主体] + [场景] + [风格] + [光照] + [视角] + [参数]

示例：
一位亚洲女性在咖啡馆工作，阳光透过窗户，温暖的电影质感，正面视角，16:9，8k高清
```

### 视频生成提示词
```
[场景描述] + [动作] + [摄像机运动] + [风格] + [时长]

示例：
一只橘猫在阳光下的草地上玩耍，摄像机缓慢推近，慢动作，电影质感，10秒
```

### 音乐生成提示词
```
[类型] + [节奏] + [情绪] + [乐器] + [用途]

示例：
upbeat corporate, 120 BPM, positive energy, piano and drums, for presentation
```

## 三、常见问题解决

### 1. 视频生成问题
**Q：Sora生成视频有闪烁**
A：尝试在提示词中加入"stable lighting"、"consistent lighting"避免光照变化

**Q：生成的人物不一致**
A：Sora 2对人物一致性支持有限，建议使用静态图像+转场

### 2. 音频问题
**Q：配音和背景音乐不协调**
A：
- 降低背景音乐音量（-12dB到-6dB）
- 避免人声频率冲突
- 添加淡入淡出

**Q：语音克隆不自然**
A：
- 增加更多训练样本
- 调整stability参数（偏高更稳定）
- 使用最新的v2模型

### 3. 剪辑问题
**Q：字幕和配音不同步**
A：
- 使用剪映"对齐字幕"功能
- 手动调整时间轴
- 检查音频采样率

## 四、进阶技巧

### 1. 批量生成配图
使用相同提示词+seed参数保持风格一致：
```
/imagine prompt: [描述] --seed 12345 --ar 16:9
```

### 2. AI辅助剪辑
```python
# FFmpeg批量裁剪
for i in {1..10}; do
    ffmpeg -ss $((i*10)) -t 10 -i input.mp4 -c copy part_$i.mp4
done
```

### 3. 智能配乐
根据视频节奏自动匹配音乐：
- 快节奏 → 120+BPM
- 中等 → 80-120 BPM
- 慢节奏 → <80 BPM

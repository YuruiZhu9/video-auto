# AI视频制作实用技巧汇总

## 1. 提示词优化技巧

### Sora 2 提示词公式
```
[主体] + [动作] + [场景] + [镜头运动] + [风格] + [色调]
示例：一只黑猫在雨夜的街道上奔跑，跟随镜头，电影质感，冷色调
```

### Midjourney 提示词
```
主体描述, 详细特征, 光照条件, 色彩风格, 构图方式 --ar 16:9 --v 7
```

## 2. 效率提升技巧

### 批量生成
- 使用相同提示词生成多个版本
- 选择最佳效果
- 减少重复工作时间

### 模板复用
- 建立常用模板库
- 保存成功的工作流
- 快速复制到新项目

## 3. 质量优化技巧

### 视频质量
- 优先使用高分辨率源
- 避免多次转码
- 合理设置码率

### 音频质量
- 使用专业语音克隆
- 添加背景音乐时注意音量平衡
- 关键位置添加音效

## 4. 常见问题解决

### 问题1：视频生成不连贯
- 解决：使用参考图像
- 解决：分段生成后拼接

### 问题2：语音不自然
- 解决：调整 Stability 参数
- 解决：选择更适合的音色

### 问题3：版权问题
- 解决：使用付费授权工具
- 解决：使用自制素材

## 5. 工具组合推荐

### 快速出片组合
```
GPT写文案 → ElevenLabs语音 → Suno音乐 → 剪映剪辑
```

### 高质量组合
```
Claude润色 → Midjourney配图 → Sora生成视频 → 剪映精剪
```

# AI视频制作技巧总结

> 更新时间：2026-03-08

## 🎯 核心技巧

### 1. 文案优化

**提示词技巧**：
- 使用具体场景描述
- 明确目标受众
- 包含情感关键词

**示例**：
```
❌ "介绍AI技术"
✅ "用通俗易懂的语言，向零基础用户介绍AI入门知识，
   时长2分钟，语气亲切友善"
```

### 2. AI图像生成

**Midjourney 技巧**：
- 使用 `--ar` 指定比例
- 使用 `--v 7` 调用最新版本
- 使用 `--no` 排除不需要的元素
- 多次生成选择最佳

**提示词结构**：
```
[主体] + [环境] + [风格] + [光照] + [色彩] + [技术参数]

示例：
A futuristic robot, in a neon-lit city, cinematic style, 
volumetric lighting, cyberpunk colors, 8K, hyper-realistic
```

### 3. AI视频生成

**Sora 2 技巧**：
- 描述要具体，包含动作和场景
- 使用电影感描述词：cinematic, wide shot, close-up
- 明确时间线：starting from... then... finally...

**示例**：
```
Aerial view of a modern city at sunrise, 
the camera slowly descends through the skyscrapers,
birds flying in the distance, golden hour lighting,
cinematic drone shot, 4K
```

### 4. 语音克隆

**ElevenLabs 最佳实践**：
- 音频样本质量要好
- 克隆后微调参数
- 保持一致性

**常见问题解决**：
- 听起来像AI → 降低 Stability
- 情感不足 → 调高 Style
- 发音不准 → 调整 Similarity

### 5. 背景音乐

**Suno 技巧**：
- 风格标签组合使用
- Custom Mode 使用参考音频
- 分段生成不同情绪

**情绪关键词**：
- Uplifting: energetic, positive, hopeful
- Emotional: touching, moving, sentimental
- Tension: dramatic, suspenseful, intense

### 6. 剪辑节奏

**音频先行**：
1. 先确定背景音乐
2. 根据音乐节奏调整视频画面
3. 添加转场匹配节拍

**节奏技巧**：
- 重点内容前留白
- 切换配合重音
- 渐变替代硬切

## 🔧 自动化技巧

### 1. 批量处理

**FFmpeg 批量脚本**：
```bash
# 批量转换格式
for f in *.mp4; do ffmpeg -i "$f" -c:v libx264 "${f%.mp4}_h264.mp4"; done

# 批量添加前缀
for f in *.mp4; do mv "$f" "AI_$f"; done
```

### 2. 工作流模板

**剪映模板**：
1. 建立标准项目结构
2. 保存为模板
3. 批量替换素材

### 3. 文件管理

**推荐结构**：
```
project/
├── script/        # 脚本文案
├── assets/        # 原始素材
├── audio/         # 音频文件
├── images/        # 图片素材
├── video/         # 视频片段
├── exports/       # 导出成片
└── project/       # 项目文件
```

## ⚠️ 常见问题

### 1. AI生成内容问题

**问题**：AI生成的内容缺乏个性
**解决**：
- 加入个人风格元素
- 人工审核修改关键点
- 混合真实素材

**问题**：版权风险
**解决**：
- 了解各平台使用条款
- 保留创作证据
- 付费版本通常商用授权

### 2. 技术问题

**问题**：视频卡顿
**解决**：
- 检查电脑配置
- 降低预览分辨率
- 使用代理文件

**问题**：音画不同步
**解决**：
- 重新对齐音频
- 检查帧率设置
- 使用FFmpeg修复

### 3. 效果问题

**问题**：AI感明显
**解决**：
- 降低AI生成内容比例
- 增加人工元素
- 调整细节

**问题**：风格不统一
**解决**：
- 建立品牌规范
- 统一色调和字体
- 使用固定工具链

## 📈 效率提升

### 1. 快捷键

**剪映**：
- `Ctrl+B`：分割
- `Ctrl+Z`：撤销
- `Ctrl+E`：导出
- `Space`：播放/暂停

**Midjourney**：
- `U1-U4`： upscale
- `V1-V4`： variation
- `🔄`： regenerate

### 2. 预设和模板

- 建立常用提示词库
- 保存参数配置
- 复用成功案例

### 3. 工具组合

**高效组合**：
- 文案：Claude 4.6 → 图像：Midjourney → 语音：ElevenLabs → 音乐：Suno → 剪辑：剪映

## 🎬 视频生成技巧

### Seedance 2.0 API 使用（2026-04-04公测）
```python
import requests

url = "https://api.doubao.com/v1/seedance/generate"
headers = {"Authorization": f"Bearer {API_KEY}"}
data = {
    "model": "seedance-2.0",
    "prompt": "A person presenting AI technology in a modern studio",
    "duration": 6,
    "aspect_ratio": "16:9"
}
response = requests.post(url, headers=headers, json=data)
print(response.json())
```

### 提高AI视频质量的关键提示词技巧
- 加入镜头语言：`close-up, wide shot, pan, tilt, dolly zoom`
- 加入光线：`cinematic lighting, golden hour, backlit`
- 加入情绪：`emotional, dramatic, peaceful`
- 避免：多人互动、复杂物理效果（当前模型限制）

## 🖥️ PPT → 视频 转换技巧

### 方案一：Gamma → 图片序列 → 视频
```bash
# 1. Gamma 导出 PPT 为 PDF
# 2. PDF 转图片序列
pdftoppm -r 150 -png presentation.pdf frame

# 3. 图片合成视频
ffmpeg -framerate 2 -i "frame_%04d.png" \
  -c:v libx264 -preset fast -pix_fmt yuv420p \
  slides.mp4
```

## 💡 效率提升技巧

### 1. 并行工作流
```
文案撰写（Agent1）──┐
                   ├──> 视频合成
配图生成（Agent2）──┤
                   │
语音合成（Agent3）──┤
                   │
BGM生成（Agent4）──┘
```
同时启动4个任务，总时间 = 最慢那个任务的时间

### 2. 提示词模板库

**视频生成提示词模板：**
```
[主体描述], [动作/场景], [背景环境],
[光线], [镜头类型], [画面比例16:9], [风格：电影/摄影/插画]
```

**音乐生成提示词模板：**
```
[情绪：upbeat/calm/dramatic], [风格：electronic/orchestral/acoustic],
[节奏：120bpm], [用途：corporate/personal/vlog], [时长：30秒]
```

### 3. FFmpeg 批量自动化
```bash
#!/bin/bash
# 批量给视频添加统一片头
WATERMARK="logo.png"
for f in *.mp4; do
  filename="${f%.*}"
  ffmpeg -i "$f" -i "$WATERMARK" \
    -filter_complex "[0:v][1:v]overlay=W-w-10:10[out]" \
    -map "[out]" -map 0:a -c:v copy \
    "branded_$f"
done
```

## ⚠️ 常见坑与避坑指南

| 坑 | 避坑方法 |
|----|---------|
| 视频生成角色不一致 | 用同一张参考图 + `--cref` 参数 |
| AI音乐太单调 | 尝试多段拼接，或用Mureka的"结构化生成" |
| 配音与视频不同步 | 用 PrismAudio 自动同步，或手动在剪映拖动对齐 |
| 导出文件太大 | 剪映导出选 H.265，FFmpeg 用 `-crf 23-28` |
| 中文乱码 | 确保字体嵌入，或在剪映中重新输入文字 |
| 版权问题 | 配图用自己训练的模型，音乐用AI生成或购买版权 |

## 一、文案策划技巧

### 1.1 黄金开场公式

**3秒法则**：视频开头3秒必须抓住注意力

```
✅ 有效开场：
- 提问式："你知道吗，90%的人都在用错误的方式..."
- 数字式："2026年，这个技能价值百万..."
- 反常识："别再学Python了！真正该学的是..."
- 场景式："早上8点，你打开手机的第一件事..."

❌ 无效开场：
- "大家好，我是xxx，欢迎来到xxx"
- "今天给大家分享xxx"
```

### 1.2 脚本结构模板

**短视频（30-60秒）**：
```
0-3s：Hook（抓眼球）
3-15s：问题/痛点（引发共鸣）
15-40s：核心解决方案（干货）
40-55s：案例/证据（增强信任）
55-60s：CTA（引导行动）
```

**中视频（1-3分钟）**：
```
0-5s：开场Hook
5-30s：背景介绍/问题定义
30-90s：核心内容（分3点）
90-150s：深度展开/案例分析
150-165s：总结回顾
165-180s：CTA
```

### 1.3 AI辅助脚本优化

使用智谱GLM-4-Flash优化脚本：
```
提示词：
"请将以下视频脚本优化：
1. 增强Hook力度，使开头更有冲击力
2. 删除冗余文字，每句不超过20字
3. 加入至少一个反常识观点
4. 结尾加入强CTA
原文：[粘贴原文]"
```

## 四、视频剪辑技巧

### 4.1 节奏感控制

```
快节奏（适合：运动/科技/广告）：
- 每张图片/片段：1-2秒
- 频繁切换 + 短转场
- 背景音乐：120BPM以上

慢节奏（适合：情感/知识/纪录片）：
- 每张图片/片段：3-5秒
- 缓慢切换 + 长转场
- 背景音乐：80-100BPM
```

### 4.2 转场选择

| 转场 | 适合场景 | 时长 |
|------|----------|------|
| Fade（淡入淡出）| 情绪转折、章节过渡 | 0.5-1s |
| Dissolve（叠化）| 连续叙事 | 0.3-0.5s |
| Slide（滑动）| 信息切换 | 0.3s |
| Zoom（缩放）| 强调重点 | 0.2-0.3s |
| 随机 | 现代感/创意 | — |

### 4.3 字幕设计

**字体选择**：
- 中文：思源黑体（Source Han Sans）/阿里巴巴普惠体
- 英文：Arial Bold / Helvetica Bold
- 避免：宋体（太老气）、楷体（难读）

**样式推荐**：
```css
字号：视频高度的1/30 ~ 1/40
颜色：白色 + 黑色描边
位置：底部居中，距边缘10%
行间距：1.5倍
```

## 五、AI工具使用技巧

### 5.1 提示词工程

**视频生成提示词公式**：
```
[主体] + [动作] + [场景] + [光线] + [风格] + [镜头语言]

示例：
"A young woman typing on laptop, drinking coffee, working in
a cozy cafe, warm morning sunlight streaming through window,
cinematic style, medium shot, shallow depth of field"

"科技公司办公室内景，程序员专注编写代码，蓝色LED灯光，
赛博朋克风格，广角镜头，景深效果"
```

**优化技巧**：
- 越具体越好："a wooden table" vs "a surface"
- 加入情绪词："energetic", "peaceful", "dramatic"
- 指定时间段："sunset", "midnight", "golden hour"
- 镜头语言："close-up", "wide shot", "bird's eye view"

### 5.2 质量提升技巧

```
1. 多生成，选最优
   → 同样的提示词生成5-10次，选最好的1-2个

2. 局部重绘
   → 用局部编辑功能修复不满意的部分

3. 风格统一
   → 固定风格关键词，保证系列视频一致性

4. 后处理增强
   → 生成后用Topaz Video AI提升画质
```

### 5.3 成本控制

| 节省方法 | 效果 |
|----------|------|
| 720P vs 1080P | 成本降低40% |
| 竖屏优先（9:16）| 更高完播率 |
| 分段生成 | 避免一次性失败浪费 |

## 七、常见问题解决方案

### 7.1 视频生成质量差

```
✅ 解决方案：
1. 改用更详细的提示词
2. 尝试不同模型（SkyReels V4 / PixVerse V6）
3. 先生成高质量配图，再图生视频
4. 增加生成次数，挑选最佳结果
5. 使用Topaz Video AI后处理提升画质
```

### 7.2 音画不同步

```
✅ 解决方案：
1. 测量音频和视频的时长差
2. 用FFmpeg的-itsoffset调整
3. 在剪映中手动对齐关键帧
4. 检查帧率是否一致（统一用30fps）
```

### 7.3 字幕不准

```
✅ 解决方案：
1. 配音使用清晰标准普通话
2. 用GLM-4-Flash先整理配音文字
3. 手动微调关键段落
4. 避免：方言/太快/背景噪音大
```

### 7.4 背景音乐太大声

```
✅ 解决方案：
1. BGM音量控制在配音的20-30%
2. BGM设置淡入淡出
3. 人声处BGM自动降音量（剪映"人声分离"）
```

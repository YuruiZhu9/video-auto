# AI视频制作技巧总结

## 🚀 效率提升技巧

### 1. 提示词优化

**视频生成提示词**
```
❌ 错误：生成一个奔跑的人
✅ 正确：A person running on a beach at sunset, golden hour lighting, dynamic pose, cinematic shot, high quality
```

**关键要素**：
- 具体动作描述
- 场景环境说明
- 光照和色彩
- 画面比例

### 2. 批量生成策略

**方法**：
1. 一次性生成3-5个版本
2. 筛选最佳结果
3. 对不满意的部分重绘

**工具支持**：
- Seedance 2.0：支持批量生成
- Suno v5：一次性生成2首

### 3. 工作流自动化

**推荐方案**：
```python
# 自动生成 + 自动剪辑流程
def automated_video_workflow(topic, script):
    # 1. 生成配图
    images = [midjourney.generate(p) for p in script.scenes]
    
    # 2. 生成配音
    audio = elevenlabs.generate_text_to_speech(script.content)
    
    # 3. 生成背景音乐
    music = suno.generate_background_music(script.mood)
    
    # 4. 合成视频
    video = ffmpeg.combine(images, audio, music)
    
    return video
```

## 💡 质量提升技巧

### 1. 视频质量

| 问题 | 解决方案 |
|------|----------|
| 画面模糊 | 使用 1080P 以上分辨率 |
| 动作不自然 | 使用 Seedance 2.0 |
| 风格单调 | 混合使用 Sora 2 + Midjourney |

### 2. 音频质量

| 问题 | 解决方案 |
|------|----------|
| 语音机械 | 调整 ElevenLabs Stability 参数 |
| 音乐太吵 | 降低背景音乐音量到 -20dB |
| 音画不同步 | 手动在剪映中微调 |

### 3. 字幕优化

- 使用剪映 "智能字幕" 识别
- 人工校对专业术语
- 调整字体大小和位置

## 🎯 场景化技巧

### 短视频（30-60秒）

**特点**：快节奏、吸引力强

**技巧**：
1. 前3秒必须有亮点（Hook）
2. 使用节奏感强的背景音乐
3. 字幕配合画面节奏
4. 结尾添加 CTA

**工具组合**：
```
Seedance 2.0 → ElevenLabs → Suno v5 → 剪映
```

### 品牌宣传片（2-5分钟）

**特点**：专业、情感丰富

**技巧**：
1. 开头讲故事/场景
2. 中间展示产品/服务
3. 结尾情感升华
4. 配音使用专业克隆音色

**工具组合**：
```
Gamma(PPT) + Midjourney → ElevenLabs(克隆) → Suno v5(定制) → 剪映
```

### 教育课程（5-15分钟）

**特点**：信息量大、结构清晰

**技巧**：
1. 章节化制作
2. 画面配合文字说明
3. 语速适中（1.2x）
4. 添加要点标注

**工具组合**：
```
AiPPT → ElevenLabs → 剪映（模板）
```

## 🔧 常见问题解决

### 1. 视频生成失败

**可能原因**：
- 提示词包含敏感词
- 服务器繁忙
- 账号额度用尽

**解决方案**：
1. 检查提示词，去除敏感词
2. 稍后重试
3. 检查账号状态

### 2. 音画不同步

**可能原因**：
- 音频时长与视频不匹配
- 帧率不一致

**解决方案**：
1. 在剪映中调整
2. 使用 FFmpeg 统一帧率
3. 预留缓冲时间

### 3. 版权问题

**注意事项**：
- Suno v5 生成音乐可商用
- Midjourney 生成图片需遵守社区规则
- ElevenLabs 语音克隆需用户授权

## 🔥 任务二：MAI-Voice-1 克隆专属声音（20分钟）

**目标：** 录制 10 秒声音样本，获得专属 AI 克隆声音，永久用于视频配音

### 准备工具（2分钟）
```
✅ 手机或电脑录音
✅ Audacity（免费）：https://www.audacityteam.org/
✅ Microsoft 账号（获取公测资格）
```

### 操作步骤（18分钟）

**Step 1：录制声音样本（5分钟）**
```
录音内容（任选一段朗读）：
"你好，欢迎使用AI语音合成系统。今天是2026年4月10日，
我来为大家演示如何制作一条专业的AI视频。"

要求：
  ✅ 时长：10秒以上（越长越好，推荐30秒）
  ✅ 环境：安静，手机放桌上，嘴距麦克风15cm
  ✅ 语速：正常语速，自然流畅
  ✅ 情绪：平静自然，不要过于激动
```

**Step 2：降噪处理（3分钟，Audacity）**
```
1. 打开 Audacity → 导入音频（或直接录音）
2. 选择一段纯背景噪音（2秒）→ Ctrl+C 复制
3. 效果 → 降噪 → 噪声消除
4. 点击"噪声分析"（记录噪音样本）
5. 全选（Ctrl+A）→ 效果 → 降噪
6. 降噪量：15dB → 确定
7. 文件 → 导出 → WAV（16-bit PCM）
```

**Step 3：克隆声音（5分钟）**
```bash
# API 调用
curl -X POST "https://api.microsoft.com/ai/voice/v1/clone" \
  -H "Authorization: Bearer YOUR_MAI_API_KEY" \
  -F "audio=@voice_sample.wav" \
  -F "name=my_custom_voice" \
  -F "language=zh-CN" \
  -F "gender=female" \
  -o clone_result.json

cat clone_result.json
# 预期输出：
# {"voice_id": "mai_voice_xxxxx", "status": "ready", ...}
```

**Step 4：合成第一条专属配音（5分钟）**
```python
import requests

API_KEY = "YOUR_KEY"
VOICE_ID = "mai_voice_xxxxx"  # 上一步获取的 voice_id

response = requests.post(
    "https://api.microsoft.com/ai/voice/v1/synthesize",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "text": "欢迎观看本期视频，今天我们用AI技术制作一条完整的视频教程。",
        "voice_id": VOICE_ID,
        "speed": 1.0,
        "pitch": 0,
        "emotion": "warm",
        "format": "mp3"
    },
    timeout=60
)

with open("my_voice.mp3", "wb") as f:
    f.write(response.content)

print("✅ 专属声音配音已生成：my_voice.mp3")
```

```

   可用次数：公测期间有限额度
   商用授权：待微软公布
```

## 四、Seedance 2.0 全模态创作实操教程

### 场景一：音频驱动视频（Seedance 2.0 独家功能）

这是目前业内首创的功能，可以将音频直接转化为视频角色的动作和表情：

```python
# Seedance 2.0 音频驱动视频 API 调用示例
import requests

response = requests.post(
    "https://ark.cn-beijing.volcengineapi.com/api/seedance/v2/generate",
    headers={
        "Authorization": "Bearer YOUR_SEEDANCE_API_KEY",
        "Content-Type": "application/json"
    },
    json={
        "model": "seedance-2.0",
        "input_modality": "audio",      # 🆕 音频输入（业界首创）
        "audio_url": "https://your-cdn.com/voice.wav",
        "character_image": "https://your-cdn.com/avatar.png",
        "duration": 10,
        "resolution": "1080p"
    }
)
print(response.json())
# 输出：AI角色根据音频自动生成对口型+表情+动作的视频
```

**实操应用场景**：
- 用自己克隆的声音（ElevenLabs/Kokoro-82M）驱动AI数字人
- 配音完成后一键生成对口型视频，大幅减少人工对口型时间
- 多语言配音→自动生成多语言视频版本（国际化场景）

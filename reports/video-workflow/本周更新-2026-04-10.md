### MAI-Transcribe-1 字幕生成实战（词错率3.8%全球第一）

**API调用示例（Python）：**
```python
import requests
import json

# MAI-Transcribe-1 字幕生成
url = "https://api.microsoft.com/ai/transcribe/v1"
headers = {"Authorization": "Bearer YOUR_API_KEY"}
data = {
    "audio_url": "https://your-audio-file.mp3",
    "language": "zh-CN",  # 中文
    "timestamp": True,
    "word_level": True    # 词级时间戳（自动字幕对齐）
}
result = requests.post(url, headers=headers, json=data).json()
print(result["subtitle_srt"])  # 输出SRT字幕格式
```

```python
  -F "audio=@voice_sample.wav" \

  -F "language=zh-CN"
# 返回：voice_id = "mai_voice_xxxxx"
```

**Step 3：文本转语音**
```python
result = requests.post(

        "voice_id": "mai_voice_xxxxx",
        "speed": 1.0,      # 语速 0.5-2.0
        "pitch": 0,       # 音调 -10~10
        "emotion": "warm" # warm/calm/excited
```

## 🛠️ 实操指南一：VoxCPM2 本地语音克隆 — 3 步出音

> VoxCPM2：全球首个无 Tokenizer 的多语言语音克隆模型，Apache 2.0 可商用

### 环境准备

```bash
# Python 3.9+ 环境
python --version  # 确认 >= 3.9

# 推荐创建虚拟环境
python -m venv vox_env
source vox_env/bin/activate  # Linux/Mac
# vox_env\Scripts\activate   # Windows

# 克隆仓库
git clone https://github.com/OpenBMB/VoxCPM2
cd VoxCPM2

# 安装依赖
pip install -r requirements.txt
```

### 语音样本准备

```
✅ 最佳实践：
  • 时长：10秒 ~ 3分钟（越多越精准，推荐 30秒-1分钟）
  • 格式：WAV（最优）或 MP3（16kHz+）
  • 环境：安静、无背景音乐、无回声
  • 内容：日常对话、朗读均可，避免过于专业术语
  • 数量：1-3 段音频即可

❌ 不推荐：
  • 多人对话（有混音）
  • 远距离录音（有回声）
  • 背景有音乐
```

### Step 1：语音合成（TTS，无需克隆）

```bash
# 中文语音合成
python synthesize.py \
  --text "欢迎使用VoxCPM2，这是一款开源的多语言语音合成模型" \
  --lang zh \
  --output demo_zh.wav

# 英文语音合成
python synthesize.py \
  --text "Hello, this is VoxCPM2, the first tokenizer-free multilingual voice model" \
  --lang en \
  --output demo_en.wav
```

### Step 2：语音克隆（需要参考音频）

```bash
# 克隆声音（10秒参考音频即可）
python clone.py \
  --reference my_voice.wav \
  --text "这是一段克隆声音的测试，效果非常自然" \
  --output cloned_voice.wav

# 克隆 + 情感控制（如果模型支持）
python clone.py \
  --reference my_voice.wav \
  --text "（悲伤地）一切都结束了..." \
  --emotion sad \
  --output sad_voice.wav
```

### Step 3：集成到视频工作流

```bash
# FFmpeg 拼接配音与视频
ffmpeg -i video_no_audio.mp4 -i cloned_voice.wav \
  -c:v copy -c:a aac -shortest \
  final_video.mp4

# 调整音量（配音通常偏小）
ffmpeg -i final_video.mp4 \
  -af "volume=1.5" \
  final_video_loud.mp4
```

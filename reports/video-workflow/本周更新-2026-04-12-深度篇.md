### 三种接入视频工作流的部署方案

#### 方案A：本地推理（适合有本地GPU的用户）

```bash
# 推荐配置：NVIDIA RTX 3090+ / A100
# 操作系统：Ubuntu 22.04 / Windows WSL2

# Step 1：克隆 VoxCPM2
git clone https://github.com/OpenBMB/VoxCPM2
cd VoxCPM2

# Step 2：创建conda环境
conda create -n voxcpm2 python=3.10
conda activate voxcpm2
pip install -r requirements.txt

# Step 3：下载模型（约2GB）
python download_model.py --model voxcpm2-base

# Step 4：基础语音合成（中文）
python synthesize.py \
  --text "这是一位创业者在讲述自己的AI创业故事" \
  --lang zh \
  --output ./output/founder_story.wav \
  --speed 1.0

# Step 5：声音克隆
python clone.py \
  --reference ./voice_samples/my_voice_30s.wav \
  --text "欢迎观看我的AI视频创作教程" \
  --output ./output/cloned_voice.wav \
  --speed 0.95  # 语速微调，0.95更自然
```

**关键参数说明：**

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| `--speed` | 0.9-1.1 | 0.95最自然，1.0标准语速 |
| `--lang` | zh/en/ja/ko | 中文/英文/日文/韩文 |
| 参考音频时长 | 10-60秒 | 越长克隆越准确 |
| 参考音频质量 | 16kHz+ | 手机录音完全够用 |

#### 方案B：云端API服务化（适合团队协作）

```bash
# 在云服务器（阿里云/腾讯云/Colab Pro）部署API服务
# Step 1：启动API服务
python api_server.py --port 8080 --model voxcpm2-base

# Step 2：调用API（批量配音）
curl -X POST http://localhost:8080/synthesize \
  -F "text=欢迎来到AI视频教程" \
  -F "lang=zh" \
  -F "speed=0.95" \
  -F "voice_ref=@my_voice.wav" \
  -o output.wav

# Step 3：集成到FFmpeg视频合成工作流
ffmpeg -i video.mp4 -i output.wav \
  -c:v copy -c:a aac -map 0:v:0 -map 1:a:0 \
  final_video.mp4
```

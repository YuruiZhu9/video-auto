### 核心技术突破

**VoxCPM2** 是全球首个**无需传统分词器（Tokenizer）的多语言语音生成与克隆模型**，这在语音AI领域是范式级创新。

传统TTS模型的痛点：
```
❌ 传统方案：
  文本 → Tokenizer（分词）→ 声学模型 → 声码器 → 音频
  问题：Tokenizer在多语言场景下表现不稳定，
        中文/方言/小语种尤甚，韵律损失大

✅ VoxCPM2 方案：
  文本 → 直接生成压缩音频潜码 → 声码器 → 音频
  优势：无Tokenizer，多语言统一表征，韵律保留更完整
```

### VoxCPM2 快速上手（本地部署）

```bash
# 克隆仓库
git clone https://github.com/OpenBMB/VoxCPM2
cd VoxCPM2

# 安装依赖
pip install -r requirements.txt

# 语音合成
python synthesize.py --text "欢迎使用VoxCPM2语音合成" \
                     --lang zh \
                     --output vox_demo.wav

# 语音克隆（需要10秒+参考音频）
python clone.py --reference voice_sample.wav \
                --text "这是一段克隆声音" \
                --output cloned_voice.wav
```

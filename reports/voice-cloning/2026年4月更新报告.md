## 三、ChatTTS 专项分析（本次重点）

### 3.1 重要澄清：ChatTTS 不是声音克隆工具

⚠️ **ChatTTS 是对话式 TTS 生成工具，不是声音克隆工具。**

| 能力 | 说明 |
|------|------|
| 音色生成 | ✅ 支持（随机采样多种预设音色） |
| 音色保存/恢复 | ✅ 支持（保存 spk_emb 用于后续恢复） |
| **声音克隆** | ❌ 不支持（无法克隆特定人声音） |
| 微调训练 | ❌ 不支持（仅预训练模型） |

**适合场景**：LLM 对话助手、有声内容生成、播客配音、多说话人对话系统。

### 3.2 ChatTTS 核心参数控制

```
[oral_0-9]  口语化程度（0最书面，9最口语）
[laugh_0-2]  笑声强度（0无，1轻，2大笑）
[break_0-7]  停顿长度（0无，7最长）
[uv_break]  词级静音断点
[lbreak]     句子级停顿
[laugh]      自动插入笑声
```

### 3.3 ChatTTS 安装与使用

```bash
# 安装
pip install ChatTTS

# 基础使用
python
import ChatTTS
import torch
import torchaudio

chat = ChatTTS.Chat()
chat.load(compile=False)

texts = ["你好，欢迎使用ChatTTS。", "这是一个测试。"]
wavs = chat.infer(texts)

for i, wav in enumerate(wavs):
    torchaudio.save(f"output_{i}.wav", torch.from_numpy(wav), 24000)
```

### 3.4 ChatTTS 音色保存与恢复

```python
# 采样一个音色并保存
rand_spk = chat.sample_random_speaker()
print(rand_spk)  # 是一串向量，用于恢复

# 恢复音色
params_infer_code = ChatTTS.Chat.InferCodeParams(
    spk_emb=rand_spk,
    temperature=0.3,
    top_P=0.7,
    top_K=20
)

# 使用保存的音色合成
wavs = chat.infer(texts, params_infer_code=params_infer_code)
```

## 四、OpenVoice V2 完整指南（MIT商用免费）

### 4.1 核心能力

- **精准音色克隆**：10-30秒音频克隆参考音色

```bash

pip install F5-TTS
```


### 6.3 已知问题

⚠️ **长文本偶发"核嗓"问题**：超过约50字的中文长文本可能出现音色失真。建议：
- 分段合成（每段≤50字）
- 或切换至 CosyVoice3 处理长文本

### 7.2 集成调用模板（exec方式）

```python
# 在 OpenClaw exec 中调用任意 TTS 模型
import subprocess

def tts_clone(model_name, text, ref_audio, output):
    """通用TTS调用模板"""
    if model_name == "qwen3":
        cmd = ["qwen-tts", "--text", text, "--ref", ref_audio, "--output", output]
    elif model_name == "cosyvoice":
        cmd = ["python", "cosyvoice_cli.py", "--text", text, "--ref", ref_audio]
    elif model_name == "openvoice":
        cmd = ["python", "openvoice_cli.py", "--text", text, "--ref", ref_audio]
    # ...
    result = subprocess.run(cmd, capture_output=True, text=True)
    return result.returncode == 0, result.stdout
```

## 九、常见问题与解决

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 音色不自然 | 数据质量差/量少 | 增加训练数据，使用CosyVoice3 RL |
| 推理太慢 | GPU显存不足 | 使用量化版（Qwen3-TTS oQ8 0.5B）|
| 中文发音不准 | 模型中文能力弱 | 换用CosyVoice3（中文CER 0.71）|
| 长文本失真 | F5-TTS长文本问题 | 分段处理，每段≤50字 |
| 声音泄漏 | RVC音色泄漏 | 使用Top1检索，RVC V3已解决 |
| 跨语言克隆走音 | 语言不在支持列表 | OpenVoice V2支持6种原生语言 |
| 情感单调 | 基础模型情感弱 | 使用Higgs Audio V2.5（GRPO对齐）|

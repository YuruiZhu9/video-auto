## 一、项目简介

ChatTTS 是一款专为大语言模型（LLM）对话场景设计的开源文本转语音（TTS）模型，由 2Noise 团队开发。2024年5月发布后在 GitHub 仅用5天即斩获 18k+ Star，是当年增长最快的开源AI项目之一。

### 核心特点
- **对话优化**：专门针对自然对话场景，韵律自然，包含停顿、笑声等
- **多语言**：支持中文和英文，中文效果最佳
- **情感控制**：可预测和控制笑声、语气强度等
- **零训练**：预训练模型，无需自己采集声音样本
- **极速推理**：单句生成约 22-30 秒（在线版），本地 GPU 更快

> ⚠️ **注意**：ChatTTS 是预训练 TTS 模型，**不支持直接克隆特定人声**（需额外微调）。若需克隆特定音色，请参考 CosyVoice 或 GPT-SoVITS 方案。

## 二、环境准备

### 系统要求
- Python 3.9+
- GPU（推荐 NVIDIA，16GB+ 显存更流畅）
- CUDA 11.8+ / CUDA 12.x

### 安装（pip）
```bash
pip install ChatTTS
```

### 安装（源码）
```bash
git clone https://github.com/2Noise/ChatTTS.git
cd ChatTTS
pip install -e .
```

### 模型下载
模型会在首次使用时自动下载（HuggingFace），如需手动下载：
```bash
# 设置 HuggingFace 镜像（国内推荐）
export HF_ENDPOINT=https://hf-mirror.com

# 或在代码中指定
import ChatTTS
chat = ChatTTS.Chat()
chat.load模型()  # 自动下载
```

## 三、快速使用

### 基础文本转语音
```python
import ChatTTS

# 初始化
chat = ChatTTS.Chat()

# 加载模型（首次自动下载）
chat.load()

# 文本输入
text = "你好，我是一个AI助手。今天天气真不错，你想聊些什么呢？"

# 生成音频
wavs = chat.chat(text, lang='zh')

# 保存
chat.save_wav("output.wav", wavs)
```

### 使用参考音频（控制风格）
```python
import ChatTTS

chat = ChatTTS.Chat()
chat.load()

# 使用参考音频引导风格
ref_audio = "path/to/your_reference.wav"
text = "这是一个由参考音频风格控制的语音合成示例。"

# 通过参考音频控制音色和风格
wavs = chat.chat(
    text,
    ref_audio=ref_audio,  # 参考音频路径
    lang='zh'
)

chat.save_wav("styled_output.wav", wavs)
```

### 情感控制（高级）
```python
import ChatTTS

chat = ChatTTS.Chat()
chat.load()

# 生成多段候选音频，选择最佳
texts = [
    "太棒了！这个结果超出我的预期！",  # 候选1
    "嗯...让我想想这个问题。"          # 候选2
]

# 生成多个候选，选择最自然的
for i, txt in enumerate(texts):
    wavs = chat.chat(txt, do_text_normalization=True)
    chat.save_wav(f"candidate_{i}.wav", wavs)
```

## 六、API 服务化

### FastAPI 服务
```python
# server.py
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
import ChatTTS
import uuid
import os

app = FastAPI(title="ChatTTS API")

# 初始化（启动时加载一次）
chat = ChatTTS.Chat()
chat.load()

class TTSRequest(BaseModel):
    text: str
    lang: str = "zh"

class TTSResponse(BaseModel):
    audio_id: str
    duration: float

@app.post("/tts", response_model=TTSResponse)
async def generate_speech(req: TTSRequest):
    try:
        wavs = chat.chat(req.text, lang=req.lang)
        audio_id = str(uuid.uuid4())
        filepath = f"/tmp/{audio_id}.wav"
        chat.save_wav(filepath, wavs)
        return TTSResponse(
            audio_id=audio_id,
            duration=len(wavs[0]) / 24000
        )
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))

@app.get("/audio/{audio_id}")
async def get_audio(audio_id: str):
    filepath = f"/tmp/{audio_id}.wav"
    if not os.path.exists(filepath):
        raise HTTPException(status_code=404, detail="Audio not found")
    return FileResponse(filepath, media_type="audio/wav")

# uvicorn server:app --host 0.0.0.0 --port 8000 --reload
```

## 七、与 OpenClaw Skills 集成

### 工作流设计
```
输入文案（用户发送）
    ↓
OpenClaw Skill 调用 ChatTTS
    ↓
生成 WAV/MP3 音频
    ↓
通过消息通道返回音频文件
```

### 示例 Skill 片段（概念代码）
```python
# /root/.openclaw/skills/chattts-tts/SKILL.md
"""
## 使用方式
用户发送：/tts 你好，今天是美好的一天！
AI 生成语音并发送
"""

import ChatTTS

    chat = ChatTTS.Chat()
    chat.load()
    wavs = chat.chat(text, lang='zh')
    chat.save_wav(output_path, wavs)
    return output_path

# 在 agent 代码中调用
audio_file = generate_speech(user_text)
# 上传/发送音频文件给用户
```

## 八、常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 生成音质发闷/有噪声 | 模型未正确加载 | 确认 CUDA 版本匹配，重新 `pip install` |
| 推理太慢（>30秒/句） | 显存不足或无GPU | 使用量化版本，或切换到在线版 chattts.com |
| 中文多音字发音错误 | 语言模型局限 | 尝试使用同音字替换，或调整 prompt |
| 无法克隆特定音色 | ChatTTS 不支持直接克隆 | 改用 CosyVoice / GPT-SoVITS / OpenVoice |
| 韵律过于平淡 | 缺少情感提示 | 在文本中添加情感符号（笑声`[laugh]`、停顿`[break]`）|

### 情感符号参考
```python
text_with_emo = """
你好呀[laugh]，我是你的语音助手。 
今天我们[break]来聊点有趣的话题吧！[smile]
"""
wavs = chat.chat(text_with_emo, lang='zh')
```

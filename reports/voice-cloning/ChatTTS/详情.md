# ChatTTS — 对话场景首选

## 1. 方案概述

**ChatTTS** 是 2Noise 团队开源的对话式语音生成模型，专门为与大语言模型（LLM）配合使用而优化。它不是传统意义上的"声音克隆"工具，而是通过微调来获得特定音色。

### 核心特点

| 特性 | 说明 |
|------|------|
| 🎯 **场景定位** | 对话助手/LLM语音输出 |
| 🌍 **语言** | 中文 + 英文（双语支持优秀） |
| 🎭 **韵律自然** | 韵律控制优秀，适合日常对话 |
| ⚡ **推理速度** | 极快（比GPT-SoVITS快3-5倍） |
| 🔧 **微调能力** | 支持 LoRA 微调定制音色 |
| ⚠️ **克隆方式** | 不支持零样本克隆，需要微调 |

**GitHub：** `2noise/ChatTTS`（45k+ Stars）  
**官方体验：** https://chattts.com/

## 2. 声音样本准备

### 音频规格

| 项目 | 要求 |
|------|------|
| **格式** | WAV（推荐）或 MP3 |
| **采样率** | 16kHz |
| **时长（微调）** | 10分钟以上（越多越好，推荐30分钟） |
| **音频质量** | 清晰无噪音，单人说话 |
| **内容** | 同一人的多段对话录音 |

### 录音建议

```bash
# 建议录音设备优先级
手机录音（48k）> 电脑麦克风 > 专业麦克风

# 录音内容建议
- 日常对话（300-500句）
- 每句5-30字
- 包含多种情感（开心、平静、疑问）
- 覆盖不同语速
```

## 3. 安装与使用

### pip 安装

```bash
pip install ChatTTS
```

### 基础推理（预训练音色）

```python
import ChatTTS

# 加载模型
chat = ChatTTS.Chat()

# 加载预训练模型（无需下载）
chat.load(source='huggingface', compile=True)  # 加速推理

# 生成语音
wave = chat.generate(
    text="你好，这是一段测试语音。我今天很开心。",
    stream=False,
    # 韵律参数
    params_refine_text=True,    # 优化标点
    params_top_P=0.7,           # 多样性
    params_top_K=20,            # 采样范围
)

# 保存
with open("output.wav", "wb") as f:
    f.write(wave[0]['audio'])
```

### 微调训练（音色定制）

ChatTTS 的微调通过 LoRA 实现，核心步骤：

```python
# 1. 准备数据集
# 目录结构：
# dataset/
#   ├── audio/        # WAV文件
#   └── metadata.csv  # 格式：audio_path|text

# 2. 微调训练
chat.finetune(
    dataset_path="./dataset",
    output_path="./chat_tts_lora",
    epochs=10,
    batch_size=8,
    lr=1e-4,
)

# 3. 加载微调后的模型
chat.load(source='custom', lora_path="./chat_tts_lora/lora.pt")

# 4. 使用定制音色生成
wave = chat.generate(text="你好，定制音色测试。")
```

### 完整训练脚本

```python
# train_chattts.py
from chat_tts import ChatTTS
from chat_tts.train import load_dataset, train_lora

# 加载数据集
dataset = load_dataset(
    path="./dataset",
    sample_rate=16000,
    max_duration=30,
)

# 训练 LoRA
train_lora(
    base_model='huggingface',  # 预训练底模
    dataset=dataset,
    output_dir='./output_lora',
    epochs=10,
    learning_rate=1e-4,
    warmup_steps=500,
)
```

## 4. 韵律控制（进阶）

ChatTTS 的核心优势是韵律控制：

```python
# 声音风格控制
params = {
    "temperature": 0.3,       # 随机性（越低越稳定）
    "top_p": 0.7,             # 核采样
    "top_k": 20,              # 高频采样
}

# 多声音角色（通过不同随机种子）
for seed in [0, 42, 100]:
    wave = chat.generate(
        text="这是一个多角色演示。",
        seed=seed,             # 不同seed产生不同音色
        **params
    )

# 对话生成（适合AI助手场景）
conversation = [
    {"role": "user", "text": "今天天气怎么样？"},
    {"role": "assistant", "text": "今天天气晴朗，适合出行。"},
    {"role": "user", "text": "有什么推荐的活动吗？"},
]
wave = chat.generate_conversation(conversation)
```

## 5. 常见问题

| 问题 | 解决方案 |
|------|----------|
| 音色不自然/机械感 | 降低 temperature，增加 top_k |
| 微调效果差 | 增加训练数据（建议30分钟以上） |
| 推理太慢 | 加载时设置 `compile=True`，使用 GPU |
| 中英文混杂发音差 | 使用 `params_refine_text=True` 预处理 |

### 性能对比

| 方案 | 生成10秒音频耗时 | 显存占用 | 需要的训练数据 |
|------|----------------|----------|----------------|
| ChatTTS（无微调） | ~1秒 | ~2GB | 0 |
| ChatTTS（LoRA微调） | ~1秒 | ~2GB | 10-30分钟 |
| GPT-SoVITS（微调） | ~10秒 | ~6GB | 1-10分钟 |

## 6. 与 OpenClaw 集成

```python
# chattts_skill.py
import ChatTTS
import base64
import io

class ChatTTSSkill:
    def __init__(self):
        self.chat = ChatTTS.Chat()
        self.chat.load(source='huggingface', compile=True)
    
    def generate(self, text, voice_seed=42):
        """生成语音"""
        wave = self.chat.generate(
            text=text,
            seed=voice_seed,
            stream=False,
        )
        return wave[0]['audio']
    
    def finetune(self, dataset_path, output_path):
        """微调音色"""
        self.chat.finetune(
            dataset_path=dataset_path,
            output_path=output_path,
            epochs=10,
        )
    
    def load_custom(self, lora_path):
        """加载定制音色"""
        self.chat.load(source='custom', lora_path=lora_path)
```

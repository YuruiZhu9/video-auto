## 一、方案简介

ChatTTS 是专为**对话场景**设计的文本转语音（TTS）模型，在 GitHub 发布5天即斩获 18K+ Stars，是 2024 年最火爆的开源语音项目之一。

**核心亮点：**
- 💬 **对话优化**：专为 LLMs 助手、聊天机器人设计
- 😊 **情感控制**：支持笑声（笑）、停顿、加粗等韵律控制
- 🇨🇳 **中英双语**：原生支持中文和英文
- ⚡ **极速推理**：生成速度极快，RTX 3060 可实时
- 🔧 **零克隆需求**：无需准备声音样本，直接生成自然语音
- 🆓 **完全免费**：MIT 开源协议

> ⚠️ **注意**：ChatTTS 本身是 TTS 生成模型（非克隆模型），如果你需要克隆特定音色，请看 [Qwen3-TTS](../Qwen3-TTS/部署指南.md) 或 [F5-TTS](../F5-TTS/部署指南.md)。

## 二、与声音克隆模型的区别

```
ChatTTS = TTS（文字→语音，非克隆）
F5-TTS = Zero-shot TTS（文字→克隆语音）
Qwen3-TTS = Few-shot TTS（3秒样本克隆）

用户需求选型：
├─ 想直接生成对话语音 → ChatTTS ✅
├─ 想克隆特定音色 → Qwen3-TTS / F5-TTS
└─ 想训练自己的音色模型 → GPT-SoVITS
```

### Python API 使用

```python
import ChatTTS
import torch

# 初始化
chat = ChatTTS.Chat()
chat.load(compile=False)  # 设置 True 可加速但首次慢

# ====== 基础生成 ======
texts = ["你好，欢迎使用ChatTTS，这是一个对话场景的语音生成测试。"]

# 标准生成
wavs = chat.infer(texts)
# wavs 是 list[ndarray]，每个元素是一个音频

# ====== 情感控制生成 ======
# 使用口语化、带有情感的文本
texts_expressive = [
    "[speed_0.9] 我今天真的太开心了，哈哈哈哈！[laugh] 这太有意思了。"
    "[break_0.5] 说真的，我觉得这个项目真的很棒。"
]
wavs_expressive = chat.infer(texts_expressive)

# ====== 保存音频 ======
import soundfile as sf
sf.write("output.wav", wavs[0], 24000)
print("✅ 已保存 output.wav")
```

## 五、进阶：控制参数详解

### 韵律标记（最重要）

| 标记 | 作用 | 示例 |
|------|------|------|
| `[speed_X]` | 控制语速 | `[speed_0.9]` 稍慢, `[speed_1.2]` 稍快 |
| `[break_X]` | 添加停顿 | `[break_0.5]` 停顿0.5秒 |
| `[laugh]` | 添加笑声 | 句末添加自动笑声 |
| `[oral_X]` | 口音强度 | `[oral_9]` 自然, `[oral_3]` 正式 |
| `[cough]` | 咳嗽 | `[cough]` |
| `[sig]` | 叹气 | `[sig]` |
| `[loud]` | 大声 | `[loud]` |

### 高级参数

```python
# 自定义采样参数
params_infer_code = ChatTTS.Chat.InferCodeParams(
    spk_emb = None,           # 说话人embedding（可固定音色）
    temperature = 0.2,         # 随机性（越小越稳定）
    top_P = 0.7,              # 核采样阈值
    top_K = 20,               # top-K采样
    refine_text = True,        # 是否精炼文本（推荐True）
)

params_refine_text = ChatTTS.Chat.RefineTextParams(
    prompt='oral_9,laugh_5,break_3',  # 全局韵律提示
)

# 生成
wavs = chat.infer(
    texts,
    params_refine_text=params_refine_text,
    params_infer_code=params_infer_code,
)
```

### 固定音色（类似克隆效果）

```python
# 通过固定随机种子获取一致音色
torch.manual_seed(42)
chat2 = ChatTTS.Chat()
chat2.load(compile=False)

# 生成多次音色一致
for i in range(3):
    torch.manual_seed(42)  # 相同种子 = 相同音色
    wavs = chat2.infer(["今天天气真不错，心情很好。"])
    sf.write(f"voice_{i}.wav", wavs[0], 24000)
```

## 六、与 OpenClaw Skills 集成

### 场景分析：ChatTTS 适合什么集成？

```
OpenClaw Agent
    ↓ 生成回复文案
ChatTTS 合成语音
    ↓ 输出 WAV/MP3
通过 TTS 工具（elevenlabs等）增强 → 更好的克隆效果
         ↓
    钉钉/消息发送

最佳组合：
ChatTTS（生成 → 控制韵律） + Qwen3-TTS/F5-TTS（克隆音色）
```

### OpenClaw Skill 示例

```python
# ===== chattts_skill.py =====

import ChatTTS
import soundfile as sf
import torch
import numpy as np

class ChatTTSSkill:
    def __init__(self):
        self.chat = ChatTTS.Chat()
        self.chat.load(compile=False)

    def generate(
        self,
        text: str,
        voice_seed: int = 42,
        speed: float = 1.0,
        emotion: str = "natural",
    ) -> str:
        """生成对话语音，返回文件路径"""
        torch.manual_seed(voice_seed)
        
        # 构建带韵律标记的文本
        if emotion == "happy":
            prompt = "oral_9,laugh_8,break_4"
        elif emotion == "serious":
            prompt = "oral_5,laugh_0,break_2"
        else:
            prompt = "oral_9,laugh_2,break_3"
        
        marked_text = f"[speed_{speed}] {text}"
        
        wavs = self.chat.infer([marked_text])
        output_path = "/workspace/voice_output/chattts_output.wav"
        sf.write(output_path, wavs[0], 24000)
        return output_path

# 使用示例
skill = ChatTTSSkill()
audio_path = skill.generate(
    text="今天给大家分享一个好消息，我们的新项目终于上线了！",
    emotion="happy",
    speed=1.0,
)
print(f"✅ 语音已生成：{audio_path}")
```

## 八、常见问题与解决

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 生成有杂音 | 环境噪音或模型未正确加载 | 清理环境，重新 `pip install` |
| 语速不自然 | 未使用韵律标记 | 添加 `[speed_0.9]` 调整 |
| 笑声太假 | 标记位置不对 | 笑声标记放句末 |
| 中文乱码 | Unicode显示问题 | 确保Python环境UTF-8 |
| WebUI 闪退 | 显卡驱动旧 | 更新 NVIDIA 驱动至 535+ |
| 显存不足 | 模型编译需显存 | 关闭其他程序，或设置 `compile=False` |

## 九、使用场景示例

### 1. 有声内容创作
```python
# 快速生成有声书段落
chapters = [
    "第一章，大雪纷飞的夜晚，小镇显得格外宁静。",
    "就在这时，门铃突然响了起来。",
    "他深吸一口气，推开了那扇沉重的门。",
]

all_audio = []
for text in chapters:
    torch.manual_seed(42)
    wavs = chat.infer([f"[speed_0.95] {text} [break_1]"])
    all_audio.extend(wavs[0])

sf.write("chapter1.wav", np.concatenate(all_audio), 24000)
```

### 2. AI 助手语音
```python
# 适合对话机器人的自然语音
response = "好的，我来帮你查询一下今天的天气情况。稍等片刻。"

torch.manual_seed(42)
wavs = chat.infer([response])
sf.write("assistant_voice.wav", wavs[0], 24000)
```

### 3. 情感对话
```python
# 带笑声和情感的对话
dialogue = [
    "[speed_1.0] 哈哈哈哈哈，这太好笑了！[laugh][break_0.5]",
    "[speed_0.9] 说真的，我完全同意你的观点。",
    "[speed_1.1] 别开玩笑了，这个真的很有用！",
]
wavs = chat.infer(dialogue)
```

# ChatTTS 详细部署指南

## 一、项目简介

ChatTTS 是专门为对话场景设计的文本转语音（TTS）模型，适用于 LLM 助手对话任务。支持中英文，最大模型使用10万小时以上数据训练。

**GitHub**: https://github.com/2noise/ChatTTS
**HuggingFace**: https://huggingface.co/2Noise/ChatTTS

---

## 二、环境准备

### 硬件要求

### 3. Python API 基本用法
```python
import ChatTTS
import torch
import torchaudio

# 初始化
chat = ChatTTS.Chat()
chat.load(compile=False)  # compile=True 可提升性能

# 待合成文本
texts = ["你好，欢迎使用ChatTTS", "这是一个测试文本"]

# 推理生成
wavs = chat.infer(texts)

# 保存音频
for i, wav in enumerate(wavs):
    torchaudio.save(f"output_{i}.wav", 
                    torch.from_numpy(wav).unsqueeze(0), 
                    24000)
```

### 4. 高级用法 - 说话人采样
```python
import ChatTTS

chat = ChatTTS.Chat()
chat.load(compile=False)

# 从高斯分布随机采样说话人
rand_spk = chat.sample_random_speaker()
print(f"说话人向量: {rand_spk}")  # 保存用于复用

# 推理参数配置
params_infer_code = ChatTTS.Chat.InferCodeParams(
    spk_emb=rand_spk,
    temperature=0.3,  # 采样温度
    top_P=0.7,       # 核采样
    top_K=20,        # Top-K采样
)

params_refine_text = ChatTTS.Chat.RefineTextParams(
    prompt='[oral_2][laugh_0][break_6]',  # 韵律提示
)

# 合成
texts = ["今天天气真好啊！"]
wavs = chat.infer(
    texts,
    params_refine_text=params_refine_text,
    params_infer_code=params_infer_code,
)

# 保存
torchaudio.save("output.wav", 
                torch.from_numpy(wavs[0]).unsqueeze(0), 
                24000)
```

### 5. 细粒度控制

#### 单词级别控制
```python
text = 'What is [uv_break]your favorite [lbreak]english food?[laugh]'
wavs = chat.infer(
    text, 
    skip_refine_text=True,
)
```

#### 控制Tokens表
| Token | 功能 |
|-------|------|
| `[laugh]` | 添加笑声 |
| `laugh_0`, `laugh_1`, `laugh_2` | 不同类型笑声 |
| `[uv_break]` | 单词间静音 |
| `[lbreak]` | 句子间停顿 |
| `oral_(0-9)` | 口语化程度 |
| `break_(0-7)` | 停顿时长 |

## 五、与OpenClaw集成

### 集成思路

1. **输入**：接收文本输入（通过消息/技能触发）
2. **处理**：调用ChatTTS API生成音频
3. **输出**：返回音频文件或CDN链接

### 示例代码
```python
import ChatTTS
import torch
import torchaudio
import os

def generate_speech(text: str, output_path: str = "/workspace/output.wav"):
    """生成语音并保存"""
    chat = ChatTTS.Chat()
    chat.load(compile=False)
    
    # 随机采样或使用固定说话人
    rand_spk = chat.sample_random_speaker()
    
    # 配置参数
    params_infer_code = ChatTTS.Chat.InferCodeParams(
        spk_emb=rand_spk,
        temperature=0.3,
    )
    
    params_refine_text = ChatTTS.Chat.RefineTextParams(
        prompt='[oral_2][laugh_0][break_6]',
    )
    
    # 生成
    wavs = chat.infer(
        [text],
        params_refine_text=params_refine_text,
        params_infer_code=params_infer_code,
    )
    
    # 保存
    torchaudio.save(output_path, 
                    torch.from_numpy(wavs[0]).unsqueeze(0), 
                    24000)
    
    return output_path
```

## 六、常见问题

### Q1: 音质不自然
- 调整 `temperature` 参数（0.1-0.5）
- 增加 `top_P` / `top_K` 值
- 多次采样选择最佳结果

### Q2: 推理太慢
- 设置 `compile=True` 提升性能
- 使用更强的GPU

### Q3: 笑声/停顿不生效
- 确保使用正确的控制Tokens
- 检查是否开启了 `skip_refine_text`

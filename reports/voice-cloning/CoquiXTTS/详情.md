# Coqui XTTS-v2 — 参考方案（已停止维护）

## ⚠️ 重要提醒

> **Coqui 公司已于2024年底宣布停止运营，XTTS-v2 模型不再更新。**
> 建议新项目使用 **CosyVoice 2.0** 替代，功能相似且持续更新。本文档仅作为技术参考。

## 方案概述

**XTTS-v2** 是 Coqui 开源的跨语言语音克隆模型，曾是零样本克隆标杆。

| 特性 | 状态 |
|------|------|
| 克隆方式 | 零样本（6秒参考） |
| 语言支持 | 17种语言 |
| 维护状态 | ❌ **已停止** |

## 为何用 CosyVoice 替代

| 对比项 | XTTS-v2 | CosyVoice 2.0 |
|--------|---------|---------------|
| 维护状态 | ❌ 停止 | ✅ 持续更新 |
| 中文支持 | ⚠️ 一般 | ⭐⭐⭐⭐⭐ |
| 克隆速度 | 6秒 | 3秒 |
| 情感控制 | ❌ 无 | ✅ 支持 |
| 许可证 | MPAA | Apache 2.0（可商用） |
| 当前可用性 | ❌ 不可用 | ✅ 完全可用 |

**结论：XTTS-v2 仅作参考，实际项目请使用 CosyVoice 2.0。**

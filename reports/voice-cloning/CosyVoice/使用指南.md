## 一、项目简介

CosyVoice 是**阿里巴巴通义实验室 FunAudioLLM 团队**开源的多语言语音生成大模型，是当前**中文开源语音克隆领域的综合最强方案**。

### CosyVoice 版本演进
| 版本 | 发布时间 | 核心能力 |
|------|---------|---------|
| CosyVoice 1.0 | 2024年 | 中文零样本克隆，情感控制 |
| CosyVoice 2.0 | 2025年中 | 多语言支持，流式推理，性能优化 |
| **CosyVoice 3.0** | **2025-12-15** | **9种语言+18+方言，发音修补，指令级控制** |

### 核心优势
- 🌏 **3秒极速克隆**：仅需3-10秒音频即可克隆音色
- 🎭 **精细情感控制**：支持开心、悲伤、愤怒、惊讶等情感
- 🔊 **9种语言+18+方言**：中文/英文/日文/韩文/粤语等
- 🏃 **实时流式输出**：RTX 3090 上单句生成约 0.8 秒
- 💼 **完全免费可商用**：Apache 2.0 许可证

## 三、快速使用

### 3.1 零样本克隆（无需训练）

```python
from cosyvoice import CosyVoice

# 加载模型（首次自动下载）
cosyvoice = CosyVoice('CosyVoice-300M-Instruct')

# 参考音频（3-10秒）
reference_audio = "path/to/reference.wav"

# 生成（中文示例）
result = cosyvoice.instruct(
    text="你好，今天是美好的一天。",
    reference_audio=reference_audio,
    instruction="用温柔的语气说",  # 指令控制情感
    stream=False
)

# 保存
with open("output.wav", "wb") as f:
    f.write(result['audio'])
```

### 3.2 零样本跨语言克隆

```python
from cosyvoice import CosyVoice

cosyvoice = CosyVoice('CosyVoice-300M-Instruct')

# 中文音色 → 英文内容
result = cosyvoice.instruct(
    text="This is an English sentence generated by a Chinese voice.",
    reference_audio="path/to/chinese_voice.wav",
    instruction="speak naturally",  # 英文指令也可以
)

with open("english_output.wav", "wb") as f:
    f.write(result['audio'])
```

### 3.3 使用预训练音色（无需自己录音）

```python
from cosyvoice import CosyVoice

cosyvoice = CosyVoice('CosyVoice-300M-SFT')

# 使用内置音色
result = cosyvoice.sft(
    text="你好，我是通义实验室的语音助手。",
    speaker="中文女声",  # 或 "中文男声", "英文女声" 等
)

with open("sft_output.wav", "wb") as f:
    f.write(result['audio'])
```

### 3.4 流式推理（适合实时对话）

```python
from cosyvoice import CosyVoice

cosyvoice = CosyVoice('CosyVoice-300M-Instruct')

# 流式生成
stream = cosyvoice.instruct_stream(
    text="这是一个流式输出的示例。",
    reference_audio="ref.wav",
    instruction="说得快一点"
)

# 逐步获取音频片段
for chunk in stream:
    # chunk 是音频片段，可实时播放或发送
    print(f"Received chunk: {len(chunk)} bytes")
```

## 四、完整训练/微调（可选）

> 如果零样本效果不够满意，可以微调进一步提升相似度。

### 4.1 数据准备

```
dataset/
├── utts/
│   ├── audio1.wav
│   ├── audio2.wav
│   └── ...
└── metadata.csv
```

**metadata.csv 格式：**
```csv
audio_path,duration,text
utts/audio1.wav,5.2,今天天气真好
utts/audio2.wav,4.8,我们去散步吧
```

### 4.2 数据预处理

```bash
# 音频格式转换（16kHz 单声道）
for f in dataset/utts/*.wav; do
  ffmpeg -i "$f" -ar 16000 -ac 1 -c:a pcm_s16le "${f%.wav}_16k.wav"
done

# 文本正则化（中文）
python -m cosyvoice.tools.normalizer_text \
  --input_text "你好，世界！" \
  --language zh
```

### 4.3 微调训练

```bash
# 单GPU训练
python cosyvoice/toolkit/train.py \
    --config cosyvoice/config/finetune.yaml \
    --train_csv dataset/metadata.csv \
    --output_dir checkpoints/my_voice

# 多GPU训练（加速）
torchrun --nproc_per_node=4 \
    cosyvoice/toolkit/train.py \
    --config cosyvoice/config/finetune.yaml \
    --train_csv dataset/metadata.csv \
    --output_dir checkpoints/my_voice
```

### 4.4 使用微调后的模型

```python
from cosyvoice import CosyVoice

# 加载微调模型
cosyvoice = CosyVoice('checkpoints/my_voice')

result = cosyvoice.instruct(
    text="你好，使用我自己微调的音色。",
    reference_audio="path/to/my_ref.wav",
)
```

## 七、API 服务化

```python
# app.py
from fastapi import FastAPI, UploadFile, File, Form
from cosyvoice import CosyVoice
import tempfile
import os
import uvicorn

app = FastAPI(title="CosyVoice API")

# 全局模型
model = None

@app.on_event("startup")
def startup():
    global model
    print("Loading CosyVoice model...")
    model = CosyVoice('CosyVoice-300M-Instruct')
    print("Model loaded!")

@app.post("/tts")
async def text_to_speech(
    text: str = Form(...),
    instruction: str = Form(""),
    reference_file: UploadFile = File(...),
    language: str = Form("zh")
):
    # 保存参考音频
    ref_path = tempfile.mktemp(suffix=".wav")
    with open(ref_path, "wb") as f:
        f.write(await reference_file.read())
    
    # 生成
    result = model.instruct(
        text=text,
        reference_audio=ref_path,
        instruction=instruction,
    )
    
    # 保存结果
    out_path = tempfile.mktemp(suffix=".wav")
    with open(out_path, "wb") as f:
        f.write(result['audio'])
    
    return {"audio_path": out_path}

@app.post("/tts_sft")
async def tts_sft(
    text: str = Form(...),
    speaker: str = Form("中文女声")
):
    result = model.sft(text=text, speaker=speaker)
    out_path = tempfile.mktemp(suffix=".wav")
    with open(out_path, "wb") as f:
        f.write(result['audio'])
    return {"audio_path": out_path}

# 启动
# uvicorn app:app --host 0.0.0.0 --port 8000 --reload
```

## 八、声音样本准备

| 项目 | 推荐要求 |
|------|---------|
| **格式** | WAV（16-bit PCM） |
| **采样率** | 16kHz / 22050Hz / 24kHz |
| **时长** | 零样本：3-10秒；微调：5-30分钟 |
| **音质** | 安静环境，无背景音乐，128kbps以上 |
| **内容** | 涵盖多种语句类型（陈述/疑问/感叹）|

### 录音环境
- 安静的室内（关窗、关电器）
- 避免硬质墙面（减少回声）
- 嘴离麦克风 15-30cm
- 可用手机耳机麦克风录制

### 录制脚本（Python）
```python
import sounddevice as sd
import numpy as np
import wavio

duration = 10  # 秒
sample_rate = 16000

print(f"Recording for {duration} seconds...")
audio = sd.rec(int(duration * sample_rate), 
               samplerate=sample_rate, 
               channels=1, 
               dtype='int16')
sd.wait()
print("Recording complete!")

# 保存
filename = "my_voice_sample.wav"
wavio.write(filename, audio, sample_rate)
print(f"Saved to {filename}")
```

# skill: cosyvoice-tts
"""
## 使用方式
用户发送: /clone 参考音频 + 文字内容
AI 调用 CosyVoice 生成并发送音频
"""

from cosyvoice import CosyVoice

_model = None

def init_model():
    global _model
    if _model is None:
        _model = CosyVoice('CosyVoice-300M-Instruct')
    return _model

def generate_voice(reference_audio: str, text: str, instruction: str = ""):
    model = init_model()
    result = model.instruct(
        text=text,

        instruction=instruction,
    )

## 十一、常见问题

| 问题 | 解决方案 |
|------|---------|
| 模型下载慢/失败 | 使用 ModelScope 或 HF 镜像：`export HF_ENDPOINT=https://hf-mirror.com` |
| 音色克隆不像 | ① 增加参考音频时长；② 使用更多样化的句子；③ 微调训练 |
| 多音字发音错误 | 使用 CosyVoice 发音修补功能（3.0新特性）|
| 显存不足 | 减小 batch_size，或切换到 0.5B 小模型 |
| 跨语言效果差 | 参考音频和目标语言差异大时，效果会下降 |
| 推理太慢 | 使用流式推理，或用 vLLM 加速（见官方 GitHub）|

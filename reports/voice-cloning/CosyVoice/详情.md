# CosyVoice 2.0 — 阿里通义实验室 🥇首选方案

## 1. 方案概述

**CosyVoice 2.0** 是阿里通义实验室 FunAudioLLM 团队开源的新一代生成式语音大模型，是目前**中文开源语音克隆领域综合实力最强**的方案。

### 核心能力

| 能力 | 说明 |
|------|------|
| 🎯 **3秒极速克隆** | 只需3秒参考音频即可克隆任意音色 |
| 🌍 **多语言支持** | 中文、英文、日语、粤语、韩语 |
| 🎭 **情感控制** | 支持自然语言指令控制情感（高兴/悲伤/愤怒等） |
| 🔄 **跨语言克隆** | 用中文参考音克隆英文音频 |
| ⚡ **快速推理** | 0.5B 模型，RTF < 0.1（消费级GPU可实时） |
| 🔓 **完全开源** | Apache 2.0 许可证，可商用 |

**GitHub：** `FunAudioLLM/CosyVoice`  
**模型大小：** 0.5B / 7B 两种规格  
**GitHub Stars：** 20k+

## 2. 声音样本准备要求

### 音频规格

| 项目 | 要求 |
|------|------|
| **格式** | WAV（推荐）或 MP3 |
| **采样率** | 16kHz 或 48kHz（推荐48k） |
| **时长** | **3秒以上即可克隆**，推荐10-30秒效果更稳定 |
| **文件大小** | 单条 < 5MB |
| **声道** | 单声道（mono） |
| **背景噪音** | 安静环境，无音乐/混响 |
| **内容** | 任意中文/英文语音均可 |

### 录音建议

```
✅ 推荐做法：
   - 用手机录音，距离嘴部约15cm
   - 选择安静的房间（夜间室内最佳）
   - 正常说话音量，语速自然
   - 内容可以是：自我介绍、朗读段落、日常对话

❌ 避免：
   - 有回声的大房间
   - 背景音乐或电视声
   - 刻意压低/提高音调
   - 录音被截断（确保音频完整）
```

### 批量样本（可选，提升质量）

如果想让克隆效果更接近真实音色，可以准备**多条短音频**：
```
样本1: "你好，我是小王"
样本2: "今天天气真不错"
样本3: "很高兴认识大家"
→ 总时长控制在1-3分钟效果最佳
```

## 4. 推理调用

### 基础用法（3秒克隆）

```python
from cosyvoice import CosyVoice

# 加载模型（首次自动下载）
cosyvoice = CosyVoice('cosyvoice2-0.5B')

# 方法1：3秒零样本克隆（最简单）
result = cosyvoice.inference_sft(
    text="你好，欢迎使用语音克隆技术。",
    prompt_text="今天天气真不错。",
    prompt_wav="path/to/your_voice.wav"
)
result.save("output.wav")

# 方法2：使用预设音色（无需参考音频）
result = cosyvoice.inference_sft(
    text="你好，欢迎使用语音克隆技术。",
    speaker="default_male"  # 预置音色
)
result.save("output.wav")
```

### 情感控制（进阶）

```python
# 自然语言控制情感
result = cosyvoice.inference_instruct(
    text="这个消息真是太棒了！",
    prompt_wav="path/to/your_voice.wav",
    instruct_text="用开心的语气，语速稍快"  # 情感指令
)
result.save("output_happy.wav")

# 更多情感示例
# "用悲伤的语气"
# "用愤怒的语调"
# "像新闻播报员一样正式"
# "像朋友聊天一样随意"
```

### API 服务化

```python
# 启动 FastAPI 服务
from fastapi import FastAPI
from cosyvoice import CosyVoice
import base64

app = FastAPI()
cosyvoice = CosyVoice('cosyvoice2-0.5B')

@app.post("/clone")
async def clone_voice(audio_b64: str, text: str):
    # 接收base64音频
    audio_bytes = base64.b64decode(audio_b64)
    with open("temp.wav", "wb") as f:
        f.write(audio_bytes)
    
    # 克隆
    result = cosyvoice.inference_sft(
        text=text,
        prompt_wav="temp.wav"
    )
    result.save("output.wav")
    
    # 返回base64
    with open("output.wav", "rb") as f:
        return {"audio": base64.b64encode(f.read()).decode()}
```

## 6. 常见问题与解决

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 音色不像 | 参考音频太短或质量差 | 增加样本数量，或用多条音频 |
| 生成速度慢 | 没有GPU或ONNX优化 | 使用 `onnxruntime-gpu`，或换用 0.5B 模型 |
| 中文发音错误 | 多音字/专有名词 | 在文本中用拼音标注，或用 `inference_instruct` |
| 音频有杂音 | 参考音频本身有噪音 | 重新录音，确保安静环境 |
| 跨语言效果差 | 跨语言克隆难度高 | 中文→英文推荐用 `instruct` 模式 |

### 性能优化技巧

```python
# 1. 使用 ONNX 加速（推理速度提升3-5倍）
cosyvoice = CosyVoice('cosyvoice2-0.5B', load_jit=True, load_trt=True)

# 2. 批量处理（适合长文本）
chunks = ["第一句话", "第二句话", "第三句话"]
for i, chunk in enumerate(chunks):
    result = cosyvoice.inference_sft(text=chunk, prompt_wav="voice.wav")
    result.save(f"output_{i}.wav")

# 3. 使用缓存（多次调用同一音色）
# CosyVoice 自动缓存音色特征，无需重复处理
```

## 8. 与 OpenClaw 集成

### 方案A：Python Subprocess（简单）

```python
# 在 OpenClaw skill 中调用
import subprocess
import json

def clone_voice(text, voice_file, output_file):
    cmd = [
        "python", "-c",
        f"""
from cosyvoice import CosyVoice
c = CosyVoice('cosyvoice2-0.5B')
r = c.inference_sft('{text}', prompt_wav='{voice_file}')
r.save('{output_file}')
"""
    ]
    result = subprocess.run(cmd, capture_output=True, text=True)
    return output_file
```

### 方案B：FastAPI 服务（推荐生产环境）

```bash
# 启动服务
uvicorn cosyvoice_api:app --host 0.0.0.0 --port 8080
```

```python
# cosyvoice_api.py
from fastapi import FastAPI
from pydantic import BaseModel
from cosyvoice import CosyVoice

app = FastAPI()
cosyvoice = CosyVoice('cosyvoice2-0.5B')

class CloneRequest(BaseModel):
    text: str
    voice_file: str  # 文件路径或URL

@app.post("/clone")
def clone(req: CloneRequest):
    result = cosyvoice.inference_sft(req.text, prompt_wav=req.voice_file)
    output = "/tmp/clone_output.wav"
    result.save(output)
    return {"file": output}
```

### OpenClaw Skill 示例

```javascript
// voice_clone_skill/index.js
const { spawn } = require('child_process');
const path = require('path');

async function cloneVoice(text, voicePath) {
  const outputPath = `/tmp/voice_${Date.now()}.wav`;
  
  const script = `
from cosyvoice import CosyVoice
c = CosyVoice('cosyvoice2-0.5B')
r = c.inference_sft('${text}', prompt_wav='${voicePath}')
r.save('${outputPath}')
`;
  
  return new Promise((resolve, reject) => {
    const proc = spawn('python', ['-c', script]);
    proc.on('close', () => resolve(outputPath));
    proc.on('error', reject);
  });
}

module.exports = { cloneVoice };
```

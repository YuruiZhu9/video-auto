## 2. 本地部署

### 2.1 克隆仓库

```bash
git clone --recursive https://github.com/FunAudioLLM/CosyVoice.git
cd CosyVoice
```

### 2.2 创建Python环境

```bash
conda create -n cosyvoice python=3.10 -y
conda activate cosyvoice
pip install -r requirements.txt
```

### 2.3 下载模型

**方式一：ModelScope（推荐国内）**

```python
from modelscope import snapshot_download

model_dir = snapshot_download(
    'FunAudioLLM/Fun-CosyVoice3-0.5B-2512', 
    local_dir='pretrained_models/Fun-CosyVoice3-0.5B'
)
```

**方式二：HuggingFace**

```python
from huggingface_hub import snapshot_download

model_dir = snapshot_download(
    'FunAudioLLM/Fun-CosyVoice3-0.5B-2512',
    local_dir='pretrained_models/Fun-CosyVoice3-0.5B'
)
```

### 2.4 启动Web Demo

```bash
python3 webui.py --port 50000 --model_dir pretrained_models/Fun-CosyVoice3-0.5B
```

访问 `http://localhost:50000` 即可使用。

## 3. Docker部署（生产环境推荐）

### 3.1 构建镜像

```bash
cd CosyVoice/runtime/python
docker build -t cosyvoice:v1.0 .
```

### 3.2 启动服务

**gRPC服务：**

```bash
docker run -d --runtime=nvidia \
  -p 50000:50000 \
  -v /path/to/models:/models \
  cosyvoice:v1.0 \
  /bin/bash -c "cd /opt/CosyVoice/CosyVoice/runtime/python/grpc && \
  python3 server.py --port 50000 --max_conc 4 --model_dir /models && sleep infinity"
```

**FastAPI服务：**

```bash
docker run -d --runtime=nvidia \
  -p 50000:50000 \
  -v /path/to/models:/models \
  cosyvoice:v1.0 \
  /bin/bash -c "cd /opt/CosyVoice/CosyVoice/runtime/python/fastapi && \
  python3 server.py --port 50000 --model_dir /models && sleep infinity"
```

### 3.3 TensorRT-LLM加速部署

```bash
cd runtime/triton_trtllm
docker compose up -d
```

可实现 **4倍加速**。

## 4. 推理调用

### 4.1 基础用法

```python
import soundfile as audio
from cosyvoice import CosyVoice

# 加载模型
cosyvoice = CosyVoice('Fun-CosyVoice3-0.5B')

# 零样本克隆 - 方式1：文本描述参考音色
output = cosyvoice.inference_zero_shot(
    '你好，欢迎来到语音合成世界。', 
    '中文女声-温暖音色', 
    'speech_rate=0.8'
)
audio.write('output1.wav', output['tts_speech'], 24000)

# 零样本克隆 - 方式2：音频参考
output = cosyvoice.inference_zero_shot(
    '今天天气真不错。',
    'path/to/reference.wav',
    'emotion=happy'
)
audio.write('output2.wav', output['tts_speech'], 24000)
```

### 4.2 支持的指令控制

| 参数 | 说明 | 示例 |
|------|------|------|
| `emotion` | 情感控制 | `emotion=happy/sad/angry/neutral` |
| `speech_rate` | 语速控制 | `speech_rate=0.8` (0.5-2.0) |
| `volume` | 音量控制 | `volume=1.2` |
| `pitch` | 音调控制 | `pitch=0` (-12到12) |
| `language` | 语言控制 | `language=zh/en/ja/ko` |
| `dialect` | 方言控制 | `dialect=siichuan` |

### 4.3 微调模型推理

```python
# 使用SFT微调模型
cosyvoice = CosyVoice('pretrained_models/CosyVoice-300M-SFT')

# 指令控制
output = cosyvoice.inference_instruct(
    '今天天气真好。',
    '中文女声-活泼',
    '用开心的语气朗读这段话。'
)
```

## 5. API服务搭建

### 5.1 FastAPI服务

```python
# server.py
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
import base64
import io
from cosyvoice import CosyVoice
import soundfile as audio

app = FastAPI()
cosyvoice = CosyVoice('Fun-CosyVoice3-0.5B')

class TTSRequest(BaseModel):
    text: str
    ref_audio: str = None  # base64或文件路径
    instruct: str = None

@app.post("/tts")
async def tts(request: TTSRequest):
    try:
        if request.ref_audio:
            output = cosyvoice.inference_zero_shot(
                request.text, 
                request.ref_audio,
                request.instruct or ''
            )
        else:
            output = cosyvoice.inference_sft(
                request.text, 
                '中文女声'
            )
        
        # 转换为base64
        buffer = io.BytesIO()
        audio.write(buffer, output['tts_speech'], 24000)
        buffer.seek(0)
        b64_audio = base64.b64encode(buffer.read()).decode()
        
        return {"audio": b64_audio, "sample_rate": 24000}
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

## 7. 常见问题

### Q1: 显存不足怎么办？
A: 使用FP16量化版本，或减小batch size

### Q2: 中文发音错误？
A: 使用 `--phone_ratio` 参数调整，或使用拼音输入

### Q3: 如何实现流式输出？
A: 使用CosyVoice2流式版本，或通过FastAPI的StreamingResponse

### Q4: 模型下载失败？
A: 使用ModelScope国内源，或配置代理

## 一、方案简介

F5-TTS（Fairy and Faithful Fast Flow-based Text-to-Speech）是上海交通大学等团队开发的零样本语音克隆模型，全名取自 "**F5** = 按下 F5 就能说话"。

**核心亮点：**
- 🕐 **2秒克隆**：仅需2秒音频即可零样本克隆音色
- 🎯 **高保真**：生成语音自然度高，音色相似度优秀
- 🌐 **多语言**：支持英语、中文等主流语言
- ⚡ **快速推理**：推理速度优于大多数同类模型
- 📜 **完全开源**：MIT 开源协议，免费商用

> 💡 **F5-TTS vs Qwen3-TTS**：两者都是零样本克隆，F5-TTS 稍早发布（2025年），Qwen3-TTS 是2026年新发布，修复了一些问题并支持更多语言。

## 二、声音样本准备要求

### 音频规格

| 项目 | 要求 |
|------|------|
| 格式 | WAV（推荐）或 MP3 |
| 时长 | **最短2秒**，推荐10~30秒 |
| 采样率 | 16kHz（标准）或 24kHz |
| 声道 | 单声道（mono） |
| 质量 | 高质量，无压缩（WAV > MP3）|

### 录音环境要求
- ✅ 安静室内，避免空调、风扇声
- ✅ 无混响，录音棚或普通房间均可
- ✅ 距离麦克风 15~30cm
- ✅ 语速自然，表达清晰
- ❌ 避免录进手机通知音、键盘声
- ❌ 录音末尾不要突然截止，留0.5秒自然衰减

### 录音内容建议

```
✅ 推荐录音内容：
1. 简单自我介绍："你好，我叫小明，今天很高兴认识大家"
2. 短段落：连贯朗读100-200字（如新闻、故事片段）
3. 即兴叙述：用自然语气讲述日常生活

录音技巧：
- 一次性录10-30秒即可（不用刻意长）
- 确保全程音频响度一致
- 避免刻意改变音色或夸张表演
```

## 四、推理使用（Python API）

### 基础零样本克隆

```python
from f5_tts import load_model, generate_audio

# 加载模型
model, cfg = load_model(name="F5-TTS", device="cuda")

# 克隆音频
ref_audio = "path/to/your_voice.wav"  # 2秒以上
ref_text = "你好，我叫小明，很高兴认识大家。"  # 参考音频对应的文本

text = "今天天气真不错，我想出去散散步。"

# 生成
audio = generate_audio(
    model=model,
    ref_audio=ref_audio,
    ref_text=ref_text,
    text=text,
    target_sr=24000,  # 采样率
    duration=None,     # 自动推断
)

# 保存
import soundfile as sf
sf.write("cloned_voice.wav", audio, 24000)
print("✅ 克隆语音已保存")
```

## 五、多音色克隆

```python
from f5_tts import load_model, generate_audio

model, cfg = load_model(name="F5-TTS", device="cuda")

# ====== 多音色同时克隆 ======
ref_audios = ["voice1.wav", "voice2.wav", "voice3.wav"]
ref_texts = ["文本1", "文本2", "文本3"]

text = "这是多音色混合测试，生成一段有趣的对话。"

# 生成（每次只用一段参考）
for i, (ref_audio, ref_text) in enumerate(zip(ref_audios, ref_texts)):
    audio = generate_audio(
        model, ref_audio, ref_text, text,
        target_sr=24000
    )
    sf.write(f"voice_{i}.wav", audio, 24000)

# ====== 跨语言克隆 ======
# 用中文音频参考，生成英文语音
ref_audio_cn = "chinese_voice.wav"
ref_text_cn = "今天天气很好"
text_en = "The weather is great today."

audio_en = generate_audio(model, ref_audio_cn, ref_text_cn, text_en, target_sr=24000)
sf.write("cross_lang.wav", audio_en, 24000)
```

## 六、与 OpenClaw Skills 集成

```python
# ===== f5_tts_wrapper.py =====

import os
import soundfile as sf
from f5_tts import load_model, generate_audio

class F5TTSWrapper:
    def __init__(self, device: str = None):
        self.device = device or ("cuda" if os.path.exists("/dev/nvidia0") else "cpu")
        print(f"🔄 加载 F5-TTS 模型（设备：{self.device}）...")
        self.model, self.cfg = load_model(name="F5-TTS", device=self.device)
        print("✅ 模型加载完成")

    def clone(
        self,
        ref_audio_path: str,
        ref_text: str,
        target_text: str,
        output_path: str = "/workspace/voice_output/f5tts_output.wav"
    ) -> str:
        """零样本克隆音色并生成语音"""
        audio = generate_audio(
            model=self.model,
            ref_audio=ref_audio_path,
            ref_text=ref_text,
            text=target_text,
            target_sr=24000,
        )
        
        # 确保输出目录存在
        os.makedirs(os.path.dirname(output_path), exist_ok=True)
        sf.write(output_path, audio, 24000)
        return output_path

# ===== OpenClaw Agent 集成 =====

AGENT_PROMPT = """
你是F5-TTS语音克隆助手。用户提供：
1. 参考音频文件（2秒以上）
2. 参考音频对应的文本
3. 要生成的语音文案

调用 F5TTSWrapper().clone() 生成克隆语音，返回音频文件路径。

示例：
输入：参考音频 voice.wav，参考文本"今天天气不错"，目标文案"欢迎大家收听我们的节目"
输出：克隆语音文件路径
"""
```

## 七、常见问题与解决

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| OOM 显存不足 | 显存 < 8GB | 减小 batch_size，或换用 CPU |
| 克隆音色不像 | 参考音频质量差/时长不足 | 确保2秒以上，音质清晰 |
| 生成有杂音 | 参考音频含噪音 | 更换纯净参考音频 |
| 跨语言发音不准 | 音素覆盖不足 | 参考音频和目标语言一致更好 |
| 推理速度慢 | 文本太长 | 分段生成，控制单次长度 |
| 语速不稳定 | 文本标点过多 | 添加标点或拆分成多段 |

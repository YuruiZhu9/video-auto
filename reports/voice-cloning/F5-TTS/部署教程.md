# F5-TTS 部署指南

## 一、模型简介

**F5-TTS** 是由上海交通大学联合剑桥大学等机构开发的开源语音生成模型，2024年10月发布。

### 核心特点
- 🎯 **零样本语音克隆**：仅需10秒参考音频即可克隆
- ⚡ **实时推理速度快**：实时率0.15，超越多数扩散模型
- 🌐 **多语言支持**：中英文，支持跨语言/方言平滑过渡
- 📚 **大规模训练数据**：10万小时多语言数据
- 🆓 **开源可商用**

### GitHub地址
https://github.com/SWivid/F5-TTS

## 二、声音样本准备

### 音频格式要求
- **格式**: WAV (推荐), MP3
- **采样率**: 16kHz 或 24kHz
- **时长**: 10-60秒（越长效果越好）
- **环境**: 安静、无混响、无背景音乐

### 录音建议
1. 使用手机录音即可，避免专业设备
2. 保持一致的语速和音量
3. 包含多种情感（可选）
4. 音频文件命名: `reference.wav`

### 预处理命令
```bash
# 使用ffmpeg统一采样率
ffmpeg -i input.mp3 -ar 24000 output.wav
```

## 四、推理使用

### 基础使用
```python
from f5_tts import F5TTS

# 初始化模型
model = F5TTS()

# 文本转语音
wav = model.generate(
    text="你好，这是一段测试语音。",
    ref_audio="reference.wav"
)

# 保存音频
model.save_wav(wav, "output.wav")
```

### 零样本克隆
```python
from f5_tts import F5TTS

model = F5TTS()

# 使用参考音频进行克隆
wav = model.generate(
    text="这是一段使用你声音克隆的语音。",
    ref_audio="your_voice.wav",
    ref_text="参考音频对应的文本内容"  # 可选
)

model.save_wav(wav, "cloned.wav")
```

### 控制参数
```python
wav = model.generate(
    text="语音速度控制测试",
    ref_audio="reference.wav",
    speed=1.2  # 语速控制，1.0为原始速度
)
```

## 五、训练/微调

### 数据准备
```bash
# 目录结构
train_data/
├── wavs/
│   ├── speaker1/
│   │   ├── 001.wav
│   │   └── 002.wav
│   └── speaker2/
└── metadata.csv

# metadata.csv格式
wavs/speaker1/001.wav|这是文本内容|中文
wavs/speaker1/002.wav|另一段文本|中文
```

### 训练命令
```bash
# 单卡训练
python train.py \
    --model_name my_voice \
    --train_data_path ./train_data \
    --epochs 100 \
    --batch_size 16

# 多卡训练
torchrun --nproc_per_node=4 train.py \
    --model_name my_voice \
    --train_data_path ./train_data
```

### 训练参数建议
- **batch_size**: 16-32（根据显存调整）
- **learning_rate**: 1e-4
- **epochs**: 50-100
- **保存间隔**: 每10个epoch

## 六、常见问题

### Q1: 克隆声音不像
**解决方案**:
- 增加参考音频时长（30秒以上效果更好）
- 确保参考音频质量清晰
- 尝试不同的参考音频片段

### Q2: 推理速度慢
**解决方案**:
- 使用FP16推理: `model = F5TTS(dtype="float16")`
- 批量处理多个文本
- 使用更强的GPU

### Q3: 中文发音不自然
**解决方案**:
- 确保参考音频是中文语音
- 使用高质量中文声码器
- 调整 `speed` 参数

### Q4: 显存不足
**解决方案**:
- 减小batch_size
- 使用梯度累积
- 使用量化模型

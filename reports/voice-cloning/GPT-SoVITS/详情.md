# GPT-SoVITS V2 — 微调效果最佳

## 1. 方案概述

**GPT-SoVITS** 是目前开源社区中**微调后音色相似度最高**的语音克隆方案。结合 GPT 的文本生成能力与 SoVITS 的声学模型，仅需 **1分钟音频**即可训练出高相似度的音色。

### 核心特点

| 特性 | 说明 |
|------|------|
| 🎯 **克隆方式** | 少样本微调（1分钟即可） |
| 🌏 **语言支持** | 中文、英文、日文、韩文、粤语 |
| 🎵 **音质评分** | ⭐⭐⭐⭐（微调后可达⭐⭐⭐⭐⭐） |
| 🔧 **定制程度** | 高，可精细控制发音/语速/韵律 |
| 📦 **包体大小** | 约 6GB（含底模） |
| ⚠️ **训练时间** | 30分钟 - 2小时（取决于数据量） |

**GitHub：** `iicmaiu/GPT-SoVITS`（35k+ Stars）  
**V2版本更新：** 更好的跨语言能力，更快的训练速度

## 2. 声音样本准备

### 音频规格

| 项目 | 要求 |
|------|------|
| **格式** | WAV（必须） |
| **采样率** | 16kHz 或 48kHz |
| **最短时长** | **1分钟**（V2版本缩短了最低要求） |
| **推荐时长** | 5-10分钟（效果显著提升） |
| **音频质量** | 清晰无噪音，单人说话，无背景音乐 |
| **格式要求** | 必须是原始PCM（非MP3重编码） |

### 数据预处理

```bash
# 自动切割音频（推荐）
python GPT_SoVITS/prepare_dataset.py \
    --input_dir ./raw_audio \
    --output_dir ./dataset \
    --sample_rate 16000 \
    --min_duration 1.0 \
    --max_duration 15.0
```

### 标注数据准备

```bash
# 生成标注（ASR自动标注）
python GPT_SoVITS/automatic_label.py \
    --audio_dir ./dataset \
    --output_file ./dataset/text.txt

# 手动校对标注（重要！）
# 格式：audio.wav|说话人|文本内容
# 示例：
# sample001.wav|ZH|今天天气很好
# sample002.wav|ZH|我们一起去吃饭吧
```

### 完整数据集结构

```
dataset/
├── raw/
│   └── 某人/
│       ├── 001.wav
│       ├── 002.wav
│       └── ...
├── 4-nameList.txt        # 训练列表（自动生成）
└── rename.sh             # 重命名脚本
```

## 3. 训练流程

### 步骤1：安装

```bash
# 方式1：整合包（Windows用户推荐）
# 下载：https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI/releases

# 方式2：源码安装
git clone https://github.com/iicmaiu/GPT-SoVITS.git
cd GPT-SoVITS
pip install -r requirements.txt
```

### 步骤2：数据预处理

```bash
# 音频切割
python GPT_SoVITS/audio_cut.py \
    --input ./raw_audio \
    --output ./cut_audio \
    --threshold -30 \        # 能量阈值
    --min_length 1000 \      # 最短ms
    --max_length 15000       # 最长ms

# ASR标注（需要联网）
python GPT_SoVITS/asr.py \
    --audio_dir ./cut_audio \
    --output ./dataset \
    --lang zh

# 生成训练集
python GPT_SoVITS/gen.bat  # Windows
# 或
bash GPT_SoVITS/gen.sh      # Linux/Mac
```

### 步骤3：训练底模（首次需要）

```bash
# 训练 SoVITS 底模（VITS变声器）
python GPT_SoVITS/train_sovits.py \
    --data ./dataset \
    --output ./models/sovits \
    --epochs 100 \
    --batch_size 8

# 训练 GPT 文本模型
python GPT_SoVITS/train_gpt.py \
    --data ./dataset \
    --sovits_path ./models/sovits/model.pth \
    --output ./models/gpt \
    --epochs 50 \
    --batch_size 4
```

### 步骤4：推理生成

```python
from GPT_SoVITS import GPTSoVITS

# 加载模型
gpt_sovits = GPTSoVITS(
    gpt_model="./models/gpt/gpt_model.pth",
    sovits_model="./models/sovits/model.pth",
)

# 生成语音
audio = gpt_sovits.generate(
    text="你好，这是一段测试语音。",  # 要生成的文本
    prompt_text="今天天气真不错。",    # 参考音频的文本
    prompt_wav="./reference.wav",     # 参考音频
    text_lang="zh",
    audio_lang="zh",
)

# 保存
with open("output.wav", "wb") as f:
    f.write(audio)
```

## 5. 常见问题

| 问题 | 解决方案 |
|------|----------|
| 训练后音色不像 | 增加训练数据，增加epochs |
| 显存不足（OOM） | 减小 batch_size，使用半精度 |
| 生成音频有杂音 | 检查原始音频质量，增加降噪预处理 |
| 跨语言效果差 | 使用对应语言的底模，或增加训练数据 |
| 训练时间太长 | 使用整合包（已优化），或减少数据量 |

### 显存优化

```python
# 半精度训练
```

## 6. 与 OpenClaw 集成

```python
# gpt_sovits_skill.py
import subprocess
import os

class GPTSovitsSkill:
    def __init__(self, model_dir="./models"):
        self.gpt_model = f"{model_dir}/gpt_model.pth"
        self.sovits_model = f"{model_dir}/sovits_model.pth"
    
    def generate(self, text, reference_wav, output_path):
        """调用GPT-SoVITS生成音频"""
        script = f"""
from GPT_SoVITS import GPTSoVITS
g = GPTSoVITS('{self.gpt_model}', '{self.sovits_model}')
a = g.generate(
    text='{text}',
    prompt_wav='{reference_wav}',
    prompt_text='',
    text_lang='zh',
)
with open('{output_path}', 'wb') as f:
    f.write(a)
"""
        result = subprocess.run(
            ["python", "-c", script],
            capture_output=True, text=True,
            timeout=120
        )
        if result.returncode != 0:
            raise RuntimeError(f"生成失败: {result.stderr}")
        return output_path
    
    def train(self, dataset_path, output_dir):
        """训练新音色"""
        # 调用训练脚本
        subprocess.run([
            "python", "train.py",
            "--data", dataset_path,
            "--output", output_dir,
        ], check=True)
```

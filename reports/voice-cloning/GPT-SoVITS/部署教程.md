# GPT-SoVITS 部署指南

## 一、模型简介

**GPT-SoVITS** 是国产开源项目，最新版本V3于2025年初更新，已收获33.2k+ GitHub Stars。

### 核心特点
- 🎯 **零样本TTS**: 仅需5秒语音即可克隆
- 📖 **少样本训练**: 1分钟数据效果更佳
- 🌏 **多语言支持**: 中文、英文、日文、韩文、粤语等
- 💻 **轻量级**: 模型仅407MB，适合笔记本运行
- 🎭 **情感复刻**: 语音克隆质量高，情感表现力强

### GitHub地址
https://github.com/RVC-Boss/GPT-SoVITS

## 二、声音样本准备

### 音频格式要求
- **格式**: WAV, MP3, FLAC, OGG
- **采样率**: 16kHz, 44100Hz 均可
- **时长**: 
  - 零样本: 5秒+
  - 少样本训练: 1-10分钟
- **质量**: 清晰无噪音，单人声

### 录音环境要求
1. ⏺️ 安静环境，避免空调、风扇噪音
2. 📍 室内录音，减少混响
3. 🎤 距离麦克风15-30cm
4. 📊 音量适中，避免爆音

### 文本内容建议
- 包含多种句子长度（短句、长句）
- 覆盖不同情感（平静、欢快、严肃）
- 涵盖常见汉字和词汇
- 总字数建议100字以上（训练时）

### 预处理
```bash
# 提取音频并降噪（使用demucs）
demucs --three-stems vocals input.wav

# 统一格式
ffmpeg -i input.wav -ar 16000 -ac 1 output.wav
```

## 三、环境配置

### 1. 环境要求
- **Python**: 3.8-3.10
- **CUDA**: 11.7+
- **显存**: 6GB+ (训练), 4GB (推理)

### 2. 安装步骤
```bash
# 克隆仓库
git clone https://github.com/RVC-Boss/GPT-SoVITS.git
cd GPT-SoVITS

# 创建虚拟环境
conda create -n gptsovits python=3.10
conda activate gptsovits

# 安装依赖
pip install -r requirements.txt

# 安装额外依赖（音频处理）
pip install soundfile librosa
```

### 3. 下载预训练模型
首次运行会自动下载，也可手动下载：
- `GPT-SoVITS-V3` 基础模型
- `cn_hubert` 中文特征提取器
- `vec768` 声码器

## 四、推理使用

### 方式一：WebUI界面
```bash
# 启动WebUI
python webui.py --share
```
访问生成的链接，上传参考音频和文本即可生成。

### 方式二：Python API
```python
from GPT_SoVITS.pipeline import TTSPipeline

# 初始化
pipeline = TTSPipeline(
    GPT_path="GPT-SoVITS-V3-8k",
    SoVITS_path="SoVITS-V3-8k"
)

# 零样本克隆
result = pipeline.generate(
    text="你好，这是语音克隆测试。",
    ref_audio="reference.wav",
    ref_text="参考音频的文本内容",
    top_p=0.7,
    temperature=1.0
)

# 保存
result.save("output.wav")
```

### 方式三：命令行
```bash

    -o "output.wav"
```

## 五、训练/微调

### 数据准备
```
dataset/
├── 0.wav          # 音频文件
├── 0.wav.txt     # 对应文本
├── 1.wav
├── 1.wav.txt
└── ...
```

### 训练步骤

#### 1. 数据预处理
```bash
python preprocess.py \
    --input_dir ./dataset \
    --output_dir ./processed
```

#### 2. 一键训练
```bash
# 完整训练流程
python train.py \
    --name my_voice \
    --dataset ./dataset \
    --epochs 50 \
    --batch_size 8 \
    --lr 1e-4
```

#### 3. 分步训练
```bash
# Step 1: 训练SoVITS
python train_sovits.py \
    --dataset ./processed \
    --epochs 100

# Step 2: 训练GPT
python train_gpt.py \
    --sovits_path ./weights/SoVITS.pth \
    --dataset ./processed \
    --epochs 50
```

### 训练参数建议
| 参数 | 推荐值 | 说明 |
|------|--------|------|
| batch_size | 4-8 | 显存不足时减小 |
| learning_rate | 1e-4 | GPT: 5e-5 |
| epochs | 50-100 | 根据数据量调整 |
| grad_accum | 4 | 梯度累积 |

### 训练监控
```bash
# 启动tensorboard
tensorboard --logdir ./logs
```

## 六、常见问题

### Q1: 零样本效果不好
**解决方案**:
- 增加参考音频时长到30秒以上
- 选择情感丰富的片段
- 调整 `top_p` (0.6-0.8) 和 `temperature` (0.8-1.2)

### Q2: 训练显存不足
**解决方案**:
```bash
# 使用梯度累积
python train.py --batch_size 2 --grad_accum 4

# 使用混合精度
python train.py --use_fp16
```

### Q3: 音质有问题
**解决方案**:
- 检查音频质量，去除噪音
- 增加训练数据量
- 尝试调整声码器

### Q4: 风格迁移不自然
**解决方案**:
- 选择多样性高的训练数据
- 调整情感控制参数
- 增加训练epoch

## 八、OpenClaw集成示例

```python
# voice_service.py
from GPT_SoVITS.pipeline import TTSPipeline
import os

class VoiceCloningService:
    def __init__(self):
        self.pipeline = TTSPipeline(
            GPT_path="GPT-SoVITS-V3-8k",
            SoVITS_path="SoVITS-V3-8k"
        )
    
    def clone_voice(self, text: str, ref_audio: str, ref_text: str = None) -> str:
        """克隆声音并生成语音"""
        result = self.pipeline.generate(
            text=text,
            ref_audio=ref_audio,
            ref_text=ref_text,
            top_p=0.7,
            temperature=1.0
        )
        output_path = f"/tmp/voice_{hash(text)}.wav"
        result.save(output_path)
        return output_path
```

## 1. 核心特性

| 特性 | 说明 |
|------|------|
| 🎙 零样本克隆 | 仅需一段参考音频即可复刻音色 |
| 😃 情感可控 | 支持参考音频/情感向量/文本描述调节 |

| ⚡ 高效推理 | 支持FP16、DeepSpeed加速 |

## 3. 安装部署

### 3.1 方式一：魔当软件（推荐新手）

1. 访问 https://seemts.com/zh/ 下载软件
2. 安装软件
3. 在魔当中搜索并安装 IndexTTS2
4. 修改安装目录（如 `D:\AI\indexTTS2`）
5. 点击安装
6. 完成后点击"我的AI"，浏览器访问 `127.0.0.1:7860`

### 3.2 方式二：官方仓库（开发者）

```bash
# 1. 克隆仓库
git clone https://github.com/index-tts/index-tts.git
cd index-tts

# 2. 安装git lfs
git lfs install
git lfs pull

# 3. 安装uv包管理器（必须）
pip install -U uv

# 4. 同步依赖环境
uv sync --all-extras

# 5. 下载模型权重
uv tool install "huggingface-hub[cli,hf_xet]"
hf download IndexTeam/IndexTTS-2 --local-dir=checkpoints
```

> ⚠️ 注意：官方仅支持 `uv`，使用 `pip` 或 `conda` 可能导致依赖冲突

### 3.3 方式三：Docker部署

```dockerfile
# Dockerfile
FROM pytorch/pytorch:2.1.0-cuda11.8-cudnn8-runtime

WORKDIR /app
RUN pip install -U uv

COPY . /app
RUN uv sync --all-extras

# 下载模型
RUN hf download IndexTeam/IndexTTS-2 --local-dir=checkpoints

CMD ["uv", "run", "webui.py"]
```

## 4. 使用方法

### 4.1 启动WebUI

```bash
uv run webui.py
# 浏览器访问 http://127.0.0.1:7860
```

### 4.2 Python API调用

```python
from indextts.infer_v2 import IndexTTS2
import soundfile as audio

# 初始化
tts = IndexTTS2(
    cfg_path="checkpoints/config.yaml",
    model_dir="checkpoints",
    use_fp16=True
)

# 基础零样本克隆
tts.infer(
    spk_audio_prompt="examples/voice_01.wav",
    text="大家好，这是IndexTTS2的语音合成演示。",
    output_path="gen.wav"
)

# 情感控制
tts.infer(
    spk_audio_prompt="examples/voice_01.wav",
    text="这场比赛太精彩了！",
    output_path="gen_emo.wav",
    emo_audio_prompt="examples/emo_excited.wav",  # 情感参考音频
    emo_alpha=0.8  # 情感强度 0-1
)

# 时长控制（用于视频配音口型对齐）
tts.infer(
    spk_audio_prompt="examples/voice_01.wav",
    text="欢迎观看本期视频。",
    output_path="gen_timed.wav",
    duration=3.0  # 精确控制3秒
)
```

### 4.3 参数说明

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `spk_audio_prompt` | str | 参考音色音频路径 | `"voice.wav"` |
| `text` | str | 待合成文本 | `"你好世界"` |
| `output_path` | str | 输出文件路径 | `"output.wav"` |
| `emo_audio_prompt` | str | 情感参考音频（可选） | `"happy.wav"` |
| `emo_alpha` | float | 情感强度 0-1（可选） | `0.8` |
| `duration` | float | 语音时长秒数（可选） | `3.0` |
| `pitch` | float | 音调调整（可选） | `0` |

## 5. API服务搭建

### 5.1 FastAPI服务

```python
# api.py
from fastapi import FastAPI, UploadFile, File, Form
from fastapi.responses import FileResponse
import tempfile
import os
from indextts.infer_v2 import IndexTTS2

app = FastAPI()
tts = IndexTTS2(
    cfg_path="checkpoints/config.yaml",
    model_dir="checkpoints",
    use_fp16=True
)

@app.post("/tts")
async def tts_endpoint(
    text: str = Form(...),
    file: UploadFile = File(None),
    emotion: float = Form(0.5),
    duration: float = Form(None)
):
    # 保存上传的参考音频
    ref_audio = "ref.wav"
    if file:
        with open(ref_audio, "wb") as f:
            f.write(await file.read())
    
    # 生成参数
    params = {
        "spk_audio_prompt": ref_audio if file else "examples/voice_01.wav",
        "text": text,
        "output_path": "output.wav"
    }
    
    if emotion != 0.5:
        params["emo_alpha"] = emotion
    if duration:
        params["duration"] = duration
    
    tts.infer(**params)
    return FileResponse("output.wav", media_type="audio/wav")

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

### 5.2 启动服务

```bash
uvicorn api:app --host 0.0.0.0 --port 8000
```

## 7. 常见问题

### Q1: 模型下载失败？
A: 检查网络，或使用镜像站点

### Q2: 显存不足？
A: 使用 `use_fp16=True`，或减小batch

### Q3: 情感效果不明显？
A: 调整 `emo_alpha` 参数（建议0.6-1.0）

### Q4: 时长控制不准确？
A: 时长控制适用于中等长度文本，过短文本效果有限

## 一、项目简介

OpenVoice 是由 MyShell 与 MIT 联合开发的即时语音克隆开源项目，于2024年发布 V2 版本。是目前**最成熟的免费即时语音克隆方案**之一，自2023年5月上线以来已处理**数千万次**克隆请求。

### 核心优势
- **即时克隆**：仅需 10-30 秒参考音频即可克隆音色
- **跨语言能力**：可使用一种语言的音色生成另一种语言（如中文音色说英文）
- **灵活风格控制**：支持情感、口音、语速等参数调节
- **多版本选择**：V1（轻量）、V2（高质量，支持更多语言）
- **完全免费**：MIT 许可证

## 三、快速使用

### 3.1 基础即时克隆（V2）

```python
import torch
from openvoice import OpenVoice

# 加载模型（V2）
model = OpenVoice.checkpoint_download(
    device="cuda",  # 或 "cpu"（速度较慢）
    market="shouting"  # 指定语言市场
)

# 方法1：使用内置音色（无需自己录音）
model.export(
    text="你好，欢迎使用OpenVoice！这是一个即时语音克隆示例。",
    speaker_id="zh_speaker_0",  # 内置中文音色
    output_path="/tmp/ov_output.wav",
    language="zh"
)
```

### 3.2 使用自定义参考音频克隆音色

```python
import torch
from openvoice import OpenVoice

# 加载模型
model = OpenVoice.checkpoint_download(device="cuda")

# 参考音频（你的声音样本）
reference_audio = "path/to/your_voice_sample.wav"

# 克隆并生成
model.clone_and_synthesize(
    text="你好，这是用我的声音克隆出来的语音。",
    reference_audio=reference_audio,
    output_path="/tmp/my_voice_clone.wav",
    language="zh"
)
```

### 3.3 跨语言克隆（特色功能）

```python
import torch
from openvoice import OpenVoice

model = OpenVoice.checkpoint_download(device="cuda")

# 中文音色参考 → 合成英文
reference_zh = "path/to/chinese_voice_sample.wav"

model.export(
    text="Hello, this is a cross-lingual voice cloning demonstration.",
    reference_audio=reference_zh,  # 中文音色
    output_path="/tmp/cross_lingual.wav",
    language="en"  # 英文内容
)
```

## 六、API 服务化

```python
# app.py
from fastapi import FastAPI, UploadFile, File, HTTPException
from openvoice import OpenVoice
import tempfile
import os

app = FastAPI(title="OpenVoice API")

# 全局模型（启动时加载）
model = None

@app.on_event("startup")
def load_model():
    global model
    model = OpenVoice.checkpoint_download(device="cuda")

@app.post("/clone")
async def clone_voice(
    text: str,
    reference_file: UploadFile = File(...),
    language: str = "zh"
):
    # 保存上传的参考音频
    with tempfile.NamedTemporaryFile(suffix=".wav", delete=False) as f:
        f.write(await reference_file.read())
        ref_path = f.name
    
    try:
        output_path = tempfile.mktemp(suffix=".wav")
        model.clone_and_synthesize(
            text=text,
            reference_audio=ref_path,
            output_path=output_path,
            language=language
        )
        return {"audio_path": output_path}
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))

# uvicorn app:app --host 0.0.0.0 --port 8000
```

## 七、声音样本准备

### 音频格式要求
| 项目 | 要求 |
|------|------|
| 格式 | WAV（推荐）/ MP3 / M4A |
| 采样率 | 16kHz 或 44.1kHz（越高越好）|
| 时长 | **10-30秒** 最佳 |
| 音质 | 128kbps 以上 |
| 环境 | 安静、无回声、无背景音乐 |

### 推荐录音内容
```
1. 自我介绍（3-5句）：
   "大家好，我叫小明，今天很高兴认识大家。"

2. 日常对话（5-10句）：
   "今天天气真好，适合出门散步。
    你喜欢吃水果吗？我特别喜欢苹果和橙子。"

3. 情感丰富的内容（3-5句）：
   "太棒了！这个消息太让人兴奋了！"
   "嗯，这个问题有点难，让我好好想想..."
```

### 录音技巧
- 使用手机录音即可，无需专业设备
- 保持嘴离麦克风 15-30cm
- 避免喷麦（不要正对麦克风说话）
- 尽量一次性录完 10-30 秒

## 九、性能优化

### 显存不足优化
```python
# 使用 CPU（牺牲速度换取显存）
model = OpenVoice.checkpoint_download(device="cpu")

# 或使用 V1 轻量版本
model = OpenVoice.checkpoint_download(
    device="cuda",
    version="v1"  # V1 显存需求更低
)
```

### 批量推理优化
```python
texts = [
    "第一句话。",
    "第二句话。",
    "第三句话。"
]
reference_audio = "ref.wav"

for i, text in enumerate(texts):
    model.clone_and_synthesize(
        text=text,
        reference_audio=reference_audio,
        output_path=f"/tmp/part_{i}.wav",
        language="zh"
    )
```

## 十、常见问题

| 问题 | 解决方案 |
|------|---------|
| 模型下载失败 | 设置 HF 镜像：`export HF_ENDPOINT=https://hf-mirror.com` |
| 克隆音色不像 | 增加参考音频时长（10-30秒），换更清晰的样本 |
| 生成音频有杂音 | 参考音频本身有噪声，预先降噪处理 |
| 显存不足（OOM） | 切换到 CPU 或使用 V1 轻量版 |
| 跨语言效果差 | V2 比 V1 好很多，建议使用 V2 |
| 推理速度慢 | 使用 GPU，V2 比 V1 速度更快 |

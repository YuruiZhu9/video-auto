# OpenVoice 部署指南

## 一、模型简介

**OpenVoice** 是MyShell团队打造的即时语音克隆技术，主打快速、零样本语音克隆。

### 核心特点
- ⚡ **瞬时克隆**: 无需大量训练数据，短音频即可
- 🎯 **零样本TTS**: 仅需参考音频即可生成
- 🌏 **多语言支持**: 中文、英文等
- 🔧 **可调节**: 音调、语速、情感可控
- 🆓 **免费开源**

### GitHub地址
https://github.com/myshell-ai/OpenVoice

## 二、与其他模型的区别

| 特性 | OpenVoice | GPT-SoVITS | F5-TTS |
|------|-----------|------------|--------|
| 克隆方式 | 即时零样本 | 零样本+微调 | 零样本 |
| 训练需求 | 无需训练 | 可微调 | 可微调 |
| 速度 | 最快 | 快 | 快 |
| 质量 | 中等 | 高 | 高 |
| 适用场景 | 快速测试 | 生产环境 | 实时应用 |

## 三、声音样本准备

### 音频要求
- **格式**: WAV, MP3
- **时长**: 10秒-5分钟
- **质量**: 清晰无噪音
- **内容**: 任意语音

### 预处理
```bash
# 降噪
ffmpeg -i input.wav -af "afftdn=nf=-25" output.wav

# 统一格式
ffmpeg -i input.wav -ar 16000 -ac 1 output.wav
```

## 五、使用方法

### 1. 基础TTS（无克隆）
```python
from openvoice import OpenVoice

# 初始化
model = OpenVoice()

# 生成语音
wav = model.tts(
    text="你好，这是OpenVoice测试。",
    language="zh",
    speed=1.0
)

# 保存
model.save_wav(wav, "output.wav")
```

### 2. 零样本语音克隆
```python
from openvoice import OpenVoice

model = OpenVoice()

# 使用参考音频克隆
wav = model.clone_voice(
    text="这是一段克隆语音。",
    ref_audio="reference.wav",
    language="zh"
)

model.save_wav(wav, "cloned.wav")
```

### 3. 声调/情感控制
```python
# 调整音调
wav = model.clone_voice(
    text="测试语音",
    ref_audio="reference.wav",
    pitch_shift=2  # 音调调整
)

# 调整语速
wav = model.clone_voice(
    text="测试语音",
    ref_audio="reference.wav",
    speed=1.2
)
```

## 六、Python API 完整示例

```python
import os
from openvoice import OpenVoice
from openvoice.text_utils import TextNormalizer

class VoiceService:
    def __init__(self, device='cuda'):
        self.model = OpenVoice(device=device)
        self.normalizer = TextNormalizer()
    
    def generate(
        self, 
        text: str, 
        ref_audio: str = None,
        language: str = "zh",
        **kwargs
    ) -> str:
        """生成语音
        
        Args:
            text: 输入文本
            ref_audio: 参考音频路径（可选，用于克隆）
            language: 语言代码
            **kwargs: 其他参数 (pitch, speed等)
        
        Returns:
            输出音频路径
        """
        # 文本规范化
        text = self.normalizer.normalize(text)
        
        if ref_audio:
            # 克隆模式
            wav = self.model.clone_voice(
                text=text,
                ref_audio=ref_audio,
                language=language,
                **kwargs
            )
        else:
            # 普通TTS
            wav = self.model.tts(
                text=text,
                language=language,
                **kwargs
            )
        
        # 保存
        output_path = f"/tmp/ov_{hash(text)}.wav"
        self.model.save_wav(wav, output_path)
        return output_path

# 使用示例
service = VoiceService()
audio_path = service.generate(
    text="你好，欢迎使用语音克隆服务！",
    ref_audio="my_voice.wav",
    pitch_shift=0,
    speed=1.0
)
print(f"生成音频: {audio_path}")
```

## 七、常见问题

### Q1: 克隆效果不稳定
**解决方案**:
- 使用更长的参考音频（30秒以上）
- 选择质量更高的音频
- 多次尝试不同的参考音频

### Q2: 声音有金属感
**解决方案**:
- 调整 `pitch_shift` 参数
- 使用更高质量的声码器
- 后处理去噪

### Q3: 生成速度慢
**解决方案**:
- 使用GPU加速
- 减少batch处理
- 使用量化模型

### Q4: 不支持某种语言
**解决方案**:
- 检查语言代码是否正确
- 更新模型版本
- 等待社区支持

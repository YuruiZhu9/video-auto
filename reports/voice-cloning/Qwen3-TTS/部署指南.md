| 模型 | 参数量 | 用途 |

| Qwen3-TTS-0.5B | 5亿 | 基础推理，轻量快速 |

- 🎨 **语音设计**：可通过自然语言描述生成新音色

## 二、声音样本准备要求

### 音频规格
| 项目 | 要求 |
|------|------|
| 格式 | WAV（推荐）或 MP3 |
| 时长 | **最短3秒**，推荐10~30秒 |
| 采样率 | 16kHz / 24kHz / 32kHz（越高越好） |
| 声道 | 单声道（mono） |
| 文件大小 | 单个文件 ≤ 10MB |
| 响度 | 正常说话音量，避免爆音 |

### 录音环境要求
- ✅ 安静室内，无明显背景噪音
- ✅ 无明显混响（不要在大理石/玻璃房间）
- ✅ 距离麦克风15~30cm
- ✅ 语气自然，语速中等
- ❌ 不要用手机免提录，环境音过多
- ❌ 避免录音末尾突然停止，留1秒自然收尾

### 录音内容建议
```
推荐内容（任选其一）：
1. 自我介绍朗读："你好，我叫XXX，很高兴认识大家"
2. 短文朗读：1-2段自然对话内容，约100字
3. 即兴说话：用日常语气说3-5句话

录音提示：
- 保持自然语速，不要刻意放慢
- 覆盖不同情绪（平静/开心均可）
- 避免唱歌或特殊发音
```

## 五、与 OpenClaw Skills 集成

### 集成架构

```
OpenClaw Agent
    ↓ 发送文本
Python 脚本（qwen3_tts_wrapper.py）
    ↓ 调用模型
Qwen3-TTS 模型（本地/远程）
    ↓ 输出音频
返回音频文件路径或 Base64
    ↓
通过钉钉/消息平台发送给用户
```

### OpenClaw Skill 配置

```python
# ===== qwen3_tts_skill.py =====

import subprocess
import os
import json
import soundfile as sf
import torch

# 模型配置（根据硬件调整）
MODEL_NAME = "Qwen/Qwen3-TTS-0.5B"
DEVICE = "cuda" if torch.cuda.is_available() else "cpu"

def load_model():
    """懒加载模型"""
    from transformers import AutoModelForCausalLM, AutoTokenizer
    tokenizer = AutoTokenizer.from_pretrained(MODEL_NAME, trust_remote_code=True)
    model = AutoModelForCausalLM.from_pretrained(
        MODEL_NAME,
        torch_dtype=torch.float16 if DEVICE == "cuda" else torch.float32,
        device_map="auto",
        trust_remote_code=True
    )
    return model, tokenizer

def generate_speech(text: str, ref_audio: str, output_path: str = "output.wav"):
    """生成克隆语音"""
    model, tokenizer = load_model()
    audio = model.generate(
        text=text,
        audio_prompt_path=ref_audio,
        max_new_tokens=1024,
        do_sample=True,
    )
    sf.write(output_path, audio.cpu().numpy(), samplerate=24000)
    return output_path

# ===== OpenClaw 集成入口 =====
AGENT_PROMPT = """
你是一个语音克隆助手。用户提供文案和参考音频路径，我将调用Qwen3-TTS生成克隆语音。

使用方式：
1. 用户发送文案 + 附上参考音频文件
2. 调用 generate_speech(text, ref_audio_path)
3. 返回生成的音频文件路径

示例：
- 输入：文案的文本内容
- 输出：音频文件路径（如 /workspace/voice_output/output.wav）
"""
```

## 六、常见问题与解决

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 克隆音色不像 | 参考音频质量差 | 更换高质量音频，确保安静环境 |
| 推理OOM显存不足 | 模型太大/显存不够 | 换用0.5B小模型，或batch_size=1 |
| 生成音频有杂音 | 采样率不匹配 | 确保输出用24000Hz，转换后再保存 |
| 中文发音错误 | 生僻字发音不准 | 在文本中加入拼音提示或换词 |
| 推理太慢 | CPU推理 | 使用CUDA GPU，或换用更小的0.5B模型 |
| 显存不足16GB | 3B模型太大 | 使用0.5B模型，float32转float16 |

### 硬件优化建议

```python
# 显存优化：使用量化
from transformers import BitsAndBytesConfig

quantization_config = BitsAndBytesConfig(
    load_in_4bit=True,  # 4bit量化，大幅减少显存
)
model = AutoModelForCausalLM.from_pretrained(
    MODEL_NAME,
    quantization_config=quantization_config,
    trust_remote_code=True
)

# 速度优化：batch处理
batch_texts = ["第一句", "第二句", "第三句"]
audios = model.generate(text=batch_texts, audio_prompt_path=ref_audio)
```

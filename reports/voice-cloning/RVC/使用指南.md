## 一、项目简介

RVC（Retrieval-based Voice Conversion，基于检索的语音转换）是一个开源实时变声框架。**不是 TTS（文字转语音），而是 VC（声音转换）**——输入你自己的声音，实时输出目标音色的声音。

### 核心特点
- 🎯 **极低训练数据需求**：仅需 5-10 分钟音频即可训练模型
- ⚡ **实时变声**：推理速度极快，支持实时通话变声
- 🔧 **操作简单**：WebUI 一键训练和推理
- 🌐 **社区丰富**：27,000+ 预训练音色模型分享
- 🔓 **完全免费**：MIT 许可证

### RVC vs 其他方案的定位区别

```
TTS（文字→声音）：  CosyVoice / OpenVoice / ChatTTS
VC（声音→声音）：  RVC ← 本篇主角
```

## 三、WebUI 使用（图形界面）

### 3.1 启动
```bash
python webui-web.py
# 访问 http://localhost:7860
```

### 3.2 训练自己的音色模型

**Step 1：准备音频数据**
```
dataset/
├── speaker1/
│   ├── audio1.wav
│   ├── audio2.wav
│   └── ...  (至少 10 条，5-30 分钟总量)
└── speaker2/
    └── ...
```

**音频要求：**
- 格式：WAV / MP3
- 采样率：16000Hz / 44100Hz
- 音质：安静、无混响、无背景音乐
- 说话内容：尽量覆盖多种语句

**Step 2：导入数据**
1. 打开 WebUI → "训练" 标签
2. 点击 "添加数据集"
3. 选择音频文件夹
4. 填写音色名称（如 `my_voice`）

**Step 3：配置训练参数**
| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 训练轮数 | 30-50 | 越多越好，但耗时更长 |
| 批量大小 | 4-8 | 显存不足则减小 |
| 学习率 | 0.0001 | 默认即可 |
| 采样率 | 40k / 32k | 越高越精细，显存需求越大 |

**Step 4：开始训练**
```
点击 "开始训练" → 等待 30-60 分钟 → 完成
模型保存在：logs/你的音色名/pth/
```

### 3.3 推理（变声）

**方式1：音频到音频**
1. WebUI → "推理" 标签
2. 选择或上传音色模型
3. 上传需要转换的音频
4. 调整参数（音高、响度等）
5. 点击 "转换" → 下载输出

**方式2：实时变声（通话）**
1. WebUI → "实时变声" 标签
2. 选择音色模型
3. 配置 ASIO 音频设备
4. 启动实时变声
5. 配合虚拟音频线（如 VB-Audio Cable）

## 四、命令行推理（适合集成）

```python
# inference.py
import torch
from rvc import RVC

# 加载模型（使用预训练音色）
rvc = RVC(model_path="path/to/your_model.pth", device="cuda")

# 变声
rvc.convert(
    input_path="input_audio.wav",
    output_path="output_audio.wav",
    pitch_shift=0,  # 音高调整（-12 到 +12）
    volume_gain=0,  # 音量调整（dB）
)
```

### 批量推理脚本
```bash
mkdir -p input output

# 将待转换音频放入 input/ 目录
for f in input/*.wav; do
  python -m rvc.infer \
    --model "logs/my_voice/pth/my_voice.pth" \
    --input "$f" \
    --output "output/$(basename $f)" \
    --pitch 0
done
```

## 六、与 OpenClaw Skills 集成

```python
# skill: rvc-voice-conversion
"""
## 使用方式
用户上传音频 → RVC 转换为目标音色 → 发送结果
输入：原始音频文件 + 目标音色模型
输出：变声后的音频
"""

import subprocess
import os
import tempfile

def voice_convert(
    input_audio: str,
    model_path: str,
    output_audio: str = None,
    pitch_shift: int = 0
) -> str:
    """使用 RVC 进行声音转换"""
    
    if output_audio is None:
        output_audio = tempfile.mktemp(suffix=".wav")
    
    # 调用 RVC 推理脚本
    cmd = [
        "python", "-m", "rvc.infer",
        "--model", model_path,
        "--input", input_audio,
        "--output", output_audio,
        "--pitch", str(pitch_shift)
    ]
    
    result = subprocess.run(cmd, capture_output=True, text=True)
    
    if result.returncode != 0:
        raise RuntimeError(f"RVC 推理失败: {result.stderr}")
    
    return output_audio

# 示例使用：

#     model_path="logs/miyano/pth/miyano.pth",
#     pitch_shift=3
# )
# message.send_audio(channel="dingtalk", target=user_id, audio_path=converted)
```

## 八、常见问题

| 问题 | 解决方案 |
|------|---------|
| 训练报 OOM（显存不足） | 减小 batch_size（设为2）或音频切片长度 |
| 推理音质差/有杂音 | 增加训练 epochs，或更换更清晰的音频 |
| 模型加载失败 | 确认 .pth 文件路径正确，版本匹配 |
| 音色不像 | 增加训练数据量（至少10分钟），覆盖多种语句 |
| 实时变声有延迟 | 减小音频切片大小，使用 faster inference 选项 |
| 音高明显失真 | 调整 pitch_shift 参数（±5 以内为宜）|
| 变声后仍有原声残留 | 使用 RVC v2 的完整训练，或尝试不同的模型 |
| 转换后语速变化 | RVC 主要改变音色，不应显著影响语速；检查音频是否有压缩 |

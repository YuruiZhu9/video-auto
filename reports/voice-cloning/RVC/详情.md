# RVC — 实时变声专用

## 1. 方案概述

**RVC（Retrieval-based Voice Conversion）** 是基于 VITS 架构的开源实时变声框架，核心能力是"变声"而非"克隆文字"。它将一个人的声音转换为另一个人的音色，但**保留原始音频的语调/语速/情感**。

### 核心特点

| 特性 | 说明 |
|------|------|
| 🎯 **定位** | 声音转换（Voice Conversion） |
| ⏱️ **最低样本** | 5-10分钟音频即可训练 |
| ⚡ **推理速度** | 极快，支持实时变声 |
| 🎵 **应用场景** | 歌曲翻唱、实时变声、游戏语音 |
| 🌏 **跨语言** | 受限，中文音色→英文语调效果一般 |
| 📦 **模型大小** | 约 1-2GB |

**GitHub：** `RVC-Project/Retrieval-based-Voice-Conversion-WebUI`（37k+ Stars）

## 2. 声音样本准备

### 音频规格

| 项目 | 要求 |
|------|------|
| **格式** | WAV / MP3 |
| **采样率** | 32kHz / 40kHz / 48kHz（选择训练选项） |
| **最短时长** | 5分钟（推荐10分钟以上） |
| **内容要求** | 清晰单人语音，最好覆盖多个音高范围 |
| **歌曲变声** | 需要干声（无人声伴奏分离后的干净人声） |

### 训练数据准备

```bash
# 音频切割（切成短片段）
python RVC/audio_tools/切割音频.py \
    --input ./source_voice.wav \
    --output ./cuts \
    --min_length 3 \
    --max_length 12

# 人声分离（用于歌曲）
python RVC/audio_tools/uvr5.py \
    --input ./song_with_music.wav \
    --output ./vocal_only.wav \
    --model_type HP5_only_pv    # 人声提取专用模型
```

## 3. 训练与推理

### 一键训练（WebUI）

```bash
# 启动WebUI
python RVC/infer-webui.py

# 浏览器打开 http://localhost:7860
# 训练步骤：
# 1. 选择"训练"标签页
# 2. 上传声音样本
# 3. 设置模型名称和参数
# 4. 点击"开始训练"
```

### 推理参数

| 参数 | 说明 | 建议值 |
|------|------|--------|
| `pitch` | 音高调整 | -12 到 +12（半音） |
| `filter_radius` | 滤波半径 | 3-7 |
| `index_rate` | 检索强度 | 0-1 |
| `hop_length` | 帧移 | 128（音质）或 512（速度） |
| `rms_mix_rate` | 音量归一化 | 0-1 |

### 命令行推理

```python
# rvc_inference.py
from rvc import RVC
import soundfile as sf
import numpy as np

# 加载模型
rvc = RVC(model_path="./models/my_voice.pth")

# 变声处理
audio, sr = sf.read("input_audio.wav")  # 输入音频
converted = rvc.infer(
    audio,
    pitch=0,           # 音高偏移
    filter_radius=3,   # 滤波参数
    index_rate=0.75,   # 检索强度
)
sf.write("output.wav", converted, sr)
```

## 4. 实时变声设置

### 虚拟声卡（Windows）

```
音频输入 → VB-Audio Cable → RVC推理 → 变声输出 → 应用/游戏
```

```bash
# 下载 VB-Audio Cable（免费虚拟声卡）
# 设置系统默认录音设备为 "CABLE Input"

# 启动实时推理服务
python RVC/realtime_vc.py \
    --input_device "CABLE Input" \
    --output_device "Speakers" \
    --model ./models/my_voice.pth \
    --pitch 0
```

### 实时推理参数优化

```python
# 低延迟配置（延迟 < 100ms）
config = {
    "hop_length": 128,      # 越小延迟越低
    "chunk_size": 512,       # 推理块大小
    "pipeline": "fusion",   # 融合模式
}
```

## 7. 常见问题

| 问题 | 解决方案 |
|------|----------|
| 变声后有杂音 | 增加训练数据，降低 hop_length |
| 音色不像 | 增加训练数据，使用reversal模式 |
| 延迟太高 | 减小 chunk_size，使用 GPU 推理 |
| 音高不自然 | 调整 pitch 参数，避免过大偏移 |
| 多人声音 | 过滤掉，使用单一声部 |

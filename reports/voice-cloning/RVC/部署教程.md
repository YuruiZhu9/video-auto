# RVC (Retrieval-based Voice Conversion) 部署指南

## 一、模型简介

**RVC** 是基于VITS开发的AI语音转换软件，被认为是目前最佳的开源免费实时语音变声方案。

### 核心特点
- 🎤 **实时变声**: 延迟低，适合直播、语音通话
- 📦 **轻量训练**: 仅需10分钟数据即可训练
- 🔄 **声音转换**: 不改变文本内容，只改变音色
- 🆓 **完全开源**: 免费使用
- 🌐 **社区成熟**: 大量预训练模型可用

### GitHub地址
https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI

## 二、适用场景

RVC是**声音转换**（Voice Conversion）而非**语音合成**（TTS）：
- ✅ 直播变声
- ✅ 语音聊天变声
- ✅ 游戏语音变声
- ✅ 录制好的音频变声
- ❌ 文字转语音（需要TTS模型）

## 三、声音样本准备

### 音频格式要求
- **格式**: WAV, MP3
- **采样率**: 40kHz (推荐), 48kHz
- **时长**: 
  - 最低: 10分钟
  - 推荐: 30分钟以上
- **音质**: 清晰无噪音

### 录音建议
1. 使用高音质麦克风
2. 保持稳定语速
3. 覆盖多种语句
4. 环境安静

### 预处理
```bash
# 提取人声（去除背景音乐）
demucs --three-stems vocals input.wav

# 统一采样率
ffmpeg -i input.wav -ar 40000 -ac 1 output.wav
```

## 五、WebUI使用

### 启动
```bash

python infer_webui.py

```

### 训练流程
1. **上传音频**: 将训练音频拖入界面
2. **预处理**: 点击"音频处理"
3. **设置参数**: 选择特征提取模型
4. **开始训练**: 等待训练完成
5. **导出模型**: 保存为.pth文件

### 推理流程
1. **加载模型**: 选择训练好的模型
2. **输入音频**: 上传待转换的音频
3. **参数调节**: 
   - 音高(Pitch): 调整声调
   - 相似度(F0): 调整音色接近度
4. **导出**: 下载转换后的音频

## 六、Python API

### 基础转换
```python
from infer import RVCInference

# 初始化
rvc = RVCInference(
    model_path="my_voice.pth",
    device="cuda"
)

# 声音转换
audio = rvc.convert(
    input_audio="input.wav",
    pitch=0,        # 音高调整（-12到+12）
    f0_method="rmvpe"  # 基频提取方法
)

# 保存
audio.export("output.wav", format="wav")
```

### 实时变声 (基础)
```python
import pyaudio
import numpy as np
from infer import RVCInference

rvc = RVCInference(model_path="my_voice.pth")

# 音频参数
CHUNK = 1024
FORMAT = pyaudio.paInt16
CHANNELS = 1
RATE = 40000

# 实时处理
p = pyaudio.PyAudio()
stream = p.open(format=FORMAT, channels=CHANNELS, rate=RATE, input=True, output=True)

while True:
    chunk = stream.read(CHUNK)
    # 处理音频...
    converted = rvc.process_chunk(chunk)
    stream.write(converted)
```

## 七、训练参数

### 训练参数建议
| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 训练轮数 | 100-200 | 数据少时增加 |
| 批量大小 | 4-8 | 显存决定 |
| 学习率 | 1e-4 | 可调整 |
| 保存间隔 | 10轮 | 模型保存 |

### 底模选择
- **V1**: 通用底模，兼容性最好
- **V2**: 效果更好，资源消耗更大
- **V2-onnx**: 支持ONNX加速

## 八、常见问题

### Q1: 变声效果不像
**解决方案**:
- 增加训练数据量
- 使用更高质量的训练音频
- 调整相似度参数

### Q2: 有杂音/失真
**解决方案**:
- 训练前去除噪音
- 降低音高调整幅度
- 检查麦克风质量

### Q3: 延迟太高
**解决方案**:
- 使用ONNX加速
- 减少模型层数
- 使用更快的声音处理

### Q4: 实时变声有卡顿
**解决方案**:
- 使用更快的推理引擎
- 减小音频buffer
- 使用GPU加速

## 🔊 二、方案详细对比

### 2.1 CosyVoice（阿里通义实验室）

**推荐指数：⭐⭐⭐⭐⭐**

#### 技术特性
- **零样本克隆**：仅需10-30秒音频即可克隆声音
- **多语言支持**：中文、英语、日语、韩语、德语、西班牙语、法语、意大利语、俄语
- **方言支持**：粤语、闽南语、四川话、东北话、山西话等18+种方言
- **情绪控制**：支持通过自然语言控制情绪、语速、音量
- **流式输出**：延迟低至150ms
- **SOTA性能**：说话人相似度可达78%

#### 声音样本准备要求
- **音频格式**：WAV/MP3
- **推荐时长**：10-30秒（最短可5秒）
- **采样率**：16kHz或48kHz
- **环境要求**：安静、无混响、无背景音乐
- **文本内容**：多样化的句子，覆盖不同情感

#### 训练/推理步骤

```bash
# 1. 克隆仓库
git clone --recursive https://github.com/FunAudioLLM/CosyVoice.git
cd CosyVoice

# 2. 创建环境
conda create -n cosyvoice -y python=3.10
conda activate cosyvoice
pip install -r requirements.txt

# 3. 安装系统依赖 (Ubuntu)
sudo apt-get install sox libsox-dev

# 4. 下载预训练模型
# 从 ModelScope 或 HuggingFace 下载

# 5. 启动Web界面
python3 webui.py --port 50000 --model_dir pretrained_models/CosyVoice-300M
```

#### API调用示例
```python
from cosyvoice import CosyVoice
cosyvoice = CosyVoice('CosyVoice-300M-SFT')

# 零样本克隆
output = cosyvoice.inference_zero_shot(
    '你好，我是语音助手。',  # 输入文本
    '参考音频路径.wav'       # 参考音频
)
```

#### 与OpenClaw集成
- 输入：文本内容
- 输出：音频文件（wav格式）
- 方式：通过Python脚本调用CosyVoice API生成音频

### 2.2 OpenVoice（MIT + MyShell）

**推荐指数：⭐⭐⭐⭐**

#### 技术特性
- **即时语音克隆**：仅需短音频片段即可克隆
- **精准音色克隆**：准确复制参考音色
- **零样本跨语言**：生成语言无需训练数据
- **灵活风格控制**：支持情绪、口音、节奏、停顿控制
- **免费商用**：MIT许可证

#### 声音样本准备要求
- **音频格式**：WAV/MP3
- **推荐时长**：3秒-1分钟
- **采样率**：16kHz以上
- **环境要求**：清晰语音、无噪音

### 2.3 ChatTTS

**推荐指数：⭐⭐⭐⭐**

#### 技术特性
- **专为对话场景设计**：适合LLM助手对话
- **自然度高**：情感表现力强
- **多说话人支持**：支持多人对话
- **精细韵律控制**：可调节语速、语调
- **在线可用**：有官网直接使用

#### 局限
- 本身不提供声音克隆功能（需要微调）
- 单次生成限制30秒
- 需处理高频噪音

#### 部署步骤

```bash
# 1. 安装
pip install ChatTTS

# 2. 基本使用
import ChatTTS
chat = ChatTTS.Chat()
chat.load()

# 生成语音
wav = chat.generate("你好，我是ChatTTS。")
```

#### 与OpenClaw集成
- 适合生成对话式语音
- 可通过tts工具直接输出

### 2.4 RVC (Retrieval-based-Voice-Conversion)

**推荐指数：⭐⭐⭐⭐**

- **音频格式**：WAV
- **推荐时长**：10-30分钟（越多越好）
- **采样率**：44100Hz
- **环境要求**：高品质录音
- **文本内容**：覆盖各种音素

### 7.1 IndexTTS 2.0（B站 Index团队）⭐⭐⭐⭐⭐

**发布背景**：2025年9月8日，B站 Index团队正式开源，是全球首个支持**毫秒级精确时长控制**的自回归零样本TTS系统。

#### 核心技术亮点
- **精准时长控制**：误差率低于0.02%，可精确控制语音时长
- **音色与情感解耦**：首次实现音色和情感的独立控制
- **零样本克隆**：仅需5秒音频即可完成高质量声音克隆
- **7种基础情感**：支持中性、高兴、悲伤、愤怒、恐惧、惊讶、厌恶的独立控制
- **中英双语**：中英文为主，混合输入时有特殊处理

#### 架构
- **T2S模块**：文本转语义token
- **S2M模块**：语义token转中间表示
- **T2E模块**：文本提示驱动的情感控制

#### 与其他方案对比优势
- 时长控制精度远超CosyVoice（CosyVoice无法精确控制生成语音的总时长）
- 情感控制为独立维度，不影响音色保真度

#### 部署建议
```bash
# 克隆仓库
git clone https://github.com/index-tts/index-tts.git
cd index-tts

# 官方提供 Docker / pip 两种部署方式
pip install index-tts

# 5秒克隆示例
python infer.py --ref_audio 5秒音频.wav --text "要合成的文本" --output out.wav
```

### 7.3 MiMo-V2-TTS（小米 · 限时免费）⭐⭐⭐⭐

**发布背景**：2026年3月18日，小米正式发布 MiMo-V2 系列三大模型，其中 **MiMo-V2-TTS** 为小米自研文本转语音基础模型，主打温暖、富有表现力的声音，面向 AI Agent 场景。

#### ⚠️ 重要说明：当前不支持声音克隆

> **官方明确标注：Voice Cloning — Status: Not currently supported。**
> MiMo-V2-TTS 是高质量 TTS 模型（输入文本 → 输出语音），但**不具备声音克隆能力**（即无法用少量音频样本克隆指定音色）。
> 如需声音克隆，推荐使用：CosyVoice / IndexTTS 2.0 / GPT-SoVITS。

#### 核心技术亮点

| 特性 | 说明 |
|------|------|
| **免费政策** | V2-TTS 限时免费（第一周全球免费；长期免费，后续待定） |
| **情感控制** | 通过 `<|style|>` 标签控制情绪：`<|happy|>`, `<|sad|>`, `<|angry|>` 等 |
| **方言支持** | 支持东北话/四川话/河南话/粤语等中文方言 |
| **角色扮演** | 支持指定角色风格：孙悟空、林黛玉等 |
| **精细音频标签** | 支持呼吸、咳嗽、停顿等精细韵律控制 |
| **唱歌风格** | 添加 `<|sing|>` 标签可生成唱歌风格 |
| **内置音色** | `mimo_default`（默认）、`default_zh`（中文女声）、`default_en`（英文女声） |
| **API 格式** | OpenAI 兼容格式 (`/v1/chat/completions`) |

#### API 调用示例

```python
import os
from openai import OpenAI
import base64

client = OpenAI(
    api_key=os.environ.get("MIMO_API_KEY"),
    base_url="https://api.xiaomimimo.com/v1"
)

completion = client.chat.completions.create(
    model="mimo-v2-tts",
    messages=[
        {"role": "user", "content": "你好，MiMo，今天天气怎么样？"},
        {"role": "assistant", "content": "<|happy|>今天天气很好，适合出门散步！"}
    ],
    audio={
        "format": "wav",
        "voice": "default_zh"
    }
)

message = completion.choices[0].message
audio_bytes = base64.b64decode(message.audio.data)
with open("audio_file.wav", "wb") as f:
    f.write(audio_bytes)
```

#### cURL 调用

```bash
curl --location --request POST 'https://api.xiaomimimo.com/v1/chat/completions' \
  --header "api-key: $MIMO_API_KEY" \
  --header 'Content-Type: application/json' \
  --data-raw '{
    "model": "mimo-v2-tts",
    "messages": [
      {"role": "user", "content": "Hello, MiMo, have you had lunch?"},
      {"role": "assistant", "content": "<|happy|>Yes, I had a sandwich."}
    ],
    "audio": {"format": "wav", "voice": "mimo_default"}
  }'
```

#### 情感/风格标签速查

| 类型 | 标签示例 | 说明 |
|------|----------|------|
| 情绪 | `<|happy|>`, `<|sad|>`, `<|angry|>` | 在文本前加情绪标签 |
| 语速 | `Speed up`, `Slow down` | 控制语速 |
| 角色 | `<|style|>Sun Wukong</style>` | 角色扮演 |
| 方言 | `<|style|>东北话</style>` | 中文方言 |
| 唱歌 | `<|sing|>` | 生成唱歌风格 |
| 精细控制 | `[cough]`, `_long sigh_`, `(sobbing)` | 停顿、呼吸、哭腔 |

|------|--------|------|
| AI Agent 语音交互 | ✅ 极佳 | 专为 Agent 场景设计，支持情绪/角色 |
| 有声书/播客 | ✅ 可用 | 内置音色丰富，支持方言 |
| 声音克隆 | ❌ 不支持 | 需使用 CosyVoice / IndexTTS |
| 唱歌合成 | ✅ 可用 | 需加 `<|sing|>` 标签 |
| 多语言播报 | ✅ 可用 | 中英文内置音色 |

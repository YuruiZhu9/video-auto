## 二、ChatTTS 方案详解

### 2.1 核心特性

- **对话优化**：专为LLM助手对话场景设计，支持多说话者
- **细粒度控制**：支持笑声 `[laugh]`、停顿 `[uv_break]`、语调控制
- **韵律预测**：自动预测自然语调，超越多数开源TTS
- **流式输出**：支持实时流式音频生成

### 2.2 声音样本准备

ChatTTS 不需要传统意义上的"克隆训练"，而是通过采样随机音色或使用参考音频生成。

**预设音色使用**：
```python

print(rand_spk)  # 保存此向量可复用
```

### 2.4 推理调用

**基础使用**：
```python
import ChatTTS
import torch
import torchaudio

chat = ChatTTS.Chat()
chat.load(compile=False)  # GPU上设为True提升性能

texts = ["你好，这是一个测试语音。", "ChatTTS支持多段文本输入。"]
wavs = chat.infer(texts)

for i, wav in enumerate(wavs):
    torchaudio.save(f"output_{i}.wav", torch.from_numpy(wav).unsqueeze(0), 24000)
```

**高级控制**：
```python
# 1. 设定音色（保存复现）
params_infer_code = ChatTTS.Chat.InferCodeParams(
    spk_emb=rand_spk,  # 之前sample的音色向量
    temperature=0.3,
    top_P=0.7,
    top_K=20,
)

# 2. 文本级别控制
params_refine_text = ChatTTS.Chat.RefineTextParams(
    prompt='[oral_2][laugh_0][break_6]',  # 韵律提示
)

# 3. 推理
wavs = chat.infer(
    texts,
    params_refine_text=params_refine_text,
    params_infer_code=params_infer_code,
)
```

**控制Token说明**：
| Token | 功能 | 范围 |
|-------|------|------|
| `[oral_(0-9)]` | 口语化程度 | 0-9 |
| `[laugh_(0-2)]` | 笑声强度 | 0-2 |
| `[break_(0-7)]` | 停顿长度 | 0-7 |
| `[uv_break]` | 单词间停顿 | - |
| `[lbreak]` | 句子间换行 | - |
| `[laugh]` | 插入笑声 | - |

### 2.5 硬件要求

- **显存**：4GB+ GPU（30秒音频）
- **推理速度**：RTF≈0.3（RTX 4090）
- **输出采样率**：24000Hz

### 2.6 常见问题

| 问题 | 解决方案 |
|------|----------|
| 音色不稳定 | 多次采样选择，或固定spk_emb向量 |
| 生成速度慢 | 使用vLLM加速（Linux only） |
| 声音机械化 | 调整temperature/top_P/top_K参数 |
| 情绪单一 | 使用控制token增强表现力 |

## 三、OpenVoice V2 方案详解

### 3.1 核心特性

- **即时克隆**：仅需短参考音频即可克隆音色
- **跨语言生成**：支持6种语言，中/英/日/韩/西/法
- **风格控制**：情感、口音、节奏、停顿、语调
- **免费商用**：MIT协议

### 3.2 声音样本准备

**参考音频要求**：
- 格式：WAV/MP3
- 时长：10秒-2分钟（越久效果越好）
- 环境：安静、无混响
- 内容：清晰发音的任意文本

### 3.3 环境配置

```bash
# 创建环境
conda create -n openvoice python=3.9
conda activate openvoice

# 安装PyTorch
conda install pytorch==1.13.1 torchvision==0.14.1 torchaudio==0.13.1 pytorch-cuda=11.7 -c pytorch -c nvidia

# 安装OpenVoice
pip install openvoice>=2.0.0
pip install -r https://raw.githubusercontent.com/myshell-ai/OpenVoice/master/requirements.txt
```

### 3.4 推理调用

```python
from openvoice import se_extractor
from openvoice.api import ToneColorConverter

# 1. 加载模型
converter = ToneColorConverter('checkpoint_dir/converter.pt', device='cuda')

# 2. 提取参考音频的音色向量
target_se = se_extractor.get_se('reference.wav', converter, silence_len=1, silence_thresh=-30, device='cuda')

# 3. 生成语音
# 先用基础TTS生成文本的音频，然后转换音色
output_wav = converter.convert(
    input_audio_path='tts_output.wav',
    ref_audio_path='reference.wav', 
    target_se=target_se,
    pitch_shift=0,  # 音高调整
)
```

### 3.5 与ChatTTS结合使用

```python

temp_wav = "temp_chattts.wav"
torchaudio.save(temp_wav, torch.from_numpy(wavs[0]).unsqueeze(0), 24000)

# 步骤2：用OpenVoice转换音色
target_se = se_extractor.get_se('my_voice_reference.wav', converter)

    input_audio_path=temp_wav,
    target_se=target_se,
)
```

### 5.4 集成代码示例

```python
import ChatTTS
import torch
import torchaudio
import os

class VoiceGenerator:
    def __init__(self):
        self.chat = ChatTTS.Chat()
        self.chat.load(compile=False)
        self.current_voice = None
    
    def generate(self, text, output_path="output.wav", voice_seed=None):
        # 设置音色
        if voice_seed:
            torch.manual_seed(voice_seed)
        
        # 生成
        wavs = self.chat.infer([text])
        
        # 保存
        torchaudio.save(
            output_path, 
            torch.from_numpy(wavs[0]).unsqueeze(0), 
            24000
        )
        return output_path
    
    def generate_with_voice(self, text, voice_vector, output_path="output.wav"):
        params = ChatTTS.Chat.InferCodeParams(
            spk_emb=voice_vector,
            temperature=0.3,
        )
        wavs = self.chat.infer([text], params_infer_code=params)
        torchaudio.save(output_path, torch.from_numpy(wavs[0]).unsqueeze(0), 24000)
        return output_path

# 使用
generator = VoiceGenerator()
audio_file = generator.generate("你好，这是测试语音。")
```

## 六、推荐方案选择

### 场景1：快速生成对话语音
- **推荐**：ChatTTS
- **优点**：无需训练、自然韵律、控制灵活
- **适用**：AI助手、语音对话

### 场景2：克隆特定声音
- **推荐**：OpenVoice + ChatTTS组合
- **优点**：即时克隆、支持跨语言
- **适用**：个性化语音、跨语言内容

### 场景3：深度定制专业音色
- **推荐**：Coqui TTS微调
- **优点**：完全可控、训练一次永久使用
- **适用**：品牌语音、有声书

---

## 七、总结与建议

1. **入门首选ChatTTS**：安装简单，效果好，适合大多数场景
2. **进阶使用OpenVoice**：需要克隆特定音色时使用
3. **深度定制Coqui TTS**：有长期稳定需求时可投入训练成本

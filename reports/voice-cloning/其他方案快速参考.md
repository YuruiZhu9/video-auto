## 一、CosyVoice2（阿里通义实验室）

**GitHub**: https://github.com/FunAudioLLM/CosyVoice
**Stars**: 20K+ | **协议**: Apache 2.0

### 核心能力
- 3~10秒样本克隆，支持情感控制
- 中文/英文/日语/粤语/韩语，跨语言合成
- 已大规模生产验证（阿里内部使用）

### 安装
```bash
pip install cosyvoice
```

### 使用
```python
from cosyvoice import CosyVoice

cosy = CosyVoice('CosyVoice-300M-SFT')
output = cosy.inference_sft(
    text='要生成的文本',
    prompt_text='参考音频对应文本',
    prompt_wav='ref.wav',
)
# output['audio'] 即为生成的音频
```

## 二、GPT-SoVITS

**GitHub**: https://github.com/RVC-Boss/GPT-SoVITS-WebUI
**Stars**: 30K+ | **协议**: MIT

### 核心能力
- 仅需1分钟录音即可训练专属音色
- 生成质量高，音色稳定，中英文支持
- 完整 WebUI（新手友好，Windows一键整合包）

### 安装（整合包，推荐新手）
```bash
# Windows 下载：https://github.com/RVC-Boss/GPT-SoVITS-WebUI/releases
# 解压后双击 go-webui.bat 即可
```

### 训练流程
```bash
# 1. 准备1分钟以上音频（WAV）
# 2. 放入 dataset_raw/ 目录
# 3. 预处理（切分+标注）
python GPT_SoVITS/preprocess_dataset.py

# 4. 训练 GPT（约2小时）
python GPT_SoVITS/finetune_gpt.py --exp_name my_voice

# 5. 训练 SoVITS（约2小时）
python GPT_SoVITS/finetune_sovits.py --exp_name my_voice

# 6. WebUI 推理
python GPT_SoVITS/gpt_sovits_webui.py
```

### 适用场景
- 训练专属音色（长期使用）
- 视频配音、有声内容创作
- 个性化语音助手

## 三、RVC（Retrieval-Based Voice Conversion）

**GitHub**: https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI
**Stars**: 40K+ | **协议**: MIT

### 核心能力
- **实时变声**：输入原声，输出目标音色
- 最低5~10分钟数据训练
- 推理速度极快，适合直播
- 支持跨语言转换
- 完整 WebUI

### 与 TTS 的关键区别
```
RVC = 声音转换（Voice Conversion）
     输入：已有音频/麦克风录音 → 音色转换 → 输出新音色音频
     
TTS = 文字转语音（Text-to-Speech）
     输入：文字 + 目标音色 → 合成语音输出
```

### 安装（整合包，推荐）
```bash
# Windows 一键：https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI/releases
# 下载解压后运行 webui.bat
```

### 训练音色
```bash
# 1. 准备5-10分钟高质量音频
# 2. 放入 dataset_raw/
# 3. 训练
python train.py --model_name my_voice --epochs 100
# 4. 得到 .pth 模型文件，在 WebUI 中使用
```

### 实时变声（直播配置）
```bash
# 搭配 VB-Audio Virtual Cable
# 麦克风 → RVC实时变声 → 直播软件
python webui.py --listen 0.0.0.0 --port 7860 --colab
```

### 适用场景
- 直播变声（实时）
- K歌变声、游戏语音变声
- 语音消息趣味化

## 四、OpenVoice V2

**GitHub**: https://github.com/myshell-ai/OpenVoice
**Stars**: 18K+ | **协议**: MIT

### 核心能力
- 即时克隆：1段音频样本即可
- 灵活的音色控制（情感、口音调节）
- 多语言支持
- 生产验证（服务数千万次）

### 安装
```bash
pip install openvoice
```

### 使用
```python
from openvoice.api import TTS as OpenVoiceTTS
from openvoice import se_extractor

tts = OpenVoiceTTS(config_path, device="cuda")
tts.load_ckpt(checkpoint_path)

# 提取音色
se = se_extractor.get_se("ref_voice.wav", model, ...)

# 生成
wav = tts.tts(text="要生成的文本", speaker=se, language="zh")
```

## 六、选型决策树

```
需要克隆特定人的声音？
├─ 即时用（不想训练）
│   ├─ 中文为主 → Qwen3-TTS ✅（3秒，Apache 2.0）
│   └─ 多语言 → OpenVoice V2 ✅（即时，多语）
│
├─ 长期使用（追求最佳效果）
│   ├─ 愿意训练2-4小时 → GPT-SoVITS ✅（最稳定）
│   └─ 想要快速 → CosyVoice2 ✅（3秒即可）
│
└─ 需要实时变声（直播/游戏）
    └─ RVC ✅（40K Stars，实时最强）

不需要克隆，想直接生成语音？
├─ 对话场景 → ChatTTS ✅（最自然，零门槛）
└─ 多语言 → Qwen3-TTS ✅（10种语言）
```

## 八、Chatterbox-Turbo（首个情感夸张控制开源 TTS）

**GitHub**: https://github.com/resemble-ai/chatterbox
**开发者**: Resemble AI | **协议**: 开源（具体见GitHub）

### 核心能力
- 🔥 **首个支持情感夸张控制的开源 TTS**：可放大/缩小情感强度
- ⚡ **超低延迟**：< 200ms，适合实时对话
- 🎭 **情感控制**：支持多种情感的情感夸张参数调节
- 🔒 **嵌入神经水印（PerTh）**：可追溯音频来源

### 安装
```bash
pip install chatterbox-tts
```

### 使用
```python
import ChatterboxTTS

tts = ChatterboxTTS()

# 生成带情感夸张的语音
audio = tts.tts(
    text="I can't believe this is happening!",
    emotion="excited",
    exaggeration=1.5,  # 1.0 = 原始情感，>1.0 = 放大，<1.0 = 减弱
)
```

### ⚠️ 注意
- 嵌入水印可能不适合所有商业场景
- 中文支持情况需进一步验证

### 适用场景
- 对话助手（实时，低延迟）
- 需要情感夸张的娱乐场景
- 情感表达丰富的语音内容

### Q1: 我只有 5-30 秒的音频，能克隆出好效果吗？

> ⚠️ **质量比数量更重要**：5秒干净音频 >> 30秒嘈杂音频
> 推荐录音环境：安静房间，靠近麦克风，不要背景音乐

### Q3: 声音样本要怎么录才效果好？

**黄金法则：安静、清晰、单人、无混响**

**✅ 推荐录音规范：**

```
设备：手机耳机麦克风 或 USB 麦克风
环境：安静房间，关闭门窗/风扇/空调
距离：距麦克风 10-15cm
音量：正常说话音量，避免爆音
时长：3-5分钟（实际使用会裁剪到30秒）
格式：WAV 16bit 44.1kHz（最高质量）
内容：念一段故事/新闻/任意中文段落
      （内容不重要，音色才是关键）
```

**❌ 避免以下情况：**
- 背景音乐/电视/人声嘈杂
- 录音有回声/混响
- 方言和普通话混说（除非目标就是方言）
- 音频被过度压缩（mp3 128kbps 以下）
- 录音时长过长（超过10分钟反而引入噪声）

**✅ 快速检查方法：**
```bash
# 用 ffprobe 检查音频质量（Linux/Mac）
ffprobe -i your_audio.wav -show_entries stream=sample_rate,channels,bits_per_sample -of default=noprint_wrappers=1

# 理想结果：44100 Hz, 1 channel (单声道), 16 bits
```

## 四、技术实战篇

### Q12: 克隆出来的声音不像，怎么提升相似度？

**🔧 相似度提升五步法：**

**Step 1：检查原始音频质量**
```bash
# 查看音频波形和频谱
ffmpeg -i audio.wav -af loudnorm=print_format=json -f null - 2>&1 | grep -A5 "input_i"
```
- 信噪比（SNR）> 20dB 为佳
- 删除静音片段、静音头尾
- 转换为单声道 16kHz（推荐）

**Step 2：增加训练数据量**
| 当前样本 | 建议增加 |
|---------|---------|
| 1分钟 | → 增加到5-10分钟 |
| 5分钟 | → 增加到20-30分钟 |
| 1小时 | → 基本满足深度微调需求 |

**Step 3：切换到相似度更高的模型**
```
低相似度：OpenVoice → CosyVoice2 → CosyVoice3 → LongCat-AudioDiT
                                        ↑ 相似度递增
```

**Step 4：调整推理参数**
```python
# CosyVoice3 提升相似度示例
result = cosyvoice.clone(
    text="要合成的文本",
    ref_audio="参考音频.wav",
    speed_factor=1.0,      # 语速：0.8-1.2之间调整
    emotion_strength=0.8,  # 情感强度：0.5-1.0之间调整
    top_k=5,               # top_k越小越接近原始音色
)
```

**Step 5：后处理增强**
```bash
# 音频标准化
ffmpeg -i output.wav -af loudnorm=I=-16:TP=-1.5:LRA=11:print_format=summary -ar 44100 normalized.wav

# 去噪（如果需要）
ffmpeg -i output.wav -af "afftdn=nf=-25" denoised.wav
```

### Q13: 生成的声音有电流音/杂音，怎么处理？

**常见问题原因及解决方案：**

| 问题 | 原因 | 解决方案 |
|-----|------|---------|
| 电流音/嗡嗡声 | 采样率不匹配 | 统一转换为 44100Hz |
| 噼啪声 | 模型推理不稳定 | 降低 batch_size |
| 金属音 | 音频压缩过度 | 使用 WAV 输出 |
| 忽快忽慢 | 模型收敛不足 | 增加训练轮数 |
| 发音错误 | ASR/音素错误 | 改用 CosyVoice3（有发音修补） |

**快速修复命令：**
```bash
# 1. 统一采样率
ffmpeg -i input.wav -ar 44100 -ac 1 -c:a pcm_s16le fixed.wav

# 2. 去杂音
ffmpeg -i input.wav -af "afftdn" cleaned.wav

# 3. 标准化音量
ffmpeg -i input.wav -af loudnorm=I=-16:TP=-1.5:LRA=11 normalized.wav

# 4. 导出为MP3（降低文件大小）
ffmpeg -i normalized.wav -b:a 192k output.mp3
```

### Q14: 长文本怎么合成？如何处理分段？

**长文本合成分两种策略：**

**策略 A：直接支持长文本（推荐）**
```python
# TADA：直接支持最长700秒
from Modelscope السيد import TextToSpeech
tts = TextToSpeech('TTS_shaoshang/CSRC-TTS')
result = tts.tts("这是很长的文本...")  # 直接传入，无需分段
```

**策略 B：需要分段处理**
```python
# 按标点符号分句
def split_long_text(text, max_chars=150):
    sentences = re.split(r'[。！？；\n]', text)
    chunks = []
    current = ""
    for s in sentences:
        if len(current) + len(s) < max_chars:
            current += s + "。"
        else:
            if current:
                chunks.append(current)
            current = s
    if current:
        chunks.append(current)
    return chunks

# 逐段合成后拼接
audio_segments = []
for chunk in split_long_text(long_text):
    audio = model.tts(chunk)
    audio_segments.append(audio)

# 合并音频
import soundfile as sf
combined = np.concatenate(audio_segments)
sf.write("long_output.wav", combined, 44100)
```

> 💡 **技巧**：在句子之间留 50-100ms 静音，让拼接更自然

### Q16: 显存不够用，怎么降低显存占用？

**显存优化五步法：**

| 优化手段 | 节省显存 | 方法 |
|---------|---------|------|
| **量化推理** | 50-70% | `--load-in-4bit` 或 `--load-in-8bit` |
| **梯度检查点** | 40% | `gradient_checkpointing=True` |
| **CPU卸载** | 60%+ | `device_map="auto"` |
| **batch_size=1** | 30% | 实时推理设 batch=1 |
| **使用小模型** | - | Kokoro-82M / CosyVoice2 Mini |

```python
# Qwen3-TTS 低显存模式
from transformers import AutoModelForCausalLM, BitsAndBytesConfig

quantization_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_compute_dtype="float16"
)
model = AutoModelForCausalLM.from_pretrained(
    "qwen-team/Qwen3-TTS-0.6B",
    quantization_config=quantization_config,
    device_map="auto"
)
```

## 八、常见坑避让指南

| 坑 | 描述 | 避让方法 |
|---|------|---------|
| 🚫 **音频格式坑** | 参考音频是 mp3，模型不兼容 | 转换为 WAV 16bit 44.1kHz |
| 🚫 **显存爆炸坑** | batch_size 设太大 OOM | 从 1 开始，逐步增加 |
| 🚫 **延迟坑** | 非流式模型每次等 10秒 | 换用流式模型（Qwen3-TTS/TADA） |
| 🚫 **方言坑** | 通用模型读不准方言词 | 用方言音频微调或选 GLM-TTS/CosyVoice3 |
| 🚫 **版权坑** | 克隆名人声音商用 | 仅个人/研究使用，不商用 |
| 🚫 **幻觉坑** | TTS 读错人名/专有名词 | 换用 TADA（零幻觉）或 CosyVoice3（发音修补） |
| 🚫 **采样率坑** | 输出音质差 | 统一用 44.1kHz/48kHz 输出 |
| 🚫 **拼接坑** | 长文本拼接有明显断层 | 留静音间隔，或用 TADA（700秒上下文） |
| 🚫 **克隆不似坑** | 参考音频质量差 | 重新录制干净音频，5秒高质量 > 30秒嘈杂 |
| 🚫 **内存泄漏坑** | 批量处理内存持续增长 | 每次推理后清理 GPU 缓存 |

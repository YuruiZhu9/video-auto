### 4.2 集成实现

**方案A：Python子进程调用**

```python
import subprocess
import os

def generate_speech(text, voice_ref=None, model="cosyvoice"):
    """调用开源TTS生成语音"""
    
    if model == "cosyvoice":
        cmd = [
            "python", "cosyvoice_infer.py",
            "--text", text,
            "--ref_audio", voice_ref or "",
            "--output", "output.wav"
        ]
    elif model == "chattts":
        cmd = [
            "python", "chattts_infer.py", 
            "--text", text,
            "--output", "output.wav"
        ]
    
    result = subprocess.run(cmd, capture_output=True, text=True)
    return "output.wav" if os.path.exists("output.wav") else None
```

## 五、常见问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| **音色不自然** | 训练数据不足/质量差 | 增加训练数据，改善录音环境 |
| **推理太慢** | GPU性能不足/未优化 | 使用量化模型/TensorRT加速 |
| **情绪单一** | 模型本身限制 | 使用支持情感的模型(Fish Speech) |
| **跨语言效果差** | 模型能力限制 | 使用CosyVoice/OpenVoice跨语言版本 |
| **发音错误** | 文本规范化问题 | 检查并修正输入文本 |
| **内存溢出** | 批处理过大 | 减小batch_size，分批处理 |

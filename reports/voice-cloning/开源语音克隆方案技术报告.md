## 二、ChatTTS 详解

### 2.1 项目介绍

ChatTTS 是专门为**对话场景**设计的文本转语音（TTS）模型，在 GitHub 上已获得 18k+ stars。支持中英文两种语言，最大的亮点是能够预测和控制细粒度的韵律特征，包括笑声、口语停顿等。

**官网**：https://chattts.com/  
**GitHub**：https://github.com/2noise/ChatTTS

### 2.4 基础使用代码

import torchaudio

# 初始化

### 2.5 高级用法 - 音色采样与控制

```python
# 采样一个随机音色（用于音色恢复）
rand_spk = chat.sample_random_speaker()
print(rand_spk)  # 保存此向量用于后续音色恢复

# 设置推理参数
params_infer_code = ChatTTS.Chat.InferCodeParams(
    spk_emb=rand_spk,    # 添加采样音色
    temperature=0.3,     # 温度参数
    top_P=0.7,           # Top-P 解码
    top_K=20,            # Top-K 解码
)

# 文本优化参数（控制韵律）
params_refine_text = ChatTTS.Chat.RefineTextParams(
    prompt='[oral_2][laugh_0][break_6]',  # 口语化、笑声、停顿
)

# 推理生成
wavs = chat.infer(
    texts,
    params_refine_text=params_refine_text,
    params_infer_code=params_infer_code,
)
```

### 2.6 控制tokens（韵律控制）

**句子级控制**：
- `[oral_0-9]` - 口语化程度控制
- `[laugh_0-2]` - 笑声控制
- `[break_0-7]` - 停顿控制

**单词级控制**：
- `[uv_break]` - 极短停顿
- `[laugh]` - 笑声
- `[lbreak]` - 换行停顿

import ChatTTS
import torch
import torchaudio
import os

def generate(text: str, output_dir: str = "/workspace/outputs") -> str:
    """生成语音并返回文件路径"""
    os.makedirs(output_dir, exist_ok=True)
    
    chat = ChatTTS.Chat()
    chat.load(compile=False)
    
    wavs = chat.infer([text])
    
    import time
    filename = f"speech_{int(time.time())}.wav"
    filepath = os.path.join(output_dir, filename)
    
    torchaudio.save(filepath, torch.from_numpy(wavs[0]).unsqueeze(0), 24000)
    return filepath

## 命令速查（3分钟跑通）

### 🔥 Qwen3-TTS（2026年首选，中文最强）

```bash
# 安装
pip install qwen3-tts torch --index-url https://download.pytorch.org/whl/cu128

# Python 使用（3秒克隆）
from qwen3_tts import Qwen3TTS
model = Qwen3TTS("Qwen/Qwen3-TTS-12Hz-1.7B-Base", quantize="int8")
audio = model.generate(text="你好，欢迎使用Qwen语音克隆！", ref_audio="参考.wav")
model.save(audio, "输出.wav")
```

### 🔥 CosyVoice2（中文克隆，阿里背书）

```bash
# 安装
git clone https://github.com/FunAudioLLM/CosyVoice.git
cd CosyVoice && pip install -r requirements.txt

# Python 使用
from cosyvoice.cli.cosyvoice import CosyVoice2
model = CosyVoice2('CosyVoice2-0.5B')
audio = model.inference_sft('今天天气真好。', '中文女声')
# 克隆模式
audio = model.inference_zero_shot('你好，我是AI助手。', ref_audio='音色参考.wav')
```

### 🔥 ChatTTS v2（无需克隆，对话场景）

```bash
# 安装
pip install ChatTTS

# Python 使用
import ChatTTS
chat = ChatTTS.Chat()
chat.load()
audio = chat.generate("今天我给大家介绍一下人工智能的最新进展。")
```

### 🔥 GPT-SoVITS v4（最高相似度，微调训练）

```bash
# 启动 WebUI
python GPT-SoVITS-webui.py
# 浏览器打开 http://localhost:9870
# 上传 5-10 分钟音频 → 自动切分 → 训练 1000 步 → 克隆推理
```

### 🔥 Fish Audio S2 Pro（最强表现力，多语言）

```bash
# 安装
pip install fish-audio-sdk

# Python 使用
from fish_audio import FishTTS
model = FishTTS("fishaudio/fish-speech-2")
audio = model.generate(text="Hello world", ref_audio="voice.wav")
```

### 🔥 LuxTTS（1GB 显存，150x 实时）

```bash
# 安装
pip install lux-tts

# Python 使用
from lux_tts import LuxTTS
model = LuxTTS()
audio = model.clone_and_speak(text="你好", ref_audio="参考音频.wav")
```

## 中文 vs 英文选择

```
中文内容？
├─ 是
│   ├─ 极低延迟（实时对话）→ LuxTTS / Orpheus TTS（中文部分）
│   ├─ 情感最丰富/方言/歌唱 → Xiaomi MiMo-V2-TTS
│   ├─ 克隆相似度最高 → GPT-SoVITS v4（微调）
│   ├─ 零样本快速（3秒）→ Qwen3-TTS / CosyVoice 3.0 / MOSS-TTS
│   └─ 有声书/超长内容 → TADA / CosyVoice 3.0
│
└─ 否（英文为主）
    ├─ 跨语言克隆 → Voxtral TTS / Dia2
    ├─ 超低延迟（<50ms）→ Orpheus TTS（25ms TTFA）
    ├─ 完全免费商用 → Dia2 / NeuTTS Air / Voxtral TTS
    └─ 高质量对话 → Sesame CSM / Chatterbox-TTS
```

## 常见坑与避让

| 坑 | 避让方法 |
|----|----------|
| Fish Audio S2 Pro 商用需授权 | 商用选 CosyVoice 3.0 / GLM-TTS（Apache 2.0） |
| MegaTTS3 即时克隆需预提取 | 用 CosyVoice2 替代或参考 MegaTTS3 官方流程 |
| OpenAudio S1 非商用授权 | CC-BY-NC-SA，商用选 GLM-TTS / CosyVoice 3.0 |
| XTTS-v2 商业授权 | 选开源替代方案（CosyVoice / MOSS-TTS） |
| 低显存跑大模型OOM | 选 0.6B 轻量版 / 开启 INT8 量化 / 降低 batch_size |
| 中文多音字发音错误 | 选 GLM-TTS（音素级控制）或 CosyVoice 3.0（发音修补） |
| 克隆音色不像 | 增加参考音频时长（5-10秒）+ 降噪处理 |
| 推理速度太慢 | 选 LuxTTS（150x实时）/ TADA（RTF 0.09）/ Orpheus（25ms） |

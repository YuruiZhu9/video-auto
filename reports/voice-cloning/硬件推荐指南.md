## 三、云端推理方案（零硬件投入）

如果你没有合适的GPU，可以通过以下方式使用开源模型：

### ☁️ 推荐云服务

| 服务 | 支持模型 | 成本 | 特点 |
|------|----------|------|------|
| **Groq (LPU)** | CosyVoice2/3 | $0.1-0.2/分钟 | 极速推理，极低延迟 |
| **Cerebras** | 各类LLM+TTS | 按量计费 | 超高速芯片 |
| **Modal** | 任意模型 | 按需付费 | 无服务器架构 |
| **Replicate** | ChatTTS/Fish Audio | 按次计费 | 快速部署 |
| **Hugging Face Spaces** | 各开源模型 | 免费/Pro | 即点即用 |

### 🔧 本地量化降配置技巧

即使显存不足，也可通过量化运行：

```bash
# INT8 量化（显存降低约50%）
from transformers import AutoModelForCausalLM, BitsAndBytesConfig

quantization_config = BitsAndBytesConfig(
    load_in_8bit=True
)
model = AutoModelForCausalLM.from_pretrained(
    "path/to/model",
    quantization_config=quantization_config
)

# INT4 量化（显存降低约75%）
quantization_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_compute_dtype="float16"
)
```

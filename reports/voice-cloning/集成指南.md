## 一、整体集成架构

```
用户发送文案 → OpenClaw 路由 → Skill 调用 → TTS 模型推理 → 音频输出 → 推送用户
```

OpenClaw 支持通过 `tts` 工具和 Skill 脚本两种方式集成语音克隆能力。

## 二、Qwen3-TTS 集成（推荐方案）

### 2.1 安装依赖

```python
# requirements.txt
qwen-tts>=1.0.0
torch>=2.0.0
```

### 2.2 Skill 脚本示例

```python
#!/usr/bin/env python3
"""
voice_clone_skill.py
调用 Qwen3-TTS 进行语音克隆
"""

import subprocess
import sys
import os

def install_deps():
    subprocess.check_call([
        sys.executable, "-m", "pip", "install", 
        "qwen-tts", "--quiet"
    ])

def clone_and_speak(text: str, ref_audio: str, output: str = "/workspace/tts_output.wav"):
    """将文案用克隆音色朗读"""
    try:
        from qwen_tts import TTS
    except ImportError:
        install_deps()
        from qwen_tts import TTS

    tts = TTS(model_name="qwen3-tts", device="cuda")
    
    # 克隆音色 + 生成
    tts.clone_voice(audio_path=ref_audio, text=text)
    tts.save(output)
    
    return output

def design_voice_speak(text: str, description: str, output: str = "/workspace/tts_output.wav"):
    """用自然语言设计声音并朗读"""
    try:
        from qwen_tts import TTS
    except ImportError:
        install_deps()
        from qwen_tts import TTS

    tts = TTS(model_name="qwen3-tts", device="cuda")
    tts.design_voice(description=description, text=text)
    tts.save(output)
    
    return output

if __name__ == "__main__":
    import json
    msg = json.loads(sys.argv[1])
    text = msg["text"]
    ref_audio = msg.get("ref_audio", None)
    desc = msg.get("description", None)
    
    if ref_audio:
        path = clone_and_speak(text, ref_audio)
    elif desc:
        path = design_voice_speak(text, desc)
    else:
        # 使用默认音色
        from qwen_tts import TTS
        tts = TTS(model_name="qwen3-tts", device="cuda")
        tts.tts_to_file(text=text, file_path="/workspace/tts_output.wav")
        path = "/workspace/tts_output.wav"
    
    print(path)
```

## 三、ChatTTS 集成（对话场景）

### 3.1 安装依赖

```bash
pip install ChatTTS
```

### 3.2 Skill 脚本

```python
#!/usr/bin/env python3
"""
chattts_skill.py
ChatTTS 对话语音生成
"""

import ChatTTS
import torch
import json
import sys

def generate_speech(text: str, output: str = "/workspace/chat_tts_output.wav", 
                    with_laughs: bool = False, speed: float = 1.0):
    """生成对话语音"""
    chat = ChatTTS.Chat()
    chat.load()
    
    # 可选：调整语速
    chat.cfg = chat.cfg | {"speed": speed}
    
    if with_laughs:
        # 加入韵律标记（笑声、停顿）
        text = f"[ laughs ] {text} [ laughs ]"
    
    wave = chat.tts(text)
    chat.save_wav(output, wave)
    
    return output

if __name__ == "__main__":
    msg = json.loads(sys.argv[1])
    text = msg["text"]
    laughs = msg.get("with_laughs", False)
    speed = msg.get("speed", 1.0)
    out = msg.get("output", "/workspace/chat_tts_output.wav")
    
    path = generate_speech(text, output=out, with_laughs=laughs, speed=speed)
    print(path)
```

```bash
  -v ./weights:/app/weights \
  --name rvc-webui \

# 或本地运行
python RVC.py --port 7860 --colab
```

### 4.2 通过 API 调用

```python
import requests
import base64

def rvc_voice_convert(
    audio_path: str, 
    model_path: str, 
    api_url: str = "http://localhost:7860"
):
    """将音频通过RVC模型变声"""
    
    # 1. 上传音频
    with open(audio_path, "rb") as f:
        audio_b64 = base64.b64encode(f.read()).decode()
    
    # 2. 调用推理API
    resp = requests.post(f"{api_url}/voice_convert", json={
        "audio_base64": audio_b64,
        "model_name": "my_voice_model.pth",
        "pitch_change": 0,  # 音高调整
        "protect": 0.5     # 保护清音
    })
    
    result = resp.json()
    return result["output_wav_base64"]

def rvc_realtime_stream(audio_chunk: bytes, model_name: str):
    """实时变声流（直播场景）"""
    resp = requests.post(
        f"http://localhost:7860/realtime_convert",
        files={"audio": audio_chunk},
        data={"model": model_name}
    )
    return resp.content
```

## 五、OpenClaw Skill 注册方式

将脚本放到 OpenClaw 的 skills 目录：

```bash
# 目录结构示例
/root/.openclaw/
├── skills/
│   ├── voice_clone/
│   │   ├── SKILL.md          # Skill 定义
│   │   ├── voice_clone_skill.py   # 主脚本
│   │   └── requirements.txt
```

### SKILL.md 示例：

```markdown
# 语音克隆 Skill

## 触发条件
当用户说"克隆我的声音"、"用这个声音读..."时激活

## 输入参数
- text: 要朗读的文案（必填）
- ref_audio: 参考音频路径（可选）
- description: 自然语言描述（可选）

## 输出
生成.wav音频文件，推送给用户

## 调用示例
{"text": "今天天气真好", "ref_audio": "/workspace/my_voice.wav"}
```

## 六、工作流组合推荐

### 场景1：用户发文案 → 自动用用户声音朗读

```
用户发送语音样本（ref_audio）
    ↓
Qwen3-TTS 克隆音色（3秒即可）
    ↓
Qwen3-TTS 生成目标文案语音
    ↓
tts 推送音频给用户
总耗时：<5秒
```

### 场景2：AI对话助手自动配音

```
AI生成回复文案
    ↓
ChatTTS 生成自然对话语音（含笑声/停顿）
    ↓
推送语音给用户
适用：客服机器人、AI伴侣
```

### 场景3：实时变声（直播/游戏）

```
麦克风输入
    ↓
RVC V2 实时变声（170ms延迟）
    ↓
输出到扬声器/直播
适用：直播变声、游戏语音、游戏NPC
```

## 七、常见问题与解决

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| Qwen3-TTS 克隆声音不自然 | 参考音频质量差 | 使用安静、无混响的录音 |
| ChatTTS 推理很慢 | GPU内存不足 | 减少batch_size或使用量化模型 |
| RVC 变声有杂音 | 底模不匹配 | 使用RVCv3最新底模 |
| 生成音频有截断 | 文本太长 | 将长文本分段生成后拼接 |
| OpenVoice V2 中文发音不准 | 语言混合 | 尽量保持中/英文分开生成 |
| 声音相似度低 | 训练数据太少 | GPT-SoVITS至少5分钟高质量音频 |

## 八、音频样本准备规范

无论使用哪种模型，以下规范能显著提升克隆质量：

### 音频格式
```
推荐格式：WAV（PCM编码）
采样率：16kHz（必须）
位深：16bit
声道：单声道
音频时长：3秒（Qwen3-TTS最小）~ 5-30分钟（GPT-SoVITS推荐）
```

### 录音环境
```
✅ 安静室内（无空调声、窗外车声）
✅ 近距离录音（麦克风距嘴10-20cm）
✅ 录音清晰（无爆音、无削波）
❌ 避免：音乐背景、混响大、空旷房间
```

### 文本内容建议
```
✅ 覆盖多种情感（开心、平静、疑问）
✅ 覆盖多种句式（短句、长句、疑问句）
✅ 覆盖常见发音（平翘舌、鼻音）
推荐朗读内容：新闻、故事、对话混合
```
